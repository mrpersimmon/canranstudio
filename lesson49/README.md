# Lesson 49 · 肉店大冒险

孩子以肉店学徒的身份学习词汇、课文和句型。当前工作分支是 `codex/butcher-version`；这里说明本地功能，是否上线需另查发布记录。

按[本地预览方法](../README.md#本地预览)启动网站后，打开 [Lesson 49](http://127.0.0.1:4173/lesson49/)。

## 学什么、怎么玩

五关在同一长页依次展开，每项练习只显示当前题。可用顶部导航复习；活动完成后主动点“下一站”。

| 关卡 | 活动与内容 |
| --- | --- |
| 开门准备 | 17 张词卡，按 6／6／5 分组；点卡听音、翻面。听音寻宝连续完成 14 个词。 |
| 肉店小剧场 | 先看 3 个听前问题，再听 11 段对白。故事小侦探共 5 题：3 题理解原文，2 题应用到新情境。 |
| 招呼有妙招 | 练 Do／Are、give 的表达顺序、表达用途和 too／either。 |
| 店员训练场 | 12 道四类别主语分类题，错题隔题回练；再练动词形式、句子判断和词块拼句。 |
| 小店我当家 | 10 道综合题，分成两组；五关各满 3 星可领取、保存或打印证书。 |

检查、重试和换题在当前活动内完成。末题先显示反馈，再由孩子手动完成；“怎么玩”“线索”和“学徒手记”按需打开。听音寻宝不提供线索。

## 内容与声音

题目、顺序、提示和音频映射统一来自[课程清单](../core/course-catalog.js)。录音放在本课 `audio/`；课文按 Sonia／Ryan 分角色朗读。补充录音的来源和参数保存在同名 `.provenance.json` 中。

词句朗读与答题反馈音各有用途。点读、展示对白或声音播放失败都不能自动算答对；只有当前句真实播放结束才新增“听完”记录。反馈音来源见[素材记录](../assets/feedback/provenance.json)。

## 修改这课时要检查

先对照[现行标准与验收清单](../docs/butcher-version/2026-09-19-2117-v1.14-Lesson49现行标准与验收清单.md)。

两课合并的独立版本见 [Lesson 49–50 单元试作](../docs/butcher-version/2026-09-19-2117-v1.0-Lesson49-50教学单元试作.md)。它使用独立进度，不替代本课。

运行 `npm run test:l49:behavior`，并实际操作以下场景：

- 空记录和旧记录都能完成全部 14 道听辨题；历史成绩不预填新一轮答案。
- 刷新后能续练，完成后能整轮重练；星星与手记保留。
- 当前句和历史句可以交替重听；取消播放后，旧声音的结束通知不影响新内容。
- 提示、重试、正确反馈、末题完成和词块撤回都可用，手机上主按钮位置稳定。
- 题目准确、答案有明确依据；内容仍有疑问的题目先完成[教学复核](../docs/butcher-version/2026-09-14-0119-v1.10-题目教学正确性要求与复核.md)。

词块拼句统一支持点选加入、再次点击撤回，全部选齐后才能检查。刷新和重试保留候选顺序。
