# 新朋友见面会 · Lesson 5–6

从“我的课程”进入，或打开本地 `/unit5-6/`。启动方式见[项目首页](../README.md)。

先看带音标的 24 张词卡，再听完整的 20 句课堂介绍。五关共 27 道必做题，练习问候、介绍新朋友、国籍、he／she／it、a／an、选择问句和否定后说明正确情况。六款汽车、两组示范与十组替换问答都可点读，纸笔练习可打印；完成五关领取 15 星证书。

共用要求见[统一设计标准 v1.20](../docs/butcher-version/publish/2026-09-24-2031-v1.20-教学单元设计标准与验收清单.md)，教材页码、逐题依据、词典和实际验收见[单元文档](../docs/butcher-version/2026-09-21-1132-v1.0-Lesson5-6教学单元与验收.md)。内容在 `content.js`，80 段录音的文字、来源与生成参数在 `audio/manifest.json`。

学习记录独立。页面测试不替代人工听审、教师验收和儿童试用；本地新增不等于线上发布。
