# Lesson 49–50 素材

本轮先以认可的 Lesson 1–2／3–4／5–6 纪念卡为参考，由内置 imagegen 生成肉店交接近景，再从同一稿导出老板与 Mrs. Bird 的完整全身姿态。老板朝右，夫人朝左；页面不镜像人物或姓名。

- `keepsake-story-v2.webp`：纪念卡与纪念册的近景。`cover-scene.svg`、`completion-scene.svg`嵌入同稿；没有烘焙姓名、星数或日期。
- `butcher*.svg`、`bird*.svg`：三姿态透明原稿按栏裁切、保留安全留白导出，再嵌入SVG。透明边缘、手脚、持物与不同屏幕逐姿态检查。
- `room.svg`、`counter.svg`、`scale.svg`和选择／关系符号为本地矢量场景与语义图标；沿用旧课蔬果素材。背景允许随舞台伸展，人物与道具保持比例。
- 旧肉类图标与历史背景保留，冻结旧页面的升级验收仍依赖它们。

原始生成图、逐次提示词与生成来源见[证据目录](../../docs/butcher-version/evidence/2026-10-13-0130-unit49-50/imagegen-prompts.md)。该目录保存未经裁切的原稿。题稿、来源页码和本地／发布边界见[设计与验收](../../docs/butcher-version/2026-10-13-0130-v2.0-Lesson49-50设计与验收.md)。
