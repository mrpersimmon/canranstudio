# Lesson 43–44 素材依据

Sam和Penny是教材连续出现的人物，沿用41–42的金发蓝外套、棕发领巾身份，本课增加厨房围裙和寻找／指示姿态。圆角深棕描边、浅蓝绿厨房、黄色水壶和珊瑚红圆茶壶组成独立场景。

- 原生SVG：图鉴、场景和选项共用。`room`、`counter`、`cabinet-empty`提供空间；水壶、茶壶、茶叶、杯子分层，茶叶部分被茶壶遮挡。
- 原文水开只在最后一句出现，杯子仍在柜里；新情境中检查正确后，同一对杯子才移到水壶前。
- `keepsake-story-v1.webp`：内置imagegen参照认可的1–2／3–4／5–6插画，近景表现Penny指出茶叶、Sam发现它。无姓名、星数或日期，动态信息由账号产生。只做格式转换和缩小，透明背景保留。[完整提示词与来源](../../docs/butcher-version/evidence/2026-10-12-1542-unit43-44/manifest.json)。
