Christine为深色圆短发、米白发夹、赭黄开衫；Ann为赤褐卷发、鼠尾草绿上衣、扇边领。奶油纸、棕色描边和柔和明暗延续认可纪念卡；身份、衣着与相邻办公室单元有明确区别。

- 先用imagegen生成两人在茶点桌旁递饼干的纪念卡，再以同一稿生成各三种全身姿态。Christine面向右，Ann面向左；人物、姓名不整体镜像。

- `keepsake-story-v1.webp`共用于课程卡、获星浮层、纪念册和GIF；姓名、星位、日期、课号由账号渲染，不烘焙进图。封面及结算插画采用同一组人物。
- 结算三图标沿用`assets/unit1-2/completion/`的认可星／勾／叉。
- 字体使用本地OFL授权的寒蝉圆黑体与Nunito；音标Arial。来源和子集输入见`assets/awards/fonts/sources.json`，不向第三方字体服务发请求。
