# Lesson 1–12视觉样板素材

采用与复核日期：2026-11-12。范围仅为Lesson1–12六个教学单元；原纪念卡、课文角色动作和教学定义保留。

本目录保存5张采用背景（1200×800 WebP）及`raw/`中的45张生成原稿。40张透明词卡采用图位于[词卡目录](../word-art-v2/sample1-12/)，512×512 WebP。新采用图总计2,036,570字节；这是45张新图的合计，不是单课下载包大小。

全部通过内置ImageGen生成。每次请求的完整提示词、真实参考、生成输出路径、原稿和采用位置均记录在[逐次生成回执](../../docs/designs/learning-flow/sample-1-12-generations/)；仅等比缩放和格式压缩，没有用渐变滤镜冒充重绘。

背景分别为街角、教室、会客角、问候街道及衣物认领教室。Lesson3–4继续使用已认可的认领亭背景。场景不预先画入重复主角，真实对白、人物动作与道具继续由课程呈现。

各词条采用状态、意义核对、真实页面证据及SHA见[采用清单](../word-art-v2/adoptions.json)。关系图复用角色和物品也单独记录SHA。运行资源包只引用采用图，不包含`raw/`；生成原稿保留供追溯，不删除原纪念卡或历史资源。
