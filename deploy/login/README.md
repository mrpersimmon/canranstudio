## 首次部署或升级

1. 记录并备份当前站点配置、首页发布目录和 `/lesson/` 发布目录；保留旧版本在非公开位置。
2. 从原首页完整发布包制作迁移产物：`node scripts/migrate-exercise.js <原首页目录> <新的迁移输出目录>`。脚本先核对原发布清单，重写 `/exercise/` 地址，再重算媒体清单、课包、首页及发布清单的校验值。不可禁用完整性校验来解决加载失败。
3. 上传并核对已提交的账号服务与迁移产物。安装 [systemd 服务](canran-lesson.service)，先在回环地址 `/health` 检查服务，尚不切换公网。
4. `LESSON_BASE_PATH=/`、`LESSON_ORIGIN=https://www.canranstudio.cn`、`LESSON_TRUST_PROXY=loopback` 和独立 `LESSON_DATA_DIR` 均须显式配置。本地预览默认仍为 `/lesson/`；根目录预览显式配置 `/`。
5. 数据迁移必须使用配套 SQLite 备份和 card-key，不能复制运行中的数据库单文件。首次管理员初始化或旧管理员恢复使用下方管理命令；是否迁入本地班级数据按用户决定执行。
6. 用 [site.conf](site.conf) 和 [nginx.conf](nginx.conf) 替换已确认的主域名站点规则。旧 `/lesson/` 及其资源静态 alias 必须取消，不能与新规则并存。TLS 证书与其他独立域名的配置保持原有管理方式。
7. 先 `nginx -t`，通过后才 reload；再验证根目录登录、班级导航、实际作答与刷新、匿名资源拒绝、旧地址 410，以及 `/exercise/` 首访和复访。正式 Nginx 来源限流也在此阶段验收。

Nginx 必须以 `$remote_addr` 覆写 `X-Forwarded-For`，不能追加客户端输入。生产漏配信任代理会拒绝启动。服务只监听 127.0.0.1，不缓存身份、课程清单和成果；服务不可用时不能回落到公开课件。

security-version 的模板增加未知 HTTP Host/HTTPS SNI 拒绝及所有站点隐藏版本，需要 Nginx 1.19.4 或更新版本。安装时先核查现有 default_server，替换原默认入口而不叠加冲突配置；实际供应商补丁与证书续期另验。来源限制由账号服务持久化执行，Nginx 负责可靠地覆写来源，并没有在该模板中额外配置 limit_req。

账号失败冷却在同一 SQLite 中跨重启保存：每来源 120 次/分钟、每账号 12 次/分钟，十五分钟窗口内十次密码验证失败后暂停该账号；成功不会清空来源预算，429 附 Retry-After。老师重置学生密码和本地 reset-admin 可恢复对应账号。数据目录必须专用，服务会将其收紧到 0700，并将数据库和 card-key 设为 0600。完整方案及线上凭据/DNS待办见[安全加固记录](../../docs/security-version/2026-09-28-安全加固方案与验证.md)。

新旧缓存分别作用于 `/` 与 `/exercise/`。旧 `/lesson/core/subpath-worker.js` 只保留网络直通的退役脚本，替换旧公开缓存；这是清退机制，不是保留旧课程内容。旧根目录课包 Worker 的原地址也返回受权限约束的新 Worker，以更新联网的旧浏览器。已经离线保存且未收到更新的副本无法被即时撤回。

## 访问尺寸统计

本地实现见[尺寸采集与第三段入口记录](../../docs/designs/course-journey/2026-10-22-1930-尺寸采集与第三段入口实施记录.md)。该功能默认关闭，本文不代表已在生产启用。部署授权后，在目标服务设置：

```text
LESSON_VIEWPORT_METRICS_ENABLED=1
LESSON_BUILD_VERSION=实际部署提交号
```

构建版本允许 1–80 个字母、数字、下划线、点或连字符。配置变更后重启目标服务；浏览器已有页面需刷新。常规回环预览仍不收集，本机隔离验收需另设 `LESSON_VIEWPORT_METRICS_ALLOW_LOCAL=1`，生产忽略该放行变量。启用后以最高管理员进入“设备与窗口”，普通教师不显示入口也不能请求汇总接口。关闭开关并重启后不再注入脚本；旧页面下一次上报收到禁用响应后清理监听。关闭不会删除旧统计。

独立库为数据目录中的 `viewport-metrics.sqlite`，有 WAL 文件；按上海日期保留 90 天汇总，事件去重摘要有效期 24 小时。运行中每分钟及接收／查询时清理，停服期间不清理。现有 `manage.js backup` 只备份学习账本与密钥，不包含尺寸统计；确需留存统计时单独使用 SQLite 一致性备份，不能只复制运行中的主文件。

真实数据补测后将经过验证的完整环境存入同一私有目录的 `viewport-validation.json`。格式为 `version:1`、`status:"passed"`、实际 `validatedAt` 和完整 `contexts` 数组，细节见实施记录；证据最多有效 30 天，需对应实际构建和浏览器。候选导出不能直接作为通过证据。无数据、无证据或证据过期时不显示虚构覆盖率。上线前还需验证真实代理限频、生产负载及日志保留，不能以本地模拟代替。

## 学习数据初始化、备份与恢复

### 一次性统一五星切换（待正式发布执行）

本轮实现与本地验收见[统一五星切换与原证归档](../../docs/butcher-version/2026-10-24-2200-v1.0-统一五星切换与原证归档.md)。发布对应代码不等于数据已经切换；应用启动不会自动重置学生。正式执行先停止账号服务及其他写入，再以原数据所有者设置 `LESSON_DATA_DIR`，运行已核对版本的 `node server/manage.js system-upgrade <新的私有备份目录>`。目标备份目录须在数据目录之外且尚不存在，命令会先保存SQLite和card-key并核验指纹，再事务迁移；禁止先清数据后补备份。

固定epoch仅执行一次。检查报告中的已通关课程、原证归档数量、原姓名／日期、未通关清零和旧grant撤销；服务启动后验证普通登录、目录、原证、旧设备拒写及新学习可持续保存。损坏／未知证据、备份失败或数据并发变化时停止，不强行跳过。回退必须使用理解当前epoch的兼容代码；需要还原备份时恢复到新目录并保留切换后的新数据，不直接覆盖当前库。未通关重置是本轮用户明确授权的动作，不得把命令加入每次发布或启动脚本。

以数据所有者运行，环境中先设置 `LESSON_DATA_DIR=/var/lib/canran-lesson`。首次 `node server/manage.js bootstrap` 将新管理员登录信息写入私有 `admin-first-login.txt`；不在代码或发布记录中填写密码。已有管理员时不会覆盖。

```bash
LESSON_DATA_DIR=/var/lib/canran-lesson node server/manage.js backup /var/backups/canran-lesson/新的备份目录
```

恢复前停服务，使用新的空数据目录，恢复并检查后再改变服务的数据目录：

```bash
LESSON_DATA_DIR=/var/lib/canran-lesson-restored node server/manage.js restore /var/backups/canran-lesson/选定备份目录
```

恢复核对 SQLite 完整性、加密密钥、学生身份、学号、正式密码、班级、开放课程和成果。课包从发布代码重建。初始密码的截止时间及领取状态以所选备份为准；旧快照不包含备份之后的领取或改密，需要教师核对并重新发放相关待激活账号。

旧库升级只为待激活且已核对拼音的账号轮换随机初始密码，撤销旧学生／待改密会话；正式密码及成果保留。初始密码固定 7 天内可领取一次，领取后最多 15 分钟完成改密，不能超过原截止时间。旧账号单需重新发放。新建账号与老师单人或批量重置均使用已核对的姓名拼音加三位随机数字（含前导零，如 `liming007`），不使用单独的姓名拼音。同拼音新账号避开已有待领取密码；已发放的有效密码不会因更新或重启自动改变。一次性领取、期限、限流与强制改密规则相同。

## 回退

已发布的账号服务只能回退到同样执行一次性密码、代理限流和访问控制的兼容版本，保留独立数据目录。首次上线没有兼容前版时，应保持课程服务不可用并修复，不能把新版受限课程退回匿名公开状态。`/exercise/` 有独立的发布目录和链接，不因账号服务回退丢失。

管理员恢复使用同一数据目录运行 `node server/manage.js reset-admin`，生成新密码并撤销旧管理会话；不能删除重建学生以解决登录问题。开发、检查、提交、推送、生产切换和真机验收分别记录。

只改管理员用户名时，备份并停止写入后执行 `node server/manage.js rename-admin <当前用户名> <新用户名>`。新用户名使用3–64位字母、数字、下划线、点或短横线，以字母开头；密码保持，旧管理会话撤销，学生／教师会话及成果不变。命令校验当前用户名、拒绝老师工号冲突，不使用`reset-admin`代替改名。私有`admin-first-login.txt`存在时同步更新账号行；若提示账号单更新失败，按数据库实际用户名核对文件，不反复重置密码。

登录页根据服务器原截止时间显示倒计时及北京时间解除时刻，到期只恢复按钮、不自动重试。账号限制不能误阻止另一账号，来源限制保持；刷新或设备时间变化不能改变后台限制。正式验收用隔离身份检查429，不故意封禁真实账号。

指定管理员密码时使用 `node server/manage.js reset-admin --password-stdin`，从标准输入传入一行 12–256 字符的密码。保留现有管理员账号，撤销管理会话、清除对应账号冷却，学生数据不变；密码不出现在命令参数或日志中。登录信息仍写入权限为 0600 的私有 `admin-first-login.txt`。操作前先按上文备份，不把实际密码、密钥或备份提交到仓库。

老师可在“所有学生”、单个班级或查找结果中勾选学生，使用“全选当前列表”批量重置。确认页显示实际人数和名单，单次最多 1000 人；名单无效或账号在操作期间被修改时整批取消，不部分重置。未选学生不变，已停用学生仍停用；成功后显示所选学生的新账号单，可直接打印。A4 纵向通常每页 2 列 × 5 行，长姓名、长班级名或长密码自动改为每页 6／4 张，保留字号并避免裁切。

管理员选择班级后，可用“保存班级名称”单独改名；班级标签和学生列表中的班级名称同步更新。“开放课程”支持一键全选／取消全选并显示已选数量，点击“保存开放课程”成功后弹出确认窗口，失败时保留选择并显示错误。改名与课程开放分别保存，互不覆盖尚未提交的修改。
