# 音标魔法乐园

孩子通过听音、对比和小游戏初步认识英语音标。

| 内容 | 孩子做什么 |
| --- | --- |
| 元音与辅音 | 认识两类声音，完成辨认练习 |
| 6 个元音 | 学 /ɪ/、/iː/、/ʊ/、/uː/、/æ/、/e/ 的口型和例词 |
| 音节魔法 | 把长单词分成音节，再慢速跟读 |
| 对比擂台 | 听 ship／sheep 等 14 组发音差别 |
| 游戏乐园 | 玩听音小侦探、左右耳辨音和拼读 |
| 48 音标表 | 点选音标听发音 |

四项计分挑战各满 3 星，共 12 星后可领毕业证书；页面上的学习板块不等于计分挑战数量。

录音在 `audio/`，优先使用 Sonia 英式发音，失败时尝试浏览器朗读。进度存储键为 `canran:soundmark:progress:v2`。
