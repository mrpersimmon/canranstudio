# Lesson 51 · 希腊四季之旅

学习《A pleasant climate》中的天气、季节、月份和频率表达。

1. **单词行囊**：26 张词卡和听音挑词。
2. **课文剧场**：听 Hans 与 Dimitri 对话，可逐句听或连续播放。
3. **月份归队**：把 12 个月归到四个季节。
4. **频率阶梯**：练 always、often、sometimes。
5. **导游考核**：完成 8 道题。

五关各满 3 星，共 15 星后可领证书。听音挑词答对后自动进入下一题。

录音在 `audio/`，课文 16 句使用较慢语速；Hans 为 Ryan 男声，Dimitri 为 Sonia 女声。播放失败时尝试浏览器朗读。
