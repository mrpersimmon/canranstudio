# 街角问候站 · Lesson 9–10

从“我的课程”进入，或打开本地 `/unit9-10/`。启动方式见[项目首页](../README.md)。

先看 22 张带音标的词卡，再听 Steven 和 Helen 的完整 14 句对话。五关共 26 道必做题，练习问候、回应与回问，以及用 Look at… 和 He’s／She’s／It’s 描述人或物。十二组描述和教材书面练习完整保留为点读与可打印练习；五关完成后领取 15 星证书。

公共要求见[统一设计标准](../docs/butcher-version/publish/2026-09-24-2031-v1.20-教学单元设计标准与验收清单.md)。教材页码、逐题设计、去重依据、词典与实际检查见[单元文档](../docs/butcher-version/2026-09-21-1712-v1.0-Lesson9-10教学单元与验收.md)。内容在 `content.js`；57 段录音的文字、来源、生成参数、裁音核对与文件校验值在 `audio/manifest.json`。

本单元使用独立学习记录。页面行为通过不等于全量人工听审、教师验收或儿童试用通过。本地新增不等于已提交、推送或上线。
