# Lesson 53 · 英伦气候小主播

跟着 Hans 和 Jim 学习《An interesting climate》，了解课文中的英国天气与四季。

1. **单词气象台**：17 张词卡和听音挑词。
2. **伦敦小剧场**：逐句听或连续播放四幕对话。
3. **风向罗盘**：完成 8 组方向、天气与季节配对。
4. **句型魔法屋**：补全 7 句课文原句。
5. **气候终极考核**：完成 8 道题，其中 2 道听音题。

五关各满 3 星，共 15 星后可打印“气候小主播”证书。进度存储键为 `canran:l53:progress:v2`。

录音使用英式发音 Sonia／Ryan／Thomas；单词语速为 −15%，句子为 −5%。
