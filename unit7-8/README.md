# 新朋友采访站 · Lesson 7–8

从“我的课程”进入，或打开本地 `/unit7-8/`。启动方式见[项目首页](../README.md)。

先看 22 张带音标的词卡，再听 Robert 和 Sophie 的完整 16 句对话。五关共 27 道必做题，练习姓名、国籍与职业，区分“直接问你”和“向别人问他／她”。职业图册保留十种职业介绍和十二组完整问答，教材纸笔练习可打印；完成五关领取 15 星证书。

公共规则只在[统一设计标准](../docs/butcher-version/2026-09-24-1913-v1.19-教学单元设计标准与验收清单.md)维护。教材页码、独立题稿、去重依据、词典与验收见[单元文档](../docs/butcher-version/2026-09-21-1601-v1.0-Lesson7-8教学单元与验收.md)。内容在 `content.js`；65 段录音的文字、声音、生成参数和校验值在 `audio/manifest.json`。

本单元使用独立学习记录。页面通过不等于人工发音听审、教师验收或儿童试用通过；本地构建不等于线上发布。
