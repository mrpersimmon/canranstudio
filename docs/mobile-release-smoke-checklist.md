## 缺陷记录与判定

每个问题只记录复现步骤、平台、屏幕方向、期望结果、实际结果、截图或录屏位置和严重度，不记录使用者身份。

- `P0`：数据破坏、安全问题或核心站点完全不可用。
- `P1`：多数使用者无法进入推荐课程、完成主要课程动作、返回地图或使用投屏。
- `P2`：局部裁切、难读、误触、层级或反馈问题，但有清楚替代路径。

任一平台存在未解决的 P0/P1，即不通过真机烟雾检查。三组平台均完成、无未解决 P0/P1，且证据链接可回查后，才能把本清单标记为通过。
