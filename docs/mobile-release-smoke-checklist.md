- [ ] 「暖灯集市」是唯一可操作城区，其他十一城区只作为不可点击远景，不出现空卡片、锁头或未绘制课程号。

- [ ] 手机不缩放也能读清标题与城区名称；没有横向滚动、裁切或安全区遮挡。

## B. 暖灯集市地图

- [ ] 点击暖灯集市后进入城区；返回箭头至少 48 × 48，华为 Mate 60 Pro+ 上不变形、不贴边且可稳定点中。
- [ ] 地图只显示 Lesson 49–54 与「音标魔法乐园」七个真实地标；Lesson 55–60 完全不展示。
- [ ] 每个地标整体一击进入课程；没有弹出的课程详情大卡。

- [ ] 竖屏和横屏保持地点语义与顺序，允许自然纵向滚动且无横向溢出。

## C. 首次完成后的成长揭晓

- [ ] 在任一课程第一次完成一个真实关卡后，先保存星级，再出现全屏「图鉴更新」。
- [ ] 揭晓明确说出新增装饰；底图和之前装饰不消失，新装饰位置没有错乱、白边或洋红残留。
- [ ] 揭晓无按钮；出现后立即误触不会关闭，约 0.7 秒后轻触任意位置可关闭并继续当前课程。
- [ ] `Enter`、`Space`、`Escape` 均可关闭；不操作时不会自动消失。
- [ ] 重复挑战、已有星级提高或刷新页面不重复发同一揭晓。
- [ ] 第五关出现「地点完成」章和独立永久纪念物；纪念物没有与第五层重复。
- [ ] 揭晓打开时课程音频停止；静音、音效拒绝或图片失败不会阻塞关闭和继续学习。

## 缺陷判定

- `P0`：数据破坏、安全问题或核心站点完全不可用。
- `P1`：多数使用者无法进入课程、完成关卡、关闭揭晓或返回地图。
- `P2`：局部裁切、难读、误触、反馈或层级问题，但有清楚替代路径。

任一平台存在未解决 P0/P1 即不通过。所有平台完成、无未解决 P0/P1 且证据可回查后，才可把真机烟雾检查标记为通过。
