## 先把题目写对

[2026-10-20专项修复](butcher-version/2026-10-20-0134-v1.0-Lesson1-144剩余问题修复与验收.md)按现行v1.54补齐44课284题的答前原文、修正两个示范与一处题意，并恢复29课练习纸。事实判断题的材料在未作答时可见，保留说话人与必要上下文；不能以课文区有全文、解释里有答案或剧情摘要代替。示范使用不同例句展示方法，仍记录实际使用支持；题干须分清评价者与评价对象。

已有课程的纯展示修复可用现有 `copy.questions` 或局部显示包装，前提是题目依据、计分及有效证据确实未改变；本轮核对72课题目／答案／版本／奖励和原记录不变。若实际改变考查任务、正确答案或支持程度，应按原内容兼容规则处理，不能把本轮的“保留全部轮次”当作一律不升版的理由。

练习纸须点击真实打印入口，在打印媒体下检查题干／例句／编号／书写线，并逐页查看实际PDF。`visibility` 级联可让DOM存在而纸面全空；打印列表不能保留 `display:flex` 后只改 `list-style-type`；多句问答按原题实际产出留空间，表格保留语义表头与合理分页。本轮两条或多条32px线是对应原题的实施结果，不是所有新课的题数、行数或页数配额。样式限定本单元练习纸，旧证打印保持独立。

题型登记逐项列研究编号、原名、采用／合并／替代／未采用或教学改编、实际认知操作与题号。补齐登记不等于新增题型；已有有效任务不用为“凑齐12种”改写，原研究中文证据待核与课程可用性分别记录。

每道题写清：要学什么、题目依据、正确答案、为什么、需要什么图片或录音。

- 选项要有明确的判断依据；语法正确但不符合情境，不能解释成“语法错误”。
- 提示只帮助思考；看过材料、播放录音、使用提示和独立答对分别记录。
- 面向小学生，线上优先点选、配对、拼词块；长篇书写和开放表达交给纸笔或课堂。
- 新题不能用旧成绩自动填答案，旧学习记录应保留。
- Lesson 49 的具体内容要求见[教学复核](butcher-version/2026-09-14-0119-v1.10-题目教学正确性要求与复核.md)。

## 素材和共用行为

原编号课的地图每一阶段都是从同一母版编辑得到的完整图片。母图为 1024 × 1024 RGBA，建筑位置固定；导出 512、768、1024 三档 AVIF/WebP 和 PNG 回退图，纪念物单独保存。详见[地标美术规则](designs/adventure-map/landmark-art-bible-v1.md)。这些是已有地图资源的维护要求，不要求新教学单元增加地图或写实场景。

优先播放 `audio/<slug>.mp3`；失败时由共享播放器尝试浏览器朗读。`slug` 是文本转小写后，把连续非英文字母或数字换成下划线，再去掉首尾下划线。例如 `It's often wet.` 对应 `it_s_often_wet.mp3`。

上面的后备朗读属于旧播放器的兼容行为，不能作为指定录音已听完的凭据。新单元的录音绑定、失败重试和验收按统一标准执行。

上述旧编号课的证书领取、保存和打印仍检查其原有条件。新教学单元的获星、纪念卡与GIF按统一标准第5、6节；不能套用旧证书的满星保存门槛。旧字体由`npm run vendor:fonts`维护；新单元与纪念卡字体登记见下表，按实际引用维护本地字库并保留许可证。

### 答题区结算顺序（O17）

Lesson1–144的72个现行单元及后续新课统一遵守[标准第5、6节](butcher-version/publish/2026-10-24-2200-v1.55-教学单元设计标准与验收清单.md#5-怎样结算固定三卡只统计本轮实际提交)。共享奖励展示、练习结束页和统计动画共同控制一次完成流程；不要在每课添加固定延时或另起一套自动弹卡计时器。

1. 末题由孩子主动完成后，先确定本轮是否完整零错。全对直接展示当前已确认成果的纪念卡，统计数字及操作区保持不可见；等待确认时保留真实旧星数，不提前授星或填日期，账号确认后再飞入新星。存在错答时直接进入一次统计，旧星仍保留。
2. 已获星的完整零错复练展示现有卡面和星光，不产生新的飞入星或获星请求。首次获星、五星日期和历史旧证读取原成果，不从页面计时、关卡点击或动画结束生成日期。
3. 等待确认、新星飞行和落位期间消费关闭输入，完成后才允许点击任意位置或使用键盘关闭；已有星的复练卡在入场结束后即可关闭。关闭后只释放一次统计展示；不在底层先跑动画，也不把关卡点击传给“再练一轮”“下一站”或题目。恢复焦点到当前可见结算操作，避免滚动跳位。离开或身份失效仍须立即终止展示，离线／失败按下条处理。
4. 以当前活动、轮次和身份识别异步返回。奖励确认期间保留真实待同步状态；离线、请求失败或展示资源失败不能无限阻塞统计。该轮已显示结果或用户已离开、重练、换人后，迟到确认只合并成果，不补弹旧轮卡片、不重播结算，也不取消应补传的学习记录。
5. 同步通知、页面重新渲染和返回可见只刷新实际状态，不把一次完成当成多次完成。刷新回看直接还原结果；重新完整完成一轮才有新的一次结算。

只修结算顺序时，保持课程ID、记录键、题目／奖励版、有效轮次及判分规则不变。不得清缓存或清学习记录掩盖旧状态问题，也不为新动效改写旧证内容、原姓名、领取ISO或首次五星日期。冻结历史课程和原证的保留能力继续按O16验收，不为了新流程改写历史资产。

共用改动先盘点全部调用方及结束页类型，再验证实际受影响路径。新课只接入并验证本课流程，不要求重新执行全站每课通关；本次共享工程的全量接入核对和实际浏览器覆盖分别报告，不能把静态调用检查当成全部页面体验通过。

### 首页横幅引用与验收

当前账号目录优先使用根`index.html`对应单元的图片列表`artwork`，只有列表为空才退回课内封面`image`。因此修改`unitN-M/index.html`的封面不会自动更新登录首页。逐项确认本课首页图片列表、课内封面和`reward.scene`；三者可采用适合各自比例的不同构图，但人物、画风和关键物品须一致，不能把本课复用同一文件的做法变成所有课程的硬性模板。

## 旧课升级与历史成果保护

本节落实已确认的O16，实现范围按[统一标准第8节](butcher-version/publish/2026-10-24-2200-v1.55-教学单元设计标准与验收清单.md#8-交付前只核对这张表)判断。旧课内容、评分、奖励或存储变更须处理受影响历史成果；纯展示修改验证记录不变及相关展示／导出，未受影响的升级证据可说明依据后复用。全新且无历史记录的课程注明迁移不适用，继续完成正常学习、同步和奖励验收；共享组件改动按实际调用方扩大范围。

1. **先核对真实基线。** 在单元记录列明实际旧版本、内容定义、记录键、旧奖励、原证书及同步边界；保存能复现受影响历史行为的必要文件和资源。旧文档题数与程序不一致时以实际程序和可核实数据为准，并记录差异；已支持的更早版本迁移路径仍须评估，不能只核对最近一版便宣称全部历史兼容。
2. **分别映射记录。** 新版写入前保护原记录，区分作答、错答、未提交草稿、词卡／阅读位置与参考分页。只有内容和判分含义经核对一致的题才承接；旧入口和位置映射到对应新内容，失去一一对应时保留可恢复信息并说明边界。新增题保持未答，次数不可核验时沿用标准的“—”与说明，不用旧答案生成新版零错星。
3. **保存历史证书所需内容。** 原领取姓名和原始时间与新版奖励分别读取；保留原称号、人物、徽章、原有摘录、主要版式、配色与导出尺寸。原证没有的摘录保持没有，不从模板补入。必要历史素材及字体继续可用，字库子集核对新旧实际字符，不能用新图或新主题覆盖旧证。查看、保存和打印不重新授奖，也不以当前姓名或设备时间改写原证。
4. **隔离新旧呈现与操作。** 可采用独立控件ID、限定作用范围的样式或组件封装，重点核对事件绑定、祖先容器裁切、打印媒体规则、导出节点及字体加载。共用标准要求结果互不干扰，不规定唯一实现，也不要求为保留证书复制整套旧场景。必要技术修复记录与前版的差异，保留历史内容和使用能力。
5. **核对两端读取。** 检查本机恢复与服务器校验／合并是否接受对应历史格式，避免客户端保留而服务器过滤丢失。已同步成果在同账号另一设备读取；原本仅本机的草稿留在原设备，待同步数据沿现有补传规则处理，不把旧草稿冒称为已上传。重练和新获星不得覆盖旧证书及日期，换账号继续遵守隔离规则。
6. **用真实升级验证。** 执行[历史成果验收](../tests/README.md#旧课升级与历史成果验收o16)，把本课结果、版本、适用理由及未覆盖项写入单元记录。实际下载或打印结果用于检查可用性，不以“按钮存在”或两行姓名日期代替原证书验收。

上述是受影响改造的实施方法，不新增题量、关卡或固定测试数量，也不要求新课先完成全站旧课翻新、集中配置或通用迁移框架。以往课程的局部成功经验可复用方法，不能直接复用为新改动已经通过的结论。

## 复用课程与样式时的核对

只修正普通学习手记中的目标显示字样时，可在单元的`copy.recordTargets`中按questionId提供标签；它只改变显示，不修改`questions`或已存记录。未配置时沿用`record.target`，紧凑手记继续使用既有`recordNames`。此项按需使用，不要求新课程填写；不要为了修正标签而重开有效轮次。实际例子与保留验证见[Lesson25–26本轮记录](butcher-version/2026-10-18-0429-v3.1-Lesson25-26原文依据与教学支持重构.md)。

先列出本课专属标识、内容与保留的共用接口，再限定替换范围；课程ID、路径、奖励版、人物和主题可以按实际设计更新，不能把普通英文词全局替换到`message`、`error.message`等接口字段。检查差异与语法后仍须验证真实页面；编译成功不证明字段接入或恢复契约正确。

| 复用对象 | 核对重点 |
| --- | --- |
| 材料、插图与帮助 | 按当前组件实际读取的字段传入，检查辅助函数是否真的消费所传参数；材料、图、替代文本和提示在未作答页面各自可用，不只核对文件存在。 |
| 题型及续做 | 按真实单选、配对、逐空或词块契约检查未齐、撤回、连续错答、订正、刷新、末题和重练。题型变了先审查旧测试前提；不能为适配模板测试而清掉应保留的草稿或错误次数。 |
| 样式与打印 | 区分旧主题和仍需保留的共用选择器、媒体查询；检查打印的display与visibility、编号及书写线、44px触控、焦点、短屏三卡和按钮。不可按旧主题标记整段截断而误删这些规则。 |
| 素材与几何 | 关键物件与判断图保比例，背景适配分开处理；核对图内实体与文件留白、接触关系和实际绘制尺寸。SVG需明确尺寸时与viewBox比例一致；图内字体可嵌入或转轮廓，结果仍按统一字体要求核对。 |
| 生成与转换 | 透明人物和不透明照片分别设置提示词、输出参数及边缘预期；保留原稿和最终提示词，格式转换不裁关键内容。成功解码和alpha指标不代替目视。 |
| 字体与版本 | 内容变化后核对字库覆盖和源摘要，不只改hash冒充补字；未新增缺字且字库可复用时记录覆盖核对。内容／奖励兼容按标准第6节判断，样式修订不无故作废有效轮次、星星或日期。 |
| 目录与文档 | 更新入口、继续学习、课包、授权、字体、奖励和测试映射，同时核对索引概览、条目及表格渲染；目录数量按实际配置，不只追加最后一行而留旧总数。 |

新课保留自己的教材目标、角色、任务和独立答案，不以模板题量、题型数或截图数替代设计。缺图／缓存测试和当前课包版本核对见统一标准第7节，运行与复验方法见[测试说明](../tests/README.md#可信的故障与复验记录)。

本表落实共用规范，不表示已集中重构全部单元。后续若实施集中配置，须验证各调用方输出、默认权限、声音模式、内容／奖励版本和记录兼容；目前逐处登记流程继续有效，不将重构作为新课开工门槛。

## 已有五星课程的改造边界（Lesson41–42，2026-10-17）

[本课记录](butcher-version/2026-10-17-1900-v2.0-Lesson41-42统一标准重构与验收.md)保留原奖励版与首次五星时间；不要把15星迁移模板套给已用五星的课程。未改题组不重开有效轮次，修订组登记准确前驱，改题未答，已验证旧记录在新版完成后仍保留。
