# Duolingo 英语题型与界面设计研究

研究日期：2026-09-27。范围为**以英语为目标语言**的 Duolingo 主应用课程，兼顾免费、Super、Max。

先打开 [图文报告](report.html)，查看逐题操作、设计分析与可点击放大的原图。也可阅读 [Markdown 报告](REPORT.md)，或使用 [覆盖清单](coverage.csv) 按题型核查证据。

本次新增 [不含口语和听力的题目](report.html#non-audio) 独立章节，集中整理 15 项阅读、点选、配对或文字输入任务，保留完整的操作、截图和设计分析。13 项有完整英语题图，故事开放写作与 Roleplay 两项仍待补图。分类以当前作答分支是否必须听音或开口为准，可选播放不等同于必须听音；未据此宣称整节课程完全无声。

## 当前覆盖

- 31 个题型、交互与变体分析条目；其中 29 个有完整英语任务或通话视口，2 个仍缺完整英语题图。
- 5 类入口、课程容器与反馈模式，单列说明。
- 48 份独立原图：44 份官方公开图片，4 份用户历史参考截图；同图复用不重复计数。
- 25 个实际引用的官方来源页面。每图标注学习方向、界面语言、完整性及来源。
- 每个条目说明学习目标、输入与输出、用户操作、UI 关键点、设计解读与证据边界。

这些数字是本报告的分析与图证数量，不是 Duolingo 官方题型总数，也不是所有现行英语题型已完成截图的声明。

## 文件

- `report.html`：主要阅读版本，原图保持比例，可搜索目录、跳转条目并打开原图。
- `REPORT.md`：同一内容的 Markdown 版本；本地版本使用绝对图片路径，离线包内版本使用相对路径。
- `coverage.csv`：题型与截图覆盖清单。
- `report-data.json`：结构化研究记录与统计。
- `adopted-images.json`：实际采用的 48 份图片及来源、尺寸、哈希。
- `verification.json`：文件、链接、图像与打包检查结果；明确区分已执行与未执行检查。
- `sources/source-link-check.json`：25 个来源页面的访问检查记录。
- `assets/`：图片原件；离线包只收录主报告实际采用的原图。

解压离线包后直接打开 `report.html`。报告正文和图片可离线阅读，外部来源链接需要联网。研究过程中的子报告、原始材料与 `background-all-languages/` 是工作底稿；当前结论以本目录的英语主报告为准，离线包不包含这些底稿。
