- 页面结构化日期：发布 2023-12-26，更新 2026-03-30；核查 2026-09-27。
- 材料形式：机制说明文章，不是中文英语课程录屏。
- **能证明：**官方曾明确说明，课程会在课末让学习者复习本课错题，将错题延后是间隔重复设计。
- **不能证明：**研究日中文英语课程的具体错误面板、按钮名称、是否即时原位可编辑、原题在何时以何种界面再次出现，以及每一题/平台都遵循同一流程。

该来源尤其提醒：**不能预先把“重试”写成“答错后立即在原位改答案”。** 原位编辑、课末复现、退出重开是不同操作，需要分别实测。文章机制说明也不能替代当前实测。

## 用户所需分支的证据缺口

| 操作或结果 | 本轮公开第一方资料的结论 |
|---|---|
| 未作答 → 开始输入/选词 | 无同题连续证据 |
| 提交前撤回、删除、改答案 | 无同题连续证据 |
| 故意错误 → 提交 → 错误反馈 | 未找到符合中文英语范围的连续官方记录 |
| 错误反馈后继续，再次遇到原题 | 只有一般机制文字；无中文英语同题连续影像 |
| 原位重试或课末重试 → 修改 → 答对 | 未验证，不能预设两种重试路径都存在 |
| 答对 → 继续 → 下一题/结算 | 静态图只显示正确面板和按钮，未显示点击结果 |
| 跳过、退出、重进、重复点按、空答案等其他分支 | 本轮没有连续第一方证据 |

根代理实测应保留同一题干、同一浏览器/设备和连续前后状态；如果原题只在课末复现，需保留到复现之间的顺序证据。只观测到一个结果时应记录该路径，不能写成穷举已完成。
