# Duolingo 无配音题型采用核对

核对日期：2026-10-06（Asia/Shanghai）。本记录回答哪些任务结构适合低年级新概念英语课堂配套网页，重点核对 Stories、Adventures、Roleplay、Read and respond、Practice 与 Flashcards。**这是本次采用建议，不是 Duolingo 当前全量功能、中文课程开放范围或学习效果的保证。** 未重新登录 Duolingo 走流程。

## 判断依据

- 采用边界以[统一设计标准 v1.26](../../butcher-version/publish/2026-09-27-2154-v1.26-教学单元设计标准与验收清单.md)第 1、6.3、8.3 节为准：不请求、预加载或播放英语配音，不使用系统朗读；保留正误与完成反馈音，全部声音失败仍可完成。线上记录阅读、词义、语境选择与有支架的句子组织，不冒记听力、发音或自由口语。
- 报告的“无需听说”指作答材料可由文字／图片取得，不代表原产品没有播放、预加载或自动朗读；移植时仍须实现和验证上述无配音要求。低年级不默认整句打字，英文定义须使用已经教过的解释词。
- [入口](../../butcher-version/publish/2026-09-27-2028-v1.0-Duolingo题型研究入口.md)、[README](README.md)、[主报告](REPORT.md)、[流程记录](FLOW_AUDIT.md)、[快照说明](LOCAL-SNAPSHOT.md)明确区分研究事实和课程验收。本目录是 2026-09-27 快照；入口的 v1.25 链接不能覆盖现行 v1.26。
- [高级活动报告](advanced-experiences.md)、[结构化资料](advanced-experiences.json)、[目标英语补充](english-advanced.md)、[中文学习者分析](chinese-learner-analysis.md)是不同范围的阶段资料。后两者仍保留 Stories 等“中文待核”的早期措辞；同目录主报告后来补入的具体中文实测应优先用于这些已补证项目。其他母语学英语、英语母语学其他语言，均不能代替中文学英语的当前实证。

## 主报告 17 项的完整采用对照

以下编号只使用当前中文主报告的 E／S／A／M 编号；后文 C11–C14 属于跨语言历史资料，不计入这 17 项。

| 条目 | 本次选择 | 用于无配音版时的重点 |
| --- | --- | --- |
| E01 中英词语配对 | 优先选用 | 小组、唯一对应的词义识别。 |
| E21 看图选英语词、E23 词义选英语词 | 优先选用 | 具体词可看图，抽象／关系词给清楚语境；不重复强制正反翻译。 |
| E07 有支架补全、E09 选词填空、E10 图境填空 | 优先选用相应结构 | 以点选或少量补词练必要的语义／语法判断；E07 不默认切整句打字。E10 中文图证仍待核。 |
| E05 英语词块组织 | 优先选用 | 练已学表达的意义与词序，记录为有支架组织。 |
| E12 对话接续 | 优先选用 | 由交际目的决定回应，不只挑语法正确句。 |
| S01 故事理解、E11 短文阅读选择 | 优先选用相应结构 | 找事实、指代、意图或关系；E11 尚未取得中文题图。 |
| S02 原文定位 | 优先选用 | 在完整原句中选词／词组，问什么就定位什么。 |
| A02 场景回应 | 改编后选用 | 与 A01 场景操作合成纯文字任务；中文原产品与静音闭环待核。 |
| E04 英译中中文词块 | 可用、低优先 | 证明理解，不能算英语句子产出；避免中文碎块点击负担。 |
| E02 英文定义选择 | 可用、低优先 | 只在解释词均已学时采用；中文题图待核。 |
| E06 整句键入 | 不做低年级默认必过项 | 可后续作为自选难度，需另验输入、拼写与多解。 |
| S03 故事开放写作 | 不做低年级默认必过项 | 原任务可无听说，但增加自由表达负担，中文题页待核。 |
| M01 自由文字 Roleplay | 不做低年级默认必过项 | 可以借鉴连续任务目标；改成词块／选择后不能宣称测了自由写作。 |

优先方向可归纳为八类熟悉操作：配对、词义／图文选择、语境填空／有支架补全、英语词块、对话接续、阅读理解、原文定位、文字驱动场景。不要求每课用齐。

## 主要任务的证据与采用边界

下表的“可用”是课程设计判断，仍须使用本课教材、已学词汇和我们的交互规则；不表示直接复制 Duolingo 页面。

| 任务及报告编号 | 原始证据 | 无配音采用建议与能力边界 |
| --- | --- | --- |
| 中英／图文配对 E01 | 中文实测 F07；Stories 末尾 F22 也是 E01 的情境变体，不是新题型。官方 Practice 展示词义配对。[主报告 E01](REPORT.md#E01)；[官方 Practice](https://blog.duolingo.com/guide-to-duolingo-practice-hub/) | 可用。每屏少量且唯一对应，用于词义辨认。改为整组主动检查、原题修改，不照搬即时消去正确对子。答对只证明有候选支持的识别。 |
| 故事理解 S01 | 中文 Taxi Ride 的 F18 检查字面意义、话语意图和情节总结；作答前英语上下文可读。[流程 S01](FLOW_AUDIT.md#flow-S01) | 可用。保留原文让孩子找事实、指代或依据；中文只降低操作负担。题型能无配音，不代表整篇 Stories 能无配音。 |
| 原文定位 S02 | F19 按中文释义选择原句中的 The directions；不是自由拼写。[流程 S02](FLOW_AUDIT.md#flow-S02) | 可用。点完整单词／词组；可扩展到有文本依据的所指人物或证据定位，但这些扩展是我们的改编。 |
| 短文阅读选择 E11（Read and respond） | 官方阅读说明有“段落＋问题／补全句＋候选”的题图；所示为法语任务。主报告 E11 尚无中文完整题图。[官方阅读说明](https://blog.duolingo.com/covering-all-the-bases-duolingos-approach-to-reading-skills/)；[主报告 E11](REPORT.md#E11) | 可用其结构。以本课短文检验人物、事件、否定或跨句关系，控制阅读量。不能称为已实测的中文 Duolingo 题型。 |
| 对话接续 E12 | 免费中文流程 F05 取得选择、错误及重练证据。[主报告 E12](REPORT.md#E12) | 可用。选出能回应当前交际目的的一句；所有候选都合语法时，要由具体情境决定答案。 |
| 英语词块组织 E05／有支架补词 E07 | Super F26 为中译英词块；F28 为单词空缺与整句输入切换，两种草稿独立。整句模式在 F28 未提交，不能当作整句通过证据。[主报告 E05](REPORT.md#E05)；[主报告 E07](REPORT.md#E07) | 可用词块／短词补全。必要时逐步减少支架，不让低年级默认改成整句键入。整块 an engineer 已给出时，不能声称独立检验了 a／an。 |
| 语境选词 E09／图境填空 E10 | E09 有中文历史完整图，未补连续实测；E10 中文题图待核。官方写作材料另展示 Stories 双空选词，但该图为西语，不能与中文 S04 混同。[主报告 E09](REPORT.md#E09)；[主报告 E10](REPORT.md#E10)；[官方写作说明](https://blog.duolingo.com/covering-all-the-bases-duolingos-approach-to-writing-skills/) | 可用结构；一空为主，确有关系才双空。干扰项对应本课语义／语法判断，不能凭图像、词性或常识绕过英语。 |

现有 E21 看图选词与 E23 词义选择继续适用。E04 英译中拼中文词块也能靠阅读完成，但 v1.26 已列低优先级：它主要证明英语理解，不是英语句子组织。上述任务不用每课全上，也不设固定顺序或题型配额。

| 对象 | 原始观察／官方说明 | 本次建议 |

| Practice／Super 单元复习、错题复习 | F24–F30 包含翻译、补词、键入和原题重练；F30 保留首次错误与重答记录。Practice 本身是组织入口；官方已说明基础技能练习免费，不能统称 Super 独占。[流程 F24–F30](FLOW_AUDIT.md)；[官方 Practice](https://blog.duolingo.com/guide-to-duolingo-practice-hub/) | 借鉴按薄弱项抽样复习与保留首次记录。只编排本版本可用的文字题，不照搬混合听写课或整套重复题。Practice、Super、Legendary 都不是新题型；限时是节奏规则。 |

## 跨语言历史语法题的改编可能

以下 C 编号来自[跨语言分类报告](taxonomy-core.md)和[历史全语言报告](background-all-languages/REPORT.md)。C11–C14 的核心图证是 2020 年法语语法专课；C12、C14 另有西语例子。它们**不是当前中文学英语或目标英语的已实测题型**。原始一手出处为[语法专课说明](https://blog.duolingo.com/language-rules-learning-grammar-on-duolingo/)、[专家与 AI 的协作示例](https://blog.duolingo.com/how-duolingo-experts-work-with-ai/)、[西语学习指南](https://blog.duolingo.com/tips-for-learning-spanish-on-duolingo/)。本次研究的主代理重新打开并核对了语法专课说明；西语补充沿用归档，未重新做现行功能调查。

| 历史结构 | 可以怎样改编到本课英语 | 取舍 |
| --- | --- | --- |
| C11 对比双空填词 | 将已教的单复数／人称等必要对比并置，例如分别为 I ___ 和 We ___ 选择 be 的形式。 | 可按目标使用；每空单独选择，不将两空捆成一个长选项。最多两空是本课程规范，不是 Duolingo 全局规则。 |
| C12 点选词尾 | 在本课教过规则后，让孩子选择词形变化；低年级可以优先选 book／books 等完整形式，减少词素拼接操作。 | 条件适用。若沿用“词尾不变”答案，应给明确可选择的“不变”状态，不把空着视作已答对。改成完整词形后应如实记为选词填空。 |
| C13 键入词尾 | 把撤去候选后的少量字母回忆作为选练。 | 低优先；这是输入支架变化，不应另算全新能力，也不强制与 C12 同题连做。 |
| C14 语法表格补全 | 用少量并置例句或人称—be 对照，补一个必要关系；先用表格展示，再抽样检验。 | 可改编为教学整理或少量检查。避免密集空格、完整范式死记和把整表变必过大题。 |

这些例子是我们的英语教学改编，不是原图文字，也不是已经实施的课程题稿。

## 暂不直接采用的范围

- E06 整句键入、S03 开放写作、M01 自由文字聊天在技术上可以不听说，但阅读、拼写、输入与自由表达负担较高；按 v1.26 不做低年级必过项。S03 在已实测 Taxi Ride 重读中没有出现，不能推断所有故事都没有；其他课程的完整写作图和字数规则也不能冒充中文英语实测。
- S05 故事听音重组、Radio R01–R05、听辨／听写／音频配对、朗读、口头回应及 Lily／Falstaff 通话依赖听说，不用于当前无配音版。Radio 的中文选项或课后全文不等于作答前有阅读依据。若改成读文本判断，须按新的阅读任务记录，不能继续记为听力。
- Stories 旧 Conversation mode 是历史模式；2022 路径资料中的“已移除”不证明当前恢复。新闻、邮件、评论、日记等高级 Stories 是文体变化；早期计划公告不证明中文目标英语已全量部署。[高级资料的历史／缺口说明](advanced-experiences.md)；[目标英语覆盖缺口](english-advanced.md)。
- Match Madness、Rapid Review、Legendary 在高级报告中的官方图主要为入口，不能凭入口推出完整答题行为。配对机制可用；强制倒计时不因“无音频”就自然适合低年级必做。

## 证据缺口与验证状态

主报告统计的 38 个研究条目包含容器情境和输入变体；其中 17 项归无需听说，11 项有完整中文题页、6 项待核。这不是官方题型总数，更不是 17 项都适合低年级。中文待核的 6 项为 E02、E10、E11、S03、A02、M01；E03 的可选键入分支需单独讨论，不能靠它扩写中文实测覆盖数。[主报告第 4.1、8 节](REPORT.md)
