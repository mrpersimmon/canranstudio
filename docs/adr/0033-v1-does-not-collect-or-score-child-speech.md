# V1 不采集或评分儿童语音

当前产品没有账号机制，V1 不引入麦克风权限、儿童录音、语音识别、语音保存或教师人工复核链路。课程仍可在角色对话和情境任务中邀请孩子开口，但系统不监听、不评分，也不把开口提示完成当作掌握证据。V1 只依据选择、匹配、排序和句子拼装等确定性触控结果，评估这些交互实际覆盖的听辨、含义、词序和结构目标；发音与口语流利度明确标记为暂不评估，不阻塞地标落成，待未来具备账号、隐私和可靠评估机制后再升级。

## Considered Options

- V1 不采集语音，只保留无评分开口邀请：与当前无账号、低复杂度边界一致，因此采用。
- V1 使用自动语音评分：即时反馈更丰富，但会提前引入权限、识别误差、隐私、存储和异常处理链路。
- 所有语音由教师复核：判断更可靠，却与 120 名儿童的日常使用规模和当前产品边界不匹配。

## Consequences

- V1 页面不能因开口练习请求麦克风权限，也不能在后台生成或上传儿童声音。
- “请你说一说”可以作为自然练习提示，但完成按钮、倒计时或页面停留不能形成独立调用证据。
- V1 的目标掌握只描述平台实际取得证据的能力维度；文案不得宣称孩子已经掌握发音或口语流利度。
- 发音与口语流利度在 V1 中是非阻塞的待评估目标，地标落成仍由可验证的核心目标聚合决定。
- 将来启用语音能力必须另行决定身份绑定、儿童隐私、录音生命周期、低置信处理和人工复核边界，不能仅接入一个语音接口就上线。
- V1 的学习任务仍应鼓励孩子主动组织语言，不能因不评分语音而退化成只有被动观看或单一选择题。
- V1 通过 ADR-0034 的“教会小猫”等可操作环节让孩子外化理解，而不依赖语音采集。
