# V1 不采集或评分儿童语音

当前产品没有账号机制，V1 不引入麦克风权限、儿童录音、语音识别、语音保存或教师人工复核链路。课程仍可在角色对话和情境任务中邀请孩子开口，但系统不监听、不评分，也不把开口提示完成当作掌握证据。V1 只依据选择、匹配、排序和句子拼装等确定性触控结果，评估这些交互实际覆盖的听辨、含义、词序和结构目标；发音与口语流利度明确标记为暂不评估，不阻塞地标落成，待未来具备账号、隐私和可靠评估机制后再升级。

## Considered Options

- V1 不采集语音，只保留无评分开口邀请：与当前无账号、低复杂度边界一致，因此采用。
- V1 使用自动语音评分：即时反馈更丰富，但会提前引入权限、识别误差、隐私、存储和异常处理链路。
- 所有语音由教师复核：判断更可靠，却与 120 名儿童的日常使用规模和当前产品边界不匹配。

## Consequences

- V1 页面不能因开口练习请求麦克风权限，也不能在后台生成或上传儿童声音。
- “请你说一说”可以作为自然练习提示，但完成按钮、倒计时或页面停留不能形成独立调用证据。
- 无评分开口邀请紧跟在一次有意义的语言行动之后，自然停留约三至五秒；孩子可以点击当前角色重听示范，也可以立即继续，不进入独立页面，不显示倒计时或“我说完了”按钮。
- `L01-M04` 正式选择感谢表达并形成 T5 触控结果后，表达留在孩子的说话槽，小猫作出温暖回应，再自然留出三至五秒无评分跟说机会。表达牌的小喇叭或重听入口播放的是学习示范，不伪装成孩子角色的声音；跟说、重听、等待或立即继续都不申请麦克风、不改变 T5 结果，也不阻塞 M04 完成。
- `L02-M02` 中，孩子把 `Excuse me.` 送入说话纸条、再把 `watch` 标签放入 `Is this your ___?` 句框，分别形成触控层面的交际意图与固定框替换结果。纸条随后播放的两条完整美式示范音必须在视觉上来自纸条扬声器，不能用孩子头像口型或角色声线伪装成孩子已经说出。M02 保存后可以自然留出三至五秒无评分跟说机会；重听、跟说或跳过都不改变 T2/T4、不阻塞完成，也不产生发音证据。
- `L02-M04` 中，孩子把 `Yes, it is.` 与随后 `Thank you very much.` 分别送入自己的说话槽，只形成触控层面的 T4 与 T5 结果；说话槽播放的完整美式音是学习示范，不是孩子录音或孩子角色声线。最终感谢真实结束并保存 M04 后可以留出三至五秒无评分跟说机会，但重听、跟说、跳过或停留都不改变结果、不请求麦克风，也不形成发音证据。
- `L02-M06` 中，孩子把完整 `Excuse me.` 送入窗口铃槽，再用 `Is this your` 与所选 `car?`／`house?` 大块组成问句，只形成触控层面的 T2 交际意图与 T4 语言块组织结果。说话纸条播放的完整美式句子不能使用孩子头像口型或文案暗示孩子已经开口；M06 保存后的无评分跟说、重听或跳过不请求麦克风、不改变结果或阻塞进入 M07。
- V1 的目标掌握只描述平台实际取得证据的能力维度；文案不得宣称孩子已经掌握发音或口语流利度。
- 发音与口语流利度在 V1 中是非阻塞的待评估目标，地标落成仍由可验证的核心目标聚合决定。
- 将来启用语音能力必须另行决定身份绑定、儿童隐私、录音生命周期、低置信处理和人工复核边界，不能仅接入一个语音接口就上线。
- V1 的学习任务仍应鼓励孩子主动组织语言，不能因不评分语音而退化成只有被动观看或单一选择题。
- V1 按 ADR-0075 在每个单元自行创作可操作的外化活动，而不依赖语音采集或固定的“教会小猫”步骤。
