# 全部七十二个教学单元构成跨年成长旅程

产品继续以完整覆盖教材 144 课、72 个教学单元为长期范围，但不要求六至八岁儿童在一个学年内完成。整册设计为约两至三年的成长旅程，可以分阶段发布；语言密度、故事自主性、阅读书写比例和界面复杂度随课程阶段逐步成熟，不能把开篇的低龄表现或后半册的结构难度一次性压给同一个年龄状态。

## Considered Options

- 完整覆盖并跨两至三年成长：保留教材体系，也给儿童认知与读写发展留出时间，因此采用。
- 一个学年完成 144 课：接近原书成人或中学生课堂建议，却会迫使低龄产品加速和抽象化。
- 只承诺前 48 课：短期范围最小，但无法指导世界、角色与能力成长的长期设计。

## Consequences

- 分阶段发布不改变教材顺序，也不能把未发布内容伪装成儿童欠下的进度。
- 后续城区可以逐步提高叙事长度和儿童自主操作，但必须继承统一世界、角色关系和无障碍基线。
- 具体发布批次与学习频率仍需单独规划，不能从“约两至三年”反推出固定日历作业。
