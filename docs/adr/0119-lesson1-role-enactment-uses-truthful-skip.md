# Lesson 1 角色扮演使用诚实跳过

> 2026-09-02：本 ADR 中“从选角页或演练中一次跳过整个阶段”的条款，已由 ADR-0121 的逐角色处置模型取代；独立跳过状态、不得伪造接触或证据、补演后替换状态、只有双角色真实完成才解锁无字回演等边界继续有效。

Lesson 1 的双角色全篇演练仍是编号阶段 `L01-M12`，但孩子可以明确跳过并继续完成教学单元。跳过写入独立“已跳过”状态，旅程进度前进而不伪造角色完成、七句教材接触、学习结果或证据；只有真实完成两个角色才解锁无字逐句回演。阶段地图显示“已跳过”并允许返回补做，补做完成后以真实完成取代跳过状态。

“跳过”作为次要动作同时出现在选角和演练过程的稳定话轮，必需英语播放期间暂时不可用。确认层只说明“以后可以回来完成”；已经完整保存的角色继续保留，尚未完成的角色下次从第一句重来。旅程数字可以显示 `6/17` 乃至 `17/17`，但阶段状态始终区分“已完成”和“已跳过”。本决定不授权伪造来源接触、提前解锁完成专属练习、修改其他阶段或发布网站。

跳过状态必须先原子保存并读回，成功后才进入下一阶段；失败、重复点击、刷新或多标签页竞争都不得乐观前进、重复记录或产生伪完成。确认层默认聚焦“继续扮演”，支持键盘与 `Esc` 返回；跳过成功后焦点进入下一阶段标题，阶段地图以可访问名称同时表达“已跳过”和“完成角色扮演”入口。
