# ADR-0022：班级课程范围采用实际访问控制

2026-09-25，用户明确选择按班级限制课程访问，并由老师在管理页调整开放范围。当前 `/lesson/` 的课程与资源公开可读，单独过滤首页不能满足“A 班不能通过课程链接进入未开放课”的目标，因此新设计要求服务端核对访问资格，课程入口、清单和受保护教学资源采用一致规则。

课程继续共用，班级开放清单与个人学习完成进度分开；没有新增“先完成上一课才能进入下一课”的要求。原 [ADR-0005](0005-published-pages-use-soft-progression.md) 中的进度软引导不构成绕过班级开放范围的许可。

同日用户确认每位学生使用个人学习卡，首版仅由用户本人作为管理员。每次进入课程先联网核对资格，整课图片等资源仍复用本地缓存；进入后短时断网可继续本轮，完全断网时不能新开课。这一取舍收窄原有离线进入能力，使班级范围变化能在下次进入时生效，2 小时与后台 30 分钟触发静默重新核验，已随整体方案认可，不是学习时长限制。

随后用户确认每位学生只有一个当前班级，允许多端登录；已完成活动、星星与证书按学生同步，现有匿名记录留在本机而不自动认领。全部正式课程要求登录，不保留公开体验课。截图中的 Lesson 49–54 六个单课及音标乐园全部下架，保留配对教学单元；不删除共享素材和历史记录。

这项决定需要改变原公开版本排除身份与授权入口的边界，也需要安排旧公开入口和缓存过渡。已经分发的副本无法被服务器收回，个人学习卡也不能保证防止凭据转借。已确认选择保留在[讨论稿](../butcher-version/2026-09-25-0021-v0.1-班级课程开放设计讨论.md)，具体流程及建议默认值见[完整方案](../butcher-version/publish/2026-09-25-0105-v1.0-班级课程访问设计与验收.md)。用户随后确认整体方案并授权在 `codex/login-version` 实施。当前本地实现，未提交、推送或上线；验收见[实施记录](../butcher-version/2026-09-25-0156-v1.0-班级访问实施与本地验收.md)。


2026-09-25 后续调整：用户要求以永久学号和姓名拼音初始密码替代学习卡，首次登录必须改密。原学生标识和成果原位保留，旧卡登录关闭，遗忘由管理员查找/重置。现行账号与授权规则见[访问设计 v1.1](../butcher-version/publish/2026-09-25-1151-v1.1-班级课程访问设计与验收.md)；本文前述学习卡选择为历史，课程与缓存访问边界继续有效。
