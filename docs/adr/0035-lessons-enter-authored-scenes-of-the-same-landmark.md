# 课程进入同一地标的专属绘本场景

孩子点击地图上的建筑或铭牌后，通过短促推近、开门或翻页进入同一座地标的专属外景、室内和局部任务场景。课程场景必须延续地图地标的色彩、材质、光线、角色比例、小猫造型与主题道具；地图不是高质量包装，课程也不是另一套通用课件。选择、匹配、排序和句子拼装等互动优先嵌入招牌、货物、信件、桌面物品和角色对话，必要的提示与反馈也使用该地标的绘本材质，同时保留清晰文字和足够触控区域。

## Considered Options

- 进入同一地标的专属绘本场景：在可控资产规模内真正保持世界连续性，因此采用。
- 保留现有课程页面，只替换背景和边框：改造最快，但核心课件结构仍会让孩子感觉离开了冒险世界。
- 制作可以自由行走和连续动画的完整游戏场景：沉浸上限最高，但资产、动画、性能与一致性风险超出当前产品阶段。

## Consequences

- 每个教学单元除地图地标成长图外，还需要一套共享美术设定的课程场景资产和主题道具。
- 地图地标、课程场景和回访故事必须共用角色设定、建筑材料、主色、光源和装饰词汇，不能分别生成后再勉强配色。
- 学习互动要像场景中发生的行为，但语义清晰、反馈速度、文字对比度和触控尺寸优先于伪真实感。
- 通用组件仍可复用其状态、判定和无障碍逻辑，但视觉表面由地标主题提供，不能直接暴露成白色卡片。
- 进入转场必须短、可跳过并尊重减少动态效果设置；它不能等待大视频下载或阻塞首次互动。
- 内部课程美术也需要纳入审查工具，不能只验收地图外观。
- 每个教学单元的专属场景数量与城区高潮额外成图由 ADR-0036 的三场景加城区高潮模型决定。
