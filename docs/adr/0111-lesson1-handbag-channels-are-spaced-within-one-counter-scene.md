# Lesson 1 的 handbag 双通道分散在同一柜台故事中

Lesson 1 仍须分别形成 `handbag` 的词音与词形结果，但不能在 `2/5` 听词找包后紧接着于 `3/5` 对同一组三件物品再找一次。声音结果保留在 `L01-M08`；`L01-M09` 只完成 `Excuse me! → Yes?` 的礼貌交际；词形结果移到 `L01-M11`，在真实手提包已经确认待归还后，从随机排序的英文归还牌中选择 `handbag`，正确即自动发音，再执行全章唯一一次交包和女声致谢。二十九份结果、双通道身份、Source ID、声明式答案、音频 `ended` 与微任务原子保存均不改变；结果所属微任务与挑战编号改变，因此体验修订号升级为 `lesson1-2-v2.1`，旧 V2 存档不迁移为新完成证据。

`L01-M08` 至 `L01-M11` 是同一段柜台交流，全部使用 `dialogue-stage`；`L01-M10` 的句块轨道只是同场的呈现段，不再切换到 `grammar-lab` 并重排背景、人物和道具。显性语法实验室仍保留在 `L02-M15`，本决定不取消句型组织或交流修复证据。
