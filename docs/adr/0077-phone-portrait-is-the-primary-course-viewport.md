# 手机竖屏是儿童课程的第一验收视口

> Lesson 1–2 范围说明（2026-08-23）：手机竖屏优先原则继续有效；下文绑定整理室门、故事册与卷地图的旧停靠构图已由 ADR-0104 与 ADR-0106 取代。

儿童课程场景、触控动作和主要动效以手机竖屏为第一构图与验收目标，平板和电脑保持全部内容、功能与可访问性，但不反向要求手机承载桌面式密集布局。这个选择让孩子能够在最普遍、最受约束的家庭设备上独立学习，也避免为手机和平板同时制作两套主要课程构图。

## Considered Options

- 手机竖屏优先：覆盖最严格空间约束并控制美术生产量，因此采用。
- 平板优先：更适合大场景与低龄触控，但会让手机更容易退化成缩小版。
- 手机和平板双主构图：两端体验上限最高，但每个教学单元需要维护两套叙事构图和动效节奏。

## Consequences

- 关键物品、人物表情和触控目标必须在手机竖屏上无需缩放即可辨认和操作。
- Lesson 1 章节停靠场景必须在手机竖屏同屏容纳开启的整理室门、桌上故事册和卷起的冒险地图；“继续整理室”与“先休息”使用同等大小、同等可达的主要触控区域，故事册作为清楚但较安静的可选回看入口。三者都要有图标、短中文标签与语义化名称，不能把休息缩成角落文字链接，也不能让寻找场景热点成为挑战。
- 平板与电脑不能只是把手机画面无边界拉大，应保留合理场景边框、景深与信息密度。
- 课程美术、字幕安全区和动效镜头先通过手机竖屏验收，再验证其他现有响应式视口。
