# 挑战星逐目标轻量点亮并在回访结束后统一结算

每次独立调用成功后，界面先让角色、道具或场景呈现孩子造成的具体结果，再以不阻塞流程的轻量动画点亮一颗挑战星。完整的星星数量、来源城区进度和新纪念章只在 3–5 分钟故事化回访结束后统一结算；若同时达到纪念章门槛，纪念章揭晓排在星星归入城区进度之后。这样孩子既能立即感知挑战成功，又不会被每题一次的奖励弹层切断故事和注意力。

## Considered Options

- 场景结果后轻量点亮，任务结束统一结算：兼顾即时反馈、叙事连续性与阶段成就，因此采用。
- 每答对一个目标立即播放完整全屏得星动画：刺激明显，但反复中断角色回应、音频节奏和下一步操作。
- 过程中完全不显示，任务结束一次公布：故事最连贯，但孩子可能无法把最终星星与刚才的具体能力挑战联系起来。

## Consequences

- 反馈顺序固定为能力成功、世界结果、轻量得星、继续任务，不能先发星再解释发生了什么。
- 逐目标得星只占用场景边缘的小范围视觉层，不新增确认按钮，也不延迟音频驱动的下一步。
- 任务结算汇总本日获得的零至三颗星、各自来源城区和相关纪念章进度，不把星星错误归入当前故事地点。
- 同一任务触发纪念章时，先完成星星结算，再进行一次独立但简短的纪念章揭晓，不能让两套庆祝同时争夺注意力。
- 结算跳过与纪念章揭晓的点击顺序按 ADR-0056 处理。
- 减少动态效果模式直接更新同一状态并保留必要文字，不能因跳过动画漏发星星或漏记纪念章。
- 星星总数与城区进度的常驻位置、结算驻留和退出方式按 ADR-0055 处理。
- 未取得挑战星的目标按 ADR-0053 使用无空星、无红叉、无半颗星的无损失纠错反馈。
