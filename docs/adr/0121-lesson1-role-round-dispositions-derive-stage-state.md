# Lesson 1 角色扮演按角色回合分别处置

Lesson 1 的 `L01-M12` 不再提供“一次跳过整个阶段”的动作。孩子进入招领员或女顾客角色后，可以完成或经确认跳过当前角色；两个角色都有处置结果后课程继续，双角色都真实完成时阶段为“已完成”，任一角色跳过时阶段为“已跳过”。混合状态因此有明确出口，但不会伪造被跳过角色的教材接触、演练完成或学习证据，也不会解锁只属于双角色真实完成的无字逐句回演。

选角页不显示跳过；角色内仅在等待孩子操作的稳定状态显示“跳过这个角色”，台词播放、重试请求进行中和保存期间不显示。音频已经失败并停下来等待选择时，“再听一次”和可执行的“跳过这个角色”同时出现，避免把可跳过阶段变成音频故障死路。跳过确认默认返回“继续扮演”，未完整完成的当前回合不保存半段进度，之后补演从第一句开始；已完整完成的另一角色继续保留。跳过一个角色后，选角页把“已跳过”作为入口外状态并允许立刻重新补演，尚未处置的角色保持主要视觉入口。正式角色扮演同时复用无字逐句回演的两层逐句提示：先给中文交际意图，再给英文开头，提示不播放、不揭晓、不推进、不评分也不写证据；动作依次使用“提示／再提示”，第二层用完后不保留不可用按钮。

儿童可见角色名称统一为“招领员”和“女顾客”；选角标题为“选择你想扮演的角色”，两个入口只写“你来当招领员”“你来当女顾客”，不再附加角色自述或“完整演完七句，再换另一个角色”等说明。内部实体身份、教材说话者与音频映射不因显示名称改变。

该状态模型使用新的 `lesson1-2-v2.6` 体验修订；V2.5 及更早记录不迁移为 V2.6 的角色处置或学习证据。这个隔离会让新修订首次打开时从第一阶段开始，但避免根据旧的整阶段跳过记录猜测孩子分别完成或跳过了哪个角色。

双角色都完成时保留“无字逐句回演／继续课程”出口；一个完成一个跳过，或两个都跳过时，不显示双角色完成庆祝，最后一个角色处置保存成功后直接进入 `L02-M11`。已经完整演完的角色保留其真实回合完成和实际教材接触，被跳过角色不产生完成或接触；混合状态仍不形成双角色完成事实、学习结果、掌握或完成专属练习资格。

角色处置遵循 `未处理 → 已跳过 → 已完成` 的单向合并顺序。真实完成优先于较早或并发的跳过，成功状态不回退；重复事件保持幂等，保存失败不乐观改变界面，刷新和并发页面只从成功读回的角色状态重新推导阶段状态。

只处置一个角色时，`L01-M12` 仍是当前未解决阶段，旅程数字保持 `5/17`；刷新回到选角表面并显示已经保存的单角色状态，直到第二个角色也完成或跳过才进入 `6/17`。孩子从阶段地图补演“已跳过”阶段时进入隔离恢复模式：保存原主线精确位置，允许补演已跳过角色和随时返回，补演一个角色后可继续另一个或退出；只有双角色都真实完成才把阶段改为“已完成”并解锁无字逐句回演，退出时始终回到原主线而不是重新跳到 `L02-M11`。
