# ADR0023：奖章按版本永久收藏

状态：已接受的产品规则，尚未实施。时间：2026-09-26 23:36。

后续说明：旧版保留原则继续有效；下文最初的“完成单元即可获得”背景不再作为现行获星条件。2026-10-07 用户确定了[每区本次全对获星与首次满星日期固定](../award-version/2026-10-07-1309-v0.8-五答题区计星与首次满星日期规则.md)的规则，当前外观采用纪念卡。

用户选择完成单元即可获得奖章，允许提示与订正，并明确希望新版奖章推出后仍保留旧版，作为老学员学习经历的纪念。因此，已获得的奖章按其正式版本保留，不能在重练、替换图片或发布新版时覆盖或删除；新版本与旧版本可以共同收藏。普通美术修补不自动变成新的可收藏版本。

这选择了长期保留历史获得记录，而非把收藏实时投影为当前课程进度或把旧图直接替换成新图。历史奖章不证明新增题已经作答。数据边界、历史补发和新版获得条件仍需在设计文档中明确，本 ADR 不代表这些规则或功能已完成。
