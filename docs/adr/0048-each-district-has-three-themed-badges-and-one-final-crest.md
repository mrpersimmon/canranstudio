# 每个城区包含三枚阶段主题小章和一枚最终主徽章

每个城区拥有一个由四枚纪念章组成的专属套组。前三枚是阶段主题小章，随着归属于该城区的挑战星达到三个里程碑依次自动解锁，用本城区角色、事件、建筑或语言用途记录持续发生的真实帮助。第四枚是唯一的城区主徽章，只有当该城区全部教学地标落成后才自动获得；重复维护少数目标即使积累了更多星星，也不能替代完成整个城区。所有纪念章永久保留、领取不扣星，也不要求孩子在多个奖品之间作出不可逆选择。

## Considered Options

- 三枚阶段主题小章加一枚最终主徽章：既提供途中可达的收集反馈，又保留整个城区完成时的重量，因此采用。
- 一枚城区徽章随星星连续升级：界面简洁，但孩子最终只拥有一个收藏物，阶段性挑战留下的独立记忆较弱。
- 完成城区后只获得一枚最终徽章：成就含义最强，但目标过远，无法支持漫长城区中的持续期待。

## Consequences

- 十二个城区最终形成十二套主题收藏，共三十六枚阶段小章和十二枚主徽章；展示时按城区收纳，不能把四十八枚徽章同时堆在地图上。
- 三枚小章必须分别对应本城区可讲述的帮助或成长阶段，不能只更换颜色、数字或稀有度边框。
- 小章可以在城区尚未完成时取得；主徽章必须检查本城区全部教学地标的永久落成状态，而不能只检查星星数量。
- 孩子达到条件后自动获得纪念章，页面可以让孩子打开查看故事说明，但不使用购买、价格、余额或错过机制。
- 城区地图只用轻量入口或空槽提示存在未收集纪念章，完整收藏在城区图鉴中展示，避免压住地标和路线。
- 三个小章里程碑按 ADR-0049 同时检查本城区星数与二、四、六座不同地标的挑战覆盖。
