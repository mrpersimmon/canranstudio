# 冒险心把首次学习支架与回访重开分成两层

三颗冒险心采用双层规则。首次学习的关键挑战中，答错会用掉一颗心并把它转化为下一层教学线索；三颗心用尽后进入伙伴救援，由角色示范、孩子完成最后变化动作并继续主线，不重开章节。目标语言已经学习后的四十五至九十秒回访闯关才使用真正的三心重开：归零可以重开这一短轮，但不倒退课程、拆除地标或收回奖励。这样保留清晰的关卡压力与翻盘感，又不因孩子尚未学会而惩罚他。

## Considered Options

- 所有关键任务都把心转成线索且永不重开：最温和，但缺少儿童期待的真正重试挑战。
- 首次学习用心换线索，后续短回访使用真实三心重开：分开教学与竞技，因此采用。
- 首次学习归零后重开整个章节：规则最像传统游戏，却让不会的孩子重复已经完成的故事并寻求成人代答。

## Consequences

- 冒险心只在需要独立作答的关键挑战出现，观看剧情、探索场景和非判定动作不显示或消耗心。
- 首次学习的每个不同关键挑战重新获得三颗心；一项语言目标上的困难不把残余心数带入另一项新目标。回访闯关则由整个四十五至九十秒短轮共享三颗心。
- 一个聚合物品微任务中的每项目标变体检索都算新的关键挑战：物品切换时静默恢复三颗心，不播放大型补心庆祝；上一件物品的困难和剩余心数都不减少下一件物品的尝试机会。
- `L02-M03` 的 `shirt`、`coat`、`dress`、`skirt` 四项声音挑战分别重置三颗心。第一次错误把一颗心转成所选衣物动作与当前目标重播，第二次增加两衣物穿戴功能对照，第三次进入变化衣物伙伴示范；孩子在任一层亲手完成后立即继续，不能要求耗完剩余的心。受支持或伙伴救援仍获得完整衣物归位故事结果，但内部保留实际支架层级。
- `L02-M04` 的四项词形挑战分别重置三颗心；词形登记结束后，T4/`Yes, it is.` 与 T5/`Thank you very much.` 又是两个独立关键挑战，各自静默获得三颗心。词形支架不消耗 T4，T4 的错误不消耗 T5；三类结果分别保存但仍共用一个 M04 恢复点。
- `L02-M05` 的钥匙与微缩影像探索不显示冒险心；随后 `house`、`car` 两项声音挑战分别静默获得三颗心。第一次误选把一颗心转为错误钥匙后果与目标重播，第二次增加无文字双影像动作对照，第三次进入变化钥匙伙伴示范；第一项目标的错误、支架或剩余心数不带入第二项。两份结果分别记录但仍共用一个 M05 恢复点，二选一首次误选后的完成不能算独立。
- `L02-M06` 的 `car`、`house` 两项词形挑战分别静默获得三颗心；第一次误配把一颗心转为完整词形对照，第二次增加首字符与整体轮廓区别，第三次进入变化钥匙伙伴示范。前一词的错误、支架或剩余心数不消耗后一词，但提前展示另一目标完整词形时必须保留其跨目标预提示；随后交流中的每个独立语言目标仍按自己的规则重新获得心。
- M06 第三场交流的 T2 与 T4 各自静默获得三颗心。T2 误用感谢语后用心依次换取情境后果、用途对照和变化人物示范；`Yes?` 真实结束后，T4 以新的三颗心进入两块问句组织，错选另一物品块后依次获得不匹配后果、案件关系线和变化大型财产示范。语言块放错物理槽位、免费点听、拖动不准或主动重听都不消耗心。
- `L02-M07` 是无评分开张仪式，不显示或消耗冒险心。案件印章可以任意顺序点亮，拉杆点按与宽容拖动等价；未接通三枚印章、存储失败、跳过建设演出或中途退出都不是学习错误，不降低目标结果、回访机会或当日建筑完整度。
- 同一微任务内连续考察两个目标时也按两次关键挑战处理。`L01-M01` 先考察 T4/肯定归属，再考察 T1/`handbag` 听音连接，两项各自从三颗心开始；进入第二步时静默重置，第一步的错误、支架或伙伴救援不减少第二步的尝试机会。两步仍共用一个微任务恢复点。
- `L01-M02` 同样按两个连续关键目标挑战处理：先由 T2/`Excuse me.` 使用完整三颗心，人物的 `Yes?` 播放至真实结束后，再为 T4/`Is this your handbag?` 静默恢复三颗心。T2 的错误、支架或伙伴救援不减少 T4 的机会，两份结果分别记录但仍共用 M02 的一个恢复点。
- 三颗心是首次学习最多三层支架的预算，不是必须耗尽的三次猜测。M02 的 T2 两选一第一次答错后，一颗心立即转成情境后果线索，后续正确记为受支持；第二次错误增加用途对照，第三次进入伙伴示范与变化人物近迁移。孩子在任一层完成就立即结束该挑战，剩余心不补发奖励也不要求继续作答。
- M02 的 T4 两选一也遵守同一预算：第一次重复 `Excuse me.` 后，一颗心转为 `Excuse me. → Yes?` 的已完成话轮线索；第二次增加手提包、问号与人物的关系动作；第三次进入另一手提包和人物的伙伴示范与近迁移。第一次错误后的正确记为受支持，完整示范后的完成记为伙伴救援，均不改变先前 T2 的结果。
- 首次学习出现任何教学线索后，本轮最多形成受支持完成；伙伴救援形成共同完成，二者都不能冒充独立证据。
- 独立完成、受支持完成和伙伴救援在儿童端都得到同样完整、积极的故事结果、章节标记和单元建设，不使用暗淡印章、残缺奖励或“差一点”标签区分；内部证据和后续回访优先级仍分别保存。
- 孩子主动使用 `Pardon?` 请求重听、普通重播、误触以及音频或系统故障均不消耗冒险心。
- 同日看过答案后的重复只提供练习和游戏反馈；新的独立证据必须来自后续变化情境回访。
- 回访短轮归零后可以立即重新游玩，不设置等待、体力恢复或付费门槛；同日重玩仍只算练习，不能重复产生挑战星或独立证据。
- 冒险心不是长期星级、货币或地标成长条件，不能在地图上形成永久“三心评价”。
