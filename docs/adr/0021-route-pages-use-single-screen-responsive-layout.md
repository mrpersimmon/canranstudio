# 路线册页采用单屏弹性布局与宽屏双页摊开

iPhone 12 与华为大屏手机的真实审查表明，保持 940×1672 固定美术构图时，四个地标可以在竖屏手机的一屏内清楚呈现。因此本决策取代 ADR-0006：手机与竖屏平板把紧凑城区栏和完整册页共同等比容纳在一个可用视口内，允许装帧余量但不裁切、拉伸或重排地标；极矮、横屏或分屏导致铭牌不可读时，保持可读尺寸并允许少量纵向滚动。

宽视口只在两张册页均能保持最低可读尺寸并完整进入可用空间时采用固定双页摊开；册页一与二固定同摊，册页三与纯装帧衬页同摊，空间不足自动退回单页。路线册页继续一页四课，使用故事化页角和空白场景左右滑动线性换页，不首尾循环；当前任务只决定默认册页与场景高亮，不形成进度硬锁。

## Consequences

- 每张册页仍保留独立底图、固定比例和锁定地标落点，不为不同设备生成不同构图。
- 单页剩余空间使用皮革与书脊装帧吸收；宽屏双页以固定书脊连接，不把八个地标合成一张地图。
- 所有当前可见册页必须作为一个完整加载单元准备；异常有安全超时与兼容格式降级，不允许无限阻塞。
- 地标成长回看在完整全景中按阶段连续播放，不自动放大或滚动；点击任意位置跳到最新状态。
- 内部地标验收台增加“孩子端成品预览”，但正式孩子端不存在可选择的显示模式。
