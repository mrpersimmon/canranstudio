# 路线册页采用单屏弹性布局与宽屏双页摊开

手机和竖屏平板通常一屏显示顶部栏及完整地图；极矮窗口保持可读尺寸并允许少量纵向滚动。地图保持 940 × 1672 比例，空余处用装帧承接。

空间足够时固定双页：1+2、已发布的第 3 页+纯衬页。页角和空白处滑动按顺序换页，不循环；推荐只影响默认页和高亮。所有可见页一并准备，失败可降级，成长回看可点击跳过。内部验收台可预览孩子端，正式产品不增加模式选择。本决策替代 ADR-0006；细则见[册页设计](../superpowers/specs/2026-08-07-single-screen-route-pages-design.md)。
