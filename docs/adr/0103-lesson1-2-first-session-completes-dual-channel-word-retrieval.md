# Lesson 1–2 首次主线完成十一物品词的双通道检索

> 实施状态（2026-08-24）：产品决定与十六阶段／二十九结果蓝图已经接受，当前工作树也已有相应 V2 实现候选；候选仍须取得同一 SHA 自动门禁、成人完整流程与目标年龄儿童观察，不能因工作树存在就称为已验收或已发布。后续 `L49B` 新范围不改变本 ADR 的二十九结果配额；共享脏工作树虽已出现部分并行草案，但尚未形成受授权且闭合的可验收候选。

## Context

Lesson 1–2 是课程生产母版，也是孩子第一次进入完整学习运行时。产品负责人明确要求：本单元列为考察对象的十一件具体物品都必须真正学习，并在当天分别完成词音与词形考察。此前 ADR-0095 为降低题量，只在首次主线保存八份代表性结果，其余通道留到跨日回访；该抽样策略与本单元的新选择冲突。

逐词双通道若被实现成“听一个词选一次，紧接着看同一个词再选一次”，会造成记忆位置、连续重复和考试感。它也不能扩张到 `excuse`、`your`、`pardon`、`very much` 等功能词或词块：这些材料必须在完整交际表达与人物行动中学习，不能伪装成物品图片分类题。

## Decision

- Lesson 1–2 将 `handbag`、`pen`、`pencil`、`book`、`watch`、`coat`、`dress`、`skirt`、`shirt`、`car`、`house` 声明为十一项具体物品目标变体。
- 十一词在首次完成主线前，各保存一份 `audio-form-supported` 结果和一份 `word-form` 结果，共二十二个独立结果格；任何一个结果不得代写另一个通道。
- 每组先完成声音主导轮。经过一次真实故事状态变化后，才进入词形轮；词形轮重新洗牌，提交前不播放答案音频，正确后自动播放对应自然美式发音。
- 候选顺序由学习运行时使用可注入种子的洗牌产生；同一尝试内保持稳定，冒险心归零并重启整个当前微任务时更换种子。答案只按稳定实体 ID 判定。
- Lesson 1–2 使用十六个孩子可见且可恢复的短阶段承载二十二份词汇结果与七份课文／交际／迁移结果。Lesson 1 为五项；Lesson 2 以段落停靠点分成五项与六项，但仍是一个教材章节。
- 教材中的其他功能词、完整表达和 Notes 通过完整课文、角色行动、句块选择、意义判断与句型迁移覆盖；它们不新增物品词形或图片分类题。
- ADR-0095 的首课抽样仍是其他教学单元的默认策略。只有 catalog 和单元设计明确声明 `first-session-full-dual-channel` 时才使用本例外；Lesson 3–4 及以后不得未经儿童观察与产品选择自动继承。

## Consequences

- 首次完成所需正式结果从当前实现的八份抽样增加到二十二份词汇结果，总正式结果为二十九份；必须通过故事分隔、两词一组和短原子阶段控制重复感。
- 进度、恢复和阶段导航统一使用十六个微任务，不再向孩子显示七至九个大场景、内部却保存另一套隐藏进度。
- catalog 必须为每个词与通道声明稳定 `reviewCellId` 或等价身份；运行时不能再只按 `stepId` 把一次正确批量写给同屏多个目标。
- 跨日回访不再用于补齐本单元首次主线的缺失通道，而是用于变化情境下的独立调用和长期掌握。
- 本决定只改变 Lesson 1–2 的首次检索配额，不改变 catalog 唯一真源、Source ID 覆盖、声明式答案、真实 `audio/ended`、微任务级恢复或完成整章后才增长地标的边界。
