# 首次完整听读同时显示英文课文并突出当前句

六至八岁儿童第一次完整听教材对话时，同时看到按原说话者和顺序排列的完整英文课文；当前播放话轮突出，已经听过的话轮保留轻量状态。场景、动作和声音继续承担意义，首遍不显示教材中文译文或理解答案。这样避免纯音频七句连播的突兀感，让孩子能把声音、人物和词形直接连起来；本决定取代 ADR-0078 的“首遍无英文文字”。

## Considered Options

- 首遍无英文课文：听力注意最纯粹，但对第一单元儿童过于突然，声音、人物与文字缺少可见连接。
- 首遍显示完整英文课文并随播放突出当前句：提供必要阅读支架，同时仍要求真实听完整段，因此采用。
- 首遍显示中英双语字幕：理解最直接，却容易让孩子只读中文，仍不采用。

## Consequences

- 英文话轮、顺序、说话者和音频都由 Catalog 的 Source ID 提供；页面脚本不得保存课程副本。
- 完整课文从播放前即可见，当前话轮随活动音频推进；文字可见不能跳过最后一句真实 `ended` 门禁，也不能提前开放理解行动。
- 教材中文译文继续作为按需 `context` 来源，首遍不显示；教材理解问题和答案也不得提前泄露。
- 音频不可用时仍提供明确文字降级；文字已经可见不等于伪造声音接触。
- Lesson 2 物品词的“先建立物品意义、再听声音、后揭示词形”局部顺序不受本决定影响。
