# 教材 Notes 通过交际行动成为支撑，不做讲义页

Lesson 1 的两条教材 Notes 分别以 `L01-N01`、`L01-N02` 保留为 `support` 来源：孩子在接近陌生人时调用 `Excuse me.`；当教材女性角色没有听清时，孩子观察她的需要并替她选择 `Pardon?`，再由女性角色说出原教材话轮。孩子先通过交际结果体验说明的真实用途，完成后才可在故事册按需查看一句儿童化解释。Notes 不在开课前展示为中文知识卡，也不各自形成计分题；主动检索和长期掌握属于 T2、T3 交际目标，而不是 Note 文本本身。

## Considered Options

- 在交际行动中体验用途，完成后按需解释：同时保留教材说明和低龄儿童的意义建构，因此采用。
- 开课前先阅读两张 Notes 卡片：来源呈现直接，但会把原本可行动的交际功能变成成人式讲义。
- 完全省略 Notes：流程最短，却无法证明教材说明的语义已经被课程真实承接。

## Consequences

- `L01-M02` 以 `semantic-enactment` 方式覆盖 `L01-N01`。`L01-M03` 中，女性角色用动作表示没有听清，小猫帮助孩子注意交流为何停住，孩子正式选择 `Pardon?`，女性角色说出第 4 话轮并得到原男性询问者的重说，由这一完整行动覆盖 `L01-N02`；小猫不是该教材话轮的说话者。覆盖表示孩子经历了说明中的交际用途，不表示背诵或回答过 Note。
- 两条按需儿童化解释属于产品原创 Content ID，分别引用对应 Note Source ID 和 T2、T3；孩子不打开解释也不阻塞章节。
- 章节故事册把两条儿童化说明分别放在 `Excuse me.` 与 `Pardon?` 所在插画旁的可选“小提示”中，不另设 Notes 讲义页。只有孩子主动打开说明时才记录这次可选查看；未打开不伪造接触，不影响已经通过交际行动获得的 `semantic-enactment` 覆盖，也不产生目标证据。
- T2、T3 的主动检索、支架状态和跨日证据绑定学习目标；Note Source ID 只有来源接触，不进入 `evidenceRefs` 或掌握统计。
- 单独的字符串数组 `exposureRefs` 无法说明逐字听读、可见文字、语义行动或按需译文等不同接触方式；后续 catalog 合同需要能为来源引用声明接触方式。此设计阶段不修改现有运行时。
