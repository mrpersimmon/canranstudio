# 地标验收台完整预热当前地标的所有阶段

地标验收台是仅供产品与美术维护者使用、不会出现在普通用户导航中的内部工具，并以连续比较美术状态为首要目标。因此进入一个地图地点后，无论当前网络类型，都准备该地点全部累计状态的手机、平板和桌面三档图片，并按美术版本长期复用；编号课程通常准备十八项，五状态支线准备十五项，数量由地点合同决定。我们接受每个编号课程约 2.5–3MB 的审查流量，以换取阶段和布局尺寸切换均无需重新等待。验收台常驻显示已准备资源数、传输体积和当前处理资源，供维护者判断下载、解码与缓存命中状态；单个资源自动重试两次后仍失败时，明确指出资源并允许单独重试或使用兼容格式，不阻塞其他图片；另提供只绕过当前地标缓存的复验入口，用于检查首次访问表现而不清除其他地标。未准备好的目标状态被选择时优先准备，同时保留当前画面直到新图可显示。状态美术审查与地图落位审查共享同一套准备结果，切换审查视角不会取消或重复准备。切换地图地点时，新地点立即接管准备优先级，旧地点尚未开始的任务停止，已经完成的图片继续留在缓存中。只有地点合同中的全部资源下载并完成解码才可标记为“验收就绪”；此后阶段、审查视角和尺寸切换不得产生该地点的新图片请求或空白，并须在一百毫秒内完成画面替换。这是审查工具对 ADR-0015 孩子学习入口节流原则的有界例外：只预热当前地标，不在进入验收台时下载全部地标；孩子学习入口继续按实际设备选择响应式图片。
