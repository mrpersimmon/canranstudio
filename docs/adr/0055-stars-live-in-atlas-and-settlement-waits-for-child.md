# 星级状态留在地图与图鉴层且结算等待孩子继续

终身挑战星总数常驻在冒险地图册顶部，并在回访结算中更新；本城区纪念章进度只在对应城区图鉴和结算中展示。课程场景不常驻任何星数，只在刚形成独立调用证据时轻量点亮本次星星。回访结算完成后保持最终状态，直到孩子点击或轻触任意位置继续，不自动消失，也不放置单独的“继续”按钮。这样成就在世界与收藏层始终可查，但学习场景不会被持续积分提示占据。

## Considered Options

- 地图与结算显示星星、城区图鉴显示本区进度、课程场景只显示即时得星：兼顾成就可见性与学习专注，因此采用。
- 所有页面始终显示终身星数：目标最醒目，却会让语言任务持续围绕积分而不是角色和情境。
- 只在图鉴深处显示星星：界面最安静，但孩子难以感知日常挑战正在积累成长期成果。
- 结算等待点击任意位置：尊重不同阅读速度且不增加按钮寻找成本，因此采用。
- 结算定时自动关闭或要求点击按钮：前者可能跳过孩子尚未看完的成果，后者增加不必要的界面操作。

## Consequences

- 地图册顶部只显示终身挑战星总数，不把每日三颗上限、空槽或城区分项同时塞进同一导航区域。
- 城区图鉴负责展示本城区三枚阶段小章、一枚主徽章及其真实进度，课程场景不复制这套收藏界面。
- 刚获得星星时仍按 ADR-0052 在场景结果之后短暂出现，但反馈完成后自动退回，不形成课程页常驻计数器。
- 回访结算的星星和进度先完成动画，再进入可无限驻留的最终状态；点击或轻触任意位置后继续新冒险。
- 结算状态本身不控制发奖事务，刷新、退出或重复点击都不能重复增加星星。
- 动画尚未完成时的点击行为与新纪念章揭晓顺序由 ADR-0056 的两步跳过和独立揭晓规则决定。
