# Lesson 1–2 使用双画幅直接操控与回家终幕

儿童实玩显示，词形关虽然写成“放回正确格”却只允许点选物品，电脑端还会在场景模式切换时丢失柜台并改变人物比例；最后的抽象路线图既不是教材内容，也没有说明为什么要把它交给手提包主人。Lesson 1–2 因而把空间关系动作统一为以宽容拖拽为主要呈现、以“先点动作端、再点目标端”为等价备用路径。拖到空白处只柔和归位，不算英语错误或扣冒险心；拖到另一个有效但错误的实体才进入语言纠错。真正的手提包归还只在所属故事阶段拖给主人一次，提交前所有候选与落点保持视觉中立。

手机竖屏与平板／电脑宽屏采用两套构图母版但共享同一场景语义、人物、锚点、语言与结果：竖版母版约为 9:19.5，宽版母版为 16:10，各自只导出必要清晰度，不为每个设备尺寸单独作图。两套新背景沿用当前星灯失物招领站的木质夜景画风，但不把人物、柜台物品或任务道具烘焙进背景；宽屏始终保留真实柜台。人物只在有对话或故事职责时出现，在场时固定于同一左右关系位和同一尺度，纯物品阶段可以让两名成人一起离场。

Lesson 2 终幕取消“完成抽象路线图再交给女顾客”：`L02-M20` 先在完整场景中听音指认真实 `car` 与 `house`；`L02-M21` 把 `car` 标签拖到真实汽车后，女顾客上车，再把 `house` 标签拖到真实房屋后，汽车抵达家中。每段成功动作使用约 4–6 秒的清楚演出；减少动态效果时直接切到相同上车／到家终态。两个正确语言动作直接推动故事，不再追加无语言意义的确认或交图操作；`car`、`house` 的教材 Source、声音与词形结果、音频结束门禁、原子保存、十七阶段和地标条件均保持不变。

## 2026-08-26 冻结选择

1. 英文标签、物品归位与手提包交付都以拖拽为主要动作。
2. 手机竖版与平板／电脑宽版使用两套同语义构图母版。
3. 取消抽象路线图，以真实上车和到家结束故事。
4. 保留“点动作端→点目标端”作为等价备用路径。
5. 只制作竖版与宽版母版，不按设备尺寸逐一作图。
6. `car` 标签触发上车，`house` 标签触发到家，不增加第三次点击。
7. 人物只按故事职责出现；在场时位置与尺度稳定，纯物品阶段可一起离场。
8. 新母版沿用当前木质星灯夜景画风，人物与任务道具保持独立图层。
9. 空白误拖只归位；拖到有效错误目标才算语言错误并进入支架。
10. 上车与到家各使用 4–6 秒标准演出，并提供相同终态的减少动态效果路径。

本决定只冻结课程与场景合同；它不授权修改运行时代码、合并 `main` 或发布网站。
