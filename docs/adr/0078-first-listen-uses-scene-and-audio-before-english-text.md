# 首次完整听读先用情境与音频建立意义

> 本决定已由 [ADR-0090](./0090-first-listen-shows-english-text-with-active-line.md) 取代；以下内容保留为历史背景。

每个奇数课章节第一次完整呈现教材对话或叙事时，先用角色、动作、道具和英文音频建立意义，不同时显示英文逐字稿。系统可以用一句极短中文语音或图示说明听力目标；孩子形成初步理解后，再按情境同步揭示英文文字，并允许按需查看中文含义。这样保留教材“先听懂、后见文字”的教学顺序，又让六至八岁零基础儿童不必在纯英语中盲猜。

## Considered Options

- 首遍情境与音频、理解后揭示文字：兼顾听力注意和独立学习支架，因此采用。
- 首遍始终显示中英双语字幕：最容易跟上，却会让儿童直接阅读中文而跳过英语声音。
- 全程英语且不提供中文支架：沉浸感最强，但把原本由教师完成的情境引入留给儿童猜测。

## Consequences

- 首遍任务说明必须短、可听且有图示，不能用一段中文讲义替代故事。
- 教材原始理解问题作为一个完整的 `context` Source ID 保留；首听前使用独立 Content ID 的极短中文任务传达同一观察目的，不展示或讲解原英文问题。孩子完成理解行动后，原问题才可以在故事册中出现；题内单词不因出现于问题中而自动成为检索或产出目标。Lesson 1 的 `Whose` 因此不单独教学或取证。
- 首次连续音频结束前不插入或开放答题；只有整段所需对话的最后一句真实播放结束，理解动作才可以开始。开始播放、经过预计时长或听完中间一句都不能冒充完整听读。
- 教材理解行动必须在完整音频真实结束后立即发生，其他词汇挑战、逐句阅读或故事奖励不能插在两者之间，以免额外任务稀释刚建立的角色与情节线索。Lesson 1 因此先让孩子把画面中已经可见的手提包交给主人，再进行 `handbag` 的声音—物品连接挑战。
- 首听理解行动不是纯故事推进：它可以为所关联的核心目标形成首次检索轨迹。紧接完整输入后第一次无支架答对只记录形成性成功；使用任一纠错支架后记录受支持完成；两者都不能形成跨日独立证据或目标掌握。Lesson 1 的物主判断映射 T4 对肯定归属的理解，而不是 `Whose` 产出。
- 首听可以暂停、从头重新播放和在完成后自由重听，以上操作不消耗冒险心；第一遍不能通过提前猜答案跳过剩余教材台词。
- 初步理解后仍留在原场景逐句揭示英文，当前音频播放时轻量同步高亮；孩子可以点按单词重听并按需查看含义。
- 教材中文译文作为 `context` 来源与对应英文 Source ID 建立关系；首遍不显示，英文台词揭示后才允许孩子主动打开。查看不是章节门禁，不出翻译题，不形成 `evidenceRefs` 或掌握；孩子未打开时也不能伪造译文接触。极短任务提示属于产品原创 Content ID，不冒充教材译文。
- 完整对话在章节后进入可自由重看的四幕插画故事册，不能用整页课文替代场景内的声音、人物和文字连接。故事册不会在结案后自动打开；孩子点按案件桌上的实体书本入口才进入，关闭后回到原章节停靠场景。
- 四幕依次保持教材原说话者与话轮顺序：`Excuse me. → Yes?`、`Is this your handbag? → Pardon?`、`Is this your handbag? → Yes, it is.`、`Thank you very much.`。当前句使用大号英文，可逐句点听，也可从头顺序播放；故事册不打乱话轮、不把同文的第 3 与第 5 话轮合并，也不把儿童或小猫登记成教材说话者。
- 每句教材译文默认收起，仅在孩子点按当前句“小灯笼”后显示；11 项词汇进入可选词语抽屉，两条 Note 的儿童化说明贴近相关场景，教材原理解问题在末页以“我们刚才解决的问题”出现但不要求再次作答。打开、翻页、查看或关闭均不阻塞章节，不产生题目结果或掌握。
- 孩子主动重听不受惩罚；音频不可用时仍按 ADR-0040 提供文字降级，不能因为坚持“无字”而阻塞学习。
- 偶数课的看图听说操练可以按已经接触过的语言显示必要文字，不机械套用奇数课首听规则。
- Lesson 2 的新物品探索仍遵守“先物品含义、再声音、后词形”的局部顺序。`L02-M05` 中，孩子先通过无英文钥匙和汽车行驶／小屋亮灯开门的微缩影像建立含义，再听完整美式词音；只有真实 `ended` 后英文词签才短暂出现。进入声音挑战前词签必须全部收起，探索中的文字接触不能冒充随后词形通道成功。
