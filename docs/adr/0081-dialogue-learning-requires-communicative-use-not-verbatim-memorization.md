# 教材对话要求交际调用而非逐字背诵

> Lesson 1–2 范围说明（2026-08-23）：交际调用而非逐字背诵的原则继续有效；下文徽章、钥匙与旧任务编号实例仅保留为历史。当前感谢迁移位于 `L02-M07`，car/house 使用真实场景，详见 ADR-0102 与当前实施验收包。

课程要求孩子听懂教材对话的交流顺序，并能在变化物品、人物或目的中调用核心表达；不把逐字背诵整段对话作为单元完成或目标掌握条件。完整跟演、角色朗读和背诵仍可以作为自选挑战与故事表演，但不能替代对含义、用途和迁移的验证。Lesson 1 因此要求孩子参与“引起注意、询问归属、请求重复、确认与感谢”，而不是强制逐字背完七句。

## Considered Options

- 理解交流顺序并在变化情境调用核心表达：最接近真实语言能力，因此采用。
- 逐字背诵完整对话：能够增加流利接触，却可能掩盖孩子并不理解或不会迁移。
- 只回答教材听力问题：负担最低，但无法证明孩子能参与本课交流。

## Consequences

- 课程可以提供完整跟读、表演和背诵入口，但这些活动默认不阻塞单元当日完成。
- 交际调用的证据必须改变物品、人物或目的，不能只让孩子复现刚刚看过的七句顺序。
- 主动调用必须保持交际角色一致性：孩子直接扮演角色时，只说当前角色自然拥有的话轮。同一单元包含双方表达时，可以在不同小情境中切换孩子的角色，不能让孩子在同一对话中替双方依次点完全部台词。
- 课程也可以使用“教材话轮代选”：孩子观察当前教材角色的需要并主动替她选择合适表达，原角色仍以教材身份和声线说出该话轮。这个选择可以形成目标检索，但不能把孩子或引导伙伴登记成该教材话轮的说话者。
- `L01-M03` 中，教材女性角色用侧耳动作表示没有听清，小猫只提醒孩子观察对话为何停住；孩子替女性角色选择 `Pardon?`，由女性角色说出教材第 4 话轮，再由原男性询问者重复教材第 5 话轮。任何把第 4 话轮改成小猫台词的旧描述均由本决定纠正。
- M03 的最终纠错层可以让另一位角色在独立的变化小情境中示范 `Pardon?` 的交际用途，再让孩子回到原场景完成选择；该示范保持自身角色一致，但属于产品近迁移支架，不会取代或改写教材女性角色拥有的第 4 话轮。
- 原男性询问者说完第 5 话轮后，教材女性角色仍以原身份说出第 6 话轮 `Yes, it is.`；孩子不替她再选择一次台词，而是在听懂肯定归属后亲手把手提包交给她。这样既保留教材角色与顺序，也避免把连续七句话逐句改成选择题。
- 教材女性角色收到手提包后仍以原身份说出第 7 话轮 `Thank you very much.`，完成教材对话；孩子不能替她占用这个 Source ID。随后小猫归还孩子原本遗失的“星灯探险徽章”，孩子才在独立迁移情境中作为接收者调用同一感谢表达并形成 T5。徽章只是失而复得的固定故事道具，不是新奖励，不显示或播放英文，也不引入新的英文目标；产品情境不冒充教材话轮。
- 孩子把完整感谢表达送入自己的说话槽，表示为当前接收者作出交际选择；表达牌点听仍是学习控制，不是孩子角色发声。课程可以随后邀请孩子真实跟说，但在 V1 不采集语音时，只声明已经取得触控层面的 T5 检索，不能把卡片音频或停留时间说成孩子完成了口语输出。
- T5 最终纠错层可以让另一位小探险者在独立的“失物被归还”情境中示范感谢用途，再让孩子回到自己的接收者情境完成选择；该示范属于产品近迁移支架，不取代教材女性角色的第 7 话轮，也不把示范者登记成教材说话者。
- 不评分语音时，可以用匹配、排序或句子组织证明对应的理解和结构维度，但不得宣称已经证明发音与口语流利度。
- `L02-M02` 的第一场归属交流让孩子始终担任询问者，不替认领者依次点完双方台词。孩子先选择完整 `Excuse me.`，再把本批四张物品标签中的 `watch` 放入单槽句框 `Is this your ___?`；认领者自己回应 `Yes?`、`Yes, it is.` 和 `Thank you very much.`，孩子只在肯定回答后亲手交出手表。这里没有真实听不清，因此不机械加入 `Pardon?`；固定句框替换是从完整表达选择走向语言块组织的第一层递进，不要求逐词排序或背诵七句。
- `L02-M04` 让孩子换成物主，归还者先用产品变化表达 `Is this your coat?` 主动询问；孩子只承担自己的 `Yes, it is.`、接回外套和 `Thank you very much.`，不替归还者说问句，也不机械加入 `Excuse me.`。两个孩子话轮分别形成 T4 与 T5，个人衣钩动作保持归属意义；说话槽示范音不冒充孩子发声。这样完成询问者到物主的角色迁移，而不是把同一七句对话重新点一遍。
- `L02-M06` 让孩子回到失物站询问者角色，但不要求一次自由排序整段对话。孩子先在真实“尚未被注意”情境调用完整 `Excuse me.`，认领者自行回应 `Yes?`；再用 `Is this your` 与所选 `car?`／`house?` 两个大块组织当前问题，认领者自行回答 `Yes, it is.` 并在交接后感谢。这样形成“完整表达选择 → 固定框替换 → 两块组织”的递进，保持双方角色一致，也不把对方台词改成孩子需要逐句点完的测验。
