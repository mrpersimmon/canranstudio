# 后续教学单元继承课程母版，只审真正例外

Lesson 1–2 作为六至八岁儿童独立课程的首个黄金母版，用当前深度冻结全课程的年龄边界、教材来源身份、学习证据、音频门禁、渐进纠错、稳定恢复、catalog 所有权、儿童交互与成长反馈。后续教学单元不再从零重复这些决策，而是先继承已经接受的全局规则与适用的任务模式，由课程制作流程完整读取教材、建立来源覆盖、设计专属故事和微任务并完成自检；只有无法由现有规则推导、会引入新产品边界或与既有决定冲突的真实例外才交给产品负责人明确决策。

## Considered Options

- 每个教学单元重新进行完整设计访谈：局部判断最细，却会把七十二个单元变成重复的百题决策，扩大不一致并让产品负责人承担可以由既有规则推导的制作工作。
- 把 Lesson 1–2 的页面与故事做成固定模板后逐课换词：生产最快，却会把课程变成重复小游戏和故事换皮，违背专属课程语义与自由叙事原则。
- 继承已确认默认规则、按教材语义独立创作、只审真实例外：既保留系统一致性和规模化生产，也允许不同教材结构形成不同故事体验，因此采用。

## Consequences

- Lesson 1–2 的黄金母版状态由冻结设计和实施验收包共同表达：前者保留完整课程语义，后者是后续 TDD、可玩原型与儿童验收的单一交接入口。验收包不能反向缩减教材覆盖或把尚未实现写成已经交付。
- 每项已确认设计必须按作用域理解：全局不变量适用于全部教学单元；可复用任务模式只约束明确采用该模式的课程；人物、道具、顺序、情节与美术等单元专属内容只属于当前单元。后续课程不能把“星灯失物招领站”、认领单、衣柜或当前词序误当成全书固定皮肤。
- 教材事实由课程制作方从受控来源查明，不向产品负责人询问可以通过 PDF、catalog 或仓库确定的事实。每个新单元先建立 Source ID、来源角色、目标、接触、形成性检索和有记录省略，再进行儿童故事创作。
- 已确认的年龄、手机竖屏、美式语音包、真实 `ended`、目标匹配证据、三心纠错、微任务恢复、catalog 唯一真源、背景音乐控制和整单元成长边界默认继承；没有冲突时不再逐项请求确认。
- 课程制作方可以在既有边界内自行决定场景、角色、道具、动画、任务顺序和儿童提示，并通过目标与来源矩阵、声明式答案、支架、音频、恢复、适龄性、可访问性、部署合同和静态构建等检查自证完整。自由创作不能把共享学习规则变成固定页面换皮。
- 只有出现以下真实例外才暂停并请求新决定：教材结构无法由已有目标或任务模式承载；需要新增或改变学习目标、证据、掌握或奖励语义；难度可能超出当前年龄边界；需要麦克风、儿童数据、付费或其他高风险能力；要改变全局画风、地标成长或语音边界；或两个都符合现有规则的方向会形成实质不同且不可轻易回退的儿童体验。
- 一个普通单元交付紧凑验收包，至少包含一句话故事、教材来源与目标覆盖、微任务路线、相对母版的真实例外、可玩的儿童体验以及自动检查结果。产品负责人的主要工作是验收孩子是否学得明白、愿意继续和是否符合品牌，而不是重新决定每个按钮与恢复点。
- 普通教学单元以零至三个新增决策为生产目标，而不是强行配额；没有真实例外时可以直接进入体验验收。出现新课程类型时可以提出更多必要问题，但新决定一旦接受就进入对应作用域，后续同类单元不重复询问。
- Lesson 1–2 完成后，Lesson 3–4 作为第一次“无密集访谈”生产演练：课程制作方依据母版独立形成完整方案，只提交真实例外和验收包。演练若暴露母版缺口，应补充全局规则或任务模式，而不是退回逐课百题访谈。
- 设计验收、运行时实施、合并与发布是不同授权边界。本 ADR 允许在已确认规则内减少重复设计提问，但不自动授权批量实现所有课程、合并 `main` 或发布网站；这些动作继续遵守用户的明确范围与发布批准。
