# 纪念章故事和美术从真实课程语义开始创作

每个城区的纪念章创作首先分析该城区真实教材内容，提取人物、生活情境、交际目的、语言能力以及使用语言后可以观察到的结果。创作团队先回答“孩子用这些英语能够帮助谁完成什么”，再把多个课程事实组织成符合四段贡献骨架的城区事件，最后才依据城区环境选择建筑、材质、道具、构图、代表色和可制作成实体物的收藏符号。

城区环境负责让六座教学地标和四枚纪念章属于同一个世界，但不能替代课程含义；皇冠、钥匙、盾牌等易识别收藏符号也不能先行决定故事。每枚纪念章的名称、核心图案、非剧透线索、揭晓铭文模板和完整说明都需要记录其课程语义来源，或证明它是由多个课程共同支持、对任意合资格路径都成立的城区公共叙事。

## Considered Options

- 从真实课程人物、交际目的和语言用途开始，再转化为城区事件与视觉：纪念章能够真正唤回学习经历，因此采用。
- 从城区环境开始设计漂亮套组，再补入课程解释：视觉统一较快，但容易出现学习关系牵强或只是背景换皮。
- 从适合收藏和实体制作的通用符号开始，再寻找课程理由：生产方便，却最容易退化成与学习无关的普通奖章。

## Consequences

- 每个城区进入纪念章美术创作前必须先完成课程语义表，包括课次来源、语言用途、角色、结果和可用公共叙事。
- 每个纪念章 brief 必须能从核心图案反向说明其对应的语言贡献，不能只用一句抽象励志文案建立联系。
- 环境与工艺可以影响表现方式，但不能改变、夸大或虚构教材事实。
- 如果某个漂亮符号无法追溯到课程语义或城区公共事件，就不能成为纪念章核心图案；最多只能作为边框装饰。
- 美术审查除风格和清晰度外，还必须审核课程可追溯性与对不同合资格路径的叙事真实性。
- 探险小猫通过统一的小型猫爪与紫金旗印记连接全套收藏，只在故事自然需要时进入主图，详见 ADR 0074。
