# Catalog 统一拥有课程专属内容

教材英文、角色话轮、任务专用中文提示、声明式答案规则、纠错支架、Source ID 映射和课程音频引用都属于课程专属内容，必须由 catalog 作为唯一真源统一提供。页面脚本只渲染 catalog 给出的状态并转发儿童动作，不能保存、拼接或改写另一份课程内容；否则来源覆盖、恢复、答案判定与音频版本会产生无法审计的分叉。`继续`、`重播`、`音乐已关闭` 等不依赖教学单元的通用界面文案由运行时共享词典维护，不在每个单元 catalog 中重复。

## Considered Options

- Catalog 统一拥有全部课程专属内容，运行时词典拥有通用界面文案：课程事实只有一份，同时避免每单元重复通用文字，因此采用。
- Catalog 只保存教材英文，页面脚本保存中文提示与纠错：短期方便，但页面会形成第二份课程真源，无法可靠验证 Source ID、恢复与答案规则一致性。
- 每个单元重复保存所有通用按钮文字：单元看似自包含，但会扩大翻译、无障碍和产品文案维护成本。

## Consequences

- Catalog 必须表达课程专属文本、角色、教材来源角色、任务提示、声明式答案、支架、音频引用及其稳定标识；不同字段可以引用同一 Source ID，但不能在页面重新抄写课程正文。
- 教材来源项使用 Source ID，产品原创课程内容使用 Content ID；两者可以相互引用，但不能共享命名空间或相互冒充。
- Catalog 对每个教材来源项还要区分进入儿童体验的来源与有记录的教材省略；省略项必须保留决定理由，但不得进入接触、证据或掌握统计。
- 通用界面文案只能描述课程无关的运行时动作或状态，不能偷偷承载某一课的答案、提示或教学解释。
- Catalog 校验需要证明所有任务引用存在、必需 Source ID 获得覆盖、答案和支架引用有效、课程音频映射完整；页面测试只验证渲染和动作转发，不再把硬编码课程字符串当作事实。
