# 教材来源全覆盖不等于每项单独计分

> Lesson 1–2 范围说明（2026-08-23）：本文“完整来源接触不等于逐项出题”的原则继续有效；全部旧 M01–M07、徽章和钥匙任务级例子仅保留为历史。当前本地候选由 ADR-0095 决定八份首课 T1 抽样，由 ADR-0102 决定删除 `L01-M04` 并使用 car/house 真实场景；当前 ID 与门禁见实施验收包。

课程必须让所有必学教材来源项获得可追踪的真实接触，让每个声明的学习目标至少经历一次主动形成性检索，并只让核心学习目标通过后续独立调用证据进入长期掌握。一个自然的交际任务可以同时覆盖多个 Source ID；系统不把教材每句话、功能词或说明各自改造成一道计分题，以免来源审计演变成儿童题海。

## Considered Options

- 每个 Source ID 各设一道计分题：审计关系直接，但混淆教材忠实度与能力证据，也会制造大量脱离情境的碎题。
- 来源完整接触、目标主动检索、核心目标跨日取证：同时保留教材边界、主动学习和可解释掌握，因此采用。
- 只抽查部分内容：体验最短，但无法证明教材或学习目标没有遗漏。

## Consequences

- 每个教材来源项需要标明 `target`、`support` 或 `context` 角色，不能因拥有 Source ID 就自动要求独立掌握。
- `context` 来源还要声明接触政策；按需教材译文可以只在孩子主动打开时记录可选查看，不要求所有孩子查看，也不产生 `evidenceRefs`。因此“存在于 catalog”和“儿童实际接触”仍是两个不同事实。
- `support` 来源还要声明接触方式；教材 Note 可以通过 `semantic-enactment` 在真实交际行动中获得语义接触，而不要求儿童先阅读或背诵说明文字。对应学习目标取得主动检索，Note 自身不进入 `evidenceRefs`。
- 教材词汇表中的每个词或短语都保留自己的 Source ID，并获得声音、词形与真实语境接触；其中承担结构或交际支撑的词项不因此获得独立 `evidenceRefs`，也不被拆成孤立词义题。
- 作答后词形揭示可以满足词汇来源项的词形接触，但不产生新的目标尝试结果。Lesson 1 的 `handbag` 听音挑战完成后才显示同一词汇 Source ID 的英文标签并重播词音；来源接触与听音证据分别记录，不能因一次呈现同时伪造两种证据通道。
- 必需词音只有播放到真实 `ended` 才能记录声音接触；开始播放、标签已经显示或达到预计时长都不够。音频失败降级可以保留词形接触和已取得的目标结果，但必须把声音接触记为缺失并优先安排音频可用的回访。
- Lesson 1 的 `handbag` 是 T1 的目标变体；`Excuse me.`、`Pardon?`、`Thank you very much.` 等完整交际表达分别由 T2、T3、T5 主动检索。构成这些表达或句型的支撑词项随完整语言块反复出现，但不额外增加核心目标或问题数量。
- 一次首听理解行动可以同时完成教材问题的来源接触并为相关核心目标形成检索轨迹，两者仍是不同事实。Lesson 1 把手提包交给正确人物时，教材问题 Source ID 只记录来源接触，孩子对肯定归属的判断记录在 T4；紧接输入的成功或使用支架后的完成都不进入独立证据。
- 一个微任务覆盖多个学习目标时，每个目标或目标变体分别保存尝试结果，不能用一条任务级通过状态替代。`L01-M01` 因此分别记录 T1/`handbag` 与 T4/肯定归属；一项需要支架不会污染另一项的无支架形成性成功，只影响对应目标的后续回访优先级。
- `L02-M01` 的四项听音选择分别保存 `book`、`pen`、`watch`、`pencil` 的声音通道结果与实际支架层级，不能用“四件全部上架”的任务状态替代四份目标变体结果。答对后的物品动作、货架位点亮、可能出现的标签或重播只属于反馈与来源接触，不能生成相应词形通道结果；四件最后一起上架也不产生第五份目标结果。
- M01 的自然重播、两项聚焦和变化物品示范都必须附着在当前词的同一声音通道尝试上。第一次误选后的正确最多是受支持完成，变化物品示范后的正确是伙伴救援；重播可以增加该 Source ID 的真实声音接触，物品动作可以增加产品支架接触，但两者都不能生成额外目标结果、替其他词填格或补出当前词的词形结果。
- `L02-M02` 分别保存 `handbag`、`watch`、`pencil`、`book`、`pen` 五份词形通道结果；旧案件档案模型只让已经归还的 `handbag` 以一致视觉载体参与检索，不创建新物品词 Source ID，也不改写“手提包已归还”的故事状态。每项作答后播放的词音继续引用原词汇 Source ID，真实 `ended` 只记录声音再次接触；标签扣合、登记盘和最终统一装标均不能生成第二份声音结果或第六份词形结果。
- M02 纠错中翻出的误选物品标签继续引用该词既有 Source ID，只形成真实词形再次接触与产品支架关系，不生成该词的主动结果。若这个词尚未完成自己的词形挑战，运行时必须把它标为同任务内已预提示；稍后结果至多是受支持完成，不能因为它在自己的轮次没有再次出现显式支架就写成无支架形成性成功。当前词、被提前提示词和其他三个词的结果仍分别保存。
- M02 第一场交流分别保存 T2/`Excuse me.` 的交际意图结果和 T4/`Is this your watch?` 的固定句框替换结果。认领者的 `Yes?`、`Yes, it is.` 与 `Thank you very much.`、孩子交出手表和第一张认领单都是可关联但不能互相替代的接触或故事事实；它们不生成新的 T1、T4 或 T5 结果。没有交流故障就不创建 `Pardon?` 接触或 T3 结果。
- M02 误选 `Thank you very much.` 可以记录该既有 Source ID 的再次文字或声音接触，但只改变 T2 的支架轨迹，不能生成 T5。误插物品标签后播放的 `Is this your pen/pencil/book?` 是产品变化表达接触；其中物品词继续引用各自词汇 Source ID，问句结构引用 T4 的教材依据，但整句不创建教材话轮 Source ID，也不生成对应物品的 T1 结果。关系线、人物无词回应和旁窗示范都只服务当前 T4 支架。
- M04 的 `Is this your coat?` 是产品变化表达，使用 Content ID 并引用教材问句结构与 `coat` 词汇 Source ID；它不是新教材话轮。孩子正式选择 `Yes, it is.` 与随后 `Thank you very much.` 分别形成 T4 与 T5，卡片点听只形成再次接触。接回外套和第二张认领记录不生成 T1，未发生交流故障时 `Pardon?` 不生成 T3，归还者主动发问也不要求或生成 T2。
- M04 T4 纠错中的 `Is this your book?` 是另一条产品变化表达，使用稳定 Content ID 并引用问句结构与 `book` 词汇来源；它和伙伴的 `Yes, it is.` 只属于当前 T4 支架，不创建教材话轮、`book` 的 T1 结果或另一份 T4。纠错中展示感谢正确时机可以标记 T5 跨目标预提示，但误选感谢本身仍不是 T5 尝试。
- `L02-M05` 分别保存 `house`、`car` 两份声音通道结果；钥匙浮雕、探索词签、微缩投影、语义动作与共同入盒把教材词汇连接到可理解故事，但不创建新的教材来源、第三份目标结果或两份词形结果。探索和反馈中的真实词音／词签可以记录各自 Source ID 接触，只有反序挑战中的正式钥匙提交才形成当前声音通道尝试。
- M05 纠错中的错误钥匙投影、双影像对照和变化实例都附着在当前声音目标的同一尝试轨迹上，不生成额外目标结果。只有当前目标词音可以增加该 Source ID 的声音接触；非目标物品只做无语言动作时，不记录它的新声音或词形接触，也不把它之后的正式挑战降级为已见答案。第一次错误后的正确仍必须因二选一排除线索记为受支持。
- `L02-M06` 分别保存 `car`、`house` 两份词形通道结果；档案牌、钥匙、微缩反馈和封页把词形连接到既有含义，但不创建新教材来源、第三份 T1 结果或声音通道结果。正式提交前的目标牌是当前检索提示，纠错中展开的错误牌是词形支架接触，结算后的反馈词音只是声音再次接触；三者必须分开记录。
- M06 的无英文案件选择只决定产品故事分支，不生成物品词结果。第三场交流分别保存 T2 完整开场语选择与 T4 两块问句组织结果；`Yes?`、`Yes, it is.`、最终感谢、钥匙交接和第三张记录只形成各自来源接触或故事事实。`Is this your car?`／`Is this your house?` 是引用问句结构与物品词来源的产品变化表达，不创建教材话轮；错误变化问句也不生成 T1。
- M07 的三个无英文案件缩影只回看 M01–M06 已保存的故事事实，不重新呈现教材来源，也不补齐缺失接触或目标结果。开张仪式和地图建设使用产品 Content ID；它们可以聚合“必做微任务已经完成”的状态，却不能把聚合状态转换成新的语言证据、平均覆盖或目标掌握。
- 成果庭院中的人物欢迎、已完成室内道具和安静／到期信箱均使用产品内容或运行时状态；自由查看不会自动重播或记录教材 Source ID。只有孩子在明确的可选重听中真实听完某条已声明音频，才可记录该来源的再次接触，仍不能形成目标尝试、补齐缺失证据或改变掌握。
- `L01-M02` 对 T2/`Excuse me.` 与 T4/`Is this your handbag?` 各安排一次完整语言块检索并分别记录结果；中间的 `Yes?` 保留人物回应及其教材来源接触，但不新增目标挑战。两份目标结果在 M02 完成时一起保存，不能用一次“完整询问成功”覆盖两项目标的真实支架状态。
- M02 的 T2 挑战只在 `Excuse me.` 与 `Thank you very much.` 两个已听过的完整表达间选择。两项都复用各自教材 Source ID；`Thank you very much.` 在这里作为情境干扰项的再次呈现不生成 T5 目标尝试结果，孩子点听任一表达也不构成主动检索或答案提交。只有正式选择按 T2 的声明式答案规则结算。
- T2 首次误选后，情境后果和排除关系已经构成支架；之后选择 `Excuse me.` 必须记录为受支持完成，不能只保存最终正确选项并丢失首次错误。伙伴完整示范后由孩子完成变化人物近迁移时记录伙伴救援；两种结果都不形成跨日独立证据。
- M02 的 T4 挑战在人物 `Yes?` 真实结束后显示 `Is this your handbag?` 与 `Excuse me.` 两个已接触的完整表达。正确项复用教材第 3 话轮 Source ID，干扰项复用第 1 话轮 Source ID；再次显示或点听 `Excuse me.` 不新增、覆盖或改判 M02 中待提交的 T2 结果。只有把完整问句正式送入对话槽才按 T4 结算。
- T4 首次误选 `Excuse me.` 后，人物再次回应、已完成话轮印记和物品关系动作都属于纠错支架；之后选中完整问句必须记录为 T4 受支持完成。伙伴示范问句后由孩子在变化人物与手提包位置中完成时记录 T4 伙伴救援。重复的 `Excuse me.` 和 `Yes?` 只复用来源接触，不生成新的 T2 或独立目标结果。
- 正式提交问句后，第 3 话轮必须由原询问者角色播放到真实 `ended`，才能把第 1–3 话轮声音接触、T2、T4 和 M02 完成一起保存。M02 的“回声线索”只承接节奏，不形成来源或证据；第 4 话轮 `Pardon?` 仍未接触，必须等待孩子主动开始 M03。
- `L01-M03` 中，孩子为教材女性角色正式选择 `Pardon?` 的动作形成 T3 目标尝试结果；小猫发现交流停住、请孩子帮忙判断的动作只是 Content ID 支架，本身不构成 T3 检索或教材来源接触。
- M03 的 T3 首次挑战只在 `Pardon?` 与 `Thank you very much.` 两个已经完整听过的表达间选择。两张表达牌都可以免费点听，但点听只形成相应来源的再次声音接触，不提交答案、不消耗冒险心，也不形成任何目标尝试结果；只有正式选择才按 T3 的声明式答案规则结算。
- `Thank you very much.` 在 M03 只是用于区分“请求重说”和“收到物品后感谢”的情境干扰项；它的显示或点听不得生成、覆盖或改判 T5。`Excuse me.` 与 `Pardon?` 的相近功能辨析等待三个表达分别完成首次教学后进入变化情境回访，不能把首次 T3 挑战升级成细微功能考试。
- 正式误选感谢语后，女性角色说出该表达并产生“男性以为交流结束、手提包仍未解决”的情境后果；这记录 T3 已使用支架，并可在音频真实结束后记录感谢语来源的再次声音接触，但不得生成 T5 尝试结果。两至三秒的感谢用途对照同样只是支架接触，不是 T5 检索。
- 完整纠错示范使用另一位角色和变化小情境时，示范动作形成产品支架接触，不形成教材第 4 话轮的 Source ID 接触。孩子返回原场景后仍须亲手选择；第一次错误后的正确记录 T3 受支持完成，完整示范后的完成记录 T3 伙伴救援，两者都不形成独立调用证据。
- 女性角色以原身份说完第 4 话轮并发出真实 `ended`，才记录该话轮的声音接触；随后原男性询问者说完第 5 话轮并发出真实 `ended`，才记录这个独立 Source ID 的声音接触。孩子的选择结果、两个话轮的来源接触和 Note 的语义接触是可关联但不可互相冒充的事实。
- 第 5 话轮结束后，由教材女性角色播放第 6 话轮 `Yes, it is.`；真实 `ended` 才记录该 Source ID 的声音接触并开放归还动作。孩子把手提包交到她手中记录为必做语义行动和故事结果，不新增 T4 目标尝试结果、不重新分配冒险心，也不形成独立调用证据；T4 的主动检索已经由 M01、M02 分别承担。
- M03 的完成事件只能在 T3 结果、第 4–6 话轮必需接触与归还动作全部成立后原子保存。来源接触、T3 尝试、T4 语义行动和微任务完成仍是四类可关联但不能互相替代的事实。
- M04 开始后，教材女性角色以原身份说完第 7 话轮 `Thank you very much.` 并发出真实 `ended`，才记录这次按原顺序、原角色的声音接触；该接触不自动形成 T5 尝试结果。随后小猫归还孩子原本遗失的固定“星灯探险徽章”，孩子作为接收者主动调用感谢表达，才按 M04 的声明式规则形成 T5。徽章没有英文名称或音频，不产生教材来源接触、词汇目标或目标尝试结果。
- 教材第 7 话轮接触与孩子的 T5 迁移结果必须分别记录：前者证明来源呈现，后者证明当前交际用途中的主动选择或组织。两者文字相同也不能互相替代，孩子在迁移情境中的表达不能改记成教材女性角色的话轮，女性原声也不能替孩子生成 T5。
- M04 的 T5 首次挑战只在 `Thank you very much.` 与 `Pardon?` 两个已经学过的完整表达间选择。两张表达牌可免费点听，但点听只形成相应来源或产品示范的再次声音接触，不提交答案、不消耗冒险心，也不形成 T3 或 T5 尝试；只有把表达正式送入孩子的说话槽才按 T5 的声明式答案规则结算。
- `Pardon?` 在 M04 是用于区分“收到物品后感谢”和“没有听清时请求重说”的情境干扰项；显示、点听、误选或未选择都不得新增、覆盖或改判 T3。T5 的触控成功、受支持完成或伙伴救援只描述交际意图选择，不升级为发音、口语流利或跨日独立证据。
- 正式误选 `Pardon?` 后，回声波纹和小猫重复归还动作记录 T5 已进入支架；`Pardon?` 的来源或产品声音接触与 T5 错误后果分别记录，任何一项都不形成 T3 尝试。两至三秒的用途对照同样只是支架接触，不是第二道目标题。
- 完整纠错示范由另一位小探险者在变化的失物归还情境中使用感谢表达，形成产品支架接触而非教材第 7 话轮接触。孩子回到自己的情境后仍须亲手选择；第一次错误后的正确记录 T5 受支持完成，完整示范后的完成记录 T5 伙伴救援，两者都不形成跨日独立证据或口语成绩。
- 因已接受 ADR 而明确省略的教材来源仍保留 Source ID、处置与理由，但不属于“必学来源”，不要求儿童接触或取证，也不能伪装成已经获得 `exposureRefs` 或 `evidenceRefs`。
- Catalog 需要分别表达来源接触、接触方式、形成性检索和独立证据政策；一次活动可以映射多个来源与目标。
- 所有 `target` 都必须有主动检索和纠正机会；只有列为核心的目标要求跨学习日、变化情境的无支架证据并参与地标最终落成。
