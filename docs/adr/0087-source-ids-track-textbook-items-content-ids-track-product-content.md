# Source ID 标识教材来源，Content ID 标识产品课程内容

> Lesson 1–2 范围说明（2026-08-23）：Source ID 与 Content ID 分离的原则继续有效；下文旧 M01–M07、徽章、钥匙与全量首课词汇映射仅保留为历史。当前 NCE-U01 已有 catalog-owned Content ID，当前任务映射见 ADR-0091、ADR-0095、ADR-0100、ADR-0102 与实施验收包。

Source ID 按真实教材来源项建立，而不按微任务、页面或渲染次数建立：一个教材话轮、一个词汇条目、一条 Note 或一种教材练习机制各有稳定身份，同一来源项在首次学习、故事册、音频和回访中再次呈现时始终复用原 Source ID。教材中两个有独立说话者位置和顺序的话轮即使英文相同，也仍是两个来源项。产品原创的中文任务提示、故事情境、声明式答案和纠错支架使用独立 Content ID，并通过引用关系说明它服务的 Source ID 或学习目标，不能进入教材来源命名空间。

## Considered Options

- 教材来源项使用 Source ID，产品原创教学内容使用 Content ID：既能审计教材覆盖，也能追踪产品设计，因此采用。
- 每个微任务合并成一个 Source ID：结构简单，但无法判断七句课文、词表与 Notes 是否逐项获得真实接触。
- 按英文字符串去重 Source ID：看似精简，但会把教材中承担不同交际作用的两个真实话轮错误合并，无法审计交流修复链是否完整。
- 同一教材来源项每次渲染都生成新 Source ID：能够记录出现次数，但会把故事册、重播和回访伪装成多个教材来源，并破坏跨任务追踪。

## Consequences

- Lesson 1 的七句对话、每个词汇条目、两条 Notes 和教材问题分别拥有稳定 Source ID；Lesson 2 的十个物品条目与教材练习机制同样逐项建模。具体编号在 Source ID 表中冻结，不由页面位置决定。
- Lesson 1 第三、第五话轮虽然都是 `Is this your handbag?`，仍分别拥有 Source ID：前者是初次询问，后者是响应 `Pardon?` 后的再次询问。两者共同引用 T4 和同一表达结构，但 catalog 必须能分别证明两个话轮按顺序接触；各自在故事册、重播或回访中再次出现时复用自己的 Source ID。
- Lesson 1 的教材理解问题作为一个完整的 `context` Source ID 建模，不按 `Whose` 等题内单词拆分；首听前的极短中文任务使用独立 Content ID 并引用该问题。孩子判断物主形成理解任务轨迹，但不产生 `Whose` 的词汇或口语掌握证据。
- Lesson 2 抄写区重复的七句文字继续引用 Lesson 1 对话 Source ID；练习机制本身使用 `L02-E01`，并依据 ADR-0098 标记为纸笔或平板手写可选拓展。它保留在来源审计中，但不进入儿童必做主线，也不要求接触或取证。
- 教材中文译文作为 `context` 来源拥有自己的稳定 Source ID，并关联对应英文来源；产品原创的极短中文任务提示使用 Content ID，不能复用译文 Source ID。
- 产品原创提示、故事道具、支架步骤、声明式答案与反馈使用 Content ID；它们可以在多个微任务中复用，也可以引用多个教材来源或学习目标。
- `L01-M02` 中 `Excuse me.` 与 `Thank you very much.` 两张表达牌继续引用各自已有 Source ID；黄铜表达牌外观、人物背对孩子的任务情境、选项关系和提交规则使用 Content ID。把教材表达当作干扰项不会创建新的 Source ID，也不会自动把它关联的 T5 记为已检索。
- `L01-M02` 的第二次选择中，`Is this your handbag?` 引用教材第 3 话轮 Source ID，`Excuse me.` 继续引用第 1 话轮 Source ID；“问问是不是她的”、小猫指向手提包与人物的动作、两项选项关系及提交规则使用 Content ID。教材第 5 话轮虽然文字相同，却属于 M03 的再次询问，不能在这里替代第 3 话轮的来源覆盖。
- T4 纠错中再次播放的 `Excuse me.`、`Yes?` 与 `Is this your handbag?` 分别继续复用第 1、2、3 话轮 Source ID；已完成话轮印记、手提包—问号—人物动作、另一人物的示范和换位近迁移使用 Content ID。支架重放不会创造新的教材话轮，也不能借重复次数补齐第 5 话轮。
- M02 结算只确认教材第 1–3 话轮；完整问句纸条归档和“回声线索”使用 Content ID。第 4 话轮 `Pardon?` 在孩子点按线索并进入 M03 前不得创建接触记录，第 5 话轮即使文字与第 3 话轮相同也仍保持未覆盖。
- M03 保持教材说话者身份：女性角色拥有并以自己的角色声线说出第 4 话轮 `Pardon?`，原男性询问者拥有并说出第 5 话轮 `Is this your handbag?`。两者分别复用各自 Source ID，不能因为孩子替女性角色作出选择就创建“孩子版”或“小猫版”教材来源。
- 女性角色侧耳、小猫发现交流停住、请孩子帮忙判断、声明式选项关系和提交规则都是产品原创 Content ID。孩子的正式选择可以关联第 4 话轮与 T3，但这些产品内容不能改写该 Source ID 的说话者元数据。
- M03 的两张表达牌分别引用教材第 4 话轮 `Pardon?` 与第 7 话轮 `Thank you very much.` 的 Source ID；“她没听清，帮她选一句”、两项选项关系、点听与提交分区及答案规则使用 Content ID。把第 7 话轮作为干扰项再次呈现，不会把它改成 M03 的教材话轮，也不会产生 T5 目标结果。
- M03 误选后的“男性准备离开但手提包仍在”、女性持续侧耳、感谢用途小画面和回到原场景的动作分别使用产品 Content ID；其中播放的教材感谢表达继续引用第 7 话轮 Source ID，但这些产品场景不能改写它在教材中的真实顺序或生成 T5 结果。
- 最终纠错层中，另一位角色使用 `Pardon?` 的变化情境台词与音频使用 Content ID，并引用 T3 与教材第 4 话轮作为教学依据；它不是新的 Source ID，也不登记为教材第 4 话轮接触。只有原教材女性角色在主场景说出的 `Pardon?` 才能完成该教材话轮的来源覆盖。
- M03 的第 6 话轮 `Yes, it is.` 保持教材女性角色及自己的 Source ID；手提包把手亮起、点选手提包后女性双手成为目标、可选拖动、吸附动画和归还完成规则使用 Content ID。儿童操作可以关联 T4 与第 6 话轮的意义，却不能改写来源身份或创建一份新的 T4 目标结果。
- 女性角色抱住手提包、微笑和“感谢线索”使用 Content ID；点按只启动 M04。随后女性原声 `Thank you very much.` 继续引用教材第 7 话轮 Source ID。小猫发现并归还孩子失物、孩子作为接收者的迁移情境、任务提示、答案规则和反馈另用 Content ID，并引用 T5 与第 7 话轮作为教学依据，不能占用或改写教材说话者身份。
- M04 的两张表达牌分别引用教材第 7 话轮 `Thank you very much.` 与第 4 话轮 `Pardon?` 的 Source ID；“收到东西，说一句”、两项选项关系、卡片扬声器、孩子的说话槽、正式提交、位置变化规则和小猫回应使用 Content ID。声明式答案绑定表达或内容身份，不能绑定“左边／右边”或固定数组下标；卡片声音来自学习控制，不登记成孩子角色的语音。
- M04 误选后的回声波纹、小猫重复归还动作、“物品已经收到”观察线索、无文字双场景对照、另一位小探险者示范和返回当前情境都使用 Content ID。变化人物示范中的感谢台词与音频引用 T5 和教材第 7 话轮作为教学依据，但不生成新 Source ID，也不能登记为教材女性角色的第 7 话轮接触。
- M04 归还物固定为孩子原本遗失的“星灯探险徽章”：黄铜星形边、深蓝珐琅面与暖琥珀色边光都属于产品视觉内容，共用稳定 Content ID。徽章不显示或播放英文，不随机替换成钥匙，也不进入教材 Source ID 或词汇表；“已经遗失—已交到孩子手中—重新别回探险手册或肩带”是可恢复的故事状态，不是积分、奖品或地图地标增长。
- M04 保存后出现的案件夹、空印章位、暖光“归档线索”、触控区域与进入 M05 的动作均使用 Content ID。它们只表达故事导航和恢复状态，不生成 Source ID、目标结果、章节完成或第二次 M04 保存；星灯探险徽章保持为已归还物，不能兼任继续按钮。
- M05 四张案件线索的框面、归位顺序、黄铜印章、点击与可选拖放规则、“手提包找到主人”图形结案章、工作灯和整理室开门演出使用 Content ID。线索中再次显示的 `Is this your handbag?`、`Pardon?`、`Thank you very much.` 继续引用已有教材 Source ID，只能记录相应词形的再次接触，不能生成目标尝试、独立证据或补齐缺失的必需音频接触；自动归位也不能冒充孩子完成排序。
- 章节故事册的书本入口、四幕版式、翻页、逐句扬声器、“从头听故事”、“小灯笼”、词语抽屉、说明入口和关闭动作使用 Content ID；七句话、11 项词汇、两条 Notes、逐句译文与教材理解问题全部继续引用各自既有 Source ID，并从 catalog 读取。页面脚本不得复制这些课程内容。孩子实际打开文字、译文或说明以及听完音频时，只记录真实发生的相应可选接触；未打开的内容不能伪造接触，任何故事册操作都不产生目标尝试、独立证据、章节完成或地标增长。
- 章节停靠场景的整理室门、故事册、冒险地图、货架与月亮图标、“继续整理室”“先休息”标签、短中文提问、小猫中性手势、触控关系和语义化名称使用 Content ID 或运行时共享界面词典，不能创建教材 Source ID。小猫的首次提示只说明去留选择，不是语言教学音频、答案或完成门禁；恢复时不自动重播，孩子可点小猫再次听取同一提示。
- `L02-M01` 中 `pen`、`pencil`、`book`、`watch` 的英文词形与美式词音分别引用教材既有 Source ID；黄铜行李车、四只布袋、教材顺序编排、钢笔笔尖、铅笔石墨线、翻页、表针动作、黄铜标签、点按与开放下一件的规则使用 Content ID。教材顺序、词形、音频引用和四项来源映射必须从 catalog 提供，页面脚本只能渲染状态与转发动作。
- `L02-M01` 后半段的声音目标顺序 `book → pen → watch → pencil`、四项稳定答案身份、当前批次完整选项集、物品语义动作、对应货架位和四项结果键都由 catalog 的 Content ID／目标引用关系声明；探索顺序与检索顺序是两组不同配置。页面脚本只能按声明重排和渲染，不能自行写死英文、靠当前位置判定答案、答对后删除选项，或把最终统一上架冒充新的目标结果。
- Catalog 还必须为 M01 的每个声音目标声明纠错计划：最易混淆的对照物品、两件物品各自的无文字辨认动作、变化外观的同类示范物以及三层结果映射都使用 Content ID，并引用当前目标与 Source ID。页面脚本只能执行通用的“重播—两项聚焦—变化物品示范”协议，不能临时猜测混淆项、把示范物建成新教材来源、提前显示词形，或把支架后的正确上报为无支架结果。
- `L02-M02` 的词形目标顺序 `handbag → watch → pencil → book → pen`、五项稳定答案身份、完整候选集、每轮布局、标签扣合反馈、反馈词音、登记盘与最终装标关系都由 catalog 声明。五个英文标签和词音继续引用各自既有 Source ID；旧案件档案模型、统一模型载体、排布和反馈动作使用 Content ID。页面脚本不能复制文字、在提交前播放词音、把 `handbag` 档案模型当成真实道具回归故事，或让已答对标签继续贴在候选上泄露答案。
- Catalog 必须为 M02 每个词形目标声明最易混淆模型、可标出的辨识片段、错误标签对照、变化外观示范物和三层结果映射；辨识片段是产品教学注释，不能由页面脚本临时切字符串或当成新的 Source ID。纠错计划还要声明可能被提前展示的其他目标，运行时据此记录同任务近距预提示并降级其后续证据，不能让页面只返回最终正确物品 ID。
- M02 第一场交流的固定物品 `watch`、两张 T2 表达牌、单槽句框、四张可插入物品标签、角色顺序、纸条与人物音频、声明式答案、归还动作和认领单都必须由 catalog 声明。`Excuse me.`、`Yes?`、`Yes, it is.`、`Thank you very much.` 的教材文字继续引用既有 Source ID；新认领者的产品角色与声线表现使用 Content ID。`Is this your watch?` 是由教材问句结构与 `watch` 词汇生成的产品变化表达，使用 Content ID 并引用相应 Source ID，不能伪造一条新的教材话轮。页面脚本不得写死 `watch`、句框或音频顺序。
- Catalog 还必须声明 M02 交流的两套三级纠错：感谢语误用后的离开动作、用途对照与旁窗叫人示范，以及四个可组问句、物品不匹配动作、关系线和旁窗单槽示范。`Is this your pen?`、`Is this your pencil?`、`Is this your book?`、`Is this your watch?` 都是带稳定 Content ID 的产品变化表达，并分别引用问句结构和物品词 Source ID；页面脚本不得运行时拼接英文或把错误问句升级成教材来源。人物无词回应不能暗中加入未教学的 `No`。
- M02 保存后的三格认领轨道、第一张图形认领单、夹入动作、衣柜轻晃、非语言衣料声、黄铜衣架线索、可操作区域和进入 M03 的关系均使用 catalog 声明的 Content ID；它们不创建 Source ID、语言接触、目标结果、第二次保存或地标成长。页面脚本不能用固定计时自动打开衣柜、临时加入 `coat` 音频，或把恢复后的线索点按重新解释为 M02 答案。
- Catalog 必须声明 `L02-M03` 的探索顺序 `coat → dress → skirt → shirt`、声音目标顺序 `shirt → coat → dress → skirt`、四件稳定衣物身份、每轮完整候选集、衣罩与衣签关系、无语言辨认动作、中央裁缝木人台、无答案含义的巡检灯、重新排布与最终共同归位。四个英文词形和美式词音继续引用各自教材 Source ID，其余场景、动作和顺序关系使用 Content ID；页面脚本不得复制单词、按位置判定、答对后删除衣物、用衣物轮廓或颜色暗示答案，或把探索衣签与最终归位写成词形结果。
- Catalog 还必须为 M03 每个声音目标声明三级纠错计划、V0 默认对照 `shirt ↔ skirt` 与 `coat ↔ dress`、上身／下身和外层／一件式无文字动作、变化颜色与版型的同类示范物、只重播当前目标的音频规则，以及受支持／伙伴救援结果映射。对照物、动作、线轴波纹、侧柜和示范物使用 Content ID，词音继续引用当前教材 Source ID；页面脚本不得播放对照词、显示词形或中文、临时换配对，或遗漏未来支架暴露对照词音／词形时的跨目标近距预提示。
- M03 保存后的衣签登记册、衣柜抽屉、黄铜封扣、亮起状态、可操作区域、第二位归还者延后入场和进入 M04 的关系均由 catalog 声明为 Content ID；它们不创建 Source ID、词形接触、目标结果、第二张认领记录、第二次保存或地标成长。页面脚本不得把教材单词写到封面、自动播放第一条词音、按计时打开登记册，或在恢复时自动启动 M04。
- Catalog 必须声明 `L02-M04` 的词形顺序 `skirt → coat → dress → shirt`、四件稳定衣物身份、每轮完整候选集、织物标签与衣物关系、先点后点和可选拖放动作、反馈词音、无配对信息的密封页缝线、重新排布、登记完成页和第二位归还者延后入场。英文标签与词音继续引用各自教材 Source ID，其余交互和场景内容使用 Content ID；页面脚本不得复制单词、提交前播放词音、按位置判定、答对后移除衣物、保留已配对答案，或把拖动表现写成学习证据。
