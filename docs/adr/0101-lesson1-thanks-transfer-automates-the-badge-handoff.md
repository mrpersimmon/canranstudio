# Lesson 1 感谢迁移自动完成徽章交还

> 2026-08-23：本决定已由 ADR-0102 取代。独立 `L01-M04` 及徽章交还情节整体删除。

`L01-M04` 保留“从听懂教材女性角色的 `Thank you very much.`，迁移到孩子作为物品接收者选择感谢表达”的 T5 学习目标，但取消“先点徽章、再点探险小猫”的独立 `perform-action`。教材第七话轮真实播放结束后，场景自动切换为招领员把星灯探险徽章呈给探险小猫；徽章与小猫都是故事角色和视觉结果，不是答案控件。孩子唯一需要完成的正式语义行动，是回答“招领员把徽章还给你，应该怎么说？”。

探险小猫是孩子在故事中的唯一化身，进入该迁移场景时必须与招领员形成清晰的双角色构图，并使用足够大的主角尺度，不得缩在成人脚边或远离任务中心。徽章自动进入呈现动画，正确选择后由课程既有真实音频和 `ended` 门禁完成反馈；这里不增加第二次领取确认、继续按钮、奖励结算或地标增长。

本决定细化 ADR-0083、ADR-0087 与 ADR-0091：教材说话者、Source ID、T5 证据和徽章故事状态不变；只移除不产生语言学习或故事分支的接收点击，并明确由招领员向孩子化身完成自动交还。

## Consequences

- catalog 继续唯一声明阶段文案、角色、徽章、视觉时刻、答案规则和目标结果；页面只负责通用渲染。
- `L01-M04` 从三个步骤缩为两个步骤：教材感谢音频，以及徽章已呈现时的感谢表达选择。
- 中断仍从 `L01-M04` 开头恢复；只有感谢表达正确且反馈音频真实结束后，才原子保存徽章已归还和感谢线索。
- 徽章和探险小猫不具有选择、拖动、接收或确认按钮语义；自动动画不会形成独立学习证据。
