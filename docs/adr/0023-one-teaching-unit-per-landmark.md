# 一个教学单元对应一个地标

教材把奇数情境课与紧随其后的偶数操练课组织为一个教学单元，冒险地图因此改为一座教学地标承载一个完整教学单元：奇数课是建立故事与理解的情境任务，偶数课是在同一地点继续主动回忆、操练和迁移的第二段任务。城区仍按连续十二个教材课次划分，但只设置六座主要教学地标；原有教材课次直达地址可以保留，不能再把同一单元拆成两座互不连续的建筑。本决策取代 ADR-0004 的“一课一地标”粒度，重新确认 ADR-0001 与 ADR-0003 的教学结构，但不决定每张路线册页应放置几座教学地标，该布局另行讨论。

## Considered Options

- 每课一座独立地标：保留现有地图与美术投入，但把教材本来连续的输入和操练拆开，也让完成课次被误认为形成长期能力。
- 同一单元使用两座相邻地标：能够保留每课的建筑主题，却仍增加地图密度，并要求孩子理解两座建筑为什么共同代表一次学习闭环。
- 一个教学单元对应一个地标、内部两个连续任务：减少地图拥挤，保持教材结构，并允许同一场景从理解自然推进到独立使用。

## Consequences

- 每个城区从十二座教学地标收敛为六座，但仍覆盖原有连续十二个教材课次。
- 地标名称、建筑主题、成长状态和纪念物都必须表达整个教学单元，不能只取奇数课或偶数课的局部内容。
- 现有一课一地标地图、铭牌、进度和课程入口需要设计迁移方案；在方案确认前不把旧页面机械拼接成新地标。
- 路线册页数量与每页地标数仍是开放决策，不能从现有四地标册页或早期三地标册页自动继承。
