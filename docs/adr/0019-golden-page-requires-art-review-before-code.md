# 黄金册页先通过高保真美术审查再进入代码

Lesson 49-52 黄金册页采用独立美术审批门。第一轮先审查整张册页的背景构图、四地标空间关系、连续路线、铭牌位置、当前地标高亮，以及 A+ 加载角色的完整姿态分镜；在这些视觉方向得到明确确认前，不生成全部成长状态，也不把新版册页接入生产网页。

首轮审查稿保存在 `docs/designs/adventure-map/golden-route-page-49-52/`。地图稿中的建筑是基于现有正式地标参考重新绘制的构图占位，不替代现有逐阶段母版；正式实现继续使用经过单课状态审查的完整地标图片，中文名称和进度由网页渲染。加载角色分镜用于锁定角色身份、造型、动作节拍和城区装扮，后续各姿态必须从同一角色锚点定向编辑，不得把联系表直接切开当成生产帧。
