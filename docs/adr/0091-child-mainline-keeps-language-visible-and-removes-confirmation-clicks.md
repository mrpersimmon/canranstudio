# 儿童主线同步显示语言并只保留有意义动作

Lesson 1–2 面向六至八岁儿童的独立主线决定让每段语言音频持续显示对应单词或句子，并让答案选择本身直接提交；因此物品词的主线声音结果明确记为 `audio-form-supported` 形成性检索，而不是纯听力证据，纯听力独立证明只可由后续明确隐藏词形的回访任务产生。已经从稳定账本取得的案件线索和认领记录进入结算场景时自动呈现，孩子只保留一次真正改变故事的盖章或开闸动作；运行时仍先校验全部前置事实，完整微任务、章节停靠点、单元原子保存、真实 `audio/ended` 与完成整幕后才增长地标的边界不变。本决策取代 ADR-0032、ADR-0041、ADR-0042、ADR-0079 与 ADR-0084 中要求主线听音时隐藏词形、强制再次收标签或让孩子逐枚点亮已获得成果的冲突条款。

同一原则也适用于故事动作与角色构图：回答“这是谁的手提包”只直接选择主人，手提包保持在柜台并写入 `handbag-owner-identified`；真正的手提包交还只在交流修复完成后的 `L01-M03` 发生一次。探险小猫不再被通用场景渲染器无条件加入每个任务；它只在 catalog 明确把孩子角色带入当前步骤、伙伴救援反馈或章节／单元奖励时出现，并使用足够大的功能性构图。页面仍只解释通用的 `select-entity`、角色出场与奖励呈现，课程专属人物、答案、文案和事实继续由 catalog 唯一拥有。
