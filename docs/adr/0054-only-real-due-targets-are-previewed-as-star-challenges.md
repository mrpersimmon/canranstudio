# 只预告真实到期目标且不制造每日得星任务

> 范围说明（2026-08-24）：ADR-0110 允许 Lesson 1–2 成果后显示不带星级、奖励或到期含义的同日隔离练习入口；它不能显示为星级委托、制造目标到期或因反复进入而产出挑战星，本 ADR 的其余规则继续有效。

故事化回访开始前，系统只按当前真实进入自适应回访窗口的目标显示“今天有 N 项星级委托”，其中 N 为一至三的实际数量，不展示固定三个空星槽。当天没有任何目标到期时，角色简短说明旧本领目前很稳，系统不把尚未到期目标提前、不追加容易题，也不允许新课产生挑战星，而是直接开始或继续新冒险。每日三颗是产出上限，不是孩子必须填满的配额。

## Considered Options

- 只预告真实到期数量，无到期时直接进入新冒险：保持学习调度与奖励含义一致，因此采用。
- 每天固定展示三个星槽并尽量补足题目：目标显眼，但会把上限变成配额，并诱导系统为奖励而制造练习。
- 完全不预告挑战数量：避免压力，却降低任务目标的可理解性，也让得星显得更随机。

## Consequences

- 一至三个目标到期时，预告显示实际委托数；孩子知道本次有多少真实挑战，但不会看见未获得的固定空位。
- 自适应间隔可以使用已经定义的回访窗口；窗口内目标属于真实到期，窗口之外的目标不能仅为保证每日得星而提前。
- 没有到期目标时不进入零任务结算，也不显示“今天无法得星”；角色用正面事实说明记忆稳定后直接进入新冒险。
- 单元完成当天的成果庭院不把星灯信箱点亮为固定“复习领奖”入口。后续新学习会话中，信箱只在一至三个真实目标到期时按实际委托数呈现；没有到期目标时保持安静，不显示空星位、倒计时、欠题或“还不能得星”，也不因孩子反复进入成果庭院提前制造简单题。
- 新课当天继续通过角色帮助、场景变化和地标建设形成即时激励，但不能替代间隔回忆产生挑战星。
- 每日上限不能被解释为每日保底、待办清单或连续签到目标，未使用的数量没有补发和追赶机制。
- 挑战星总数、城区进度与回访结算退出方式由 ADR-0055 的分层可见性和自主驻留结算规则决定。
