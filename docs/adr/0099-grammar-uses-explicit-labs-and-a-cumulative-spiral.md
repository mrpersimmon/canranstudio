# 语法采用显性实验室与累计式螺旋

小学新概念英语课程先用人物、物品、动作和完整表达建立意义，再在教材首次引入或实质扩展一个语法结构时，安排儿童可见的“星灯语法实验室”显性命名规律；之后通过变化练习、对比分类、阶段整合反复调用。显性讲解不等于成人化讲义：可以介绍 `be` 动词、一般疑问句、肯定简短回答、代词 `it` 等必要学校术语，但不把术语背诵当作本单元成绩，也不要求书面练习。普通巩固继续留在故事行动中，每完成六个教学单元的一个城区，再进行一次累计语法整合。

## Considered Options

- 只在故事中隐性模仿句型：界面最轻，但孩子难以形成可迁移、可累积的结构认识。
- 每个单元都安排固定语法讲义与术语测试：显性度最高，却容易把小学课程抬成脱离意义的中学语法考试。
- 先意义、再显性命名，并以累计式螺旋反复整合：兼顾儿童理解、学校体系衔接与后续迁移，因此采用。

## Consequences

- 课程的语法进程固定为“首次遇见 → 显性规则 → 变化练习 → 对比分类 → 阶段整合”，但这些功能不要求每个单元显示成相同页面。
- 一个教学单元首次引入或实质扩展语法时，必须有可见的星灯语法实验室；只做普通巩固时，语法继续嵌入故事，不重复整页讲解。
- 语法实验室属于当前奇偶 Lesson 教学单元内部，不增加第三个教材章节，也不改变一个教学单元对应一个地标的规则。
- 术语只能在孩子已经通过例句和动作理解意义后出现；当单元的核心能力是组装、连接、选择、找错或迁移时，不得用术语默写代替这些能力证据。
- Lesson 1–2 的星灯语法实验室位于 Lesson 2 开头，共三个微任务：比较陈述与问句、把 `it` 连回物品、在变化物品上独立组装并找错。前两项为自由教学尝试，第三项才正式结算。
- Lesson 1–2 介绍 `be` 动词、一般疑问句、肯定简短回答、代词 `it`，并说明 `your` 是“你的”；本单元不要求孩子背诵“形容词性物主代词”这个分类名。
- 设计 Lesson 3–4 前，课程团队必须先读完整册教材并建立全册语法主干地图，记录每个结构的首次出现、显性教学、对比整合和回访位置，避免逐课临时堆叠。
