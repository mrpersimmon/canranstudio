# 课程音频默认使用可替换的美式英语语音包

外研社官方目录把《新概念英语智慧版》标为英式英语，但本儿童课程决定使用清晰、自然、角色可区分的美式英语预录音作为发布默认，并允许用经过内容和音质审核的真人老师课程语音包替换，而不改动教材文字、学习任务或证据合同。第一轮选型先从 catalog 导出同一组 Lesson 1 台词，用 Kokoro 的两条美式声线和 MeloTTS `EN-US` 在本地零 API 费用生成匿名 WAV；任何声线都只有在课程内容、美式发音、技术完整性和许可门禁全部通过后，才可能成为默认包。若本地候选均不合格，再比较 Google Cloud TTS 免费额度或仍符合资格的 Amazon Polly 免费层。教材配套英式音频只作为正版学习资源和课程核对来源，未取得书面产品授权前不复制、嵌入或随网站发布。

## Considered Options

- 美式英语默认包加可替换真人老师语音包：既形成一致的儿童输入，又保留后续专业录音与本地化能力，因此采用；先执行本地免费 AI 声线盲听，胜出者仍须通过完整发布门禁，不能把“免费”直接当作采用理由。
- 永久绑定一套录音：制作与验证最简单，但更换老师、修正发音或升级录音时会牵动课程内容。
- AI 生成并经人工审核的默认包：制作和修订效率高，但必须通过口音、角色连续性、节奏、文本准确性和儿童可懂度验收，并明确披露 AI 生成。
- 真人录制默认包：表演控制和身份归属更直观，但需要录音排期、完整授权和版本修订流程。
- 直接把教材配套音频作为产品默认资产：最接近教材录音，但个人正版访问资格不等于网络产品的复制和再分发授权。

## Consequences

- 每条完整台词和每个独立词项分别录制，不用逐词拼接合成长句；同一角色在一个语音包中保持口音、音色、语速和表演连续。完整台词以约 95–115 词/分钟的自然美式英语为目标，保留正常重音、连读和语调，不采用逐词蹦读；每条都可完整重播。
- V1 由课程制作或维护人员离线导入已经通过审核的完整语音包，不向老师、家长或孩子开放产品内自助上传、公开分享或自由替换入口。
- 一个教学单元是语音包允许替换的最小完整作用域。该单元两篇连续 Lesson 的全部英文角色台词、独立词音和英文提示必须与 catalog 标识一一对应；缺少或未通过验收的任意必需文件都会阻止整个单元切换，儿童端继续使用该单元原有的完整语音包。不能逐句混用两个语音包，也不能让同一教学单元中途更换口音、音色或表演风格。
- 本地候选包尚未发布时，逐条人工听测可以否决并修复错误文件；修复后的完整 manifest 仍作为一个新候选包整体验收，必须记录被否决文件哈希、替换引擎、声线与美式 locale，并由自动检查阻止旧错误字节回归。这种候选期修复不等于允许线上逐句切换语音包，也不解除正式发布前的整单元零缺口审核。
- 衣物词与随后钥匙章节连续暴露 Kokoro 候选发音问题后，本地验收包不再继续按章节补洞：`NCE-U01` 的全部 32 条语言音频统一重建为 macOS `en-US` 候选，男性教材话轮与产品问句固定使用 Reed，女性教材话轮与独立词音固定使用 Samantha。该系统声线只用于隐藏本地体验的快速人工验收，不解决正式产品的输出授权与专业语言审听，不能因自动门禁通过而进入发布。
- 每个教学单元在任一发布版本中只有一个正式启用的完整语音包。通过验收的 AI 包可以作为初始默认；真人老师的整单元语音包通过相同三层验收与授权检查后，在教学单元边界统一替换它。旧包只作为版本回滚资产保留，不在儿童端或家长设置中提供 AI、真人或声线选择，也不让已经开始的单元中途换包。
- 真人老师录音进入产品前必须确认录音者授权、可使用范围和后续版本处理方式，不能把“老师愿意录”自动视为已取得产品授权。
- AI 生成音频通过正式验收后可以成为发布语音包，但必须标明为 AI 生成，不能冒充真人老师或教材官方录音；运行时不临时合成课程台词。
- 免费选型顺序固定为 Kokoro 两条美式声线与 MeloTTS `EN-US` 的本地匿名盲听；本地候选不合格时才转向 Google Cloud TTS 或 Amazon Polly 的适用免费额度。云服务额度、结算和输出条款必须在实际生成日重新核对。
- 最终声线采用两阶段盲测。课程编辑与通用美式英语审核者先淘汰内容、发音、节奏或教学适宜性不合格的候选；再让目标年龄儿童在相同的 Lesson 1 微场景中体验仍然合格的匿名声线，以任务理解为第一观察项，以愿意继续听和明显不适为辅助观察项。儿童偏好不能推翻语言准确性门禁；体验不采集儿童声音、姓名或正式学习证据，并须按适龄测试与监护边界组织。
- 发布验收由三层共同完成，并采用零缺口门禁：必需 Source ID、角色和文件必须 100% 对应；课程编辑核对全部教材原文与交际位置；熟悉通用美式英语的审核者逐条判断发音、重音、连读、语速和教学适宜性；系统检查全部文件的映射、格式、响度、噪声、哈希，并验证每条都能完整播放到真实 `ended`。已知文本或发音错误、削波、明显合成异常和缺失文件必须为零；任意一条失败都会阻止整个教学单元发布，不能用平均分、抽检或“稍后修复”绕过。三层任何一层都不能代替另外两层。
- 教材正版激活、个人账户播放和产品内再分发是不同权利边界；如要使用教材官方音频，必须另行取得权利方明确授权。
- 本培训体系只提供美式英语课程语音包，不设计英式教材原声音轨或儿童端口音切换。教材配套英式音频即使未来获得产品授权，在当前体系中也只作为课程核对或外部正版资源；改变这一边界需要新的明确决定。
