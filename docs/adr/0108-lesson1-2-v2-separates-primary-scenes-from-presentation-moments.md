# Lesson 1–2 V2 分离主场景构型、场景呈现段与成果停靠

> 范围说明（2026-08-24）：ADR-0110 只扩展本 ADR 中成果／停靠“只提供继续与休息”的动作集合，允许出现视觉上次要、可跳过的隔离练习入口；`outcome-rest` 不拥有主线挑战、结果、冒险心、进度或恢复微任务的其余边界继续有效。

## Context

M13–M17 已选择双人同框对话舞台、真实物品操作面、原场景变形语法实验室、连续变形街景窗和保留真实故事结果的成果／停靠场景。如果把这五类都作为微任务 `sceneMode`，章节停靠、知识卡和最终演出就会被误算为第十七个任务；如果只保留一个含混的 `visualMoment`，页面又只能按 Microtask ID、步骤字符串或本地条件猜测人物、道具与布局转折。运行时已有的 `phase` 还负责 `audio-playing`、`awaiting-response`、保存等生命周期，不能再承担视觉分镜含义。

## Decision

- 十六个恢复微任务各自声明一个稳定的 `presentation.sceneMode`，只允许 `dialogue-stage`、`object-workbench`、`grammar-lab`、`route-investigation` 四类主构型。主构型表示从微任务开头恢复时承载主要正式行动的空间关系，不是学习功能、页面类型或儿童关卡。
- Catalog 同时声明稳定的 `sceneVariant` 和有序 `presentation.moments[]`。每个场景呈现段拥有自己的语义 ID、进入条件、参与者、焦点实体、可见语言、状态终点、主动作与减少动态效果终态；运行时快照只暴露当前 `currentPresentationMomentId`，页面不得按 Microtask ID、内部步骤名或课程文案推导构图。
- `participantEntityIds` 表示这一呈现段完整的在场人物，`focusEntityIds` 才表示当前说话、动作或物品焦点。Lesson 1–2 的双人故事关系一旦出现，两名成人在后续有角色呈现段中持续同场；切换焦点不得把其中一人从 DOM 卸载，再在下一段无因重建。纯物品阶段可以声明空参与者让人物整体离场。
- 场景呈现段只表达同一微任务内的视觉与交互状态变化。它不新增结果、冒险心、进度、原子保存、恢复位置或儿童导航项；刷新仍按所属恢复微任务的合同处理。运行时 `phase` 继续只表示音频、作答、支架、重启与保存生命周期。
- `outcome-rest` 是完成后的第五类体验构型，不属于任何活动微任务的允许 `sceneMode`。它只在 `L01-M11` 成功保存后的章节停靠、`L02-M15` 成功保存且知识卡关闭后的段落停靠，以及 `L02-M21` 完整保存与读回后的单元成果中出现。它没有 `challengeRef`、结果格、冒险心、`microtaskStatus` 或进度序号；顶栏分别保持 `5/16`、`10/16`、`16/16`。
- 知识卡是成功后的非计分呈现层，不是新的微任务，也不等于 `outcome-rest`。保存失败时不得进入成果／停靠构型，最终地标也不得提前增长。
- 对话舞台采用双人同框的上下分镜；物品操作台使用托盘、标签册、衣架等真实承接面；语法实验室由原柜台现场展开句块轨道并保留人物与目标物品；路线调查台用同一扇全宽街景窗连续折叠成路线钉；成果／停靠场景保留实际故事结果，只提供等权的继续与休息，最终以路线交付、读回、人物离场和地标成长收束，不出现结算白卡。
- ADR-0111 进一步冻结 Lesson 1 的柜台连续性：`L01-M08`–`L01-M11` 均属同一 `dialogue-stage`；`L01-M10` 虽然展开句块轨道，但只更换任务面板与焦点，不更换背景、人物基准位置或手提包所属场景。

## Consequences

- 十六阶段的主构型、场景呈现段、前后状态、动效与减少动态效果终态记录在 [Lesson 1–2 V2 手机场景 Storyboard](../designs/lesson1-2-v2-mobile-scene-storyboard.md)。
- Catalog 校验必须拒绝活动微任务使用 `outcome-rest`，并校验所有呈现段 ID、触发条件、参与者、焦点实体与终态引用完整。页面与通用渲染器只消费声明式快照。
- Lesson 1–2 的 catalog 与浏览器回归必须锁定“有角色时为完整双人阵容、无角色时为空场”，并在同一微任务焦点切换后直接检查可见人物实体，防止把单人名单重新当成焦点捷径。
- 产品负责人随后已以 Q21-A 接受完整蓝图并授权本地 TDD 修正候选；实现仍必须以同一候选 SHA 的完整门禁证明 `sceneMode`、`sceneVariant` 与有序 `moments[]` 已真正消费，文件存在本身不是完成或发布证明。
- 本决定记录 M13–M17 的产品选择；Q21-A 只授权本地候选实施与验收，不授权合并 `main` 或发布网站。
