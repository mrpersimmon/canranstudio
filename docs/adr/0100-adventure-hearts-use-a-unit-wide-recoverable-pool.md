# 冒险心使用教学单元级全局可恢复池

Lesson 1–2 及后续同类儿童主线使用一个贯穿整个教学单元的三颗冒险心池，不在新题、新目标、微任务或章节之间重置。只有正式语义提交会改变冒险心：答错减少一颗，孩子亲手完成正确答案补回一颗，上限为三颗；免费点听、探索、重播、教学自由拼装、误触以及系统或音频失败都不改变心数。归零后，探险小猫先用变化实例完成第三层示范，再播放一至两秒“星光倒带”，从当前微任务开头重来、补满三颗心并重排选项，不重开章节或教学单元。本决定取代 ADR-0079，以及 ADR-0031、ADR-0040 等旧任务条款中的逐目标重置与首次学习不重开规则；这些文件的匹配纠错和真实音频完成原则继续有效。

## Considered Options

- 每个关键目标重新获得三颗心：孩子几乎感受不到跨任务的关卡压力，并鼓励把一次学习拆成大量独立小题。
- 全单元共享三颗心，归零即失败或退回章节起点：挑战最强，但会惩罚尚在学习的儿童并制造无意义重复。
- 全单元共享、答对可补回，归零后只重启当前短微任务：保留持续挑战、翻盘感与教学安全，因此采用。

## Consequences

- 领域中的正式名称仍是“冒险心”，儿童界面使用三枚心形图标；星形只保留给长期奖励“挑战星”等明确奖励，视觉、无障碍名称和内部语义不得混用。
- 冒险心从进入 Lesson 1 到完成 Lesson 2 持续存在；章节切换、休息后恢复和普通重新进入都保持当前值，只有孩子二次确认“重新开始整个教学单元”才重置为三颗。
- 只有会形成目标尝试结果的正式语义提交可扣心或补心。正确完成即补一颗，即使使用过支架也可补心，但证据仍必须记录为受支持完成或伙伴救援，不能因补心改写为无提示成功。
- 冒险心为零时，当前任务先完成第三层变化实例示范，再执行短倒带、重启当前微任务、补满三颗并重排候选；孩子仍须亲手完成，且该次结果固定保持伙伴救援语义。
- 每个可重启微任务必须控制在三十至九十秒，最多包含两次正式提交，避免归零后重复长对话、长动画或整章内容。
- 冒险心不影响章节完成、单元当日地标建设、长期掌握、挑战星或最终故事结果；儿童端不生成永久“三心成绩”。
- 纠错仍按“情境后果 → 聚焦线索 → 变化实例示范”递进。答对补心是继续冒险的可恢复资源，不是抹除错误历史。
