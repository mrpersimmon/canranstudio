# 每个学习目标每个学习日的首次独立调用产生一颗星

挑战星以学习目标为单位发放。在故事化回访任务中，某个学习目标于当前学习日第一次形成独立调用证据时，系统发放一颗挑战星；证据必须来自无提示、变化情境且与目标相匹配的作答。同一学习目标在同一个学习日最多产生一颗星，无论重复多少题或进入多少次任务。依赖任何纠错支架、已经看过答案或只在首次学习当天完成的反应都不发星；它们仍然可以推动角色反馈、当日建造和后续学习安排。一次回访任务中的不同目标分别判断，因此孩子可以获得其中已经真实赢得的星星，不采用全对或全无规则。

## Considered Options

- 每个学习目标每天首次形成独立调用证据时发一颗：让每颗星对应一次可解释的真实挑战，同时阻止同日重复刷题，因此采用。
- 每答对一道题发一颗：反馈频繁，但题目颗粒、选择题难度和重复次数会直接制造不公平的刷星空间。
- 整段回访任务全部通过才发一颗：规则简单，却会让一个薄弱目标抹掉孩子在其他目标上已经取得的真实成功。

## Consequences

- 一段包含两至三个到期目标的 3–5 分钟回访任务，可以根据独立证据获得零至三颗星，并受 ADR-0051 的每日挑战星上限约束。
- 一个目标的失败不会取消其他目标已经获得的星星，也不会扣除历史星星。
- 使用提示后的成功只触发纠错完成反馈，并把该目标安排到更早的后续学习日；不能通过立即换题把刚看到的答案转成挑战星。
- 新课当天的成功推动角色、场景和地标当日建造，但挑战星保留给跨学习机会后的独立回忆。
- 发星记录需要至少包含学习目标、所属城区、学习日和证据事件，使同一证据重复提交时仍只能增加一次，并能按 ADR-0047 归属城区奖励。
- 星星反馈按 ADR-0052 分成场景结果后的轻量点亮与整段回访结束后的统一结算，不能打断作答或抢在能力反馈之前。
