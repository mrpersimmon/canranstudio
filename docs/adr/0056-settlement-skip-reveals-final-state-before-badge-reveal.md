# 结算先完整呈现最终状态再进入纪念章揭晓

回访结算动画尚未完成时，第一次点击或轻触只将动画立即推进到完整最终状态，不能在同一次操作中关闭；进入最终状态后的下一次点击才继续。如果本次解锁了城区纪念章，继续动作进入一个独立的城区主题揭晓页，孩子再次点击任意位置后将纪念章收入对应城区图鉴并继续冒险；没有新纪念章时则直接继续。星星和纪念章资格在动画之前已经记录，点击只控制展示节奏，不控制是否发奖。

## Considered Options

- 第一次点击跳到最终状态、第二次点击继续：既允许快速跳过动画，又保证完整成果至少可见一次，因此采用。
- 动画期间忽略点击：实现简单，但强迫不想等待的孩子观看完整庆祝。
- 一次点击同时跳过动画并离开：推进最快，却容易因误触让成果页一闪而过。
- 星星结算后单独揭晓新纪念章：让日常挑战与阶段成就各自获得清楚的意义，因此采用。
- 纪念章与星星同时出现或只留图鉴新标记：前者信息竞争，后者削弱阶段收藏的获得感。

## Consequences

- 动画中的点击只能完成当前结算，不能触发继续、纪念章揭晓或课程跳转。
- 最终状态需要明确进入可继续阶段，后续任意位置点击只执行一次导航动作。
- 有新纪念章时，星星结算后的继续目标是纪念章揭晓；无新纪念章时才直接进入当天新冒险。
- 纪念章揭晓使用来源城区的视觉与故事，不使用通用奖牌弹窗；点击任意位置收入图鉴，不显示领取按钮。
- 刷新、退出、快速连续点击和减少动态效果模式都不能造成重复发星、重复授章或跳过持久化。
- 同一城区多章同时解锁与跨城区回访授章按 ADR-0057 使用合并收藏展开和不离开当前旅程的纪念来信。
