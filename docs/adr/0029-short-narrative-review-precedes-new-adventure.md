# 新冒险前先进行短时故事化回访

孩子每次开始一次新的学习会话时，如果存在到期学习目标，系统先选取最需要回访的少量目标，组成不超过 3–5 分钟的故事化热身任务，随后进入或继续当天的新冒险。没有到期目标时直接进入新冒险；到期目标过多时只处理本次时间容量内的部分，其余在后台继续调度。即使孩子在热身中答错，也只进行必要纠错并提前后续回访，不能无限重试或阻止当天的新冒险。

## Considered Options

- 短时故事化回访后进入新冒险：让主动回忆稳定发生，同时控制启动成本，因此采用。
- 清空全部到期目标后才能进入新冒险：复习强度最高，但积压会迅速变成惩罚和流失门槛。
- 让孩子自由选择回访或新冒险：自主感较强，但最需要回忆的内容容易长期被跳过。

## Consequences

- 单次热身以 3–5 分钟为硬上限，系统需要同时限制目标数量、题目数量和失败后的重试次数。
- 调度必须对到期目标排序，但孩子端不能展示欠题数、逾期天数或清空队列的压力。
- 热身失败形成纠错与后续调度信息，不作为禁止新内容的惩罚。
- 新冒险仍然是每次学习会话的主要体验，热身必须拥有角色、事件和明确语言用途，不能退化成题库入口。
- 热身从同一地标到跨城区的目标选择与故事连贯规则由 ADR-0030 的渐进式跨情境回访决定。
