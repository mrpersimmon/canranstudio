# 课程语音移除非语言首尾空档但保留已选声色

孩子真人复听确认：移除界面成功提示音后，独立词音仍有相同的异常前奏听感。浏览器实际资源只包含目标 MP3，没有第二条音效或重叠播放；进一步直接解码发现，Lesson 1–2 的二十一条独立词音都要等待约 380–430 毫秒才出现首个英语起音。因此 `nce-u01-kokoro-candidate-v2` 在完整教学单元范围内移除非语言首尾填充，保留用户已选的 `am_michael` 与 `af_heart` 声色和原语音帧，不重新合成或改换 voice。浏览器解码后的英语起音必须不晚于 150 毫秒，完整英语仍由真实 `ended` 门禁；生成脚本以后对新候选执行同一处理。若真人复听在清理空档后仍拒绝起音或语调，问题应明确升级为同一声色的词音重制，而不能再次归因于界面音效。
