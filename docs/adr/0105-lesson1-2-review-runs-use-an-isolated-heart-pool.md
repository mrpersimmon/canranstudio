# Lesson 1–2 跨日回访使用独立冒险心池

## Context

Lesson 1–2 主线使用贯穿两个章节的可恢复三心池；跨日回访则是可稍后进行、每次只有二至四项和四十五至九十秒的变化情境短轮。若回访读取主线剩余心数，孩子可能第二天一进入就处于一心劣势，回访错误也会污染下一课的首次学习状态；若完全取消冒险心，又会失去已经建立的闯关、翻盘和伙伴救援反馈。

## Decision

- 每个跨日 `reviewRunId` 创建独立三心池，初值与上限均为三；它不读取或写入主线 `adventureHearts`。
- 正式回访答错减少一颗，孩子亲手答对补回一颗；系统、音频失败、免费重听和“稍后再来”都不改变心数。
- 回访归零后，小猫先在变化实例中示范；系统清除该 review run 的临时结果、补满三颗并从短轮第一项重开。主线完成、章节、地标、下一课资格与既有结果均不回退。
- 发生伙伴示范的这一轮只记录 `review-assisted-practice`，不得产生 `independent-retrieval` 或掌握证据，并把相关格安排到下一学习日。只有跨日、变化情境、全程无支架的成功可以形成独立调用证据。
- 回访结束后丢弃临时心数，不带入下一次回访、下一课、挑战星、长期评级或永久三心成绩。

## Consequences

- 主线与回访共享冒险叙事，但拥有不同生命周期；两套心池必须由不同状态键和事件 schema 隔离。
- 回访归零的成本最多是重玩当前四十五至九十秒短轮，不会把尚在学习的孩子送回六至八分钟章节。
- 回访测试必须覆盖主线剩余一心但回访仍从三心开始、回访错误不改变主线、归零清临时证据、辅助重玩不生成独立证据，以及下次回访重新从三心开始。
- 本决定补充 ADR-0100 的主线全单元心池，不改变其主线归零只重启当前微任务的规则。
