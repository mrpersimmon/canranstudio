# 聚合目标仍保留变体级覆盖与回访

多个同类词项可以聚合成一个阻塞地标落成的核心学习目标，但每个词项作为目标变体分别保留声音与词形两个通道的首次检索、延迟独立成功和薄弱状态。Lesson 1–2 因此把 `handbag` 与 Lesson 2 的十个物品词组成一个“物品听辨与认读”核心目标：十一项都必须接触声音、英文词形与物品，并分别完成“听声音找物品”和“看词形找物品”的形成性检索；后续回访再为每个变体的两个通道分别取得无支架正确连接。薄弱的具体词与通道优先提前出现，但十一项仍不拆成十一套地标目标或一次性二十二题。

## Considered Options

- 十一项分别作为核心学习目标并各自发放掌握与奖励：粒度最细，却会把一个词汇族错误扩大为十一套地标门槛。
- 一个核心目标加十一项目标变体，每个变体保留声音与词形两个通道格：完整保留二十二个可解释缺口，同时让地标门槛仍表达一项可理解的词物能力，因此采用。
- 只抽查若干代表词：负担最低，但无法发现未被抽中的具体缺口。

## Consequences

- 一个故事任务或回访短轮可以同时检查多个目标变体，不为每个词建立独立页面。
- `L02-M01` 先按教材顺序让 `pen`、`pencil`、`book`、`watch` 各自获得物品、声音与词形接触，再把四件物品一起放入整理台并打乱；只有这一完整探索结束后才开始四项声音通道检索。声音目标固定按 `book → pen → watch → pencil` 出现，每一次都保留四件物品作为完整选项，并在下一词前用可见短动效重新排布；已经答对的物品不移除，最后一词也不能靠排除得出。四项词形通道检索等待 M02，再接续第一场归属交流。探索点击、物品动作、重听和标签揭示都不构成目标尝试，也不能把第一次见面伪装成冷测验。
- `L02-M02` 用同材质的五个 2.5D 档案模型承载 `handbag` 与本批四件物品，固定按 `handbag → watch → pencil → book → pen` 完成词形通道检索。每轮只给目标英文标签，提交前不播放词音；五个模型始终保留并重新排布，答对标签在反馈后收进中立登记盘，不能留在物品上泄露后续答案。五项全部结算后，四张当前标签才统一装上货架，`handbag` 档案模型回到旧案件夹，再进入第一场归属交流。
- `L02-M03` 先按教材顺序 `coat → dress → skirt → shirt` 完成四件衣物的物品、声音和词形探索接触，再收起所有衣签并按 `shirt → coat → dress → skirt` 进行声音通道检索。每轮完整保留四件衣物并可见地重新排布；答对衣物只到中央木人台完成短动作后返回，不从后续候选移除。只有四份声音结果都成立后才让四件一起归位；四项词形通道继续等待 M04。
- `L02-M04` 按 `skirt → coat → dress → shirt` 完成四件衣物的词形通道检索。每轮只显示当前英文织物标签与完整四件衣物，提交前不播放词音；答对后标签只短暂别到衣物并在反馈词音真实结束后进入无配对信息的中立密封页，衣物返回且重新排布。四项全部结算后才进入第二位归还者交流，词形阶段本身不建立稳定检查点；后续固定 `coat` 交流不能再生成一份 `coat` 词形或声音通道结果。
- Lesson 2 的三个批次都采用“探索与整批听音检索 → 下一微任务整批词形检索与一次交际”：M01/M02 覆盖 `pen`、`pencil`、`book`、`watch`，M03/M04 覆盖四件衣物，M05/M06 覆盖 `car`、`house`。`handbag` 在 L01-M01 取得声音结果，并在 L02-M02 的旧案件标签回看中取得词形结果。
- M05 不能因大型财产批次只有两项就把第二题做成消去后的必然答案：`house → car` 两个声音目标都必须在完整两把钥匙同等可选、重新换位的条件下分别提交并保存结果。微缩影像与最终共同入盒是分组故事反馈，不得把两项压成一个“钥匙批次通过”结果；M06 仍须分别补齐两个词形通道格。
- M06 的 `car → house` 两个词形目标同样必须在完整两把钥匙同等可选、重新换位且提交前无词音的条件下分别结算；首个档案牌完成后不能移除对应钥匙或保留其英文映射。两份词形结果必须等 M06 后续交流一起原子保存，但不能被一条“档案挂牌完成”状态合并或替代。
- Lesson 1–2 的一次四十五至九十秒回访通常选择三至四个到期的“词 × 通道”格，并嵌入一至两个当前到期的交际目标；二十二个格都形成延迟无支架成功理论上至少需要六轮四格回访，真实轮数由支架、错误和学习日安排决定，不能写死或一次堆出。
- 核心目标仍遵守跨至少两个学习日、变化情境和无支架成功规则；每个变体的声音与词形成功都是相对首次教学的延迟检索，同日看到答案后的重复不能填格。调度通常把同一词的两个通道分散到不同回访事件，避免连续重复造成虚假流畅。
- 同一次同时给出声音和词形的复合提示不能被重复计算为两种独立通道；一个通道的成功也不能填补另一个通道。
- 某个听音挑战完成后的词形揭示只补足该变体的词形接触，不把本次听音结果改写成看词认物成功。`handbag` 的首次形成性证据因此仍只有听音通道；词形通道必须在后续变化任务中单独检索。
- 调度需要同时选择到期核心目标和其中优先出现的变体；某个变体在特定通道失败或依赖支架时，应优先在同一通道安排后续回访，而不是用另一通道的成功掩盖缺口。
- 目标变体与通道格不独立发放目标掌握、地标落成或二十二份奖励；但任何格尚未形成延迟无支架成功时，T1 都不能被误判为完整掌握。
- T2–T5 在不同回访短轮中自然轮换；每轮不必重演完整五目标交际链，也不能把到期目标拆成脱离故事的闪卡队列。
