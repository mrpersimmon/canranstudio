# 教材物品使用 catalog 管理的统一透明插画资产

Lesson 1–2 的 emoji 物品与胡桃木、黄铜、深夜蓝的 2.5D 失物招领站画风不一致，也无法保证跨平台形状、色彩与精细度。`handbag` 继续使用已接受的手提包道具；`pen`、`pencil`、`book`、`watch`、`coat`、`dress`、`skirt`、`shirt`、`car-key`、`house-key` 使用内置 ImageGen 分别生成的透明手绘 2.5D 资产。每件保留 1254×1254 透明 PNG 母版，并生成 640×640 AVIF 与 WebP；catalog 实体拥有响应式地址，通用运行时只渲染资产，不保存课程配图副本。儿童物品选择中不再允许 emoji 回退；资产必须有完整透明通道、清楚小尺寸轮廓、无文字、无人物、无水印，并在桌面与 390×844 手机视口中验收。
