# 纠错反馈使用任务面板内的黄铜提示签

Lesson 1–2 原纠错反馈作为白色悬浮 Toast 固定在场景右下角，遮挡人物并脱离奶油纸、胡桃木、黄铜与星灯的视觉体系；其中外链 `star-fill.svg` 作为 `<img>` 不能继承 CSS `currentColor`，实际显示成突兀黑星。纠错、正确、伙伴示范和保存提醒现在统一渲染在当前 `.mission-console` 内，采用带打孔、黄铜星章和小标题的行李签结构；伙伴示范继续显示探险小猫，正确与危险状态只调整同一材质系统中的边框和印章颜色。反馈参与任务面板正常布局，不再绝对定位覆盖场景；移动端必须完整落在任务面板可视范围内，减少动态效果模式继续适用。
