# 全课程固定青年声色且正确反馈不在语言前播放音效

整套课程把最初候选包的 `am_michael` 与 `af_heart` 分别作为青年男性和青年女性的默认美式声色，独立词音默认沿用青年女声；未来教学单元只有在人物年龄或真实叙事情境需要时，才能用有记录的课程例外偏离。孩子作答正确后保留视觉确认，但目标单词、句子或角色回应必须成为下一段可听内容，不在其前播放提示音、旋律或点击声；这避免界面音效与录音开头留白组合成被误听为人物“前调”的声音。该决定不改变语音包整单元替换、角色 Source ID、真实 `ended` 门禁或正式发布前的人工语言审核。
