# 所有教学单元采用五幕学习骨架

每个教学单元都使用“发现问题 → 听懂线索 → 教会小猫 → 换个情境使用 → 建造地标”的五幕学习骨架。固定的是理解、主动回忆、费曼式外化、迁移和即时成长反馈这些学习功能，不是页面、小游戏或故事模板。奇数情境任务主要承担发现问题、可理解输入和初次解释；紧随的偶数操练迁移任务继续推动孩子重新组织语言、在变化情境中使用，并完成当日建造。人物、事件、互动和美术必须针对教材主题单独创作。

## Considered Options

- 固定学习功能、自由设计故事表现：既能保证学习闭环，又保留每个地标的主题性，因此采用。
- 每个地标完全自由设计：创意空间最大，但容易遗漏主动回忆、解释或迁移，只剩内容展示。
- 所有地标复用完全相同的小游戏：生产最省力，但很快形成换皮题库，削弱世界真实感和学习意义。

## Consequences

- 内容设计稿必须标明每一幕的学习目标、孩子动作、反馈和证据，不能只列页面与动画。
- “教会小猫”要求孩子重新组织、选择理由、修正错误或构造例子；观看小猫讲解不能替代外化。
- V1 可以用选择、排序、匹配和句子拼装完成外化，不需要为了费曼式学习引入录音。
- “换个情境使用”必须改变人物、物品或交际目的，不能只更换选项顺序。
- “建造地标”提供当日进展反馈，不等于目标掌握；最终亮灯与徽章仍由跨日证据决定。
- 同一教学单元的两门教材课次共同完成五幕，不要求每门课机械重复五次。
- 从地图地标进入五幕任务时的场景、角色和界面连续性由 ADR-0035 的同一地标场景连续性决定。
