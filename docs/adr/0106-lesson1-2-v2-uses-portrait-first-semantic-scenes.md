# Lesson 1–2 V2 使用竖屏优先的语义场景构型

## Context

Lesson 1–2 的十五微任务 V0 在桌面舞台中分别绝对定位标题、人物、道具和任务卡，再以固定像素位置与视口高度减法缩入手机。390×844、360×640 和手机横屏审查显示：人物与道具过小或悬空，空场景留下大块无意义背景，高密度内容被塞入卡片内滚动，短屏和横屏发生裁切，终幕多个同侧人物还会完全重叠。

运行时虽然把 catalog 的 `sceneMode` 输出为数据属性，但当前通用页面没有让它选择真实布局；十五阶段因而主要只剩“左右小人物加底部白卡”和“空背景加底部白卡”两种外壳。这与 V2 要求的连续人物因果、真实物品变化、390px 手机可读性和无卡片内嵌滚动冲突。继续给 V0 添加尺寸补丁会把即将退役的十五阶段结构固化进共享渲染器。

## Decision

- 不再为十五微任务 V0 制作临时手机补丁。它只保留为 as-built 事实与反例证据；下一次儿童验收以十六阶段 V2 为唯一候选。
- V2 手机主画幅采用 360–430px 宽的竖屏互动绘本，不把桌面横向舞台等比缩小。平板与桌面可以在不改变任务、人物因果和内容顺序的前提下展开成宽画幅。
- V2 使用五类语义场景构型：对话舞台、物品操作台、语法实验室、路线调查台、成果／停靠场景。Catalog 声明当前阶段的场景语义、人物、道具、语言、动作和答案关系；通用渲染器拥有响应式排布、焦点与动效，不在页面复制课程内容。
- 普通阶段默认在一个手机视口内呈现当前核心动作。完整课文等确实较长的内容只允许整页自然纵向滚动和当前内容跟随，不在任务卡、对话卡或候选区内建立第二个滚动容器。
- 对话场景采用近景人物舞台：当前有职责的人物落在柜台或地面上，使用足够大的全身形象并随话轮突出；物品位于人物手中、柜台、托盘、衣架或路线图等真实关系位置。没有教学或故事职责的人物离场，不以小头像、悬空贴纸或角落装饰填充画面。
- 完整课文听读在宽画幅采用“两侧完整人物＋中间窄课文卷轴”，课文与控制不得遮住人物面部或主要身体轮廓；手机把人物放在课文上方并使用页面级自然滚动，不能用覆盖人物的宽白卡换取同屏塞满内容。
- 现有决定继续有效：声音始终带对应英文；冒险心只在正式挑战显示；纠错支架进入当前场景；探险小猫只在提要、支架和成果中承担职责；盖章、拉杆、点灯和重复确认等无结果点击不因移动端重构而恢复。

## Consequences

- 共享场景接口必须从“所有阶段输出同一平铺 DOM”深化为由稳定语义选择构型的渲染边界；`sceneMode` 不能再只是未消费的数据标签。
- 响应式测试必须按五类构型覆盖至少 360×640、390×844 与 430×932，检查标题、人物、道具、当前英文和主操作不相交，且普通阶段无页面裁切或内嵌滚动。
- 课程专属角色、文案、道具、音频和动作仍由 catalog 唯一拥有；场景模板只提供通用布局能力，不能变成把所有后续课程套进失物招领站的固定皮肤。
- 横屏回退、顶栏、同屏题目密度、拖拽替代、长课文自动跟随、路线调查顺序和动效强度由 ADR-0107 闭合；主构型、场景呈现段与成果停靠边界及五类逐阶段分镜已由 [ADR-0108](./0108-lesson1-2-v2-separates-primary-scenes-from-presentation-moments.md) 与 [手机场景 Storyboard](../designs/lesson1-2-v2-mobile-scene-storyboard.md) 闭合。本决定本身不授权修改 catalog、运行时或页面，不授权合并 `main` 或发布网站。
- ADR-0077 的“手机竖屏优先”继续有效；只取代其中绑定旧整理室门、故事册与卷地图的 Lesson 1 V0 停靠构图。ADR-0097 的“反馈进入场景材质和正常布局”继续有效；只取代所有反馈必须进入 `.mission-console` 的旧容器约束。
