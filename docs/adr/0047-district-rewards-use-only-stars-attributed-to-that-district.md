# 城区主题奖励只由归属于该城区的挑战星解锁

挑战星保留一个终身累计总数，但每颗星同时记录产生证据的学习目标及其来源城区。城区专属纪念章、装饰和收藏只由本城区来源的挑战星与学习成就解锁；全局累计总数和其他城区的星星不能替代。孩子在跨城区故事中回访旧目标时，赢得的星星仍归回该目标的来源城区，而不是故事发生地点。全局累计总数只表达整段冒险中的挑战历史，并可在账号版作为实体礼物领取资格的依据，不直接授予任何无关城区的主题纪念章。

## Considered Options

- 同一颗星同时保留全局累计与来源城区归属：既保存完整能力历史，又让主题收藏与实际学过的内容一致，因此采用。
- 全局星数可以解锁任意城区纪念章：规则简单，但会出现尚未学习某个城区却已经持有其主题成就的叙事断裂。
- 每个城区建立独立星星货币：归属清晰，但会制造十二套余额、兑换规则和儿童理解负担。

## Consequences

- 产品仍只有一种挑战星和一个终身累计总数；城区视图只是按来源筛选同一批发星记录，不是第二种货币。
- 每枚城区纪念章都必须能够解释它与本城区角色、地标、语言任务或结局的关系。
- 跨城区回访需要携带学习目标来源信息，不能按当前页面、故事地点或当前打开的城区错误归属。
- 一个城区的星星不足时，其他城区的星星不能补齐；孩子需要通过该城区目标的后续独立回访继续获得。
- 实体礼物若是通用礼物，可以使用全局星级里程碑；若是城区主题实体物，则仍须满足对应城区条件。
- 城区内部的纪念章结构由 ADR-0048 的“三枚阶段主题小章加一枚城区主徽章”规则决定。
