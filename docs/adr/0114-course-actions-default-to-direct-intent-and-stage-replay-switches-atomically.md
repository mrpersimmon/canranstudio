# 课程动作默认使用直接意图，阶段回看必须原子切换

Lesson 1–2 的儿童实玩表明，拖动英语牌、先点物品再点人物和重复确认并没有增加语言理解，反而把注意力从“听懂并作答”转移到了操作规则。课程因此采用“一个学习意图，一个最短语义动作”的默认合同：识别物品或人物时直接点击答案；把手提包交给主人时直接点击接收人，系统负责演出手提包移动、角色回应和稳定终态。拖拽不再是课程默认操作，只有当空间关系本身就是明确学习目标并经单独决定时才能作为例外。

手提包交付完成后，主人以女声说 `Thank you very much.`；只有当前真实音频 `ended` 才显示继续动作，页面停留在已经交付的故事终态。错误选择第一次只柔和摇动并提示“再看看”，第二次才给方向性支架；提交前不得高亮或用构图暴露正确答案。

角色演练与正式主线共享同一故事背景、真实柜台、人物身份和设备画幅坐标。电脑与手机可以使用不同的响应式显示尺度或裁切，但同一设备档内人物左右关系、脚底基线和视觉尺度必须稳定。角色演练不得额外绘制桌面；有故事职责的两名角色必须同时在场，只通过亮度、轻微呼吸或焦点表现当前说话者。

儿童从阶段地图进入已完成阶段时，运行时、角色练习会话、临时选择、音频和页面模式作为一个事务切换：旧会话先终止，再渲染所选阶段。完成或退出回看后精确恢复原主线。页码、标题、场景和交互内容不得来自不同阶段。所有可重听英语都保留可见英文，右侧只显示带无障碍名称的“星灯黄铜小喇叭”图标；播放中图标发光并禁止重复触发，不再显示“重新播放英文”或“看着英文听一遍”等可见说明。

主线阶段、阶段回看、章节停靠点、完成页或独立练习发生真正导航切换时，文档滚动位置必须一次性回到新页面顶部；同一阶段内的音频逐句、作答反馈、设置与阶段地图开合不得抢走孩子当前阅读位置。这样既消除“新阶段从中间开始”的错位，也不制造答题过程中的页面跳动。

“同一阶段内不跳动”同时包含 DOM 身份合同：在模式、状态类别和恢复微任务都没有改变时，音频开始／结束、答对／答错、纠错支架、设置开合与阶段地图开合只能原位更新发生变化的节点，不得替换 `.station-world`、`.scene-frame`、`.mission-console` 或未发生语义变化的场景人物／物品。只有真正切换阶段、模式或页面状态边界时才允许重建舞台。E2E 必须保存这些节点引用并断言操作前后身份相同，以防入口动画、图片解码与场景布局因意外重建而再次产生闪烁。

## 2026-08-26 冻结选择

1. 识别题直接点击物品或人物；不再声明、渲染或监听拖拽。
2. 手提包交付直接点击主人，不先选择手提包，也不增加确认按钮。
3. 点击主人后自动演出手提包移动，再播放女声感谢；真实 `ended` 后停留并等待继续。
4. 第一次错误只轻摇并提示“再看看”；第二次给方向性支架，始终不预亮答案。
5. 角色演练复用真实柜台，不得新增悬浮桌面或台座。
6. 同设备档人物大小与位置稳定；手机和电脑可采用各自的响应式尺寸，不要求生成不同人物身份。
7. 有故事职责的两名角色同时在场，当前说话者只做轻量强调。
8. 阶段回看原子切换运行时、练习会话、临时 UI、音频和页面阅读起点，并完整恢复主线；阶段内重渲染不重置滚动。
9. 重听控件使用“星灯黄铜小喇叭”图标，靠近可见英语右侧；可见提示文字删除。
10. 十七阶段、电脑短屏、手机竖屏和阶段回看路径都要有自动回归门禁，并继续接受真人实玩验收。
11. 同一导航表面使用原位 DOM 调和；只有真正导航才能重建舞台，节点身份回归测试是发布前强制门禁。
