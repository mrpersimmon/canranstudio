# 后台按学习目标调度，前台呈现故事任务

复习不再以整门教材课次或整个教学单元为最小单位。系统分别追踪声音与含义、句型调用、听辨区别和交际意图等学习目标的练习与独立调用证据，只重新安排真正需要回访的目标；孩子端则把这些目标重新组织成地点内有目的的故事化回访任务，不暴露闪卡队列、遗忘算法或碎片化题单。这样既减少重复已经掌握的内容，又保持冒险世界与语言用途的连续性。

## Considered Options

- 整个教学单元一起复习：实现和解释最简单，但会让孩子重复大量已经掌握的内容。
- 直接展示按目标排列的闪卡或题目队列：调度精细，却把学习体验重新变成脱离情境的练习工具。
- 后台目标级调度、前台故事化任务：兼顾记忆效率和儿童体验，因此采用。

## Consequences

- 一个教学单元可以同时包含已经掌握、正在学习和等待回访的不同学习目标，不能再用单一 `5/5` 代表全部状态。
- 每道活动必须明确自己为哪个学习目标提供什么证据；视觉点击、观看动画和重复原题不能冒充独立证据。
- 故事化回访任务只能组合能够形成自然语言用途的目标，不能为了填满题量随机拼接。
- 地标落成由本单元核心学习目标的目标掌握状态聚合决定；非核心拓展目标不阻塞落成。
- 单元当日建设后的成果庭院只保留安静的星灯信箱，不直接展示目标列表、通道格或复习按钮。信箱只有在之后的新学习会话中存在真实到期目标时才亮起并承接故事委托；自由参观地标、同日重进或点击完成场景不能自行制造回访、独立证据或挑战星。
- 具体间隔、成功次数、跨地标交错规则和失败后的重排仍需单独决定。
