# Lesson 1–2 不要求纸笔或键盘书写

Lesson 1–2 的主线和单元完成不包含教材原有的七句抄写，也不以手机键盘输入替代；这个开篇单元只对听辨、理解、认读和交际调用形成证据。六至八岁孩子尚未被假设具备拼写或手机英文输入能力，整段输入会把键盘操作、标点和拼写负担混入本单元的听说目标，因此完全跳过本单元的书写与键盘输入。

## Considered Options

- 完全跳过本单元的书写与键盘输入：让任务负担与已声明的课程入门基线、交际目标一致，因此采用。
- 用一两个短词输入替代抄写：可以检索拼写，但会在尚未声明拼写目标时扩大证据范围。
- 用手机输入完整七句：形式上接近教材作业，却主要考察设备操作与拼写，且不证明交际理解。

## Consequences

- 教材中的抄写要求被记录为一次有意识的低龄产品改编，不能声称孩子已经完成或掌握该书写任务。
- Lesson 2 重复展示的七句课文继续引用 Lesson 1 的七个对话 Source ID，不为重复文字创建新来源；“抄写 Lesson 1 对话”这一教材练习机制单独记录为 `L02-E01`，处置为有记录的教材省略，并引用本 ADR 作为理由。它不要求儿童接触，不产生 `exposureRefs`、`evidenceRefs`、书写完成或掌握记录。
- 本单元仍可展示完整英文、提供点读和邀请无评分跟说，但不能用这些活动冒充书写或拼写证据。
- 本单元允许孩子选择、拖动和排列已经完整显示的大号词块或短语块；这种语言块组织不属于纸笔或键盘书写，可以证明含义选择与结构组织，但不能证明拼写、发音或口语流利度。
- 语言块支架从情境中选择完整表达，递进到固定句框替换物品，再递进到排列两至三个大块；不使用逐词乱序或逐字母拼装。`Yes, it is.` 在本单元保持为完整语言块，也不引入 Lesson 3 的否定回答作干扰项。
- 后续教学单元可以在明确声明字形、拼写或书写目标后重新引入相匹配的活动，本决定不禁止整套课程教授书写。
