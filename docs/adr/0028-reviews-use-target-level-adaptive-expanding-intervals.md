# 复习采用目标级自适应扩展间隔

每个学习目标独立维护回访阶段和下一回访窗口，不为所有孩子、所有目标套用同一张固定遗忘曲线。新学当天的调用只用于形成性反馈；第一次真正的间隔回访发生在下一个学习日。后续先以约 3、7、14、30 天作为可校准的扩展窗口：无提示成功推动目标进入更长间隔，依赖提示或失败则立即纠错并把目标提前到下一个学习日附近。窗口根据孩子下一次实际学习机会交付，不把未登录期间形成的逾期项目展示成惩罚性欠账。

## Considered Options

- 所有孩子使用固定艾宾浩斯时间表：简单，但把总体遗忘规律误当成个人处方，也忽略目标难度和真实表现。
- 目标级自适应扩展间隔：规则透明、可以从小规模数据校准，也能与故事化任务结合，因此采用。
- 第一版直接建立复杂预测模型：长期可能更精细，但当前数据不足，难以解释和审计。

## Consequences

- 同一个教学单元中的不同学习目标可以处于不同回访阶段，不能以整课最后访问时间统一安排。
- 无提示成功、提示后成功和失败是三种不同证据；只有无提示成功推动间隔扩张并可能形成独立调用证据。
- 提示或失败会触发即时纠错和更早回访，但不会清除历史证据、撤销目标掌握或让已经落成的地标退化。
- 约 3、7、14、30 天只是第一版种子窗口，不是对外承诺；应使用机构儿童的匿名汇总表现持续校准。
- 孩子只看见自然的故事化回访任务，不看见调度阶段、到期日期、欠题数量或遗忘曲线。
- Lesson 1–2 当日完成后的成果庭院不显示“几天后复习”、固定日历、二十二格队列或待完成数量；星灯信箱当天保持安静。以后只有实际进入回访窗口的目标才让信箱在新学习会话中亮起，具体日期、支架导致的优先级和未选中的积压目标继续留在后台。
- 多个目标同时到期时的单次回访负担以及它与新冒险的先后关系由 ADR-0029 的冒险热身回访决定。
