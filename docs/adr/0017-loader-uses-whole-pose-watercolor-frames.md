# 加载角色采用完整水彩姿态帧与原生网页动画

地图整理动画采用 A+ 高质量水彩绘本方案。角色以“希腊四季之旅”的美术语言绘制四至六张完整姿态帧；所有帧锁定相同画布、比例、光源、白边、阴影和脚底锚点，禁止把头、手、尾巴等拆成大量身体零件重新拼装。地图闪光、罗盘指针等不会产生身体接缝的细节可以作为少量独立装饰层。

原生 CSS 与 Web Animations API 负责姿态切换、轻微位移、淡入淡出和真实加载状态控制，不引入 Lottie 运行时。动画表现为约两至三秒可无缝循环的绘本微动作，并且可以在关键地图资产完成解码时立即自然结束。减少动态效果模式直接展示同风格静态姿态。

全站保持同一只探险小猫作为角色身份；每个城区只提供小型装扮包，替换围巾、地图封皮、徽章、强调色和两三个课程相关环境道具，而不重新制作十二套角色动作。这样同时保证水彩质感、角色识别、城区一致性和加载资产的可控性。
