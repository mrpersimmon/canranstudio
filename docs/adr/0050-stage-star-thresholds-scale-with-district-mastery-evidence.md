# 阶段星数按城区掌握证据规模折算

设一个城区有 N 个核心学习目标，每个目标进入目标掌握需要两个不同学习日的独立调用证据，因此该城区的挑战基准为 2N。三枚阶段主题小章的星数门槛分别按挑战基准的约百分之二十五、五十和七十五向上取整，并继续叠加 ADR-0049 的二、四、六座地标覆盖要求。孩子只看到发布时已经固定的明确星数目标，不需要理解内部计算；不同城区即使目标数量不同，也不会因为使用同一套绝对数字而偏松或偏严。

## Considered Options

- 按每个城区目标掌握所需证据规模折算：门槛随真实学习量变化，并能保持跨城区相近的挑战强度，因此采用。
- 十二城区使用同一组固定星数：最容易解释，但目标数量较少的城区会偏难，目标数量较多的城区会偏容易。
- 每个城区人工制定三档星数：能够细调主题体验，但标准容易漂移，也增加长期维护与审计成本。

## Consequences

- 若城区有 N 个核心学习目标，三个星数阈值依次为向上取整的 0.5N、N 和 1.5N，同时必须满足二、四、六座地标覆盖。
- 城区主徽章仍以所有核心目标掌握并使全部地标落成为准，不使用 2N 星数作为替代条件。
- 门槛在城区正式发布时固定并直接展示给孩子，不能在孩子开始收集后因重新计算而提高。
- 后续维护回访获得的星星可以推进已发布门槛，但不会改变挑战基准本身。
- 挑战星按 ADR-0051 采用每日总量上限而不是每目标终身上限；具体每日数量仍需单独确定。
