# 阶段主题小章同时要求挑战星和地标覆盖

城区的三枚阶段主题小章不能只按累计星数发放。每枚小章都必须同时达到本城区挑战星阈值，并让挑战星分别来自至少二、四、六座不同教学地标；某座地标只要有一个学习目标产生过挑战星，就形成一份地标覆盖。重复回访同一地标获得的真实挑战星仍进入本城区与全局累计总数，但不会扩大覆盖面。这样孩子既需要持续克服挑战，也必须逐步接触整个城区，不能只反复练习一个熟悉目标拿满套组。

## Considered Options

- 同时要求本城区星数和二、四、六座地标覆盖：兼顾练习深度与城区探索广度，因此采用。
- 只按本城区累计星数解锁：规则最简单，但长期重复一个熟悉地标也可能取得全部城区主题章。
- 每完成固定两座地标直接发章：覆盖清晰，却让挑战星与城区收藏脱节，也无法区分打开课程和真正跨日调用。

## Consequences

- 第一、第二、第三枚阶段小章分别要求至少二、四、六座不同地标贡献过挑战星，并同时满足各自的本城区星数阈值。
- 只有无提示独立调用产生的挑战星能够形成地标覆盖；访问、首次学习、提示后成功和普通课程完成都不能计入。
- 同一地标贡献多颗星时，星数继续增长但覆盖数保持一，避免把重复深练误认为广泛探索。
- 尚未发布的地标不会形成覆盖，因此第三枚小章和最终主徽章要等城区内容完整后才能获得；已经获得的前两枚小章不受后续发布影响。
- 城区主徽章仍以全部教学地标落成为条件，不被六地标覆盖或累计星数替代。
- 三个本城区星数阈值按 ADR-0050 以目标掌握所需证据总量的约百分之二十五、五十和七十五折算。
