在同一页面、同一音量下对 `coat / dress / skirt / shirt` 进行匿名 A/B/C 真人试听后，用户确认只有 C 没有特殊起音。C 继续使用 `af_heart`，但不直接合成孤立单词：先把 catalog 目标词放入简短自然载体中生成，再按声音活动边界截取最后一次完整目标词。`nce-u01-kokoro-candidate-v3` 将 `context-cropped-lexeme-v1` 固定为二十一条独立词音的制作方式，速度为 1.0；人物话轮与完整变化问句继续使用 `natural-utterance`，保持既有角色声色。四条被实际听过并接受的衣物文件直接进入包并以 SHA-256 锁定，不能用“相同配方”的随机重生成文件替换。其余十七条同配方文件仍是未逐条人工审核候选，正式发布前继续受完整语言门禁约束。
