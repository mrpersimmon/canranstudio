# Lesson 1–2 V2 在完成成果后提供隔离的可选练习

> 2026-08-25：Lesson 1 的“停靠点可选、少量话轮角色换位”已由 ADR-0112 取代为必修双角色全篇演练，并另行解锁无进度逐句回演；本文关于单元后三题案件复盘的隔离边界继续有效。

## Context

既有 ADR 为防止同日刷题伪造掌握，要求 Lesson 1–2 的成果／停靠只提供继续与休息，成果庭院不显示复习按钮，真实到期目标只在之后的新学习会话中形成故事化委托。产品负责人随后在 `L49B-02` 与 `L49B-04` 选择：Lesson 1 完成后可以自愿做两个短角色换位回合，完整单元成果后可以自愿做三题案件复盘。

这两项活动有明确教学价值，但不能靠改名绕过既有证据、调度与奖励边界。它们必须成为 Lesson 1–2 的窄范围隔离练习例外，而不是新的主线阶段、同日到期回访或星级奖励入口。

## Decision

- `L01-RS01` 在等权“继续”“休息”之外，可以显示视觉上次要、可跳过的角色换位入口；`NCE-U01-OUTCOME` 在完整保存、读回、地标成长演出之后，可以显示视觉上次要、可跳过的三题案件复盘入口。各节点原有的主线继续与离开动作必须先可用，练习不能遮挡、延迟或替代它们。
- 角色换位包含两个短回合，一次只代入一个教材角色并遮住该角色的少量关键话轮；对方教材角色、文字与声线保持原样。它不采集、不评分、不要求自报完成，也不让孩子在同一回合替双方说话。
- 案件复盘固定三题，分别联结语篇理解、交际／结构和词汇变化情境。若记录，只能写为 `same-day-practice` 诊断；重复进入不得修改首次结果、`nextDueDay`、独立证据或掌握。
- 两类活动都运行在隔离练习会话，不拥有主线 `challengeRef`、`resultId`、冒险心、进度、恢复微任务、故事事实、章节／单元完成或地标。它们不产生挑战星、到期目标、星级委托、奖励、证书或下一课门禁。
- 这只是 Lesson 1–2 的窄例外。ADR-0025 的目标级故事回访、ADR-0029 的新会话到期热身、ADR-0054 的真实到期星级委托，以及 ADR-0108 对 `outcome-rest` 无主线挑战／结果／进度的其余合同继续有效。

## 已实现合同

截至 2026-08-24，当前 Lesson 1–2 V2 工作树已按以下边界接通两类可选练习；这里的“已实现”只描述本地代码与自动合同，不表示已经形成同一 SHA 发布候选、通过目标年龄儿童观察、合并 `main` 或发布网站。

- Catalog 是唯一内容真源，并以完整入口三元组约束练习资格：角色换位只接受 `L01-RS01 + rest-stop + buildStage 0`，案件复盘只接受 `NCE-U01-OUTCOME + unit-built + buildStage 5`。页面与隔离练习运行时都逐项比对 `outcomeNodeId/status/buildStage`；因此最终复盘只能在十六阶段、二十九结果完成并成功读回、整单元进入 `unit-built` 后出现，不能提前增长或借用 `buildStage 5`。
- 角色换位按 catalog 的 `dialogueTurnRefs` 逐句运行。招领员回合遮 `L01-D01/D03`，手提包主人回合遮 `L01-D04/D06/D07`；当前儿童角色的句子先遮住、揭晓后播放原 Source 音频，对方句子保持原教材文字并自动使用原角色声线。每一句都必须收到当前 `practiceSessionId + stateVersion + requestId + segmentId` 的真实 `ended` 才能进入下一句；失败停在原句并提供重试，迟到或旧媒体回调不能推进。
- 案件复盘固定三题，分别使用 `discourse-understanding`、`communication-structure`、`vocabulary-transfer`，题目、变化情境、候选、答案与正确音频均来自 catalog。稳定 `optionId` 先映射为声明式响应，再复用主学习运行时的 `select-one` 判定；答错只显示 catalog 纠错并留在本题，答对后也必须等正确英语音频真实 `ended` 才能继续。Catalog 的 `same-day-practice` 只声明允许的诊断上限；当前实现不向学习账本写练习事件。
- 可选练习只存在于独立内存会话，不接收主线 ledger、store、outbox、冒险心、结果或故事事实接口。进入、答错、完成、退出与重复进入期间，主运行时快照、账本投影和 revision-scoped `localStorage` 原始记录保持完全相同；退出后直接重绘原成果节点。练习会话自身不持久化，因此刷新只由主运行时从稳定存档恢复到原 `L01-RS01` 或 `NCE-U01-OUTCOME`，不会恢复一份伪造的第十七阶段。
- 最终页的“回看任意已到达阶段”只打开既有阶段地图和 sandbox；它不删除 `localStorage`、不刷新页面、不重置十六阶段／二十九结果。真正清除进度仍只属于设置中的二次确认“重新开始本单元”。

## Consequences

- Catalog 持续拥有角色、话轮、遮词范围、复盘候选与三类练习目标；页面脚本不得复制内容。后续修改必须继续证明退出、刷新、重复进入与错误都不污染主线或跨日账本。
- 自动测试持续锁定练习没有主线结果、心池、地标、调度或掌握副作用；成人走查仍须确认两个主动作不被次要入口挤压，孩子可以直接离开而不感到漏做必修。
- 本决定只部分取代 ADR-0025、ADR-0029、ADR-0054 与 ADR-0108 在 Lesson 1–2 上“成果后没有练习入口／只显示继续休息”的具体条款，不把同日练习推广成全课程默认环节。
- 本决定与上述本地实现事实都不授权合并 `main`、推送发布分支或发布网站。
