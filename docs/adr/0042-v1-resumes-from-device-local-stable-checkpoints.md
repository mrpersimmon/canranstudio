# V1 从设备本地稳定检查点恢复

V1 没有账号机制，在当前浏览器中保存每个已完成微步骤的学习结果以及最近稳定位置。保存内容包括学习目标证据、回访窗口、教学单元与场景位置、已完成微步骤和已经看过的地标成长变化；孩子中途退出后，从最后一个未完成微步骤的开头恢复。音频播放秒数、过渡动画位置、尚未提交的选择和短暂反馈不保存，避免恢复到无法解释的中间状态。不同设备之间不承诺同步，清除浏览器数据会清除本机进度。

## Considered Options

- 每个完成微步骤保存稳定检查点，未完成步骤从头恢复：兼顾恢复体验、数据简单度和状态可靠性，因此采用。
- 只在整门课完成后保存：实现最简单，但移动端中断会迫使孩子重复大量已经完成的内容。
- 保存每次点击、动画帧和音频秒数：看似精确，却会扩大状态数量，并频繁恢复到台词、反馈或转场的尴尬中间位置。

## Consequences

- 微步骤完成必须是明确、幂等的业务事件，刷新或重复恢复不能重复增加星星、证据或建造状态。
- 恢复时先加载对应稳定场景和任务，再准备音频；不能自动重播已经结算的答案反馈。
- 本地数据需要版本号和安全迁移；读取失败时回退到最近可解释的场景起点，而不是让页面崩溃。
- 设置中需要清楚说明进度只保存在当前设备，并对清除本机进度提供二次确认。
- 回访调度所需日期与证据也保存在本机，因此换设备或清理浏览器后无法保持原调度历史。
- 同一设备被多个孩子共用时的长期进度边界与临时体验由 ADR-0043 的单设备单冒险者规则决定。
