# 纪念章记录具体故事贡献和语言能力

每枚城区阶段小章纪念孩子在该城区完成的一种具体贡献，例如帮助一类角色、修复一处公共空间或完成一种主题任务；图鉴说明明确写出孩子使用了什么英语能力、帮助谁完成了什么。城区主徽章综合本城区六座教学地标的核心图案，代表整段城区旅程。纪念章不采用铜、银、金换色等级，也不只显示星数、建筑截图或与课程无关的稀有物。

## Considered Options

- 每枚章对应具体贡献和语言用途、主徽章综合六座地标：收藏物能够唤回真实学习故事，因此采用。
- 铜银金三级小章加城区名称主徽章：生产最统一，但只能表达等级，无法解释孩子在世界中做过什么。
- 直接使用代表建筑图案：与地图视觉一致，却容易退化成地点截图而不是学习成就。

## Consequences

- 每枚阶段小章至少需要名称、独立主题图案、一句故事贡献和一句可理解的语言能力说明。
- 文案采用“你用……帮助……完成……”的能力与贡献结构，不使用“天才”“顶级”“稀有”等人格或比较标签。
- 三枚小章必须拥有不同叙事作用，不能只替换颜色、星数、边框或罗马数字。
- 主徽章需要从六座地标提炼共同城区符号，不能机械缩小六张建筑图后拼贴。
- 纪念章的核心图案固定精心创作，并以同一高清视觉母版兼容网页和未来实体制作，详见 ADR 0060。
- 固定阶段小章表达对所有合资格路径都成立的城区级贡献，个人实际路径另写入真实经历铭文，详见 ADR 0061。
