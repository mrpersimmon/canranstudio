# Lesson 1–2 V2 使用聚焦、等价且不中断学习的手机交互合同

## Context

ADR-0106 已经选择 360–430px 竖屏互动绘本与五类语义场景构型，但仍没有冻结最矮手机、顶部状态、同屏题量、拖拽替代、七句跟随、路线调查、动效和横屏回退。若这些边界留给页面临时决定，V2 仍可能在 390×844 看似正常，却在 360×640 重现任务卡挤压；也可能把拖动精度、强制滚动或设备旋转误当成英语能力。

移动端交互既要保留故事游戏感，也必须让六至八岁孩子始终知道当前只需完成哪一件事。课程进度、冒险心、音频门禁、答案关系和阶段恢复已经由 catalog 与运行时拥有，因此移动布局不能另造一套题目状态或完成边界。

## Decision

- 360×640 是手机竖屏硬验收下限，390×844 是主视觉基准，同时覆盖到 430×932。除完整课文等已声明长内容外，普通阶段的当前提示、焦点实体、全部候选和主操作必须在最矮视口一屏可用。
- 手机只保留一条紧凑顶栏，显示当前阶段短标题、`已完成/16` 和独立设置入口。点击进度，或点击设置中的“选择学习阶段”，打开同一个全屏阶段地图；地图列出十六个可理解标题，遵守已到达、当前和未来禁用状态。冒险心只在当前正式挑战区显示，不常驻顶栏。
- 孩子进入第一个阶段前不开放阶段地图入口。进入后，地图把已完成阶段标为“回看”、当前阶段标为“继续学习”、未来阶段标为“未到达”；点击当前阶段只关闭地图并继续原主线，点击已完成阶段才进入一次只包含该阶段的“阶段回看”。
- 阶段回看不写主线进度、结果、心池、故事事实、排期、地标或奖励。回看期间顶栏始终提供无需确认的“退出回看 · 不保存”；完成所选阶段后停在独立完成页，明确说明进度未变化，并提供“返回继续学习”和“选择其他阶段”两个出口。选择其他阶段可连续回看另一已完成阶段，但不改变最初保存的主线返回点。
- 进入回看时必须在内存中保留完整主线尝试：当前阶段、题目、作答／支架状态、冒险心、随机候选顺序和呈现位置。主动退出或完成后返回时逐项恢复；若原主线正在播放英语，则取消旧请求，回到原音频段开头创建新请求播放，迟到回调不得推进。回看完成只做克制的视觉庆祝，不产生持久奖励或地标增长。
- 同一时刻只呈现一个当前 `challengeRef`，正式候选挑战固定使用三至四个清楚的大候选。一个阶段包含两个词时在同一故事空间顺次完成；前一个正确后物品进入托盘、衣架或路线图，后一个仍保留完整诊断候选集，不能因只剩一题而删成唯一答案。
- 正式答案提交以点按为可靠底线。句块和标签可以同时支持宽容拖拽与大吸附区，也必须提供点按后自动入槽的等价路径；路线图交付等真实故事动作可以按 catalog 声明强调拖拽，但仍保留点按替代。拖动精度、速度和落点偏差不形成英语结果或扣心。
- 完整七句播放时，孩子未主动滚动则页面把当前句自然带到舒适阅读区。孩子主动滚动后，系统停止自动跟随并显示“回到当前句”；音频继续播放，只有当前有效的最后一句真实 `ended` 才开放门禁。点回当前句后恢复跟随，查看前文不产生额外接触或结果。
- `car`／`house` 每条线索先以单张全宽街景出现；识别后缩成线索钉进入逐步展开的纵向路线图。两条完成后路线图成为主画面，再进行英文挂牌与最终交付，不把两张街景挤成并排缩略图，也不引入自由缩放开放地图。
- 动效采用“强状态变化、弱常驻动画”：说话者前移、物品归位、架子展开、路线生成和成果交付可以明确有力；同一时间只保留一个主动作，背景只做极轻微呼吸。减少动态效果模式直接到达同一可理解状态，不漏掉语言、事实、反馈或入口。
- 手机横屏不阻断课程。页面给出轻量“竖屏体验更好”提示，同时提供可完成的紧凑回退布局；设备旋转不得清空当前阶段、重排随机候选、重启音频请求、遮住设置／退出入口或伪造完成。

## Consequences

- 顶栏、阶段地图、冒险心和当前挑战必须由同一运行时快照驱动；阶段地图只导航到已到达阶段或当前阶段，不自行解锁未来内容。
- Catalog 必须提供十六个短导航标题、路线调查的街景／线索／路线关系、长内容跟随所需的稳定段落和全部课程专属文案；“回到当前句”“竖屏体验更好”等通用状态文案由共享界面词典拥有，页面只实现通用跟随、等价触控和布局行为。
- E2E 必须覆盖三档竖屏、横屏旋转、长课文手动滚动、回到当前句、点击／拖拽等价提交、候选集不泄漏答案、减少动态效果，以及阶段回看的首关前禁用、当前阶段续学、单阶段完成页、常驻退出、连续换阶段、精确主线恢复和无持久副作用。
- 五类场景的具体构图、十六阶段逐项映射和关键动效分镜已由 [ADR-0108](./0108-lesson1-2-v2-separates-primary-scenes-from-presentation-moments.md) 与 [手机场景 Storyboard](../designs/lesson1-2-v2-mobile-scene-storyboard.md) 闭合；完整蓝图随后已由产品负责人以 Q21-A 接受并授权本地 TDD 实施。本决定与该接受均不授权合并 `main` 或发布网站。
