# 教材书写作为可选拓展，不阻塞儿童主线

教学单元必须保留并审计教材中的书写活动，但在尚未声明书写目标的六至八岁儿童单元中，只把它作为纸笔或平板手写可选拓展，不放进必做儿童主线，不使用手机键盘替代，也不参与单元完成、地标成长或核心目标证据。Lesson 1–2 的七句抄写继续复用 Lesson 1 的七个对话 Source ID，练习机制 `L02-E01` 标记为 `optional`；当前主线仍只对听辨、理解、认读、结构组织和交际调用形成轨迹。本决定取代 ADR-0082 中“完全省略书写”的处置，但保留“不要求书写才能完成单元”的边界。

## Considered Options

- 作为纸笔或平板手写可选拓展：既保留教材技能入口，又不让设备操作阻塞低龄儿童主线，因此采用。
- 作为第五个必修模块：教材形式最完整，但会把尚未声明的书写能力扩张为完成门槛。
- 从产品与配套材料中完全省略：主线最简，但家庭或教师无法选择承接教材原有抄写活动。

## Consequences

- `L02-E01` 保留稳定 Source ID、重复对话来源关系、允许的拓展载体和“不产生学习证据”边界；它不是 `requiredSourceIds`，也不进入主线 `exposureRefs` 或 `evidenceRefs`。
- 当前儿童 POC 不必增加书写页面；未来提供拓展时应位于章节或单元完成后的非阻塞入口，并明确显示为可选。
- 纸笔版可以是可打印材料；平板版只能提供直接手写，不以手机英文键盘、书写时长或“我写完了”冒充书写掌握。
- 可选拓展的完成不改变章节停靠点、单元当日完成、地标状态、回访调度、挑战星或长期掌握。
- 后续教学单元若明确把字形、拼写或书写设为核心学习目标，需要另行设计任务、纠错与匹配证据，不能从本可选拓展自动继承掌握资格。
