# 地标当天建设，延迟掌握后亮灯落成

地图把即时成就反馈与长期掌握证明分开：孩子当天完成真实学习挑战后，地标立即增加结构、设施或生活细节；只有在之后的间隔回访中无提示想起目标语言，并在变化情境中成功使用，地标才亮灯、点亮铭牌并获得纪念徽章。这样既让每次努力马上可见，又不再把当天做完、提示后答对或短期记忆误称为真正掌握。

单元当日完成要求奇数课与偶数课两个章节的全部必做活动完成，并在这时统一触发地标当日建设；不能每完成一道题或一个微任务就增长建筑。受支持完成和伙伴救援可以满足活动完成并推动当天故事，但必须保留证据差异，不能直接触发目标掌握或最终亮灯落成。

## Considered Options

- 当天完成就直接显示完全体：反馈最快，但地图无法区分短期表现与长期记忆。
- 延迟掌握前完全不成长：证据最严格，但孩子当天看不到努力改变世界，削弱胜任感和继续意愿。
- 当天建设、延迟掌握后落成：同时保留即时反馈与诚实的学习状态，因此采用。

## Consequences

- “完成任务”和“掌握单元”成为两个不同状态；界面、文案、进度与测试不得继续混用“完成”。
- 当日建造不能依赖打开页面或简单点击，必须对应整个教学单元全部必做活动的完成。
- 单个章节完成时可以在当前故事场景中给出案件印章、室内灯光或新区域开放等章节成果反馈，并形成稳定恢复点；这些反馈不得改变地图教学地标的任何成长状态。
- Lesson 1 的章节反馈由孩子在 `L01-M05` 亲手盖下案件印章后统一触发：印章图形出现、室内工作灯亮起、第二间整理室开启，三项结果完整成立后才保存章节停靠点。四张案件线索只是回看 M01–M04 已取得的故事结果，不再次出题或产生证据；这个完整章节演出仍不得让地图地标增长。
- Lesson 2 前六个微任务可以持续改变室内故事状态，例如 M02、M04、M06 分别把认领单夹入三格记录轨道；这些可恢复结果只表示批次进展。第一张认领单和随后点亮的衣架线索不得让地图建筑增加设施、亮灯或取得徽章；只有 M07 确认三个批次与整章必做活动完成后，才统一触发本单元的当日地标建设。
- M06 的第三张认领记录与点亮的星灯开张总闸只表示三个批次已经在室内完成并提供 M07 入口；M06 保存、总闸亮起、恢复到该边界或孩子点按总闸本身都不得增长地图地标。M07 仍须拥有自己的必做开张行动和原子完成条件，整幕完成后才统一写入当日建设。
- `L02-M07` 先让孩子任意顺序激活三个案件印章，再亲手启动星形开张拉杆；只有三枚印章、开张动作、认领窗口开启和货架／衣架／钥匙柜工作状态全部成立，才把 M07、Lesson 2、单元当日完成、地标当日建设阶段与自适应回访状态原子写入。地图雨篷、图形牌、窗口和可见货架的成长演出必须等待写入及读回校验成功，不能用拉杆动画、固定计时或页面图标先行冒充建设。
- M07 保存前退出从三枚未激活案件印章重做，不保存半栋建筑；保存后在揭晓演出中退出，恢复时直接显示完整当日建设状态，不重复写入或发放成果。当天建设仍不得提前点亮屋顶星灯、金色铭牌、整栋暖光或纪念徽章，后四项只属于五个核心目标延迟掌握后的最终落成。
- M07 建设揭晓后停留在完整地标前的成果庭院，独立、受支持和伙伴救援路径使用同一完整建筑与“今天完成三批认领”的真实文案；不得显示残缺雨篷、暗淡设施或“全部掌握”。自由参观、返回地图、信箱状态与停留时间都不能改变建设或最终亮灯条件，真实证据差异只进入后台回访优先级。
- 提示后答对可以继续任务和获得纠错反馈，但不能直接产生掌握证据。
- 独立、受支持和伙伴救援都能推动当天故事；只有前者可能形成与目标匹配的独立证据。
- T1 虽然仍只占一个核心目标和一个地标门槛，但其完整掌握要求 11 个物品词的声音、词形两个通道格都取得延迟无支架成功；任何具体词的任一通道仍有缺口时，不能用整组平均表现点亮该目标，也不为二十二个格分别发奖。
- 间隔多久、到期任务如何排程以及一次失败后怎样重新安排仍需单独决定。
- 地标美术必须同时支持未开始、当日建设过程和最终亮灯落成，最终灯光与纪念徽章不能提前烘焙进普通成长阶段。
