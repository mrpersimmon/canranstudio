# 挑战星采用每日上限而不是每目标终身封顶

长期维护回访仍是有意义的记忆挑战，因此不为单个学习目标设置终身发星次数。挑战星只来自系统按自适应间隔选中的到期学习目标，同一目标同一学习日最多一颗，每个学习日总计最多三颗；自由重做、尚未到期的目标和为了填满额度追加的简单题不能发星。这样孩子在较长间隔后再次独立想起内容仍能得到诚实反馈，同时每日最大产出保持可预测。

## Considered Options

- 只限制每天总量，到期目标未来仍可继续发星：保留长期复习的激励，并通过调度与每日速率限制刷星，因此采用。
- 每个目标终身最多两至三颗星：总量最容易预测，但孩子长期独立记住后会遇到“挑战成功却没有星”的反馈断裂。
- 只限制同一目标同一天一颗：不会阻碍复习，却允许通过多次进入和大量到期目标在一天内累积过多星星。

## Consequences

- 每天不是复习全部地标；系统只从当前到期目标中选择最高优先级的二至三个，组成一次 3–5 分钟故事化热身。
- 每个学习日最多三颗挑战星，正好覆盖正常热身中的二至三个目标，使孩子不会在同一段标准任务里遇到“答对却超过上限”的落差。
- 同一目标掌握后回访间隔逐步扩展，不会因为孩子每天打开网站就每天出现；失败或依赖提示的目标才会较早回来。
- 到期目标过多时只选本次容量内最需要的部分，其余在后台顺延，不展示欠题数字，也不阻止当天新冒险。
- 到期目标少于每日上限时只能获得实际赢得的星星，不能用容易题或重复题补足额度；未用额度不结转。
- 达到每日上限后，正常流程不再呈现新的可得星回访；孩子仍可继续新课、帮助角色和建设地标，避免反复出现“答对却不给星”的落差。
- 全局星数可以长期增长，但增长速率有硬上限；账号版实体奖励还必须由服务器验证学习日、到期资格、每日上限和一次性领取状态。
