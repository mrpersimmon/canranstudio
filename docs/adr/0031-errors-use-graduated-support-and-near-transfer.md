# 答错后逐级提供支架并立即进行近迁移

孩子第一次作答失败后，系统先保护再次独立观察和回忆的机会，不立即揭晓答案。支架按需要逐级增加：先重听或重新观察情境，再提供声音、含义或句型局部线索，最后才完整示范正确表达。示范后不要求机械重复原题，而是立即换一个人物、物品或交际目的稍有变化的微情境，让孩子重新使用目标语言。任何依赖支架后的正确反应都记录为受支持成功，不形成独立调用证据，并触发更早的后续回访。

## Considered Options

- 逐级支架、完整示范后立即近迁移：既避免无效盲猜，也让纠错重新回到意义和使用，因此采用。
- 首次答错立即展示答案并继续：节奏最快，但孩子容易只产生熟悉感，没有重新调用。
- 不断重复同一道题直到答对：可能最终出现正确点击，却无法区分理解、记忆和猜测，还会制造挫败。

## Consequences

- 活动必须能够区分无提示成功、受支持成功和失败，不能只保存最终对错。
- 每个学习目标需要可按层级提供的线索，以及至少一个用于纠错后近迁移的微情境。
- 支架一旦出现，本轮表现不再产生独立调用证据；重新获得证据必须等待后续间隔回访。
- 纠错阶段需要限制总时长和尝试次数，完成必要示范与近迁移后继续新冒险，不能形成无限重试。
- 反馈语言必须描述可改进的线索或策略，不能给孩子贴上“不会”“退步”或“失败者”等标签。
- 不同学习目标使用选择、排序、口头表达或替代输入形成证据的规则由 ADR-0032 的目标匹配证据决定。
