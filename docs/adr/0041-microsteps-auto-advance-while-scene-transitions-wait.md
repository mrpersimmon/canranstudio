# 微步骤自动推进，跨场景转换等待孩子行动

> Lesson 1–2 范围说明（2026-08-24）：有意义微步骤自动推进、稳定边界等待孩子的原则继续有效；下文 `L01-M04` 徽章、钥匙、第三认领者、拉杆与旧 M01–M07 例子均为历史。当前目标活动顺序和继续边界见 ADR-0091、ADR-0104、ADR-0106 与 V2 蓝图；十五任务事实只见历史实施验收包，十六阶段候选状态由 V2 验收包记录。

同一场景内的台词、选择、匹配与简短反馈，在当前语言音频真实结束且学习反馈完成后自动进入下一微步骤，不显示通用“下一题”按钮。五幕之间或进入另一张专属场景时，流程暂停，由角色邀请孩子点击门、道路、人物或任务物主动继续。答错时停留在当前任务并进入阶梯式纠错，不自动跳过；页面进入后台、设备锁屏或失去可见性时暂停自动推进，返回后从稳定状态继续。

## Considered Options

- 微步骤自动、跨场景转换由孩子主动触发：兼顾流畅练习与冒险控制感，因此采用。
- 从台词到换场全部自动连续播放：观看顺滑，但容易在孩子分心、音频异常或尚未准备时擅自推进。
- 每句话、每道题和每次反馈后都点击下一步：控制最明确，却产生大量无意义操作并破坏对话节奏。

## Consequences

- 内容模型必须明确标记微步骤边界和场景边界，不能让页面临时猜测何时需要人工确认。
- 正确或受支持完成后的反馈需要短而完整；反馈结束后自动推进，不能再要求孩子点击确认正确答案。
- 下一微步骤的视觉和音频应提前准备，使自动推进后立即有回应而不是出现空白等待。
- 一个已经写入稳定恢复点的微任务边界不同于任务内部的微步骤：当下一微任务将开始新的教学行动或音频时，即使仍在同一场景也先暂停，由孩子操作场景化继续锚点后再开始。
- `L01-M01` 原子保存后先用约一秒让 `handbag` 黄铜标签归入案件册，再点亮场景中的“回看线索”；只有孩子点按线索才开始 `L01-M02` 及其首段音频。这里不显示通用“下一题／继续”按钮，不自动播放下一任务，也不打开全屏微任务结算页。
- `L01-M02` 在第 3 话轮真实结束并原子保存后，用约一秒让完整问句纸条归入案件册，再点亮场景中的“回声线索”；只有孩子点按线索才开始 `L01-M03` 及第 4 话轮。M02 不能自动播放 `Pardon?`，也不显示通用下一题按钮或全屏结算页。
- `L01-M03` 在孩子亲手归还手提包并原子保存后，女性角色抱住手提包、露出微笑，身旁点亮“感谢线索”；只有孩子点按这处场景锚点才开始 `L01-M04` 及教材第 7 话轮。这里不自动播放感谢语，也不出现通用继续按钮、任务结算页或提前开始孩子的 T5 迁移。
- `L01-M04` 原子保存后，星灯探险徽章重新别回孩子的探险手册或肩带；三至五秒无评分跟说机会结束或被跳过后，桌上案件夹露出空印章位并点亮“归档线索”。只有孩子点按案件夹才开始 `L01-M05`；这里不自动切入归档、不倒计时，也不能让徽章本身成为通关按钮或奖励钥匙。
- `L01-M05` 打开案件夹后，M01–M04 的四张线索自动依次归位，不要求孩子排序或重新答题；随后孩子可以直接点按大号黄铜印章，也可以把它拖入空印章位。印章落下、工作灯亮起和第二间整理室开启作为一个短章节演出连续完成，不在三项结果之间插入“继续”按钮，也不要求长按、精准拖动或控制力度。
- M05 与 Lesson 1 章节停靠点保存后，继续、回看与休息仍留在结案场景内：开启的磨砂玻璃门进入整理室，桌上实体书本打开故事册，卷起的冒险地图返回路线地图。这里不弹通用结算窗口，不自动选择或倒计时；只有孩子点按相应场景物件才执行动作，故事册关闭后仍返回同一停靠场景。
- `L02-M02` 的第五张标签反馈音结束后，四张当前标签统一装上货架、旧案件模型归档，第一位认领者在同一微任务内自然来到窗口，不插入通用“继续”按钮。交流内部按纸条示范音 `ended`、人物回应 `ended` 和孩子必做动作自动开放下一微步骤；系统不能替孩子自动选择 `Excuse me.`、填入 `watch` 或交出手表。最终感谢真实结束并生成认领单后才结算 M02，结算后的无评分跟说邀请不是额外确认步骤。
- M02 结算并保存后，认领单先夹进三格黄铜轨道第一格，关闭的衣柜只用一次轻柔衣料声点亮衣架线索；只有孩子点按这件场景道具才开始 `L02-M03`。这里不出现通用继续按钮、不自动打开衣柜或播放 `coat`，点按也不重复提交 M02。认领轨道是章节进度反馈，不能兼任地图地标成长演出。
- `L02-M03` 的四项声音结果与衣物共同归位全部成立后先原子保存，再滑出关闭的衣签登记册并点亮黄铜封扣；只有孩子点按登记册才开始 M04。这里不显示通用继续按钮、不自动打开登记册、不提前显示第一张英文衣签或让第二位归还者入场，点按也不重复提交 M03。
- `L02-M04` 内四张织物标签按各自反馈词音真实结束自动开放下一张，不在同一登记任务内插入继续按钮；第四项结算后登记册自然翻到完成页，第二位归还者进入窗口。词形登记与物主交流属于同一微任务和场景段落，中间不生成结算页或稳定检查点；问句、T4、亲手接回和 T5 按真实音频与必做动作顺序自然开放，但系统不能替孩子匹配标签、选择表达或接回外套。
- M04 原子保存后，两张认领记录与孩子个人衣钩保持可见，关闭的黄铜钥匙柜只用一次无语言轻响点亮钥匙线索；只有孩子点按这件场景道具才开始 M05。这里不出现通用继续按钮、不自动打开钥匙柜或播放 `car`／`house`，点按也不重复提交 M04。
- `L02-M05` 内孩子逐次把当前钥匙放上识别台；微缩影像出现、目标词音真实结束和短暂词签接触后，当前探索自然收束并开放下一把钥匙，不插通用继续按钮。两项探索完成后词签统一收起并自然进入反序声音挑战；每个目标结算后钥匙回到候选区、两把钥匙重新换位并开放下一目标，系统不能替孩子选钥匙或因只剩一题就移除已答对钥匙。两项结果成立后两把钥匙共同入盒并连续完成 M05 保存，不在单把钥匙、投影或首个目标后插入场景切换。
- M05 原子保存后，安全盒与两把钥匙轮廓保持可见，关闭的黄铜标签窗只用一次无语言纸片声点亮边框；只有孩子点按标签窗才开始 M06。这里不出现通用继续按钮、不自动打开标签窗、显示英文或播放词音，点按也不重复提交 M05。
- `L02-M06` 内两张档案牌按各自反馈词音真实结束自动开放下一张，不在同一挂牌任务内插入继续按钮；每项结算后档案牌翻成中立封页，两把钥匙返回、重新换位且保持完整可选。第二项结算后第三位认领者在同一微任务内自然来到窗口，词形挂牌与后续交流之间不生成结算页或稳定检查点；系统不能替孩子匹配档案牌、选择后续语言块或完成归还。
- M06 交流内部按 `Excuse me.` 示范音 `ended`、认领者 `Yes?` `ended`、完整问句 `ended`、肯定回答 `ended`、孩子必做交接和最终感谢 `ended` 自动开放下一微步骤，不插通用继续按钮。系统不能替孩子选择案件、提交开场语、组成物品问句或交接钥匙；语言块落到不匹配的物理槽只获得就近停靠提示，不打断为错误页。
- M06 原子保存后，第三张认领记录夹入轨道第三格，当前钥匙保持已交接、另一钥匙保持安全登记；关闭的星灯开张总闸只用一次无语言机械声点亮。只有孩子点按总闸才开始 M07，这里不自动切地图、触发建设、播放下一任务语言或显示通用继续按钮，点按也不重复提交 M06。
- `L02-M07` 的三个案件印章允许孩子任意顺序逐个点亮；每个短缩影结束后自动回到同一控制台，不插通用继续按钮。三枚全部完成后星形拉杆自然开放，孩子点按或宽容拖动一次即连续完成光路汇聚、卷帘开启与三类设施进入工作状态，不在这些结果之间插确认步骤。只有原子保存与读回校验成功，镜头才连续进入地图建设演出；跳过演出直接落到同一完整状态，不能跳过孩子必做印章与开闸动作或持久化。
- 地图建设演出完成或跳过后留在成果庭院，不自动进入下一课、回访或路线地图。打开的认领窗口进入自由参观，卷起的冒险地图返回城区；两个入口都只在孩子点按后行动，不倒计时、默认选中或因欢迎动作结束自动导航。星灯信箱当天不启动任务，只有后续新学习会话存在真实到期目标时才按回访合同接管。
- 场景化继续锚点的点按只表达孩子准备继续，既不是答案或学习证据，也不得再次提交上一微任务或重复发放成果。
- 场景入口必须是故事中真实可理解的对象，同时保留足够触控区域和单步提示，不能把找热点变成挑战。
- 页面不可见时暂停音频、计时和自动推进；恢复后不能重复计分或跳过当前内容。
- 中途关闭后的保存粒度与恢复位置由 ADR-0042 的设备本地稳定检查点决定。
