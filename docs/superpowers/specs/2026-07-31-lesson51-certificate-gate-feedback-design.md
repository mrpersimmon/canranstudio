# Lesson 51 证书缺星提示

历史设计 · 2026-07-31，用户选择高保真方案 1。后续由[统一满星设计](2026-08-01-unified-certificate-gate-design.md)接替。

问题：旧打印按钮被禁用，孩子点击后没有反馈。

选择的做法：保留可点击入口；未达条件时展开票券，说明还缺什么，并提供“前往补练”“稍后再说”。前者跳到首个未完成目标并聚焦，后者收起提示并恢复焦点。打印前重新检查资格。

票券使用暖白纸面、深色边框、偏移阴影和课程强调色；手机上下排列按钮，打印时隐藏提示。

当时的“一关至少一星”已失效，当前编号课需要五关全部三星。[原始视觉来源与完整记录](../../archive/2026-09-17-docs-before-simplification.zip)。
