# 统一证书提示设计

2026-08-01 已确认。Lesson 51 的票券是共同视觉基准；各课只换名称、图标、强调色和目标名称。

## 孩子会看到什么

证书入口从一开始就可见、可点击。没满星时，点击会看到：

- 还差多少星、多少关未满星。
- “前往「目标」补满星”，跳到第一处需要补练的地方。
- “稍后再说”，收起提示并回到原入口。

编号课五关各 3 星，共 15 星；音标课 `vs/g1/g2/g3` 各 3 星，共 12 星。保留已有进度；不足满星的旧证书按新规则锁定，不清空成绩。

## 页面与交互规则

1. 共用 `core/certificate-gate.js` 和 `core/certificate-gate.css`，各课提供当前评级、按学习顺序排列的跳转目标和原有证书操作。
2. 票面暖白 `#fffdf5`，深棕边框 `3px #2f271f`，带票根缺口和错位阴影。桌面按钮并排，窄屏主操作在上。
3. 未满星入口仍能展开帮助，不能用 `disabled` 或 `aria-disabled="true"` 禁用。
4. 展开后焦点移到主操作；取消后回入口；跳转后移到目标标题。音标游戏先切到对应标签，再滚动与聚焦。
5. 评级变化时更新缺星、目标和资格；已满星时收起提示。
6. 领取、保存、打印前各自重新检查当前评级和姓名要求，不能仅信任按钮外观。
7. 缺失或无效评级按 0 星处理；目标不存在时保持提示并显示“暂时找不到目标关卡，请使用课程导航。”，不执行打印。
8. 反馈支持读屏，减少动态效果模式关闭非必要动画；打印时只显示原证书。

## 怎样验收

逐课检查空进度、部分进度、损坏数据、14/15 与 15/15、音标 11/12 与 12/12；确认跳转、取消、焦点、读屏提示、390 像素窄屏和打印均可用。修改页面属性不能绕过实时资格检查。

本设计只统一证书资格和缺星提示，保留各课评分方法与证书成品。原始高保真路径、当时五课配色和跳转表见[原文备份](../../archive/2026-09-17-docs-before-simplification.zip)；当前活动名称以课程清单为准。
