# Lesson 49/50 新学习运行时与纵向切片规格

> 状态：已批准，实施中
> 课程语义真源：docs/designs/four-seasons-city-curriculum-semantics-v1.md
> 首个教学单元：Lesson 49 + 50，暖灯风味市集
> 产品边界：V1 无账号、无儿童语音采集、设备本地进度
> 实施状态：U01 纵向切片正在实施；本文不是上线或发布证明

## 1. 结论

Lesson 49 与 Lesson 50 不再是两门彼此独立、各有五关和一座地标的课件。它们组成一个教学单元：

- Lesson 49 承担“发现问题”和“听懂线索”；
- Lesson 50 承担“教会小猫”“换个情境使用”和“建造地标”；
- 两个原有 URL 继续有效，但进入同一个共享学习运行时和同一份教学单元进度；
- 新课当天完成后，暖灯风味市集建设完成但不亮最终灯光；
- 后续目标级回访产生独立证据和挑战星；
- 五个核心目标都在两个不同学习日、两个变化情境中无提示成功后，市集才亮灯并永久落成。

本轮不是给旧页面换皮。现有词汇、课文音频、题目数据和触控交互可以复用，但进度、证据、地标归属、奖励语义和页面编排必须由共享运行时重新组织。

## 2. 第一性原理

### 2.1 学习不是“看完内容”

孩子真正需要的是：

1. 在具体问题中注意到语言有用；
2. 从可理解输入中建立声音、意义和意图连接；
3. 通过教会小猫重新组织知识；
4. 在变化情境中主动调用；
5. 经间隔后仍能调用，才称为掌握。

翻卡、播放完音频、读完规则、看过答案和同日重复刷对都不能替代主动调用。

### 2.2 记忆调度不是机械套用“艾宾浩斯日期表”

V1 使用目标级自适应扩展间隔：

- 新课当天只记录形成性表现；
- 第一次真正回访在下一个学习日；
- 后续以约 3、7、14、30 天为种子窗口；
- 无提示成功扩展间隔；
- 提示后成功或失败在完成纠错后提前到下一学习日附近；
- 未打开网站的日子不形成惩罚性欠账。

这遵循间隔效应、主动回忆和迁移原则，但不会把总体遗忘曲线误当成每个孩子、每个目标都相同的固定处方。

### 2.3 激励必须证明真实挑战

- 新课成功：改变角色和地标，不发挑战星。
- 到期回访中第一次无提示独立成功：先产生世界结果，再轻量点亮一颗挑战星。
- 同一目标同一学习日最多一颗；设备每日最多三颗。
- 没有到期目标时不制造简单题补星。
- 地标落成和最终主徽章不能由累计星数替代。

## 3. 目标与非目标

### 3.1 目标

- 建立“奇偶课合一”的教学单元目录。
- 用一个共享运行时承载五幕、检查点、音频生命周期、纠错支架和恢复。
- 建立目标级形成性表现、回访、独立证据、掌握、挑战星与纪念章投影。
- 让地图、课程和图鉴读取同一个设备本地学习真源。
- 用 Lesson 49/50 打通一次完整纵向闭环。
- 保留现有公开 URL、教材顺序和无账号边界。

### 3.2 非目标

- 不在 V1 请求麦克风、录音、语音识别或自动口语评分。
- 不实现账号、授权码、跨设备同步或服务端防作弊。
- 不一次重写 Lesson 51–60。
- 不把当前纪念章 POC 直接接入生产状态。
- 不把现有 l1–l5 星级自动换算成挑战星或掌握。
- 不在本文阶段提交、推送、合并或发布。

## 4. 孩子体验

### 4.1 从地图进入

孩子点击“暖灯风味市集”后：

1. 如有 1–3 个真实到期目标，先进入 3–5 分钟故事化回访；
2. 如无到期目标，小猫简短说明“旧本领现在很稳”，直接继续新冒险；
3. 首次学习从 Lesson 49 情境开始；
4. 中断后从最后一个稳定检查点恢复；
5. 新课已完成但尚未掌握时，可继续故事化回访，不把整门课重新播放。

课程场景不常驻星数、空星槽、城区徽章进度或“今日还差几颗”。这些信息只在地图、图鉴和回访结算中出现。

### 4.2 Lesson 49 与 Lesson 50 的连续关系

| 入口 | 已有检查点 | 行为 |
| --- | --- | --- |
| /lesson49/ | 无 | 从第一幕开始 |
| /lesson49/ | 已完成前两幕 | 恢复到第三幕前的单元营地 |
| /lesson50/ | 已完成前两幕 | 直接进入第三幕 |
| /lesson50/ | 无 | 先完成约 60–90 秒的压缩版前两幕与两个关键线索检查，再进入第三幕 |
| 任一入口 | 新课五幕已完成 | 打开当前到期回访；无到期时进入地标回望 |

直接打开 Lesson 50 不能凭 URL 自动制造 Lesson 49 的完成证据。压缩桥接不是跳过：孩子必须完成问题识别和两个关键线索检查，运行时才分别提交 beat-1-completed 与 beat-2-completed 的形成性建设事件，把稳定 checkpoint 和 buildStage 推进到 state-2。桥接不写 independent evidence、不发挑战星、不产生目标掌握；中途退出时仍停在最后真实完成的桥接微步骤，不能直接恢复到第三幕。

### 4.3 五幕纵向切片

#### 第一幕：发现问题

场景：肉铺和果蔬摊的订单混在一起，伯德夫人和家人的需要没有分清。

孩子动作：

- 观察人物、商品和订单板；
- 指出还缺少“谁要什么、不要什么、数量多少”；
- 选择应该先问或先听的线索。

世界结果：摊位开门，订单板展开，第一处建筑细节出现。

#### 第二幕：听懂线索

场景：伯德夫人与肉店老板的教材对话。

孩子动作：

- 点击角色播放预录完整句；
- 音频结束后再进入下一微步骤；
- 把 beef、steak、mince、chicken 与数量/选择放入正确订单；
- 在错误时先重听或观察，再逐级获得局部线索。

音频规则：

- 预录教材音频优先，speechSynthesis 只作降级；
- 场景推进由 ended/完成回调驱动，不使用固定 3.4 秒定时器；
- 下一句音频在当前句播放时预取，减少“切题后像卡住”的等待；
- 手动重播会取消旧请求，不产生重叠朗读。

世界结果：备货台完成，第二处建筑细节出现。

#### 第三幕：教会小猫

场景：小猫整理错了订单和句子。

孩子至少要处理三类错误：

1. 助动词错误：doesn't 后使用动词原形，不能继续使用 likes/wants；
2. 句型意图错误：二选一问题、接受、拒绝和偏好不能混为一类；
3. 第三人称错误：he/she 的肯定句使用 likes/wants，否定句由 doesn't 承担变化。

交互采用分类、选择理由、句子拼装和改错。只点击“明白了”或观看小猫解释不能过幕。

世界结果：询问、选择、偏好和拒绝表达被修正完整，第三处建筑细节出现。

#### 第四幕：换个情境使用

场景：从肉店切换到野餐/果蔬采购，同一语言服务于新人物、新商品和新目的。

孩子动作：

- 根据未见过的两个人物偏好卡配篮；
- 组织 Do you want any...? 与 X or Y?；
- 用 I like... but I don't... 和 He/She likes... but doesn't... 解释选择；
- 错误后经过支架与示范，再完成一个近迁移微情境，不机械重做原题。

世界结果：共享餐桌摆好，第四处建筑细节出现。

#### 第五幕：建造地标

孩子核对最终订单，确认商品、数量和偏好表达一致，没有放入不喜欢或不需要的食材。

世界结果：

- 暖灯风味市集完成当日建设；
- 地标保持日间/未亮灯完全体；
- 页面明确说明“市集建好了，旧本领会在以后回来找你”，不宣称已经掌握；
- 不发挑战星；
- 后续地图将该地标显示为“已建设，等待回访”。

## 5. 目标证据与纠错

### 5.1 证据等级

| 等级 | 定义 | 形成独立证据 | 推动间隔 | 可得挑战星 |
| --- | --- | --- | --- | --- |
| independent | 未出现任何支架，第一次作答成功 | 是 | 是 | 到期且未触及当日上限时是 |
| supported | 重听、局部线索或示范后成功 | 否 | 否；更早回访 | 否 |
| failed | 在有限支架后仍未完成 | 否 | 否；更早回访 | 否 |
| practice-only | 开口邀请、观看、翻卡或新课形成性活动 | 否 | 否 | 否 |

### 5.2 阶梯支架

第一次错误后：

1. 重新观察人物/订单或重听音频；
2. 提供声音、含义或句型的局部线索；
3. 完整示范；
4. 立即换人物、商品或目的做一个近迁移微情境；
5. 结束本轮并把目标提前回访。

支架一旦出现，本轮即使答对也只能记为 supported。不能答错后立即亮出正确选项并自动跳走。

### 5.3 目标掌握

对 FLC-U01-T01 至 FLC-U01-T05 分别判断：

- 两条 independent 证据；
- learningDay 不同；
- contextId 不同；
- evidenceMode 符合目标声明；
- 任一证据都没有支架。

五个目标全部满足后，U01 进入 mastered，地标切换为夜间暖灯完全体并永久保持。维护回访失败不会拆灯或撤销已获得纪念章。

## 6. 地标状态与美术合同

暖灯风味市集必须使用完整累计状态图，不在运行时拼接松散装饰层：

| 状态 | 含义 |
| --- | --- |
| state-0 | 未开始 |
| state-1 | 完成发现问题 |
| state-2 | 完成听懂线索 |
| state-3 | 完成教会小猫 |
| state-4 | 完成变化情境 |
| state-5 | 完成当日建设，建筑完整但未亮最终灯光 |
| state-mastered | 五个核心目标跨日掌握，建筑与铭牌亮灯、永久落成 |

因此正式资产不是现有的 0–5 六张，而是七个完整累计状态。每个状态都必须从同一高清母版逐步编辑，保持：

- 相同画布、地面锚点、透视、建筑位置和主要轮廓；
- 同一城区的纸雕水彩、金属、石材和暖灯材质语言；
- 建筑主体同时体现肉铺、果蔬摊和共享备餐桌；
- state-0 至 state-5 不提前烘焙最终亮灯；
- state-mastered 的建筑灯光、铭牌灯光和庆祝细节属于同一张定稿图，不用 CSS 光环代替；
- 512、768、1024 响应式派生图保持同一构图，不按容器拉伸变形。

审图使用隐藏的无存储 POC，至少可以切换七个状态、三档手机/平板尺寸和美术原图；孩子端不得感知审图控件。

## 7. 深模块设计

### 7.1 设计原则

新的学习逻辑必须形成少数深模块：课程调用者只学习小接口，调度、证据、幂等、奖励和恢复的复杂性留在实现内部。删除任一模块时，如果这些复杂性会重新散落到 Lesson 49、50、地图和图鉴，说明该模块正在提供真实深度。

### 7.2 curriculum-catalog 模块

职责：

- 声明教学单元、教材课次、五幕、核心目标、允许证据、情境、音频和地标资产；
- 验证一个 Lesson 只归属一个教学单元；
- 验证核心目标 ID、情境 ID、证据模式和资产路径。

外部接口只保留：

- getTeachingUnit(unitId)
- getTeachingUnitForLesson(lessonId)
- listTeachingUnitsForDistrict(districtId)
- validate()

课程内容数据不能再次散落在两份页面脚本中。

### 7.3 learning-ledger 模块

职责：

- 本地档案迁移与规范化；
- 稳定检查点；
- 目标证据、跨日/跨情境掌握；
- 自适应回访窗口；
- 挑战星每日上限与幂等；
- 地标、城区覆盖和纪念章资格投影。

外部接口只保留：

- open：从存储适配器载入并规范化；
- apply：提交一个带 eventId 的学习事件，返回新快照和需要展示的效果；
- read：读取课程、地图或图鉴需要的投影。

存储 seam 只有两个真实 adapter：

1. localStorage adapter：生产使用；
2. in-memory adapter：单元测试与无存储 POC 使用。

模块必须接受 adapter、clock 和 idFactory，不能在实现内部直接创建 Date、localStorage 或随机 ID。这样测试与调用者通过同一个接口工作。

### 7.4 learning-runtime 模块

职责：

- 五幕与微步骤状态机；
- 入口、恢复和 Lesson 50 情境桥接；
- 动作校验、阶梯支架、近迁移；
- 音频完成驱动的推进；
- 把合格结果作为事件交给 learning-ledger；
- 把视觉、音频和导航需求作为效果返回。

外部接口只保留：

- create
- enter
- dispatch
- snapshot
- destroy

页面只发送“孩子做了什么”，不能自行决定星星、掌握、地标或纪念章。

### 7.5 DOM 场景实现

DOM、CSS、触控、焦点、音频播放器和减少动态效果属于 learning-runtime 的网页实现，不形成额外的假想 seam。只有当出现第二个真实呈现 adapter 时，才把它抽象为公开接口。

## 8. 设备本地档案

### 8.1 真源

V1 的真源仍是当前浏览器的 localStorage。没有账号意味着：

- 不保证跨设备同步；
- 清理浏览器数据会丢失进度；
- 客户端日期和数据可以被修改；
- 当前阶段不能把实体礼物兑换做成高可信自动结算。

页面必须诚实描述这一边界，不把本地数据包装成云端账号进度。

### 8.2 最小持久化

持久化只保存不可从别处推导的事实：

- schemaVersion 与 revision；
- 单元稳定 checkpoint；
- 五幕当日建设进度；
- 每目标最多两条掌握证据的日期、情境、证据模式和结果；
- 当前间隔阶段、下一回访窗口和最近表现；
- 幂等 starAwardId、学习日累计与已获得纪念章；
- 尚未看完的结算/揭晓展示标记。

mastered、landmarkState、districtCoverage 和 badgeEligibility 均由上述事实投影，不重复保存为多个互相漂移的真源。

### 8.3 学习日

- learningDay 使用设备本地日历日的 YYYY-MM-DD。
- 同一目标同一 learningDay 最多形成一条独立证据和一颗挑战星。
- 设备日期回拨到已经出现过的日期时，不重复发星或制造第二条证据。
- 所有生产提交都带唯一 eventId；重复 dispatch、刷新恢复或双击不得重复写入。

### 8.4 旧进度迁移

- 保留现有 Lesson 49/50 评级键，不删除、不覆盖。
- 旧评级只标记 priorExposure，允许跳过已熟悉的展示性内容；它不形成独立证据、挑战星或目标掌握。
- 两座旧地标不自动兑换为一座新地标的最终状态。
- 上线前提供一次迁移预览，显示旧评级如何被保留；若需要给予建设进度补偿，必须另行确认固定映射，不能在实现中临时猜测。

## 9. 回访与结算

### 9.1 选题

- 每次只从真实到期目标中选 1–3 个最高优先级目标；
- 优先顺序考虑失败/受支持表现、逾期程度、间隔阶段和避免连续同一题型；
- 同一故事任务只组合能形成自然目的的目标；
- 其余到期目标后台顺延，不显示欠题数量。

### 9.2 得星反馈

每个合格目标的顺序固定为：

1. 能力成功；
2. 角色/道具/世界发生结果；
3. 场景边缘轻量点亮一颗星；
4. 继续任务。

回访完成后统一结算 0–3 颗星和来源城区。结算等待孩子点击任意位置：

- 动画中第一次点击只跳到完整最终状态；
- 最终状态的下一次点击才继续；
- 若有新纪念章，先进入独立揭晓，再点击任意位置收入图鉴；
- 点击只控制展示，发奖事务在动画前已幂等提交。

## 10. 地图和图鉴投影

地图从 learning-ledger 读取：

- buildStage 0–5；
- mastered；
- nextDue 是否存在；
- 当前稳定 checkpoint；
- 最近活动地点。

图鉴从同一投影读取：

- 本城区挑战星；
- 贡献过挑战星的独立地标数；
- 15/30/45 星与 2/4/6 地标覆盖门槛；
- 6 座地标永久落成状态；
- 三枚阶段章和一枚主徽章资格；
- 展示是否已经看过。

POC 的 state query、固定 6/12 或 12/12 数字、验收按钮和硬编码进度都不能进入生产投影。

## 11. 失败与降级

- 存储写入失败：可以显示即时答题反馈，但不能宣称永久建设、得星、掌握或授章。
- 图片失败：显示可理解的静态场景与具体状态文字，不显示破图。
- 音频失败：提供重试和文本/图片线索，不能卡住状态机。
- speechSynthesis 不可用：预录音频失败后允许静音继续，不弹出阻塞式 alert。
- JavaScript 异常：保留返回地图与重新进入当前稳定 checkpoint 的路径。
- prefers-reduced-motion：直接呈现最终状态，不漏记事件，也不跳过孩子需要阅读的结果。

## 12. 可访问性与移动端

- 手机竖屏是布局与交互真源；华为大屏、iPhone 12 和小屏 iPhone 必须同测。
- 每个主要触控目标至少 44×44 CSS 像素。
- 场景不产生横向滚动；地图和课程图片保持固有宽高比。
- 语义按钮使用真实 button；角色、订单、篮子和句子状态有可访问名称。
- 音频播放、正确/错误和地标变化不能只靠颜色或声音表达。
- 覆盖层打开时锁定背景滚动，关闭后恢复原焦点和滚动位置。

## 13. 验收标准

### 13.1 课程

- Lesson 49/50 两个 URL 进入同一个 U01 进度。
- Lesson 49 完成后停在 state-2；Lesson 50 完成后达到 state-5，但不亮最终灯。
- 五幕没有常驻星数，也不会因新课完成产生挑战星。
- husband 只作为课文中的家庭关系词出现，不设计“人物还是肉类”的闯关；内容发布校验继续防止错误归类。
- 对话不会在音频结束前自动跳句；下一音频已预取且无明显空白等待。
- 错误不会立即亮答案并自动跳题。

### 13.2 记忆与奖励

- 同日重复成功不能制造第二证据或第二颗同目标星。
- 两个不同学习日、两个不同 contextId 的无提示成功才掌握。
- supported 和 failed 不会发星或推进间隔。
- 每日最多三颗；没有到期目标时为零，不补简单题。
- 五个目标都掌握后地标从 state-5 切到 state-mastered。

### 13.3 地图与图鉴

- 一座暖灯风味市集代表 Lesson 49+50。
- 当前两座旧地标不再同时作为正式单元奖励。
- 地图、课程和图鉴刷新后读取同一投影。
- 纪念章门槛使用 15/30/45 星与 2/4/6 地标覆盖，不出现 6/12 或 12/12 地标。

### 13.4 纵向切片过渡期

当前生产地图已经发布 Lesson 49–54，而本规格只改造 U01。为避免孩子端出现“一座新单元地标 + 四座旧 Lesson 地标”的混合语义，U01 纵向切片在 U02、U03 尚未完成前只进入隐藏验收台和明确标记的内部候选构建：

- 正式生产地图继续保持当前发布状态，不切换单地标目录；
- U01 的地图投影、七状态图和返回路径在内部候选构建中完整验证；
- 只有 U01、U02、U03 三个当前已发布奇偶课对都完成单元迁移后，才能整体切换生产地图；
- 若业务必须提前上线 U01 混合态，必须另写并审核临时兼容 ADR，明确旧地标、奖励和退场日期，本文不默认授权；
- 纵向切片完成不等于生产地图可以发布。

### 13.5 回归

- 旧进度键保持可读且不被删除。
- 现有直达链接、返回地图链接和静态部署边界继续有效。
- 无 localStorage、静音、离线音频失败和减少动态效果均不存在学习死路。

## 14. 开放但不阻塞规格编写的美术问题

- U01 七张累计地标状态的正式构图需要单独美术审查。
- 旧肉店与旧城堡素材只能在语义与风格审计后决定保留、重绘或降级为场景道具。
- 纪念章名称和具体图案要在六单元语义表审核后另出 brief；当前只冻结课程贡献与门槛。

这些问题阻塞正式美术和上线，不阻塞学习运行时纯模型、数据合同与测试夹具的实现。
