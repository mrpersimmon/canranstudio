# 册页布局与成长回看

2026-08-07 产品方向已确认，可进入实现；正式接入、合并和发布须有各自验收。本文取代旧的“手机显示 1.5–2 屏长地图”要求。

## 一张图适配不同屏幕

- 手机和竖屏平板：顶部栏与完整地图通常放进一屏。
- 空间足够的宽屏：固定双页摊开，第一页与第二页同摊；第三页发布后与纯装帧衬页同摊。
- 极矮窗口：保持文字可读，允许少量纵向滚动。
- 所有尺寸共用 `940 × 1672` 比例、地标位置和状态，不裁切、拉伸或按设备重排。
- 返回和设置触控区至少 `44 × 44`；剩余空间用皮革、书脊和阴影承接。
- 双页按实际可用宽高、最低可读尺寸和触控目标判断，不靠设备名称判断。

首批地图：`district5-page1`“风味四季路”放 Lesson 49–52；`district5-page2`“气候家庭街”预留 Lesson 53–56，只显示已发布的 53、54。第三页未发布，不显示入口或占位。

## 默认打开哪一页

依次取：有效的课程返回地址 → 最近学习且未完成的课 → 最早未完成的已发布课 → 全完成时最近学过的课 → 没记录时第一页。

世界入口对应显示“从风味四季路出发”“继续：册页名”或“重游：册页名”。单页顶部显示册页名；双页顶部显示城区名，各页另有名签。所有已发布页可直接访问。

## 怎么换页

地图边缘用页角、桥等显示“前往 · 册页故事名”。双页以整摊切换，同摊两页之间不加多余控件。

手机可左滑前进、右滑返回；只能从地图空白或装帧边缘起手。地标、铭牌、页角、顶部栏和设置不触发滑动，系统边缘返回优先。横向意图明显时才换页，首尾轻微回弹，不循环。

正常换页 250–350 毫秒；减少动态效果时直接切换。手动翻页不写入学习完成记录，旋转屏幕保留当前页和地标。当前任务用铭牌暖光、旗帜和小猫强调，不自动放大或滚动地图。

## 加载要达到什么标准

| 场景 | 要求 |
| --- | --- |
| 单页／双页 | 当前所有可见底图与已发布地标准备完成后一起显示 |
| 180 毫秒仍未就绪 | 显示小猫整理地图，准备好立即结束 |
| Fast 4G 模拟 | 3 秒内可操作 |
| 4.5 秒仍未就绪 | 用兼容格式和已准备内容继续，失败资源后台重试 |
| 相邻页已预载 | 100 毫秒内开始换页，350 毫秒内完成 |

按屏幕需要选 AVIF/WebP，不强制下载母版。首屏稳定后只空闲预载相邻已发布页，未发布地点不发图片请求。全过程不出现半本书、空白页、拉伸或布局跳动。

## 返回地图后的成长回看

最近学习地标的未看阶段按顺序交叉淡入，每段约 500–700 毫秒。先准备完整阶段链，准备失败就直接显示最新状态和简短汇总。

点击任意位置立即跳到最新状态，一次标记整条阶段链已看，并阻止点击误入底下的课程。结束后恢复操作。其他地标只保留轻量暖光，等下次聚焦再看；减少动态效果直接显示最新状态。声音可选，失败不能拖慢流程。

## 验收台里的孩子端预览

在 `/poc/landmark-review/` 增加内部预览，真实呈现页面、页角、滑动、装帧、地标和加载状态。地标点击只提示将进入哪课，不离开验收台，也不读取或写入真实学习记录。

查询参数使用 `review=student`，`scenario` 可为：

- `journey`：所选地标用指定阶段，此前已发布地标完成，此后初始。
- `initial`：全部初始。
- `complete`：全部完成。

未发布地标始终不存在。地址刷新能恢复，无效参数安全回退。例：

```text
/poc/landmark-review/?location=lesson54&stage=5&review=student&viewport=huawei&scenario=journey
```

固定检查尺寸：iPhone 390 × 844、华为 466 × 980、平板 768 × 1024、电脑 1366 × 768、原图 940 × 1672；原图档只查美术细节。

## 实施与验收顺序

先验证册页选择逻辑 → 在验收台做五档尺寸与三种场景 → 用户确认构图与操作 → 共用同一份位置数据接入正式页面 → 检查加载、滑动和回看 → 完成自动与真机检查 → 按授权提交、合并和发布。

检查重点：单／双页切换、短屏、手势边界、完整加载、性能预算、回看顺序与点击防穿透、刷新恢复、预览数据隔离。真机须覆盖 iPhone、华为和平板，另检查电脑。本文不包含第三册页、Lesson 55／56、账号、追踪或新的孩子端显示模式。
