# 首页学习路线设计

## 背景

当前首页把 Lesson 49、Lesson 50、音标番外篇和 Lesson 51 依次渲染为四张大型纵向卡片。课程数量增加后，页面会线性变长；番外篇也混在正课编号中，用户难以理解课程体系。

用户已选择第三张高保真方案作为视觉真源：

## 目标

- 把编号 Lesson 组织成可扩展的第一册学习路线。
- 把音标等非编号内容放入独立的“番外站 · 专项技能”。
- 当课程增长到 144 课时，用户仍能通过分段和按编号查找快速定位，而不是浏览一条无限变长的卡片列表。
- 保留现有奶油点阵纸、深棕描边和错位阴影、儿童游乐园配色、本地字体及课程进度。
- 保持当前静态 HTTP 站点形态，不增加服务端、账户体系或新路由。

## 信息架构

首页按以下顺序组成：

1. **紧凑页头**：保留“新概念英语 · 互动课件”“英语闯关乐园”和英文副标题，减少首屏高度。
2. **继续学习**：展示一门推荐的未完成编号课程，包括课程图、标题、能力标签、进度和入口。
3. **第一册 · 学习路线**：提供六个 24 课分段票券、上一段/下一段控制、按编号查找和状态说明。
4. **课程站点**：当前分段只渲染或显示该范围内的课程站点；已上线课程可进入，未上线站点明确显示“即将开放”。
5. **番外站 · 专项技能**：独立于 Lesson 路线和分段筛选，展示“音标魔法乐园”等专项内容。
6. **设备进度提示和页尾**：继续说明进度只保存在当前设备。

## 课程目录与扩展边界

首页使用一个明确的目录数组描述可见项目。每个项目至少包含：

- `kind`: `lesson` 或 `special`；
- `lesson`: 编号课程的整数编号，番外篇为 `null`；
- `route`: 已上线课程入口，未上线站点为 `null`；
- `title`、`subtitle`、`art`、`tone`；
- `progress`: 存储键、旧键、关卡 ID、迁移模式和满星数。

编号课程和番外篇从同一目录读取，但渲染到不同区域。新增正课只需增加一条 `kind: lesson` 数据；新增番外篇只需增加一条 `kind: special` 数据。发布新路由仍须按现有发布流程同步 `scripts/course-registry.js`，本次不改变该发布契约。

当前目录包含：

- Lesson 49：肉店大冒险，已上线；
- Lesson 50：挑食小王子大冒险，已上线；
- Lesson 51：希腊四季之旅，已上线；
- Lesson 52–56：仅作为“即将开放”站点，不提供链接或虚构课程标题；
- 番外篇：音标魔法乐园，已上线。

## 推荐课程规则

“继续学习”不能声称知道用户的“上次访问”，因为现有进度没有可靠时间戳。标题使用“继续学习”。

选择规则为：

1. 在 `0 < 星数 < 满星数` 的编号课程中选择星数最高者；
2. 同星数时选择 Lesson 编号较大的课程；
3. 没有进行中的课程时，选择编号最小的未完成课程；
4. 全部已完成时，选择编号最大的已上线课程并显示“再次挑战”。

番外篇不参与编号课程推荐。

## 分段与查找行为

- 固定分段为 `1–24`、`25–48`、`49–72`、`73–96`、`97–120`、`121–144`。
- 首次加载时选中包含推荐课程的分段；当前数据会落在 `49–72`。
- 点击分段票券只改变课程站点区域，不影响“继续学习”和“番外站”。
- 上一段/下一段在边界处禁用；分段按钮使用 `aria-pressed` 表达当前状态。
- “按编号查找”只接受 1–144 的整数：
  - 已存在站点时，切换到对应分段、滚动并聚焦该站点；
  - 合法但尚无站点时，切换到对应分段并提示“Lesson N 还未加入目录”；
  - 空值或非法输入时提示“请输入 1–144 的 Lesson 编号”。
- 提示区域使用 `aria-live="polite"`，查找不进行页面跳转。

## 视觉与响应式约束

- 桌面基准为源图的 1001 × 1570 像素构图；实现 QA 使用 1280 × 2006 CSS 像素视口/全页截图进行等比例比较。
- 页面最大内容宽度约 1040–1080 像素。
- 课程站点在宽桌面呈五列路线网格，与选定高保真稿的五站首排一致；中等宽度降为三列。使用轻量虚线路径连接，不遮挡内容或焦点环。
- 推荐区为左图右文；番外站为独立橙色强调区。
- 760 像素以下：推荐区和番外站改为单列，分段票券可横向滚动，课程站点改为单列，装饰路线隐藏。
- 沿用本地 `Baloo 2`、`ZCOOL KuaiLe` 和系统中文字体，不请求第三方字体。
- 课程插画使用项目内透明 PNG 资产；不以占位框、手绘 SVG 或临时 CSS 图形代替。
- 保留 `prefers-reduced-motion`，并为链接、按钮和输入提供清晰的键盘焦点环。

## 状态与错误处理

- 本地存储不可用或数据损坏时，继续使用现有 `CanranCore.storage.loadProgress` 的归一化结果，首页仍可访问。
- 空分段显示“这个分段还没有开放课程”，不创建不可点击的假链接。
- 未上线站点使用非链接元素并显示“即将开放”。
- 脚本运行前，页面保留基础标题和导航语义；脚本完成后生成完整目录并更新进度。

## 测试与验收

- E2E 验证 Lesson 与番外篇位于独立区域，且所有已发布路由仍只有一个入口。
- E2E 验证首次分段为 `49–72`、分段切换和空状态。
- E2E 验证查找已上线、未上线和非法编号的行为与焦点。
- E2E 验证推荐课程由真实进度选择，而不是固定 Lesson 49。
- 现有首页进度、路由、字体、烟雾和部署测试必须继续通过。
- 在桌面和移动视口检查无横向溢出、操作可达和内容不裁切。
- 最终必须把源图与浏览器截图放入同一张对比图，修复所有 P0/P1/P2 差异，并在项目根目录生成 `design-qa.md`，其 `final result` 为 `passed`。
