# Lesson 51 发布修复设计

历史设计 · 2026-07-31 已确认。基线：`main@8690d7dadbef2bfdc60e08dfd512d4f662374c42`。

目标：让 Lesson 51 完整进入课程清单、静态构建、进度、音频和发布检查。

## 主要规则

- 公开课程统一登记，缺少登记的课程目录不能进入发布包；页面、音频、说明和路由同时覆盖。
- 进度使用 `canran:l51:progress:v2`，五关各 0–3 星，只保留最高评级。旧 `l51-stars-v1` 总数不推算分关成绩。
- 错后改正可以完成题目，但不再获得首答分。
- 连续播放只在当前一轮最后一句正常结束时授予课文完成；停止、取消、失败与旧回调都不能发奖。
- 字体和音频随站点提供，不扩展外部运行时依赖。
- 线上检查先比对发布清单，再逐个核对文件、路径、大小和响应头。`/home` 三种旧地址检查跳转，兼容文件本身在发布前核验。
- 持续集成使用只读权限、固定工具版本和明确依赖来源。
