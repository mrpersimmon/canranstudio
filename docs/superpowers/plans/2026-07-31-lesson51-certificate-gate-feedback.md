# Lesson 51 缺星提示计划

历史计划 · 2026-07-31。本文保留当时目标与完成标准，不代表今天已经测试或上线。

让孩子点击尚未解锁的证书时，知道还缺什么，并能主动跳到未完成关卡。

## 主要工作

1. 保留可点击的证书入口。
2. 点击后显示缺少的任务、前往补练和稍后再说。
3. 打开、取消、跳转时正确移动和恢复键盘焦点。
4. 打印前再次检查资格。
