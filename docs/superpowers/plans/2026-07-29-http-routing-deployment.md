# 路由与发布计划

历史计划 · 2026-07-29。本文保留当时目标与完成标准，不代表今天已经测试或上线。

让项目目录与访问地址一致，发布包可核对，出错后可以恢复。

## 主要工作

1. 首页放在根目录，Lesson 49 移到 `lesson49/`，`/home/` 作为兼容跳转。
2. 只把明确允许公开的文件打包到 `dist/`。
3. 发布清单记录提交号和每个文件的校验值。
4. 检查路由、响应头和线上文件是否与本地发布包一致。
5. 发布时保留旧版本，通过切换当前版本入口启用新内容；失败时恢复旧版本。

## 状态与后续变化

原计划使用裸 IP HTTP。该传输方案已退出使用，当前配置转向正式 HTTPS 域名；不要执行原文中的旧 HTTP 命令。
