# 统一证书提示实施计划

历史计划 · 2026-08-01。本文保留当时目标与完成标准，不代表今天已经测试或上线。

让各课共用缺星提示，编号课统一为 15/15 星，音标课为 12/12 星。

## 主要工作

1. 建立共享 `core/certificate-gate.js` 和对应样式。
2. 依次接入 Lesson 51、49、50、54 和音标课。
3. 入口始终可操作，缺星时显示还差多少、第一处补练位置和取消按钮。
4. 跳转音标游戏时同步切换对应标签。
5. 领取、保存、打印前重新读取并检查资格。
6. 检查损坏数据、键盘、焦点、窄屏和发布包。
