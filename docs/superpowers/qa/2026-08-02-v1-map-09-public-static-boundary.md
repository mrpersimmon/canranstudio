# V1 Map 09 公开静态发布边界

## 结论

Map 09 把“公开、可索引、可直达、纯静态”从产品约定升级为构建与浏览器发布门。
候选版本只有同时满足课程目录、学习地点、同源录音、公开元信息、无凭证入口、无应用
服务、无 Cookie、无隐藏设备身份和无分析事件时，才能生成绑定当前 `HEAD` 的静态发布包。

这份证据只证明本地发布就绪，不执行提交、推送、合并、部署，也不改变 ICP、DNS、TLS
或当前接受的 HTTP origin。

## 自动发布门

完整本地命令：

```text
npm run verify:v1:release
```

该命令按顺序执行：

1. 稳定规则与共享运行时单位测试；
2. 全部 Playwright 课程、地图、音频、证书、字体、移动端和路由回归；
3. 课程目录、学习地点、静态构建、Nginx、在线验证器与公开 V1 边界合同；
4. 从干净公开输入生成静态目录和 `release-manifest.json`，并绑定精确提交 SHA。

`scripts/public-v1-boundary.js` 现在是静态构建的一部分，而不是仅在测试中旁路检查。
它会拒绝：

- 缺少 HTML5、`zh-CN`、UTF-8、设备视口或描述性标题的首页与课程页；
- `noindex`、`nofollow`、刷新跳转、密码 / 邮箱 / 手机号输入和授权 / 登录入口；
- 跨域脚本、样式、图片、音视频或表单依赖；
- `fetch`、XHR、WebSocket、EventSource、Beacon、Service Worker、IndexedDB 或会话存储；
- Cookie、认证令牌、应用服务端点、分析运行时和隐藏身份字段。

负例测试证明上述门禁会拒绝应用 API、分析 Beacon、认证 Cookie、隐藏访客 ID、
Service Worker、跨域依赖、`noindex`、刷新入口和凭证表单。课程发布合同还会在录音目录
存在但页面只使用语音合成时失败，因此浏览器语音降级不能冒充正式同源录音。

## 浏览器可观察证据

`tests/e2e/public-v1-boundary.spec.js` 从真实静态服务器验证：

| 发布边界 | 浏览器证据 |
| --- | --- |
| 公开直达 | `/` 和课程目录中的六条已发布课程路由直接返回 200，URL 不经过登录或隐藏入口 |
| 可索引元信息 | 每页保留 `zh-CN`、UTF-8、设备视口、描述性标题，并且页面及响应均未声明 `noindex` / `nofollow` |
| 无凭证入口 | 没有密码、邮箱、手机号、一次性验证码输入，也没有授权码、学习码、邀请码或登录文案 |
| 纯静态网络 | 页面加载不发生 fetch、XHR、WebSocket、EventSource、Beacon 或 Service Worker 注册；浏览器请求保持同源 |
| 无身份与追踪 | 没有 Cookie；本地写入只允许统一课程目录声明的进度键和单档设备冒险档案，值中没有用户、儿童、设备或访客 ID / token / UUID |
| 正式音频 | Lesson 49、50、51、52、54 与音标课在用户点击前不尝试录音或语音合成；点击可见播放控制后只使用各课程自己的同源 `.mp3` |

本轮修正了音标课两个听辨游戏进入页面后自动尝试播放的问题。现在题目仍会准备好，但录音
只在孩子点击“听一听”后播放；既有中断、播放状态和语音失败反馈回归继续保留。

## 既有发布面

统一课程目录和静态构建继续负责以下内容：

- 首页冒险地图、课程目录、Lesson 49 已发布地点底图、五层成长图、故事纪念物和移动预览；
- Lesson 49、50、51、52、54、音标课及 Lesson 49 课堂投屏的直接静态路由；
- 每个已发布课程的同源预录音频目录；
- 不完整学习地点不能进入 `published` 状态，未注册 Lesson 不能进入构建；
- 字体、音频生命周期、评分、证书、HTTP/Nginx 路由和精确 SHA 发布清单。

## 人工证据边界

真实微信内置浏览器、iPhone Safari 和 Android Chromium 仍必须执行
[`docs/mobile-release-smoke-checklist.md`](../../mobile-release-smoke-checklist.md)。当前状态仍是
`HUMAN_REQUIRED — 待执行`，桌面 Chromium 和自动化测试不能替代，也不得写成“已通过”。

真机只使用空白演示浏览器，不导入或记录真实儿童姓名、账号、设备唯一标识或学习数据。
当前 HTTP 的传输与 origin 连续性风险仍按既有决定接受；HTTPS、账号和云端权威记录属于 V2。
