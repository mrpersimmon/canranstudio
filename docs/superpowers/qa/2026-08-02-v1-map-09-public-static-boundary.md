# V1 公开静态网站检查记录

历史检查 · 2026-08-02。只描述本地发布检查，不证明已提交、推送或上线。旧 HTTP、投屏和课程目录说明已被后续版本替代。

## 检查什么

V1 的首页和课程可直接打开，无登录、授权码、Cookie、身份追踪或应用服务。页面具备语言、编码、视口和标题；字体、图片、正式录音均与网站同源。

构建脚本检查公开边界，并用错误示例确认它会拒绝外部资源、认证表单、身份字段、分析请求、不允许的后台通信和错误索引声明。音频目录存在但页面只用语音合成，也不能通过。

当时修复了音标课两个听辨游戏在打开页面时自动尝试发声的问题，改为孩子点击后播放。

## 结果如何使用

完整本地入口为 `npm run verify:v1:release`，生成绑定提交号的发布包。检查通过不等于发布完成，也不代替儿童试用。

真机仍为 `HUMAN_REQUIRED — 待执行`，见[真机检查](../../mobile-release-smoke-checklist.md)。当前 HTTPS 发布操作见[发布指南](../../../deploy/README.md)；原始范围和旧限制见[原文备份](../../archive/2026-09-17-docs-before-simplification.zip)。
