# 线上校验器带宽校准

## 现象

Lesson 51 候选版本完成原子切换后，默认线上门禁在多个大型 PNG 与字体文件上报告 10 秒超时。发布流程随即将 `current` 回滚到保留的上一版本，没有把未通过线上门禁的候选称为已发布。

## 根因对照

上一线上版本使用原默认值（8 路并发、每个资源 10 秒）验证时，45 张既有地图图片同样超时。将同一份上一版本清单改为 2 路并发、每个资源 60 秒后，597 个页面、脚本、图片、字体与音频资源全部通过精确响应头、路径、大小和 SHA-256 校验，耗时 276 秒。

因此，失败来自发布校验器的带宽假设，不是 Lesson 51 文件损坏。新的默认配置只调整并发与超时，不放宽哈希、大小、同源、HTTP 响应头、重定向或发布清单约束。

## 发布口径

- 默认并发：2；
- 单资源超时：60 秒；
- 单资源上限：8 MiB；
- 线上候选仍必须通过完整 `npm run verify:live:http`；
- 地图图片体积优化仍属于后续移动端地图画布重构范围，不能用更长超时掩盖真实用户体验问题。
