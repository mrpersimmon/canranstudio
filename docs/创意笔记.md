# 创意笔记

## 2026-11-27　让学生用英语决定故事接下来发生什么

**首选试课是 Lesson 31–32《花园号外》**，拟占用现有应用环节约 90 秒。花园课的五组题库共收录 51 个条目。学生先辨认谁在爬树，再补全 Tim 正在做什么，挑战中还会遇到谁坐在树下。可以把已经听懂的事实交给孩子，让他用这些事实解决一个新问题。[当前花园课程](../unit31-32/content.js)

### 《花园号外》的一屏样板

校报编辑收到一张只拍到两条尾巴的照片，稿子上写着「猫在追狗」。他把稿子推给今天的小记者，问：“这条新闻能发吗？”

1. **采访目击者。** 学生选 *Where’s Sally?*，镜头移向树荫。选 *Who’s climbing the tree?*，镜头抬高，Tim 从树叶后面探出头。两个问题都成立，各自带来不同消息。
2. **排演刚才听见的事。** Jack 说 *It’s running after a cat.* 学生点两下，安排哪只动物跑在前面、哪只追在后面。把位置放反时，眼前就会上演“猫追狗”。学生可重听录音、交换位置，再看自己的句子演一次。
3. **给头版署名。** 同一张照片可以配 *The dog is running across the grass.*，也可以配 *The dog is running after a cat.* 前一句写地点和路线，后一句写追逐对象。学生挑自己想报道的发现，看到署着自己名字的头版。

摄影玩法借鉴《New Pokémon Snap》中观察动作、亲自选照片收入图鉴的体验。花园样板优先复用现有插画、人物、原声和词块，沿用原题评分、学习记录及原纪念卡。[游戏官方的摄影图鉴介绍](https://newpokemonsnap.pokemon.com/en-ca/create-photodex/)

### 三种不同的课堂角色

| 课程与构想 | 学生能做的事 |
| --- | --- |
| Lesson 1–2《让大人再说一遍》 | 学生演女士。男士问起手提包时，学生随时可以点 *Pardon?*。男士停下来，举起包，再说一遍。学生可以用这句话掌握对话节奏。 |
| Lesson 3–4《今天你值失物招领班》 | 客人认得自己的伞，学生能看见柜里的伞。学生可以直接递伞，也可以先举起一把问 *Is this your umbrella?*。递错时客人会说 *This is not my umbrella.*。下一轮交换角色，由学生纠正拿错伞的大人。 |
| Lesson 143–144《树林里的听证会》 | 镇长提议再立一块告示。学生可以支持，也可以追问“原来那块告示为什么躺在垃圾堆里？”从原文挑两条证据，给镇长写一份建议。 |

失物招领借用教学中的“信息差”。双方各自掌握对方需要的信息，提问有了实际用途。[British Council 的课堂信息差示例](https://africa.teachingenglish.org.uk/skills/tips/increasing-speaking-class)

### 让小镇记住孩子

认领过雨伞的客人可以隔几课再从商店门口探出头，举着另一把伞问 *Is this yours?*。孩子先认出人物，再自然地用上以前学过的表达。

### 试课时观察什么

- 头版印出来后，孩子会不会主动提出“我还想拍另一张”？记下是谁先提议再玩，以及他想换什么。
- 换一张从未见过的动物图后，孩子能不能自己用英语说清“谁在追谁”？把独立表达和听完提示后的表达分开记录。
