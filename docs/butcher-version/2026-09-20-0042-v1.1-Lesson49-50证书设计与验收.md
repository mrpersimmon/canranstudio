# Lesson 49–50 证书设计与验收

已在 `codex/butcher-version` 本地实施。预览：[我的单元证书](http://127.0.0.1:4175/unit49-50/#learn/certificate)。本次只调整组合单元的领奖体验；原 Lesson 49 的证书、题目和通关条件保持原样。尚未提交、推送或发布。

## 设计变化

原证书主要是星星和文字，孩子的名字不突出，保存的图片也缺少页面中的设计。现在把它做成一次采购冒险的纪念：

- **孩子是主角**：名字居中放大，称号为“晚餐采购小达人”。肉店老板和伯德夫人站在两侧。
- **看得见完成了什么**：五枚彩色徽章对应五关，配上“15 颗星 · 五关完成”。领取前也能看到已集齐与待完成的徽章。
- **保持现有画风**：复用课程中的人物与图标，保留奶油色纸面、棕色描边和肉店条纹。
- **领奖有一点仪式感**：打开时短暂浮入；系统要求减少动态效果时直接显示。
- **方便留下来**：保存图片与打印证书并排展示，使用同一组人物、文案、名字、徽章和日期。图片为 1440 × 1100，打印适配一张 A4。

日期表示首次领取日，重开证书会保留。空名字使用“采购小学徒”；较长名字在手机上改为整行展示。证书只记录本单元练习完成，不宣称孩子已经独立掌握全部知识。

## 实际验收

2026-09-20，本轮 **17 项页面行为检查通过**，没有运行单元测试或发布检查。

| 范围 | 实际结果 |
| --- | --- |
| 原单元流程 | 从空记录完成全部 81 道基础题和 11 段故事；最后主动结算才解锁证书。旧课进度不会代替单元进度。 |
| 领取与重开 | 名字和首次领取日恢复；空名字有默认称呼；关闭、Esc 和焦点返回正常。 |
| 响应式布局 | 320、390、768 像素下长名字不横向溢出，保存与关闭可操作；桌面预览已人工查看。 |
| 保存图片 | 真正触发下载，检查 PNG 格式及 1440 × 1100 尺寸，并查看实际图片。 |
| 加载失败 | 人物图加载失败时不生成残缺证书，显示重试提示；恢复后能保存。 |
| 打印 | 生成的 PDF 为一张 A4，仅含证书；打印画面保留名字、人物和徽章。未连接实体打印机。 |
| 动效 | 浏览器实际开启“减少动态效果”后，证书无动画且完整可见。 |

回归先在旧设计上确认新标题和徽章检查失败，再实施新设计。视觉复查发现长名字挤成竖列，以及全局页脚样式带来多余留白和透明度；均已修正。短视口内证书可滚动，关闭与保存区域保持可用。

测试准备通过页面操作完成整个单元后保存浏览器记录，不伪造答题或完成标记。测试中的“减少动态效果”改为显式设置并检查实际样式；加载恢复后的真实图片下载允许 15 秒等待。最终组合运行无失败项。
