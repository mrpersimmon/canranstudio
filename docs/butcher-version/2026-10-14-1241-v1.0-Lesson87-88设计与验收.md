# Lesson 87–88 · 修理厂里的进度单

2026-10-14 12:41 · codex/debug-grammar-v2 · 依据[统一标准v1.49](publish/2026-10-14-0013-v1.49-教学单元设计标准与验收清单.md)。无配音课堂配套版；五个答题区、五颗星。以下先记录设计，验收完成后补实测结果。

## 教材与边界

- 课本纸页178–181／PDF211–214：保留13轮原文、7个新词；88课4组完成情况→过去时间的问答、12组不规则动词、书写A6／B10及原例。
- 《同步导学》Grammar纸页152／PDF166：现在完成时与一般过去时的构成、表达重点、时间语境；兼顾过去持续到现在的用法。按“不同例子短示范→立即练→撤去示范→综合独立检验”展开。
- 《语法练习册》纸页248–252／PDF262–266：动作完成与仍在进行、过去式／过去分词、完成后追问具体时间。题目明确给出维修状态，不能根据开始时间擅自判断是否做完。
- Wood三天前送来LFZ 312 G，撞到了灯柱；工人仍在尝试修理。两人在接待处交谈，再进入车库；不添加修好、购车、受伤或责任归属的结局。“Well, it was my car.”体现看见车况后的反应，不理解成已卖给别人。
- 时态表示叙述重点，不等于现实有无影响。撞车这个过去事实仍可影响现在；for也能出现在已经结束的过去经历中，不能只凭一个时间词判时态。this morning明确给出当前是下午。

## 视觉与材料

修理厂接待台与室内车库组成两处相连场景。Wood为灰色卷发、细小胡须、梅紫背心和浅褐外套；接待员为深发、蓝帽与青绿工作马甲，手持进度夹板。人物延续认可纪念卡的圆润描边风格，先生成双人近景，再生成同身份、面向彼此的全身像。

车库展示同一辆有凹痕的青绿色车，避免危险事故动作。对白始终在场景内，转场不改变舞台高度，人物、手和道具完整可见。参考区保留4组问答、12组动词与课后原题。沿用统一字体、结算三卡、纪念册与动图。
