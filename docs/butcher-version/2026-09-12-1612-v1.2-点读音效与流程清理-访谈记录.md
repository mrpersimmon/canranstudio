# v1.2 点读、音效与流程确认

2026-09-12 16:12 的历史记录；以下实施和测试状态均指当时。

用户要求移除课堂投屏、点击词卡即发音、统一 mutton hotpot 声音、给末组词卡明确下一步，并使用参考分支的反馈音。收到执行汇总后，用户回复“可以执行”。

确认范围：

- 删除投屏入口、页面、专用代码与配置。
- 只让词卡整卡点读并翻面；答题选项只负责选择。新点读中止旧朗读。
- mutton hotpot 使用同文的本地录音。
- 末组词卡连接听辨主线。
- 新判对、判错、活动完成各有音效；普通选择、提示、继续和恢复静默。

调查发现点卡原来只翻面，短语音频映射为空而使用系统朗读，末组只会禁用下一组，缺少衔接。实装与复现防护见[实施验收](2026-09-12-1659-v1.2-点读音效与投屏清理-实施验收.md)。
