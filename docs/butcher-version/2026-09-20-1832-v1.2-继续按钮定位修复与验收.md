# 继续按钮定位修复与验收 v1.2

时间：2026-09-20 18:32。分支：`codex/butcher-version`。本次完成本地修复和页面检查，未提交、推送或发布。

## 按钮应该做什么

“继续冒险”回到上次访问或操作的学习位置；活动末尾的“下一站”进入下一个活动。Lesson 49–50 的“继续采购”遵循相同规则。继续不清除答案或星星，也不自动完成下一题。

## 原问题与原因

打开 Lesson 1–2 的 `#l3`，手动滚回封面，再点“继续冒险”。地址仍是 `#l3`，页面却停在封面。现场记录中，点击前后滚动位置都是 0，目标章节顶部距屏幕顶部约 2945 像素。

保存的位置和按钮点击均正常。定位原来只依赖地址变化：给地址重复赋同一个章节，不会产生地址变化事件，滚动也就没有发生。Lesson 49–50 使用相同写法，有相同问题。

原检查通过重新打开 `#cover` 再继续，地址确实发生变化；没有覆盖“手动滚回封面，但地址没变”，部分检查也只验证地址，没有检查章节是否出现在屏幕上。

## 修复与防御

- 两单元跳转到相同地址时，也明确执行页面定位；不同地址继续沿用原路由。两处页面脚本引用更新，避免继续使用缓存中的旧脚本。
- 保留学习草稿、星星和内容版本，不重置作答；重复继续不新增相同地址的历史记录。
- 新增 [12 项页面回归](../../tests/e2e/unit-resume-scroll.spec.js)：两单元、根路径与 `/lesson/`、390 与 1280 像素、重复继续、手机下拉导航、浏览器返回、键盘回车、未提交选择及刷新恢复。
- 对照 Lesson 49：它原本主动执行定位，本次页面验证通过，无需改动该课路由。
- [现行标准](2026-09-22-1850-v1.18-教学单元设计标准与验收清单.md)和[测试说明](../../tests/README.md)加入“目标标题必须进入可视区域”的验收要求。
