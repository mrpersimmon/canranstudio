## 原因与本次边界

21–22 和 23–24 的人物直接复用了完整站姿；25–26 和 27–28 的 Mrs. Smith 直接复用同图；19–20 的妈妈使用了另一个文件，但头部、裙装和抬手轮廓仍太接近 Mrs. Smith。先前把画风共用扩展成完整人物复用，逐课看图又未进行跨课对照。问题在设计取舍和验收遗漏，不是课程必须复用同一批人。

本次先更新统一标准，再优化上述五课的人物与道具配合；保留题稿、原文顺序、判分、音标、反馈音、无配音模式和学习记录。17–18、29–30 作为周边参考，不在本轮重画范围。未授权提交、推送或发布。

## 角色与画面设计

延续深棕描边、柔和低饱和颜色和现有字体；舞台、词卡与证书布局沿用。差异从剪影、头部、衣装结构及动作产生，不依赖换底色。

| 单元与角色 | 身份依据／稳定特征 | 本次优化及状态 |
| --- | --- | --- |
| 19–20 Mum | 教材中的孩子妈妈；没有与 Mrs. Smith 为同一人的依据 | 独立的短卷发、宽脸与裤装短外套；关照、邀请坐下、提出冰淇淋请求和交接后各有恰当姿态。 |
| 21–22 Jane | 与 23 的 Jane 采用连续角色设计，保留侧马尾、长脸和领口 | 思考确认时手在身前，提起单本书时单手支持；交接后回到自然姿态。 |
| 23–24 Jane | 同上 | 托一组杯子用双手，站姿更稳；不能复制拿书动作。 |
| 21／23 Man | 教材未命名；采用同一位男士是视觉改编假设，不作为教材事实或考点 | 保留眼镜、胡须与背心；21 用指示与单手接书，23 用不同指示与双手接托盘。 |
| 25–26 Mrs. Smith | 与 27 的房间主人延续同一身份，保留头部特征 | 厨房形象用围裙与身前自然手势。课文依然是房间叙述，不添加说话人。 |
| 27–28 Mrs. Smith | 同上 | 客厅形象用开衫裙装与迎接手势，与厨房形象可辨、仍认得出同一人。 |

先完成 19–20 的代表人物和故事关键状态，再完成交接两课与 Mrs. Smith 两个场景的素材。所有引用处跟随各课素材，包括词卡、封面、剧场、完成图、证书和实际保存图。21/23 的道具落点随手势调整，但确认和交接时机保持原课文顺序。
