## 为什么再改

前一轮主要完成无配音、题目去重和可操作性；旧角色与背景未经样板质量对照就直接复用。页面用例与无溢出检查通过，仍留下人物近似、实际尺寸过小、脚悬空、衣帽间环境过简、道具只是独立卡片等问题。因此此前的目视结论不足以证明人物和场景达到 Lesson 1–2 的完成质量。

修改前同尺寸对照：`output/playwright/unit34-visual-comparison/01-unit1-2-scene.png` 与 `02-unit3-4-scene.png`。本次先新增真实页面检查，复现人物比例、站位及只改状态文字而未交到手边的问题，再实施。

## 保留与调整

| 部分 | 决定与用途 |
| --- | --- |
| 人物 | 重绘原有可编辑矢量素材，沿用棕线、简化手绘与柔和色块。客人采用便帽、窄腰马甲与领带；工作人员采用较宽轮廓、衬衫马甲、蝴蝶结与胡须。区分轮廓和服装结构，不单靠换色。人物包装不增加教材事实，不据此考查身份之外的内容。 |
| 环境 | 衣架、挂衣格、门、地板与木质寄存柜台组成可辨认的衣帽间。人物立在地面，工作人员在柜台后方；手机保留人物、主物品和柜台，再给对白独立宽行。 |
| 道具 | 保留教材对应的雨伞、寄存牌和外套图形；放到手边和台面。持伞增加同画风的长柄变体，让伞面避开人物的脸。请求、出示寄存牌、未确认、确认领回有可见变化。确认前不暗示物品归属，错答不交接。 |
| 对白 | 仍保留两侧人物、左右气泡、固定高度历史区内部滚动与逐句中文；桌面与手机分别安排真实空间，正文不挤成窄栏。 |
| 答题 | 继续使用相同的选项、灯泡、检查、重试和结束按钮。桌面选项均衡排布，手机纵排；稳定的场景高度避免作答操作跳动。 |
| 其他使用处 | 封面与结束画面体现同一柜台和交接事件；词卡、证书及实际导出复查共享人物。 |

图片表现不补写教材归属：指出雨伞不是自己的，不表示外套也错，更不能推出雨伞是谁的。故事在 “Yes, it is.” 后领回；柜台练习仅在最后一步正确提交后领回。新题、选中、错答、刷新和重练均遵守此边界。
