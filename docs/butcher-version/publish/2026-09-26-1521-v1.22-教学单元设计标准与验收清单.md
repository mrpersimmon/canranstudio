# 教学单元设计标准与验收清单 v1.22

适用分支：`codex/butcher-version`。标准更新于 2026-09-26 15:21；Lesson 5–6 模式索引更新于 2026-09-25 16:43；单元模式与依据索引覆盖至 Lesson 29–30。

**制作、修改和验收教学单元，以本文为唯一现行共用标准。** 配音版和无配音课堂配套版是两种并列的教学模式，共用内容、视觉、操作与学习记录规则，分别验证声音相关要求。旧 v1.21 及更早版本只供追溯。

继续沿用用户已确认满意的 Lesson 1–2 场景样板：人物有辨识度，题目能组成有意义的任务，对白融入场景，关键道具醒目，完成页回应故事。Lesson 49 继续作为同类题操作与反馈的参考；新单元结合自己的教材设计场景与任务，不复制样板的角色、四步任务或题数。

本版新增综合挑战的目标覆盖表：从真实题干和选项判断测到了什么，再决定题量，避免以两三道抽查代表整课练习。继续沿用改造时的视觉质量门槛：先与已确认样板对照，分别验收功能与画面，不因旧素材存在、模式转换完成或测试通过就判定视觉合格。“课程资源齐全再进入、复访复用缓存”的详细策略由[网页加载缓存设计](2026-09-24-2031-v1.0-网页加载缓存设计.md)单独维护；缓存机制已经在本地实现，按独立文档记录已验证范围；真实移动设备与线上发布不能以本地结果代替。

## 先确定本单元采用哪种模式

| 比较项 | 配音版 | 无配音课堂配套版 |

## 1. 先确定孩子要学会什么

从教材决定学习目标，再决定活动。相邻两课可组成一个完整单元，但不能为了套模板加入无关语法或凑题数。

| 材料 | 必须做到 |
| --- | --- |
| 原文 | 对照教材页图，保留全部句子、顺序、人物及重复句；记录纸页、PDF 页和稳定编号。 |
| 新词 | 全量覆盖。名词配准确图卡；功能词结合本课例句解释，图片只作辅助。 |
| 偶数课练习 | 保留替换、问答、书写等原训练目标。线上优先点选与词块，课堂保留真实对话、自由表达和适量书写。 |
| 改编题 | 写明目标、教材或新情境依据、答案、干扰项理由、反馈、图片及适用的录音。作者信息不出现在孩子的界面里。 |
| 学习结果 | 首次独立、提示后、修正后分别记录。星星和证书奖励完成，不等同于自由口语或独立写作能力。 |

出题与配图共同遵守：

- 单选答案唯一；题干、图片、选项考同一件事。问“谁”就选人物，问“哪个词”才选词。
- 原文事实与另设情境分开。不能从职业猜性别、从拒绝购买猜不喜欢，也不能把题目没有提供的信息当成已知条件。
- 否定某个状态不等于肯定另一个状态，例如“不冷”不能单独推出“热”。教材某个职业人物的状态不代表整个职业；身体、年龄与外貌描述不评价人的好坏，休息不能自动等同于懒惰。
- 物主练习须给出明确归属和说话对象，不能只因某人在场就认定物品是他的。perhaps 等不确定表达不能当作已经确认；同一符号如 ’s 的不同语法用途按完整句子区分。
- 理解题前提供必要材料；听辨前不显示答案。插图、标签、位置和颜色都不能暗示正确选项。
- 目标是理解英语时，核心判断要依赖英文材料；中文用于交代必要场景，不把答案全部翻译后只考常识。提问须区分“直接问某人”与“向别人打听某人”，避免让 you／he／she 都说得通。
- 人称、单复数、指代、词形分别讲。I 是第一人称单数，we 是第一人称复数；一般动词的规则不能直接套到 be、can 等结构上。
- 不把未教的新结构放入必做题。本课解释要说明范围，不能把一次指代写成单词永远只有这一种含义。
- 物品必须画对。例如 pen 与 pencil、dress 与 skirt 应可区分；house 不能变成可拿走的失物。
- Lesson 1 的 Pardon? 是请求重复；Yes? 与 Yes, it is. 的用途不同。不能用同一条笼统解释代替。
- 不为了增加点击量拆碎课文、加入无意义分支，或让低年级默认整句打字。
- 必做题必须遵守下方的去重要求。教材原文中的重复句照常保留；教材覆盖不等于把全部替换组合都做成必做关卡。

### 禁止高度重复的必做题

**同一判断已经覆盖后，不得只换名词、人名、图片、题目标题或选项位置，继续堆成一组必做题，也不得换一个活动名让孩子再做一遍。** 操作保持熟悉，学习任务应有区别；不能用机械换词凑题数、凑关卡或延长学习时间。

先看孩子实际需要作出什么判断，再看题目外观。审题时将普通替换词和装饰场景暂时隐去：如果已知条件、判断步骤、干扰项所针对的错误和所需支持都相同，就先归为同一组，再判断有没有保留必要。仅给每道题写不同的 `target` 名称不能证明递进。

| 情况 | 如何处理 |
| --- | --- |
| 十件物品都选 `Is this your …?`，所有选项只在物品名上不同 | 实际主要是认名词，不能声称逐题都新增了问句训练。词汇已有覆盖时，必做保留代表题，完整替换组放示范、选练或课堂。 |
| “听不清同学”换成“车声盖住朋友”，仍从同一组表达里选 `Pardon?` | 可以作为有计划的复习，不能仅凭场景换皮标成新能力或迁移；不应在多个环节整组重复。 |
| 新词逐词听辨或辨义，或比较不同主语、肯定／否定、已知／未知归属、不同说话人 | 新词本身或改变的条件要求重新判断，可以沿用同一控件；仍要检查是否在前后环节重复覆盖。 |
| 从已教示范到撤去支持后的独立组织，或隔开后的抽样复习、针对错题回练 | 写清撤去了什么支持、复习哪个易错点、出现时机与数量。仅把选择换成拼句不自动算递进；已能拼完整句后，不再强制把同句拆成几道更简单的题。 |

每道必做题的作者记录须能回答：**孩子依据什么信息、作出什么判断；与前题或前一单元相比，增加了什么，或为什么需要复习。** 连同答案和干扰项一起审查，说明“巩固一下”不足以保留一整组同构题。完整替换材料移到示范或选练，不等于删掉教材词汇与训练目标。

综合挑战可以抽样复习已学内容，但不能把前面多个练习换词后整组重做。标为“迁移”的题须说明真正改变的判断条件；没有变化就如实记录为复习，并审查重复总量。相邻单元衔接先看新增目标，不默认让所有孩子重做已学词和旧句型的整套题。

不规定“每隔几题必须换题型”，也不为减少重复引入未教结构、复杂题干或额外操作。必要对比、词汇覆盖与适量复习保留；无新增判断、无必要覆盖、无具体复习用途的重复必做题，**验收不通过**。

三个单元修改前的重复题对见[审查快照](../2026-09-21-0039-v1.0-三单元必做题重复审查.md)，当时的取舍与验证见[整改记录](../2026-09-21-0055-v1.0-三单元练习去重与验收.md)。后续修订后的现行题稿入口见第 10 节。

### 综合挑战必须覆盖核心目标

最终挑战承担本单元的综合复习与检查。先列目标，再决定题量；不能因为前面展示过、练过，便省略课末必要的独立判断，也不把 2–3 道抽查题默认称为全单元综合练习。题量不设统一配额；每课按目标、题干负担和实际儿童走查取舍。

单元文档必须提供下表，逐项对应真实题号：

| 核心目标／必要对比 | 教材依据 | 前面如何学习和练习 | 最终题号及孩子实际要作出的判断 | 线上／课堂分工与范围 |
| --- | --- | --- | --- | --- |
| 本课目标，不只写笼统的“语法” | 原文、词表或偶数课练习 | 区分展示、示范和独立作答 | 必须审看题干、选项、词块及图片，不能只读目标标签 | 未在线上检验的项目须说明由什么活动承担 |

- 每个适合线上检验的核心目标都要有实际作答机会；必要的肯定／否定、人称、形式或意义对比不能只出现一侧。新词在单元中全量教学覆盖，具体词义与功能词语境分别安排；只有展示没有作答的内容须如实记录，综合挑战合理抽样重点和易混词，不再次强制逐词、逐句或整组替换。
- **出现不等于检验。** 给出整块 `an engineer` 让孩子排序，只能记录相应句子组织，不能算作独立选择 a／an。正确选项里的缩写、已经填好的资料及标签同样不能充当对应能力的作答证据。
- 一题可以自然结合多个目标，但不能把大量空格或无关判断塞进一题来虚减题数。需要判断的内容和干扰项应清楚；某个组合答对一次，只证明该任务的表现，不等于各项能力均稳定掌握。
- 将必要的间隔复习与真实条件变化分开记录。熟悉的题型可以继续用；不可把前面整组题换名字照搬。题目尽量围绕本课情境交错安排，不为形式多样新增复杂操作或未教知识。
- 结果继续区分首次独立、提示后、修正后，给出对应的再练方向。星星、完成率及证书只奖励已完成的练习，不宣称全部词汇、自由口语或独立写作均已掌握。
- 无配音版以阅读、词义、语境选择和有支架的句子组织为线上证据。真实听力、发音与自由口语由课堂检验；配音版的播放结束也不能代替相应语言能力证据。
- 扩充挑战时保留经校验的未改题成绩；新增或改写题保持未答，旧完成标记不能让新版直接领证。姓名和原证书日期是纪念信息，独立于当前题量保存，不能反过来用作答题或领证证明；主动“重开本课”才按明确范围清空。题量、末题按钮、暂停续做、缓存升级、本地恢复和登录后换设备都按真实页面验证。

本轮依据见[最终挑战覆盖审视](../2026-09-26-1347-v1.0-最终挑战覆盖审视.md)。Lesson 7–8 按十题实施；Lesson 1–2、3–4、5–6 的[综合挑战补齐记录](../2026-09-26-1655-v1.0-Lesson1-6综合挑战与验收.md)分别为 8、9、10 题；[Lesson 9–10](../2026-09-26-1732-v2.1-Lesson9-10综合挑战与验收.md)为 10 题，补齐问候、回问、告别、完整人称缩写和观察描述。[Lesson 11–12](../2026-09-26-2113-v2.1-Lesson11-12审视优化与综合验收.md)为 10 题，补齐询问主人、物主转换、确认否认、两种 ’s 与归还道谢。[Lesson 13–14](../2026-09-26-2154-v2.0-Lesson13-14场景与综合练习优化.md)为 10 题，补齐邀请、too 的承接、双色描述、颜色问答、两种 ’s 与赞美。各单元按目标取舍而非统一配额。其他单元仍需逐课核对，不因本标准发布自动视为已整改。

### 让题目组成有意义的任务

适合交际情境的练习，围绕一个孩子能理解的目的展开。每步写清“依据哪段英语、需要判断什么、正确后发生什么”。例如 Lesson 1–2 的叫住女士、回应 Pardon?、确认接收者、组织感谢，分别练不同的判断，并共同完成归还手提包的任务。

| 学习目标 | 可采用的呈现 | 取舍依据 |
| --- | --- | --- |
| 礼貌回应、询问与交接 | 连续人物对白、选择回应、点击接收者 | 英语判断推动事件，人物反应与教材语境一致。 |
| 物品、位置与动作 | 看图找物、选择位置或对应动作 | 必须理解英文才能判断，图片与中文不直接替孩子回答。 |
| 指代、人称与类别 | 有明确人物关系的选择或分类 | 关系有材料依据，不能只看头像猜答案。 |
| 组织句子 | 熟悉的词块拼装 | 用于独立组织已经学过的表达，不把已完成的句子再次拆碎凑题。 |

按目标选择合适题型，不要求每课用齐所有题型，也不把所有课程改成“帮某人还物品”。没有交际事件的课文可采用观察、阅读或整理任务，不虚构人物对话。教材完整覆盖、同类操作与默认学习顺序继续遵守第 1、4 节。

审查重复度时，除逐题判断，还要比较相邻单元的角色、场景、主要操作、任务结果和完成奖励。只换标题、配色、角色名字后仍走同一套任务，不算形成了新体验；保留相同练习须说明必要覆盖或具体复习用途。场景变化也不能增加无关小游戏、必经动画或操作门槛。

## 2. 统一什么，允许什么变化

采用“熟悉的操作，有区别的故事与任务”。统一按钮含义、题型行为与反馈；人物、场景、道具、活动呈现及完成结果由教材决定。

| 层面 | 固定规则 | 可变化范围 |
| --- | --- | --- |
| 全站画风 | 抽象人物与物品、深棕描边、圆角语言、现有本地字体 | 人物轮廓、服装结构、发型配件与教材相符的场景 |
| 同类操作 | 选择、检查、提示、继续、重练和反馈规则；配音版另共用播放规则 | 对应教学内容，不另造一套操作 |
| 单元主题 | 同一人物、关键道具与故事状态前后一致 | 场景色、故事环境、任务目的及完成后的呈现 |
| 活动容器 | 题目与操作清楚，层次有主次 | 舞台、图鉴、答题面板、拼装区和领奖区 |
| 作答状态 | 选中、正确、错误、禁用、焦点可识别 | 不随单元主题改换含义 |

中文标题沿用快乐体，英文与数字沿用 Baloo 2 等已有本地字体。正文以易读为先。保持人物画法与物品图标的风格，不在不同单元间切换水彩、写实、像素或三维风格。

网站品牌名称统一为“灿然英语工作室”，页面标题、首页标识与辅助阅读名称保持一致。品牌图标使用 `assets/brand/starflower.png` 的星花图，加载页直接复用同一原图，不另画近似版本；加载方式见独立缓存设计。

主要人物应能通过轮廓、服装结构、发型或配件辨认，不能只给同一个人换衣服颜色。Lesson 1–2 的眼镜长外套男士与戴帽宽下摆女士、Lesson 49 的围裙老板是参考；其他单元依据自己的角色设计。同一教材人物可以跨课复用，同名并不自动表示同一个人物。

人物与场景包装不作为额外教材事实。教材没有给出的姓名、性格、亲属关系或物品归属，不能靠画面暗示后再拿来考孩子。封面、课文、题目、结束画面和证书应能辨认出同一组人物及道具。

同类题在综合挑战里也沿用相同控件。例如配音版挑战中的听辨仍使用同一大喇叭、图卡和检查区；无配音版挑战中的词义题沿用词义练习的控件。可以改变挑战标题周围的场景提示。

### 改造前先确认画面质量，不默认旧素材合格

任何新单元或改版都要先查看实际页面。已确认的 Lesson 1–2 提供的是完成质量的参考，不是要求每课复制它的街角、人物或任务。无配音改造、内容去重和功能修复同样不能跳过画面验收。

1. **先对照，再决定复用。** 在相同屏幕尺寸、相近活动状态下，截图对照目标课与已确认样板。单元记录列出人物、背景、关键道具、对白和完成结果分别保留、调整还是重画，以及原因。不能仅因目录中已有素材就写“沿用”。
2. **人物要在实际尺寸下认得出。** 至少通过轮廓、发型／配件、服装结构形成区别；不能只是同一身体换颜色。缩到手机仍能看清脸与角色特征，不能靠大预览掩盖页面里人物过小。职业特征只用来识别角色，不作为性别、性格或能力判断。
3. **场景要能解释人物在做什么。** 衣帽间应看得出挂衣区、寄存柜台和活动空间；不同场景依据本课需要设计。脚落在同一合理地面上，遮挡有前后关系。不能用几根装饰线代替环境，也不能把人物悬在空中、把物品放进无关卡片充当交接。
4. **关键道具必须参与事件。** 在手边、台面或实际目标位置出现，大小足够辨认。事件前后改变物品位置、人物姿态或可见状态；仅改一行“已领回”文字不算完成画面设计。道具只有在原文明确确认或用户正确提交后交接，选择、错答、未知归属均不能提前发生。
   **对白换了对象，画面也必须换对象。** 编写分镜时逐句列出物品身份、摆放和交接时机：同一物品换位置要保留特征；拿出另一件要有可辨认的区别和收回／拿出过程，不能只让同一件原地变色。颜色搭配花纹或形状帮助辨认，但教材未给出的包装细节不作为教材事实或考点。Lesson 3 的两次否认、第三次确认见[雨伞分镜](../2026-09-25-1607-v2.2-Lesson3-4雨伞叙事与验收.md)。
5. **先做完整的一小段。** 先完成一个代表场景的初始、线索／错答、正确结果和结束状态，再应用到封面、课文与其他使用处；避免最后才发现人物、背景和对白无法共存。留白服务阅读与主次，不能因为隐藏音频或删掉说明留下大块无用途空白。

角色与道具的尺寸不规定全站统一像素值；按手机和桌面的真实页面判断。示范画面、课堂材料与答案选项的用途不同，不能为突出道具而突出某个未选答案。改素材时检查全体引用处，包括词卡、封面、证书及实际导出图。

## 3. 背景、颜色与容器怎么用

### 颜色各司其职

背景表达“在哪个故事里”；按钮表达“可以做什么”；反馈表达“刚才发生了什么”。主题色不能覆盖状态色。

| 用途 | 规则 |
| --- | --- |
| 全站基底 | 以暖白或浅奶油纸面承托内容。页面纹理克制，题干和选项后方保持安静。 |
| 主操作 | 推进、检查和继续沿用明确的绿色主按钮；封面开始入口可沿用珊瑚红。主次关系不随主题变化。 |
| 次操作 | 重听、返回、重练、帮助用次要按钮；浅底棕边为常用方案。无需把所有次操作都涂成橙色。 |
| 播放与线索 | 配音版的听辨大喇叭和两种模式的灯泡保留熟悉的暖黄色提示；灯泡不能与主操作争抢注意。 |
| 作答反馈 | 正确绿色、错误红色、当前题黄色描边、未答对灰色。结合文字、图标或边框，不能仅凭颜色辨认。 |
| 选项 | 同一道题中所有未选选项使用同等底色、边框和尺寸待遇；不能随机涂成不同颜色或突出正确项。 |

必须检查文字与底色的对比、选中边框、焦点和禁用状态。不能因背景变浅就把文字、边框也淡到难以辨认。

### 两个单元的主题方向

下表结合 2026-09-20 的主题方向与 2026-09-24 已确认的 Lesson 1–2 实际样板。颜色是实施起点，最终仍需结合文字对比和真实页面检查调整。

| 项目 | Lesson 1–2 礼貌小帮手 | Lesson 49–50 晚餐采购大冒险 |
| --- | --- | --- |
| 氛围 | 清爽、轻快的相遇与日常物品 | 温暖的商店与采购 |
| 场景底色 | 淡蓝 `#EAF3F8`、暖白 `#FFFDF8`，少量浅杏点缀 | 暖桃 `#FCEBDD`、奶油 `#FFF8EE`，少量砖红 `#C45D46` |
| 主题元素 | 街角相遇、可区分的两位人物、珊瑚红手提包与金色搭扣 | 店铺招牌、柜台、食品、采购物品 |
| 使用边界 | 不沿用肉店红白遮阳棚；不提前把手提包归给某个人 | 红白条纹可用于店铺舞台，不铺到所有练习容器 |
| 保持不变 | 抽象画风、文字可读性、操作区和题型规则 | 同左 |

### 按活动选择容器

| 活动 | 推荐处理 | 应避免 |
| --- | --- | --- |
| 小剧场 | 连贯的场景中放清楚的对白气泡；对白外层轻量或透明，气泡用不透明浅纸面承托英文 | 用大块白色面板遮住整个舞台；复杂窗框、花纹穿过文字；每课照搬同一场景 |
| 图鉴、表达卡 | 像整理好的收藏页；可点击卡片清楚，大容器减轻边框与阴影 | 大框、小框、卡片层层使用同样粗重的描边和阴影 |
| 听辨、单选 | 干净的答题面板；题目、主要入口、选项、反馈、操作顺序清楚 | 花纹穿过文字或选项，给不同选项不同主题色 |
| 拼句 | 已选区和待选区结构清楚，词块像可拿起、可放回的小块 | 只换背景色，却让拼句位置或撤回方式与其他课不同 |
| 结束与证书 | 名字、已获得徽章和完成感突出；庆祝集中在完成时刻 | 每次选项点击都触发大动画，或未完成就显示已获得奖励 |

外层容器先用间距、分组、浅底色和细分隔；需要时再加边框。点击卡片、按钮可以保留更明确的描边和下沿，避免背景框看起来比按钮更能点击。

进入单元时，场景区别可以明显；专心答题时收敛装饰；完成后增强认可感。不为主题增加走地图、开门、找人物等必经操作，也不增加与教学无关的功能。

### 对白与关键道具

- 对白以英文为主，人物名为辅；短句用紧凑气泡，长句自然换行。气泡角或左右位置帮助识别说话人，不将每句都做成高大的功能卡。
- “看中文”是较轻的次要按钮，仍有清楚的边框、焦点和至少 44 像素的触控入口。减轻视觉重量不等于缩小到难以点击；无配音版不添加喇叭或点读样式。
- 宽屏可用两侧人物与中间对白；窄屏优先给英文整行空间，将人物放在下方两侧。对话区保持内部滚动，人物、必要道具与下方操作不互相遮挡。
- 关键道具要在实际显示尺寸下可辨认。先减少图标内部留白，再调整尺寸、轮廓、颜色与周围留白；窗框、长椅等背景降低对比。不能只放大一个留白很多的图片框。
- 同一物品在等待、选中、交接和完成时保持外形一致；场景中心的重点展示与拿在手里的尺寸可以不同，但不能遮住表情、名称或让人物轮廓难辨。动作遵守当前剧情，不能提前把待确认的物品画在正确人物手里。
- 突出剧情道具不能变成突出正确选项。同题各选项的图片展示尺度、边框和背景待遇一致，不给正确项单独加光圈、尺寸或颜色。

### 已确认的实际样板

Lesson 1–2 的[场景与任务设计](../2026-09-24-0121-v2.0-Lesson1-2场景样板与验收.md)、[对白与道具优化](../2026-09-24-1312-v2.1-Lesson1-2对白与道具优化.md)及其中的实际页面截图，是本版的视觉与任务参考。2026-09-24 用户已明确确认本地效果满意。

新单元借鉴这些原则，并展示自己的短句、长句、作答前后与完成页接受检查。旧双单元视觉对照稿保留在 [v1.17 历史标准](../2026-09-20-1325-v1.17-教学单元设计标准与验收清单.md)，不作为强制复刻布局。

## 4. 页面与题型操作

### 默认学习顺序

沿用 Lesson 49 的学习顺序：**词汇小图鉴 → 词汇练习 → 课文阅读／小剧场 → 课文理解 → 表达与句型练习 → 综合挑战 → 证书**。配音版的词汇练习可用听辨；无配音版采用词义、语境或看图任务，不能仍标成“听音寻宝”。活动可按故事命名；教材没有的目标不额外添加。特殊教学顺序需要明确依据，不随换主题或扩课自行改变。连续叙述课文采用阅读导览，按原句顺序呈现，不为套用双人舞台而虚构说话人。

首次从首页或封面开始，进入图鉴。图鉴供自由浏览，不要求逐张点击刷进度；整卡是否同时发音按本单元模式处理。导航、页面顺序、活动结束的“下一站”和证书徽章顺序一致。已有记录继续原位置，单纯换序不清除答案、星星或证书；旧章节链接仍指向原来的内容。

### 同类活动的操作

采用连续长页、章节导航和每项练习的当前题。导航供回看；“下一站”由孩子主动点击。每一站有清楚名称，不用长说明替代界面本身。主界面保留必要题干与操作信息，删去“听完了，准备好再选择”等没有帮助的重复说明。

| 类型 | 必须一致的操作 |
| --- | --- |
| 词卡 | 正面保留大图、英文和下方较小的配套音标，音标默认可见；点整卡翻看词义，再点返回正面。配音版同时点读，无配音版只翻看。前后组是按钮，首组禁用上一组，末组提供下一站。无“教材词／补充词”等编写标签。 |
| 词汇练习 | 题干给足作答依据，选项组居中，主动检查与继续。听辨入口与播放门槛见第 6.2 节；无配音词义与看图题见第 6.3 节。 |
| 课文 | 完整保留原文。按教材人数与叙述形式安排舞台；双人对话在宽屏可用两侧人物，窄屏按第 3 节给对白让出宽度。固定高度对话区内追加历史句，只滚动内部。 |
| 历史原文 | 旧句在同一对话区回看，中文按句开关，不另设重复的“已听原文”区域。配音版可点旧句重听；无配音版不把静态句子做成播放按钮。回看不重复计进度。 |
| 理解题 | 先获得所需课文再作答；题干直接说明判断目标。原文人物题不能伪装成需要孩子补充个人经历的题。 |
| 单选 | 选项组居中，状态明确；主动检查、主动继续。题干、配图与选项构成一个完整问题。 |
| 场景任务 | 选择回应、人物或物品仍使用明确的选项按钮与检查区。选中仅表示选择；错答不推进剧情或显示正确对象；检查正确后才发生交接、找到物品等结果，下一步仍主动点击。 |
| 拼句 | 点候选加入、点已选撤回，候选原位置留空；全部词块用完才检查。刷新和重试保留候选位置。 |
| 句型对照 | 正反变换在空间允许时一行显示；小屏自然换行并保留方向，不产生横向溢出。 |
| 线索 | 有帮助才提供。灯泡位于检查按钮左侧，使用后如实计为提示。只指出关注对象、回顾位置或思考方法，不给正确选项、答案译词或完整词块顺序；没有独立线索就不显示灯泡，禁止用答案解析兜底。 |
| 帮助 | 玩法与本题线索分开，按需打开。涉及答案的规则提示如实记录，不能算首次独立作答。 |
| 反馈 | 答对用简短成功提示和统一音效。答错只显示“再看看，试一次。”及错误反馈音，保留原题并允许重选／重拼；不追加解析，不朗读、填入或标亮正确答案，不自动跳到下一题。连续答错、刷新恢复也遵守此规则。没有“看看原因”。 |
| 结束 | 最后一题先反馈，孩子主动点击完成才结算。用该任务的结果呈现完成感；下一站为主、再练一轮为次，集中成组、居中排列，窄屏可纵向排列；无无效的额外分支按钮。 |
| 挑战 | 同类题沿用上述布局，暂停与答题操作分开；继续后恢复当前题，阶段衔接和结算规则清楚。 |

选择、播放、展开灯泡、反馈和原题重试不应推移操作区或让整页跳动。换题只在题干不可见时调整视口。小屏可换行，但操作次序不能随意颠倒。

场景状态来自实际阅读位置与有效作答。刷新恢复当前状态；回看历史句不倒退剧情，也不代替当前句完成。重练回到本轮初始状态，旧完成记录不能让新一轮直接交包或选中答案。动画只辅助说明结果，不能代替点击检查、要求等待无关动画，或在完成前展示奖励。

重试不是代答：未作答、答错都不增加完成进度；孩子真正改对后才计完成，并保留“首次未答对／修正后完成”。使用线索、规则或示范后完成不能算独立完成。只改线索文字不清空有效记录；题干、选项、答案或内容版本变化，必须重新核对旧完成记录是否仍适用。

学习区仍可展示完整课文、词义和不同例句。练习中的示范须与当前题错开，不能复制当前题完整答案。没有配音的课程不因这项规则恢复英语配音；有配音的听辨保留孩子主动重听的入口。旧单课允许直接重选按钮，重试不得删掉错误选项来自动排除到只剩正确项。填空在未答对时使用真正的占位文字，不能仅把答案文字设成透明，让读屏仍读出答案。

可点击内容使用符合用途的按钮、链接或展开控件，外观与用途一致。主要触控入口至少 44 像素；键盘焦点清楚，弹层可关闭并返回原焦点。保留“减少动态效果”支持。已移除的课堂投屏不重新加入。

## 5. 进度、记录与导航

### 进度对应真实作答

题号表示“正在看第几题”，绿色表示“本轮已答对多少题”，两者不能混用。

- 第 1 / 4 题未答对：第 1 格黄框，四格均未填绿。
- 第 1 题答对、还没继续：立即一格绿色。
- 第 4 / 4 题未答对：前三格绿色，最后一格黄框。
- 第 4 题答对、还没结算：立即四格全绿。
- 再练一轮：本轮归零。选择、播放、提示、错答和重复提交都不增加绿色。

有回练的活动按原题最近一次有效结果填格。重复答对不能加格，再错应撤回对应绿色，修正后恢复；首次成绩单独保留。

### 保存与隔离

课程、活动、内容版本、题目和练习轮次分别标识。历史完成、当前草稿和历史成绩分开。

- 新题、重练、扩充题量不能由旧答案自动填成正确。刷新恢复的是经过校验的本轮状态。
- 教学内容升版应使受影响的完成凭据失效；纯视觉变化不清除孩子的有效学习记录。
- 单元进度不读取其他单课或单元的星级；旧星级不能冒充新题已经答完。
- 浏览器保存失败须有明确提示和重试，不能显示虚假的保存成功。
- 首页按单元独立恢复有效位置。损坏或未知地址回到开始入口，首页不覆写答题草稿。
- 根目录与 `/lesson/` 的记录隔离；重开只清理用户确认的网站版本和课程范围，保留取消和确认步骤。

### 导航简洁直接

首页以课程卡片直接选课。课号、单元名、开始／继续和必要的恢复位置足够；设置为次要入口。新单元可以使用自己的主题元素，但首页本身保持统一。

封面的“继续”回到上次访问或操作的学习位置，“下一站”推进到下一个活动。手动滚回封面后，即使地址没有改变，“继续”也必须重新定位，让目标标题出现在屏幕上，保留未提交的选择和星星。验收不能只检查地址；还要覆盖连续点击、手机、键盘、刷新与浏览器返回。问题和修复见[继续按钮定位验收](../2026-09-20-1832-v1.2-继续按钮定位修复与验收.md)。

返回“我的课程”、浏览器前进后退、旧入口及必要的单课入口继续可用。没有脚本时尽量保留静态课程链接；不以主题包装增加必经层级。

## 6. 声音、插图与资源

### 6.1 两种模式共用：音标与反馈音

- 英语配音用于呈现教学内容；正误与完成反馈音用于提示操作结果。两者独立，反馈音不得朗读或泄露答案；反馈音播放失败不能阻塞检查、重试、继续或结算。
- 单词与短语都补齐音标，默认放在词卡正面；不因简化界面、停用配音或更换录音省略。按本课词义、词性核对权威词典并保留来源，明确本单元采用的口音体系。
- 词卡采用对应的独立读词形式；课文中的自然弱读、连读按语境另行说明，不能把词卡音标解释为所有语境的唯一读音。无配音版仍核对音标，不需要为此新增录音。
- 高风险文字与音标单列核对：I、a、am 等短词，Mr. 等称谓，人名、品牌名，以及 read、lead、excuse 等随词义或词性变音的词。配音版还须听审对应录音；文字核对不能代替听审。

### 6.2 配音版

#### 学习操作

| 环节 | 配音版要求 |
| --- | --- |
| 词卡 | 点整卡发音并翻看词义，不要求另找小播放按钮；再点可返回正面。 |
| 听辨 | 居中的大喇叭是主要入口，使用大图＋英文选项；指定录音真实播放结束才允许检查，重听不限次，无灯泡或无效提示。不能在播放前展示答案。 |
| 课文 | 当前句可播放，历史句可点读；突出正在播放的句子。旧句重听不能代替当前句的完成，末句之后由孩子主动确认完成课文。 |
| 表达与示范 | 有点读用途的内容使用明确入口；纯阅读文字不伪装成播放按钮。 |

英语录音与文字逐条对应，同一角色和同组词卡保持音色一致。新完整句子使用完整录音，不用词音拼接代替自然句子；英美口音、音标和文字成套核对，教材与录音口音不同时写明采用哪套。最小音对必须听得出本课要训练的差别。

复用音频须保留来源、文字映射、声音参数、文件校验值和原验收状态；复用不等于本轮已经人工听审。没有合格材料时如实保留待办，不能靠隐藏播放失败或系统朗读把本单元标为配音验收通过。

#### 生成和修复必须可追溯

- 若用上下文合成后裁出词音，必须核对目标词的完整边界，不能夹带引导语或丢失词头；不能只凭时长、文件存在或播放结束判定正确。短词既可能裁错，也可能独立合成失真，不能把“改成独立合成”直接视为修复完成。
- 保存实际音素、停顿、目标词边界、引擎和模型版本、音色、速度及处理方法。生成配方与例外规则进入版本管理，不能只留在临时文件里；关键分词或音素变化、缺词、越界裁切时停止生成，不静默忽略或换用其他声音。
- “有音素”不等于“整个词读全”。人名的连字符、所有格和其他变形须逐个核对实际输出，例如 Chang-woo 不能只剩 woo，Paul’s 不能只剩所有格词尾；发音例外规则必须验证确实命中了完整目标，不能只记录“启用了规则”。同形异音词须按本课词性选择读法，例如 Excuse me 中的 excuse 是动词，不能沿用名词词尾。
- 发音修复使用新的录音文件名；页面回归检查实际收到的录音，覆盖重复点读、刷新和 `/lesson/` 路径，防止缺陷文件被缓存或批量生成带回。文件一致性检查只防回退，不代替人工听审。
- 只更换录音、教学文字和题目未变时，不应清空孩子的已听位置、完成记录或其他作答；用真实旧页面产生的记录验证升级，不能把任意旧题稿都当作兼容版本。
- 修复时保存原样例，先建立能暴露原问题的检查，再用同一路径复验，并排查同类短词、同一生成批次及共用录音的其他课程。不得仅为通过测试而更换录音校验值。案例见 [Lesson 7–8 的 I 词音修复](../2026-09-21-2112-v1.1-Lesson7-8词音修复与防护.md)。

#### 文件、页面、人工听审分别记录

| 层次 | 检查什么 | 通过不能代表什么 |
| --- | --- | --- |
| 文件与来源 | 文字映射、可解码、非静音、文件校验值、起音、边界和生成记录；旧课程缺记录须明示。 | 不代表读音正确、自然或音色合适。 |
| 真实页面 | 从词卡或句子点击，实际录音加载、原生结束、重听、失败重试、离开与刷新；根路径和 `/lesson/` 的引用一致。 | 不代表人工已经听过，不能用模拟播放器代替录音检查。 |
| 人工听审 | 新增或更换录音逐条对照文字和音标，核对漏词／多词、词头词尾、重音、停顿、自然度和同组音色；记录审核人、日期与文件校验值。 | 不代表整课教学内容或儿童体验已经验收。 |

自动语音识别只能辅助筛出复核队列：同音词、数字写法、缩写和人名都可能转写不同；短词即使被正确识别也不保证声音自然。不能把识别差异直接算作“错误数”，也不能把无差异算作“人工通过”。音标标错、文字绑定错误等证据充分的问题，与“疑似发音异常”“只是转写差异”“尚未检查”分开报告。

没有逐条人工记录的录音包维持待听审状态；重新生成后不得继承旧文件的听审结论。审核记录完整、校验值不变且教学语境未变的复用录音，可以引用既有结论，但要注明来源和日期。发布时不能用播放成功、识别通过或旧单元的验收代替本次门槛。

- 指定录音失败可重试；浏览器后备朗读不能充当“已听完指定录音”的证据。
- 快速重听、切题、取消、离开、刷新后，旧播放回调不能推进新题或新句。

### 6.3 无配音课堂配套版

网页训练词义、阅读和句子组织；发音、听力、跟读和真实交流由课堂教师安排。题目、活动名称、结果记录与证书都须符合这个分工，不能把英译中或看图选择称为听力达标。

| 环节 | 无配音版要求 |
| --- | --- |
| 词卡 | 仍先进入图鉴，保留图、英文和音标；点击展开中文，再点返回，不发音。 |
| 词汇练习 | 用词义、语境或看图任务提供完整作答依据，不出现喇叭、重听或“听完才能检查”的门槛。 |
| 课文 | 保留全部原文、人物和顺序；孩子主动展开下一句，最后确认完成。旧句可回看，中文按句展开，只滚动对话区内部。 |
| 表达与示范 | 阅读卡保留完整教材材料；可展开内容用展开控件，静态文字不做成播放按钮。 |
| 声音行为 | 学生页面不请求、预加载或播放英语配音，不使用系统朗读，无播放中／已听完状态；正误与完成反馈音独立保留，全部声音不可用时仍能完成学习。 |

词义题可混合英译中、中译英和看图选英文。每题应有词汇覆盖或判断用途，不把整组正反翻译强制做两遍；图片题不能在选项重复同一图片，让孩子绕过英文直接配图。

关系词、物主词、多义词和抽象词用本课语境限定含义。不从单个人物头像猜亲属关系，不用物品外观猜主人，不把休息解释为懒惰。选项数量服从有效对比，不为凑选项加入未教的新结构或新词。去重和准确性仍按第 1 节执行。

停用的录音及清单可保留为历史材料，注明学生页面已停用。对应的当前播放验收记“不适用”，历史上尚未听审的材料继续记“历史待审”；不能把停用写成发音问题已修复或听审已通过。

### 6.4 改变模式或更换素材时

模式变化须同时核对题目依据、入口文案、完成条件、学习记录和证书表述。只是把喇叭藏起来、把活动改个名字，不算完成改版；播放临时失败也不能静默切成另一种训练。

| 变化 | 必须处理 |
| --- | --- |
| 配音版改为无配音版 | 为原听辨题提供词义／阅读依据，使用新题号；旧听力成绩不能自动完成新题，完成条件改变的活动重算。移除英语播放调用及门槛，按无配音清单走完全程。 |
| 无配音版恢复配音 | 先具备符合第 6.2 节的来源、逐条听审与页面验证，再启用入口；不能因历史文件仍在就恢复。新听辨不能继承阅读成绩，旧阅读记录不改称听力成绩。 |
| 仅更换录音，题目与教学文字不变 | 核对具体旧版本的兼容性，保留有效作答、姓名、词卡页与已听位置；新文件重新听审，并验证页面没有取到旧缓存。 |
| 仅改视觉、按钮排布或线索措辞 | 保留有效记录；若实际上改变了题干、选项、答案或完成规则，按教学内容升版处理。 |

迁移只支持已核对的具体旧版本；使用旧页面真实产生的记录验证升级。未改的词卡页、姓名、有效阅读位置和练习证据尽量保留，不能一概清空，也不能让未知旧数据代答新题。需要回看历史素材时与学生现行入口区分。

### 6.5 插图与访问路径

- 插图准确且同风格，人物与物品应完整清楚；装饰不得遮挡教学线索或提前泄露答案。
- 同一人物与关键道具建立可复用素材，封面、活动和完成画面保持一致。共用图标改动要列出使用位置并复查，避免只看当前单元就遗漏其他课程。
- 题干、对白和按钮保留真实文字与可操作控件，不把整张场景截图当成互动界面。纯视觉素材更新不改变题目含义或完成条件；缓存更新与学习内容版本分开处理，保留有效学习记录。
- 本地使用 HTTP 预览，不使用 `file://`。根路径和 `/lesson/` 的导航、录音、图片、字体都须可用，资源请求不能跑回另一套站点。

### 6.6 课程加载与缓存

允许孩子点课后看到简洁加载页；课程内全部必需图片、背景、人物、字体和操作依赖准备完整，当前画面可显示后再进入，不能展示半幅课件。准备范围覆盖后续词卡、不同人物状态、完成页、证书以及可从课内直接进入的选练，不只准备首屏。再次进入复用已核对资源，直接恢复有效学习位置。

资源缓存与学习记录分开。清理资源不删除作答、星星或姓名；仅改图片与缓存不能让旧题失效或新题自动完成。配音下载不冒充已听完；无配音课程不得因预缓存而重新请求英语录音，反馈音失败不阻塞练习。

加载界面、完整性判断、版本切换、存储清理、失败恢复、速度目标与行为清单只在[网页加载缓存设计](2026-09-24-2031-v1.0-网页加载缓存设计.md)维护。首访、复访、缺图、弱网、断网、旧版本、子目录隔离及证书均须验证；尚未实施的项目标待实现，不能沿用旧课程测试结果填通过。

## 7. 证书与线下练习

名字突出，故事人物与已获得的关卡徽章围绕孩子展开。领取前显示真实的已完成与待完成状态，未完成不能领证。

活动结束与证书延续本单元的事件和角色，例如已归还的手提包、已完成的采购。结束画面让孩子看见自己的帮助产生了什么结果；不把每课都做成仅替换标题的同一张奖状，也不增加无关积分或虚构能力称号。

页面、实际保存图片与打印使用同一组名字、人物、文案、徽章和首次领取日，允许按画布尺寸调整排版。组合单元当前 PNG 为 1440 × 1100，打印适配一张 A4。

空名字有友好称呼，长名字不挤成竖列；图片加载失败不能输出残缺证书，要能重试。减少动态效果时仍完整显示。

线下对话和纸笔练习按需展开，不伪装成已经完成的线上口语测评。打印必须实际渲染查看：页数正确之外，文字、人物和书写区域也必须可见。

证书只写实际完成的学习任务。无配音版使用“课堂配套练习”等准确表述，不称为听力通关；配音版的听辨完成也不等于自由口语或独立写作达标。

## 8. 每次交付的验收清单

产品功能沿用用户要求，仅通过页面行为测试。预期答案来自教材与审定题稿，不从程序答案字段生成。先填本次范围，再填写共用清单和所选模式清单；空项是待验证事项，不代表已知缺陷。

交付记录开头写明：**单元与内容版本、教学模式、改动范围、实际页面路径、检查日期、所用清单、结果与证据位置。** 每项标“通过／未通过／待验收／不适用”，不适用须写理由；不能把不适用、停用或未检查折算为通过。下方清单不自动继承旧结果。

### 8.1 两种模式都要验证

| 范围 | 待验证事项 |
| --- | --- |
| 内容 | [ ] 页图、原文、词表、题干、唯一答案、干扰项、反馈与配图逐项核对；新情境边界清楚。 |
| 必做题去重 | [ ] 逐题写明依据、判断、干扰项作用及新增内容／具体复习用途；按实际任务归组，已删除或改写无必要的同构题。换词、换图片、换题型和打乱选项不作为去重证据。 |
| 跨环节递进 | [ ] 连同前一单元、示范、应用、拼句、挑战一起对照；没有换活动名后整组重做，也没有先做完整任务、再强制拆碎重复。标为迁移的题确有新的判断条件。 |
| 单元体验去重 | [ ] 比较相邻单元的角色、场景、主要操作、任务结果与奖励；能说明实际区别或复习依据，不只是换标题、颜色或物品后照搬整套任务。 |
| 综合挑战覆盖 | [ ] 已提交核心目标—前置练习—最终题号对照；每个线上核心目标及必要对比都有实际判断，未检验项说明课堂分工；现成词块、答案或标签不冒充检验。 |
| 挑战扩充与结果 | [ ] 旧题、新题、未提交选择、重练、末题和刷新行为正确；旧通关不能自动完成新题；首次独立／提示后／修正后和再练方向准确；登录版另验跨设备升级。 |
| 必要复习 | [ ] 新词与关键对比完整覆盖；抽样复习有明确对象和数量，错题回练有依据，不要求所有孩子重走整套已会题；示范、必做、选练和课堂分工清楚。 |
| 模式一致 | [ ] 单元文档、图鉴、词汇练习、课文、示范、挑战、记录与证书使用同一已确认模式；没有只改某一个活动、遗漏其他英语播放入口。 |
| 学习入口 | [ ] 无记录时首页与封面从图鉴开始；词汇练习后进课文、课文后进理解，导航、下一站与徽章顺序一致。手动滚回封面后“继续”仍定位旧位置，保留作答与星星。 |
| 加载与缓存 | [ ] 按[独立缓存方案](2026-09-24-2031-v1.0-网页加载缓存设计.md#7-页面行为验收清单)覆盖整课图片就绪、实际字体、首次／再次进入、下载失败与恢复、版本一致、进度保留及 `/lesson/` 隔离；未实施时保持待实现，不记通过。 |
| 词卡音标 | [ ] 每组、每张正面都有与教学目标一致的音标；词性、短语形式与口音体系正确，来源可查；小屏、翻面再返回、翻页与刷新后可见且不裁切。 |

### 8.4 涉及模式切换或内容升级时追加验证

| 范围 | 待验证事项 |

| 真实旧记录 | [ ] 先在具体旧版本真实学习产生记录，再打开新版本；保留经核对仍有效的姓名、位置和作答，不直接写入伪造记录替代页面验证。 |
| 新旧题隔离 | [ ] 旧听力不自动完成新阅读，新阅读不自动完成新听辨；新题未选、末题和刷新恢复时均不会提前进入正确状态。 |
| 受影响范围 | [ ] 题目、操作、完成条件、入口文案、证书和保存版本一并核对；未改内容不被误清空，未知旧版本不直接认作兼容。 |
| 恢复配音 | [ ] 启用前完成第 8.2 节；录音文件还在、过去能够播放或其他单元通过，均不作为恢复依据。仅转为无配音时此项写不适用并说明。 |

发现问题时记录症状、复现、原因、此前为什么漏检、修复、同类影响和可执行的防护检查。不能用“以后注意”代替防护，也不能为了换主题或模式放宽检查。

页面截图不等于完整行为验证；浏览器通过不等于人工听审或儿童喜欢。旧测试次数不能相加，也不能当作本轮重新通过。文档整理只做文档检查；实际改课程时执行相应页面清单，两者分别报告。

换词卡、换人物等正常操作还要检查过渡过程：已准备课程不能短暂隐藏整页或闪回加载层。点击后逐帧及 DOM 变化时记录可见性与图片状态；等待最终图片完整的断言不足以发现闪烁。具体资源准备与故障保护按缓存文档 C16 验收。

视觉验收同时看实际页面和代表截图，至少覆盖封面、短／长对白、道具状态变化、末题与完成页。截图须清楚呈现目标区域；被固定导航遮住、截断或仍在动画中的截图不能证明最终排版通过。检查最终落位时等动画结束，检查跳动或遮挡时另看过渡过程；仅“无溢出”不能证明比例、层次和辨识度合格。

### 8.5 视觉质量必须单独验收

功能检查与视觉检查是两项独立结果，都通过才可交付本地候选版。通过几十个页面用例，只能证明其中覆盖的行为；“图片加载成功”“没有横向溢出”“元素没有相交”不证明人物、构图、比例好看。人工目视检查不可由这些数字代替。

| 检查 | 必须留下的证据 |
| --- | --- |
| 样板对照 | [ ] 修改前后与已确认样板的同尺寸页面截图，说明具体改善；不拿不同缩放、空记录与完成态混比。 |
| 人物与空间 | [ ] 桌面和手机都看得清角色特征，人物站得住，柜台／地面／人物遮挡合理，主道具不被对白压住。 |
| 对白与比例 | [ ] 短句、长句、中文展开和累积历史都清楚；没有巨大空卡片，正文与角色兼顾；操作位置稳定。 |
| 事件完整 | [ ] 未提交、错答、答对、末题、刷新恢复和重练逐一验证；交接结果在画面中可见且时机正确。逐句核对中途的物品身份变化，不能只看事件首尾；快速操作、减少动态效果和刷新不能显示旧对象或提前交接。 |
| 素材一致 | [ ] 封面、课文、题目、完成页与导出图使用同一组人物与关键物品；共享素材引用处已复查。 |
| 实际结论 | [ ] 列出检查的尺寸、状态、截图位置和未通过项；明确“本地目视通过”与“用户／教师／儿童认可”各自的状态。 |

恢复阅读位置须在页面实际可见、资源已就绪后核对，不能只依赖字体加载完成；直接路径和带加载页的发布路径都要检查。

比例、定位和操作稳定可以补充页面回归检查，但不能写一个只检查新 CSS 数值的测试来宣称美观。优先守护用户可见的问题，例如道具未答先交接、脚悬空、手机角色不可辨、长句盖住道具。视觉未通过时继续迭代，不以“功能已完成”关闭该问题。

## 9. 文档、提交与发布边界

- 教学与交互共用要求只在本文维护；加载缓存细则只在同目录的独立缓存方案维护。单元文档记录教学模式、教材范围、学习目标、课堂分工、题稿、素材来源和实际验收，引用本文，避免再复制一份公共规则。
- `docs/butcher-version/publish` 存放唯一现行统一标准与网页加载缓存设计；历史题稿、实施记录和证据继续保留在上级目录。设计文件按 `YYYY-MM-DD-HHmm-v版本号-名称.md` 命名，时间到分钟；入口 README 不另加版本。被替代文件写明历史状态并指向现行文件，不复制多份现行规则。
- 内容审定、设计确认、代码完成、页面验证、人工听审、教师／儿童验收、提交、推送、发布分别报告。
- 收到提交或推送请求时，按[测试说明](../../../tests/README.md)运行或复用相关检查；说明范围后再执行授权的 Git 操作。推送以目标远端提交号一致为准。
- 正式发布另按[发布指南](../../../deploy/README.md)执行。针对 `/lesson/` 从已提交版本构建、核对清单与资源，再切换发布目录并检查正式页面；保留独立回退方式，不影响官网根目录。
- 本地预览、对照稿、文档或检查通过，都不等于线上已经更新。凭据不写入设计文档、代码或发布包。
