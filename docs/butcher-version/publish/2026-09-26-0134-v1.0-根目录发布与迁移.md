# 根目录发布与迁移 v1.0

日期：2026-09-26 01:34。用户已确认本次网址布局与部署；实际发布提交和线上验收以交付记录为准。

## 用户打开哪里

| 地址 | 内容 |
| --- | --- |
| `/` | 新版学生入口；登录后直接显示本班已开放课程导航，保留记住登录 |
| `/admin/` | 当前教师管理功能 |
| `/unit1-2/` 等十六单元 | 保留当前 butcher-version 课程和账号权限，课程内容不因迁址改变 |
| `/exercise/` | 原根目录的探险猫练习站，保留原有内容与公开访问方式 |
| `/lesson/` 及其旧课件、资源 | 移除公开访问，返回 410；只保留用于清退旧缓存的 Worker 响应 |

本次是迁址与账号服务首次上线，不把练习站的匿名成绩认领成学生个人成果。当前本地预览默认 `/lesson/` 不代表生产仍发布该路径。

## 必须保持的行为

1. 图片、字体、配音、题目选项、返回课程、教师预览、打印账号地址、接口和 Cookie 都与当前发布路径一致。
2. 学生永久身份、学号、正式密码、班级开放范围与真实完成成果不变；未完成选择不会因为迁址变成答对。
3. 旧图片 URL 与新 URL 只是部署位置不同。仅在题目版本、题目内容、答案和真实提交状态一致时保留已完成记录；不得放宽内容升级时的防代答规则。
4. 个人草稿继续使用原有账号命名空间，新版资源缓存作用于根目录，旧练习站资源及 Worker 限定在 `/exercise/`，不能覆盖根目录。
5. 保留原站的文件完整性校验。移动资源后重新计算媒体清单、课包、首页中的预期摘要及发布清单；不使用跳过检查的测试开关上线。
6. 根目录匿名访问只显示登录，受限资源由服务器检查；原 `/lesson/` 静态 alias 及长期资源 alias 全部退出主域名路由。
7. 升级联网旧浏览器的 Worker，不删除学生本地记录，也不声称能够撤回完全离线、未更新的旧副本。
8. 备份与代码发布分离；管理员及学生密码不进入 Git、公开目录或发布说明。

## 验收

- 根目录创建班级、账号发放、首次改密、登录、课程导航和完整单元通关；刷新与复访保留真实成果。
- 迁移前先真实看课文并完成带图片的题目，迁移后按原密码登录，原完成页和星星仍在，还能完成下一项活动。
- 未登录直接访问课件、清单及固定资源不会绕过权限；学生不能调用管理功能。
- `/lesson`、`/lesson/`、旧单元、固定资源及清单不再返回旧内容。
- 已打开的旧缓存页面收到更新后，不继续从缓存显示旧公开课件。
- `/exercise/` 首访完整加载，进入练习、返回及刷新复访可用；图片、音频、脚本的请求不越出 `/exercise/`。
- 正式 Nginx 检查与重载成功，HTTP 转 HTTPS 可用；攻击来源被限流后，其他来源的正常账号仍可登录。
- 部署包、远端分支与目标提交分别核对。桌面浏览器验证和真实手机微信验收分开报告。
