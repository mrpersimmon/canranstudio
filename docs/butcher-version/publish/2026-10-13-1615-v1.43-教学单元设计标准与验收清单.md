# 教学单元设计标准与验收清单 v1.43

2026-10-13 16:15 · 适用分支：`codex/debug-grammar-v2`。唯一现行共用标准；本版登记61–62的无配音五区课程；共用规则保持不变。旧版只供追溯，文档位于 `publish` 不代表已经上线。

**一个教学单元由相邻两课组成，例如 Lesson 3–4。每单元固定五个答题区、五个星位，最多五颗星；每个答题区结束固定三张统计卡。** 题量由教材目标决定，不复制样板题数。

## 1. 教什么：教材准确，语法以练促学

- 课本保留完整原文、人物、顺序、重复句和全部新词；偶数课保留替换、问答、书写等训练目标。单元题稿注明纸页／PDF 页、线上与课堂分工。
- **语法以本单元《新概念英语1 同步导学》Grammar 为依据**，课本核对语境，语法练习册校验形式和常见误解。使用“短示范 → 立即练习 → 撤去帮助 → 综合挑战再次运用”；不整页搬说明，不用背术语代替表达。
- 示范与当前题完整答案错开。错答只短提示并原题重试；答对后必要时用一句话归纳。使用线索、规则或示范须记录，有帮助的答对不称为独立掌握。
- 每个核心目标对应“依据—示范—练习题号—综合题号”；出现过不等于考过。例如给出完整 `an engineer` 词块不能算独立判断 a／an。综合挑战覆盖适合线上检验的核心目标及必要对比，词汇合理抽样，不把两三道抽查当作全课综合练习。
- 单选答案唯一，题干、配图与选项考同一件事；问“谁”选人物，问“哪个词”选词。干扰项针对真实误解，不添加未教结构凑选项。
- 核对说话人、听话人、指代、单复数和归属；原文事实与另设情境分开。不从职业猜性别，不把“不属于我”推成“属于你”，不把不冷推成热。be 的问句／否定规则不推广到所有英语句子。
- **禁止高度重复。** 隐去人名、名词、图片后仍是同一判断的题，须说明必要对比、撤去的支持或具体复习用途；仅换题型、换词和打乱顺序不算递进。跨环节、相邻单元一起审查。

## 2. 怎样组织：五区分工，参考材料不增加关卡

默认顺序：**图鉴 → 词汇练习 → 完整课文 → 理解练习 → 语法小工坊 → 情境应用 → 综合挑战 → 纪念卡**。其中词汇、理解、语法、应用、挑战为五个答题区；教学内容不算答题区，不发星。具体任务按教材安排，特殊顺序须说明教学依据。

语法改造同时整理旧锦囊、接力和例句：按目标合并练习，完整替换材料可收进可选参考或课堂材料；不删教材目标，不再增加必经小关卡。保留旧章节链接的有效去向。

## 3. 怎样操作：同类题保持一致

| 内容 | 共用规则 |
| --- | --- |
| 图鉴 | 最先进入；大图、英文、音标正面可见，整卡翻看中文；无教材词／补充词标签。前后组用按钮，末组给下一站，不要求逐张点击刷进度。 |
| 课文 | 根据教材安排对话或叙述；固定对话区累积完整历史，只滚动内部，中文逐句展开。首次开始、中途继续、读完后的下一站清楚；回看不重复计进度。 |
| 单选／原文定位 | 选项组居中，可改选，主动检查与继续；词／词组有明确可点边界，句子仍完整可读。 |
| 配对 | 每屏优先3–4对，唯一对应；全部配齐再检查，原位撤销改配。整组算一次提交，不把三对计成三次；错答不消去正确项或排除错项。 |
| 逐空填答 | 优先一空，相关任务最多两空，逐空选择，可撤销；未填齐不能检查，不预填答案或把空白当正确。 |
| 词块 | 按意义切分；点候选加入、点已选撤回，候选原位留空。填满要求的空位再检查，有干扰项时不要求用完全部。 |
| 场景任务 | 先给必要英文材料，再选物品、人物、动作或位置；选中不等于完成。检查正确后才交接或改变场景，同一物品不复制到两处。 |
| 线索／反馈 | 有用的灯泡在检查按钮左侧；无独立线索就不显示。线索不提供答案；错答只“再看看，试一次。”或认可的短版，不标正确项、不追加解析、不自动跳题。 |
| 继续／重练 | 末题先反馈，主动完成后结算；再练在左、下一站在右，集中成组。无“怎么玩”、手动暂停、“看看原因”和无效分支；参考材料不冒充播放按钮。 |

所有可点内容用符合用途的按钮、链接或展开控件，支持键盘和至少44px触控范围。选择、提示、检查、重试不推动操作区或整页；换题只在题干不可见时调整视口。刷新、返回、重试保留题目、未提交选择及候选顺序，不能代答或越题。

题号表示所在题；进度绿格只表示真实答对。最后一题答对立即全绿，重复提交不加格；再练本轮归零。无配音必做题不要求键盘输入英文。

## 4. 怎样呈现：统一画风，每课有自己的故事

- 品牌统一为“灿然英语工作室”，网站及加载页复用 `assets/brand/starflower.png`；沿用圆角与深棕描边。
- **整单元统一字体，保留信息层级。** 中文用寒蝉圆黑体：正文 Regular 400，标题、按钮及重点 Medium 500；英文用 Nunito：句子／正文 Regular 400，单词、按钮／导航及重点 SemiBold 600。封面、图鉴、对白、练习、结算、纪念卡、书页与导出遵循同一分工，不统一成同一字号或粗细。音标单独用完整覆盖 IPA 的字体，45–46 沿用 Arial，不能强换 Nunito 导致缺字或混杂字形。
- 字库本地随课准备，使用真实字重，不合成粗体。正文可按文案裁成字库子集，新增文字须补齐；动态姓名保留完整中文覆盖。换字体后复查换行、按钮、长姓名与导出；加载细则见第7节。
- **人物沿用已确认纪念卡的画风。** 封面／导航横幅、图鉴、课文、题目及完成画面保持同一角色的头身比例、面部画法、轮廓、配色与质感，按剧情换动作和表情。新单元先对照第6节认可样板确定角色基准，再扩展；不能另画一套风格不同的课内人物。
- 角色靠轮廓、服装结构、发型和配件辨认，不能只换衣服颜色。教材同一人物可复用身份，不同情境换姿态；同名不自动判定为同一人。相邻易混单元须并排对照。
- 单元可变化背景、主题色和活动容器；选中、正确、错误、禁用、焦点的含义全站一致。图鉴、舞台、练习和完成区有层次，不让装饰抢题目。
- **对白放在场景内。** 开场问题和对白历史与人物、道具同处一个场景框；桌面与手机都不另排到场景下方。气泡靠近对应角色，历史区固定高度、内部滚动；长句和中文完整可读，短句不撑巨大卡片。窄屏可在场景内重排，不能遮住脸、手和关键道具。
- **人物不能被意外裁切。** 舞台全身人物的头发、手指、双脚及持物完整可见；源素材和页面容器都须留安全余量。伸手、持物、换姿态和切景逐一检查，不能靠裁人物或过度缩小人物腾出对白空间。纪念卡的近景构图按第6节，不等于允许素材断手、缺脸。
- **人物应面向交谈对象。** 站位、视线与手势随对方位置调整；换边、换姿态、切景和刷新后都须复查。镜像仅作用于适合翻转的人物图，姓名、文字和独立道具保持正常；含文字或有明确左右含义的姿态另备素材，不整组翻转。
- 人物站得住，道具看得清；关键物品贯穿封面、课文、练习、结算和导出图，身份与交接时机随剧情准确变化。
- 先做好一个代表场景的未答、错答、答对与结束状态，再扩展。批量开发仍逐课提交设计、桌面／手机画面和验收；一课通过不代表整批通过。功能通过与画面美观分别判断。

## 5. 怎样结算：固定三卡，只统计本轮实际提交

本轮从开始练习或点击“再练一轮”起，到主动完成该答题区止。刷新、离开续做不另开一轮。只有点击检查并得到判分才计一次，选项变更、提示、回看和重复点击已禁用按钮不计数。

| 固定卡片 | 口径与图标 |
| --- | --- |
| 连续答对 | 本轮最长连续答对次数；答错即中断，订正答对从1重新累计。金色星星。 |
| 本次答对 | 本轮实际提交正确的次数，包含订正答对。绿色对勾。 |
| 本次答错 | 本轮实际提交错误的次数，同一题错两次就计两次，订正不抹去错误。珊瑚红叉号。 |

单位统一为**次**，不再按每题首次提交分类计数。例：5题中第3题错两次后改对，其余均对，三卡为 **3／5／2**。重练不带入上轮次数；只改统计口径不清空已有作答、奖励或日期。合并旧活动等导致次数无法核验时，三卡保留并显示“—”，说明“旧记录次数不完整”；不伪造零次或全对，完整重练后恢复数字。

所有答题区复用同一结算规则及[认可的 imagegen 星／勾／叉原图](../../../assets/unit1-2/completion/README.md)，桌面和手机保持三卡并排、等宽等高，零值与多位数字一致。人物与道具、短标题、三卡、再练／下一站构成完成页，不能退回“这一组完成了”。无题目的图鉴、课文、参考例句不展示统计卡。普通结束页在320×568短屏须完整露出三卡和两个按钮；人物成果页可纵向滚动，但卡片、文字和推进操作不裁切，刷新重进同样可用。

不得按内容随意变成两张或四张卡。确需改变数量，须单独写明教学目的、三卡为何不足、替代方案及对比较和验收的影响，不能以排版方便作为理由。

**动画有先后。** 新星经确认后展示悬浮纪念卡，关闭后再播放统计卡入场与跳数；无奖励浮层则直接播放统计。已获星后重新完整零错，展示现有卡面和星光，不重复飞入新星。刷新回看不重复庆祝；同步失败不阻塞查看结果，补传后不重播已经看过的统计。

## 6. 怎样获星：每单元固定五颗，完成与奖励分开

- **五个答题区，每区最多一颗，共五颗。** Lesson 3–4 合为一个单元，共五颗；不是两课各五颗。题量、页面数和参考材料不增加星位。
- 本轮全部题目完成、实际答错0次，并主动完成该区，才可获得该区星星。订正可完成学习但本轮不发新星；重新完整挑战零错可再争取。提示不算错答，但不能因此称为独立掌握。
- 已获星不因重练、后来答错、刷新或换设备扣回。首次五星日期由服务器固定、按北京时间显示，未满星不显示日期；新卡版本保留旧卡和旧日期，不用动画结束时间或设备时间代替。
- 姓名取登录学生；正式奖励归账号，离线先存本机并显示待同步，确认后点亮。匿名和教师预览不能冒充学生成果、不能导出；换学生清除上一人的画面、待展示事件和导出任务。关课不删除已得收藏，重开不扣旧星。
- 卡面沿用本课故事，0星空位静止且不能保存，1–4星仅亮星持续发光、普通边框，第5星才开启流动金边。首星入纪念册；课程底部、悬浮卡、书页、放大与导出使用同一身份和成果快照。
- 悬浮结算沿用 **C方案**，无额外标题和按钮；点击任意位置或按 Esc／回车／空格退出并返回焦点，不点击穿透、不滚动跳位。已核实的不兼容升级可展示现有卡与一句“课程已升级，重新挑战，全对即可点亮星星！”，不能把错答或同步失败说成升级。
- 奖励光效默认开启，不因系统减少动态设置或翻页开关而隐藏；其余页面仍支持减少动态。姓名、人物和纸色稳定，光效不扫过主体或频繁闪烁。先准备真实参与展示的图片节点与字体；离屏暂停、恢复不重授奖，素材或动画失败仍能继续学习。

| 改版／续做情况 | 必须保留的边界 |
| --- | --- |
| 只改图片、布局、缓存、统计展示 | 不重开有效轮次，不要求重新争星；保留次数、错答和已获星。 |
| 旧页只打开或仅选择、未提交 | 不当作旧已作答轮次；现行规则下完整零错一轮即可获星。 |
| 内容或奖励版本改变，已有提交 | 仅承接核对过的相同题；新增题未答。旧答案拼接不能冒充新版整轮零错；旧收藏独立保留；旧15星完成记录单独展示，不伪装成新版五颗零错星，原领证日期与跨设备历史必须保留。 |
| 刷新／离开／离线恢复 | 本轮草稿与历史成果分开；恢复不洗掉错误，服务器旧完成不覆盖本机新重练。同步确认前不预发星。 |
| 来源不明或损坏 | 不伪造统计或奖励；说明恢复状态，保留可恢复信息并允许重练，不一律归因为课程升级。 |

教学完成、提示后完成、订正完成与获星分别记录；统计次数不能替代能力判断。获星判据及教学记录仍可保存每题作答证据，不改变本节规定。

**纪念卡要能认出这节课。** 新卡须与[Lesson 1–2](../../../assets/awards/unit1-2-handbag-closeup.webp)、[3–4](../../../assets/awards/unit3-4-umbrella.webp)、[5–6](../../../assets/awards/unit5-6-friends.webp)已确认卡面在同尺寸、同星数、同类虚构姓名下并排比较；不把 Lesson 41–42 待确认稿当作新样板。

| 卡面要求 | 验收重点 |
| --- | --- |
| 故事、人物与道具 | 近景或中近景表现关键事件，脸、手、视线与物品互动清楚；身份承接本课，背景退后，不用远景缩略图或通用站姿拼贴充数。 |
| 画风、信息与尺寸 | 暖纸、圆润棕色轮廓、柔和主题色、克制边框；工作室、称号、姓名、五个星位、课号层次清晰。沿用现有卡面比例和自适应布局，桌面最大720px、手机最大340px，长姓名与短屏不裁切。 |
| 分层素材与证据 | 插画不画死示例姓名、星数或日期，动态文字由账号生成。保存角色依据、关键事件、素材来源、提示词及确认稿；查看实际书页、手机和导出尺寸，不能仅凭放大原图或图片已加载通过。 |

纪念册沿用 **A方案侧翻书封**：深绿封面用网站星花，素材齐全再展开，约1.25秒且可跳过；手机单页、桌面双页，真实卡居中随书页落位，纸色不跳变。每次进入开书一次，翻页、目录和放大不重播；关掉翻页仍保留星光。点卡可放大、保存、退出并恢复焦点；空册、失败、离线和旧收藏如实显示，故障可重试或返回。

有身份且至少一星才显示“保存动图”，成功短提示“动图已生成”；不另加格式选择。设备端用同一成果快照生成循环GIF，字体和图片先解码；姓名不传第三方，翻页／导出不重复请求个人成果。生成可取消、失败可重试，切换账号或离开不得突然下载。现有基准984×528、60帧、4.8秒循环；实现可优化，但真实下载须解码确认光效变化、姓名人物纸色不变。设计证据见[奖励索引](../../award-version/README.md)，不以桌面下载代替手机微信保存验收。


## 7. 声音、加载与访问

| 模式 | 必须做到 |
| --- | --- |
| 配音版 | 词音、句音按语境、音标和实际发音逐条听审，记录来源；不能仅凭能播放、AI转写或旧文件存在就通过。听辨用显著喇叭，指定录音真实结束才开放检查；失败可重试，旧播放回调不推进新题，不能悄悄切成无配音。 |
| 无配音课堂配套版 | 不请求、预载或播放英语录音，不用系统朗读；保留音标与正误反馈音。图鉴翻词义、课文主动阅读、词义／看图／阅读题提供完整依据，不能称听力达标。教师负责发音、听力与真实交流；所有声音失败仍可通关。 |

单元文档先声明模式；当前本地 Lesson 1–62 配对单元为无配音课堂配套版；49–50为改版、51–62为新增，线上状态按发布记录核对。新单元按用户确认采用，改变模式须同时改题目依据、名称、门槛与记录；旧听力成绩不能代答新阅读题。停用录音不等于发音已修复。

课程完整资源准备好再进入，复访复用缓存，课中不闪回加载层。资源缓存与学习记录分离，清缓存不清作答；细则只维护在[网页加载缓存设计](2026-09-24-2031-v1.0-网页加载缓存设计.md)。

登录首页坚持一单元一横幅，按班级开放；新课不自动向旧班开放，直链仍校验权限。账号、个人收藏和公共资源分离，完整要求见[访问设计](2026-09-26-0048-v1.2-班级课程访问设计与验收.md)。给用户的本地预览默认是正确工作树的完整账号服务，使用独立测试学生，包含首页与纪念册；不使用 `file://` 或匿名页面替代。
