教学标准引用缓存与访问规则，不复制实现细节。[奖励设计索引](../../award-version/README.md)保存确认稿和实施证据，不能用旧 PNG、首次分类统计或不弹重练卡的规则覆盖现行标准。

所有旧标准为历史快照。更新版本同步[总文档导航](../../README.md)、[历史索引](../2026-09-11-2306-v1.1-文档索引.md)、[测试说明](../../../tests/README.md)与现行引用。设计文档按 `YYYY-MM-DD-HHmm-v版本号-名称.md` 命名，时间到分钟；入口 README 不另加版本。

发布操作遵循[发布指南](../../../deploy/README.md)，实际状态核对对应提交和发布证据，不用文档位置或旧检查数字代替上线验收。历史根目录迁移见[迁移记录](2026-09-26-0134-v1.0-根目录发布与迁移.md)。

题型研究见[Duolingo 研究入口](2026-09-27-2028-v1.0-Duolingo题型研究入口.md)，研究事实和采用要求分开。
