## 0. 本次统一五星切换（O18，仅执行一次）

用户确认一次性破坏性升级，以下规则优先于旧文档中的“旧进度全部承接”和“学生选择课程版本”。固定升级标识为 `five-star-system-20261024-v1`，显式管理命令执行；启动服务、再次发布和重复执行命令均不得重置新版学习。

- **先备份再迁移。** 保存SQLite一致性备份及配套card-key，核验完整性与源状态；先归档有效证书，再在一个事务中切换。备份失败、来源损坏、未知证书或并发学习导致快照变化时停止，不部分清空。
- **逐账号、逐课程判断。** 当前有效完整五星证书及受支持历史纸证领取依据都属于已通关；不能只按新五星格式筛掉旧15星证。已通关保留5星资格、原证书原名/内容/领取ISO；目录标“已通关”，按钮“再次学习”。这一资格不代表新版题目已经作答。
- **新版练习从空白开始。** 所有旧作答、错误、草稿、位置与旧轮次退出当前学习状态。未通关课程含旧1–4星统一0星；已通关仍5星但题目为空。新练习错答不扣已通关资格，不重复发证、不改原日期。新完成的课程按正常五星规则授奖。
- **原证独立保存。** 服务端certificate_archives保存不可被新版作答覆盖的原件快照；纪念册、原件详情及原支持的保存/打印读取档案，不将旧答案注入新progress。纸证不转换为带原日期的新卡。动态姓名更改不改变归档姓名。
- **纪念册分区。** 按用户补充确认，“已获得的原证书”只展示历史15星纸证（`kind=legacy-paper`）。五星版没有调整，五星纪念卡继续在正常纪念册中展示，不重复列入原证书区；没有历史15星纸证时不显示该区域、标题或空列表。后台保留五星卡的技术快照及备份不改变产品分区，也不删除原星数、姓名或领取日期。
- **切断旧写入。** 原账号全部72课提升generation，撤销旧grant；新版写入必须带当前epoch。浏览器按账号与epoch隔离新存储，旧本机键留作备份，不读入新练习、不自动补传。旧页/旧设备/离线队列不能恢复已清空的星和进度，换账号仍严格隔离。
- **本机未同步证书。** 只读取当前学生旧命名空间的有效收据，提供本机原件/资料保留途径；不把本机未经服务端确认的资料自动授予正式5星，匿名或归属不明记录不自动认领。资源仍遵守账号与课程/档案权限，不能为旧证开放课件或题稿；关课且云端无授权依据的本机资料保留下载副本，不冒称已正式入册。
- **提示固定原文。** “课程体系已全面升级，未完成课程将重新开始，已获得的证书完整保留。”受本轮迁移影响的账号首次在该设备进入时显示，可关闭；新账号不误提示被清进度。后续普通更新只提示刷新，不重复宣称本轮重置。

此次授权仅适用于本轮固定epoch。后续普通界面、加载、动画修复不再次清零；新练习只接收现行题稿的有效提交，不再运行旧题逐项迁移链。其余教学准确性、五区、三卡统计、O17结算顺序、字体、性能及权限标准保持。


## 1. 教什么：教材准确，语法以练促学

- 课本保留完整原文、人物、顺序、重复句和全部新词；偶数课保留替换、问答、书写等训练目标。单元题稿注明纸页／PDF 页、线上与课堂分工。
- 课本范围按实际页面核对：纸页与PDF页分开记录，保留原题编号、全部原例、所需词形及音标；相邻课标题或图式相近，不能直接沿用上一课文字、页数和任务。词卡释义区分当前词性、词义与固定搭配，不把词组含义无条件移给单词。
- **语法以本单元《新概念英语1 同步导学》Grammar 为依据**，课本核对语境，语法练习册校验形式和常见误解。使用“短示范 → 立即练习 → 撤去帮助 → 综合挑战再次运用”；不整页搬说明，不用背术语代替表达。
- 示范与当前题完整答案错开。错答只短提示并原题重试；答对后必要时用一句话归纳。使用线索、规则或示范须记录，有帮助的答对不称为独立掌握。
- 每个核心目标对应“依据—示范—练习题号—综合题号”；出现过不等于考过。例如给出完整 `an engineer` 词块不能算独立判断 a／an。综合挑战覆盖适合线上检验的核心目标及必要对比，词汇合理抽样，不把两三道抽查当作全课综合练习。
- 单选答案唯一，题干、配图与选项考同一件事；问“谁”选人物，问“哪个词”选词。干扰项针对真实误解，不添加未教结构凑选项。**材料先可作答，再验判分**：每道材料题在未作答画面提供独立判断所需的对象、时间、状态等线索；题稿字段、隐藏说明、答案表或答后反馈不能代替孩子可见的材料。材料给事实，不提前代做推理；依据不足时补充情境或调整问法。
- 核对说话人、听话人、指代、单复数和归属；原文事实与另设情境分开。不从职业猜性别，不把“不属于我”推成“属于你”，不把不冷推成热。be 的问句／否定规则不推广到所有英语句子。
- **时间与事实**：相对时间题给定所需的故事日期或钟点，保留原文自身的时间参照；结合事件是否发生、是否仍在持续和叙述重点判断，不把单个时间词当时态开关，月／年不按固定天数折算。原文中的人物概括、偏见或评价不教成普遍事实，也不补写意愿、因果或结局。必要区分放在对应示范、练习或按需参考，遵守第3节，不自动贴在课文旁。
- **形式与含义一起核对**：改写检查人称、时态、数量、必要性、语气、地点关系及事实前提；明确是保持原意还是改变指定条件。例如“没有”到“不多”、过去安排改为将来安排都不称同义转换；单次事件改成持续状态须有期间未中断的依据。
- 指定句式、词形或表达重点时写明任务条件；合法但不符合指定条件的表达，不解释成普遍语法错误。回应或改写若依赖另一个人的情况、参照范围或额外事实，须先提供依据，不能从一个问句、一个选项或“按例”自行推定。
- **规则写清适用语境**：多义词按当前含义成对举例，如have的拥有义与活动义；同一形式有多个本课核心用途时，先对照情境中的意义，再练形式并分别独立检验。现在完成时的名称不表示所有动作都已结束；也不把某个含义的限制推广到整个单词。
- **否定问句先明确事实**：成对练肯定和否定回应，按英语事实选Yes／No，不逐词套中文“是／不是”。考语气时给出场景和说话意图，不只凭否定形式判断生气、邀请或惊讶。本条在目标涉及否定问句时适用，不要求所有课程增加这一练习。
- **来源冲突先核实**：教材参考存在绝对禁令、内部冲突或可靠反例时，另核对可追溯的权威语法来源，在单元记录写出原说法、来源、适用语境与采用边界。保留教材目标及原例的引用，核实有误的说明不继续作为正确示范；不把未经核实的简化规则变成判错依据，无法消除的歧义不进入唯一答案题。为解释边界补充的内容不能扩张成无关必学目标。
- **禁止高度重复。** 隐去人名、名词、图片后仍是同一判断的题，须说明必要对比、撤去的支持或具体复习用途；仅换题型、换词和打乱顺序不算递进。跨环节、相邻单元一起审查。

## 2. 怎样组织：五区分工，参考材料不增加关卡

默认顺序：**图鉴 → 词汇练习 → 完整课文 → 理解练习 → 语法小工坊 → 情境应用 → 综合挑战 → 纪念卡**。其中词汇、理解、语法、应用、挑战为五个答题区；教学内容不算答题区，不发星。具体任务按教材安排，特殊顺序须说明教学依据。

语法改造同时整理旧锦囊、接力和例句：按目标合并练习，完整替换材料可收进可选参考或课堂材料；不删教材目标，不再增加必经小关卡。保留旧章节链接的有效去向。

偶数课参考与书写按实际产出安排：原编号、原例和每组目标完整保留；一句、两句或多轮问答分别留足书写空间，不统一每题行数。打印视图核对可见内容、编号、分区、分页与书写线，不能只检查题目数量；实体打印仍单列待验或实测结果。

用户认可 **Lesson 1–2、25–26 的题型操作与呈现**为样板；场景参考 Lesson 1–2 与 Lesson 49，不能照搬角色和整套题目。各课教材页码、题量、题稿及验收去向见[单元索引](../2026-10-15-0041-v1.0-教学单元设计与验收索引.md)，具体结果以所链接的单元记录为准；新增一课不再扩写共用标准。

按目标选择题型。[Duolingo 研究入口](2026-09-27-2028-v1.0-Duolingo题型研究入口.md)的12项候选（E01、E04、E05、E09、E10、E11、E12、E21、E23、S01、S02、A02）逐项记录**研究编号＋原题型名称＋孩子实际完成的认知操作＋题号**；未采用写明理由和替代任务，合并或替代不重复计作不同题型。复用旧表先回原报告核对，不能把词义单选写成E01配对、把找语法错误写成S02词义定位，或把对话内填空冒充E12选下一句。研究中的待核状态照实保留，教学改编不宣称原产品已实测。覆盖表不是必须凑齐12种的配额，也不能用题型名代替目标覆盖。

## 3. 怎样操作：同类题保持一致

| 内容 | 共用规则 |
| --- | --- |
| 图鉴 | 最先进入；大图、英文、音标正面可见，整卡翻看中文；无教材词／补充词标签。前后组用按钮，末组给下一站，不要求逐张点击刷进度。 |
| 课文 | 根据教材安排对话或叙述；固定对话区累积完整历史，只滚动内部，中文逐句展开。首次开始、中途继续、读完后的下一站清楚；回看不重复计进度。 |
| 单选／原文定位 | 选项组居中，可改选，主动检查与继续；词／词组有明确可点边界，句子仍完整可读。 |
| 配对 | 每屏优先3–4对，唯一对应；全部配齐再检查，原位撤销改配。整组算一次提交，不把三对计成三次；错答不消去正确项或排除错项。 |
| 逐空填答 | 优先一空，相关任务最多两空，逐空选择，可撤销；未填齐不能检查，不预填答案或把空白当正确。 |
| 词块 | 按意义切分；点候选加入、点已选撤回，候选原位留空。填满要求的空位再检查，有干扰项时不要求用完全部。 |
| 场景任务 | 先给必要英文材料，再选物品、人物、动作或位置；选中不等于完成。检查正确后才交接或改变场景，同一物品不复制到两处。 |
| 线索／反馈 | 有用的灯泡在检查按钮左侧；无独立线索就不显示。线索不提供答案；错答只“再看看，试一次。”或认可的短版，不标正确项、不追加解析、不自动跳题。 |
| 继续／重练 | 末题先反馈，主动完成后结算；再练在左、下一站在右，集中成组。无“怎么玩”、手动暂停、“看看原因”和无效分支；参考材料不冒充播放按钮。 |

**推进按钮保持短文案，去向在按钮外说明。** 常规推进按钮显示“下一站”，完整目的地保留在可访问名称和实际路由中；Lesson1–6在词卡末组与答题结算的按钮组上方显示“接下来：目的地”，不能把长目的地拆成按钮内第二块文字或缩字硬塞。课文最后一句用“去练习”一次完成阅读并进入理解练习，不再先确认读完、再点击下一站。明确的终点操作“查看纪念卡”仍用原语义。320px及反馈尺寸下确认单行、至少44px触控范围、与重练按钮同排且不横溢出。界面调整不得改变授星、统计、历史、重练或返回行为；其他单元推广外部去向提示需另行验收。

**课文阅读不自动附加理解结论。** 保留完整原文、教材开场问题、对白历史、必要的人物／地点标识和阅读操作状态；中文译文由孩子逐句主动展开。不额外设置自动出现的“故事进展”、剧情摘要、答案结论或语法解析栏，也不换成气泡、标签等形式默认显示同类内容。教材含义与事实核对用于编写和验收，不直接变成孩子界面上的常驻提示。需要教学讲解时，放入对应的示范、练习或按需参考，并遵守帮助记录与独立作答的要求。

所有可点内容用符合用途的按钮、链接或展开控件，支持键盘和至少44px触控范围。选择、提示、检查、重试不推动操作区或整页；换题只在题干不可见时调整视口。刷新、返回、重试保留题目、未提交选择及候选顺序，不能代答或越题。

题号表示所在题；进度绿格只表示真实答对。最后一题答对立即全绿，重复提交不加格；再练本轮归零。无配音必做题不要求键盘输入英文。

### 3.1 单屏答题（Lesson 1–144，2026-11-09全书推广）

2026-11-10补充：进度条须检查实际色块边界，色块高度跟随容器，不能出现“6px容器装14px色块”。进度到题干保留清楚间隔，紧凑规则不再挤掉这段留白。长图文材料可合并为一个明确入口，完整原文、原图与关闭操作都可达；不叠加装饰性情境入口，且不能改题目或计分。见[本次修复与回归](../../designs/learning-flow/2026-11-10-words-story-material-layout.md)。

**常规题的题干、选项、已选词块、反馈及检查／重试／下一题必须同屏可操作。** 以浏览器当前可用高度分配空间，不能只按宽度缩放，也不能用整页缩小、裁切选项或隐藏作答材料来满足一屏。新显示层只在Lesson1–2、3–4、5–6启用，其他单元暂保留原布局；推广须逐题检查，不由共用文件修改推定72课全部验收。

- **顶部收拢。** 全部72单元使用第3.2节的48＋44px共用导航和五阶段入口；不再额外保留56px旧关卡下拉。学习记录、学习设置、星数及本关参考收进更多菜单。正常同步不独占一行，待同步／失败仍在导航提示。菜单显式居中、限制可见高度，关闭记录或设置后焦点回到更多。
- **中间完整作答，底部稳定操作。** 活动题独占答题视图，反馈与主按钮作为独立底部区域；未作答仅预留22–26px短反馈位，不预留80–122px空白。检查、重试、下一题原位替换；提示浮于操作区上方且可主动收起，不推动题干或按钮。
- **按题型收紧。** 配对编号与文字横排；短词行约56px、间距8px。词块保留原待选顺序、选中位置和撤回机制，不能因压缩遮住已选词块。主要文字至少16px，交互目标至少44px；缩小的是留白和装饰，图片等比、人物完整。
- **材料按实际可用高度分配。** 短示范、原文和情境材料优先完整显示，不能先固定为104／130px而在下方仍有大量空白时迫使用户内滚。先保留反馈与主操作，再按整题剩余空间决定是否限高；确实不足时材料局部滚动并可键盘聚焦，选项不移出屏幕。极短横屏／浏览器放大等边界允许中央区域滚动，底部操作仍可达；不把这一回退用于普通手机题目的默认布局。
- **短屏按真实内容预算。** 700px以下优先减纸面内边距；620px以下减少词块空槽与操作栏装饰间距，保留22px反馈、44px按钮。三项长句填空仅在等宽排布确实降低溢出时换列，不按答案状态换列。320×568压力屏的长示范可缩至48px局部滚动，全文不删、可键盘聚焦；正常SE不借此隐藏选项。逐题同时检查候选、已选词块和嵌套容器，不能只检查页面无横滚。
- **同题稳定。** 排版选择在题目呈现、字体就绪或视口变化时计算，同题选中、检查、反馈不得反复换列或改变底部高度。对白容器与人物点击区分区，必须实际轻点人物中心，不能只检查按钮矩形存在。
- **文字必须被自己的控件完整容纳。** 姓名、题干、选项、图片说明、反馈和统计标签检查逐行文本范围，不仅检查父元素矩形；配合截图确认可见遮挡。长句选项在选中、判分禁用、回看和变更尺寸后均要撑开正确高度，不能让文字越过圆角边框。普通纯文本选项按当前实际行数、行高、内边距与边框确定最低高度，重排后重新计算，图形按钮与词块保留自己的结构；可访问名称、选项值和判分不变。截图可能触发浏览器重新排版，检查必须同时保留截图前、帧边界和截图后的测量，不能只凭被截图“修好”的终态结论。
- **词块布局不能依赖一次幸运的随机顺序。** 两个长词块连续出现等合法排列也要覆盖。空间不足时可按词块宽度选择普通非dense分列，让长词块跨列并自然换行；只在确实减少高度时采用。不能重排DOM、视觉阅读顺序、键盘顺序或已保存的词块次序；不以缩字、裁字或缩小44px点击目标换取一屏。
- **数据与流程保持。** 继续调用原题目、选项、判分、轮次、帮助记录、存储及奖励逻辑；导航、刷新、更多菜单和转屏不增加作答次数。正常结束后恢复原结算／纪念卡流程，不改答对飞星和关闭后统计的顺序。
- **词卡分页始终可达。** 全部72单元每组仍六词，保留原词库和翻组书签；卡面先呈现图、英文和音标，展开后保留原词和音标、显示中文与例句。正常必测手机的折叠态按实际可用高度分配三行，必须完整显示六词且无额外滚动条；末组“下一站”提示也纳入高度预算。插图等比适配剩余空间，文字字号与信息不削减；展开长例句或320px压力场景时才允许内容自然滚动。组号与翻组按钮位置保持，切换词义不推移操作。不能用隐藏溢出或接受1px溢出来掩盖实际出现的滚动条。
- **全文入口不能藏进截断区。** 材料题的“查看全文”在限高材料容器之外；打开独立阅读面板，完整原文可滚动，标题与关闭始终可达。关闭后回到原题和触发按钮，不修改选项、题号或记录。

### 3.2 连贯的学习界面（Lesson1–144）

2026-11-10补充：故事气泡按Lesson1–2样板组织，姓名和“中文”按钮同排，英文在下，译文完整展开；按钮至少44px，左右归属跟随说话人。阅读区和场景连贯时，必须保留人物、道具与地面的原坐标，不可为填满画面随意拉伸背景。本次树林场景仅延续原底色并去除内部边线。

单题可操作之外，还须验证“课文→答题→得星→结算→下一关／返回／重练”的连续体验。本节只升级呈现，不修改教学版本、作答签名和已有记录；Lesson1–6共同使用学习承载层，其余69个单元复用前须另验对应场景，不能由样板通过推定全课完成。

- **导航贯穿环节。** Lesson1–6使用48px课号／已学摘要／返回／更多栏，加44px可点击的五阶段行，总预留为92px；不再同时显示关卡下拉。阅读、答题、结算、封面、词卡和纪念卡共用同一导航，结束一组不能切回158px旧导航。封面和纪念卡可从更多进入，完成后的纪念卡主操作保留。阶段链接按本课原活动与路由别名生成，不把别课路径硬编码到共用层。主操作位置不因换界面上下跳位。
- **纸面与信息层级一致。** 题卡和结算卡采用暖纸、细柔边框、轻阴影与统一绿色主按钮；Lesson1–6作答纸面的纹理、边框和阴影由持续存在的承载层绘制，高度由当前视口和稳定操作栏确定。同一视口内跨题型、订正和回看不按题长改变外框高度或重新居中，题目内容在该区域内更新；长题按第3.1节保留材料与触控下限，不能裁掉内容凑一屏。课文整个对白滚动容器仍透明，只有独立气泡保留纸色，不把作答纸面铺到街景上。未判分的选择不显示成正确。
- **页面衔接与单题切换分开。** 导航和背景保持；结果、词卡等环节可使用190ms轻过渡，课文新气泡160ms轻显。单题前进、订正重绘和只读回看不得重新把整个题卡淡到半透明或整体上下位移；新题DOM完整后必须在首次绘制前完成呈现适配与尺寸计算，禁止先画自然尺寸再下一帧收紧。反馈原位更新，尊重减少动态；纪念卡星光与奖励顺序保持。遇图片闪动先同时检查真实图片就绪、整卡透明度与逐帧几何，不能只凭终态截图或资源已缓存判定正常，也不能未经复现就将问题归于网络。
- **旧布局约束须显式清理。** 绝对定位对白区从旧grid改为分层场景时，同时检查`align-self`、`grid-area`、宽高和inset的计算结果。Lesson3–4曾继承`align-self:start`使对白撑到约1500px，最后一句不可见；只改父容器高度不能解决。所有场景核对初句、末句、译文和转屏。
- **人物与持物同参照。** 课文人物完整显示，归还后的手提包以女士容器为定位基准；转屏、切景和恢复不能再用不相干的视口偏移定位持物。对话历史在场景内部滚动，当前句可见，翻看历史不被无故拉回。
- **课文舞台有比例上限。** 页面可占满可用高度，插画舞台不得随高屏无限拉长。Lesson1–6竖向布局舞台最高640px，宽屏／短横屏最高560px，并始终受实际可用高度约束；人物随空间适度放大，不能保持固定小人而将背景撑到千像素。舞台与阅读进度作为同一内容组居中，计数紧跟舞台，底部操作仍稳定。对话区为气泡尖角留足横向边距，不能靠裁切文字或隐藏溢出来掩盖错误。
- **课文完成区有明确空间分配。** 读完后计数与完成状态合成一行，下面保留去向及两个齐平的操作按钮；不再把额外完成标题塞入88px操作栏，也不保留穿过文字的旧分隔线。固定高度要容纳所有可见子元素，右侧目的地提示不能把右按钮单独推低。检查所有按钮、文字与状态之间的间隔及包含关系，不能仅确认下一站按钮在屏幕内。
- **保留原焦点归属。** 更多、记录和设置关闭后可回到更多；奖励卡关闭后回到当前学习结果，不能被通用弹层监听器抢回导航。快速前进／返回取消旧过渡，旧动画结束回调不得清除新动画状态。
- **参考资料不挤占学习主区域。** 单屏答题与结算都只保留该状态需要的内容。“礼貌用语”“换个物品问一问”等资料统一从更多进入独立阅读面板，不能仅在答题时隐藏、结算时又出现在固定高度容器内。英文与中文说明按条目成组，保留原文；标题和关闭按钮固定可见，只有正文滚动，关闭后恢复原任务和焦点。学习记录、提示次数和成绩不因查看参考资料变化。不要全局隐藏所有`details`：纪念卡旁的练习纸等独立功能仍须保留。
- **跨环节验收不能只看终态。** 切换采样必须包含前一题、切换边界和后一题；空内容、隐藏或缺失帧也记录，不能先筛掉再判定通过。同时核对前后纸面几何、导航、透明度、图片、操作栏和实际截图；“新题出现后几帧不动”不等于切换平稳。覆盖开始阅读、中文展开、阅读完成、真实得星、结果、返回、重练与减少动态。固定容器检查旧flex／换行和最终计算样式，含ID的全局选择器及`:not`、`:is`优先级不能因局部规则写在后面而忽略；不可用裁切掩盖冲突。
- **同时检查最上层保护和真实绘制。** 题卡本身保持`visible`也可能被不透明加载层盖住；课中正常切题必须同时监测`data-course-painting`、课程加载层插入、实际合成帧与目标图片区域。概率性问题按用户指出的前进／回看路径重复复现，记录实际标签页、URL、视口、题号和来源版本；错误标签页、尺寸或过渡占位的画面须拒收。静态终态、图片`complete`、没有JS报错或截图文件存在都不能单独作为“不闪”的结论。图片来源与节点状态的规则维护在唯一[加载缓存设计](2026-09-24-2031-v1.0-网页加载缓存设计.md)，不通过移除真实故障保护掩盖闪烁。
- **桌面工作区也要收拢。** Lesson1–6在宽度≥1024px时，整个学习工作区最高720px，在导航下剩余空间内居中；题卡和主操作共同受此上限约束，不能只缩题卡却把按钮留在千像素页面底部。手机继续使用可用高度与稳定底部操作，不能照搬桌面留白。
- **学习记录不是第二个长页面。** 标题和关闭固定，只有正文滚动；按关卡分组，默认展开当前关卡，先呈现已学阶段与收藏星数摘要。逐题区分“本轮”与“此前”；优先读取已校验的当前轮提交状态，旧记录作为回退，重练尚未作答的题不能把此前成绩冒称本轮。兼容合并／升级后的轮次身份，不改写原记录。遮罩、关闭和Escape均恢复原任务及焦点。
- **返回阅读保留真实位置。** 离开课文前保存对白滚动位置与是否位于末尾；返回后在新尺寸下恢复。末句要完整可见，主动向上翻看历史不能被强制拉到末尾；隐藏场景时的尺寸归零不得覆盖已保存的位置。

本轮实现、保留的首错及视觉对照见[Lesson1–2流程打磨记录](../../designs/learning-flow/README.md)。后续首页／纪念册或其他课程的升级不能由本样板推定已完成。

参考区修正追加验收：逐个检查带附加资料的活动在未作答、结算、重练和回看状态下的布局，不能仅用某一个不含资料的结算页推定全课通过。SE与两档Pro Max检查完整统计、按钮位置、资料末条可读及关闭可达；见[参考资料布局修复](../../designs/learning-flow/reference-panel.md)。

课文追加验收：大屏也要验证开始阅读、本课全部句子读完、中文展开、进入练习后返回与刷新，不能用桌面结算页通过替代课文检查。固定加入用户反馈的1435×1244，并检查1366×768、768×1024、699／700断点及三种必测手机；Lesson3–4、5–6另核对12句／20句及末句译文；人物与舞台比例、末句完整、横向滚动为零和阅读记录同时核对，见[课文舞台比例修复](../../designs/learning-flow/story-layout.md)。

### 3.3 题目回看、情境与里程碑（2026-11-01，Lesson1–6）

- **查看位置与作答位置分开。** 上一题只浏览当前轮已提交并已前进的题，不能访问未来题。回看保留该题当时的选项／词块顺序、配对与最终答案，所有答案控件只读；明确显示“回看 X / N”和首答／订正状态。当前题未提交草稿仍可修改，错答沿用原订正规则并保留全部错误次数。进入下一题后不得回改成绩，不把回看设计为重做。
- **回看没有学习数据写入。** 查看游标只在内存，不修改真实`group.index`或版本／轮次签名；输入适配器使用历史答案的深副本，拦截禁用按钮的程序事件。回看、讲解和纯回看导航不写学习位置、不提交进度、不重新判分、统计或授星。刷新回到真实作答位置或已存结果；仅保存最终答案的旧记录不补造每次错选详情。
- **回到原任务清楚可达。** 上一题与主操作共用原底部一行，第一题禁用上一题；回看时下一题只移动查看位置。回看题头直接提供“回到当前题”或“返回结果”，更多菜单只作为备用入口；反馈用“首答正确／订正后答对”，不重复堆叠“只读回看”等术语。完成后仍可回看本轮答题，恢复复用原结果，不再次触发完成回调、纪念卡或三卡统计；重练才开启新轮次。奖励尚未结束时不能通过回看绕过门禁，恢复后焦点回到题目／结果而非更多按钮。
- **情境是题干的一部分。** 作答必要的情境、词义、说话人与物品归属原文完整保留，与题干组成同一个标题区，使用较轻正文，不独立做成悬浮提示或突兀彩块。示范、原文阅读、题干补充各司其职；不得为缩短页面删除事实或改变题库签名。
- **对话材料按内容确定姓名列。** 同一段材料按实际字体测量最长角色名，各行共用该列宽和可换行正文列，统一24px首行行高及8px列间距；不得把适用于“男士”的32px硬套到“工作人员”或“Mr. Blake”。姓名列最多占行宽30%，极长姓名在自己的列内换行，不省略或改写名称；正文首行对齐、第二个说话人不无意缩进。字体就绪和视口变化后重新核对实际文本范围，不能只检查元素外框或依赖不同字号的默认baseline。
- **讲解主动打开。** 答对后的原语法规则不自动覆盖题目；提示和讲解共用上一题与主操作之间的灯泡位置，触控范围至少44px。复用原灯泡图标，答前保留原线索、答后提供有原规则的讲解，读屏名称分别为“给点线索／讲解”；DOM焦点顺序与视觉顺序一致，不能只靠低优先级的order声明。弹层显式居中、限制宽高，关闭回到灯泡；讲解不计提示次数、不重排底部操作，没有原规则不凭空补解释。反馈与主按钮位置在答前／答后保持。
- **已学进度、本轮题组和收藏星分开。** 导航显示“词汇、故事、语法、应用、挑战”五阶段及“已学N/5”；已学数量按当前题稿有效完成事实计算，重练不倒退，本轮题数才归零。绿色对号仅表示该环节已实际获星；订正完成但未获星、尚待服务器确认时保留阶段序号，不能仅凭完成或答对状态打勾。集齐5星显示5个绿勾，部分获星只勾选对应环节。已有获星不因重练或后续错答消失；旧五星可以显示收藏成果，但不能补造新版已学数量。当前阶段高亮与获星对号分别表达，辅助名称区分“已获星／已学完，未获星／未学完，未获星”。五阶段是唯一可见的关卡切换入口：原生链接、至少44×44px；词汇进入原词卡、故事进入原阅读，保留后续练习及阅读门禁。点击阶段只导航，不完成任务、不授星、不改答案；键盘、浏览器后退和当前草稿恢复均须验证。
- **错误反馈服从已确认的短提示。** Lesson1–6固定为“答错了，再试试。”，保留当前题订正和真实错误次数，不追加操作指导、答案、排除候选或自动解析。原题标题、任务说明与必要材料负责说明怎么做，不能借F06扩展错误区内容。
- **展示文案与题目身份分离。** 短标题优先明确动作，例如“用词块问：我是学生吗？”、“isn’t等于哪两个词？”。规则用简短解释配例句，材料仍保留人物与物品归属；文案映射不得改题库对象、题目ID、答案、选择顺序或内容签名。共用呈现器须兼容未配置新文案的课程。
- **新增导航必须重验可用高度。** 总头部高度统一由变量管理，覆盖阅读、题目、结果、词卡和纪念卡，打印隐藏两行导航。320×568、375×667须逐题复验；长场景优先减少留白与场景占高，人物仍完整，按钮至少44px，不缩字或隐藏材料来凑一屏。真实触摸、回看恢复、刷新、重练、错答、待同步、成果和减少动态都须包含在影响性验证中。
- **人物持物与姓名分层。** 归还到手中的道具与人物图片放在同一比例画板中，用人物自身的百分比锚点定位；姓名位于画板之外。不得用整个按钮（含姓名和内边距）作为持物坐标。通用选项缩略图规则只命中直属主图，不能穿透到嵌套道具。验收含答前、答后、订正、只读回看、确认归属与选择接收者两种场景及同次挂载尺寸切换，核对道具、姓名和按钮实际边界。
- **基础配色不依赖当前路由。** 学习页按钮的底色、边框和文字颜色，在未激活的课程页面也应保持同一主题；路由激活类只控制当前布局和显隐，不触发旧主题到新主题的颜色插值。保留真实选中、禁用和点击反馈，以及认可的内容入场过渡。纪念卡出口须逐帧验证第一次和重复进入，不能只用最终截图排除闪色。根因与证据见[人物持物与出口闪色修复](../../designs/learning-flow/2026-11-08-props-and-control-colors.md)。
- **封面不能以“按钮在屏内”作为布局合格线。** Lesson1–6由共用学习层统一封面内边距、图文间距和主按钮；清理旧课程封面的重要内边距及插图四侧自动外边距影响。插图与文案保持连续，自动留白只分配在整组内容外侧。按钮至少48px高，四周保持可见空间，底边距至少16px并计入安全区；正常必测手机一屏完整显示，不能把阴影或末行压在页面边缘。极矮窗口从顶部开始自然滚动，不用强制居中造成上部无法滚回。保留各单元人物与环境图层，布局改动不得覆盖已有场景背景。见[封面间距与底部边界修复](../../designs/learning-flow/2026-11-08-cover-spacing.md)。
- **参考资料按阅读内容排版。** 参考弹层中的条目不继承旧教学卡152px最小高度、汽车展板105px图片或额外外框。图片区、英文、中文、编号各有明确位置，图片不能越过自己的列压住文字；无图片的条目使用完整文字列。独立提示卡与后续卡组之间同样保留间隔，不能只检查组内gap。原例句、国别说明与编号完整保留。
- **空反馈不能叠成大块留白。** 课程内纪念卡的保存反馈保留一行位置，主导航与练习纸之间的总间隔保持紧凑；本轮收敛为32px，不能重新叠加空状态25px、双侧margin和练习区24px边距。保存反馈出现时，原卡、保存与课程导航不跳动。
- **长弹层只滚动正文。** 更多菜单展开书面练习时，标题与关闭同参考资料、学习记录一样常驻；正文承担滚动，展开后自动定位、滚到最底部仍能直接关闭。练习编号位于自己的内容边界内；学习记录只保留一套展开箭头，不再叠加伸出分组外框的默认列表圆点。
- **复制展示不等于复制交互。** 由原内容克隆到弹层的功能按钮必须连接原行为。打印沿用原练习纸动作；打印前临时展开真正被打印的原节点，结束或取消后恢复原折叠状态，不改学习记录。回归不能只检查“打印按钮存在”或调用过print，须在打印媒体下检查首末练习内容可见、菜单不混入打印，再检查恢复状态；物理打印机验收单列。

上述跨页面规则的本次完整复查、七类修复与截图见[Lesson1–6完整复查报告](../../designs/learning-flow/2026-11-08-lessons1-6-complete-audit.md)。答题纸面为稳定切题而保留的空间不按题长重新缩框；阅读卡的冗余留白与这一约束须分开判断。

首轮实现与首错见[回看与里程碑实施记录](../../designs/learning-flow/question-review.md)，Lesson3–6的扩展见[接入记录](../../designs/learning-flow/2026-11-01-lessons3-6-learning-flow.md)。本样板不表示其余69个单元已接入。

## 4. 怎样呈现：统一画风，每课有自己的故事

**2026-11-01补强：从首页进入课堂的连续视觉。** 本次以Lesson3–4为实施样板，见[完整链路与证据](../../designs/learning-flow/2026-11-01-unit34-journey-visual.md)；其他课逐课复核后推广，规范更新不表示全部72课已换素材。

- **美术基准明确。** 优先使用本课首页已认可的人物与环境为主参考，纪念卡提供身份与故事依据。固定脸型、头身比例、服装、轮廓、材质和光照，再扩展动作；不能只换按钮颜色而保留另一套修长人物／线框布景。现有纪念卡及旧证不因课堂美术升级重做或覆盖。
- **同一地点，不同学习密度。** 首页展示外景，剧场是可辨认的同一地点近景／室内；答题时环境淡化，正文落在清楚的不透明纸面；完成时复用同角色与环境。保留原续学落点，不为每次展示新场景强制重播课文。首页星花、暖纸、暖棕、深绿主操作和金色成果贯穿，课内主题色作点缀。
- **背景不能携带作答答案。** 通用环境不预画人物、待辨认衣物／雨伞、寄存数字或选项。教学道具由原题稿和剧情控制，红纯色、黄条纹、紫圆点三伞及数字5等事实不得被美术替换改变。情境必要的物件仍完整呈现，题目、原答案、版本／签名不为换图而重写。
- **人物、地面与物品同一画板。** 认领亭样板采用完整3:2背景与同坐标人物／柜台／道具；对白为独立真实UI，不把整块作答纸面铺在剧场对白后。按透明图实际轮廓、手掌和握柄测量，不按空白外框定位；分别检查等待、错误认领、交换、领回。小屏答题要先预留固定对白／按钮区域，再缩小整组场景，禁止新增剧情框把选项挤出一屏。
- **道具必须有可理解的支撑关系。** 认领前外套搭在台沿，领回后搭在前臂；伞杆／握柄可由手或台面支撑，不悬在两人中间。纠正一个物件位置后，必须同时检查相邻道具、脸和台面；不能让移近柜台的伞面盖住工作人员。用源图光学支撑点投影检查接触，以截图复核；仅证明图片矩形在屏内不够。
- **运行图与原稿分离。** 提示词、参考图、实际原稿、透明检查、采用图SHA及几何登记在固定包；运行时只注册明确的采用WebP，不能用目录前缀把原始PNG整包预载。不把固定提示词等同于再次生成逐像素一致，后续优先复用采用素材并附同一角色参照。
- **跨页面视觉验收独立于功能测试。** 同一课程、相同CSS视口，必须把首页、剧场、答题与结算并排检查人物、道具、空间、配色和字体，同时检查原纪念卡。源图和页面尺寸／密度不同应先归一、记录，不能把被截断的采集图当成产品问题或通过证据。SE和两档Pro Max必测，完整逐题、恢复、奖励与防闪检查仍保留；有角色漂移、素材拼贴、白边、错误道具或主要内容遮挡时，功能测试通过也不能验收。

- 品牌统一为“灿然英语工作室”，网站及加载页复用 `assets/brand/starflower.png`；沿用圆角与深棕描边。
- **整单元统一字体，保留信息层级。** 中文用寒蝉圆黑体：正文 Regular 400，标题、按钮及重点 Medium 500；英文用 Nunito：句子／正文 Regular 400，单词、按钮／导航及重点 SemiBold 600。封面、图鉴、对白、练习、结算、纪念卡、书页与导出遵循同一分工，不统一成同一字号或粗细。音标单独用完整覆盖 IPA 的字体，45–46 沿用 Arial，不能强换 Nunito 导致缺字或混杂字形。
- 字库本地随课准备，使用真实字重，不合成粗体。正文可按文案裁成字库子集，新增文字须补齐；动态姓名保留完整中文覆盖。换字体后复查换行、按钮、长姓名与导出；加载细则见第7节。
- 可读性检查针对字体就绪后的真实可见内容：词卡正面长单词不被意外拆开，词组可在合理词间换行；参考表在手机可改为关系组，但字段和含义不能丢失。图内英文与数字也遵循字体分工；无横向溢出、图片可解码或文件存在都不等于清晰可读。
- **人物沿用本课已确认的视觉身份。** 首页、纪念卡、封面、图鉴、课文、题目及完成画面保持同一角色的头身比例、面部画法、轮廓、配色与质感，按剧情换动作和表情。首页已有认可新风格时，课堂按它衔接，原纪念卡继续保留；新单元先对照第6节认可样板确定基准，再扩展，不能另画一套风格不同的课内人物。
- **图鉴道具也要与人物同画风。** 优先复用已认可人物；需要新绘制的汽车、太阳等采用暖棕手绘轮廓、柔和纸感填色与克制体积。以暖纸卡面、细柔边框和轻阴影承载，不把旧扁平小图标放进厚边框大空卡。准确国旗、图表和题目识别标签优先保证教学事实，不能为画风重画错国旗或删去题目依赖的品牌名。词卡专属插图与作答用标牌应分开引用。
- **词卡按实际屏幕核验。** 手机两列，宽屏可三列；大图、英文和音标有独立稳定空间，中文展开后仍能对照原词与音标。24词等整组范围逐张检查长词、长释义和例句，展开前后邻卡位置不动，内容不裁切；透明切图在暖纸和白底都没有白框或晕边。源PNG、采用WEBP、实际提示词、参考图和取舍分别保留，运行包只引用采用图。自动几何通过后，仍须并排目视剧场／纪念卡与最终词卡。
- **首页课程横幅也是本单元的视觉交付。** 首页入口、课内封面和当前纪念卡须对照同一角色与故事基准，核对人物身份、画风、关键物品和构图；三处可以因比例不同采用不同构图，不强制同一个文件。已有合格插画可以复用，不要求每次重新生成。旧证书保留原图与日期，不等于现行入口必须继续使用旧画风。
- 角色靠轮廓、服装结构、发型和配件辨认，不能只换衣服颜色。教材同一人物可复用身份，不同情境换姿态；同名不自动判定为同一人。相邻易混单元须并排对照。
- 单元可变化背景、主题色和活动容器；选中、正确、错误、禁用、焦点的含义全站一致。图鉴、舞台、练习和完成区有层次，不让装饰抢题目。
- **对白放在场景内。** 开场问题和对白历史与人物、道具同处一个场景框；桌面与手机都不另排到场景下方。气泡靠近对应角色，历史区固定高度、内部滚动；长句和中文完整可读，短句不撑巨大卡片。窄屏可在场景内重排，不能遮住脸、手和关键道具。
- **人物不能被意外裁切。** 舞台全身人物的头发、手指、双脚及持物完整可见；源素材和页面容器都须留安全余量。伸手、持物、换姿态和切景逐一检查，不能靠裁人物或过度缩小人物腾出对白空间。纪念卡的近景构图按第6节，不等于允许素材断手、缺脸。
- **人物应面向交谈对象。** 站位、视线与手势随对方位置调整；换边、换姿态、切景和刷新后都须复查。镜像仅作用于适合翻转的人物图，姓名、文字和独立道具保持正常；含文字或有明确左右含义的姿态另备素材，不整组翻转。
- 人物站得住，道具看得清；关键物品贯穿封面、课文、练习、结算和导出图，身份与交接时机随剧情准确变化。
- 关键物件与教学图保留正确比例，背景的适配不能连带拉伸人物、物件或数值图。检查实际绘制尺寸、可见实体边界及接触关系，不只按图片外框定位；源文件内部留白、容器高度限制和浏览器自然尺寸取整须分别核对。答前装饰不得复制或突出正确候选、绕过材料判断。
- 素材边界按用途制定：全身人物、中近景卡面、透明切图和不透明照片分别核对原稿、页面及导出。透明通道或边缘指标通过不能替代目视；不把不透明照片强行套用切图的透明边缘要求，也不容许把透明预览棋盘格误画为背景、意外断手或关键物品缺失。
- 先做好一个代表场景的未答、错答、答对与结束状态，再扩展。批量开发仍逐课提交设计、桌面／手机画面和验收；一课通过不代表整批通过。功能通过与画面美观分别判断。

## 5. 怎样结算：固定三卡，题数与提交次数分开

本轮从开始练习或点击“再练一轮”起，到主动完成该答题区止。刷新、离开续做不另开一轮。只有点击检查并得到判分才计一次，选项变更、提示、回看和重复点击已禁用按钮不计数。

Lesson1–144全部72个单元按用户确认的共用界面采用以下展示，实际账本保留原口径；实施和验证范围见2026-11-09全书记录。

| 固定卡片 | 口径与图标 |
| --- | --- |
| 连续答对 | 本轮最长连续答对次数，单位“次”；答错即中断，订正答对从1累计。恢复认可的金色星形统计图标，它不表示获得了同等数量的收藏星。 |
| 首答正确 | 第一次提交即正确的题数，单位“题”；绿色对勾。用过提示／示范的记录仍保留，不宣称独立掌握。 |
| 订正完成 | 首答未对、后来订正完成的题数，单位“题”；重试箭头。一个题多次答错仍只计一题。 |

完成页“首答正确题数＋订正完成题数＝本轮总题数”。例：10题中的第1、3题首答错误后订正，显示首答正确8题、订正完成2题；若其中一题重复答错，也不增加总题数。5题中第3题错两次后改对，三卡显示**3次／4题／1题**。

**原提交账本继续保存。** 学习记录“本轮详情”仍显示连续答对、本次实际答对与实际答错次数，上例仍是3／5／2次；错误次数、帮助记录、轮次、奖励资格和日期不因显示方式改变。仅根据已校验的当前轮状态派生显示，不改写旧记录。合并旧活动等导致统计不完整时保留“—”及原说明，不伪造零次、首答全对或授星；重练不带入上轮统计。

所有答题区保持三卡并排、等宽等高，零值与多位数字一致；图标与含义对应，不能为减少歧义仅删除一张卡的图标造成视觉缺口。[原认可图标](../../../assets/unit1-2/completion/README.md)保留，订正完成复用既有重试箭头。人物与道具、短标题、三卡、再练／下一站构成完成页；各单元综合挑战移除“下次再练”折叠区，逐题错误和帮助信息留在学习记录，不删除数据。无题目的图鉴、课文和参考不展示统计卡。320×568短屏须完整露出三卡和两个按钮；刷新重进同样可用。

各单元每组首题在原反馈位轻提示“本组每题一次答对，可点亮一颗星。”，选中和提交不增加布局高度；答后由正常反馈替换。有错订正的完成页先肯定完成，再提示可重练争取星星，不把已完成学习描述成失败；计数、独立掌握判据及原获星不变。

不得按内容随意变成两张或四张卡。确需改变数量，须单独写明教学目的、三卡为何不足、替代方案及对比较和验收的影响，不能以排版方便作为理由。

**结算按本轮结果只走一条路径。** 末题反馈仍由孩子主动完成；完成后按下表衔接，不先展示“答对／答错”数字再用纪念卡打断，也不让统计在浮层后方提前入场、跳数或回放。

| 本轮情况 | 展示顺序 |
| --- | --- |
| 完整零错，尚未获得本区星星 | 直接展示当前真实成果的纪念卡；等待账号确认时沿用已确认星数并给出简短状态，不预发新星或日期。正式新星确认后飞入，落星完成后允许点击关闭；关闭后才显示三张统计卡并播放一次入场与跳数。展示素材准备期间同样不提前露出统计数字及其操作区。 |

| 本轮存在错答，包括订正后完成 | 不展示本轮纪念卡或飞星，直接显示三张统计卡并播放一次结算动画。已有星和收藏继续保留，不因本轮有错扣回。 |
| 已完成轮次刷新、返回或跨设备回看 | 直接读取已保存结果，不重新庆祝或重复计数；确实开始并完成新一轮时再按对应分支结算。 |

**异步确认不得改变已结束的展示顺序。** 等待奖励不能无限阻塞结果：离线、同步失败或展示资源失败时，保留学习记录和真实待同步状态，允许直接查看本轮统计。该轮已显示统计、离开活动、进入新一轮或切换身份后，迟到的确认只按原规则更新成果，不突然插入旧轮纪念卡、飞星或再次播放统计。不得为消除等待提前授奖，也不清除尚待同步的真实获星请求。

动画是否已播放、当前是否等待卡片只属于呈现状态；不得据此重开有效轮次、修改题目版本、清空作答／错答，或改写旧证内容和领取日期。等待／飞星期间不在可访问名称中提前宣称可关闭；就绪后才提供关闭提示。用户关闭卡片后优先聚焦“下一站／查看纪念卡”等主推进，无推进操作才使用原回退焦点，不能默认落到“再练一轮”。提前点击／按键仍不得穿透奖励门禁。

## 6. 怎样获星：每单元固定五颗，完成与奖励分开

- **五个答题区，每区最多一颗，共五颗。** Lesson 3–4 合为一个单元，共五颗；不是两课各五颗。题量、页面数和参考材料不增加星位。
- 本轮全部题目完成、实际答错0次，并主动完成该区，才可获得该区星星。订正可完成学习但本轮不发新星；重新完整挑战零错可再争取。提示不算错答，但不能因此称为独立掌握。
- 已获星不因重练、后来答错、刷新或换设备扣回。首次五星日期由服务器固定、按北京时间显示，未满星不显示日期；新卡版本保留旧卡和旧日期，不用动画结束时间或设备时间代替。
- 姓名取登录学生；正式奖励归账号，离线先存本机并显示待同步，确认后点亮。匿名和教师预览不能冒充学生成果、不能导出；换学生清除上一人的画面、待展示事件和导出任务。关课不删除已得收藏，重开不扣旧星。
- 卡面沿用本课故事，0星空位静止且不能保存，1–4星仅亮星持续发光、普通边框，第5星才开启流动金边。首星入纪念册；课程底部、悬浮卡、书页、放大与导出使用同一身份和成果快照。
- **当前纪念卡统一固定横版。** 课程底部、得星弹层和纪念册采用同一个1640×880（41∶22）设计平面，整体等比适配手机、平板和电脑。禁止小于600px后切成竖版或把人物移到文字下方；姓名、星位、插图、金边与纸纹保持相对位置和比例。高度不足时整卡缩小，外部保存／关闭操作仍可用；历史纸证继续保留原比例。遵守[纪念册M50–M51](../../award-version/纪念册统一设计标准.md)，本次只改显示，不改课程版本、授星与导出画布。

- 奖励光效默认开启，不因系统减少动态设置或翻页开关而隐藏；其余页面仍支持减少动态。姓名、人物和纸色稳定，光效不扫过主体或频繁闪烁。先准备真实参与展示的图片节点与字体；离屏暂停、恢复不重授奖，素材或动画失败仍能继续学习。

教学完成、提示后完成、订正完成与获星分别记录；统计次数不能替代能力判断。获星判据及教学记录仍可保存每题作答证据，不改变本节规定。

## 7. 声音、加载与访问

**登录等待提示（2026-10-25修正）。** 被限流时按服务器原截止时间显示真实剩余倒计时及明确的北京时间解除时刻，不固定提示“再等十五分钟”。到期恢复按钮，由用户主动重试，不轮询或自动提交密码。账号限制下允许切换其他账号，来源限制保持。普通界面修复和管理员改名保留学习记录、旧证及领取日期，不触发一次性课程重置。接口及验收范围见[登录冷却专项](../../security-version/2026-10-25-登录冷却提示与管理员改名.md)。

| 模式 | 必须做到 |
| --- | --- |
| 配音版 | 词音、句音按语境、音标和实际发音逐条听审，记录来源；不能仅凭能播放、AI转写或旧文件存在就通过。听辨用显著喇叭，指定录音真实结束才开放检查；失败可重试，旧播放回调不推进新题，不能悄悄切成无配音。 |
| 无配音课堂配套版 | 不请求、预载或播放英语录音，不用系统朗读；保留音标与正误反馈音。图鉴翻词义、课文主动阅读、词义／看图／阅读题提供完整依据，不能称听力达标。教师负责发音、听力与真实交流；所有声音失败仍可通关。 |

单元文档先声明模式；已登记单元的模式与资料见[单元索引](../2026-10-15-0041-v1.0-教学单元设计与验收索引.md)，实际开课和线上版本按单元及发布记录核对。新单元按用户确认采用，改变模式须同时改题目依据、名称、门槛与记录；旧听力成绩不能代答新阅读题。停用录音不等于发音已修复。

课程完整资源准备好再进入，复访复用缓存，课中不闪回加载层。资源缓存与学习记录分离，清缓存不清作答；协议与恢复细则维护在[网页加载缓存设计](2026-09-24-2031-v1.0-网页加载缓存设计.md)，既有速度目标、测量边界及更新检测成本汇总在[性能设计标准与验收清单](2026-10-23-2107-v1.0-性能设计标准与验收清单.md)。100毫秒点击反馈、已准备目录条件下5秒冷加载、20次复访P95 1.5秒及零重复资源下载要求保留，不通过删必需素材、缩减字库或清学习数据提速。普通更新3–5分钟错峰与独立撤回检查均由共享加载层实施，不增加新课重复开发负担。

**目录与课内准备分开（2026-10-21故障修正）。** 登录后的课程目录在身份、班级授权及成果读取完成后即可选择课程；不等待全班插画和完整共用字库下载。目录插画按需准备，单图失败只在该横幅提供重试，保留课程名、进度及入口；字体后台预备失败同样不能封锁目录。完整中文字库、旧证字体和逐文件校验保留，进入某课仍须满足本课完整资源与字体要求。验收必须从未准备的真实目录操作，注入实际图片／字体失败并证明其他课可进入、原地可重试，不能只在目录预热完成后验证入口。详细边界见加载缓存设计第12节。

目录离开时须取消本页后台准备并释放资源占用，浏览器返回目录后恢复准备；旧目录不能持有字体锁而阻塞新课。保持原生点课和新标签行为，不增加无限等待入口。生命周期及真实复访验收口径见性能设计标准第3节，由共享加载层维护，适用于所有现行课程，不要求新课各自实现或机械重跑全站。

**先确认实际版本与故障触达。** 故障测试先对照构建课包、资源去重／别名和实际请求，确认目标确实收到预期故障，再检查拦截、重试与恢复；Worker发起的请求也须触达。未命中目标只说明该次测试未成立，不能当成恢复通过。恢复后的刷新、目录复访、答题与记录保护仍按独立缓存清单执行。

**统一进入最新版（O18，2026-10-24）。** 每次进入课程先核对授权后的最新完整课包；目录不再提供“继续旧版／进入新版”选择。已打开页仍使用同一套完整资源，检测到更新只提供“刷新课程”；刷新和下次进入采用最新版，不在作答中途混入新文件。最新包失败可重试或返回目录，不能把旧包作为用户长期入口。后台保留的兼容发布目录仅供维护者回退。轻量元数据、ETag、错峰及失败退避继续执行，不每次下载全部资源。

构建成功或服务重启不等于当前页面已使用新课包。沿正常更新流程核对可见变更及适用的版本标识；刷新、目录再入等操作按实际情况选择，不规定所有环境必须走同一顺序。不得通过清学习数据、伪造状态或无依据重开轮次掩盖版本／恢复问题。

登录首页坚持一单元一横幅，按班级开放；新课不自动向旧班开放，直链仍校验权限。账号、个人收藏和公共资源分离，完整要求见[访问设计](2026-09-26-0048-v1.2-班级课程访问设计与验收.md)。给用户的本地预览默认是正确工作树的完整账号服务，使用独立测试学生，包含首页与纪念册；不使用 `file://` 或匿名页面替代。

**首页图片引用要单独核对。** 首页入口可能使用独立于课内封面的图片来源。新建或改造单元时，应核对实际运行的静态首页（如有）与登录首页加载的当前图片、返回和复访后的显示；不能以课内封面已更新、目录可进入或图片成功解码代替首页视觉通过。只更新受影响的入口；未变且已有对应证据的部分可注明依据后复用。

### 本地页面验收入口（2026-11-02，Lesson 1–6）

- 用独立[页面验收台](../../designs/learning-flow/2026-11-02-page-review-bench.md)快速查看真实封面、词卡、逐句课文、每题、结算、得星和资料弹层。目录由实际课程定义生成，状态仅提供该页面支持的项；复制链接须包含课程、验收项、状态、尺寸和星数。
- 验收台必须与真实学生数据库和成绩同步隔离，示例答题／奖励只留在内存。正式学生导航、账号接口和发布包不得携带验收适配器；预览能显示满星不代表真实授星及同步流程通过。
- 预设使用原题型、原组件和原纪念卡，不复制另一套“看起来相似”的页面。题库答案只用于构造演示状态；教材语义、题面充分性仍按下文独立验收，不用示例通关代替。
- 必含Chrome SE375×667、14/15 Pro Max430×932、16 Pro Max440×956。缩放整个预览框不改变课程内部CSS尺寸；320压力、平板／电脑按影响保留，真实手机系统行为另验。
- 全流程可见性必须包括**课程封面与返回封面**。隐藏非活动内容的ID选择器不能压过活动表面的可见规则；布局、人物及开始按钮需在实际手机视口检查，不能只验题区。
- 切项保留上一画面直到新内容就绪；迟到消息不能盖回旧项。资料、书面练习和记录调用正式弹层；奖励动画在预览可见后启动。
- **状态切换（2026-11-03）**：常用展示状态采用可直接点击、明确选中的按钮组，手机点击高度至少44px，溢出只在按钮栏内滚动。同一验收项应复用已加载文档更新演示数据，不能把每次状态选择当作整课重载；首次打开或换页仍执行原资源校验。切换前取消旧弹层／奖励动画并清理示例轮次与账本；旧窗口、旧请求的完成通知不能清除新请求的等待。以真实反馈、文档实例和资源请求检查性能及正确性，不能仅缩短加载提示。
- **位置同步（2026-11-03）**：状态按钮作用于当前实际显示的题目或页面；课内前后题、只读回看、翻组、阅读和重练必须同步外层目录、标题和链接。回看位置与本轮进度分开读取。应用状态时再次校验当前位置，连续指令继承已确认的新位置，不能依赖启动时缓存的题号。验收必须覆盖“课内导航后点外层状态按钮”，不能只测目录选题。
- **连续验题（2026-11-06）**：手动选择的题目预设与当前实际作答状态分别保存。课内进入下一道作答题、目录选题或工具翻页时自动应用受支持的预设，提供“取消沿用”恢复跟随作答。订正、检查答案和只读回看仍使用本轮记录，不能反复重建当前题或抹去之前的错误次数。不支持的页面使用自身状态，下一道兼容题恢复沿用。复制定位链接和刷新应同时保留当前画面与选择。

## 8. 交付前只核对这张表

仅通过真实页面行为验证产品；答案来自审定题稿，不从程序答案字段生成。每项记录通过／未通过／待验／不适用及证据，不适用须有理由。

按“核对来源与目标 → 未作答材料和代表场景 → 全课作答与续做 → 完整账号及导出”推进。先修复缺失线索、歧义或图形错误，再把答题走通作为验收证据；既有样板、通过的题数和截图数量不能替代逐题依据检查。

**复用先保留共用契约。** 区分课程标识、内容与共用接口，限定替换和样式整理范围。复用组件须核对实际消费的字段和题型状态；不能因清理旧主题而丢掉打印、书写线、触控、焦点、判分、错答记录、取消或恢复行为。成功通关不能代替这些分支；实施位置见[课程编写指南](../../course-authoring.md#复用课程与样式时的核对)。

**失败先留证据再定位。** 对动画采样与完整账号流程记录应用／测试版本、浏览器、挂载路径、尺寸、并发、失败阶段和耗时。先按同版本、原断言隔离复现；若已修改版本，说明差异，不能称为同版本复验。区分应用问题、测试预期错误、调度负载和环境限制，不直接减少覆盖、降低阈值、只延长超时或改慢产品动画来消除失败。隔离通过只证明该条件下通过，不证明任意负载正常或已定位底层原因。

**按影响复验，不按数量凑验证。** 修复或更改后直接验证受影响内容、真实页面和共用调用路径；未受影响的既有检查可注明版本、范围及理由后复用。新单元仍须完成本课适用的全部验收，不能用旧课结果或几道抽查代替。仅改文档时核对规则保留、状态、引用和链接，不冒记页面重新通过；不把重跑全部旧课或集中配置重构作为每次新课开发的前置条件。

**保持质量的边界**：减少重复文档和登记遗漏，不减少教材内容、独立迁移、必要对比或适用的验收项；不新增固定题数、强制题型配额、额外关卡或结算卡。验收可按实际影响复用已完成的检查，但须注明版本、范围和未覆盖项；新内容、相邻单元差异及本次改动必须有直接证据。已知失败、环境限制和未做的人工验收不得改标通过。

**O16按实际影响适用。** 下表只界定历史成果专项，不替代本课其余适用验收；实现方法见[编写指南](../../course-authoring.md#旧课升级与历史成果保护)，操作与证据见[验收说明](../../../tests/README.md#旧课升级与历史成果验收o16)。
