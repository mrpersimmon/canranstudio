# Lesson19–20 双空任务与历史成果重构 v3.1

2026-10-18 · `codex/release-canranstudio`。依据[统一标准v1.53](publish/2026-10-17-0031-v1.53-教学单元设计标准与验收清单.md)，在[现有65题五星版v3.0](2026-10-17-0258-v3.0-Lesson19-20五星重构与验收.md)上整改。保留更早36题15星成果及其旧证书；本轮不是重新将15星折算为五星。

## 1. 核对来源和范围

重新目视用户提供的课本纸38–41／PDF71–74、同步导学Grammar纸38–39／PDF52–53、语法练习册纸50–54／PDF64–68。课本保留34词卡、19个新词条、13段完整原文、20幅对比图及原数字、Written A6／B10与全部原例。对比图仍每页两幅，原参考分页不变；书写仍为A六个80×32px填空位、B四十条32px线。

原65题的综合第13题同时填三个空，违反现行逐空任务最多两空的规定；第4题把am／are／is三个判断捆在一个选项。两道旧be题进入语法区后也缺少短示范。本轮先在实际未答页面复现，再调整题目与教学支持，不以原来已经通关作为合规依据。

现行为**66题，15／3／16／8／24**。原65题中62题对象完全不变、3题修订、1题新增；只改变综合区会话，其他四区有效轮次保留。增加的一题用于重新组合原来六个判断位，每题最多两空，原教学覆盖不减、不新增语法类别，不作为其他课的题量配额。

## 2. 题目与教学支持

下表G、E分别为现行语法区和综合区顺序。完整目标与原资料边界承接v3.0；[独立作答单](../../tests/support/unit1920-fivezones.js)按教材与本表修订，不从运行时答案生成。

| 目标 | 示范／立即练习 | 独立检验与本轮调整 |
| --- | --- | --- |
| I、复数人物与单数中心词的be | G15补The girl is happy.／The girls are happy.及I am happy.，给出happy释义 | E4分别选择I的am与children的are；E5判断their mother的is。不能由their误判mother为复数。 |

| there be可数单复数与不可数名词 | G2、G3原示范及练习不变 | E14保留一顶帽子／两个袋子的is／are；原some milk判断移至E5，与their mother对照，均按中心名词决定is。原六个判断位分布在E4／5／14，每题两空。 |
| tall／long按对象选词 | 原词卡和完整20幅对比图不变 | 原E7现E8的题面只引用已提供的文字资料，去掉“给两张图配文字”的失实指令；人物身高与裤子长度两个目标保留。 |
| 存在与拥有、缩写、否定与no、一般疑问及简答 | G1、G4–11保持原设计 | 现E13、15–20继续独立运用；no仍表示完全没有，any仍限定中性询问和明确否定。 |
| Who／What／Where及many／much | G12–14、A7／8保持原设计 | 现E21–24；原E23拼复数存在句现为E24。特殊问句、数量和对象边界保持，词块题不冒称独立选择全部词形。 |

示范只改展示层，不改变G15／16题目签名；提交时按实际显示的短示范记录`revealed`，不追改历史独立作答。语法结算写“存在与状态练习完成！”。综合区撤去短示范，原支持后完成与独立运用区分不变。

课文不补写人物意愿或剧情结论，不将不冷推为热，不按职业／年龄／胖瘦评价同学。there be、some／any和Who／What的来源简化边界仍按v3.0记录执行；本轮没有改写其权威来源核对结论或扩张过去时目标。原场景、交接时刻、认可人物和卡面全部保留。

## 4. 两层历史成果保护

真实前版的11个运行文件冻结在`tests/fixtures/unit19-20-before-v153/`，独立旧作答单为`tests/support/unit1920-before-v153.js`；服务端新增冻结的65题定义，既有36题定义不覆盖。

- 版本`park-teaching-v153`仅表示本轮内容；奖励继续`park-five-zones-v1`。只有综合会话改为`v153`，准确登记原`five-zones-v1`及更早前驱；现E4／5／8／14未答，其余20道相同综合题按证据承接，旧答案不冒充新版整轮零错。
- 新写入前保存65题的原groups／records／activity；`unit1920V153Snapshot`用于本机，已同步档案为`unit1920V153Progress`，与36题的`unit1920LegacyProgress`／旧证书分开。未同步草稿仍只在原设备，已同步完整成果另验跨设备。
- 显式传递本轮迁移标记与原档案，避免把新学生的未改题组误认成历史版本；更早15星判定排除当前两个会话版本。服务器仍以冻结定义核实旧完成记录，新增题和不可核实统计不会被补成已答。
- 已验证历史在后来重练同ID题时保持原证据；迟到的旧客户端上传可补缺失内容，不覆盖已冻结的原作答。原纪念卡、奖励账本及首次五星日期继续沿用，旧15星姓名、领取时间、PNG与打印能力分别保留。
- 三代真实升级发现36题版与65题版可同时保存相同题目的完成组。原服务器按首个匹配组取值，会丢掉后来的有效五星runId，另一设备因此把该区当成迁移完成，三卡显示“—”。本轮限定Lesson19–20优先当前定义对应的会话，仍保留更早兼容来源；核对原四个runId及全部states，未改判分或把未知统计填成零。

新课程没有历史时不创建虚构档案。本次局部保护不扩展成其他课程必须采用的新框架。
