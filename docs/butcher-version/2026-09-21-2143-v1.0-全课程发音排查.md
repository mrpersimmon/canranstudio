## 4. 为什么原来的检查会漏掉

| 原来的盲点 | 本次暴露的例子 | 已纳入标准的防护 |
| --- | --- | --- |
| 文件存在、能解码、页面播放结束就算完成 | Mr. 的引导语也能正常播放结束 | 文件、真实页面、人工发音三层分开；每层只报告自己的结论。 |
| 用上下文合成，却未核对裁出的完整目标词 | I 与 Mr. 都可能受分词和停顿影响 | 保存音素、停顿和目标边界；发现关键变化停止生成；保留原样例。 |
| 只拒绝空音素，不检查整个名字是否读全 | Chang-woo 只剩 woo；Paul’s 只剩词尾 | 完整词、连字符、所有格逐个检查；发音例外必须验证命中结果。 |
| 音标校对与录音生成互不核对 | excuse 词卡音标是动词，录音走名词 | 以本课词义和词性选读音，记录权威依据；短词及同形异音词专项核对。 |
| 把识别文字等同于正确声音 | excuse 转写正确，词性读音仍不对；同音词反而被列为差异 | ASR 只做初筛；禁止按差异数量宣称错误数或通过数。 |
| 生成例外只保留摘要，难以复现 | 老的 Chang-woo override 仅有校验值 | 实际规则、版本与最终音素进入版本管理；保留审核人、日期和文件指纹。 |

标准与审查工具已经补充，但 **尚未把所有旧生成流程逐个改造，也未修复这 5 处课程问题**。不能把文档要求写好等同于防护已经在所有生成器中自动生效。
