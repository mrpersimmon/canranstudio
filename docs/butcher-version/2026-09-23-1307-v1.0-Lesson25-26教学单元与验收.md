# Lesson 25–26 · 厨房探访记

本单元按[现行统一标准](2026-09-22-1850-v1.18-教学单元设计标准与验收清单.md)制作为无配音版本。状态：本地实现与页面验收完成，尚未提交、推送或发布；教师与儿童课堂验收待进行。

## 1. 依据与学习目标

已逐页核对用户提供的《外研社新概念英语智慧版1》纸页 50–53（PDF 83–86）。Lesson 25 是 12 句连续介绍厨房的短文，不改造成虚构人物对话。读前问题是电炉的颜色。Lesson 26 保留 8 组图示、Written A 的 4 题 8 空、Written B 的 7 组双句表达；勺子只属于图示，不冒充第 8 道书面原题。

孩子应能理解厨房物品与位置；用 There is / There's 介绍一件物品；结合已知语境用 the 回指同一物品；用 It 接着描述它；理解 Where is it? 和 in / on 的位置区别。在线完成不等于通过听力、发音或自由口语评价。老师组织带读、听辨、真实问答，纸笔练习保留给课堂使用。

- 原文采用单栏、固定高度的阅读区，历史句内部滚动。逐句看中文，12 句都呈现后主动点“完成课文”。不用双人舞台把叙述冒充对话。
- 错答只提示“再看看，试一次。”，不泄答案；灯泡给思考方向。图片选项同尺寸、同外观，位置题需清楚画出内部或表面关系。

## 4. 易误教边界

- Mrs. 是本课对 Mrs. Smith 的称呼，不等于“妈妈”。cooker 是炉灶，不是 cook（厨师），electric cooker 不画成电饭煲。
- there 在 There is 里用来介绍存在，不能在此译成“那里”。It 回指已说明的单件物品。
- a/an 看紧随词的发音：a cooker / an electric cooker。不能教成按字母机械判断。
- the 指语境明确的物品，不以“第几次出现”作为普遍规则。Written A 第 3 题附教学语境：“桌子是双方都知道的那张”，使 the table 的预期答案明确；保留原题字句，不把其他语境下的 a table 宣判为语法错误。
- in 是容器里面；本课 on 是表面上。8 幅原图同时表达位置与 clean/large/empty/sharp/dirty/full/blunt/small。
- 词卡沿用美式音标；教材原印音标为英式。a/an/the/of 单独认读展示强读式，连读时有弱读，不要求每次逐字强读。

### 本轮发现与修正

1. **六块长拼句在平板裁切。** 原模板只对七块以上预留更多高度，含 refrigerator 的六块句子也会换行。将本单元预留空间扩展至六块；四种宽度实际逐块选取、撤回，并检查选区完整和操作区稳定。此前只按词块数量估计空间不足，必须测完整可见文本。
2. **证书能显示却不能保存。** 人物逻辑名与插图文件名大小写不一致，导出时找不到对应图片。统一本单元人物资源标识；正常、长名字、空名字、图片失败后恢复的真实下载检查均通过。仅看弹窗不构成导出验收。本轮未改共享证书导出，Lesson 23–24 和既有单元相关证书流程回归通过。
3. **位置图需要逐幅看实际关系。** 修正厨房图右缘、盒子和铅笔的落点、瓶中液体高度、勺子在杯内的遮挡，避免“资源加载成功但图意错误”。调整后复看图样，并重跑完整图册／图片加载检查。
4. **冠词说明限定准确。** the 的词卡写“指明确的人或物”，不限制为单数；学习说明同时覆盖单件、多件。纸笔第3题补明确桌子的共享语境。没有把第一次出现必用 a、再次出现必用 the 当作通则。

第一次入口行为测试因导航尚无新课而失败，实现后转绿。更早一次本地测试受机器代理干扰而未启动，设置本地地址绕过代理后才开始实际页面验收，未把启动失败计成产品缺陷。
