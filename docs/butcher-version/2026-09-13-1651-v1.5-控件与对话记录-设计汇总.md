# v1.5 控件与对话记录设计

2026-09-13 16:51 的历史记录；以下实施和测试状态均指当时。

用户已确认并授权三项修订：听辨移除线索及占位；词卡上一组保持完整按钮外形；原文记录在固定高度区域逐句累积并可点读。

1. 只显示本轮已经呈现的句子，不预先展示后文；看见当前句不等于听完。
2. 当前句真实播放结束才解锁下一句，孩子手动前进；末句也需手动完成。
3. 点击旧句只重听与高亮，不改学习位置、不奖励；新朗读停止旧朗读。
4. 当前句被打断后必须重新听完；旧音频迟到的结束事件不能解锁它。
5. 阅读历史或展开中文时不拉回底部；主动下一句只定位对话区，整页不动。中文开关不触发朗读。
6. 刷新恢复句子、位置和听完状态，默认静音、中文收起。显式重演才从首句累积，已有奖励保留。

验证应覆盖 11 段真实音频、历史与当前句交替、重演、离开停音、窄屏和旧听辨记录。结果见[实施验收](2026-09-13-1719-v1.5-控件与对话记录-实施验收.md)。
