## 五区任务与覆盖

顺序：旅行小图鉴 → 单词寻宝 → 四季小剧场 → 故事小侦探 → 语法小工坊 → 明信片小向导 → 综合挑战 → 纪念卡。固定五区、五颗星。

| 目标 | 示例／线上练习 | 综合复核 |
|---|---|---|
| 气候／天气、四季、月份、国家词义 | 图鉴包含全部37个新词；词汇配对、看图、语境辨义 | 气候与天气、月份、国名抽样 |
| 完整故事及频率事实 | 12轮主动阅读；来源、季节月份、sometimes与always、天气事实边界 | 原文冬季／秋季、频率理解 |
| What's … like?询问状况 | 不同例句短示范后选意、选完整提问、拼句、填空 | 撤去示范独立问天气／气候 |
| 人／物特征与形容词回答 | 有完整短材料，回答人用he/she、天气／物用it | 房间特点、人物特点，不能答成喜好 |
| come from／国籍、come(s)、Do/Does | 12组完整参考；明信片场景应用中使用、否定与提问 | 新人称和国家独立运用 |
| 20th–31st、月份大写与顺序 | 全部序数词保留在参考，月份卡有数字 | 不规则21st／22nd／23rd／31st抽样 |

每题有稳定id、目标、依据及独立审定答案。重复仅用于撤去支持或跨情境迁移，不只更换名词。线上无需发音／键入英文；真实发音、听力与开放交流由教师带领。书面练习保留在可打印参考，不另发星。

## 视觉与交互

- 主题是希腊海边的四季相册：奶油白、海蓝、橄榄绿；深棕圆润线条和寒蝉圆黑＋Nunito沿用45–46。选择／正确／错误按钮含义保持共用规则。
- Hans：浅棕侧分短发、蓝衬衣与旅行马甲、笔记本；Dimitri：深棕卷发、青绿开衫、奶油衬衣、橘棕长裤。两位成年角色采用已认可纪念卡头身比例；与其他单元同名不自动复用身份。
- 先画中近景纪念卡：Dimitri翻开四季图册、Hans指着其中一张，两人视线／手势有联系；脸、手、图册清楚。再派生全身课内人物。人物始终面对对方，头手脚与道具不得裁切。
- 对白在场景内固定滚动区；读到四季时切换相册页，不把眼前天气一秒换四季。手机上正文与人物分层但仍在同一场景框。
- 应用题的明信片状态只在检查正确后改变，选择、错误和线索不代交付。
- 封面、课内人物、完成画面、纪念卡同一套资产。动态姓名、五个星位、日期由页面绘制。
