# Lesson 85–86 · 电影院外聊巴黎

2026-10-14 11:59 · codex/debug-grammar-v2 · 依据[统一标准v1.49](publish/2026-10-14-0013-v1.49-教学单元设计标准与验收清单.md)。无配音课堂配套版，五个答题区、五颗星；设计、开发与本地验收，不表示提交或上线。

## 教材与边界

- 课本纸页174–177／PDF207–210：保留George、Ken全部13轮原文、7个新词，86课15种动作／过去分词与第1至第15序数标签，书写A7／B12及原例。
- 《同步导学》Grammar纸页150／PDF164：have been to（去过、已回）、have gone to（去了、未回）、have been in（持续待在某地）；分别练含义、地点介词及问答。
- 《语法练习册》纸页243–247／PDF257–261：现在完成时与明确过去时间、do–did–done、返程和当前结果。86课“已经做了；何时做的”单独检验，不被三种地点表达挤掉。
- 两人现在在电影院外，海报里的巴黎不是当前位置。George看过电影，但从未去过巴黎；Ken四月去过，那次一直下雨。不把末句对London的比较写成普遍气候规律，也不添加旅行计划或确定当前城市。
- 导学把gone to限制为第三人称、排除所有for时长的说法过于绝对。[Oxford的形式表](https://www.oxfordlearnersdictionaries.com/grammar/online-grammar/present-perfect-simple-been-and-gone)包含I／you与gone；[British Council](https://learnenglish.britishcouncil.org/free-resources/grammar/english-grammar-reference/present-perfect)也有gone to加计划离开时长的用例。本课围绕“是否回来／是否仍待在那里”教学，不设置这些绝对禁令；gone to本身也不能证明已到达目的地。

## 视觉与材料

影院外檐、电影海报与票根构成主题，暖纸搭配柔和紫、青绿。George为金发圆眼镜、芥末围巾与蓝外套；Ken为深发、青绿格纹夹克、手持票根。先生成纪念卡近景，再沿用同一身份生成朝向彼此的全身人物；封面、舞台和成果使用一致画风。

海报属于电影；Ken的雨中巴黎在独立的回忆画框中出现，原场景和人物位置保持稳定。完整对白在场景内累积，内部滚动；中英文展开不挤掉人物。既有字体、三卡、五星、账户、缓存机制不改。
