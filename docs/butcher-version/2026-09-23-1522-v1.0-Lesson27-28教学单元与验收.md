## 内容与题稿

1. 图鉴30卡：8个新词，课文物品与复数形式、功能词、书写所需的不规则复数。大图＋英文＋美式音标，整卡翻义。
2. 单词寻宝8题：living room→客厅；near语境→靠近；window图→window；armchair→扶手椅；door图→door；picture→图画；wall→墙；trousers→长裤。旧词不强制整轮重做。
3. 课文13句：原文顺序单列导览，读前“书在哪里？”。理解2题：书在音响上；扶手椅靠近桌子。第二题要求区分物品与参照物，按课文找两处位置事实。
4. 复数发现站2题：There ___ some armchairs→are；knife／policeman复数→knives · policemen。后一题整合两种已示范变化，不堆替换题。
5. 位置问答站2题：询问是否有图画→Are there any pictures in the room?；There are some tickets on the shelf. They're in that handbag.中的They→tickets。区分存在提问与位置提问，以及复数回指。
6. 拼句3题：There are some pictures on the wall. / Are there any books in the room? / No, there aren't any books in the room.。分别训练陈述、倒装问句、否定式。后两题同场景问答相衔接，不算重复换名词。
7. 挑战2题：forks on shelf且near spoons的双关系图→甲图；There aren't any cups on the table.能确定→桌上没有杯子（不能推出别处没有、或桌上没有其他物品）。

总计19道必做题，5关15星。首次独立／提示后／修正后分别记录，错答只短反馈原题重试。

## 准确性边界

- trousers为复数形式，一条裤子也用这个形式；不通过图中裤子条数决定is/are，不引入a trousers。
- 本课some＋复数名词不指定具体数量；any按本课询问有无及否定句讲解，不写成“所有问句必须any”。There are后本课搭配复数名词；不能把some本身当作are的依据。
- knife→knives、policeman→policemen，不能概括所有-f结尾或所有职业都按此变化。
- 书面B另设练习场景；第1/9组“房间里没有书”与课文不是同一现场。界面须明确这一点。
- near表示靠近，不等于on，不要求接触。位置图的接触与包含关系须目视审查。
- 香烟只作为教材原图与例题中的物品保留，无吸烟人物、广告或奖励形象。
- 原文无对话人物，不虚构说话人。
- Written B10 按教材对比普通椅子和扶手椅。网页与练习纸明确该组 chairs 指无扶手的普通椅子；扶手椅仍是椅子的一种，不能把教材的对比读成互斥分类。
