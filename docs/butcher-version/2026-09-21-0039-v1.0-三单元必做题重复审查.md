## Lesson 1–2：整组替换最突出

题目依据：[当前内容](../../unit1-2/content.js)、[教材范围与初版题稿](2026-09-20-1053-v1.0-Lesson1-2教学单元与验收.md)。下表覆盖本单元全部 40 题。

| 活动 | 题数 | 审查结论 |
| --- | --- | --- |
| 听音寻宝 | 11 | 每题识别不同单词的声音，可以保留相同操作，不因界面相同就判为重复。 |
| 故事小侦探 | 4 | 归属、your 指向、Pardon? 用途、感谢对象不同；未发现整组机械替换。 |
| 回应小帮手 | 4 | 招呼、请重复、确认、感谢四种用途不同；主要重叠在后面的挑战。 |
| 看图问一问 | 10 | **明确需要精简。** 每题所有选项都是 `Is this your + 名词?`，选对名词即可，几乎不再判断如何提问。 |
| 词块拼装台 | 3 | 问句、确认、感谢三种结构不同。从识别到独立组织可保留代表练习，不能继续扩成十物拼装。 |
| 礼貌小挑战 | 8 | 多题与前面同构，需要明确哪些是抽样复习，不能一概叫作“新情境”。 |

“看图问一问”的问题不是十个词不重要，而是这些词已在图鉴、听辨和完整问句示范中覆盖，必做题又把同一判断做十遍。十种替换仍可完整保留为示范和课堂材料；线上挑代表应用，不为了让孩子多点几次逐物再考。

挑战的具体重叠如下。题目标识均省略 `u12-v1-` 前缀。

| 前题 → 挑战题 | 实际变化 | 建议 |
| --- | --- | --- |
| `polite-repeat` → `exam-pardon` | 同学声音轻 → 朋友的话被车声盖住；同一组选项选 Pardon?。 | 可以抽样复习，不算新的表达判断。 |
| `ask-dress` → `exam-dress` | 同样询问连衣裙，题干和正确答案相同，部分干扰名词更换。 | 去掉这次直接重复，不能称“在新物品上询问”。 |
| `polite-confirm` → `exam-yes` | 书 → 外套；都已知是自己的，选 Yes, it is.，选项相同。 | 与其他确认练习统筹保留一次必要抽查。 |
| `polite-thanks` → `exam-thanks` | 帮忙还手表 → 帮忙找书；还是选相同感谢表达。 | 与请重复、确认题一起控制复现量。 |
| `build-pen` → `exam-house` | 钢笔 → 房子；四个词块的句法位置不变。 | 属于问句组织的复习，不是仅凭换名词就获得新能力。 |
| `story-your` → `exam-your` | 男士问女士 → 你问同学；your 仍指听话人。 | 可保留一次视角复习，但不能作为整组换词题的理由。 |

因此，8 道挑战中有 6 道能找到前面的同构任务；不是说这 6 道一律删掉，而是应重新选择少量代表，避免把各小站重新做一遍。另两道中，`exam-pencil` 是单词听辨抽查，`exam-car` 把单词识别放进完整问句，后者确实改变了听辨材料。

调整时仍只使用本单元已教的表达，不能为追求变化提前加入 Lesson 3–4 的 my、否定回答等结构。也不能把“不知道主人”改成无依据的归属判断。

## Lesson 3–4：局部改善后，仍需全单元去重

题目依据：[当前内容](../../unit3-4/content.js)、[教材范围](2026-09-20-2227-v1.0-Lesson3-4教学单元与验收.md)、[上一轮五题修订](2026-09-21-0018-v1.1-Lesson3-4接力练习优化与验收.md)。下表覆盖现行 45 题，使用新版接力而非旧十题。

| 活动 | 题数 | 审查结论 |
| --- | --- | --- |
| 听音寻宝 | 12 | 七个新增听辨词有覆盖作用；coat、pen、pencil、dress、shirt 五个词已在 Lesson 1–2 听辨。后续应说明复习用途，避免默认为所有孩子全量再考。 |
| 故事小侦探 | 6 | 请求物品、号码、拿错物品、my 指向、it 指代、结局各有作用；保留。 |
| 回应小帮手 | 5 | 否定说明、道歉、肯定／否定回答和 your 理解有区别；与接力、挑战统筹去重。 |
| 看图问一问 | 5 | **明确需要精简。** suit、school、teacher、son、daughter 都只是在同一句中挑名词，且重复上一单元的提问任务。 |
| 你我的接力 | 5 | 内部已加入听懂归属、换人说话、已知／未知归属对比；第 2 题仍与回应里的肯定回答同构。不能据局部修订宣布全单元无重复。 |
| 词块拼装台 | 4 | 已在接力拼过“不是我的，是你的”，随后再拆开拼类似两半，顺序不理想；需区分首次组织词序与重复拼装。 |
| 认领小挑战 | 8 | 道歉、否定、daughter 提问和否定拼句均有前题模板；my 和未知归属也属重点复习，应统筹总量。 |

五个新词需要学，但人物关系不能按物品所有权解释；teacher、son、daughter 的图鉴、词义和问句示范要保留。改题应体现“如何向对方确认关系”或本课新增的回应判断，不必把每个名词包装成一次新的句型训练；关于人的问句也不能一律套用 it 回答。

| 前题 → 后题 | 重复依据 | 建议 |
| --- | --- | --- |
| `u34-v1-polite-yes` → `u34-v2-reply-confirm-own` | 雨伞 → 手表；都已知是你的，正确回答和三个选项相同。 | 只保留有必要的确认题，接力位置让给与 my／your 有关的判断。 |
| `u34-v2-reply-build-denial` → `u34-v1-build-my`、`u34-v1-build-your` | 前面拼完整的否定加归属回应，后面换成 book 再分别拼两半。 | 如需教授 It isn't 内部词序，应放在完整回应之前；已掌握后的拆分可按错题需要出现，不作后续固定必做。 |
| `u34-v1-polite-sorry` → `u34-v1-exam-sorry` | 拿错雨伞 → 拿错寄存牌；同一组表达选择 Sorry, sir.。 | 作为有计划的复习抽样，不称新的道歉能力。 |
| `u34-v1-polite-no` → `u34-v1-exam-no` | 外套 → 铅笔；都已知不是你的，选 No, it isn't.。 | 与接力第 5 题的信息不足判断区分，减少单纯换物品。 |
| `u34-v1-ask-daughter` → `u34-v1-exam-daughter` | 同一句问女儿，三个完整问句选项只改顺序。 | 删除直接重复或改成真实的新判断。 |
| `u34-v1-build-not` → `u34-v1-exam-build` | 雨伞 → 西服套装；否定句结构和词块顺序相同。 | 保留代表抽查即可，不必每种物品都做一遍。 |

挑战第 5 题理解同学说的 my，与故事里的客人说 my 是同类指代复习；第 8 题“不能确定主人”与新接力第 5 题同属信息不足，但分别要求解释和选择回应。可以保留必要复习，不把视角或输出形式变化自动算成新增目标。完整问句听出 school 则有不同于单词听辨的输入要求。

## Lesson 49–50：跨活动与挑战重复更明显

题目依据：[组合单元内容](../../unit49-50/content.js)、[继承的 Lesson 49 题库](../../core/course-catalog.js)、[教材范围](2026-09-19-2117-v1.0-Lesson49-50教学单元试作.md)。组合内容中的 69 题加分拣 12 题，共 81 题；不能只读组合文件就漏掉继承题。

| 活动 | 题数 | 审查结论 |
| --- | --- | --- |
| 听音寻宝 | 23 | 23 个不同单词有覆盖作用，不直接判为无意义重复；单轮较长，节奏和疲劳需儿童试用确认，不能只看题数断言。 |
| 故事小侦探 | 5 | 原文事实和另设情境可区分；第 5 题“也喜欢牛排”与心声接力第 1 题重复。 |
| 问话小帮手 | 6 | Do／Are／Does 的对比有意义；`Do you like meat?` 与 `Do you want beef?` 都只判断 Do／Are，需合并或让 like／want 的不同用途真正影响选择。peas 题增加 Does 干扰，可与第三人称题组成对比。 |
| 交接小帮手 | 4 | 接收者、物品、词序辨认、撤去示范后组织，任务有区别。不能仅因共用一句话就全部删掉。 |
| 餐桌小任务 | 4 | 喜欢／本次想要、I／she 与 do／does 回答各有作用；重叠主要在挑战。 |
| 表达小锦囊 | 1 | 判断 To tell you the truth 的用途；与从整句理解老板回应不完全相同，可保留。 |
| 心声接力 | 3 | 肯定 too、否定 either、be 结构的否定回应有区别；第一题与故事练习去重。 |
| 分拣小能手 | 12 | 人称、数、所属词、并列主语等对比有作用；S01 与 S04 都是被谈论的一个人，S04 没有新增分类条件。 |
| 动词换装间 | 4 | 单复数对比、普通 -s、watch／go 的 -es 形式有必要覆盖；不能按“都是二选一”判重复。 |
| 句子检查站 | 6 | don't／doesn't／isn't／can't／aren't／am not 考不同主语和动词结构，保留同一补句操作。 |
| 词块拼装台 | 3 | 肯定句、否定句、Does 问句三种组织任务；可保留，挑战中不宜再整组换词复刻。 |
| 采购小挑战 | 10 | 7 道能找到前面的同构题；需要重新分配抽样复习和真正的综合判断。 |

明确的跨站重复是 `story-steak-too` 与 `either-form-too`：都给出对方喜欢牛排、自己也喜欢，选择 `I like steak, too.`；只是人物标签和干扰项数量不同。两题不必都固定保留。

分拣不应简单砍成每类一道：`her husband` 要防止把 her 算进人数；`this book / these books`、`his dog / his dogs`、`we / they` 有各自的对比意义。应优先移走 S04（the butcher）这样的同类额外样例，再审查所属词结构是否还需要全量复现，不能把四分类或语法正确性一起删掉。

挑战中七组对照如下：

| 前题 → 挑战题 | 相同的核心任务 |
| --- | --- |
| `give-order` → `exam-order` | 按给定接收者和物品，拼 `Give + 物品 + to + 接收者`；换了肉和人。 |
| `either-form-either` → `exam-either` | 两人都不喜欢，选择否定句加 either；chicken 换成 lamb。 |
| `u4950-penny-tomatoes` → `u4950-exam-want` | 喜欢但这次不要，选相同 but 结构；换人物和食物。 |
| `u4950-does-penny`／`u4950-does-want` → `u4950-exam-does` | 第三人称单数问句中选 Does 与一般动词原形。 |
| `u4950-negative-am` → `u4950-exam-be` | I 对应 am not，reading 换成 eating，干扰项仍为 don't／isn't。 |
| `fill-parents` → `u4950-exam-plural` | 主语同为 My parents，like／likes 二选一；fish 换成 potatoes。 |
| `u4950-order-negative` → `u4950-exam-order-negative` | 拼第三人称 doesn't want；She／tomatoes 换成 He／peas。 |

这七题可以承担复习，但不应统称迁移，更不必全量再次必做。另三题中，订单语音听 mince、同时核对夫妇两人的偏好有新的材料或信息整合；pear 是单词听辨抽查。优先保留代表抽查，其他位置可以合并为依据明确的采购任务，例如阅读两人的本次需求后选同时符合的采购单；不用为保住十题硬加难题。

分拣的[回练安排](../../core/lesson49-subjects.js)还会在重做错题前要求经过两道不同的其他题；没有待复习错题可用时会再次出已答对题。它有防止立刻照抄纠错的意图，不计入 81 道基础题。本次记录为**需另行审视的重复负担**，后续核对回练次数与教学用途；不能把间隔题计作新增知识点，也不能由此要求全班重复整套分拣。

## 后续修改次序

1. 先改 Lesson 1–2 的十题提问、Lesson 3–4 的五题提问；完整替换材料留在已有点读与课堂材料中。
2. 按整个学习路线去重：3–4 的回应／接力／拼句，49–50 的 too 回应与分拣重复样例。
3. 重新选择三个挑战的必要复习和综合任务。题数由目标决定，不能先定八题、十题再用换词填满。
4. 改题时维护教材覆盖和唯一答案，更新受影响题目版本与记录，防止旧答案自动完成新题；随后按页面行为验收。

以上是审查后的修改建议，**尚未实施**。不在本轮虚构新的总题数，也不把所有同构复习题一律删除。

## 为什么之前漏掉，以及这次补上的检查

此前的题稿与页面验收主要检查教材覆盖、答案、录音、操作和能否走到证书；上一轮接力修订主要检查该活动的五题。不同的名词、题目标识和活动名掩盖了“其实在做同一种判断”，没有把前后所有必做题放在一起比较。

统一标准现要求逐题说明判断与用途，并同时审查活动内部、跨活动和相邻单元；特别核对挑战的“迁移”是否真实。无必要的重复必做题不通过。这个检查属于内容审稿，不能由题数、答案正确率或浏览器自动通过代替，也不需要为每种变式新增一套控件。

本轮实际完成：读取并展开三个单元使用的全部题目，核对数量、题干、选项、词块、顺序、继承内容和上述成对证据；更新统一标准与文档入口，并检查修改文档的本地链接和差异格式。没有改课程代码，没有重新运行页面行为验收或教师／儿童试用。**未提交、未推送、未部署。**
