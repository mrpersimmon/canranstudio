## 五区分工与覆盖

V为词汇、R为理解、G为语法、A为应用、C为综合；数字表示当前真实顺序。共37题：5／5／12／5／10。图鉴、课文、按需参考、抄写均不发星。

| 目标及依据 | 示范与立即练习 | 撤支持与综合 |

| 陈述／询问、be语序 | G1对照钢笔示范练书；G2判断问句目的；G3 is、G4 are、G5 am、G6更换说话者 | G11/G12不附示范，独立问与答；C7外套陈述改问句，C9问自己，C10换人问答。 |
| 肯定、否定及缩写 | G7物品与本人回答对比；G8书的否定示范后在手提包情境判断；G9问答配对；G10缩写辨认 | A3明确物品属于自己再回应；C1肯定、C2明确手表不属于自己再否定；缩写不另凑综合题。 |
| 礼貌表达及交接 | A1补招呼、A2回应、A3确认、A4归还、A5组织感谢 | C4/C5在新情境区分请求重复和引起注意；结论不自动贴在课文旁。 |

原37题材料、答案、题号、`taskSessions`、前驱题稿和奖励版 `grammar-five-zones-v1`均不改。R2未答时显示原文第3–5句并可展开完整故事；R5同时呈现问与答；A3给归属事实，A4先给女士的肯定回答。逐题保存未答画面，不能以答案通关代替材料审查。

重复审查：R1判断整体意义、R4判断提问目的、R5判断it所指、C3将your词义与物品指代分别填写，认知操作有差别。A2与C1分别为即时接话和两个位置的对比；G3与C7分别有示范组装和撤支持改写。相邻3–4涉及伞、票及be否定，不把它的对象或话轮搬进本课。
