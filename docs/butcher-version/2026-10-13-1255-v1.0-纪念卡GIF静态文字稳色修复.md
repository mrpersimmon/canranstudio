# 纪念卡 GIF 静态文字稳色

2026-10-13 12:55 · `codex/debug-grammar-v2` · 开发中发现，非线上事故。

**症状与复现：**Lesson55–56真实账号完成五星后下载GIF，比较第0与15帧，同一标题区域有15个边缘像素变色，最大通道差11；文字位置没动，页面卡面正常。一星、新旧卡片的颜色分布不同，未必触发。

**直接原因：**导出使用固定调色板，但gifenc的RGB565近似缓存每帧重新建立。同一个颜色桶先遇到变化的金边颜色，可能给后面的静止字边选择另一个调色板索引。仅固定调色板仍不足以保证静止像素不变。

**修复：**逐帧比较原始RGBA。源像素未变时沿用上帧调色板索引；源像素改变才更新。仍只有一张固定调色板，保留上一帧原始像素，不累计60张原图；星光与金边继续动画，取消操作及账号成果逻辑不变。

**为何旧检查漏掉：**原有用例以其他插画、文字和主题色验证，刚好没触发同桶碰撞。55–56的独立真实GIF检查复现失败，不把少量字边变化放宽为通过。

**防御：**保留55–56真实账号下载回归，检查60帧、循环、星区变化、标题／姓名／主体插画静止；已有卡面与另一浏览器一起验证。实际通过范围见[单元验收](2026-10-13-1255-v1.0-Lesson55-56设计与验收.md)，修复代码存在不等于已经部署。
