# Lesson 73–74 · 街角的短语手册

2026-10-13 23:45 · codex/debug-grammar-v2 · 无配音课堂配套版。依据[现行统一标准v1.49](publish/2026-10-14-0013-v1.49-教学单元设计标准与验收清单.md)。先核教材、单课设计与独立题稿，再开发和页面验收。未提交、推送或部署。

## 教学依据与边界

- 智慧版纸页150–153／PDF183–186：73课完整叙述与引语、13个新词；74课5个新词、8幅动作材料、A5及B8书面练习。线上保留完整材料，书写作为可打印课堂练习。
- 同步导学Grammar纸页132–133／PDF146–147：形容词构成副词、不规则过去式、直接引语。使用短示范后立即练习，最后撤去示范；不搬整页术语或要求死记全部词表。
- 语法练习册纸页208–213／PDF222–227：不规则形式、过去肯否对比、时间问答、动作与方式组句。核心形式来自本课故事和74课8幅图；扩展词表放可选参考，不把未学单词塞进必做题。
- 故事事实：Mrs. Mills上周到伦敦，不熟悉而迷路；在车站附近遇见一位讲德语的游客。游客从自己的衣袋取出短语手册，读出自己不会英语。课文没有给出国王街路线、抵达结局或游客国籍；不能把“讲德语”直接判为“德国人”。“I can ask him…”是心里想，不是游客的台词。
- 语法边界：副词说清动作怎样完成；形容词描述人／物。常见-ly、辅音+y改-ily，hard／fast／late可同形，good的方式副词是well；不能教所有副词都加-ly，也不把hardly当作努力。read现在／过去拼写相同而音标不同（/riːd/→/red/），无配音不宣称发音达标。直接引语保留人物原话与说话人，不升级为间接引语时态转换教学。

## 五区分工与题稿

图鉴前置，完整原文分段阅读后进入理解；词汇、理解、语法、应用、综合恰好五区，固定五颗星。五区共72题：单词寻宝8／故事小侦探8／语法小工坊20／旅行记录员8／综合挑战28；42张带音标词卡、14段完整课文，参考与书写不增星。

| 核心目标 | 帮助与练习 | 撤去帮助后的检验 |
| --- | --- | --- |
| 新词、手册用途、方式词的意义 | 图鉴、词义／图片／配对 | 综合词义和必要情境 |
| 因果、人物、地点、动作顺序与开放结尾 | 完整叙述、理解选择 | 材料核对，避免编造事实 |
| 形容词与副词用途，-ly／-ily与同形 | 不含当前题完整答案的短示范、填空／定位 | 不同动作的独立方式表达 |
| 本课不规则过去式及didn’t后的原形 | 配对、逐空、时间语境 | 过去事件与否定对比 |
| 原话、引号、说话人和I指代 | 叙述／思想／说话的视觉区别，定位与选择 | 根据原话核对人物，不变造引语 |
| 74课动作＋方式，礼貌表达与旅行记录 | 资料后组句，核对短语手册再翻开 | 综合新的短记录与选择 |

与71–72区别：不再整组讲规则-ed、过去习惯和Did基础简答；仅在不规则动词否定中复习必要原形。重复练习通过撤去示范、变换说话人或不同动作检验迁移；不按换名词机械扩题。

## 本课画面

深棕#50372a、暖纸#fff8ee、街角蓝#456d83、浅雾蓝#eaf1f3、杏黄#dfb36e、砖红#ba7562。字体遵循寒蝉圆黑400／500＋Nunito400／600，音标Arial。

先以1–2／3–4纪念卡为画风基准，生成游客展开短语手册、Mrs. Mills专注倾听的中近景，再扩展同身份全身人物。Mrs. Mills银灰波浪短发、珊瑚贝雷帽、深湖蓝宽翻领外套和黄围巾；游客姜红小胡子、深蓝便帽、沙色口袋外套、绿裤与斜挎包。不得仅改71–72衣服颜色。

车站标志、街道立面与步道构成场景；故事文字始终在场景内。旁白居中，人物原话两侧，心里想单独标识；不让旁白冒充另一位角色。双方朝向对方，手脚不裁。手册从衣袋到手中再展开，场景只出现一本；前段游客未读书，后段切到同身份读书姿态。姓名与路牌由网页文字绘制，镜像不翻字。

纪念卡称号“旅行小讲述家”，保留两人、短语手册与车站线索；插画不写死姓名、星星、课号或日期。奖励表达清楚，不宣称已经学会地图路线或真实口语沟通。
