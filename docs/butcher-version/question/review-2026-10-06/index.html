本轮实际页面证据

在独立的本地审查入口操作，没有重置用户体验页的学习记录。以下截图均由本轮实际页面保存；原稿的两张截图也已核对。

01 单词寻宝 · 可操作，但有重复说明

三组点选和配对计数清楚。主要问题是题干下方又解释同一操作，右上角还重复提供“怎么玩”。建议删文案，保留编号／选中状态，不仅靠颜色区分配对。

02 手提包的故事 · 已确认按钮错位

阅读中两按钮实测纵坐标为 391／455 像素，并非同行。根因在 core/unit-theme.css:79–82：主按钮固定在右列，唯一的次按钮同时命中 first-child 与 last-child，后者把它排到第二行。Lesson 25–26 已有 only-child 修正规则，Lesson 1–2 尚无对应处理。初始状态还同时提供“开始”和无实际需要的“从头看”。

03 故事小侦探 · 同一操作被解释两次

标题与下方说明都在解释中文词块的操作。空位、词块和检查按钮足以承载常规流程；删可见说明时，词块的可访问名称与撤回焦点仍要保留。

04 句子小工坊 · 确有必须键入的单词

这是 E07 的单词输入实现，不是点选题；手机会进入系统输入法流程。本轮未检验实体手机键盘遮挡，因此不把遮挡当作已证实故障。应依据用户的交互范围调整题型。

05 礼貌小挑战 · 题干负担与暂停页冗余

对话题把人物、归属、操作目标和英文问句合并为一个长标题。暂停则把题面替换为继续按钮。已通过真实操作确认：选择一项后直接刷新，不经过暂停，选择仍保留。因此删除暂停入口可以保留续学能力。

建议实施顺序

  1. 先处理阅读布局和键盘输入。两课按未开始／阅读中／完成三个状态建立明确操作行，DOM 顺序与视觉顺序一致；两道输入题改为点选补空，调整题型覆盖记录，核对是否与已有任务重复。
  2. 再统一指令与辅助入口。逐题整理“选择配对／翻译这句话／补全句子／完成对话／读一读，选答案”等短指令；保留必要条件，移除两个单元的“怎么玩”、常驻操作说明和暂停入口。共享组件新增明确配置，先让这两课采用，不用全局 CSS 隐藏所有课程控件。
  3. 同步旧记录与统一标准。纯布局和进度文案调整保留成绩；输入转点选、选项或判断条件改变的题使用新题号与内容版本，保留姓名和证书日期。只去标题句号也会触发当前完整内容签名变化，应逐题核对等价映射，不能全局忽略题干差异。旧记录含 paused 状态时自动回到当前题，不能删了继续按钮后留下空白页。
  4. 验收两课后再推广。核对 320／390／768／1280 和短屏；按钮不跳动、中文展开不推移操作、词块可撤回、空答案不可检查、错题可修正；验证刷新、退出重进、旧暂停记录、离线、登录换设备、末题结算与证书。真实手机再验证操作和焦点。统一标准 v1.26 的帮助、暂停和 E07 条款须随采用决定更新。
