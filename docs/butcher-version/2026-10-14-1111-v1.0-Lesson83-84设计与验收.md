# Lesson 83–84 · 出发前的行李箱

2026-10-14 11:11 · codex/debug-grammar-v2 · 依据[统一标准v1.49](publish/2026-10-14-0013-v1.49-教学单元设计标准与验收清单.md)。无配音课堂配套版，五个答题区、五颗星；本地设计与开发，不表示提交或上线。

## 教材与教学分工

- 课本纸页170–173／PDF203–206：12轮完整原文、5个新词，84课20种食品饮料及1,000–20,000数字标签，书写A7／B10和原例全部保留。
- 《同步导学》Grammar纸页146–147／PDF160–161：现在完成时的当前影响／延续至今、have／has＋过去分词、肯否问答、缩略形式及already／just／yet／ever／never／before。不能把“完成时”解释成所有动作都结束了。
- 《语法练习册》纸页236–242／PDF250–256：先说已做，再用过去时回答具体时间；some／any与数量回应。只按材料核对，不从“想再吃”推断“一定没吃过”。
- 原文中Tom、Carol现在吃午饭、正在收拾行李，明天才离开；Sam已吃过午饭、刚喝过咖啡，今年在家度过假。保留邀请、婉拒、转到客厅和结尾，不添加目的地、买票或已出发的结局。
- 线上练阅读、词义和表达；教师承担语音与口语。20种材料及A／B含教材成人饮酒项目，完整留在词义参考与练习纸；儿童必做任务使用食物、水、牛奶等。

## 视觉（沿用原记录）

主视觉为打开的青绿色行李箱、折叠衣服和客厅，奶油纸／灰绿／柔和蓝点缀；字体和状态色沿用标准。Carol、Tom、Sam承接81–82身份，Carol更换为整理衣服姿态；纪念卡近景表现收拾中的谈话，不再端食物。对白始终在场景内，按当前说话人切换双人站位，脸、手、双脚和道具完整；手机长段对白内部滚动。
