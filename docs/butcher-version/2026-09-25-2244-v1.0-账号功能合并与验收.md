# 账号功能合并与验收 v1.0

本次在 `codex/butcher-version` 的独立工作目录整合账号功能；不操作 `codex/login-version` 的工作文件、分支指针或账号数据。本次不推送、不部署。

## 已确认的范围

- 只接入账号登录、首次改密、老师管理、班级开放范围、账号恢复和个人学习成果同步。
- 所有课程的教材、题目、人物、场景、学习顺序和配音模式，以合并前的 butcher 版本为准。Lesson 3–4、5–6 保持无配音，保留词卡换组不闪屏的修复。
- 用户另行确认：登录后只开放十六个配对单元，Lesson 49–54 单课和音标乐园七个旧入口继续下架。账号服务单独实现这项限制；butcher 的原始课程与内部静态预览导航保留，不借账号合并删除内部回归所需的历史入口。
- 登录服务使用 Node.js 24 或更新版本；不能把带账号的课程发布成匿名静态目录。正式切换须单独验收和授权。

四处冲突分别是旧标准的位置、测试说明、两个无配音单元的定义。现行统一标准继续使用 v1.21，补入账号访问规则；两个单元保留全部课堂版内容和旧记录迁移，仅调整访问受保护共享素材的接口。已逐一对比十六单元的教材数据、题目和关卡呈现，均与 butcher 快照一致。49–50 的既有完成条件作为同步服务的数据补充，课程前端仍使用原有逻辑。

## 检查中发现并处理的问题

旧测试有写死 4173 的网址，在 4190 执行时出现连接失败。确认默认端口空闲后，用原有配置执行；未停止其他任务的服务。完整提交检查仍使用默认端口，不能将部分用例的自定义端口支持当作全部支持。

账号版本曾把 49–50 的完成条件改为只从新数据字段读取；历史课程版本没有这个字段，页面初始化报错，故事题无法作答。原账号检查只走当前课程，没有覆盖该历史组合，因此未发现。恢复 butcher 的课程运行文件后，已有旧版本升级行为用例通过；同步服务仍能读取新增的同值完成条件。保留该回归，不改写历史题目，也不伪造学习记录。

复访速度检查仍有一项未达标。按相同顺序运行前面的课程检查后，合并前快照的 20 次复访 P95 为 1614 毫秒，合并后为 1639 毫秒；阈值为 1500 毫秒。合并后的首次整组测量为 1712 毫秒。单独运行该用例时，原版为 1392 毫秒，合并后为 1427 毫秒。故该超时可在合并前复现，单项通过不足以宣告性能验收通过。具体性能原因尚未定位，本次保留原阈值与缓存性能策略，作为已有问题单独记录，后续再做性能优化。
