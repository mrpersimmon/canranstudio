# 课程导航 v1.0

当前分支 `codex/butcher-version` 的首页改为“我的课程”。直接选课，视觉沿用 Lesson 49–50。仅本地实现，未提交、推送或发布。

## 设计决定

旧首页先展示世界总览，再进入城区、翻地图找地标。深棕羊皮纸、水彩建筑和课内的浅色几何人物不一致，也增加了选课步骤。

新首页按以下顺序排列：

1. **晚餐采购大冒险 · Lesson 49–50**：唯一突出的红色按钮。首次“开始学习”，有有效记录时“继续学习”，旁边只显示上次活动名。
2. **更多冒险**：Lesson 51–54 双列卡片，手机单列；整张卡可点击，直接进入课程。
3. **音标魔法乐园**：一行独立入口。
4. **单课练习**：默认收起 Lesson 49、50，展开后可继续使用原课程。

顶部保留次要的“学习设置”。不再显示世界总览、城区、地图翻页、待开放地区或地图加载动画。

## 画风与操作

| 项目 | 现行要求 |
| --- | --- |
| 配色 | 奶油底 `#FFF6E9`、纸色 `#FFFDF6`、深棕轮廓 `#4A3226`、珊瑚红主按钮 |
| 字体 | 沿用课程本地字体；标题用快乐体，英文与数字用 Baloo 2 |
| 插画 | 复用老板、伯德夫人、牛排、番茄、梨及现有功能图标，不混入水彩建筑 |
| 边框 | 粗棕边、圆角、底部硬阴影，与课内卡片和按钮一致 |
| 层级 | 一个主要行动；卡片只保留课号、名字与已有星星，不堆叠介绍 |
| 可点击外观 | 入口是链接卡片，展开是折叠按钮，设置是次要按钮 |
| 键盘 | 可跳到课程，展开单课，打开设置；关闭弹窗后焦点回到原按钮 |
| 触屏 | 课程卡片和操作至少 44 像素，不依赖鼠标悬停 |

Lesson 49 与组合单元页顶部统一显示“我的课程”返回入口。组合单元 `/unit49-50/#cover` 仍可直接打开，封面的继续按钮仍可恢复活动。

## 数据与兼容

- 原单课星星与学习手记保留，组合单元仍使用自己的记录，绝不拿单课满星冒充单元完成。
- “继续学习”只接受当前单元真实存在的活动或关卡；损坏记录、不认识的地址退回开始入口，首页不覆写答题草稿。
- 从其他标签返回或浏览器前进、后退时刷新继续位置。
- 旧 `/?district=…&focus=lesson49` 等地址继续可用，定位对应卡片；必要时自动展开单课。
- `/home/` 继续跳转到首页，保留参数。
- 重开仍需两次确认；取消不会清除记录。确认后包括单元记录一起清理；清理失败提示重试，不假报成功。
- 没有脚本时，静态课程链接和单课展开仍可用；设置按钮隐藏。
- 首页不加载旧地图大图。旧素材保留，供课程内部成长展示和历史资料使用。

单元目录已加入静态打包输入。旧“禁止首页直接链接课程”的维护检查也改为只允许可用单课。完整打包、线上路由与发布验收尚未执行。

## 实际验收

页面行为覆盖 **42 个不同检查**：导航 7、课程直达 1、首页进度 2、设备与异常存储 4、路由 12、Lesson 49 返回 1、Lesson 50 故事 3、移动故事 1、单元完整流程 10、键盘导航 1。

- 首轮导航入口检查先失败，再完成实现；继续位置也先复现缺失再实现。
- 综合首轮 40 项通过、1 项旧入口断言失败。原因是单元页的“晚餐采购”返回封面链接已改为“我的课程”；已把旧封面恢复检查改为访问仍受支持的封面地址，并补上新的课程目录往返流程。
- 最后导航与单元 17 项全部通过；键盘专项 1 项通过。前一轮其余 24 项结果继续有效。没有执行全仓库或发布验收。
- 自动检查覆盖 320、390、768、1280 像素宽度、图片加载、横向溢出、点击面积、真实本地音频、从零完成单元与领取证书。
- 已在内嵌浏览器对照单元页和新导航的配色、人物、描边与按钮，并查看手机和桌面完整截图。真机、儿童试用仍待人工验收。

旧地图专属的城区、翻页、地标位置检查已保存到 `tests/archive/atlas-2026-09-19/`。导航可达、存储安全和课程进度仍由现行页面检查覆盖；课程内部成长检查继续保留。
