# Lesson 49 最初改进方案

2026-09-11 23:06 的历史记录；以下实施和测试状态均指当时。

这份方案提出保留五关、肉铺情境和全部关键知识点，让孩子先尝试、看反馈，再换情境练习。P0/P1 后来在本地实施，儿童试做仍未开展。

| 五关 | 原计划重点 |
| --- | --- |
| 词汇 | 修正 steak、mince、butcher 图义；区分教材与补充材料；按具体词记录检查情况。 |
| 课文 | 保留完整 11 段原文；真实播放结束后手动继续，再做角色回应和新情境选择。 |
| 句型 | 对比 Do / Are；先预测再看 give 变身；分别检查词序、接收者和 either / too 的含义。 |
| 三单 | 结合主语分类、完整句和否定句练习；不把 I / you 统称为复数。 |
| 综合 | 用新订单检查各目标，保留首答、提示和修正记录。 |

线上以点选、词块为主，整段说话与写作留给教师组织。奖励活动完成，不能把看动画、开奖励或满星当成语言掌握。

后续变化：页内美术改为几何图标；单活动布局又被 v1.3 长页替代；听辨改为 14 词；角色改为故事小侦探。主语分类与教学文案以 v1.10 当前题稿为准，课堂投屏已在 v1.2 移除。

实施证据见[最初实施](2026-09-11-2306-v1.1-实施记录.md)和[后续单活动版](2026-09-11-2350-v1.1-单活动版实施与验收.md)。儿童兴趣、独立操作和延后表现需要另做试验。
