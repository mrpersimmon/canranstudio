# Lesson 49 现行标准与验收清单

历史版本。扩课与新交付请使用[统一设计标准 v1.19](2026-09-24-1913-v1.19-教学单元设计标准与验收清单.md)。下文保留当时的要求，不作为并列的现行标准。

基准：`codex/butcher-version` 的 v1.13 本地实现，并纳入 v1.15 题目进度规则。本文汇总当前要求；历史方案如有冲突，以本文和后续明确修订为准。清单中的空项表示需要在待交付版本重新验证，不代表已知故障。

## 课程结构与学习目标

| 关卡 | 当前材料和题量 | 需要观察什么 |
| --- | --- | --- |
| 开门准备 | 17 张词卡；14 词连续听辨 | 能否把听到的词与图文对应，而非只认位置 |
| 肉店小剧场 | 11 段原文；5 道故事题 | 能否分清人物喜好、实际购买和新情境，不凭常识猜原文 |
| 招呼有妙招 | 问话 8 题、交接 6 题、表达用途 1 题、回应 6 题 | Do／Are 的本句结构、give 的物品与接收者、truth 的用途、肯定 too 与否定 either |
| 店员训练场 | 主语分类 12 题、词形 7 题、句子选择 4 题、拼句 2 题 | 人称与数、一般现在时一般动词的词形、doesn't 后原形、词序 |
| 小店我当家 | 综合挑战 10 题，分两段；一张证书 | 在不同人物、物品与表达中应用，分别记录独立、提示和修正后的表现 |

共 14 项活动、75 道基础题；分拣错题会追加回练。题量是当前 Lesson 49 的事实，不是其他课必须照搬的配额。扩课应复用交互标准，再按教材目标选题。

完成奖励与能力判断分开：五关各 3 星用于领取证书；真实作答、提示和修正情况保存在手记。原课程已有星级可兼容保留，不能拿旧星级补成新题答案。

## 先保证教对

- 每道题注明学习目标、教材位置或新情境依据、正确答案、误选理由、图片与录音。单选题应有唯一符合题意的答案。
- 问人物就选人物；问词语就选词语。题干、图片、选项考同一件事。
- 原文事实与另设情境分开。不从拒绝购买推断“不喜欢”，不从职业推断性别。
- 人称、单复数、代词指代、动词词形分别教。I 是第一人称单数，we 是第一人称复数；不要把一般动词的规则套到 be、can 等结构上。
- 听辨不提前暴露答案。理解题答前必须能获得必要材料。没有提供的信息不能靠孩子猜。
- 首次独立答对、用提示后完成、修正后完成分别记录。星星奖励活动完成，证书不代表独立口语或写作能力。
- 线上优先点选和词块拼装，课堂承担真实对话、自由表达和适量书写。

## 页面和交互

五个章节在连续页面中展开，每项练习显示当前题。顶部导航供复习，下一站由孩子主动进入。

| 类型 | 现行规则 |
| --- | --- |
| 词卡 | 同一套粗线条抽象插图；点击整卡发音和翻面。上一组、下一组均为按钮，最后一组提供下一站。隐藏教材词、补充词等编写标签。 |
| 听辨 | 大喇叭为主要入口；选项使用大图标加英文。真实播放完成后才允许提交；可以重听。没有灯泡和无用说明。 |
| 课文 | 完整保留原文；双人舞台、固定高度的对话区、内部回看历史句。点任意历史句重听不改变当前学习进度；每句单独看中文。 |
| 选择题 | 选项居中、选中状态明确；主动检查、主动继续。灯泡位于检查按钮左侧，不以普通文字冒充按钮。 |
| 词块 | 点词块加入，点已选词块撤回；候选位置保留；拼完整才能检查。刷新、重试不打乱候选位置。 |
| 反馈 | 答对显示简短成功提示及统一音效；答错直接给简短纠正。取消“看看原因”。听辨错答用重听、重选纠正。 |
| 结束 | 主按钮前往下一站，次按钮再练一轮，集中排列。末题先显示反馈，孩子点击完成后才结算。 |
| 帮助 | 玩法与本题线索分开，按需打开。答题前查看规则或提示应如实记录。 |

字号、配色和按钮使用现有 Lesson 49 组件。反馈、重听、灯泡和选项操作不推移操作区；换题仅在题干不可见时滚动。小屏不裁切、不横向溢出；键盘焦点、按钮名称和正误反馈可识别。

## 进度与声音

- 题号表示当前题；每题一格，答对立即变绿，当前题用黄色描边，未答对保持灰色。末题答对即全绿，点击完成才结算。
- 分拣回练按原题最近一次结果填格，错答、重复提交和历史成绩不能增加进度。再次答错撤回对应绿格，修正后恢复。
- 课程、题目、练习轮次分别标识。新题或重练不能从历史成绩自动补成正确。
- 刷新恢复当前选择、已检查状态和真实听完位置；旧星星、历史手记可以保留。
- 停音、离开活动、快速切换后，旧音频回调不能完成新题或新句。
- 英语朗读与反馈音分开。录音失败可以重试，不能当作真实录音已听完。
- 音频与显示文字对应；相同角色和词卡音色保持一致，新文件要实际听审。
- 移除课堂投屏入口和功能。预览使用本地 HTTP 地址，不使用 file 地址。

## 每次交付的页面验收

沿用用户要求：仅通过页面行为测试。预期答案依据审定题稿，不从待测程序的答案表反向生成。

- [ ] 教材、题干、选项、纠错、图片逐项复核，新增情境说明清楚。
- [ ] 从空记录完成词卡、听辨、课文、理解、语法和综合挑战。
- [ ] 每种题型至少走过未选、答错、重试、答对、下一题、末题和重练。
- [ ] 检查前不能靠播放、提示或历史成绩自动得到正确答案。
- [ ] 首题、末题答对后立即更新格子；错答不填绿，回练不重复计数，重练归零。
- [ ] 刷新、返回、旧记录、新题版本、另一课程的进度均不会串用。
- [ ] 当前句与历史句交替重听，结束、取消和失败均不误记进度。
- [ ] 320、390、768、1280 像素检查内容、按钮与完成页；短屏换题可看到题干。
- [ ] 未完成时不能领证；完成后可领取、保存、打印，返回和关闭可用。
- [ ] 按钮键盘可操作，弹层可以关闭，帮助和反馈不遮住必要内容。
- [ ] 实际听审新增音频，核对每张新增插图的意思和画风。
- [ ] 记录孩子试用与教师验收；没有实际执行就写“待验收”。
