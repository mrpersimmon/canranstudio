# 分拣题到底训练什么

2026-09-14 01:01 的历史记录；以下实施和测试状态均指当时。

用户问：“her husband 归属的是 he/she/it？本质是什么？还有 I 和 you 怎么能算成一组呢？”需要区分三个任务。

| 任务 | her husband 的例子 |
| --- | --- |
| 换代词 | 本课指伯德夫人的丈夫，可用 he；her 表示“她的”，不代表整个短语是 she。 |
| 辨人称与数 | 整个主语指被谈论的一位丈夫，所以是第三人称单数。 |
| 选动词 | 在本课一般现在时肯定句中用 likes；否定句、be 等另按句式判断。 |

| 人称与数 | 代词 | 本课一般现在时肯定句中的例子 |
| --- | --- | --- |
| 第一人称单数 | I | I like steak. |
| 第一人称复数 | we | We like steak. |
| 第二人称，单数或复数 | you | You like steak. |
| 第三人称单数 | he / she / it | He likes steak. |
| 第三人称复数（本课当前例子） | they | They like steak. |

I / you / we / they 在这些 like 例句中都用原形，不等于属于同一种人称。I am / you are / he is 也说明不能把这套分组无条件用于所有动词。they 的表格只说明本题多人语境，不排除单数指代。

**当前决定：选类别。**用户后来确认第一人称、第二人称、第三人称单数、第三人称复数四个按钮，详见[12 题完整稿](2026-09-15-0135-v1.10-四类别选择12题完整稿.md)。本活动为后续动词练习作准备；匹配同样文字或认识类别名称都不能单独证明动词掌握。

本次只有概念与文档澄清，没有实施网页。
