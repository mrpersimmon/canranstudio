## 五关路线

1. **采购准备**：看词卡，听懂单词。
2. **肉店小剧场**：带着问题听完整故事，再找答案。
3. **帮忙买晚餐**：问需求、交接食物，区分喜欢与想要，回应同伴。
4. **表达训练场**：辨认主语，选择词形，补全否定句，拼装句子。
5. **晚餐准备好了**：10 题综合挑战，一张单元证书。

同类题只保留一套操作：选中 → 检查 → 反馈 → 继续。听辨用大喇叭和图文选项；需要线索的题使用检查按钮左侧的灯泡。末题主动完成后再出现“下一站”和“再练一轮”。

## 新题审阅要点

- `like` 是喜好，`want` 是当前需求；喜欢某食物不能推出这次一定想买。
- `Does she like…?` 和 `She doesn't want…` 中，一般动词用原形；不把这条规则说成所有句子都用 do／does。
- Written A 的预期答案依次为 **don't、doesn't、isn't、can't、aren't、am not**。be 和 can 保留各自结构。
- 食物说一般喜好时，可数名词采用合适复数，如 tomatoes、potatoes、peaches；cabbage、lettuce 在本单元食物语境按不可数用法呈现。
- “Mrs. Bird 不买鸡”不等于“她不喜欢鸡”。原文只明确她丈夫和老板不喜欢鸡肉。
- 人物接收者题答 Mrs. Bird，词语题才答 me。we 是第一人称复数。
- 新图与新词一一对应；录音使用现有本地文件。音色一致性仍需实际听审，自动播放结束不等于听审通过。

课堂衔接：教师用水果卡复习 banana／orange／apple；将 13th–24th 用作摊位编号，让学生看编号找食物，并安排一人问喜好、一人按自己的真实需求回答。Written B 的其余人物、食物组合可作课堂替换练习；纸笔练习与自由对话由教师观察，不从线上星数推断。
