## 可以怎样试

需要 Node.js 24 或更新版本。在项目根目录执行：

```bash
npm ci
npm run admin:login -- bootstrap
npm run preview:login
```

学生入口：`http://127.0.0.1:4182/lesson/`；管理入口：`http://127.0.0.1:4182/lesson/admin/`。首次生成的管理员登录信息只写入 `.data/lesson-access/admin-first-login.txt`，不写入 Git；已有管理员时 bootstrap 拒绝覆盖。忘记密码时维护者可在服务器运行 `npm run admin:login -- reset-admin`，旧管理登录同时失效。

本次本地预览已创建“示例 A 班”和“示例 B 班”，分别开放 1–2 与前五个单元。两张体验卡在本机 `.data/lesson-access/demo-cards.txt`，仅为本地演示。管理页可自行建班、批量加学生、打印学习卡和调整课程。

## 新开发

- 服务器校验个人学习卡、班级开放范围；首页只显示本班课程。课程直链、清单、原始资源地址和固定资源地址都在同一服务后面。
- 管理页支持建班、改名、勾选课程、多行添加学生、同名学生编号、转班、停用／恢复、重发学习卡和班级预览。预览不会写入学生成绩。
- 学习成果按学生保存到 SQLite；学习码随机生成、加密保存，登录会话使用 HttpOnly Cookie。数据目录在发布目录以外，提供数据库与学习卡密钥一并备份、恢复的命令。
- 已完成活动同步，星星由现有完成条件重新计算，证书沿用原有门槛；未提交选项不上传。两台设备的完成活动合并，重开课程使用新的记录代次，过期上传不能恢复旧成绩。
- 首页和课内显示同步状态。断网成果留在原学生的本机队列，再次联网或该学生回到首页时重试，包括已经收回的课程；换学生不认领上一位的待同步记录。
- 每次新进入联网核验，资源缓存仍按课程完整准备。2 小时和后台超过 30 分钟是静默核验触发点，不是学习时长限制；有效资格不要求学生额外点击。

## 防止再次出错

提交检查纳入 `browser-login`；CI 使用 Node.js 24 并执行登录行为检查与 `build:login`。课程清单以 `server/catalog.js` 为准，课包资源所属课程从依赖清单计算；同一课的完成要求由其教学定义提供。新增课程须登记、添加进入／作答验收，再由管理员决定开放给哪些班。

后台只接收与当前身份、历史有效课程进入凭证和当前记录代次相符的成果，并核对当前内容版本和完成状态。它防止状态串用及错误同步；不是高风险考试的防作弊系统，不能证明答题者的真实身份。

### 本轮发现并修复的回归

旧 Worker 的 activate 阶段若等待 `client.navigate()`，导航又要等待 Worker 激活，已打开的旧课程会卡住。迁移行为检查先复现，再改为发起导航而不等待其完成，旧下架页与新身份隔离检查通过。另补上核验失败遮罩的优先级，避免被课件准备样式隐藏；离线失败始终能看到重试按钮。浏览器历史恢复先保持遮罩，再核验资格，防止换学生后短暂显示上一位的缓存画面。
