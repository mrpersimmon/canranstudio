# Lesson 75–76 执行复盘与标准改进建议

2026-10-14 01:11 · **待用户确认，尚未并入统一标准。** 本课仍以[现行 v1.49](publish/2026-10-14-0013-v1.49-教学单元设计标准与验收清单.md)为准；[单元实施与验收](2026-10-14-0047-v1.0-Lesson75-76设计与验收.md)记录实际结果。

| 优先级 | 本次发现 | 建议增加或调整的一句话 |
| --- | --- | --- |
| 高 | 答案流程能通过，不保证孩子看到了材料。本次部分题目曾因字段未接入而漏显示；已补齐并加页面断言。现行标准有“提供完整依据”，但验收操作还不够明确。 | **每道材料题在未作答画面核对全部必要线索；从实际画面能独立作答后，才检查判分。** |
| 高 | 新课注册分散，首次账号验收发现纪念卡回退旧字体。修复单元的字体登记后再验。现行标准规定字体，但没有简短接入清单。 | **新增单元同时核对首页、开课权限、课包、字体及卡册／导出，不能只检查课内页面。** 技术上可后续集中维护单元配置，减少漏项。 |
| 高 | this week不自动代表过去；相对时间题可能受当天日期影响。现行语境原则可补一个明确边界。 | **相对时间题给定故事中的日期或钟点；依事件是否发生判断时态，不凭单个时间词机械判断。** 月／年不按固定天数折算。 |
| 中 | 教材售货员的“women always…”是人物概括，不是普遍事实；不能为忠实原文而教成生活规则。 | **原文保留人物说法，涉及概括或偏见时作简短区分；答案只承认材料能支持的事实。** 不擅改对白，也不添加购买成功等结局。 |
| 中 | 标准第2节逐课表不断增加，与末尾“题数只在单元记录维护”冲突，也让读者难找共用原则。 | **正文只留通用规则与验收要点；各课页码、题量、设计和验收状态移到单元索引。** 保留链接，不丢历史。 |

建议优先采用前两项，它们直接对应本次实际遗漏；其余三项分别提高教学准确性和可读性。暂不增加固定题量、强制凑题型或更多结算卡。

本次修复属于新课接入；尚未发布，也未影响线上学生记录。自动页面验证与目视检查不能代替教师审课、儿童试学和手机微信验收。
