## 失败、修复与复验

1. 最初两项红测分别复现首页仍为五张旧SVG、实际示范未记录；修复后按原行为目标通过。报告`initial-red`与`first-green`保留。
2. 完成页测试仍找旧的两个SVG节点，按原断言隔离仍失败；新完成图本身正常。测试改为认可的双人纪念图并继续检查三卡、按钮、解码与布局，不伪造旧节点。`completion-isolated`保留。
3. 纸笔测试将两个纪念卡节点作为单一locator，先隔离复现，再逐个核对打印隐藏；未改产品隐藏规则。`writing-isolated`保留。
4. 临时账号站把课程根目录做成junction，枚举时漏课，导致Unknown course；清理时的Windows文件锁又遮住首个错误。保留首因诊断，按原有历史测试惯例创建真实课程目录，修夹具后重跑。未改生产目录枚举或数据库权限。
5. 本课新人物最初放进共享`assets/unit1-2/`，使无关课程包带上新资源。改为`assets/unit1-2-current/`显式依赖后，另外71包两挂载均与前轮一致；未重构共用打包器。
6. 无Worker时图已解码为blob，测试额外fetch受CSP限制；原断言隔离重现后改比较真实节点像素与首页源摘要。人物选项原URL尾缀也会受子路径／blob影响，产品改按候选语义身份取图，再在真实课包核对人物像素。未放宽CSP。
7. WebKit390×500结果按钮底端为554.4px，原布局隔离复现；仅本课短屏缩减装饰高度与空白，原501px边界复验通过，三卡与操作均保留。`short-isolated-webkit`与`short-final-webkit`分别记录。
8. WebKit账号旧测试在课程尚“正在准备画面”时用5秒普通控件断言；隔离仍失败。测试改先等待公开加载完成／真实词卡可见，再用原控件断言，并保留准备阶段的明确30秒界限。不据此宣称5秒加载性能达标。离线测试曾额外goto同一URL触发WebKit内部导航错误；原断言隔离复现后只继续已打开页面作答，离线进入页面属于另一项缓存契约，未混为通过。
9. 编写用题型元数据一度引入Regular子集没有的“研”字，未涉及学生可见正文。改用已有“报告”表述并重新核对零缺字；未替换共享字体或用回退掩盖缺字。

报告名中的引擎与挂载是实际运行条件；一组内1 worker，独立Chromium检查与WebKit可能并行，失败均保留。修测试、修产品、后来纯素材路径变化与按影响复用分开记录，不称所有复验都是完全相同版本。
