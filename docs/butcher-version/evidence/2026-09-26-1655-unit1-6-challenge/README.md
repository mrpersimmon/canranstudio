## 发现的问题及防御

**长句裁切。** 旧 5–6 六词块介绍及本次 3–4 长句，所选区预留高度不足，窄屏和部分平板宽度需要内部滚动才能看全。旧检查只看整页不横溢出和能点完，未核对所选区。现在只给这两课挑战的长词块预留充足空间，并逐题检查所选区内容完整、按钮位置稳定；不靠固定 CSS 数值作为通过依据。

**旧版验证不能拼凑不存在的版本。** 最早的 1–2 去重样例使用旧内容配新运行脚本，引入不存在于真实发布的组合。现行迁移用例冻结对应旧脚本和内容，并用真实控件产生记录。证书准备和资源地址检查改用测试配置的地址；路径检查保留 HTTP(S) 协议限制，排除浏览器会话 `blob:` 地址。

相关课程、旧样例或独立题稿变化时，检查计划会选择三课完整行为和综合挑战专项。登录升级专项命令列在测试说明；不把离线内部课程检查当作生产登录权限验收。
