# Lesson 23–24 · 房间寻物队

依据：[统一设计标准 v1.18](2026-09-22-1850-v1.18-教学单元设计标准与验收清单.md)。内容 v1，采用**无配音课堂配套版**。网页练词义、阅读、位置判断与句子组织；教师负责发音、听辨、带读与真实交谈。保留正误和完成反馈音，全部声音不可用时仍须通关。

## 教材与教学边界

已逐页核对用户教材《外研社新概念英语智慧版1》PDF 第 79–82 页，纸页 46–49：Lesson 23《Which glasses?》、Lesson 24《Give me/him/her/us/them some… Which ones?》。不是将上一单元的物品名批量替换。

本次新增的判断是：从一件物品转向同类的多件物品，用位置确定是哪一些；these / those 随说话者的位置理解；读懂请求中的接收者、物品和位置。on 在本课表示物品在承托表面上，不能只因画得较高就认定为 on。

- 两课 14 个新词全部进入图鉴，另有 some、复数指代及必要复习词，共 30 张卡。词卡默认显示美式音标，整卡翻义；浏览不刷星。
- glasses 在本课是玻璃杯的复数，不是眼镜。ones 在原文代替 glasses，换语境可代替别的复数可数名词，不把它教成永远等于杯子。
- 本课 some + 复数可数名词表示一些，不指定两件或三件；不把“some 只能跟复数可数名词”教成通则。词卡强读 /sʌm/ 不表示自然句子没有弱读。
- this / that / one 与 these / those / ones 的数量对应分清；“近／远”以说话者为参照，不以屏幕左／右为固定答案。
- desk 本课为书桌、课桌，table 为桌子；不把抽屉有无或用途重叠当成永远互斥的规则。
- on the cupboard 是橱柜顶面，on the dressing table 是梳妆台台面，不能把物品画进柜子或漂浮在上空。
- Written A 保留六题。例题 Tim、第 3 题 Tom 的男性身份、Jane 的女性身份明确说明；不教孩子只凭人名猜性别。
- 物品属于谁，不自动决定要给谁。线上 us 题补明“递回给两位说话者”的场景，选项对比 us / we / our，训练接收者形式；不拿缺少上下文的 them 强行判错。
- cigarette 中性识词，插图为无品牌、未点燃的香烟；完整教材替换组照录，不做线上拿取／使用香烟的必做任务。课堂用书、笔、纸盒等实物或图片卡。

## 页面与视觉

主题是浅薄荷色房间与木质家具。基底 `#F4FAF8`、场景 `#E0EFE9`、边线 `#BAD8CD`、主题字 `#34675B`、纸面 `#FFFDF8`、共用深棕 `#4A3226`。沿用快乐体中文、Baloo 2 英文、抽象人物与物品。主按钮和正误状态不改色。

布局延续已确认的长页：图鉴先行；两侧人物与固定高度对白区；选项居中；灯泡在检查左边；完成后下一站与重练集中成组。记忆点放在房间里的位置图，不增加地图、寻路或拖拽门槛。

## 完整原文

| 编号 | 人物 | 原文 |
|---|---|---|
| L23-D01 | MAN | Give me some glasses please, Jane. |
| L23-D02 | WOMAN | Which glasses? |
| L23-D03 | WOMAN | These glasses? |
| L23-D04 | MAN | No, not those. The ones on the shelf. |
| L23-D05 | WOMAN | These? |
| L23-D06 | MAN | Yes, please. |
| L23-D07 | WOMAN | Here you are. |
| L23-D08 | MAN | Thanks. |

原文实际为 **8 段人物发言**，D04 包含两个句子；页面按人物发言保留 8 段，不为凑点击拆成 9 段。教材读前问题是“男士想要哪些杯子？”，开始前不展示架上杯子的答案图。

## 独立题稿与必要性

先确定本表，再写课程和页面测试。自动检查的预期来自教材和此题稿，不读取程序答案。所有错误仅反馈“再看看，试一次。”；过程提示不提供正确词或完整答案。

| 编号 | 孩子依据什么、判断什么 | 正确答案 | 干扰及保留理由 |
|---|---|---|---|
| V1 | on the shelf 中 on 的位置含义 | 在……上面 | 区分上／里／下；只覆盖本课义项 |
| V2 | shelf 词义 | 架子；搁板 | 不把书本、桌子或柜子当搁板 |
| V3 | desk 词义 | 书桌；课桌 | 干扰为床、盘、椅，不用重叠的 table 设歧义 |
| V4 | 桌子中译英 | table | 和 bed / shelf / plate 对比 |
| V5 | 盘子图片选英文 | plate | 同题不给选项重复图片，不绕过英文 |
| V6 | cupboard 词义 | 橱柜 | 与梳妆台、床、地板区分 |
| V7 | cigarette 词义 | 香烟 | 单次中性识词，不进入使用任务 |
| V8 | 电视机中译英 | television | 与音响等不同设备区分 |
| V9 | on the floor 中 floor | 地板 | 放回房间语境，不扩展楼层义 |
| V10 | 梳妆台图片选英文 | dressing table | 与 shelf / bed / cupboard 区分 |
| V11 | magazine 词义 | 杂志 | 与 newspaper 区分 |
| V12 | 床图片选英文 | bed | 新物品一次覆盖 |
| V13 | 报纸中译英 | newspaper | 不和 magazine 混同 |
| V14 | stereo 词义 | 立体声音响 | 与电视、灯、书桌区分 |
| V15 | some glasses 表达的数量 | 一些玻璃杯，没说具体几只。 | 不武断等于一只、两只或眼镜 |
| R1 | D04 的位置限定 | The ones on the shelf. | 相同杯子，不同位置，须读原文 |
| R2 | D01、D04 跨句指代 | 前面说到的那些玻璃杯 | ones 不是数字一，也不是架子 |
| O1 | 请求从一本改为几本，表达随数量变化 | Give me some books, please. | book 未变复数／仍是 a book；与 V15 的词义识别不同 |
| O2 | 说话者指着自己手边两本书确认“这些吗” | These? | Those? 距离不合；This one? 数量不合 |
| B1 | The books on the desk. 与三幅位置图对应 | 甲组 | 相同书桌、书的数量颜色；乙在抽屉里，丙在书桌上方独立搁板上，不能只判断“画得高” |
| B2 | Written A6 补明递回场景，两位说话者已是接收者，选择 Give 后的形式 | us | we 是主语形式，our 说明所属；只抽样复习这一题，不从所有权硬推接收者，也不重做上一单元整组人称题 |
| T1 | 请求中同时组织接收者和复数物品 | Give us some boxes, please. | 较示范换物品并撤去完整句支持；box→boxes 在学习区已给出 |
| T2 | 用复数作询问和确认 | Which ones? These? | 从前课单数确认推进到复数，不强制全物品替换 |
| T3 | 否定当前一组，再用位置限定 | No, not those. The ones on the table. | 用位置而非上单元颜色／形容词限定；保留 the |
| E1 | 新委托合并 her、magazines、on the bed | 把床上的几本杂志递给简。 | 接收者错误或位置错误；少量抽样综合 |
| E2 | 同一人修改位置要求，按最后要求行动 | 桌子上的那些杯子 | 不能坚持旧位置或将两处全部拿来；改变判断条件，而非再刷原故事题 |

与 Lesson 21–22 对照：不重做 give、which、各容器词义、单数属性选择、完整接收者组或“条件不够再问”的挑战。保留一道人称复习，新增重点是复数、位置关系和更正后的最新要求。先识词，再理解原文，再组织表达，最后两题综合；不先拼完整句又拆成一组低级重复题。

### 本轮发现与防护

1. **位置图片过小。** 复用了普通选项的 68 像素图宽，虽能完成题目，却难以辨别桌面、抽屉和上方搁板。理解题和位置题改用同一大图卡布局：桌面三列，手机一列；增加四种宽度的图片尺寸、选项同等外观及无溢出检查。仅能通关和资源加载成功不足以证明图片可读。
2. **图片选项需要同等文字信息。** 甲／乙／丙本身不描述场景，已在共享练习控件增加可选图片描述，并保留选项原名称。页面验收检查三个描述准确对应各图；其他课程相关交互回归通过。
3. **接收者不能只由所有权推断。** us 题补明把雨伞递回给说话者们，选项改为 us / we / our；独立页面检查覆盖语境、选项、错答重试和改对。完整教材六道 Written A 仍单独保留。
4. **插图信息更准确。** 钢笔增加明确的金属笔尖和墨孔；cigarette 单数图卡改为一支，复数场景使用多支；these／those 使用同风格人物并以指示距离区别，不靠左右位置判答案。图样与实际词卡、图册分别复验。
