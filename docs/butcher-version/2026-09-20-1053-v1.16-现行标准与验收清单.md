## 从教材到教学单元

相邻两课合为一个有始有终的学习经历。先明确孩子要听懂什么、理解什么、在什么场景说什么，再选活动；不要照搬 Lesson 49 的语法或题量。

| 材料 | 制作要求 |
| --- | --- |
| 原文 | 核对教材页图，保留全部句子、顺序、人物与重复句。记录纸页、PDF 页和稳定编号。 |
| 新词 | 全量覆盖，名词配准确图卡；功能词放回例句中理解，不能用一张含糊图片解释全部用法。 |
| 偶数课练习 | 保留其训练目标：替换、问答或书写。线上可改为点选与词块，线下保留真实口头练习及适量书写。 |
| 改编题 | 写明目标、依据、答案、干扰项理由和纠错。题目只能依赖已经提供的信息。原文与新情境分开。 |
| 完成记录 | 首次独立、提示后、修正后分别记录；完成奖励不等于自由口语或独立写作能力。 |

单选答案必须唯一。问“谁”就选人物，问“哪个词”才选词。不因性别或常识推断物品归属。人称、数、指代与词形分开讲，规则限制在适用结构内。未教的新结构不能偷偷放进必答题；有必要时先教学并标明范围。

## 画面与操作

沿用奶油纸面、深棕描边、抽象人物与物品、橙色辅助按钮和绿色推进按钮。中文标题沿用快乐体，英文沿用现有本地字体。连续长页分章节，每项练习只显示当前题。孩子通过“下一站”主动推进，导航可回看。

| 类型 | 必须一致的行为 |
| --- | --- |
| 词卡 | 整卡点读并显示词义；前后组都是按钮，末组有下一站。无“教材词／补充词”标签。 |
| 听辨 | 居中的大喇叭、大图加英文选项。真实录音播放结束才允许检查；重听不限次。无灯泡、无答案泄露。 |
| 课文 | 双人舞台；固定对话区内追加历史句。点历史句重听，不替当前句计进度；中文逐句开关。 |
| 理解题 | 先获得必要课文，再答题。题干直接说明要判断什么，不能只扔一句英文让孩子猜任务。 |
| 单选 | 选项组居中；选中、禁用、正误状态明确。主动检查、主动继续。 |
| 拼句 | 点候选加入、点已选撤回，原位置留空。全部词块用完才检查；刷新和重试保留候选位置。 |
| 线索 | 只提供有帮助的线索；统一画风的灯泡位于检查按钮左侧。使用后如实记为提示。 |
| 反馈 | 短成功提示加统一音效；错答直接纠正，听辨以重听重选纠正。没有“看看原因”。 |
| 结束 | 主按钮下一站、次按钮再练一轮，集中成组。最后一题先反馈，再主动结算。 |
| 导航 | 简单课程卡片，标题、课号、开始／继续足够；每个单元独立恢复上次位置。 |
| 证书 | 名字突出、故事人物、关卡徽章。领取、PNG 保存与 A4 打印使用同一内容；日期为首次领取日。 |

可点击内容使用符合用途的按钮、链接或展开控件，键盘焦点清楚。说明按需展开。选择、听音、线索和反馈不得造成整页跳动；换题仅在题干不可见时调整视口。对话历史只滚动内部区域。

## 进度、录音与保存

- 题号代表当前题；灰格未答对，黄框当前题，答对立即绿格，末题答对立即全绿。主动点击完成才结算。
- 完成、当前轮草稿和历史成绩分开。课程、活动、内容版本、题目、练习轮次各有身份；历史成绩不能填入新题或重练答案。
- 内容版本变化必须使相关完成凭据失效。刷新只恢复经过校验的本轮作答，不接受未来题提前正确。
- 新单元不读取其他课星级；重开只清除当前网站版本的课程记录，不能清除同域其他应用的数据。
- 英语与正误音分开；录音与文字逐条对应，同一角色音色一致。复用声音保留来源和验收状态，不能写成新完成的人工听审。
- 播放失败可重试；不把浏览器后备朗读算作指定录音已听完。切题、重听、离开、刷新、取消后，旧回调不能完成新内容。
- 所有资源在根目录预览和 `/lesson/` 子目录均可加载。验收必须点击真实控件触发原生音频，不能只请求音频网址或替换声音对象后就宣称声音通过。
- 浏览器保存失败有可理解提示和重试入口。预览用 HTTP；不用 `file://`。
