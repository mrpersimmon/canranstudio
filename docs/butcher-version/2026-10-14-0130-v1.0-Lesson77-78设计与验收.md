# Lesson 77–78 · 诊所里的预约时间

2026-10-14 01:30 · `codex/debug-grammar-v2` · 无配音课堂配套版，固定五区五星。依据[统一标准v1.49](publish/2026-10-14-0013-v1.49-教学单元设计标准与验收清单.md)。下列为本课设计与实施记录，不新增共用规则。

## 教材依据与教学分工

- 《新概念英语智慧版1》纸页158–161／PDF191–194：77课12轮完整对白、appointment／urgent／till三个新词；78课12个钟面、7个星期、12个月、2012–2021、6种日期写法、A五句改过去和B四组相对时间问答（另有三组示例）。
- 《同步导学》纸页139–140／PDF153–154，Grammar在纸页140／PDF154：否定的一般疑问句的完全式与缩略式、语序、交际语气，以及根据事实使用Yes／No。语法不被78课的时间介词标题替代。
- 《语法练习册》纸页220–224／PDF234–238：核对过去式、What／Where／When问答、must与want表达及过去语境。作为准确性校验，不把整本练习扩展为本单元必做。
- 线上检验阅读、句式、事实与回应、时间信息转换；教师负责发音、语气和真实交流。完整替换材料与书写放在可选参考／练习纸，无额外必经关卡。

## 场景与边界

诊所前台为浅薄荷色与暖木色；Croft为梳背深棕头发、小胡子、赭色外套、芥黄领带，手扶面颊；护士为短卷发、素白帽、鼠尾草绿制服。两人轮廓、动作与鞋店角色区分，先按认可纪念卡样板生成近景，再扩展同身份全身姿态。人物相向、不裁切；对白固定在场景里，内部滚动。

课文在上午。护士先提议4月24日星期一上午10点，再提议下午2点；Croft没有确认预约，未交代就诊或治愈结果。不能把“提议时间”画成“预约成功”。原文未给年份，日期与星期仅作为故事信息，不按设备年份重新推算。结尾是表达难以忍受的夸张，不把牙痛当真人，也不拿等待或治疗选择做医疗判断。

短钟面与卡片在检查正确后才更新；不是点选就登记。卡面表现沟通中的两人及预约本，称号“就诊沟通小达人”，不展示治疗成功。
