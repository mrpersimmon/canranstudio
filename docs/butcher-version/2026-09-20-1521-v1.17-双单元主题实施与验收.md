## 已做的调整

| 部分 | 实现结果 |
| --- | --- |
| 单元身份 | Lesson 1–2 用浅蓝街景；Lesson 49–50 用暖桃店景。封面、章节定位和导航单元卡片使用相应配色。 |
| 小剧场 | 保留两侧人物与固定高度对白。新场景只作背景；旧对白内部滚动、点句重听和逐句中文继续可用。 |
| 肉店元素 | 红白店篷只出现在采购故事；礼貌单元、练习容器和证书不再套用肉店条纹。 |
| 图鉴与锦囊 | 浅杏底、细外框，白色可点击卡片保持深色描边和下沿。上一组、页码、下一组排成一行。 |
| 答题与结束 | 听辨、单选、拼句仍共用原有题型操作。题头体现单元色，作答区保持暖白；喇叭、左侧灯泡、检查、继续和重练规则一致。 |
| 可读性 | 主按钮使用较深绿色，白字对比约 4.93:1；答对文字对比约 5.90:1。对白角色名取消半透明。禁用主按钮使用明确灰色，已提交选项仍清晰可读。 |
| 领奖 | 保留名字、人物、五关徽章和首次日期；证书标题与顶边随单元配色。下载图片读取页面配色，打印也保留主题。 |

题稿、答案、题数、录音、内容版本和进度存储键均未因视觉改版调整。插画不显示手提包归属或可用于选答案的物品；所有未选选项使用相同待遇。

## 发现的问题与防御

| 问题 | 原因与处理 | 防止再出现 |
| --- | --- | --- |
| 两课看起来都像肉店 | 共用了暖色外框与条纹。新增仅供组合单元使用的主题层，原 Lesson 49 样式继续保留。 | 页面检查冷暖场景、图鉴层次和同类选项样式；不能只看颜色变量是否存在。 |
| 手机里的伯德夫人与对白重叠 | 旧手机规则把人物放到第 2 列，新布局第 2 列是对白。明确人物始终在第 1、3 列，清理旧人物名牌外观。 | 新页面检查实际人物与对白边界；320 和 1100 像素均覆盖，并复查 390、768、1280 像素。 |
| 页面证书换色，下载仍是旧色 | 图片绘制曾写死颜色，原检查只确认文件、尺寸、人物和文案。改为与页面共用配色。 | 完整作答后真实下载，核对 PNG 的主题色与页面；同时目视检查 PNG、打印页。 |
| 答对文字偏淡 | 原绿色在浅底上的文字对比约 3.66:1。分别调整文字与主操作色，保留绿／红的反馈含义。 | 从真实页面读取文字和底色计算对比；换主题、刷新后再答下一题，不能代答或丢记录。 |
| 手机末组翻页按钮不等高 | 初查只覆盖短按钮。末组“下一站”折行后右侧变高 14 像素。两侧改为随行等高，两课都把活动名称完整保留在一行。 | 真正翻到最后一组，再检查两侧按钮位置、高度和文字折行。 |

按页面行为先验证失败，再修正。旧检查侧重流程和结果，未覆盖跨单元的视觉差异、人物实际边界及下载配色；新增检查补上这些观察点。
