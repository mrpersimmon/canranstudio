## 语义核实和采用边界

课本注释说some一般用于肯定句、any一般用于不确定答案的问句和否定句。旧题把some tea放在无充分语境的问句干扰项中，容易教成“问号必用any”。已移除这种歧义干扰，G13／E16补充有肯定预期的合法some问句；不声称这时any一定错误。核对[Cambridge Some and any](https://dictionary.cambridge.org/grammar/british-grammar/any-and-some)的官方检索正文，直接打开时403的限制如实保留；另参照[Some](https://dictionary.cambridge.org/grammar/british-grammar/some)的官方检索正文。强读some、任指any等其他用途不扩大成本课必考目标。

导学按第一项处理并列清单；[British Council Using there is and there are](https://learnenglish.britishcouncil.org/free-resources/grammar/a1-a2/using-there-there-are)说明口语列举与正式形式存在语体差异。本课保留导学原例和目标，但G11／E13明示指定的列举句式，解释仅限当前练习，不把其他合法形式作普遍语法错误。复数问答来自本课导学练习5，不整套搬入43–44或额外扩张can等后课目标。
