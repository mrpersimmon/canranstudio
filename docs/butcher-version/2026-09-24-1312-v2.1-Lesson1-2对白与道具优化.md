# Lesson 1–2 对白与道具优化 v2.1

日期：2026-09-24 13:12。分支：`codex/butcher-version`。

本版落实用户确认的两项优化：对白融入街角场景，手提包更容易被看见。它是[场景样板 v2.0](2026-09-24-0121-v2.0-Lesson1-2场景样板与验收.md)的视觉补充；用户于 2026-09-24 确认本地效果满意，相关原则已合入[统一标准 v1.19](2026-09-24-1913-v1.19-教学单元设计标准与验收清单.md)。

## 这次改了什么

| 部分 | 调整后的呈现 |
| --- | --- |
| 对白外框 | 去掉中间的大块白底；街景连贯，只有说话气泡有底色和边框。 |
| 对白气泡 | 奶油色纸面、棕色轮廓与朝向说话人的气泡角。英文优先，短句使用紧凑布局。当前句与正在重听的句子分别标记。 |
| 看中文 | 保留清楚的按钮外形，减轻描边和阴影；点读与翻译按钮仍有至少 44 像素的高度。 |
| 手机 | 对白占整行，人物在下方两侧，避免长句挤成窄列；两个人物与中间的包各有空间。 |
| 手提包 | 减少图标内部留白，使用珊瑚红包身、金色搭扣与清楚的提手；增大等待归还时的显示尺寸，淡化窗框与长椅。 |
| 归还之后 | 包缩小到合适的手持比例，落在女士手边，不挡住身体。封面、课文、归还任务和完成纪念使用同一个图标。 |

英文对白、逐句看中文、历史句子点读、内部滚动与下方固定操作继续保留。小剧场在女士完成确认前，包留在两人之间；回看旧句不倒退当前的场景进度。归还题仍须检查正确才交包，选中或答错都不交包。

本次没有改题目、题数、答案或内容版本，也没有切换声音模式。22 道练习、七句原文、21 张音标词卡以及已有有效记录继续使用。图标缓存版本只加在显示层，不改题目中的图片地址，避免仅改外观就令旧答题记录失效。

## 问题为何漏过，如何防止再发生

此前的检查主要证明可操作、无横向溢出，没有判断短对白是否过高、背景是否抢眼、包与人物的实际比例。今后样板的视觉验收同时看短句、长句、历史翻译展开、待归还、已归还和完成页，不能只验封面或第一题。

这次手机复查还发现共用舞台样式覆盖了单元的行列布局。已将舞台样式限定在 Lesson 1–2 的课文容器，并增加页面断言：对白在人物上方、两个人物与待归还的包不重叠。其他单元的舞台规则保持原状。

新增页面检查还覆盖短句高度、长句不截断、点击面积、历史重听不丢句子、不挪动操作区，以及归还后包的尺寸和手边位置。落位检查等待答对反馈动画结束后再测量，避免把动画中的临时缩放当成最终尺寸。
