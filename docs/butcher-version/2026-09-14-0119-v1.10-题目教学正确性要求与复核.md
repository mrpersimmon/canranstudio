# Lesson 49：题目正确性要求与复核

2026-09-14 的内容审阅。用户要求：**所有题目的设计都必须不能教错孩子。**这是一项已确定的要求。

## 每题必须说清什么

1. 考什么、题干是什么意思、为什么只有一个正确答案。
2. 必要的原文和人物关系是否答前可见，图片是否支持同一个意思。
3. 区分“不符合本题”与“英语不合法”，不把语境规则说成通用规则。
4. 提示、帮助、答错解释和答对解释与题目一起审阅。看过答案示例的作答应标记为有辅助。

## 四个教学边界

| 容易混淆的内容 | 应怎样解释 |
| --- | --- |
| 换代词、辨人称和数、选动词形式 | 是不同任务。分类练习只能为后续动词练习作准备。 |
| they | 可以有单数指代。当前题组明确指夫妇二人，不能写成“they 永远是多人”。 |
| 人和动物的代词 | 职业不等于性别；动物也可按语境用 it / he / she。题目需要明确指代。 |
| “不是单三就用原形” | 范围过大。一般现在时肯定句中的普通动词、be 和否定句应分别说明。 |

## 当时发现的问题

| 位置 | 问题与后续处理 |
| --- | --- |
| exam-story | 解析把两人都说成不喜欢 chicken；原文只明确丈夫如此。 |
| give-handoff、exam-handoff | 答前或答错时不能声称物品已经交到某人手中。 |
| fill-drink、主语帮助 | 修正对 they 和动词形式的过度概括。实际打开的帮助层含“主语不是单三→动词用原形”。 |
| exam-listen | mince 与 beef 可能交叉，题干应明确听辨录音原词；正确答案不变。 |
| chicken 词卡 | 补充课文 a chicken 的“整鸡”用法，图义对应。 |
| Do / Are | 八道练习答案正确，但按“身份、状态、地点”解释会误导；应按句子结构说明。 |
| pouch-truth | 限定为“课文中老板用了哪个开头”，避免暗示只有一种坦白表达。 |
