# 词卡换组闪烁修复 v1.0

2026-09-25 21:55；`codex/butcher-version` 独立工作目录。本轮由 Lesson 5–6「新朋友小图鉴」的下一组词卡闪烁反馈触发。教学内容、成绩与配音模式均未改变。

## 现象、原因与漏检

进入 `/lesson/unit5-6/#learn/words` 后点下一组，词卡区会瞬间消失，整页加载层再次出现。390 与 1280 宽度各复现两次，四次都失败；每次捕获两个页面隐藏状态。桌面滚动距离为 0、卡片区高度稳定，排除单纯滚动或卡片高度变化。手机还有原有的回到图鉴标题操作，但不是桌面闪烁的原因。

三个候选依次检查：翻组自动滚动；卡片重建造成短暂缺图；加载层再次触发。实际是后两者相连：文件已经在缓存里，首次完整性检查也通过临时地址解码过，但第二组图片的**实际显示地址**还没准备。新图片节点短暂未完成，共用保护立即隐藏课程、重新插入加载层，解码完成又恢复。不是下载失败，也不是教学动画。

原检查等到图片完整后才验收；既有逐帧缺图检查还允许加载层遮住课程，因此把正常翻组时的整页闪回当作安全遮罩而漏掉。本次增加「正常操作不能重新遮住课程」的独立信号。

## 修复与防护

- 在整课准备阶段，按本页真正使用的地址准备全部必需图片，最多四张并行；保留当前课页的图片对象供词卡、人物、完成页复用。临时地址验证与实际地址可显示各负其责。
- 背景与词卡使用同一份准备记录，避免同地址重复处理。持久缓存与无存储时的临时地址两种路径均覆盖。
- 仍保留缺图、坏图和资源撤回时的保护；没有删掉加载层，也没有清缓存或学习记录来掩盖问题。
- [页面过渡检查](../../tests/e2e/course-image-transitions.spec.js)在点击前开始记录 DOM 变化与每帧可见性，检查加载层、整页隐藏及未就绪图片，而不是只看最终截图。检查已加入共用缓存检查计划。
- [缓存设计](publish/2026-09-24-2031-v1.0-网页加载缓存设计.md)新增 C16；[统一设计标准](publish/2026-09-25-1136-v1.21-教学单元设计标准与验收清单.md)补充正常切换的过渡验收。
