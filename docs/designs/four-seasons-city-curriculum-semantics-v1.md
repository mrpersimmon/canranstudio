# 四季生活城六单元课程语义表 V1

> 状态：已批准，实施中
> 教材范围：外研社《新概念英语智慧版 1》Lesson 49–60（教材页 98–121）
> 地图范围：第 5 城区“四季生活城”
> 结构决策：奇数情境课与紧随其后的偶数操练课组成一个教学单元；一单元一座地标
> 实施状态：课程语义已冻结；U01 运行时正在实施，美术仍需单独验收

## 1. 结论

四季生活城不再拥有十二座彼此分离的 Lesson 地标，而由六个连续教学单元组成：

| 单元 | 教材课次 | 地标工作名 | 孩子真正完成的生活任务 |
| --- | --- | --- | --- |
| U01 | Lesson 49 + 50 | 暖灯风味市集 | 听懂订单，问清选择，按本人和家人的口味配好食材 |
| U02 | Lesson 51 + 52 | 四季旅行问询港 | 确认来客来自哪里、是什么国籍，并整理气候旅行提示 |
| U03 | Lesson 53 + 54 | 环球气候播报站 | 播报不同方位和季节的气候，并采访国际来客 |
| U04 | Lesson 55 + 56 | 索耶家庭时光屋 | 按时间和频率整理家庭成员每天通常做什么 |
| U05 | Lesson 57 + 58 | 今日变化钟楼 | 对照“平常安排”和“今天此刻”，帮助角色找到人和活动 |
| U06 | Lesson 59 + 60 | 街角生活补给铺 | 询问库存、大小和替代品，完成连续采购 |

六座地标共同表达的不是抽象语法目录，而是孩子在真实生活中逐步学会：

1. 听懂别人需要什么；
2. 问出缺失的信息；
3. 表达不同人物的情况；
4. 根据新情境作出合适回应；
5. 用英语帮助角色把生活重新安排好。

本文对 U01 冻结到可编写运行时的五幕与证据粒度；对 U02–U06 冻结教材范围、交际任务、五个核心目标、变化情境和地标主体。后五单元进入实现或正式美术前，仍需分别补齐与 U01 同粒度的五幕动作、世界结果、支架和题目级 contextId，不能只凭本表直接生产页面。

## 2. 课程语义约束

### 2.1 地标必须覆盖整个奇偶课单元

- 地标、故事、成长和纪念物必须同时承载奇数课的情境输入与偶数课的操练迁移。
- 不能继续把同一教学单元拆成两栋无连续关系的建筑。
- 不能只因为某个现成图漂亮，就让它取代教材中的人物、交际目的或可观察结果。

### 2.2 五幕固定学习功能，不固定小游戏

每个单元都要完成：

1. 发现问题；
2. 听懂线索；
3. 教会小猫；
4. 换个情境使用；
5. 建造地标。

“教会小猫”必须让孩子重新组织、判断理由、纠错或构造例子；观看讲解不算费曼式外化。“换个情境”必须改变人物、物品或交际目的，不能只换选项顺序。

### 2.3 只把系统真正能验证的能力列为核心目标

V1 不采集或评分儿童语音。开口仍被鼓励，但不会因为点击“我说完了”而形成掌握证据。核心目标只使用无提示选择、匹配、排序和句子拼装等确定性触控证据；发音和流利度作为非阻塞练习保留。

### 2.4 当天建设不等于长期掌握

- 新课当天完成真实任务：地标立即完成建设，但保持未亮灯状态。
- 下一个学习日开始按目标回访。
- 每个核心目标需要在两个不同学习日、两个变化情境中分别无提示成功，才进入掌握。
- 全部核心目标掌握后，地标才亮灯、点亮铭牌并永久落成。

## 3. U01：暖灯风味市集

### 教材事实

- Lesson 49：伯德夫人在肉店购买 beef、steak 和 mince；她在二选一中作决定，接受或拒绝商品，并说明自己和丈夫不同的食物偏好。
- Lesson 50：使用 tomato、potato、cabbage、lettuce、pea、bean、pear、grape、peach 等蔬果，继续练习 I/he/she likes... but ... doesn't like/want any。
- 教材的 13th–24th 序数词用于定位蔬果盘，作为词汇与顺序支持内容，不单独阻塞地标落成。

### 交际任务

肉铺和果蔬摊的订单混在一起。孩子要先听懂伯德夫人的订单，再教会小猫分清“商品、人物、数量和口味”，最后在一张新的野餐采购单中，为不同人物配好食材。

### 五个核心学习目标

| ID | 核心目标 | V1 合格证据 |
| --- | --- | --- |
| FLC-U01-T01 | 听到核心食材和数量线索时，把订单与正确商品篮匹配 | 无文字标签的音频到图片/数量匹配 |
| FLC-U01-T02 | 理解并组织 Do you want any...? 以及 Yes, please / No, thank you | 新商品情境中的问答排序或句子拼装 |
| FLC-U01-T03 | 理解并组织 Do you want X or Y? 以及明确选择 | 新的二选一商品与人物情境 |
| FLC-U01-T04 | 表达自己的喜欢、不喜欢和不需要：I like... but I don't like/want... | 根据未见偏好卡拼装完整对比句 |
| FLC-U01-T05 | 表达第三人称偏好：He/She likes... but doesn't like/want... | 根据新人物双偏好卡拼装完整句 |

### 五幕动作

| 幕 | 孩子动作 | 世界结果 | 证据性质 |
| --- | --- | --- | --- |
| 发现问题 | 查看混乱订单，指出“谁、要什么、不要什么”还没弄清 | 市集摊位开门，订单板出现 | 进入任务，不形成掌握 |
| 听懂线索 | 按角色触发真实对话音频，给伯德夫人配肉类与数量 | 正确商品进入备货台 | 形成性听辨 |
| 教会小猫 | 修正小猫把 doesn't 后面加 likes、把 No, thank you 当成接受等错误 | 小猫把询问、偏好和拒绝表达修正完整 | 形成性外化 |
| 换个情境使用 | 在果蔬/野餐场景中根据新人物偏好完成询问、拒绝和配篮 | 新餐桌被正确摆好 | 当日独立迁移，但不发挑战星 |
| 建造地标 | 核对订单并点亮营业牌的“待回访”状态 | 市集完成建设但不亮最终灯光 | 当日建设完成 |

### 两个跨日变化情境

1. 早餐铺：根据家庭成员偏好和库存，为两人分别配餐。
2. 野餐补给台：更换人物、商品、数量和二选一条件，完成新订单。

### 主题校正

- 保留“肉店”作为市集核心建筑；Lesson 50 的蔬果成为同一市集的迁移摊位。
- 不再把 Lesson 50 单独做成“挑食小王子城堡”。教材没有该人物，皇家幻想不能取代购买与偏好任务。
- Do/Are 全面分拣、一般现在时规则大全、give 双宾语变换等可以作为拓展练习，不能占据主闭环或阻塞地标落成。

## 4. U02：四季旅行问询港

### 教材事实

- Lesson 51：Hans 询问 Dimitri 来自哪里；Dimitri 按季节、月份和频率描述希腊气候。
- Lesson 52：扩展国家与国籍，并练习 Where do/does... come from? 和 What nationality is/are...?

### 交际任务

旅行问询港来了不同国家的旅客。孩子要确认来客的国家和国籍，再根据季节、月份和气候为他们整理出行提示。

| ID | 核心目标 | V1 合格证据 |
| --- | --- | --- |
| FLC-U02-T01 | 建立常见国家与国籍词的意义配对 | 新人物卡与地图/国籍卡匹配 |
| FLC-U02-T02 | 组织 Where do/does... come from? 与完整来源回答 | 单复数变化的人物资料拼装 |
| FLC-U02-T03 | 组织 What nationality is/are...? 与完整回答 | 单人/多人来客问答拼装 |
| FLC-U02-T04 | 将月份归入正确季节并理解季节顺序 | 新月份组合的排序与匹配 |
| FLC-U02-T05 | 用天气词和 always/often/sometimes 描述气候规律 | 根据未见气候图组织完整陈述 |

变化情境：交换生登记台；旅行明信片咨询。
地标约束：保留希腊花园、月份盘和旅行登记台；“护照”是道具，不得压过气候交流主体。

## 5. U03：环球气候播报站

### 教材事实

- Lesson 53：描述英国不同方位的天气、季节偏好、昼夜长短和日出日落早晚。
- Lesson 54：扩展更多国家与国籍，并在第三人称人物上继续来源问答。

### 交际任务

孩子帮助播报站完成一段国际天气节目：先把天气放到正确方位，再说明季节变化，最后采访来自不同国家的来客。

| ID | 核心目标 | V1 合格证据 |
| --- | --- | --- |
| FLC-U03-T01 | 用 north/south/east/west 与天气词描述区域气候 | 听播报后把天气标放入新地图方位 |
| FLC-U03-T02 | 表达并解释季节偏好 | 从新气候资料选择季节并拼装理由 |
| FLC-U03-T03 | 描述 days/nights are long/short | 按季节资料完成昼夜对比 |
| FLC-U03-T04 | 描述 the sun rises/sets early/late | 将日出日落信息拼成完整句 |
| FLC-U03-T05 | 在第三人称来客资料中正确调用来源与国籍问答 | 新国家、新人物数目的联合采访任务 |

变化情境：英国天气图换成虚构岛城；播报员换成旅行记者。
地标约束：以气候播报为主任务，国际来客采访承接迁移；不再制作第二座近乎重复的“护照馆”。

## 6. U04：索耶家庭时光屋

### 教材事实

- Lesson 55：按早晨、中午、下午、晚上和夜间介绍索耶一家每天的作息，并使用频率副词。
- Lesson 56：操练第三人称动词 s/es 和 What does she/he do...? 问答。

### 交际任务

孩子帮助索耶家整理一天的家庭时光表，让来访的小猫知道每个人通常在什么时候做什么。

| ID | 核心目标 | V1 合格证据 |
| --- | --- | --- |
| FLC-U04-T01 | 听懂并识别核心日常活动 | 音频到人物/活动卡匹配 |
| FLC-U04-T02 | 按一天的时间段组织活动 | 未见家庭日程的顺序排列 |
| FLC-U04-T03 | 用 always/usually/often/sometimes 表达频率 | 根据频率资料选择并拼装陈述 |
| FLC-U04-T04 | 在第三人称日常行为中正确使用动词 s/es | 新人物日程中的谓语拼装 |
| FLC-U04-T05 | 组织 What does... do...? 与完整回答 | 根据未见作息表进行问答拼装 |

变化情境：另一户家庭；市场工作人员的一天。
地标约束：住宅、家庭成员与时间板属于同一地点；不再拆成“家庭屋”和“作息钟房”两座地标。

## 7. U05：今日变化钟楼

### 教材事实

- Lesson 57：在多个整点比较索耶一家“每天通常做什么”与“今天此刻正在做什么”。
- Lesson 58：继续用时钟和 usually... but today... 对照一般现在时与现在进行时。

### 交际任务

城区今天的安排发生变化。孩子需要同时维护“平常日程”和“今天现场”两块时钟牌，帮助角色找到正确的人和活动。

| ID | 核心目标 | V1 合格证据 |
| --- | --- | --- |
| FLC-U05-T01 | 听辨并表达整点时间 It is... o'clock | 新时钟的音频、表盘与句子匹配 |
| FLC-U05-T02 | 根据 every day/usually 与 today/at the moment 判断时间视角 | 新句子的时间线索分类 |
| FLC-U05-T03 | 用一般现在时组织通常发生的活动 | 新人物平常日程句子拼装 |
| FLC-U05-T04 | 用现在进行时组织今天此刻的动作 | 新现场图的 be + doing 拼装 |
| FLC-U05-T05 | 对照 usually... but today... 并组织两类问题 | 新异常日的完整对照任务 |

变化情境：节庆日；交通变化日或雨天计划调整。
地标约束：“雨日”只能是变化情境之一，不能取代教材主体；钟楼应明确呈现两条时间线。

## 8. U06：街角生活补给铺

### 教材事实

- Lesson 59：顾客在文具店购买 envelopes、writing paper、pads、glue 和 chalk，询问大小、库存、替代品和零钱。
- Lesson 60：继续复习整点时间，并用食品和日用品练习 Do you have any...?、I have some...、I don't have any...，同时处理 some/any 与名词单复数。

### 交际任务

孩子帮助补给铺完成顾客清单：确认有没有货、大小是否合适，缺货时提供替代品，并在结账前确认是否还有别的需要。

| ID | 核心目标 | V1 合格证据 |
| --- | --- | --- |
| FLC-U06-T01 | 听懂文具与生活用品的库存意义 | 音频订单到货架/清单匹配 |
| FLC-U06-T02 | 用 I want some... 与 What else do you want? 完成连续采购 | 两至三轮新清单对话排序或拼装 |
| FLC-U06-T03 | 用 Do you have any...? 及 some/any 回应库存 | 根据未见库存表完成问答 |
| FLC-U06-T04 | 用 large/small 与 one/ones 提供同类替代 | 新商品、尺寸和替代品任务 |
| FLC-U06-T05 | 在商品语境中处理可数名词复数与不可数名词 | 新货架项目的数量表达拼装 |

Lesson 60 的整点时间作为 U05-T01 的交错维护目标进入本单元，不重复计为新的核心目标。

变化情境：食品杂货；野餐补给；课堂材料仓。
地标约束：主建筑必须能容纳文具、食品和生活用品；不能只画食品店，也不能用“暮色钟楼”取代采购任务。

## 9. 城区目标总量与纪念章门槛

本版共冻结 30 个核心目标，每座地标 5 个：

- 核心目标数 N = 30；
- 形成目标掌握所需的基准独立证据为 2N = 60；
- 第一枚阶段章：15 颗本城区挑战星，并覆盖至少 2 座地标；
- 第二枚阶段章：30 颗本城区挑战星，并覆盖至少 4 座地标；
- 第三枚阶段章：45 颗本城区挑战星，并覆盖全部 6 座地标；
- 最终主徽章：30 个核心目标全部掌握、6 座地标全部永久落成；不能用星数替代。

门槛只统计真实到期目标在当日第一次无提示独立成功所产生的挑战星；同一目标同一学习日最多一颗，全站每日最多三颗。

### 纪念章公共叙事方向

以下只冻结贡献含义，不冻结名称和美术：

1. 第一阶段：孩子开始听懂生活中的真实需要，并让至少两个地点重新运转。
2. 第二阶段：孩子能在多种人物和生活安排之间传递、核对并组织信息。
3. 第三阶段：孩子已经把六座地标的生活线索连接成一条完整城市路线。
4. 最终主徽章：孩子在跨日、跨情境回访中证明整座四季生活城的核心能力已经稳定。

任何最终名称和图案都必须对所有可能的合资格路径成立，不能把只属于某一课的食物、护照或时钟误写成全城区共同事实。

## 11. 内容审校禁区

- 不把“人物还是食物”设计成儿童闯关题；人物词的语义类型只作为内容发布校验，防止课件文案误归类。
- 不能用点击、翻卡、播放完音频、页面停留或“我说完了”冒充学习证据。
- 不能把语法规则大全当成故事目标；规则只服务于当下交际任务。
- 不能让提示后答对、重复原题或同日刷题产生独立证据或挑战星。
- 不能因为 Lesson 标题带有时钟，就忽略页面主体仍在练习库存、some/any 和商品表达。
- 不能把未在教材出现的角色设定写成教材事实；幻想角色只能作为承载任务的世界角色。
