## 1. 本轮问题

加载页出现了两类没有行动价值的说明：

- “先把整课的人物、图片和声音准备好，开始后就不用再等。”
- “所有人物、图片和声音都已准备好。”

它们把课程包的技术机制翻译成了儿童文案，但没有改变孩子下一步要做什么；同时又与标题、进度条、百分比和加载状态重复。第二句话还会在页面即将自动进入课程时制造一次没有必要的完成停顿。

本轮已确认的方向：加载页是状态界面，不是机制说明页；删除上述解释，不把下载、缓存和资源准备原理讲给孩子。

## 2. 审计口径

### 2.1 儿童行动文案

帮助孩子识别当前任务、理解下一步或从异常中恢复所必需的界面语言。

已经由画面、进度或控件明确表达，并且不会改变孩子行动的机制解释、状态复述和安抚语，不属于儿童行动文案。

### 2.2 本轮保留对象

- 教材原文、英语词句、题干、选项与知识卡
- 每个状态中唯一的一条当前任务提示
- 故事情境中承担定位作用的标题
- 作答后的具体教学反馈和分层纠错提示
- 加载失败、音频失败、保存失败与破坏性操作的后果和恢复动作
- 无障碍名称；其长度可以不同于可见短标签

### 2.3 本轮删除候选

- 对下载、缓存、保存和运行机制的解释
- 与标题、进度条、控件或相邻状态同义的复述
- “读完自动继续”“不计进度”等多处重复的流程说明
- 面向开发者的内部术语、标识符和诊断数据
- 不影响孩子行动的安抚语、装饰性副标题和模板化 kicker

## 4. 页面级结论

1. **加载页：高风险。** 技术机制、进度数据和完成状态重复，需要收敛成一个状态表面。
2. **正常教学：整体可用，局部高频重复。** 问题主要来自共享任务模板，而不是每一道题独立写坏。
3. **导航与设置：基本健康。** “回看不保存”和重新开始说明需要控制出现次数。
4. **休息点与完成页：高风险。** 内部进度模型被翻译成了面向孩子的长说明。
5. **可选复盘与次日复习：高风险。** 可选性、是否计进度、题量和返回规则被反复解释。
6. **错误与恢复：基本健康。** 这类文案具有行动价值，必须与普通说明分开治理。

本轮静态检查覆盖当前 17 个阶段及共享渲染路径；浏览器截图覆盖代表性正常、完成、复盘、设置、纠错和听音找物状态。尚未对 17 个阶段逐屏完成所有尺寸的人工视觉验收，也不构成完整无障碍合规结论。

## 5. 全局规范

以下规范以 Lesson 1–2 当前实现为样本形成，作为后续课程必须共同遵守的全局规则；本轮不直接审计或整改其他课程。

### `G01` 单一行动

每个可交互状态必须且只能有一条可见的主要任务文案。位置标题、教材内容、候选答案和事件反馈可以共存，但不能再次改写同一个动作。

### `G02` 四类职责

每条可见文案必须能归入一种职责：

- `source`：教材内容
- `task`：当前行动
- `status`：当前系统状态
- `recovery`：异常后果与恢复动作

“冗余说明”不是一种合法职责，而是审计失败。

文案来源与职责相互独立：来源分为 `textbook`、`unit-authored` 和 `shared-interface`。教材原文不受普通界面短句规则机械裁剪，但仍受答案公平性与展示完整性约束。

### `G03` 状态最小化

同一状态最多显示一个进度控件和一条动态状态。进度条已经表达的内容不再用说明句复述；正常儿童界面不展示 MB、课程清单、缓存、校验、运行时阶段等诊断信息。

### `G04` 异常例外

错误、危险操作与恢复不是“解释性冗余”。失败态必须说明一个可理解的后果，并提供至少一个真实可执行的恢复动作；破坏性操作的完整后果只在最终确认处出现。

### `G05` 长度与版式

首版只做显示宽度告警，不用简单字符数自动删文案。建议告警线：任务标题 14、主提示 30、按钮 10、瞬时状态 20、恢复正文 32、结果说明 42 个显示宽度单位。390×844 与 1280×720 视口出现截断、遮挡或溢出时直接阻断验收。

### `G06` 技术语言

儿童可见界面禁止出现原始实现词和内部标识，例如 `runtime`、`requestId`、`sourceRef`、`challengeRef`、`SHA-256`、`Service Worker`、`CacheStorage` 与 HTTP 状态码。下载、保存、进度、检查等词按语境人工复核，不机械禁用。

### `G07` 重复检测

- 同一屏相同文案或相同 `copyId` 重复出现：自动阻断。
- 同一屏以不同句子复述同一行动或状态：人工审查阻断。
- 不同页面重复使用同一按钮词不等于冗余，前提是动作语义一致。
- 移动端和桌面端都必须保证同一时刻只出现一条主要任务，不能用不同节点互相遮盖来规避规则。

### `G08` 验收分层

1. Catalog：检查职责、显示宽度、内部术语、异常恢复动作和教材豁免。
2. 构建：保证共享界面文案有单一真源，加载页预渲染内容与共享文案同步。
3. 浏览器：检查一条主要任务、一个 live 状态、同屏重复、内部 ID 和两类代表视口溢出。
4. 人工：回答“孩子现在会做什么”，检查语义复述、故事语气、焦虑感、音画时序与答案公平性。

自动检查通过不能代替儿童视角的逐屏人工验收。

## 6. 已确认决策

- `Q2-A` 加载页采用“猫猫 + Lesson 1–2 + 进度条/百分比 + 一条动态状态”的最小结构；从儿童界面移除 MB、资源清单和机制说明。
- `Q3-A` 正常教学统一采用“一个位置标题 + 一条主任务 + 学习内容/候选项”；反馈只在孩子行动发生后出现。
- `Q4-A` 休息点、完成页和可选练习统一采用“故事结果 + 保存状态 + 下一步动作”；可选或不计进度只说明一次。
- `Q5-A` 异常、破坏性操作、教学纠错和无障碍名称属于精简规则的例外；长度先告警，截断、重复任务和内部技术术语直接阻断验收。

“都按照你推荐的来”只确认本节列出的 `Q2-A` 至 `Q5-A`；后续“确认实施”已授权本地代码与测试修改，但仍不等同于提交、推送、部署或完成人工验收。

## 7. 本地实施记录

- `Q2-A`：加载页收敛为猫猫、`Lesson 1–2`、真实进度条/百分比和一条动态状态；删除机制说明、MB、课程清单、重复阶段名与独立完成说明。慢网和失败复用同一状态位置，恢复按钮保留。
- `Q3-A`：共享教学渲染器把主任务标为唯一 `task/primary` 表面；删除听音、交还物品等状态中的同义辅助句和自动继续说明。手机与桌面复用同一个任务节点，不以互相遮盖的重复节点规避检查。
- `Q4-A`：阶段休息、课程成果、角色回演、案件复盘、阶段回看和次日复习均改为“结果或定位 + 必要状态 + 下一步动作”，删除内部进度模型、重复可选说明和完成复述。
- `Q5-A`：答错后的具体线索、保存/音频/加载失败恢复、重新开始后果和无障碍名称继续保留；没有把“少字”机械应用到教学支架与异常恢复。
- 回归护栏：Catalog 固定精简后的文案合同；浏览器检查每个可作答状态恰好一条可见主任务，并覆盖 390×844、桌面教学尺寸、慢网、自动进入、成果页、复盘与次日复习。

本地验证结果：语法检查通过；核心单元测试 `81/81`；Lesson 1–2 及课程包相关浏览器测试 `70/70`。应用内浏览器复核确认加载页最小结构、加载后直接进入学习阶段、不自动打开阶段地图、手机端任务可见且不越界、控制台无错误。

交付边界：本轮没有提交、推送、部署，也没有把自动验证记作儿童人工验收；其他课程没有做页面文案整改。
