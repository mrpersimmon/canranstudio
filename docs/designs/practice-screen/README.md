# Lesson 1–6 单屏答题样板

2026-10-31 · `codex/book-version` · 本地开发，未提交／推送／发布。

## 目标、根因与实现

用户在375×667发现配对题的空反馈区迫使上下滑动才能检查。旧手机导航约158px，配对三行及间距约306px，反馈空位80px；其他普通题还有120px空位。旧词块区、示范和场景分别带有独立固定高度，仅压缩反馈框无法让整题可操作。

新[显示层](../../../core/practice-screen.js)和[样式](../../../core/practice-screen.css)仅由Lesson1–2、3–4、5–6的入口加载。当前活动题采用固定可用视口，保留原练习DOM和事件；课程原返回／关卡导航、记录和设置仍使用原功能入口。顶部56px，标题与进度合并，反馈22–26px，主操作44–48px。对应可用空间选择普通选项列数，收紧配对、填空和词块；较长材料局部滚动，不删去事实、示范或例句。

同题排版按内容节点和视口缓存，反馈不触发重新换列。`visualViewport`变化、resize、字体就绪和历史恢复负责更新显示。共用判分文件仅增加一个可选的呈现定位调用，原题目、版本、选项顺序、错误次数、帮助记录、答案与存储格式保持。

人物场景重新分配了对白、道具和点击区的空间。早期候选中对白透明区域遮住了女士按钮，已把对白限制在上方、人物目标放在下方，并以真实轻点验证中心命中与手提包交接。沿用现有插图，没有重画人物。

更多菜单包含原学习记录、学习设置、星数、同步状态及当前题区静态参考。正常同步不独占顶部一排；待同步／失败仍可见。菜单显式居中并受屏幕高度约束，恢复原弹层后回焦更多。结算、得星卡和原卡保存继续使用现有流程。

## 实际验证

- Chromium根路径：六项新专项及两项既有结算回归，共8项。WebKit内部前缀：六项新专项。各阶段独立复验不重复累加为新的用例覆盖。
- 三课分别37、33、36题，共106题。两引擎均逐题检查320×568和375×667的答前／答后；每个题区首题另验390×844、768×1024、1366×768。每引擎469个布局样本，共938个；选项和已选词块的嵌套裁切检查通过，操作区不出屏，题目主区域最大取整差不超过1px。完整材料区仍可局部滚动。摘要见[尺寸结果](evidence/2026-10-31/geometry-summary.json)。
- 实际解完全部题目并得到三个单元各5星；独立错答用例检查转屏、菜单、关卡切换、返回和刷新前后的`groups`／`records`一致，订正仍保留原错误；未完成单元没有额外卡片。
- 真实轻点配对、重试与人物目标；线索可关闭再打开且不推移按钮。既有结算用例检查等待真实确认、落星后关闭、仅一次统计、复练不增星以及短屏三张统计卡。
- 16项检查流程用例及72课构建通过。资源清单确认三个样板分别加载JS／CSS两项新资源，Lesson7–8不加载。与HEAD核对三课`content.js`及`core/course-catalog.js`没有变更。

实际目录：`output/test-practice-screen-chromium-final/`、`output/test-practice-screen-webkit-final/`、`output/test-practice-screen-chromium-recovery/`、`output/test-practice-screen-webkit-recovery/`及菜单专项目录。主体逐题检查在最后仅调整更多菜单居中规则之前完成；菜单调整后只复验两个引擎的菜单／恢复专项，题目几何没有变化。

## 首错与修正记录

1. `test-practice-screen-before`准确复现原配对题检查按钮的可见比例为0。
2. `test-practice-screen-first`的新测试误用原生AX中显示的checkbox角色，实际DOM是按钮；按实际按钮契约修正，保留原可见范围断言。
3. `test-practice-screen-inventory`至`fit`阶段保留词块过高、长示范撑高、场景对白挡点击和嵌套选区裁切的样本。通过合并标题／进度、按题型收紧、材料局部滚动、固定词块行和场景分区修复，没有降低触控下限或删题。
4. 记录保护首稿误读了静态版存储键，改为登录版实际`canran:lesson:unit1-2:learning:v1`后，完整记录比较通过。
5. WebKit首次刷新恢复断言发生在课程加载层尚未撤下时；trace保留在`test-practice-screen-webkit-final`。改用既有真实课程就绪边界，再做原来的严格恢复断言，独立复验通过；未放宽记录或布局断言。
6. 实页检查发现全局margin重置使更多菜单贴左上角。`test-practice-screen-menu-before`先复现左边距为0，之后显式设置居中、最大宽高，两个引擎分别复验菜单边界和恢复流程。
