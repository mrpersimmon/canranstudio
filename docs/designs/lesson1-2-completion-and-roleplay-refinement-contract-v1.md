## 已确认决策

1. 成果页三枚星全部使用当前中间星的五角星轮廓 `★`；不引入 SVG 或 CSS 自绘。可以保留中间稍亮与错峰轻动画，但三枚图标不得再用不同轮廓暗示不存在的状态差异。
2. 背景中央星灯两侧的两个无名黄铜吊坠直接移除，不再替换成小星星；中央星灯和更外侧原有星灯保留。横竖母版必须表达同一场景语义。
3. 正式角色扮演复用无字逐句回演的两层逐句提示：第一层中文交际意图，第二层增加英文开头；每句重置，不播放、不揭晓整句、不推进、不评分、不写证据。“揭晓并播放我的台词”始终可以直接使用。
4. 临时动作只有当前确实可执行时才出现。第一层使用“提示”，第二层使用“再提示”，第二层用完后按钮消失；台词播放、重试请求进行中和保存期间不显示提示或跳过，不保留禁用占位按钮。音频已经失败并停止、正在等待孩子选择时，同时显示主要动作“再听一次”和次要动作“跳过这个角色”。正式角色扮演与无字逐句回演执行同一规则。
5. 选角页不显示整个阶段的跳过入口；进入角色后，“跳过这个角色”只处理当前角色，并使用“跳过这个角色？／继续扮演／跳过这个角色”的确认层。未完成回合不保存半段进度，之后补演从第一句开始。
6. 每个角色分别记录“已完成”或“已跳过”。两个角色都有处置结果后课程可继续；两者都完成时阶段为“已完成”并解锁无字逐句回演，任一角色跳过时阶段为“已跳过”且不解锁。阶段地图允许补演，双角色真实完成后以“已完成”替换。
7. 跳过一个角色后返回选角页；角色按钮仍只显示准确角色动作，入口外使用“已完成／已跳过”状态。已跳过角色可立即重新进入补演，尚未处置的角色保持主要视觉入口。
8. 选角标题使用“选择你想扮演的角色”；删除“完整演完七句，再换另一个角色”。两个入口只写“你来当招领员”“你来当女顾客”，角色进行中及后续补演表面也统一使用“招领员／女顾客”。内部实体身份、教材说话者与音频映射不变。
9. 新的角色处置模型使用 `lesson1-2-v2.6`；V2.5 及更早学习记录不迁移到 V2.6，新修订首次打开从第一阶段开始。
10. 本轮视觉范围只处理星形轮廓与两枚背景吊饰，不顺带重构整个成果页；成果页结构与既有蓝图的偏差另列巡检。
11. 原有共享 V2 横竖背景在原路径上同步移除两个吊坠，Lesson 1–2 与直接复用该背景的 Lesson 3–4 一起变化；这项明确的共享资产调整是本轮唯一扩展到 Lesson 3–4 的视觉范围。
12. 双角色都完成时保留“无字逐句回演／继续课程”出口；一个完成一个跳过，或两个都跳过时，不显示双角色完成庆祝，最后一个角色处置保存成功后直接进入 `L02-M11`。
13. 完整演完的单个角色保留真实回合完成和已经发生的教材接触；被跳过角色不产生完成或接触。只要任一角色跳过，阶段仍不形成双角色完成事实、语言结果、掌握或无字逐句回演资格。
14. 角色状态按 `未处理 → 已跳过 → 已完成` 单向合并；真实完成可以替换跳过但不能回退。重复保存幂等，失败不乐观前进，并发页面以成功读回的最高可靠状态重新推导阶段结果。
15. 只处置一个角色时，阶段仍是当前未解决的 `5/17`；刷新回到选角页并恢复该角色的“已完成／已跳过”状态。第二个角色也形成处置结果后才进入 `6/17`。
16. 从阶段地图进入“已跳过”阶段时使用隔离补演模式，保存原主线精确位置。已完成角色只显示状态，已跳过角色可补演；补完一个后可以继续另一个或返回主线，双角色真实完成后才替换阶段状态并解锁无字逐句回演。中途退出和最终完成都返回原主线，不跳到 `L02-M11`，也不重复结算后续课程。
17. Lesson 1–2 升级为 `lesson1-2-v2.6` 并生成新的 package ID。共享背景改变后，Lesson 3–4 保持 `lesson3-4-v1` 及原 package ID，不隔离已有学习进度；它只更新资源清单与入口校验哈希，由 manifest 哈希驱动新缓存、差异下载和原子切换。
18. 背景采用局部编辑而非整图重绘：分别以现有横竖 PNG 为母图，只移除两个细长吊坠并用相邻木拱、夜空或帘幕自然补齐；中央星灯、外侧原有星灯、窗户、柜台、光影和构图不得漂移。人工确认母图后确定性生成同版 AVIF 与 WebP。
19. 实施验收必须同时覆盖角色处置四种组合、单角色进度、两层提示、动作显隐、音频失败、保存与并发、真实教材接触、地图补演、精确文案、三枚五角星、两个课程横竖背景、五个必检画幅、两课程包冷暖缓存及真实浏览器巡检。自动证据、资源生成、人工视觉接受、提交、推送和发布继续分别记录。

## 验收门禁

1. 角色组合覆盖“完成／完成、完成／跳过、跳过／完成、跳过／跳过”；第一个角色处置后仍为 `5/17`，第二个处置后才为 `6/17`。
2. 正式角色扮演和无字逐句回演都覆盖两层提示、逐句重置、直接揭晓、播放中动作消失、音频失败后的重试或跳过。
3. 保存失败、刷新、重复操作和并发页面不得产生伪完成；角色处置只能按 `未处理 → 已跳过 → 已完成` 合并。
4. 混合状态只保留真实发生的角色完成和教材接触，不产生双角色完成事实、语言结果、掌握或无字逐句回演资格。
5. 阶段地图补演保存并恢复原主线精确位置；补演一个角色后可以继续另一个或退出，双角色真实完成后才替换阶段状态。
6. 所有选角、角色名称、提示、删除文案、失败和恢复动作执行 Catalog 精确文字与单一可见动作检查。
7. 成果页三枚装饰星全部使用 `★`；Lesson 1–2 与 Lesson 3–4 的横版、竖版均确认两个吊坠已移除，中央和外侧原有星灯未漂移。
8. `1280×720`、`1440×900`、`390×844`、`844×390`、`762×430` 不得出现重叠、裁切、横向滚动或不可点击占位动作。
9. Lesson 1–2 V2.6 与 Lesson 3–4 V1 的清单、入口哈希、冷缓存、暖缓存、内容校验、失败保旧和原子切换全部通过；进入课程后无资源缺失。
10. 自动门禁通过后仍需真实浏览器完成一次角色流程和两个课程横竖背景巡检；上述证据不等同于提交、推送、部署或产品负责人人工接受。
