## 1. 目的与证据边界

本文把已接受的六类故事构图展开为十七个恢复微任务的竖版与宽版可实现分镜，并声明无字逐句回演的同页长内容布局。它冻结“孩子看见什么、当前只做什么、正确后故事怎样真正改变”，不复制教材内容，不替 catalog 决定答案，也不证明当前页面已经达到这些画面。

当前工作树已有已获设计授权、但仍需完整验收的 V2 实现候选。本文既不覆盖或回退这些改动，也不把文件存在、单测草稿或本地页面冒充同一 SHA 验证或发布证明。

## 2. 四个正交设计维度

1. **主场景构型**：每个活动微任务只有一个，稳定值来自 `dialogue-stage`、`object-workbench`、`grammar-lab`、`homeward-journey` 或 `full-role-enactment`。它决定从阶段开头恢复时的基本空间关系。
2. **故事语义互动模式**：每个正式挑战声明孩子如何作用于语言与世界，只来自 `scene-identify`、`object-place`、`label-connect`、`utterance-select`、`relation-reconstruct`。它与主场景构型正交：前者描述动作，后者描述空间。
3. **场景呈现段**：Catalog 的 `presentation.moments[]` 声明同一微任务内的视觉焦点、参与者、实体状态和主动作；运行时快照提供 `currentPresentationMomentId`。它不是新的题、进度或恢复边界，也不与运行时 `phase` 混名。
4. **成果／停靠呈现**：`outcome-rest` 只挂在已成功保存的章节停靠、段落停靠或最终单元成果后；它不属于十七个活动微任务，也不显示额外进度。

知识卡是成功后的非计分呈现层。它可以从语法实验室升起，但关闭后才进入段落停靠；知识卡本身不是成果／停靠构型。

## 3. 六类双画幅冻结构图

### 3.1 对话舞台 `dialogue-stage`

```text
┌ 短标题                 进度        设置 ┐
├───────────────────────────────────────┤
│ 当前英文从说话人一侧进入；说话者前移       │
│                                       │
│  男招领员       柜台＋当前物品       女顾客  │
│  落地近景                         落地近景  │
│                                       │
├───────────────────────────────────────┤
│ 七句全文／当前一个挑战／三至四个大候选      │
│ 正式挑战时才显示三颗冒险心                 │
└───────────────────────────────────────┘
```

- 两名人物、柜台和当前物品始终形成可见关系；英文属于说话人，不漂浮在无主白卡里。
- 宽屏上两名人物固定在左右外侧，七句课文只在中间窄通道内自然展开，不遮住脸部或人物主轮廓；手机上人物先出现在课文上方，然后随页面自然滚动阅读。
- 七句真实 `ended` 完成后停留在当前场景，只保留“从头重听”和“继续”；未重播时不再重复显示“七句课文听完了”。
- 人物识别挑战在提交前保持候选人同尺寸、同亮度、同描边，不用高亮或焦点泄露答案。
- 交付只有一次。物品从故事中的真实位置进入对方手中，不用“再点确认”或第二次交接补动画。

### 3.2 物品操作台 `object-workbench`

```text
┌ 短标题                 进度        设置 ┐
├───────────────────────────────────────┤
│ 当前英文＋当前有效音频；功能性人物在一侧    │
│                                       │
│   托盘／标签册／衣架等真实工作面            │
│   候选 1    候选 2    候选 3–4             │
│   已完成物品留在真实槽位，形成可见清单       │
│                                       │
├───────────────────────────────────────┤
│ 当前唯一动作提示；点击一个语义答案即可提交      │
└───────────────────────────────────────┘
```

- 候选是场景里的物品，不是脱离背景的 emoji 卡片；正确后进入托盘、标签格或衣架。
- 听音轮与词形轮由承接面的真实变化区分，不让同一个词在连续两屏重复同一种点卡片操作。
- 人物只在仍有故事职责时出现；两人的共同事件尚未结束时保持完整同场，只用焦点与动作突出当前承担者，不让其中一人随题目切换突然消失。人物在场时固定左右关系位与尺度；纯物品阶段可让两人整体离场，把空间让给物品关系。

### 3.3 语法实验室 `grammar-lab`

```text
┌ 短标题                 进度        设置 ┐
├───────────────────────────────────────┤
│ 人物＋handbag/watch 仍留在原故事场景       │
│ 当前完整英文随组装实时变化                  │
│                                       │
│ 柜台展开： [Is this your] [watch] [?]     │
│           大块轨道，点按自动入槽             │
│                                       │
│ it ───── 星光关系线 ─────▶ 当前物品         │
├───────────────────────────────────────┤
│ 成功后才升起儿童知识层；第二层术语自愿展开    │
└───────────────────────────────────────┘
```

- 不是跳到成人黑板课，而是原柜台现场变形；人物、目标物品和句子用途不断场。
- 先让已经学过的 handbag 问句完整变形一次作为无结果示范，再由孩子组织 watch 问句；句块吸附时，上方完整话轮同步更新，`it` 必须可见地指回当前物品。
- 知识卡不计分、可立即继续，关闭后才可能进入段落停靠。

### 3.4 回家旅程 `homeward-journey`

```text
┌ 短标题                 进度        设置 ┐
├───────────────────────────────────────┤
│       同一扇全宽故事窗：一次只看一景         │
│        真实汽车 / 真实房屋；候选中立          │
│                                       │
│ 先听音指认 car、house                    │
│ 再点与 car 对应的汽车：女顾客上车            │
│ 再点与 house 对应的房屋：汽车抵达家中         │
├───────────────────────────────────────┤
│ 第一次错只轻摇；第二次错给方向性支架            │
└───────────────────────────────────────┘
```

- 不用钥匙隐喻，不把两张街景并排缩成看不清的小图。
- `L02-M20` 只完成声音主导的真实场景指认，不出现抽象路线位置，也不提前演出上车。
- `L02-M21` 的两个词形关系直接推动故事：`car` 发音真实结束后演出女顾客上车，`house` 发音真实结束后演出汽车到家；没有额外确认或交图。
- 标准上车／到家演出各 4–6 秒；减少动态效果直接显示相同终态，不改变音频、结果与保存门禁。

### 3.5 完整角色演练 `full-role-enactment`

```text
┌ 短标题                 进度        设置 ┐
├───────────────────────────────────────┤
│ 招领员固定左侧                     主人固定右侧 │
│ 当前角色：金色徽章      当前说话者：柔和呼吸光  │
│                  手提包留在柜台             │
├───────────────────────────────────────┤
│ 七行完整对话；孩子角色当前句先隐藏             │
│ [揭晓并播放我的台词]；对方话轮可见并自动播放     │
└───────────────────────────────────────┘
```

- 角色选择与回合切换只改变徽章和焦点，不交换人物位置；当前说话提示不得覆盖人物面部。
- 每个角色都从 D01 到 D07 完整运行。孩子角色的句子先回想再揭晓；对方句子保留文字并自动使用原角色声线。
- 完整角色整轮保存；中断的角色从 D01 重来，已经完成的角色显示勾选。两轮完成前没有阶段完成。
- 正式演练与无字逐句回演都只保留柜台手提包，不重复交包，也不加入书或手表。

### 3.6 成果／停靠 `outcome-rest`

```text
┌ 已完成 6/17、11/17 或 17/17             ┐
├───────────────────────────────────────┤
│ 保留刚刚发生的真实结果：                   │
│ 包已在主人手中／知识已保存／女顾客已到家     │
│                                       │
│ 不出现结算白卡、领奖、盖章、拉杆或点灯       │
│                                       │
├───────────────────────────────────────┤
│       继续                    休息      │
│               两个动作等权                │
│  次要自选入口：无字逐句回演或案件复盘（按节点）│
└───────────────────────────────────────┘
```

- 只有所属微任务原子保存成功后才能出现；保存失败留在原场景提供重试。
- 最终成果先读回完整状态，再播放人物离场和地标成长；演出不新增语言结果或点击门槛。
- 自选入口不做成第三个主按钮，也不阻塞继续／休息／下一课；短屏可以放在主动作之后随页面自然滚动，不能挤小人物、英文或两个等权主动作。

### 4.1 三个成果／停靠节点

| 节点 | 出现条件 | 保留的故事结果 | 动作与下一位置 |

### 4.2 五种互动模式的精确顺序

| Microtask | 正式挑战的 `interactionPattern` 顺序 | 主要可见后果 |
|---|---|---|
| `L01-M07` | 无 | 完整输入结束，不显示冒险心 |
| `L01-M08` | `scene-identify ×2` | 等权人物候选给出回应；答对才揭示随机丢失物托盘；包仅进入待归还状态 |
| `L01-M09` | `utterance-select` | 女顾客被礼貌叫住并回应 |
| `L01-M10` | `relation-reconstruct → utterance-select` | 问句形成；交流修复后原角色重说 |
| `L01-M11` | `label-connect → utterance-select` | 归还牌连到已确认的包；单次交包后女顾客说出感谢 |
| `L01-M12` | 无 | 两个角色分别完成七句全篇演练；只形成阶段完成，不形成语言结果 |
| `L02-M11` | `object-place ×2` | pen、pencil 进入核对托盘 |
| `L02-M12` | `scene-identify ×2` | book、watch 从包内场景自动进入托盘 |
| `L02-M13` | `label-connect ×2` | 两个英文标签与物品建立连接 |
| `L02-M14` | `object-place ×2` | book、watch 进入英文目标格 |
| `L02-M15` | `relation-reconstruct ×2` | watch 问句形成；`it` 指回物品 |
| `L02-M16` | `object-place ×2` | coat、dress 挂入分类架 |
| `L02-M17` | `scene-identify ×2` | skirt、shirt 从衣帽间自动上架 |
| `L02-M18` | `label-connect ×2` | coat、dress 英文挂牌连接完成 |
| `L02-M19` | `object-place ×2` | skirt、shirt 进入英文目标位 |
| `L02-M20` | `scene-identify ×2` | 听音后分别指认完整汽车与房屋场景 |
| `L02-M21` | `label-connect ×2` | 标签连接真实汽车／房屋，依次触发上车与到家 |

跨阶段连续计算也没有三个相同模式。所有模式都必须保留三至四个完整候选和稳定答案关系。Lesson 1–2 一律使用一次最短语义点击；系统随后完成归位、贴签、交付或场景变化。第一次错误只轻摇并提示“再看看”，第二次才进入方向性支架；视觉后果不能伪装成新的提交模式。

### 4.3 可跳过角色演练与两类可选同日练习

- **双角色全篇演练**：`L01-M12` 标题为“角色扮演”。孩子可任选首角色完成两个 D01–D07 回合，也可经确认诚实跳过；完整角色整轮保存，未完成角色补做时从 D01 开始。跳过只写独立状态，不生成教材接触、结果、故事事实或回访来源；地图保留“已跳过 · 完成角色扮演”入口。
- **无字逐句回演**：`L01-M12` 完成后解锁；七句初始全部隐藏，一个共享按钮逐句揭晓并播放。已揭晓句持续保留且可重听；提示按“中文意图 → 英文开头”两层展开。它没有角色选择、进度、恢复、结果或掌握，每次重进从 D01 开始。
- **案件复盘**：在 `NCE-U01-OUTCOME` 完成地标演出后自愿进入三题短复盘，分别联结语篇理解、交际／结构和词汇变化情境。它不是终考、到期回访或证书门槛；可选诊断最多写 `same-day-practice`，不能改变首次结果、排期、掌握、故事事实、地标或下一课资格。

## 5. 关键动效分镜与减少动态效果终态

| 动作 | 标准动效 | 减少动态效果 | 不允许 |
|---|---|---|---|
| 说话者切换 | 当前人物短距离前移，英文从其一侧淡入；上一位退回关系位 | 直接切换高亮、姓名与英文归属 | 两人持续摇摆、台词漂浮无说话人 |
| 七句跟随 | 当前句自然滚入舒适区；孩子手动滚动即停止自动跟随 | 直接更新当前句标记；“回到当前句”瞬时定位 | 强制抢回滚动、卡片内滚动、固定计时门禁 |
| 物品归位 | 物品沿短路径进入托盘、标签格或衣架并停住 | 起点淡出、终点立即出现 | 飞向无语义中央槽、持续弹跳 |
| 柜台变形 | 柜台一次展开为句块轨道，人物和物品保持原关系 | 直接切换到展开终态 | 切入成人黑板房、多个部件同时乱飞 |
| `it` 指代 | 一束星光从 `it` 连到当前物品，随后稳定停留 | 直接显示静态关系线与同色高亮 | 把 `it` 做成术语背诵题 |
| 上车／到家 | `car` 发音结束后女顾客用 4–6 秒上车；`house` 发音结束后汽车用 4–6 秒抵达亮灯房屋 | 直接切到人物已上车／汽车已到家终态 | 抽象路线图、交地图、标签后再点确认、无意义等待 |
| 单次交付 | 包或外套按一条路径进入女顾客手中，事实只写一次 | 终点状态直接替换 | 二次提交、二次交人、领取按钮 |
| 地标成长 | 完整读回后按“人物离场 → 招牌成长”顺序演出 | 直接显示离场后和已成长终态 | 保存前预亮、结算卡后再点亮 |

所有标准动效同一时刻只有一个主动作；背景至多极轻呼吸。目标英语必须先于非语言提示音，且语言 `ended` 门禁在两种动态偏好下完全相同。

## 6. 竖版、16:10 宽版与动态响应

### 6.1 360×640 硬下限

- 顶栏只保留短标题、`已完成/17` 与设置；点击进度打开全屏阶段地图。
- 阶段短标题只在顶栏出现一次；场景中央只显示当前动作提示，不重复左侧大标题或卡片标题。顶栏和阶段地图读取 catalog 的同一标题字段。
- 人物可从全身收紧到膝上构图，但脸、手势、当前物品与说话关系必须清楚；不得把人物缩成头像。
- 当前英文、一个 `challengeRef`、三至四个大候选和主操作必须同屏。普通阶段不得靠卡片内滚动完成。
- 七句全文是唯一明确长内容之一，使用页面级自然纵向滚动；播放、手动回看和“回到当前句”都不创建第二滚动容器。

### 6.2 430×932 与 16:10 平板／桌面

- 430×932 仍使用竖版母版；平板／桌面使用独立 16:10 宽版母版。两套背景都沿用木质星灯夜景画风，只包含建筑环境与稳定故事表面，不烘焙人物、手提包、任务物品或答案状态。
- 渲染器按容器长宽比选择竖版或宽版母版，再读取该画幅自己的语义锚点范围定位人物、柜台、托盘、衣架、汽车与房屋；手提包始终是独立图层，在当前画幅锚点范围内动态贴合真实柜台。断点只在所属画幅内重排这些图层，不产生第三张设备专用背景。超宽容器在 16:10 舞台外扩展环境边缘，不能继续放大并裁掉柜台或人物。
- 宽版固定三层安全区：顶栏、中央任务／语言区、真实柜台／动作区。宽版人物使用约舞台可用高度 65%–75% 的课堂尺度，竖版人物使用更紧凑的独立尺度；人物有故事职责时固定在各自画幅的左右关系槽与脚底基线，纯物品阶段两人一起离场。切换 `sceneMode` 不能更换同一地点背景、移动柜台、改变同一画幅的人物比例或把任务道具放到地面。
- 场景中的真实人物或物品是唯一候选层；任务面板不复制第二组答案。正确后只让原位实体短暂响应、立即播放目标英语并原子更新冒险心，禁止再显示“线索找到了”卡或只含答案的过场页。
- 1280×720 及以上宽版采用课堂字号档：行动提示 38–44px、英语目标 36–42px、选项 26–30px、辅助文字不低于 20px；竖版使用独立字号档。主题重听点击区在手机为 52×52px、宽版为 60×60px，播放时只让自身发光，不触发舞台重排或闪烁。
- 正确实体使用约半秒的原位反馈：物品轻微发光归位，人物按职责轻点头或伸手，冒险心同步补亮；目标英语从反馈开始便播放。禁止飞行星光、卡片、彩纸和语言前提示音。
- 只增加呼吸空间、工作面尺寸和场景细节，不增加题量、额外角色、并排挑战或第二套导航；内容顺序、当前焦点、主动作和结果状态与竖版一致。

### 6.3 手机横屏

- 显示不遮挡操作的“竖屏体验更好”，同时切换为可完成的紧凑构图；不强制旋转。
- 旋转保留 Microtask、当前 `challengeRef`、候选顺序、冒险心、当前音频请求、场景呈现段和退出入口。
- 七句全文可以在横屏使用页面级纵向滚动；候选区、台词区与反馈区仍不得各自滚动。
- 横竖切换只换构图母版和锚点投影，不重新创建课程内容、候选随机域或媒体请求。

## 7. Catalog、运行时与页面所有权

### Catalog 唯一拥有

- `presentation.sceneMode`、`sceneVariant`、`presentation.moments[]`；
- 每个正式挑战的五值 `interactionPattern`，以及 `L01-M12` 两个完整角色回合、无字逐句回演和三项案件复盘的稳定身份；
- 每个呈现段的参与者、固定人物关系位、焦点实体、可见语言、进入条件、状态终点、主动作和减少动态效果终态；
- 竖版／宽版背景资源、语义锚点、安全区、稳定点击候选、两级错误支架，以及上车／到家 4–6 秒标准演出；
- 教材／产品文案、Source／Content 引用、音频、候选、答案关系、支架、故事事实、停靠点与后续位置。

活动微任务 `sceneMode` 只允许 `dialogue-stage`、`object-workbench`、`grammar-lab`、`homeward-journey` 与 `full-role-enactment`。`outcome-rest` 必须由 rest stop 或 unit outcome 声明，不能塞进活动微任务允许集。

### 运行时唯一拥有

- 当前 `currentPresentationMomentId`、生命周期 `phase`、`challengeRef`、随机候选、冒险心、音频 request/segment、临时结果、原子保存和停靠恢复；
- 呈现段进入条件的确定性推进；正确后音频真实 `ended`、保存与读回门禁；
- 一次点击对应一次统一语义提交、两级错误纠错，以及系统故事后果的幂等演出；
- 正式双角色阶段的完整角色整轮保存、两轮完成门禁与未完成轮重启；无字逐句回演和案件复盘使用隔离练习会话，不得调用主线提交或跨日独立证据接口；
- 减少动态效果只改变到达终态的方式，不改变事实或推进条件。

### 页面只负责

- 按主构型、variant、当前呈现段、参与者和焦点实体渲染通用响应式布局；
- 转发点按、滚动、重播、继续、休息与设置事件；
- 不按 Microtask ID、步骤前缀、DOM 位置或课程字符串猜布局、答案、完成或下一个呈现段。
