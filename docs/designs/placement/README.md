# 跳级测试

2026-09-10 更新 · codex/duolingo-version · 无键盘规则；历史验收记录见 git 与原 bug-prevention.md。

## 产品规则

用户可以在未来 Lesson 分区的首个节点选择“跳级到这儿？”。例如跳到 Lesson 21 & 22，测试范围只包括 Lesson 1–20；目标章节从第一关开始学习。当前正在学习的分区保留正常路线入口。

1. 说明页呈现目标 Lesson、20 题、五颗心及“答错 5 题，本次跳级失败”。可以直接开始，或下次再说。
2. 每次固定 20 题，采用听音选择/组句、选词补句、情境回应与组句。基础课程使用已教词句的图片和文字选项；有可用题目时混合至少三种机制。
3. 词库与候选项是题型自身支持，不额外提供答案提示或错误后反复判分。听力题必须播放完，可正常重听；非听力题不提前播放正确整句。检查后反馈，再手动继续。相同词块按实际文字判等，其他允许词序由 catalog 明示。
4. 每道题只能判分一次；每次错误扣一颗心。第 5 次错误立即失败，即使它发生在最后一题；完成 20 题且错误少于 5 次才能通过。
5. 离开、刷新、重进保留同一题序、草稿、判分结果和剩余机会。失败后可以明确选择“再试一次”，生成新的题序并恢复五颗心。
6. 成功后返回路线并定位新的起点。之前的未完成节点标记“跳级通过”，仍可完整学习；已完成节点的真实学习证据保持原样。
7. 保存失败不显示已扣机会或已解锁，重试成功后才更新。多标签页使用现有写入锁和版本校验，冲突时重新读取记录。
8. “重置小镇挑战”只清除普通选做挑战；“全部从零开始”同时清除跳级进度，既有撤销能力继续生效。

## 抽题方式与边界

唯一真源仍为 catalog。基础题在 `content/placement.js` 审核维护，无键盘 authored 定义与主线候选一起生成 `unit.placement`。页面不拼造题目、中文提示或答案。

- 题库共 592 个题目变体；同一次按完整原句归一化去重，补句、组句与选意不会重复考同一句。
- 优先从当前未通过分区到目标之前的分区抽题，通常预留 14 题；其余题从更早内容抽取。某个短章节没有 14 个独立原句时，先抽完可用题目，再用前置知识补足，绝不加入未到达的目标或之后内容。
- 跨很多章节时分段抽样，覆盖整个跨度，并保证抽到最后一个前置章节；避免随机抽样只落在最容易的前段。
- 没有更早的已学分区时，20 题均取自被跳过的范围。Lesson 1 & 2 补齐了 20 个独立词句目标，避免“题数不足五道，却允许错四道”的门槛漏洞。
- 固定种子与题目 ID 随测试保存，恢复时重新验证种子、范围、题序、每题判分及通过条件。

20 题及上述抽样比例是本产品实施选择，不声称是 Duolingo 的内部算法。它是抽样测试，不代表逐题核验了所有被跳过章节。当前为本设备保存的学习进度，不是跨设备考试认证。

## 视觉与交互依据

参考截图与来源归档在 [Duolingo 跳级参考](../../references/duolingo/2026-09-08-placement/README.md)。

- 路线与题内统一 `#141f23` 背景；跳级入口用青绿色立体按钮、居中的白色双箭头。
- 跳级节点使用相同高度和行距；说明气泡不撑开路线。
- 开始测试为蓝色主按钮，检查/继续为绿色；错误反馈粉红，剩余机会橙色。
- 简短中文任务标题、清晰的点选作答区、底部稳定主操作。完成后回路线，不自动进入下一关。
- 复用已审核的 imagegen 猫猫素材，保留用户要求的迪士尼绘画方向。双箭头与心形属于现有 UI 图标系统；本次没有新增角色或物品插画。

实际最终结果以根目录 [design-qa.md](../../../design-qa.md) 和 [问题与防护记录](bug-prevention.md) 为准。实现、程序验证、实际页面验收和官网发布分别记录。

题库和作答契约升为 v3。旧完成或失败测试按冻结版本读取；旧进行中测试存档为“版本更新中止”，不扣机会，重新开始完整 20 题。新测试只反映有选项支持的路线检查，不宣称与原输入门槛等价。实际迁移与验证见 [本轮实施记录](../no-keyboard-learning/implementation.md)。
