# 跳级测试

## 产品规则

用户可以在未来 Lesson 分区的首个节点选择“跳级到这儿？”。例如跳到 Lesson 21 & 22，测试范围只包括 Lesson 1–20；目标章节从第一关开始学习。当前正在学习的分区保留正常路线入口。

1. 说明页呈现目标 Lesson、实际题数、对应机会数及失败门槛。正常为 20 题、五颗心，答错 5 题失败。可以直接开始，或下次再说。
2. 每次最多 20 题，采用听音选择/组句、选词补句、情境回应与组句。基础课程使用已教词句的图片和文字选项；有可用题目时混合至少三种机制。
3. 词库与候选项是题型自身支持，不额外提供答案提示或错误后反复判分。听力题必须播放完，可正常重听；非听力题不提前播放正确整句。检查后反馈，再手动继续。相同词块按实际文字判等，其他允许词序由 catalog 明示。
4. 每道题只能判分一次；每次错误扣一颗心。20 题时第 5 次错误立即停止答题；缩短测验要求至少答对 80%，可错数为 floor(实际题数 × 20%)，下一次错误即失败。必须完成全部实际题数才能通过。最后的正确或错误判分仍停在反馈页，手动“继续”保存成功后才结算并开放通过路线；刷新重进继续显示这道题的反馈。
5. 离开、刷新、重进保留同一题序、草稿、判分结果和剩余机会。失败后可以明确选择“再试一次”，生成新的题序并恢复本次题数对应的机会数。
6. 成功后返回路线并定位新的起点。之前的未完成节点标记“跳级通过”，仍可完整学习；已完成节点的真实学习证据保持原样。
7. 保存失败不显示已扣机会或已解锁，重试成功后才更新。多标签页使用现有写入锁和版本校验，冲突时重新读取记录。
8. “重置小镇挑战”只清除普通选做挑战；“全部从零开始”同时清除跳级进度，既有撤销能力继续生效。

2026-09-11 用户已明确允许跳级结算使用“剩余机会”，要求图标风格一致。第三卡采用新的 imagegen 薄荷绿绘画心形，与金色勾选、蓝色靶心匹配。普通关卡的“本次用时”保持原语义。此次授权不改变此前未经要求替换指标的历史事实，详见[诊断与变更记录](../placement-feedback-20260911/README.md)。

## 抽题方式与边界

唯一真源仍为 catalog。基础题在 `content/placement.js` 审核维护，无键盘 authored 定义与主线候选一起生成 `unit.placement`。页面不拼造题目、中文提示或答案。

- 题库共 592 个题目变体；同一次按完整原句归一化去重，补句、组句与选意不会重复考同一句。
- 先从当前未通过分区（含）到目标分区（不含）的题目中抽取。该范围足够时，全部题目都来自该范围；不足时先取完所有独立词句，再逐章向前补充，从较近课程开始。语法锚点、题型补足也遵守这一优先级，绝不加入目标或之后课程。
- 跨很多章节时分段抽样，覆盖整个跨度，并在最后一个前置章节有可用题时保留该章题目；避免随机抽样只落在最容易的前段。
- 更早课程取完仍不足 20 个独立词句时，按实际可用数量出题。6 题须至少答对 5 题，允许错 1 题，显示 2 次机会；少于 5 题须全对。题库为空时显示暂不可测试，不允许空测验通过。当前完整题库可经前序补题达到 20 题；短题数路径另用缩小的真实题库验证。
- 新测试保存 samplingPolicy=skipped-first-v1、固定种子与题目 ID；恢复时重新验证范围、题序、判分和动态通过条件。已保存的旧 v3 测试没有新策略标记，继续使用冻结的旧抽样算法，不重排、不清空历史成绩。

最多 20 题及上述抽样方式是本产品实施选择，不声称是 Duolingo 的内部算法。它是抽样测试，不代表逐题核验了所有被跳过章节。当前为本设备保存的学习进度，不是跨设备考试认证。

## 视觉与交互依据

参考截图与来源归档在 [Duolingo 跳级参考](../../references/duolingo/2026-09-08-placement/README.md)。

- 路线与题内统一 `#141f23` 背景；跳级入口用青绿色立体按钮、居中的白色双箭头。
- 跳级节点使用相同高度和行距；说明气泡不撑开路线。
- 开始测试为蓝色主按钮，检查/继续为绿色；错误反馈粉红，剩余机会橙色。
- 简短中文任务标题、清晰的点选作答区、底部稳定主操作。完成后回路线，不自动进入下一关。
- 复用已审核的 imagegen 猫猫素材，保留用户要求的迪士尼绘画方向。题内双箭头与机会条沿用现有 UI 图标；结算心形使用同套绘画素材，避免混用扁平与绘画风格。
