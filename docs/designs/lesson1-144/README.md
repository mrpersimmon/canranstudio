完整分区、目标和关卡数见 [课程地图](course-map.md)。在已发布的前 50 课基础上，本次补充 94 课、642 段原文、520 个新词条、296 个新例句、1,592 条录音。偶数课的数字、时刻与不规则动词形式也进入课本；代表性数字和时刻进入主线练习。

课程遵循 [首要设计原则](../../design-principles.md)，以用户提供的 Duolingo 路线、词块翻译、填空和输入界面为参照。每组保留明显的 Lesson 区分：手动推进完整故事，在关键处判断含义；点击学习词句；完成辨认、组句和补全；在综合练习中检索前一分区与间隔更远的知识。完成每一关后明确返回路线，顶部进度只表示当前闯关。

后半册把现在完成时、比较级、定语从句、间接引语、情态推测、条件句与被动表达加入练习。输入挑战选做，支持完整句子和局部填词；已审核的缩写、关系词、间接问句和时刻表达可等价作答。单组挑战、全部挑战和整套课程可分别重置，并保留撤销能力。

## 教材核对与原有进度

- 教材唯一依据为用户提供的 PDF，指纹、逐课页码和正文核对见 [教材来源记录](source-verification.json)。新增 642 段中，641 段在忽略空格、大小写和标点后与 PDF 文字顺序一致；一处 OCR 将 I 识别为 1，已渲染原页确认字母 I。
- PDF 第 179–182 页是阶段测试，Lesson 73 起明确增加四页偏移。最后一课定位到 PDF 325–326 页。中文注释和新练习由本项目编写，偶数课练习按教学目标改编。
- 原文姓名、称谓和代词保留，视觉中的人物为猫。教材中的人物猜测不会作为已证实事实考查；新练习通过文字给出足够线索。
- 学生笔记仅解释语言和故事。给作者的编排约束放在本设计文档：新练习使用食品、文具、出行等生活情境；教材中的医疗、烟酒、分期和彩票情节仅用于理解故事，不改成儿童执行操作。人物的夸张评论不作为性别、外貌或职业规则。原文保留与练习选材是两项不同职责。
- 自由输入的常用缩写和同义表达按完整句子审核，保存在 `content/book1/accepted-translations.json`；更改对应原句后必须重新审核。不得用全局文字替换猜测助动词、实义动词或情态动词后的缩写。当前已审核 82 个原句、129 个替代表达；挑战仍以教材目标及明示的可接受答案为范围。
- 发布版本为 `lesson1-144-v6.0`；旧 `unitId` 与 `experienceRevision` 保持不变。发布范围扩展不等于创建新学生。前 50 课的题目、顺序、答案、节点、课本和挑战保存逐项指纹；读入旧记录不得重写或虚构成绩。

执行 `npm run compile:course` 重新生成课程和媒体请求。编译器文件沿用 `scripts/compile-lesson1-50.js` 名称以保持现有命令兼容，实际范围为第一册 144 课。修改作者文件后必须重新编译；不得在页面中另写题目、答案或音频对应关系。

新增图像通过 imagegen 生成迪士尼绘画方向的完整猫猫场景，按原构图压缩为 WebP；不使用程序代替绘制。第 101 课背景画像中出现的人脸已通过 imagegen 改为猫，原提示、修正提示和最终指纹均有记录。

录音采用固定版本的 Kokoro、正常语速和完整自然句。合成前遇到未解析英文词即停止，11 个新词和专名已补充明确发音；不启用音频拉伸、慢速播放或不可靠的系统兜底。录音和图片按需校验并缓存。

## 发布前防护

首次准备仍遵守原有 4 MiB 上限。课程传输采用 `course-table-v1` 无损字符串和结构去重，解码后逐项、顺序和原 catalog 完全相等；包含 70 个文件，共 3,154,821 字节。传输表不是第二套内容来源，不能用于编辑课程。

完整逻辑检查、四尺寸逐题页面检查、十三类故障注入、音频全量解码和原生播放抽样均保留。没有通过记录、覆盖不足、指纹过期或公开文件与 HEAD 不一致时，发布包构建必须失败。实际结果见 [当前验收](../../../design-qa.md)，原因与复发拦截见 [问题记录](bug-prevention.md)。
