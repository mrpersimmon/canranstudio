# Lesson 3–4 视觉系统与素材登记 v1

状态：实现契约
体验修订：`lesson3-4-v1`

## 1. 视觉命题

- 主题：夜晚的星灯失物招领站，一张号码牌带着孩子走完整个取物流程。
- 用户：以儿童为主；电脑端常用于授课，需要大字和远距离辨认；手机端保留人物但缩小，给任务留空间。
- 唯一任务：听懂、判断所有关系、演完整段，再迁移到新物品。
- 风格：温暖的舞台式故事书，不做通用卡片后台，不堆星星、爱心或奖励条。

## 3. 固定场景与响应式锚点

背景复用 Lesson 1–2 的同一失物招领站：

- 宽屏：`starlight-station-bg-v2-wide.avif/webp`，设计画布 1600×1000。
- 竖屏：`starlight-station-bg-v2-portrait.avif/webp`，设计画布 1080×2340。
- 来客：左下固定；服务员：右下固定。
- 电脑端人物顶部应明显高于柜台台面，人物高度约视口 `46–58vh`。
- 手机端人物缩为 `24–32vh`，仅露出足够建立角色的上半身或三分之二身。
- 柜台上的道具使用相对于 `.counter-plane` 的百分比锚点，不能按屏幕像素漂浮。

## 4. 识别性元素

黄铜 `5` 号牌既是故事道具，也是进度信使：每完成一个阶段，号码牌在顶部冲压轨迹上移动一格。它只在孩子确认的过渡中移动，不做循环动画。这样进度属于故事，而不是通用进度条。

自我审查：

- 不能回到“所有内容都塞进奶油白大卡片”的通用设计。
- 场景是主画面；羊皮纸只承载需要阅读或点击的内容。
- 同一背景、人物和柜台贯穿十段，避免像十个不相关小游戏。
- 除号码牌外不添加装饰性徽章、爱心、星级、知识卡或庆祝条。

## 7. 动效与防闪烁视觉约束

- 背景 `<picture>`、两个人物和柜台在首次挂载后不替换节点。
- 阶段变化只更新现有面板内容和道具容器；不清空根节点，不切换整页。
- 当前与下一阶段关键图片在交互开放前预解码。
- 预解码格式顺序与可见 `<picture>` 完全一致：AVIF 优先，失败后再尝试 WebP、PNG。
- 号码牌过渡 260ms；物品确认 180ms；无持续呼吸动画。
- `prefers-reduced-motion: reduce` 下移除位移，只保留即时状态变化。
- 音频播放不改变图片 URL、背景或人物类名。
