# Lesson 1–50 实施与验收

用户于 2026-09-07 授权完成前 50 课网站。分支 `codex/duolingo-version`，基线 `fac029f`。本次采用用户指定的 Duolingo 课程与交互原则、深色路径/课内参考，以及 imagegen 迪士尼绘画风格。

## 课程范围

- Lesson 1–50 连续编排为 25 个两课分区、129 个关卡、576 个活动。
- 349 段教材原文按顺序完整呈现，26 个故事活动（Lesson 5 的原故事仍分两关），每一句手动触发，原速播放并可重听。
- 选择、听词辨义、听句辨义、词块组句、句子补全、图片配对、互动故事和文字输入；学习与考察分开标记支持条件。
- 26 组选做输入挑战，共 190 题，包括句内填词和中文到英文的完整输入；挑战包含已经教过的词句和之前分区的复习。
- 叙述课 25、27、33、35 使用场景与旁白，保留原文叙述形式；其他故事有猫猫角色与情境理解节点。
- 每关结束主动返回路线；顶部只显示本次闯关进度。重置单组挑战、全部挑战和全课程继续独立保存、失败重试并支持撤销。

详细范围见 [逐分区课程地图](course-map.md) 和编译生成的 [覆盖清单](coverage.json)。教材参考为用户提供的《新概念英语智慧版 1》PDF 第 35–134 页，PDF 和同步参考文件没有修改或公开打包。课堂例句、中文释义与练习是教学改编，不标成教材原句。

## 素材与加载

- 新绘制并接入 21 幅 imagegen 场景。保留 [提示词](imagegen-prompts.json)、[美术登记与文件指纹](art-register.json) 和 `assets/lesson1-50/scenes/source/` 原图。客厅图重绘去掉错误的书堆；衬衫与玻璃杯课文有专用场景。
- 新生成 793 条原速语音，复用并迁入 314 条已存在录音，连同前六课共 1,231 条。采用固定 Kokoro 模型、固定音色和明确的人名发音，见 [音频登记](audio-register.json)。没有慢速文件或播放速率拉伸。
- 首次只准备约 2.55 MiB 的课程、公共程序和路线素材；录音及课内插画按使用下载。启动清单固定媒体索引的指纹，单个文件验证字节数和 SHA-256 后才缓存；损坏的媒体、丢失的索引会失败并提示恢复，不退回未核验文件。
- 旧版存储身份保留，新增发布版本单独为 `lesson1-50-v5.0`，避免把扩课当作新用户。已有成绩、故事/词卡记录、输入挑战和重置备份保留。

## 维护与复现

1. 在 `content/expansion/` 修改对应原文或学习蓝图；`lesson1-6-baseline.json` 保留本次扩课的原基线。
2. 运行 `npm run compile:course` 生成唯一运行时 catalog 和素材请求。新增音频通过 `scripts/media/generate-kokoro-audio.py` 读取请求，固定模型版本生成；美术使用 imagegen，不用占位图替代。
3. `npm run build:course` 打包。`npm run test:media` 完整解码全部语音，`npm run test:browser-media` 验证真实浏览器播放与缓存、存档升级，`npm test` 验证课程与状态规则。
4. `npm run test:browser` 在四种屏幕逐活动、逐故事句段、逐挑战输入状态检查。四个尺寸并行执行同一套流程，最终证据必须合并满足全部范围；没有抽掉后面的课。
5. 查看实际页面，保存截图。提交当前输入之后，`npm run build` 才能生成与该提交一致的发布包；部署继续是独立步骤。

当前实际结果见根目录 [design-qa.md](../../../design-qa.md)，修复原因及复发防护见 [扩课修复记录](bug-prevention.md)。没有将自动解码或浏览器的 ended 事件写成所有录音已获人工听感验收。
