# 黄金册页 V2：平衡地标大小

历史构图修订。[修订图](map-composition-review-v2-balanced.png)以肉铺为大小基准：城堡缩小约 15%，希腊花园放大约 10%，旅行站缩小约 15%–20%；统一铭牌大小与间距。
