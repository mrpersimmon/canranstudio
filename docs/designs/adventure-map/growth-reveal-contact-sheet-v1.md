# 阶段成长揭晓 · V1 视觉与动效合同

## 目标

孩子第一次完成课程中的真实关卡后，课程先保存成绩，再立即以全屏揭晓告诉孩子“地图上的地点具体长出了什么”。揭晓不是额外任务，也不把孩子送回地图；0.7 秒防误触窗口结束后，点击或轻触任意位置即可关闭并继续向下闯关，页面上不显示关闭按钮。

## 真实组件证据

`growth-reveal-contact-sheet.png` 由共享 `core/growth-reveal.js` 在 390 × 844 真实课程页面中直接打开并截取：

- 阶段 1：从 `state-0` 切换到带红白遮阳棚的 `state-1`，完整建筑保持同一锚点；
- 阶段 2：从 `state-1` 切换到增加新鲜食品陈列的 `state-2`；
- 阶段 5：从 `state-4` 切换到完成态 `state-5`，出现「地点完成」章和独立永久纪念物。

它证明课程内揭晓、城区地图与课程目录引用同一套完整累计状态图，而不是运行时叠加松散图层或维护三套近似图片。

## 动效节奏

1. 羊皮纸卡片在约 0.42 秒内进入；
2. 成长后的完整状态图在约 1.05 秒内显现并获得金色光晕；
3. 最后一关的完成章随后盖下；
4. 约 1.8 秒后画面停留在最终状态，永不自动关闭；
5. `prefers-reduced-motion: reduce` 时直接展示最终静态状态。

实现使用原生 HTML、CSS 与 JavaScript，因为这是课程内的实时交互状态；Remotion 适合导出视频，不适合作为每个孩子可关闭、可恢复焦点、可响应当前关卡的运行时。

## 行为边界

- 仅已成功持久化的 `0 → 正数` 首次评级触发；重复挑战或提高星级不重复出现；
- 图片或音效失败时仍保留文案，并允许正常关闭；
- 打开前停止课程当前音频，反馈音效失败不阻塞学习；
- 无可见按钮；支持任意位置轻触，以及 `Enter`、`Space`、`Escape`；
- 打开期间背景不可滚动，关闭后恢复原焦点与滚动位置；
- 完成第五关时纪念物与 `state-5` 保持独立，地图上永久保留。
