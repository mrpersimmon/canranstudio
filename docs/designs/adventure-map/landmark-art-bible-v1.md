## 2. 统一的是画风，不是建筑

## 3. 累计状态图片契约

五关课程交付 `state-0` 至 `state-5` 六张完整累计图；音标专项交付 `state-0` 至 `state-4` 五张完整累计图。

- 每张状态图都是完整地标，不是运行时透明增量层；
- 所有状态使用同一高清无损母版和同一固定画布；
- 建筑位置、基线、镜头、比例、透视、光线、基础植被和模切轮廓不得漂移；
- 新状态只能在合理锚点增加或完善内容，不能移动、替换或重新生成基础建筑；
- 禁止六张图片分别从空白提示词独立生成；优先在上一状态或统一母版上定向编辑，再一次性无损压平；
- 状态图中不出现徽章、课程文字、按钮、数字或 UI；徽章始终作为独立收藏资产；
- 第五阶段可以喜庆，但庆典必须附着在建筑和环境上，并保留主题辨识度。

## 4. 徽章契约

徽章继承 Lesson 51 罗盘的品质：明确圆形或纹章轮廓、古金属框、课程主题图案、植物或丝带辅助结构、克制配色、手绘纸张质感和奶油色模切边。

徽章必须概括课程成就，不得把地标里随机截取的物件当作徽章；不得把徽章直接烘焙进任何地标状态图。

## 5. 画质与移动端

- 无损母版至少保留 1024×1024 RGBA；条件允许时保留 1536 或 2048 源文件；
- 不从已压缩的 WebP/AVIF 继续编辑，也不重复有损转码；
- 网页派生 512、768、1024 三档，由显示尺寸与设备像素密度选择；
- 棕色细线、奶油色透明边、水彩颗粒、建筑窗框与徽章小纹样是画质验收重点；
- 文件体积不构成牺牲清晰度的理由，不合格时提高编码质量或回退到更高分辨率。

## 6. 每课程审查门

每门课程在接入网页前必须同时通过：

1. `state-0…N` 联系表审查：六张图一眼可见同一地点逐步成长；
2. 差异审查：每次只出现该关声明的新增内容；
3. 几何审查：基础建筑像素位置与外轮廓稳定；
4. 语义审查：建筑与新增物件都能解释课程主题；
5. 透明边与缩略图审查：无色键残留、无裁切、在手机地图尺寸仍可读；
6. 徽章审查：与 Lesson 51 罗盘同一品质，但主题独立；
7. 华为手机与平板真机审查：不模糊、不变形、不被地标牌或地图边缘遮挡。
