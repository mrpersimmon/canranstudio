# 十二城区图鉴唯一入口 · V1 视觉真源

## 已对齐方向

网站根入口只呈现一册可探索的世界图鉴。孩子先看见十二城区世界总览，再进入当前开放的「暖灯集市」，最后直接点击地标进入课程。旧首页头图、继续学习卡、课程目录、番外站与页脚入口均不出现在可见界面中。

手机竖屏是构图真源，平板只扩大取景：城区的空间含义、唯一可进入区域和操作顺序不因设备改变。十一处未来城区是不可操作的远景地貌，不使用空卡片、锁头或“正在绘制”占位。

## 真实页面证据

- `atlas-only-world-overview-phone.png`：390 × 844，手机竖屏首屏；
- `atlas-only-world-overview-tablet.png`：768 × 1024，平板竖屏首屏。

两张图均由本次实现后的真实 `/` 页面在空白设备档案、减少动态效果模式下直接截取，不是脱离代码的概念稿。

## 视觉与交互合同

- 图鉴标题、探索副标题与完成地点数位于地图纸张内部；
- 设置是右上角的书签，不与主要探索入口竞争；
- 「暖灯集市」是唯一高饱和、带地标插画和金色光圈的区域，整个地标均可点击；
- 其他城区仅作为带名称的低对比远景，`aria-hidden` 且不进入键盘焦点；
- 普通访问 `/` 始终回到世界总览，不因上次浏览城区而偷偷跳层；
- 从课程返回时只有合法的 `district` 与 `focus` 参数会进入城区并定位真实已发布地点；
- 手机与平板均使用自然纵向滚动，不要求拖拽、缩放或横向平移。

## 保留与放弃

保留暖色羊皮纸、手绘地标、旅途虚线和印章式视觉语言。放弃十二张城区卡、未绘制 Lesson 号方框、独立推荐大卡、旧课程目录和会遮挡地图的课程详情面板。完成进度被收进地标名称牌上的实体印章，当前闯关地点用光圈与「正在闯关」徽记提示。
