## 窄屏长数值的修复

- 现象：替换金色徽章后，320px 跳级成功卡的“20/20”几乎贴住边框，[修复前](long-value-before.jpg)。
- 原因：新增图标为 24px，旧图标为 18px；五字符成绩和固定 20px 字号占满了扣除真实滚动条后的卡片内宽。
- 遗漏：旧规则只检查是否越过卡片外框，不能发现卡片内边框的留白耗尽。最初普通结算数字较短，也未暴露这一状态。
- 修复：最窄屏幕中超过四个字符的数值采用 18px；其他尺寸保持原有字号，图标不压缩。
- 防护：正式可读性检查要求值与图标位于边框内并额外留 1px；三枚彩色图标加入现有透明度、可见性与滤镜检查。
- 复验：20/20 左右边距由约 3.14px 增为 5.64px（含 3px 边框）。[修复后](placement-pass-320.jpg)。同时检查本次用时和其余结果卡。
