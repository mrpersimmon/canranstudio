# Lesson 分区、快速点击与雨伞场景修复

日期：2026-09-06。状态：本地实现、自动检查与实际页面验收通过；未推送、未部署。

## 教材分区决定

采用三段：Lesson 1 & 2、Lesson 3 & 4、Lesson 5 & 6。路径标题直接呈现教材课号；关卡介绍标明实际涉及的 Lesson；复习关标明 Lesson 1–4 / Lesson 1–6。保留 11 个关卡的 ID、顺序和学习记录。

依据：[外研社第一册介绍](https://www.fltrp.com/c/2022-10-20/514394.shtml)说明单数课为对话或短文，双数课通过图片呈现。配对为地图章节是本产品的设计选择，不是声称出版社规定应用必须这么分区。现有 catalog 前六课内容对应此配对；第 5、6 课原来被拆成两个主题，现在合成一个教材分区。

## 美术验收规则

本轮原道具的复杂金属高光不符合已约定的迪士尼二维绘画方向，不能仅凭生成提示词认定其合格。重新通过 imagegen 生成：较少的明暗层次、柔和轮廓、完整身体、相向目光与手势；号码牌的大号 5、雨伞的星星/条纹/圆点需在缩小后仍能区分。

保留 [来源、母版和提示词](../../../poc/learning-path/assets/story-v2/README.md)。生成器返回的假棋盘背景另按用户已授权的技术透明处理导出；不隐藏这一步，也不把元数据朝向声明当作实际目检。新素材通过后记录哈希，后续被替换必须重新确认来源、朝向、边缘与小尺寸辨认。
