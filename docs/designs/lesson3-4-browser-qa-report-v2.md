## 2. 已实现的防回退门禁

- 背景、人物和道具层不得在阶段变化中 `replaceChildren`。
- 任务面板不得设置为整块 `aria-live`。
- 当前图片必须按实际格式顺序预解码。
- 正式错误才改变三心；归零救援产生 assisted 证据。
- 角色跳过、互补分配、正式补做和隔离回演均有状态机测试。
- 次日复习要求已解决主线、有效完成时间和下一个本地自然日。
- 复习存储键、心池与结果都和主线隔离。
- 静态合同阻止页面重新硬编码题目或接受答案。
- 共享场景不含儿童可见中文文案；标题、指令、状态与反馈统一来自 catalog。
- 旧票据轨道、旧完成条和整页替换式过场已从共享场景与样式中移除。
