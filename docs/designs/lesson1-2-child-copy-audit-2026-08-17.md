# Lesson 1–2 儿童文案与词形反馈流程审计

> 日期：2026-08-17  
> 范围：保留 2026-08-17 历史问题结论，并同步 2026-08-23 当前 15 个微任务的儿童提示、共享响应控件、正确反馈与三级纠错提示
> 原则：孩子看到的主提示只回答“现在发生了什么、我要做什么”；不把系统状态、课程术语或视觉隐喻当成操作说明。

> 2026-08-23 当前实现：候选共十五个微任务。独立徽章感谢阶段已删除，教材感谢保留在完整首听和四幕课文回顾，并在外套归还情境中检索；car/house 使用直接小镇影像，不再借钥匙表达。以下表格只是 catalog 文案的审计快照，活动文案仍以 catalog 为唯一真源。

## 1. 发现的问题

1. 部分提示只是课程作者标签，例如“完整问归属”“听完肯定回答”，孩子无法据此判断要观察什么。
2. 部分提示把界面隐喻当成任务，例如“把感谢送进说话槽”“铺好两块问句轨”，需要先理解产品术语。
3. 多个按钮统一写成“确认这条线索”或“完成动作”，没有重复当前动作的实际结果。
4. 词形题答对后先进入一个独立的“听一听”页面，孩子必须再点一次才能继续；这个播放不是新问题，却表现得像新任务。
5. 正确反馈“线索对上了”和音频提示“听完才会开启下一步”在解释系统，而不是回应孩子刚完成的行为。
6. 同一套抽象纠错话术被同时用于人物动作、表达选择、词形辨认和句子排序，部分语义不匹配。

## 3. 共享控件与反馈整改清单

| 原文或行为 | 整改后 |
|---|---|
| 答案选中后还出现“确认这条线索”“就是它”“就说这句”“放进问句”或“排好问句” | 选择本身直接提交；句块放满最后一块后自动判定 |
| 所有实物动作都用“完成动作” | 按动作显示“交给对方”“接过来”“盖下印章”“拉下拉杆” |
| “刚才的声音是谁？” | “刚才听到的是哪个物品？” |
| “线索对上了！” | 按行为显示“找对了！”“这句话正合适！”“问句排好了！”等 |
| “问句轨道”“按顺序铺两块问句轨” | “完整问句”“按顺序点两块词语” |
| “听完才会开启下一步” | 普通必听音频显示“听完就继续”；不再解释内部解锁机制 |
| 答对后本来需要播放英语，却出现新的“听一听”或喇叭按钮 | 从孩子确认答案的同一次点击给出视觉确认并立即播放对应单词、句子或角色回应；英语之前没有提示音，真实 `ended` 后自动进入下一步 |
| 一套抽象纠错提示覆盖所有题型 | 拆成人物动作、表达选择、词形辨认、句子排序四套具体提示 |
| 为回答“物品是谁的”而复用“点物品、点人物”的交还动作 | 理解题只点击主人，物品保持在原位；真正交还只在故事因果成立后出现一次 |
| 为感谢迁移另造“接回徽章”环节 | 整个独立环节删除；教材感谢留在完整课文回顾，T5 在外套主人真实收到物品时检索 |
| 用 car-key / house-key 代指 car / house | 直接呈现汽车和房屋的小镇场景图；孩子选择的是教材词本身，不先理解钥匙隐喻 |
| 探险小猫机械出现在每个画面，缩在成人脚边 | 普通对话与物品任务不显示装饰性小猫；只在开场引导、伙伴救援或里程碑中以足够清楚的尺寸出现 |

## 4. 交互合同

- 词形题提交前不播放词音，避免泄露答案。
- 第一次答案点按会直接提交并记录当前结果；凡接下来需要播放英语的任务，都在同一次手势中给出视觉确认并立即播放对应单词、句子或角色回应，英文持续可见且没有可点击的喇叭、播放或二次确认按钮。
- 播放期间不接受下一次作答；只有当前活动请求的真实 `ended` 才能进入下一词。
- 正确反馈不在英语之前播放任何界面音效；只有 catalog 对应英文音频的真实 `ended` 才能形成声音接触并开放后续步骤。
- 播放失败仍进入既有显式降级流程，不用计时器伪造完成。
- 同一件故事物品只能在故事因果成立的位置真实交还一次；身份判断、词汇匹配和回看不能复用交还模板。
- 小猫出现必须承担引导、救援、孩子角色或庆祝职责；没有职责时不占据场景构图。
- 教材文字、任务提示、答案、纠错与音频映射继续只存在于 catalog；页面脚本只渲染共享控件文案和运行时状态。

## 5. 验收重点

- 逐一预览当前 15 个阶段，主提示必须能独立说明当前行动。
- 词形题应形成“看词—点物品—视觉确认并自动听词音—下一词”的连续节奏，中间没有前置提示音、确认或额外播放按钮。
- 表达选择与实物动作按钮必须说出实际行为，不出现“确认线索”“完成动作”等系统语言。
- 答错后的三层提示必须与当前题型一致，不泄露答案，也不制造虚假的独立成功。
