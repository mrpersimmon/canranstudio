## 3. 统一设计标准的可优化点与落地

本轮在现行 v2.0 原文件修订，保留稳定文档入口；以下改动均已写入该标准，不另立一份竞争规范。

| 可优化点 | 本次固化的规则 | 解决的问题 |
| --- | --- | --- |
| 通用规则、组件尺寸和场景坐标混写 | §1 分成三层：所有入口的通用要求、共享组件的当前基线、按课校准的场景值。 | 防止把某段的人物比例／坐标机械复制到其他课。 |
| “沿用已验收”容易被理解为豁免 | §1／§4.3 明确：旧布局继续受 J19／J20 等现行规则约束；人物与来源固定，运行时位置可以修正。 | 本次问题虽在第二段曾修过，仍遗漏了首段。 |
| 几何检查只看按钮矩形与静态标题 | §4.3.1／J10 明确完整金章点击框、当前外圈、焦点和动效范围；保守 alpha 几何检查配合目视。 | 消除“DOM 没越界，但金章压帽／外圈被裁”的验收盲点。 |
| “信息成组”缺少对存量邻课的定义 | §4.3／J20 要求避让上方完整入口，兼容信息组与独立课名；预留成果行，金章出现不改变课名位置。 | 不要求先重做全部课，也能避免新旧布局相互挤压。 |
| 满星预览、界面样本和真实获星证据混淆 | §9.2 明确隔离响应样本可以验几何，但不写成绩、不替代实际作答与首次日期检查；共享组件须复验其他使用方。 | 避免只验零星，或把满星演示当作业务验证。 |
| 有规范、有历史通过，却缺少问题关闭依据 | §10 要求发现编号、证据、J 规则、修复位置、复验、限制和状态成对记录；保留原失败图。 | 防止补了文档就误认为问题已解决。 |

同时清理测试说明中仍把 v1.2 称为现行维护入口的句子；设计索引指向本轮关闭记录。全局“passed”不再脱离验收范围单独挂在设计验收首页。

后续可继续优化但本轮未实施：将视觉样本与尺寸结果整理为可复用的报告工具，以及补实体手机／微信验收。现有共享信息组件已经能承载本次修复，无需为此重建首页布局系统。

## 4. 实际验证与失败记录
