# 单列入口与地面锚点优化

2026-10-23 · `codex/fronted-opt-version`

本轮已完成以下列明的本地实现与验证。全部72课使用单列入口；3–4、39–40、141–142有独立真实接地点标定，其余24段中景的证据层次见接地记录，不能概称全部完成逐脚数值验收。

## 原问题与修复边界

用户仍能看到人物地标与地图串位。上一轮的“课名更靠近自己的地标、不发生矩形重叠”没有覆盖人物鞋底与实际平台的接触关系。侧边中文课名需要宽度、换行和避让，会进一步拆散同一课的视觉结构；仅删除中文文字而不移除旧标签占位与避让约束，不能解决问题。

本轮分开处理两个独立问题：地图入口改为统一纵向结构，首段 Lesson 3–4 的实际地面接触单独校准。背景与人物仍共用同一等比画布；不把文字缩短作为人物落地已正确的证据。

## 新入口约定

1. 每课结构固定为“人物地标 → 星星和金章 → Lesson 号码底牌”。三部分按人物实际可见轮廓中心对齐，误差限为 1 CSS px。星章上缘距可见轮廓下缘为 6 CSS px。
2. Lesson 底牌上缘距成果行下缘为 8 CSS px，独立点击高度为 44 CSS px。地图底牌只显示完整号码，例如 `Lesson 139–140`；不显示中文课名或“当前”字样，不再使用左右分布、逐个避让的大课名框。
3. 底部当前课程卡、目录、搜索和可访问名称继续保留完整中文课名。视觉简化不影响找课或辅助技术辨识课程。
4. 选中状态使用底牌颜色、外框和原有地标点击反馈，保持选中前后底牌尺寸不变。选择课程不能改成绩，也不能因为增加选中文字导致地图重新排布。
5. 任意两课的可见人物、成果行、Lesson 底牌之间至少保留 12 CSS px 空隙。空间不足时优先使用安全的竖版构图和页面自然滚动；不拉伸底图、不裁去人物、不压缩点击区。
6. 地面接触必须独立验收：人物鞋底、柜台或椅腿对照背景实际平台，而不是只看整张透明图片边界或运行时 `feet` 数值。统一几何坐标不是逐课美术验收。
