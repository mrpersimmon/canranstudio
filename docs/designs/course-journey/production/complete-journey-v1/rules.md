# 全量入口制作与验收规则

1. 每课身份以本课纪念卡为准，第一课仅作为画风参照。不能把首课女士的帽子、围巾或外套移植给 Penny、Carol 等角色。相同角色跨课时核对头发、服饰和配色。
2. 每个入口是一组完整人物及故事道具；不直接把纪念卡截图当地图入口。站立人物、坐姿人物的鞋、座椅和道具底部均不得被画布截断；柜台、电视或大桌子不得替代被遮住的下半身。
3. 保留适合儿童理解的真实故事时刻。89 看房未决定，131 假期未确定，137 中奖仅为假设；101／133 的远方人物只出现在明信片／报纸中；123 的胡子属于照片中的过去形象；139 用两个电话场景表示异地通话；143 是林间局部观察，不伪造已清理完成。
4. 课号、姓名、日期、得星、金章和当前选择均由网页绘制。人物图片不烘焙卡框、成绩、悬浮对话泡或整片地板背景。火车人物的车窗与墙面须移除，保留座位与人物作为真实透明地标。
5. 每个地标的星星与金章同排，整体居中于本地标可见轮廓，排顶距轮廓底部 6 CSS px。不得给新单元增加独立 stars／medal 坐标。三种获星状态保留统一占位。
6. 课名单独避让，完整显示，不通过缩小文字或省略号隐藏问题。窄屏和三位数编号按所需行数保留高度；标题高度参与后续标题间距与画布底部计算，不能只修改 CSS。不足 375px 采用窄标题方案；侧边标题同时避让人物和星章。底部留白按固定学习区、导航实际高度加 16px 计算，保证长课名时仍可滚动访问入口。
7. 新素材依据实际 alpha 尺寸等比放置。当前 19 段的竖版前／中／后景可见高度目标为画布宽的 .33／.2805／.238425，再根据各组实际宽高比统一收紧，以保证站立区与 85% 的层次。横版另有 .25／.2125／.180625；本次竖版可见宽度上限为 .38／.36／.42，横版为 .22／.27／.27，防止宽屏不必要地退回竖版。这些是本次构图值，不是未来场景通用坐标。
8. 本轮发现 320px 时中景星章会碰到较大的前景头部，修正整体人物比例，保留脚下星章规则。必须检查星章与全部人物、全部标题、完整金章点击框；不能只验当前课内部。
9. 每次改稿另存请求和 receipt，并更新 selected-variants 与独立测量边界。用初稿的边界检查修订稿会产生假失败，不得以放宽 6px 阈值处理。
10. 课程集合、星数、首次日期与续学地址只取真实账号接口。演示全收集仅能在明确的本地演示库补齐缺失版本，先备份，保留已有成果和学习进度；不修改正式业务成绩。
11. 63 个固定尺寸是覆盖目标的验证矩阵，不是 95% 真实访问已达标的证据。浏览器模拟、实体机、微信、真实键盘和访问统计分别报告。
