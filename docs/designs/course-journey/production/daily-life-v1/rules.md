# Lesson 19–30 素材身份与生成约束

## 共用画风与图层

原始认可手机图决定环境、材料、光线和人物比例；`handbag-couple.png` 决定圆润大头、短肢体、暖棕轮廓、温暖肤色与柔和体积。本课纪念卡／角色图负责身份与道具，不复制其卡片裁切或较高的身材比例。人物、道具和实际站立面的角度要一致。

每份请求明确哪张是编辑目标、风格参考或身份参考。人物为真透明完整构图，环境为不透明竖／横画布；不程序抠图、拉伸、裁掉脚或覆盖原纪念卡。画面中不生成课号、标题、按钮、图钉、星星、金章、姓名或日期。实际留白不一定达到请求的 10–12%，记录真实边界，不把期望值写成验收值。

## 环境与手机构图

两段环境分别保存 1024×1536 竖图和 1374×1145 横图，原生尺寸以 receipt 为准。横图使用对应竖图作为场景身份参考，以已采用横图作为几何编辑目标，不把竖图裁拉成横图。保持连贯的奶油石路、珊瑚拱桥、青绿水面、花草和左上暖光。

厨房、客厅、卧室采用开放式房间入口与空前庭，保留可站立的真实地面。人物站位按实际地面、可见边界和前中后景关系验收；不能只因中心点在台面上就默认双脚、椅脚、桌脚都安全。

星星和金章在运行时统一位于对应地标可见轮廓底部下方，整排中心跟随地标；课名可以在旁边避让。该规则由共用 `overlay-layout.js` 执行，不固定在背景或人物 PNG 中，也不继续复用旧分散的 stars 坐标。完整成果行、44px 金章点击范围、标题、人物及裁切边一起验，不能只检查发亮图标本身。
