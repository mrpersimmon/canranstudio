## 编码与真实尺寸

所有生成使用内置 image_gen。原生 PNG 按字节复制保留；WebP 只按 quality 88 编码，不裁切、去背、重绘、拉伸、重采样或将原人物烧入地面。实际提示词、参考顺序、透明开关、工具返回位置和 SHA 保存在对应收据中，不用事后整理的理想提示词覆盖真实调用。

六张庭院均为 1536 × 1024、alpha 范围 0–254。竖向底图实际为 **724 × 2172**，不是提示词中期望的 1024 × 3072；其 1:3 比例保留。宽屏底图实际为 **1254 × 1254**，不是请求中的 1536 × 1536。两张底图均不透明，原生尺寸差异如实保留，不作人工放大。连接桥为 1536 × 1024、真实透明背景。

## 已知生成偏差与接入要求

- 左右道路主动延伸至画布边缘，部分桥体延伸至底边；连接端头不适用“所有方向均保留 8% 透明边距”的旧要求。仍须保留人物完整、操作留白和页面安全空间。
- 生成道路只大致遵循请求中的入口／出口方向，不能把提示词坐标直接当作图中实际可走通的精确端点。运行接点需结合最终素材和页面检查。
- 原地面的软透明边缘仍可能保留；WebP 查看器也可能展示透明像素中不可见 RGB 的压缩条带。5–8 已测 PNG/WebP 的 alpha 逐像素完全一致；其他资源及最终透明合成以各收据和浏览器实拍为准，不能因单独查看器画面直接承诺页面无接缝。
- 中央空铺地保留仅是人物组合的前提。原人物鞋底、柜台腿等真实接触点仍须在页面中逐项检查；不能把 alpha 矩形合法、单个 feet 点或共同变换当作接地充分证据。
- 段间石桥属于装饰层，应依据相邻 stage 的实际矩形与各自连接端口重算。它不负责人物定位，不与人物接地点互相补偿，不进入课程点击和完成状态。
- 底图／石桥失败应隐藏失败装饰、保留可读底色；课程选择、星章、搜索和开始学习继续工作。人物或本课地面失败仍按原逐课重试规则处理。
- 路径色彩相似并不能证明连续。最终需同时检查道路方向、端头遮接、建筑尺度、植被衔接和手机纵向浏览时的旅程感。

## 历史保留与复现

[modules-v1](../modules-v1/README.md) 的原图、实际请求、收据与 42 文件冻结记录原样保留。v1 页面结果不能作为本版环境的验收结果，v2 也不反写 v1 的历史结论。

已有采用资产优先复用。确需再生时使用对应收据的真实提示词、同 SHA 输入、原参考顺序和透明开关；历史绝对路径可以替换成当前工作树中的同字节文件。固定提示词和输入不保证随机生成逐像素相同，需再次检查人物合成、端口与手机效果。

## 只读冻结与校验

[verify-manifest.cjs](verify-manifest.cjs)冻结本轮24个文件：18个采用PNG／WebP，以及unit1-4-receipts、unit5-8-receipts、unit9-12-receipts、environment-requests、environment-receipts、desktop-environment-receipt这6个实际请求／收据JSON。各课程与宽屏实际请求原文已嵌在对应收据中，辅助单独请求副本不重复计入。

校验脚本只读仓库内文件，比对固定SHA与字节数；不写回基准，不访问历史生成目录，不联网再生成。运行模型、人物／桥路位置、样式、可更新设计记录及验收截图不在冻结范围，仍需随真实页面检查调整。

在仓库根目录运行：

```text
node docs/designs/course-journey/production/modules-v2/verify-manifest.cjs
```

脚本已执行，24个文件全部匹配：9个采用资产的18个图像文件，以及6个请求／收据文件。校验通过仅证明冻结文件一致，不能替代页面视觉、手机适配或业务验收。
