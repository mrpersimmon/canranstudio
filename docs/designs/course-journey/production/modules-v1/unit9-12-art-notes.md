## 明确的边界与未满足项

请求要求四周至少 8% 透明余量，实际生成未全部达到；一次针对性修订后仍如此。禁止把该要求写为通过。9–10 在 alpha>16 时边界为 [.022786, .088867, .982422, .921875]；11–12 为 [.064453, .031250, .958984, .927734]。两张完整轮廓没有被裁掉，但运行时应给整个模块增加外部安全留白，按真实边界校验点击反馈和阴影，不依赖请求中的 8%。本次未程序修改 PNG 来伪造边距。

三张对应请求 JSON 与 receipt JSON 固化了实际 prompt、引用角色、引用 SHA-256、工具返回路径、原图 SHA-256、输出尺寸、alpha 测量与编码输出 SHA-256。9–10 初稿保留为 unit9-10-ground-first-generation.png，当前采用第二版，生成历史不覆盖。
