# Lesson 5–8 地面模块生成与复核

- 工具：内置 image_gen；5–6 两次调用，7–8 一次调用。人物参考仅用于配色与比例，成图不包含人物。
- 学堂庭院与花架谈话露台分别保存原始 PNG 与仅编码 WebP；不裁切、不去背、不绘制、不缩放像素。
- 实际尺寸均为 1536 × 1024；原生 alpha 实测范围均为 0–254。多数实物区域为 254（接近不透明），并保留原生透明与软边。
- 环境画风采用原 opening/neighborhood 地图；5–6 使用奶油/珊瑚学堂门面，7–8 使用矮花架拱门，中央石板地面留空。
- 建议脚底中心归一化位置为 (0.50, 0.72)，安全站立区为 x=0.23–0.77、y=0.56–0.75。最终以原角色实际鞋底及家具腿为准进行整体模块视觉验收。
- 人物与地面合为同一个局部父容器；不要各自按页面尺寸计算独立位置。人物、地面与底部进度的运行时布局由主任务实现。
- **构图偏差明确记录：** 提示词要求左右 8%–10% 透明留白，首稿与单项改稿仍只有约 3% 的实物安全边；主体未裁边。UI 应为完整模块额外保留外侧空间，不裁掉平台或通过像素加工伪造留白。
- 5–6 首稿保留在 variants/unit5-6-ground-v1.png，采用第二稿。所有实际提示词、参考路径、返回路径、alpha 边界和 SHA-256 见对应 request/receipt JSON。
