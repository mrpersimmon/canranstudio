# Lesson 13–18 生成约束与实际落点

## 风格来源与图层职责

认可手机图决定暖棕轮廓、圆润大头、短肢体、柔和体积和温暖肤色；已采用的 `handbag-couple.png` 决定透明人物层的完成度与干净边缘。本课纪念卡与角色图负责身份、服饰、道具和故事，不能直接用卡面矩形替代地图人物。

人物和环境独立。环境沿用奶油石路、珊瑚拱墙、青绿水面、花草和左上暖光，保留真实可站立地面及信息区。生产图不画课号、课名、星星、金章、图钉、按钮、姓名或日期；这些由真实网页与业务数据绘制。每份实际请求明确参考图顺序，环境局部编辑以被编辑环境为第一张输入。

## 人物完整性与摆放

完整保留头、帽、手、脚与道具，以可见身体和鞋底校正比例，不用透明画布外框比较大小。原生 alpha、可见边界、实际尺寸与编码写进 receipt。留白以真实输出为准，不把提示词期望当作已达到的数值。

当前第三段全部使用成果＋课名信息组。竖屏中景人物左移至 x=0.35 后，环境 v2 补足铺地；实际鞋底采用 y=0.46，未照抄编辑提示词设想的 y=0.492。横屏后景信息中心采用 x=0.78，避免窄桌面与中景人物相交；中景信息左边界采用 x=0.64，完整成果行也避开自己的行李与鞋底。手机后景人物 x=0.73，为左上地图范围控件留空间。

三层信息避让必须取上一层最终位置及完整高度，不能只算原始脚底或只处理两层。长范围名称应完整可见，不能只测此前较短的“Lesson 1–6”。完整矩阵、零／部分／满星、缺图重试、真实进入、权限与减少动态分别按统一标准验收。

横构图前景成果行在鞋底下方保留 4px 净空，避免 WebKit 百分比排版的亚像素贴边；同时把前景用于画布下限的 label 锚点从 0.85 调为 0.86。成果组使用 info 实际定位，但旧 label 锚点仍参与当前布局器的最小可见范围计算，不能只增加 offset 而遗漏画布底部。
