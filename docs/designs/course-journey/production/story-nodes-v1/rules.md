# 单元人物与场景生成规则

本包固定 Lesson 3–4、5–6 的人物与首段地图环境补充，沿用原[认可手机稿](../../references/approved-mobile-v1.png)及已经采用的[手提包人物](../../../../../assets/course-journey/handbag-couple.png)。背景和人物分别生成，实际课号、名称、星数与操作由页面绘制。

## 共用要求

- 每课以关键人物、代表性动作或道具和局部场景表达课程故事。角色与情节取本课已确认图及教学事实，不能把 Lesson 1–2 的人物复制到其他单元。
- 人物保持暖棕圆描边、温暖肤色、短肢体和清晰表情，头身比与手提包人物对照。建筑保持奶油石路、珊瑚拱墙、青绿水面和左上暖光；人物为二维故事插画，环境有柔和体积。
- 全身图保护帽子、手、脚和关键道具。柜台可合理遮挡工作人员下半身；不能为了露脚改变认领情境。近景纪念卡只提供身份和故事依据，地图另做适合站立的构图。
- 人物输出真实透明背景，不带房屋、地台、泛光底盘或 UI。使用工具原生 alpha；边缘问题通过图像工具修正，不用程序抠图、阈值去背景或手绘替代。
- 环境图留出可站立的平地与标签空间，不再烘焙同一套人物或重复关键道具。本次移除旧环境中的巨型紫伞和木箱，由认领人物组中的单把伞及柜台承担情节。
- 三课场景、人物、真实星数和标签使用同一地图坐标。根据最终图片重新量取可见轮廓、脚底和地面，生成提示词里的坐标不能直接当成实际落点。
- 手机通过纵向留白和滚动容纳人物；不压小触摸目标、遮住相邻人物或单独拉伸背景。对长屏放大和短屏滚动都检查可见人物边界。

## 固定输入与验收

人物初次生成按“认可母版 → 已采用人物画法 → 本课纪念卡”排序。人物局部修正再加入本次候选图，明确只改比例或留白。环境编辑将待编辑环境作为第一个输入，第二个输入为认可母版；这是编辑目标顺序，不能误解为更换视觉主基准。

每次保留完整请求、引用顺序、来源和输出哈希、原生尺寸、透明边界以及修正记录。生成输出可能不等于提示词要求的像素尺寸，应采用实际尺寸并按原比例显示。相同提示词不保证随机生成逐像素一致；一致性优先依靠复用已验收资产。

新单元先准备自身身份与道具依据，再从本规则建立新版本配方。不可覆盖本包的历史请求、认可图和最终图片来冒充同一次生成。实际页面要与同尺寸参考一起目视，并检查真实选择、搜索、缺图恢复和学习成果不变。
