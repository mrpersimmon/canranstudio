# Lesson 1–12 星章与课号贴近人物

日期：2026-10-25。分支：`codex/fronted-opt-version`。现行规则归入[统一设计标准4.8／J33](2026-10-22-1332-v2.0-首页入口统一设计标准与验收清单.md#reward-spacing)。本轮只调整前六个配对单元的信息距离；13–144保留原规则，素材、原人物、成绩和生成凭据不变。

## 1. 问题与根因

用户发现星星和Lesson课号离所属人物太远，电脑模式尤其明显。上轮把人物、铺地、星章及课号保留在同一方形article内，并验证没有串位和重叠，但普通流stage使用`flex:1`占满剩余高度，将成果信息推到区段底部。人物可见底缘在约.56W，容器则随宽度W一起增大，因此电脑上的空隙被放大。

“属于同一article”“与相邻课不重叠”只能证明结构归属，不能证明用户看起来足够接近。本轮保留单一近景和人地绑定，单独纠正成果信息的距离；不把此前的融合检查改写成已经验证过该距离。

## 2. 当前距离标准

| 测量 | 当前要求 |
| --- | --- |
| 人物／道具可见底缘到星章行上缘 | 目标14 CSS px，验收范围12–16 CSS px；手机和电脑均按实际可见轮廓测量 |
| 星章行下缘到Lesson按钮上缘 | 8 CSS px |
| 可见底缘到Lesson按钮上缘 | 手机星章行44px时为66px；桌面星章行48px时为70px，不能统一写成70px |
| 操作与稳定性 | 星章／金章及课号保持完整点击区；0／2／5星、未选中／选中、加载／失败不改变距离基准 |
| 本课与相邻课 | 人物、星章和课号须构成紧凑的本课组合；既检查实际距离，也检查相邻完整组合及页面滚动后的归属 |

其中“可见底缘”包含原图中完整人物和柜台等道具，不使用透明图片外框、单个脚点或完整方形地形区段的下缘。

| 可见底缘→星章行上缘 | 130.406px | 14px |

## 3. 实现与不变项

[route-worlds](../../../course-journey/route-worlds.js)根据原人物的anchor、可见bounds和等比宽度计算`visualBottom`。如果p为人物锚点y，s为人物宽度占artboard的比例，b为原图可见底缘，a为原图锚点y，则：

```text
visualBottom = p + s × (原图高度 / 原图宽度) × (b - a)
stage实际高度 = visualBottom × artboard宽度 + 8px
星章行上缘 = 可见底缘 + 8px + 原有6px外边距
Lesson按钮上缘 = 星章行下缘 + 8px
```

[PanoramaJourney](../../../course-journey/PanoramaJourney.jsx)把该比例传给本课article；[panorama.css](../../../course-journey/panorama.css)采用按宽度计算的padding比例和8px内容高度，明确`box-sizing:content-box`与`flex:none`。这避免百分比误按扣除底部padding后的容器高度计算。原星章6px、课号8px普通流间距继续使用，留白移到课号之后。

方形article、整张静态地形、完整1:1 artboard、原人物比例和脚点、同源地面补片及它们的坐标均不变；没有移动或拉伸地形来迁就文字。图像按钮的焦点内缩调整为4px，并使用更高特异性的规则，避免被旧样式覆盖或压到鞋底。13–144的地图及成果位置不变。

本轮没有新增或修改美术资产，也没有新的图片生成调用。历史[modules-v3素材与提示词](production/modules-v3/README.md)继续保留原字节和来源范围。
