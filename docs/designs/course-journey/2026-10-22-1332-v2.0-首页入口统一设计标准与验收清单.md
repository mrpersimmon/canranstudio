## 2. 导航、账号与找课

首页和纪念册复用同一品牌标识、文字导航和账号行为。桌面保留“我的课程／我的纪念册／我的”，当前位置明确；首页手机采用“课程／纪念册／我的”底部导航，语义与目标一致。

修改密码、退出登录收在“我的”；退出不再叫“切换学生”。“本机旧记录”是“我的”中的次级入口，普通打开默认折叠；桌面直接进入历史入口可以展开。旧记录来自使用账号之前，不自动归入当前学生，不在首页占据找课空间。首次登录、设置新密码、进入首页和实际进课须连通；共用导航修改还要验证退出后的其他标签页身份更新。

| 操作 | 页面应发生什么 |
| --- | --- |
| 点人物、场景或课名 | 选中课程，更新唯一当前标记及侧边／底部学习区，给出短促反馈；不直接进入课程。 |
| 点“进入课程／继续学习” | 使用该课真实续学地址、当前基础路径和预览上下文进入课程。 |
| 切换地图范围 | 显示该区域已授权节点，当前课程同步到区域内的有效课程；没有授权节点的区域不提供虚假入口。 |
| 目录中的“地图定位” | 自动切到对应区域、选中并定位该课；只给已实现地图的课程提供此操作。 |
| 普通选择或关闭目录 | 保持浏览位置；关闭目录恢复触发点焦点。只有显式定位才主动把不可见节点带入视口。 |
| 刷新或从课程返回 | 恢复合法的当前课程、对应地图和界面书签；失效或越权书签丢弃。 |

### 搜索与目录

- 搜索始终跨全部已授权课程，不局限于当前地图或当前筛选区间。课程数量、名称、星数和续学地址由真实接口提供。
- 数字精确匹配所属配对单元：`5`→5–6，`8`→7–8，`10`→9–10，`12`→11–12，`50`／`Lesson 50`→49–50，`144`→143–144；不能把 `5` 当作所有含数字 5 的课。
- 名称等文字支持归一化后的模糊匹配；无结果时给出可理解的空状态和返回全部课程的操作。
- 当前目录区间按 Lesson 编号划分，每 18 个 Lesson 为一个区间，即最多 9 个配对单元；不按稀疏授权列表的下标重新编号。地图段与目录筛选区间是两种不同组织方式。
- 手机只保留一份实际搜索输入，目录使用模态语义和明确关闭按钮。唯一结果按 Enter 只聚焦可见的“进入课程”，不自动离开首页；不能聚焦隐藏目录中的同名控件。
- 目录每行显示 Lesson 范围、完整名称和真实星数；缩略图只作辅助，图片失败也能认课和进入。
- 地图范围控件须容纳完整长名称，例如 `Lesson 13–18`；旧短名称能显示不代表扩展后不会被原生下拉箭头截断。
- 手机范围选择放在“学习旅程”标题旁，退出插画区域，避免遮住人物和同轴入口。

## 4. 响应式地图、人物站位与信息分组

### 4.1 每章一张原生近景、三个原始区段

Lesson1–144的72个配对入口全部采用连续近景，按编号分成24章，每章三个配对单元。每章只绘制一张权威近景，按原生比例显示；手机自然纵向滚动，较宽页面保留有描边的地图画布和独立装饰远景。近景不使用cover裁切、不为窗口高度压扁人物，也不把不同宽高比的图片强拉成同一比例。

当前地图宽度上限手机480px、较宽画布560px；768px起有外围间距与描边，1024px起采用侧栏，断点两侧须按J39互补。相同宽度下只改变窗口高度，不改变人物与近景的对应位置。

近景目标比例1:3。按J41只允许整图一个原生像素的整数取整差，登记真实宽W、高H；每个区段的源高度为H/3，页面段高为H/3×显示宽度/W。人物的局部artboard仍为显示宽度的1:1正方形。不能把“原图区段”“人物artboard”和只负责预留成果空间的stage当作同一尺寸。中间没有授权课程时保留原区段的静态通路，不能重新编号；没有授权的首尾区段可以裁去，剩余人物仍对应原来的源像素。

旧大图相机、前中后景缩放和6px成果距离保留在[历史规则归档](2026-10-26-单列大图规则归档.md)，不再用于当前入口。

### 4.2 人物、静态地形与同源铺地共用坐标

原人物和道具保持原文件及比例。当前可见组高为地图显示宽度的36%，脚点纵坐标为局部artboard高度的56%；所有72入口按真实可见轮廓居中，保留原人物文件和原锚点数据，运行时整体位置按实际完整组合校准。具体坐标和铺地范围必须按实际构图校准，不能将透明图片外框当作人物或鞋底。

背景静态地形不随点击晃动；原人物与同源脚下补片共享轻回弹。补片取同一张图、同一缩放和原始段号，其原图偏移为负的段号×H/3。半透明遮罩只用于融合同源地面，不能掩盖两张不相容地形、重复平台或拉伸道路。

独立标定实际可见鞋底、轮子、座椅与桌架支撑；悬空鞋和被遮住的支点不编造。低alpha边缘保留，不为通过几何检查删像素。数学投影通过后，仍要看实际组合中的台阶、栏杆、家具、前景和场景语义：例如火车座椅需要可辨认的车厢内景，不能仅因鞋底落在平地上就接受站台构图。

### 4.3 星星、金章和Lesson统一归属本课

所有72入口均为“人物与同源铺地 → 星章 → Lesson”的同轴组合，完整放在本课article中。星章行上缘距人物／道具可见底缘目标14px、允许12–16 CSS px；课号在星章行下8px。stage按可见底缘比例加8px，再接星章原6px外边距，空白留在课号之后；不得用整个区段的剩余高度拉开成果距离。

星章点击行手机44px、桌面48px，课号按钮至少44px高；地图课号保持完整单行、不缩字或省略。学习区的Lesson范围也作为完整文本单元，空间不足时整体换到下一行，不能断成半截课号。中文名称保留在学习区、目录、搜索及可访问名称中，允许Jimmy、Jill、Sally等英文人名开头。

零星、部分星、满星与当前选择采用同一空间约束。前景墙、屋檐、家具及强阴影不能穿过本课的成果／课号区域；即使文字由代码绘制在最上层，也须检查背景中的实体是否让入口看起来落在屋顶或家具上。末课按钮能通过普通页面滚动完整到达，并在固定学习区上方保有约16px余量。几何、可读性和真实接地分别验收。

### 4.4 裁切不能变成隐藏的滚动容器

地图裁切层使用 `overflow:clip`；页面正常滚动，地图内部不能因点击、焦点或定位自行平移。必须分别检查页面滚动与地图的 `scrollTop`／`scrollLeft`，不能用“页面已回到顶部”代替内部位置正确。`overflow:hidden` 虽然没有滚动条，仍可能被程序或焦点滚动；保留的旧浏览器降级不等于该浏览器已经验收。

### 4.5 搜索面板与软键盘

结果少时缩短目录面板；可用高度小时优先保留输入、完整结果、进入及关闭操作，收起次要说明。以实际可用视口处理软键盘占位。390×500／519／520／521 场景中结果容器须能放下完整操作，当前专项要求高于 100px，不能只证明按钮还在 DOM 中。短结果面板当前取 clamp(400px,60dvh,560px)，再受可见高度上限约束；不能只用固定比例导致断点另一侧骤然挤压结果。

### 4.9 页面上下边界与固定栏（J35–J36）

标题、工具栏、地图和固定学习卡须作为完整页面验收。2026-10-25在612×913复现：手机侧栏上内边距为0，范围选择框紧贴品牌栏；底部直接使用“卡片＋导航＋16px”作页面占位，滚到底后露出16px纸色横带。详见[根因、修复与实测记录](2026-10-25-页面边界间距与修复经验汇总.md)。

1. **顶部呼吸空间**：小于1024px时，品牌栏下边界到标题／范围控件所在行上边界保留16 CSS px；320px也不取消。标题、选择框、搜索与目录依次排布，不能只给其中一个按钮加偏移。
2. **吸顶单独测量**：标题滚出后保留搜索与目录，工具栏距视口顶部8px、底部8px。负向吸顶距离按工具栏与侧栏的实际相对位置计算，不能在改变顶部内边距后仍沿用固定`top:-64px`，也不能露出上一行残缺文字。
3. **滚动避让与页面占位分开**：避让量为实际学习卡高度＋实际底部导航高度（含安全区）＋16px；页面占位使用前两者之和，并利用最后一个完整Lesson按钮之后的场景尾部，最多让场景伸入圆角卡片后方24px。扣除的空间必须来自按钮之后，不能直接删光预留量。
4. **末课安全**：滚到页尾时，最后一个可操作Lesson按钮距学习卡上缘目标至少16px，允许1px布局／滚动取整误差；地图场景与卡片之间不得再暴露纸色横带。旧大图容器末端至少保留18px，其中2px处理取整与边缘重叠；只调整容器，不放大、拉伸或移动原人物及画布。地图自身的装饰边框／底色仍按对应形态目视检查，DOM场景框接上不等于图像边界一定自然。
5. **变化来源分离**：卡片长课名、安全区与导航高度只影响滚动占位；章节或授权集合变化后重新测量末端空间。任何这些变化都不能触发人物／地面相对位移，不能拿当前滚动位置改变相机比例。桌面不保留手机底部占位。
6. **复验三种位置**：首次顶部、标题完全滚走后的吸顶状态、页面绝对底部都要看。固定矩阵增加用户实际反馈的612×913，另验320长课名、390手机、平板与1023／1024切换；第一段、第二段和旧大图分别检查。工具栏输入／目录、末课选择、焦点与继续学习均须可用。

### 4.10 章节切换不先清空画面（J37）

2026-10-25用户反馈1–6切到7–12时整屏闪烁。实页采样确认页头和首页根节点未重建；旧实现按章节key立即卸载地图，新图片即使命中缓存仍从loading进入异步decode，连续6个采样帧隐藏了地形和人物。缓存命中不能作为已能绘制的依据。

1. 24章之间切换采用“保留当前已解码画面→在不可见层准备目标→整体替换”。目标真实地形及本章人物均已解码后再显示；不靠延时后强行显示，也不先移除旧图再淡入新图。最多临时保留两个章节层，替换后卸载旧层，不预渲染全部72课。
2. 共用远景、页头、搜索与底栏保持稳定，不添加全页透明度动画。准备层必须整体不透明度为0且不可交互，不能只用可被子元素覆盖的`visibility:hidden`。旧画面保留期间也设为inert／aria-hidden，避免点击旧课与目标选择不一致；超过160ms才出现简短加载提示，目录和学习入口继续可用。
3. 请求代次决定哪个目标有权显示。快速返回原章节取消待切换目标；迟到的成功或失败回调均不能把用户重新带过去。学生、基础路径或授权课程集合改变时立即丢弃不相容的保留层，不以无闪烁为由展示失效课程。
4. 图片“解码完成”和“已向用户展示”分开。首次满星庆祝等目标层真正显示后再消费；目录定位也须等该层解除inert后再聚焦和滚动，不能在隐藏层上把待定位请求提前清空。
5. 底部空间只测实际显示的层，忽略准备层；显示提交后重新测量。保持J32人地绑定、J33星章距离、J35–J36上下边界，切换时不以加载状态改变地图比例或整页滚动位置。
6. 资源明确失败时结束等待，展示目标章节已有的局部失败与重试状态，Lesson及学习入口仍可用。失败不算就绪、不播放首次庆祝；不能无限保留旧图来冒充目标已经打开。
7. 必须检查真实切换的中间帧：缓存往返、延迟网络或解码、快速取消、失败／重试、搜索定位、授权变化以及普通／减少动态。切换完成后的单张截图无法证明没有闪烁。当前机制覆盖全部24章；本轮实测相邻双向、首末环路与受控图片延迟，见4.14。不把接入机制或定时DOM采样等同于所有任意排列、慢网络和逐像素视频均已通过。

本轮根因、实现、实际采样和未测项见[章节切换闪烁修复](2026-10-25-章节切换闪烁修复.md)。

### 7.1 从历次修复提炼的共同原则

新增课程或调整布局前，先判断问题属于哪一层；不能用另一层的偏移掩盖根因。下面归纳J01–J44，不另建第二份平行标准。

| 问题族 | 统一原则 | 必须保留的验证证据 |

### 9.1.1 真实访问覆盖目标

最近 30 天学生首页有效访问上下文的验证覆盖目标为 95%，总体及手机、平板、电脑分别报告。分母包含 unknown、未覆盖和验证失败的有效样本；缺数据时标记待统计。固定尺寸通过、区间推估和真实访问覆盖率不是同一个指标，不能相互替代。

用户已确认暂无本站尺寸数据。现已按[访问尺寸采集方案](2026-10-22-1620-网站访问尺寸采集方案.md)实现同源采集、独立聚合库和管理员汇总，生产与常规本机预览默认关闭；尚无生产数据，95% 仍待验证。运行及证据配置见[实施记录](2026-10-22-1930-尺寸采集与第三段入口实施记录.md)。

采集只保存页面环境聚合和短期事件摘要，不记录姓名、学号、班级、成绩、完整地址或原始浏览器信息。统计故障、限频或关闭不得影响学习；教师班级预览排除，普通教师和学生不能读管理汇总。覆盖率按精确环境和构建匹配有效证据，未知或未测仍留在分母；证据须由实际验证产生，不得直接把候选清单改名算作通过。

每次布局修正至少复验原问题视口、窄短屏、长屏和桌面，以及普通／当前和三种获星层级；共享信息组件改动还复验已接入的其他地图段。按影响范围选择上述矩阵，不把“修一课”扩大成每次重跑全部 72 课教学，也不以零星样本替代满星避让。

手机模拟、WebKit、实体 iOS／Android、微信、真实软键盘、弱网及课堂体验分别报告。现有记录尚不能代表实体手机、微信或完整发布验收已完成。本地演示号的满星只用于预览，不是实际学习证据；涉及演示数据变更须单独标识并保护旧收藏及日期。

### 9.3 交付与发布

开发前指出受影响的 J 编号与真实页面，运行必要的原问题和相关回归；不为无关课程扩大测试，也不弱化边界、授权、日期或性能断言。文档改动检查链接、版本关系和来源覆盖，不冒称重跑了功能测试。

收到提交／推送请求后按[测试说明](../../../tests/README.md)运行或复用相关检查，`npm run check:plan`说明范围，`npm run check:commit`执行相关检查。开发、提交、推送和发布分别授权及报告；推送以远端分支提交号一致为准，远端检查单列；完整发布验收在正式发布阶段按[发布指南](../../../deploy/README.md)执行。

### 维护原则

今后的首页修正先更新本文的现行要求及 J 编号，再补实际证据与必要的布局快照。现有 J 编号不复用为其他含义；新问题继续递增。变化涉及形态、风格、成果表达或数据边界时须遵循用户确认，不能从旧提案自动恢复已放弃方案。

审视发现与通用 J 规则分别记录：每项发现保留“问题、影响范围、证据、对应 J、修复位置、复验结果、剩余限制及当前状态”。有了规则或通过了旧版本检查，不等于当前问题已关闭。关闭时链接同视口、同状态的修复前后画面，并说明是自动几何、人工目视、模拟浏览器还是真机；历史失败与原结论保留，另附关闭记录。
