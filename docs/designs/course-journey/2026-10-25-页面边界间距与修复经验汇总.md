# 2026-10-25 页面边界间距与修复经验汇总

适用分支：`codex/fronted-opt-version`。现行规则已合并到[统一设计标准4.9／J35–J36](2026-10-22-1332-v2.0-首页入口统一设计标准与验收清单.md#page-boundaries)，历次问题的共同原则见[7.1](2026-10-22-1332-v2.0-首页入口统一设计标准与验收清单.md#shared-lessons)。本文保留本轮根因、实施与证据，不另建平行规范。

## 用户反馈与根因

用户在612×913标注了标题／范围控件贴近品牌栏，以及页尾地图与“当前课程”卡之间的留白。

| 问题 | 实际原因 | 修复方式 |
| --- | --- | --- |
| 顶部拥挤 | 小于1024px的侧栏上内边距为0，标题行直接从品牌栏分隔线开始。 | 统一保留16px顶部内边距，小于360px也保留。 |
| 吸顶偏移隐患 | 原`top:-64px`固定依赖旧标题高度，改顶部空间后会残留标题／统计行。 | 按工具栏在侧栏里的实际位置计算吸顶偏移，吸顶后上下各8px，前面的文字完全退出。 |
| 页尾16px白缝 | `bottomReserve = 学习卡高度 + 导航高度 + 16px`同时用于滚动避让和页面padding，安全间距被画到地图外。 | 保留完整滚动避让量，另算页面占位；只从末课按钮之后的场景尾部借用空间，让地图最多进入圆角卡后24px。 |
| 320px下1px细缝 | 初修后旧大图尾部刚好16px，卡片小数高度、向上取整与页面滚动取整叠加，实际间隙1.015625px。 | 旧大图容器尾部至少18px，含2px重叠余量；不改原画布／人物比例与坐标。保留首轮失败记录。 |

原始复现：[顶部](evidence/2026-10-25-page-boundaries/02-before-612-top.png)、[页尾](evidence/2026-10-25-page-boundaries/03-before-612-bottom.png)。页尾场景底边725px、卡片上边741px，白缝正好16px。
