## 1. 访问尺寸采集

采集运行在本站，同源上报、独立 SQLite 聚合、管理页查看。只收页面类别、CSS 布局／可见视口、DPR 档、方向、归一浏览器及粗设备类别、服务端粗身份组与构建版本。统计库没有学号、姓名、班级、成绩、原始 UA、IP、完整 URL 或永久访客标识。请求经过既有会话和服务器日志，不能把“统计库不留身份”扩大为请求绝对匿名。

### 启用与停用

详细操作见[运行说明](../../../deploy/login/README.md#访问尺寸统计)。启用需在目标服务同时配置 `LESSON_VIEWPORT_METRICS_ENABLED=1` 与可追溯的 `LESSON_BUILD_VERSION`，重启该服务。版本限 1–80 个字母、数字、下划线、点或连字符，推荐实际提交号。生产禁止本机放行变量；本机专用验收另加 `LESSON_VIEWPORT_METRICS_ALLOW_LOCAL=1`。

删除启用变量或设为非 `1` 后重启，服务不再注入采集脚本；旧页面下一次上报收到禁用信号后清理监听。已有聚合库不会随停用被删除。统计库不包含在现有学习账本备份命令中；如需留存应单独使用 SQLite 一致性备份，不能复制运行中的单个数据库文件冒充完整备份。

### 95% 与验证证据

当前没有真实生产样本，覆盖率为待统计／待验证；固定 63 个尺寸不能证明真实 95%。总体、手机、平板、电脑的首页样本分别报告。平台无法可靠判断时保留 unknown，例如桌面式 iPad／Mac UA；不据宽度补猜。

管理员导出的是 `needs-verification` 候选，不会自动承诺通过。实际复验后，运维可在私有数据目录维护 `viewport-validation.json`：

```json
{
  "version": 1,
  "status": "passed",
  "validatedAt": "实际验证完成的 ISO 时间",
  "contexts": ["仅放实际验证通过的完整 context 对象"]
}
```

上例是结构说明，字符串占位不是可运行证据。每个 context 必须具有 `pageKind,audience,buildVersion,browserFamily,engineHint,platformGroup,reason,layoutWidth,layoutHeight,clientWidth,visualWidth,visualHeight,visualScale,dprBucket,orientation`。从候选项取 `context`，只纳入真正通过的项，保留对应截图、操作结果和浏览器版本的外部验收记录。精确匹配全部字段，不能拿相同内核、相近宽度或过期构建替代；unknown／unversioned 不计分子。

证据时间不能在未来，有效期 30 天。证据缺失、格式错误或过期均显示待验证，不静默算成 0% 或 95%。首页首次／布局变化用于主指标，可见区域变化另算；所有已收到但未知／未测环境保留分母，未收到的访问不在样本内。当前接口提供首次、可见变化与设备子项，界面重点显示主指标及设备子项。

尚未实现自动执行候选矩阵并签发证据的流水线，也没有统计置信度或最小样本量门槛；小样本只能参考。生产负载、实体设备、微信、真实软键盘和采集遗漏偏差需要后续真实观察。服务端去重有效期与轮询清理的物理时间区别已写入方案。
