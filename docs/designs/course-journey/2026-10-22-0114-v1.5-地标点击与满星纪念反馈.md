## 交互与视觉

| 用户操作或成果 | 页面反馈 |
| --- | --- |
| 按下人物、道具所在的场景 | 整组以脚底为支点压到 97%，约 80ms；人物、道具共同运动，文字保持稳定。 |
| 松开并点击场景或课程标签 | 选中对应课程，深绿标签和底部／侧边课程区同步；380ms 内回弹到 103.5%，轻收至 99.5%，最后归位。仍由“继续学习／进入课程”进入课程。 |
| 连续点击同一场景 | 取消上次回弹并重新响应，不能堆叠动画或累计放大。 |
| 手指纵向拖动 | 保持页面滚动；移动超过 10px 或浏览器取消指针时撤销按压，不触发选课。保留双指缩放。 |
| 获得一至四星 | 只点亮真实已获星，沿用纪念卡星图、柔光和错峰闪光。 |
| 新集齐满星 | 人物轮廓内扫过一次暖金高光，最后一颗星轻抬，星花金章短促弹入；整个过程约 1 秒。 |
| 满星静止状态 | 保留星星亮光和一枚固定金章。取消背景呼吸光圈、旋转环及人物的持续金色滤镜。 |
| 点击满星金章 | 选中该课并重看一次纪念动画；不会重新发奖、改分或改日期。 |

当前样板使用完整人物组回弹，没有声称人物已经能独立挥手、摇伞或转头。若要增加独立动作，需另拆肢体／道具层并验收，不能把整张静态图左右摆动称作角色表演。

## 布局与可访问性

人物点击层与原生画板使用相同等比尺寸、脚底锚点；活动范围延伸至脚下近处，不扩大到相邻地标。标签和金章保持更高点击层级。金章放在星数左侧，手机点击区 44px、桌面 48px，不侵入 Lesson 和课名；可见金章比点击区小。桌面、平板和手机仍使用原响应式构图，不重写已冻结的位置表。

人物是可用 Enter／Space 操作的真实按钮，有独立的课程名称和选中状态。动效以脚底为支点，不晃动整张地图或课名。减少动态时撤销正在执行的回弹、扫光和星星循环，保留静态金章、真实星数和当前课程标记；重新允许动态时不补播旧动作。装饰金章加载失败时显示“满星”文字标识，课程与纪念动画入口仍可用。

## 成果数据边界

星数、最大星数、授权和首次满星日期继续使用账号服务。点击场景、标签、金章都不写入成绩或纪念卡。

浏览器只保存每名学生已经看过的完成提示，用于区分“上次尚未满星，这次已满星”。首次访问、历史已满星和新授权的历史满星均安静展示，不自动播放。普通刷新不重复庆祝；课程真正从未满星变为满星才自动播放一次。此提示记录不是成绩来源，不跨浏览器同步；换设备首次访问只展示已有金章。禁止用它反推成绩，存储被禁用时也不能影响上课。

## 素材与固定输入

新金章由内置 imagegen 参考现有品牌星花、首课人物和认可地图生成，保持相同画风。完整提示词、参考顺序、透明开关、实际输出与哈希见[固定包](production/game-feedback-v1/README.md)。人物、背景及纪念卡没有重画，原两个固定包继续校验。

## 验证记录

最初回归已复现点击 Lesson 3–4 人物后仍停留在 Lesson 1–2；接入人物点击后该检查通过。首轮连续点击发现按压 CSS 过渡和释放回弹同时运行；只限定过渡阶段能通过 Chromium，但 WebKit 仍暴露重叠。最终按下和释放都使用同一个可取消动画引用，移除该层 CSS 过渡，保留“不叠加”的原断言。

最终执行范围与截图在[设计验收](../../../design-qa.md)记录。专项覆盖真实零星→一星→五星、一次自动庆祝、主动重看、刷新、减少动态、星数和首次日期保持；新触摸专项覆盖三课点击、重复点击、键盘及滚动取消，Chromium 还执行原生触摸事件形成的页面滚动。实体手机、微信和完整发布验收未执行。未提交、未推送、未发布。
