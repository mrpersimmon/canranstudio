## 实施原则与采用的参考

学习记录首先是“在什么题目和支持条件下做过什么”的事实。题库变化不能追溯修改历史判分，词块组句也不能变成自主表达成绩。输入中的字符属于小草稿，完成和评分属于课程记录，二者采用不同写入频率。离线可用必须实际经过重开页面验证，缓存一次音频不能代替这一验证。

沿用 [Duolingo 深色课内截图](../../references/duolingo/2026-09-06/lesson-dark/README.md) 中的自由输入、部分翻译、检查与继续布局；地图与课内仍用同一深色主题。新语法题采用已有输入表面与固定操作区。原课文、真实音频结束、手动继续、结算后回到路线的约束继续保留。

## 记录与版本约定

- `recordSchema` 保持 4；`contractVersion` 为 2，`answerPolicyVersion` 为 2，跳级抽题 `version` 为 2，课程发布修订为 `lesson1-144-v6.1`。它们分别表达结构、证据定义、答案规则、抽题规则和课程发布。
- 存储键和学习者身份保持不变。v1 历史定义取自 `33a82bb`，不得为迎合新内容重写；以后改变评分契约，应新增版本并保留已发布版本的定义。
- 历史题序固定；已回答项使用其历史答案规则，旧测试的新回答使用新规则。不会追溯把旧错题改为答对，也不会扣回历史路线进度。
- 历史节点完成与当前活动全部完成分别判断。联调中曾发现旧通关标记会把新增输入题误当成只读重练，现已通过实际补做回归修正：重新进入只补齐未完成的新活动，之后再进入才是普通重练。
- `:recovery:migration` 保存首次迁移前原始封套；`:recovery:backup` 保存最近一个可用封套；`:recovery:quarantine` 保存最近一次显式恢复所替换的原始内容。它们是有界的本地恢复机制，不是云备份或无限历史。
- `:draft` 仅保存当前输入身份、主记录修订号和短文本。每个输入事件同步验证写入；主记录修订或题目身份不同的草稿不恢复到别的题目。完整记录提交仍检查修订并读回验证。
- 恢复先比较最初展示的原始字节，再隔离、写入和读回；另一个标签页已经改变记录时拒绝覆盖。
- 回退上线版本时须保留本轮兼容读取和历史定义，不能直接部署不认识新任务的 `33a82bb`。本轮没有执行部署或线上回退。

## 教学边界

本轮新增主线题依次覆盖填写词形、改正双重词形标记、构造 Does 问句，以及用已知词汇表达新句。错误只有命中已编写的诊断模式才记具体误因，其余记为未分类，不对学习者做推测。

题面支持分别记录为句子框架、含错原句、待变换原句、指定句式或无额外框架。独立答对表示首次作答未另外使用帮助，不会把题目本身已经提供的原句抹成“完全无提示”。本轮六个输入句和三个延后句都与前 50 课已教原句不同；试点挑战已能按对应技能使用这组三类新句，其他挑战仍复习原题，不宣称全册都有新句迁移。

记录页把独立答对、借助帮助、新句独立答对和隔日独立答对分开显示。不能从一题的正确率声称已经掌握语法。跳级仍为 20 题，第 5 次错误结束测试；宽范围抽题加入已覆盖的三类试点技能，不增加额外否决阈值。

翻译仍使用 catalog 中经过审定的有限答案集合，不是通用自然语言语义判卷。前后册走同一扩充机制并保留语法负例。其余章节的语法能力链和更多等价说法需按覆盖表继续做教材与学生验证。

Lesson 133 的具体多解题面已修正；全册涉及 some/any、完成时与过去时、情态动词的语境敏感题，尚未逐题完成教师审核。本轮没有把这些题批量判为多答案，也没有声称已完成全册人工教学验收。

离线验证指完整启动页及已缓存内容可以重开；按需媒体尚未缓存的部分仍需联网。没有把几段缓存音频宣称为全册所有内容已离线下载。

## 性能与容量实测

同一台电脑的 Chromium、420×856、CPU 限速 4 倍。基线为保留结算改版的 `6872844`，修复版为本轮工作区。使用真实运行时完成的新记录（前三关）、半本和全本合成记录；两边都通过各自的存档校验，历史对照只逆转明确的新题和契约增量。每种情况测 9 轮。

| 合成记录 | 单次输入处理中位数，修复前 → 后 | 地图生成与强制布局中位数，修复前 → 后 |
| --- | ---: | ---: |
| 新记录 | 1.1 → 0.4 ms | 74.8 → 23.0 ms |
| 半本 | 15.2 → 0.4 ms | 111.5 → 40.2 ms |
| 全本 | 30.8 → 0.4 ms | 150.8 → 51.6 ms |

这是运行时输入处理和实际 DOM 布局的受控对照，包含真实 localStorage，不是手机实测或键盘到屏幕的端到端延迟。测试时还有课程检查并行运行，数值用于观察本次改动，不能当作硬件性能保证。另一个真实页面检查验证 23 个字符不改写完整进度，输入节点保持，刷新后草稿恢复。
