## 1. 一句话体验

孩子来到星光迎新厅，听布莱克先生介绍五位新同学，在人物、国籍和初见问候之间建立关系；随后走到汽车展台，把 `He / She / It` 与肯定陈述迁移到六辆汽车、品牌和国家属性。

## 3. 儿童文案与公平性

- 顶部标题只说明当前故事动作，不在题目里出现可点击正确标签。
- 理解题在完整对话结束前不可操作；候选人答前不显示国籍标签。
- S08 的车辆图片答前不显示品牌名；答对后才揭晓英文并播放。
- 错误第一次只重播最相关声音；第二次给关系提示，不变暗其他候选、不指出正确位置。
- 正确后原场景短反馈，目标英语直接播放；不插入“答对了”、爱心、知识卡或确认页。

## 4. 直接意图与页面节奏

1. 全部主要行为是一次点击或触摸；不使用拖拽，不要求先选来源再选目标。
2. `prompt-album`、`sequence-choice` 的内部多轮都留在同一阶段、同一页面。
3. 音频重播与对应英文同屏；播放中禁止叠播，重播不改变进度。
4. 角色练习中的孩子台词先隐藏，点击后揭晓并播放；页面不伪装语音识别或口语评分。
5. 自动进入下一内部轮次；阶段之间由状态机继续，不出现冗余过场页。

## 5. 完成与恢复

单元完成必须同时满足：10 个阶段全部完成；D01–D20、P01–P06 和必需词音均真实接触；角色练习覆盖两个角色；所有需要推进的音频都来自当前 `requestId` 的真实 `ended`。刷新使用键 `poc:learning-experience:NCE-U03:lesson5-6-v1` 回到当前阶段安全起点，不恢复半段音频或动画中间态。

完成页只显示两个同宽动作：`重新体验` 与 `继续`。本地候选中的继续仅返回课程入口，不暗示已经发布。
