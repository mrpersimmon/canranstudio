## 1. 验收结论如何成立

Lesson 1–2 是六至八岁儿童独立学习课程的首个黄金母版。实现只有同时满足以下五项才可以提交体验验收：

**一句话故事：**孩子与探险小猫先在星灯失物招领站帮助一只手提包找到主人，再整理并归还随身物品、衣物和钥匙三批失物，亲手让小站开张。

**相对母版的真实例外：**不适用；Lesson 1–2 本身定义第一版课程生产母版。

1. 教材来源无缺口，产品原创内容与教材来源身份不混淆；
2. 十二个微任务按声明式合同运行，并在各自边界原子保存和恢复；
3. 每个学习结果与孩子实际完成的目标、通道和支架层级一致；
4. 所有必需语言音频由当前活动请求的真实 `ended` 门禁，故障不伪造声音接触；
5. 手机竖屏儿童体验能让六至八岁孩子看懂、点准、愿意继续，并只在完整章节或完整教学单元后呈现对应成长。

页面截图相似、动画播放完毕、最终选项正确或全部自动测试通过，都不能单独替代这五项的联合验收。

## 2. 教材来源与内容身份合同

### 2.1 必须建立的来源清单

Catalog 必须从受控教材转录生成可审计来源清单，并至少覆盖以下集合：

| 教材位置 | 必需来源事实 | 验收规则 |
|---|---|---|
| Lesson 1 对话 | 七个按说话者和顺序区分的话轮 | 第三、第五话轮即使文字相同也必须是两个 Source ID；重播时复用原 ID |
| Lesson 1 词汇表 | 十一个词或短语条目 | 每项都有声音、词形与真实语境接触；只有与 T1–T5 对齐的内容承担主动检索 |
| Lesson 1 Notes | `L01-N01`、`L01-N02` | 角色为 `support`；通过交际行动获得 `semantic-enactment` 接触，不进入掌握证据 |
| Lesson 1 理解问题 | 一个完整问题来源 | 角色为 `context`；不把题内 `Whose` 拆成目标词或独立题 |
| Lesson 1 中文译文 | 与对应英文来源逐项关联 | 角色为 `context`；默认收起，查看不出题、不形成掌握 |
| Lesson 2 替换操练 | pen、pencil、book、watch、coat、dress、skirt、shirt、car、house 十项教材来源 | 每项进入 T1 的声音和词形两个独立通道格 |
| Lesson 2 抄写区 | 复用 Lesson 1 七个对话 Source ID | 不重复创建教材来源；练习机制记为 `L02-E01` 并标为有记录省略 |

Catalog 校验必须拒绝重复 Source ID、悬空引用、缺失角色、缺失必需接触和把产品变化表达冒充教材原句。教材原文的正式字符串只在 catalog 保留一份；本验收包记录集合与关系，不成为页面脚本的内容副本。

### 2.2 三类稳定标识不得互换

| 标识 | 表达什么 | 不能表达什么 |
|---|---|---|
| Source ID | 教材中的真实来源项 | 产品提示、原创情节、恢复位置 |
| Content ID | 产品原创提示、任务情境、变化表达、支架、答案规则和音频引用 | 伪造教材页上的新话轮 |
| Microtask ID | 任务、原子保存与恢复边界 | 教材身份或产品文案身份 |

所有产品变化问句，例如由问句结构与物品词生成的 `Is this your watch?`，必须使用稳定 Content ID 并引用相应 Source ID。页面不得运行时拼接英文。

### 2.3 内容安全回归

- 本单元不得借入超出教材范围的词汇来增加难度。
- 不使用成人语法术语、脱离情境的翻译辨析、荒谬送分项或语言陷阱。
- 全局回归仍须保护既有 Lesson 49 语义红线：`husband` 只可作为课文词汇和内部语义保护，不得出现“人物还是肉类”的儿童分类题。
- Lesson 1–2 不要求纸笔抄写、键盘输入、拼写、麦克风录音或发音评分。

## 3. 学习目标与首次检索覆盖

### 3.1 五个核心目标

| 目标 | 当日首次学习必须证明什么 | 长期掌握仍需什么 |
|---|---|---|
| T1 物品听辨与认读 | 十一项物品各自完成一次听音找物品和一次看词找物品 | 每个“词 × 通道”在至少两个学习日和变化情境中取得延迟无支架成功 |
| T2 礼貌引起注意 | 在人物尚未注意时主动选择或组织 `Excuse me.` | 两个变化人物或场景中的无支架调用 |
| T3 请求重复 | 在角色真实没听清时选择 `Pardon?` 并触发重说 | 两个变化听辨情境中的无支架修复选择 |
| T4 询问并确认归属 | 理解肯定归属，并用完整表达或大号语言块完成归属交流 | 两个变化物品与人物中的无支架归属交流 |
| T5 礼貌致谢 | 在孩子真实收到物品后调用 `Thank you very much.` | 两个变化归还结果中的无支架调用 |

同日形成性成功、受支持完成和伙伴救援都可以推进故事，但都不等于长期掌握。五个目标全部满足跨日、跨情境、无支架条件后，地标才能最终亮灯落成。

### 3.2 T1 的二十二个通道格

| 物品组 | 听声音找物品 | 看词形找物品 |
|---|---|---|
| handbag | `L01-M01` | `L02-M02` |
| pen、pencil、book、watch | `L02-M01` | `L02-M02` |
| coat、dress、skirt、shirt | `L02-M03` | `L02-M04` |
| car、house | `L02-M05` | `L02-M06` |

二十二个通道格是一个聚合目标下的二十二份变体状态，不是二十二个地标或二十二套奖励。反馈时看到词形或听到词音只算接触，不能复制成另一通道的结果。

## 5. 声明式答案与儿童动作合同

### 5.1 判定类型

运行时至少要能解释以下语义动作；具体数据结构可以深化，但不能退化为页面条件分支：

| 判定语义 | 示例 | 正确性依据 |
|---|---|---|
| `select-one` | 从完整表达牌中选交际意图 | 提交的稳定表达 ID 等于当前目标声明的答案 ID |
| `match-entity` | 听词音或看词形后找物品 | 目标词汇 ID 与物品语义 ID 的 catalog 关系 |
| `place-in-slot` | 把 watch 放入单名词槽 | 稳定标签 ID、槽位角色与当前案件 ID 的关系 |
| `ordered-blocks` | 组成 car/house 两块问句 | 孩子主动提交的稳定块关系与当前案件分支一致 |
| `perform-action` | 把物品交给人物、盖章、开闸 | 必需实体、目标角色和动作类型的声明关系 |
| `all-of` | M07 原子完成条件 | 所有必需账本事实存在且写后读回一致 |

严禁用选项位置、颜色、坐标、数组下标、DOM 顺序、字符串拼接、拖动路径或动画结束事件判断课程答案。

### 5.2 操作与学习结果分离

- 手机主路径为“先点对象，再点目标”；宽容拖动只是可选拟物乐趣。
- 点听与正式提交必须是两个清楚分开的动作。点听不提交、不扣心、不产生目标结果。
- 放到不匹配的物理槽位属于操作帮助，不是语言错误；系统应提示槽形或停靠到候选区，不扣心。
- 误触空白、重复点已选对象、页面失焦、音频失败和系统故障都不能消耗冒险心。
- 只有当前目标的正式语义提交才可以创建尝试；干扰表达的显示、点听或误选不能顺带改判另一个目标。

## 6. 纠错、支架与证据合同

### 6.1 三种当日结果

| 结果 | 何时记录 | 儿童端结果 | 后续含义 |
|---|---|---|---|
| 无提示形成性成功 | 第一次正式提交正确，且未接触会泄露答案的同任务支架 | 完整、积极的故事结果 | 仍不是跨日独立掌握 |
| 受支持完成 | 首次错误后的情境后果、排除、对照、近距预提示或其他支架后完成 | 与无提示成功相同的完整故事结果 | 提高对应目标或通道的回访优先级 |
| 伙伴救援 | 看过伙伴完整示范后，由孩子亲手完成变化动作 | 与前两者相同的完整故事结果 | 更高优先级回访，不倒退主线 |

两选一第一次答错已经提供排除信息，之后答对必须记为受支持，不能只保存最终正确项。若前一目标的支架提前暴露后一目标的答案用途，后一目标即使第一次正式提交正确，也必须带跨目标近距预提示标记。

### 6.2 支架必须匹配错误类型

| 错误类型 | 第一层 | 第二层 | 第三层 |
|---|---|---|---|
| 听音找物品 | 所选物品产生自身语义后果并归位，重播目标词音 | 只开放目标与最易混淆项，用无文字动作突出区别 | 在不同外观同类物上示范，再回原完整集合近迁移 |
| 看词找物品 | 并排完整目标词与误选词 | 聚焦声明的辨识片段或整体轮廓 | 在不同外观同类物上示范，再回原集合完成 |
| 交际意图 | 让实际选中表达产生可理解后果 | 无讲义地对照正确使用时机 | 变化人物完整示范，再由孩子近迁移 |
| 语言块关系 | 完整播放孩子实际组成的合法问句并显示情境不匹配 | 用物品、案件与槽位关系线提示 | 用另一物品完整示范，再回当前案件完成 |

纠错不得使用红叉、错误蜂鸣、羞辱文案、`No`、语法讲义、中文直接报答案或无限重复猜测。每个新目标或目标变体静默恢复三颗心；不播放大型补心动画。

## 7. 音频清单、生命周期与发布门禁

### 7.1 语音包清单

每条完整教材话轮、产品完整变化表达和独立词音都必须拥有单独音频文件，不得把单词片段拼接成长句。Manifest 至少包含：

- Source ID 或 Content ID；
- 单元、角色、声线角色与美式英语要求；
- 文件地址、格式、时长、哈希与版本；
- 生成模型和 voice 或真人录音授权；
- 课程编辑审核、通用美式英语审核和技术审核状态。

一个教学单元是最小替换范围，任一发布版本只启用一个完整语音包。真人老师录音可以在通过相同零缺口验收后整单元替换 AI 包；儿童端不提供 AI/真人或声线选择。

### 7.2 活动请求与 `ended`

- 任一时刻只有一个活动语言音频请求。
- 只有当前活动请求发出的真实 `ended` 才能推进对应门禁和登记声音接触。
- 翻页、重播、切任务、页面隐藏或新请求会使旧请求失效；旧请求迟到的 `ended` 必须被忽略。
- 预计时长、超时、动画结束、选择完成和音频元素缓存状态都不能伪造 `ended`。
- 自由重听可以增加真实接触，但不生成目标尝试、完成、独立证据或口语成绩。

### 7.3 故障降级

语言音频先进行有限次自动重试。仍失败时必须保留文字、人物动作和手动继续入口；本次声音接触标记为缺失，不扣心、不记录听音成功，并优先安排音频可用的短回访。显式降级可以保存已完成的非声音结果，但不能把超时写成 `ended`。背景音乐失败直接进入无音乐状态，不影响学习证据。

### 7.4 发布前零缺口门禁

发布候选必须同时满足：

1. 必需 Source ID、Content ID、角色和文件 100% 对应；
2. 课程编辑逐条核对文字、交际位置和角色；
3. 熟悉通用美式英语的审核者逐条核对发音、重音、连读、节奏和低龄适宜性；
4. 系统逐文件检查格式、哈希、时长、削波、噪声、响度、首尾静音和完整 `ended`；
5. 已知文字错误、发音错误、明显合成异常和缺失文件均为零。

最终供应商、声线、响度与首尾静音阈值须在首批真实候选生成后盲听和同一手机环境校准。这些是制作参数，不重开课程设计。儿童偏好测试只在成人语言审核合格的匿名候选之间进行，不录制儿童声音或写入学习证据。

### 7.5 背景音乐控制

儿童端右上角持续提供不小于 48×48 CSS px 的一键背景音乐开关，并在本设备保持偏好。关闭音乐只停止背景音乐，不得关闭英文台词、词音、重播或必要学习反馈。语言播放时背景音乐必须明显压低，关键辨音不与音乐竞争。

## 8. Catalog、运行时与页面责任边界

| 层 | 必须拥有 | 明确禁止 |
|---|---|---|
| Catalog | 教材来源、产品内容、目标、选项、稳定答案、支架、音频顺序、必做动作、原子条件与场景文案 | 把持久化或 DOM 状态当课程事实 |
| 运行时 | 当前微任务、活动音频请求、尝试与支架轨迹、接触、结果、原子保存、恢复、回访和地标状态机 | 根据页面字符串猜答案；用超时伪造学习接触 |
| 页面 | 按状态渲染、提供无障碍名称、转发声明式动作、播放视觉与音频表现 | 复制或改写课程英文、拼接问句、决定答案、支架、音频顺序、完成或地标增长 |
| 测试 | 验证 catalog 完整性、运行时合同、页面薄层、可访问性和真实浏览器流程 | 只比较截图或只覆盖快乐路径 |

页面脚本中的课程专属英文字符串数量必须为零。`继续`、`重播`、`音乐已关闭` 等课程无关文字来自运行时共享词典；课程专属中文提示和故事文案来自 Content ID。

## 9. 儿童视觉与可用性验收

### 9.1 必须呈现的视觉方向

- 手机竖屏优先的手绘 2.5D 微缩故事剧场；深夜蓝、奶油纸、暖琥珀光与胡桃木、黄铜、布料、纸张、磨砂玻璃材质统一。
- 任务状态成为案件册、标签柜、货架、衣架、钥匙柜、认领单和黄铜槽位，不使用一组漂浮的通用白卡。
- 人物表情和全身动作清楚，物品精致且可辨，car/house 钥匙不只靠颜色区分。
- 所有关键触控区不小于 48×48 CSS px；选中、禁用、当前、错误和可继续状态不只靠颜色表达。
- 英文在手机竖屏清楚可读；减少动态效果、非精确触控和音频不可用都不能形成死路。

### 9.2 动效层级

| 层级 | 时长与用途 | 不能承担什么 |
|---|---|---|
| 场景生命感 | 非阻塞的呼吸、灯影、纸签轻动 | 答案、保存或催促 |
| 操作反馈 | 约 250–700 毫秒的抽屉、吸附、槽位和印章反馈 | 课程结算 |
| 里程碑演出 | 约 1500–3000 毫秒的案件归档、单元建设和最终亮灯 | 替代原子写入或重复发奖 |

普通答对不播放全屏庆祝和彩屑。阻塞性演出允许跳过；减少动态效果保留最终状态，只缩短位移、视差和循环。

### 9.3 八个视觉验收锚点

可玩原型至少要覆盖并截图/录屏以下状态：

1. Lesson 1 七句英文课文完整可见、当前话轮随原声突出且不可提前作答的状态；
2. 手提包物主判断和 `handbag` 听辨；
3. 两张完整表达牌的点听/提交分区与人物情境后果；
4. Lesson 1 结案章、工作灯、故事册、继续与休息停靠点；
5. 随身物品整理台与五项旧案件标签柜；
6. 会动的衣柜、衣签登记册和孩子接回外套；
7. car/house 造型钥匙、微缩影像与两块问句轨；
8. 三案合闸、开张拉杆、当日建设地标和成果庭院。

### 9.4 目标年龄儿童验收

在监护与适龄测试条件下，观察六至八岁孩子能否独立开始、理解当前要做什么、区分点听与提交、用点按主路径完成、在错误后继续、从中断点恢复，并愿意进入下一微任务。测试不录制儿童声音，不把成人解释后的完成算作独立可用，也不以“孩子最终点过去了”替代对误触、停顿和求助的观察。

## 10. 成长、完成与回访边界

| 时点 | 可以增长什么 | 不可以声称什么 |
|---|---|---|
| 单个微任务完成 | 场景内的案件线索或整理足迹 | 地图地标增长、长期掌握 |
| `L01-M05` 完成 | 室内结案章、工作灯和第二间整理室 | 地图建筑增长、单元完成 |
| `L02-M07` 原子保存成功 | 雨篷、图形招牌、认领窗口和可见货架的当日建设 | 全部掌握、屋顶星灯最终亮起 |
| T1–T5 全部跨日掌握 | 屋顶星灯、金色铭牌和整栋暖光 | 同日题目正确即可触发 |

受支持完成和伙伴救援获得与无提示成功同样完整的当日故事与建筑，差异只进入内部证据和回访优先级。回访按真实目标状态自适应安排，不使用所有孩子统一的固定“艾宾浩斯日期表”；同日见过答案后的重玩不能制造独立证据。

## 11. TDD 实施顺序

以下步骤只在获得单独实现授权后执行，每一步先写失败测试，再做最小实现并重构：

1. **Catalog 红灯**：来源清单、Content ID、二十二个通道格、十二个微任务、答案/支架/音频/原子条件完整性测试先失败；补齐 catalog 后转绿。
2. **学习账本红灯**：尝试分类、跨目标预提示、接触与结果分离、同日不掌握、M07 原子集合和幂等读回测试先失败；实现状态模型后转绿。
3. **音频生命周期红灯**：活动请求、迟到 `ended`、取消、重播、故障降级和背景音乐隔离测试先失败；实现统一音频门禁后转绿。
4. **逐微任务恢复红灯**：为十二个微任务逐一覆盖任务内刷新、保存后刷新和下一锚点恢复；实现通用微任务恢复接口后转绿。
5. **声明式动作红灯**：覆盖所有判定类型、点听/提交分离、非精确操作和页面零课程字符串；实现薄页面适配后转绿。
6. **真实浏览器流程红灯**：覆盖快乐路径、每类纠错、音频失败、M07 写入失败/重试、减少动态效果和背景音乐偏好；最后完成视觉表现。

不得先把十二个微任务硬编码到页面，再补 catalog 或测试。任一为通过测试而复制课程内容的补丁都不接受。

## 12. 自动验收矩阵

### 12.1 单元测试

- [ ] Catalog 中所有必需 Source ID 唯一、角色正确、引用闭合、教材省略有记录。
- [ ] 所有 Content ID、音频引用、声明式答案、支架和原子条件可达且无悬空。
- [ ] T1 十一项 × 两通道完整，结果不互相复制。
- [ ] T2–T5 的干扰项不会生成或覆盖其他目标结果。
- [ ] 首错后正确为受支持，伙伴示范后为伙伴救援，跨目标近距预提示可追踪。
- [ ] 十二个微任务内部不持久化半成品，完成时结果与任务一次写入。
- [ ] 活动音频请求之外的迟到 `ended`、超时和动画事件不能推进。
- [ ] M07 只有在前置账本完整、写入及读回成功后声明单元完成。
- [ ] 页面课程专属英文字符串为零；产品变化表达不伪造教材 Source ID。
- [ ] `husband` 不进入任何儿童食物/肉类分类任务，内部语义校验仍保留。

### 12.2 E2E

- [ ] 两个章节快乐路径完整可玩，十二个微任务顺序和场景继续锚点正确。
- [ ] 每一类支架至少一条真实浏览器路径，儿童端没有负面惩罚表现。
- [ ] 在每个微任务的中间和保存后刷新，恢复行为与第 4 节一致。
- [ ] 点听不提交、拖动不是门槛、误放物理槽不扣心。
- [ ] 音频加载失败有显式出口，不伪造声音接触或死锁。
- [ ] 背景音乐开关一键生效、跨场景保持，且不静音课程语音。
- [ ] 孩子可从设置中请求重新开始本单元；取消不改变进度，经二次确认后只清除课程进度，保留背景音乐等独立设备偏好。
- [ ] 隐藏本地 POC 的阶段导航可以打开全部十二个微任务；所有跳转和预览操作使用隔离会话，不写学习进度、证据、地标或回访，退出后返回原稳定恢复点。
- [ ] 减少动态效果保留所有最终状态和可操作性。
- [ ] Lesson 1 完成不增长地图；Lesson 2 完整保存后只增长当日建设。
- [ ] 完成后进入成果庭院，不出现白色成绩单、正确率或“全部掌握”。
- [ ] 真实到期回访由信箱在后续会话呈现；同日自由参观不制造独立证据。

### 12.3 仓库门禁

获得实现授权并完成代码后，交付证据必须来自同一提交：

```bash
npm run test:unit
npm run test:e2e
npm run test:deploy
npm run build:static
npm run verify:v1:release
```

同时提供手机竖屏本地儿童体验页和八个视觉验收锚点。测试报告必须明确提交 SHA、命令、退出状态和未覆盖项；不能用旧提交、部分命令或“本地看起来正常”替代。

## 13. 退出条件与剩余制作校准

### 13.1 实施可以进入儿童验收的条件

- 第 12 节全部自动门禁通过；
- 十二个微任务及故障/恢复路径在本地儿童体验页可玩；
- 八个视觉锚点完成手机竖屏和减少动态效果检查；
- 正式候选语音包通过课程、美式英语和技术零缺口门禁；
- 文档、catalog、运行时和页面对同一 Source ID、Content ID、Microtask ID 与提交 SHA 一致。

### 13.2 不重开课程设计的制作校准

以下事项必须用真实候选或可玩原型完成，但不再向产品负责人发起逐项课程访谈：

- 最终 TTS 供应商、声线与真人替换候选；
- 响度、首尾静音、噪声和文件格式的量化阈值；
- 具体插画资产、动作曲线和既定时长范围内的动画节奏；
- 目标年龄儿童对提示、触控、可读性和继续意愿的观察改进。

只有这些校准暴露了真实课程例外，例如年龄难度、学习目标、证据语义、儿童数据、全局画风或奖励边界需要改变，才重新请求产品决定。普通制作修正由团队依据本验收包完成。

### 13.3 发布边界

课程设计接受、运行时实现完成、合并 `main` 和发布网站是四个不同授权。即使本验收包全部通过，也必须等待产品负责人明确允许后才能合并或发布。
