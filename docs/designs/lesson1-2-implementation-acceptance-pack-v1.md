## 1. 当前本地实现的验收边界

以下清单保留十五微任务 V0 当时的内部验收合同；它现在只用于解释历史差距，不再提供产品晋级路径，即使全部满足也不能把 V0 重新标成当前候选：

1. 教材来源无缺口，教材 Source ID 与产品 Content ID 不混淆；
2. 十五个微任务全部由 catalog 声明，并按各自边界原子保存和恢复；被移除的 `L01-M04` 旧存档必须恢复到 `L01-M05`；
3. 十一词全面接触、八份当天抽样、三项显性语法任务和五个核心目标的结果与真实行为一致；
4. 所有正式任务使用声明式答案、匹配纠错和全单元三颗冒险心；
5. 所有必需语言音频持续显示英文，并由当前活动请求的真实 `ended` 门禁；
6. Lesson 1 整章结束只形成室内成果，Lesson 2 全部完成后才增长地图当日地标；
7. 同一提交的单元、E2E、部署合同、静态构建和 V1 发布验证全部通过；
8. 成人在手机竖屏本地页完整游玩并接受课程难度、节奏、视觉、音频、纠错和成长。

这仍只叫“内部成人候选”。未在监护与适龄条件下观察六至八岁儿童前，不得写“儿童验收通过”“孩子可以独立学会”或同义结论。

## 2. Catalog 来源与内容身份合同

### 2.1 必需教材来源

| 教材位置 | 必需事实 | 验收规则 |
|---|---|---|
| Lesson 1 对话 | 七个按角色和顺序区分的话轮 | 第三、第五话轮文字相同仍使用不同 Source ID；重播复用原 ID |
| Lesson 1 词汇表 | 十一个词或短语 | 每项均有声音、词形、意义和真实情境接触；来源覆盖不等于逐项出题 |
| Lesson 1 Notes | `L01-N01`、`L01-N02` | 角色为 `support`；经交际行动获得 `semantic-enactment`，不单独计分 |
| Lesson 1 理解问题 | 一个完整问题来源 | 角色为 `context`；不把 `Whose` 拆成目标词 |
| Lesson 1 中文译文 | 与英文来源逐项关联 | 角色为 `context`；默认收起，查看不形成掌握 |
| Lesson 2 替换操练 | pen、pencil、book、watch、coat、dress、skirt、shirt、car、house | 每项进入 T1 的两个长期证据通道，但当天只写冻结抽样 |
| Lesson 2 抄写区 | 复用 Lesson 1 七个对话 Source ID | `L02-E01` 标为纸笔或平板手写可选拓展；不阻塞主线或取证 |

Catalog 校验必须拒绝重复 Source ID、悬空引用、缺失角色、缺失接触、页面内容副本和把产品变化问句冒充教材原句。

### 2.2 三类标识

| 标识 | 表达什么 | 禁止表达 |
|---|---|---|
| Source ID | 真实教材来源项 | 产品提示、原创情节、恢复点 |
| Content ID | 产品原创提示、变化表达、选项、答案、支架和音频引用 | 伪造教材正文 |
| Microtask ID | 任务、原子保存和恢复边界 | 教材身份、答案身份 |

Catalog 是课程唯一真源。教材英文、产品英语、课程专属中文、角色、选项、答案、支架、音频序列、故事动作和原子完成条件在页面脚本中的副本数量必须为零。

### 2.3 内容安全

- 不借入超出教材范围的生词制造难度。
- 必要语法术语只在意义建立后出现，不做背诵测试，不制作成人语法讲义。
- 不使用脱离情境的翻译辨析、荒谬送分项或语言陷阱。
- `husband` 只可作为课文词汇和内部语义保护，不得进入“人物还是肉类”的儿童分类题。
- 纸笔或平板手写只可作为不取证的可选拓展；手机键盘、拼写、麦克风、录音和发音评分都不是本单元完成门禁。

## 3. 十五个微任务原子合同

每个微任务三十至九十秒，最多两次正式语义提交。任务内不得持久化题目进度、音频秒数、动画帧、临时候选或半份结果；完成时把目标结果、接触、故事状态、当前冒险心和下一锚点一次写入。

## 4. 星灯语法实验室合同

`L02-M01`–`L02-M03` 是 Lesson 2 开头的三项语法学习，不增加第三个单元章节。

| 阶段 | 孩子要做什么 | 可以出现的术语 | 计分 |
|---|---|---|---|
| 比较 | 对比 `This is your handbag.` 与 `Is this your handbag?`，移动 `is`、观察问号 | `be` 动词、一般疑问句 | 自由尝试，不扣心 |
| 连接 | 把 `Yes, it is.` 中的 `it` 连回物品 | 肯定简短回答、代词 `it` | 自由尝试，不扣心 |
| 迁移 | 换物品组装问句，选回答并发现错误关系 | `your` 只解释为“你的” | 最多两次正式提交 |

验收不得把“会背术语”替代“会比较、连接、组装、选择和找错”。本单元不要求背“形容词性物主代词”，也不要求书面练习。

后续课程生产必须遵守累计式语法螺旋：首次遇见 → 显性规则 → 变化练习 → 对比分类 → 阶段整合。设计 Lesson 3–4 前，必须先有全册语法主干地图；每六个教学单元的城区结束安排累计整合。

## 5. 词汇覆盖与节奏合同

### 5.1 全面接触、八份当天检索

| 批次 | 当天 `audio-form-supported` | 当天 `word-form` | 只接触、以后回访 |
|---|---|---|---|
| handbag | handbag | — | handbag 词形通道 |
| pen、pencil、book、watch | watch | pencil | pen、book 与未考通道 |
| coat、dress、skirt、shirt | shirt、skirt | coat | dress 与未考通道 |
| car、house | house | car | 两词另一通道 |

当天恰好保存五份 `audio-form-supported` 和三份 `word-form`。十一词全部获得物品、声音、可见词形和情境接触，未抽中的格不是漏学。声音任务同步显示词形，不得宣称纯听力或复制 `word-form` 结果。

### 5.2 节奏与玩法

- 同一词当天不连续考两个通道。
- 最多连续两个单词正式挑战，之后必须回到语法、交际或故事行动。
- 一批物品只需一次有意义的打开/整理动作；顺序显示物品、英语与音频，不要求十个重复必点入口。
- 随身物品用旅行袋取放与整理，衣物用衣架和纺织标签；car 与 house 直接使用精致的小镇实景影像窗，不再借钥匙代指。
- 正确后视觉确认并自动播放英语，真实 `ended` 后推进；不出现额外喇叭门禁。
- 所有物品图由 catalog 提供高质量插画；独立物品使用透明抠图，car/house 使用完整场景图，材质、光影和尺度与小站一致，不使用 emoji。

## 6. 表达选项与声明式判定

### 6.1 候选数量

- 第一次学习一个交际功能：三个候选。
- 后续变化迁移或整段总结：四个候选。
- 所有候选必须已经出现、语义真实、可逐项免费点听，并对应不同误解；不得加入明显荒谬答案。

候选的独立扬声器是免费点听子控件；点卡片主体直接正式提交。免费点听不提交、不扣心、不生成目标结果。正确后由相应角色声线自动播放目标表达，真实 `ended` 后自动推进。

### 6.2 判定语义

运行时至少支持：

| 类型 | 用途 | 正确性依据 |
|---|---|---|
| `select-entity` | 点击手提包主人 | catalog 声明的实体关系 |
| `select-one` | 选择交际表达 | 稳定表达 ID 与当前意图关系 |
| `match-entity` | 听音或看词找物 | 词汇 ID 与物品 ID 关系 |
| `ordered-sequence` | 四图重建完整对话 | 稳定事件 ID 的因果顺序 |
| `ordered-blocks` | 组装归属问句 | 稳定块 ID、槽位角色和案件关系 |
| `connect-reference` | 把 `it` 连回物品 | 代词节点与当前实体关系 |
| `detect-error` | 找出错误句子关系 | catalog 声明的结构/语义约束 |
| `perform-action` | 交接、盖章、开张 | 实体、角色和动作关系 |
| `all-of` | 章节或单元原子门禁 | 全部必需账本事实与写后读回 |

严禁按选项位置、颜色、坐标、数组下标、DOM 顺序、字符串拼接、拖动路径或动画结束判断课程答案。

## 7. 纠错、证据与冒险心

### 7.1 结果必须诚实

| 结果 | 条件 | 儿童端 | 内部证据 |
|---|---|---|---|
| 无提示形成性成功 | 第一次正式提交正确且未接触泄露答案支架 | 完整积极故事结果 | 仍不是跨日掌握 |
| 受支持完成 | 出现情境后果或聚焦线索后由孩子完成 | 同样完整 | 提高对应回访优先级 |
| 伙伴救援 | 看过变化实例示范后由孩子完成 | 同样完整 | 保持伙伴救援，不可改写独立 |

两选一或三选一第一次答错已经提供排除信息，之后正确必须是受支持。补回冒险心不能清除支架轨迹。

### 7.2 三层纠错

| 错误类型 | 第一层 | 第二层 | 第三层 |
|---|---|---|---|
| 人物/表达 | 所选内容产生温和、可理解的角色后果 | 聚焦人物目的与表达用途 | 小猫在变化人物上示范 |
| 听音/词形找物 | 所选物品执行自身动作并归位 | 聚焦目标与最易混项的声音或视觉差异 | 小猫在变化同类物上示范 |
| 语法连接/组装 | 完整呈现孩子实际关系及不匹配后果 | 聚焦移动位置、指代或案件关系 | 小猫用变化物品完整示范 |

第三层后仍由孩子亲手完成。不得使用红叉、错误蜂鸣、羞辱、`No`、系统 Toast、中文报答案或无限猜测。

### 7.3 全单元冒险心

- 一个 Lesson 1–2 单元只有一个三颗冒险心池。
- 章节切换、休息、恢复和新微任务不重置；二次确认重新开始整个单元才重置。
- 只有正式语义提交改变心数：错误减一，孩子正确完成加一，上限三。
- 教学自由尝试、探索、免费点听、重播、误触、操作失败、页面失焦、音频和系统失败均不改变心数。
- 归零时先完成第三层变化示范，再播放一至两秒星光倒带，从当前微任务开头重来、补满三颗并重排候选。
- 归零后的微任务结果固定是伙伴救援，即使重启后第一次提交正确。
- 儿童端可画三枚星形，但无障碍名称和内部字段必须是“冒险心”；不得与挑战星、地标星灯或永久成绩混淆。
- 心数不阻塞章节或单元完成，不改变当日地标、长期掌握或最终故事。

## 8. 音频生命周期与发布门禁

### 8.1 角色与声色

Lesson 1 七个教材话轮的角色顺序必须是男、女、男、女、男、女、女；第七句 `Thank you very much.` 固定属于拿回手提包的女方。

全课程青年声色基准 `nce-youth-v1`：

- 默认青年男声：`am_michael`；
- 默认青年女声：`af_heart`；
- 独立词音：`af_heart`；
- 完整台词自然整句生成，不拼接单词；
- 独立词音使用 `context-cropped-lexeme-v1`，不得保留可听成奇怪前调的非语言起音；
- 已人工选择的 coat、dress、skirt、shirt C 文件继续以哈希作为验收锚点。

真人老师录音只能在同一教学单元全部文件通过相同来源、角色、美式英语、技术与授权门禁后整包替换；儿童端不提供 AI/真人或声线选择。

### 8.2 活动请求与 `ended`

- 任一时刻只有一个活动语言音频请求。
- 所有语言音频播放期间持续显示对应英文单词或句子。
- 只有当前活动请求的真实 `ended` 能登记声音接触、开放下一步或满足完成条件。
- 翻页、切任务、页面隐藏或新请求使旧请求失效；迟到 `ended` 必须忽略。
- 预计时长、超时、缓存、动画结束和选择完成都不能伪造 `ended`。
- 正确提交后目标英语是下一段可听内容，之前不得插入提示音、旋律或点击声。
- 音频失败先有限重试；仍失败时保留英文、动作和手动继续，不扣心、不记录声音成功。

当前主线不得创建背景音乐、循环环境音、连续低频或嗡嗡声。未来音乐需要新的明确产品决定与独立听感验收。

### 8.3 零缺口

发布候选必须同时满足：

1. 必需 Source ID、Content ID、角色、文件和哈希 100% 对应；
2. 课程编辑逐条核对文字、位置和角色；
3. 熟悉通用美式英语的审核者逐条核对发音、重音、连读、节奏和低龄适宜性；
4. 系统逐文件检查格式、时长、削波、噪声、响度、起音和完整 `ended`；
5. 已知文字错误、发音错误、明显合成异常和缺失文件为零。

独立词音在浏览器解码后 150 毫秒内出现英语起音；整理首尾空档不得裁掉起始辅音。AI 生成者不能只靠自己的自动检查证明语言质量合格。

## 9. 页面、视觉和可访问性验收

### 9.1 角色与场景

- 手机竖屏优先的手绘 2.5D 微缩故事剧场；深夜蓝、奶油纸、暖琥珀光、胡桃木、黄铜、布料、纸张和磨砂玻璃统一。
- 成年先生与成年女士沿用开场建立的统一形象；人物涉及当前情节时清楚可见，不退回 emoji、图标或人物缩略卡。
- 对话人物站在内容两侧，当前说话人提亮；学习者与向导始终是同一只探险小猫。
- 十一件教材物品使用 catalog 管理、与场景一致的插画；其中九件是透明物品资产，car/house 是完整小镇场景资产。
- 主提示是孩子能直接回答的情境问句或具体动作，不显示课程作者术语、内部状态或无意义操作。
- 关键触控区不小于 48×48 CSS px；点按是主路径，拖动仅为宽容替代。
- 选中、当前、错误和可继续状态不只靠颜色；减少动态效果与音频故障不能造成死路。

### 9.2 十二个视觉验收锚点

本地候选至少截图或录屏：

1. 无答案泄露的故事提要；
2. 两位成人持续在场、七句课文完整可见并随原声突出；
3. 只点主人、手提包不提前移动；
4. 三项表达候选及“扬声器免费点听 / 卡片主体提交”；
5. 四幅图重建完整对话；
6. Lesson 1 结案、故事册、继续与休息停靠点；
7. 语法实验室的陈述句/问句比较；
8. `it` 指代连接与变化物品组装；
9. 旅行袋四词接触及少量检索；
10. 衣柜、统一衣物插画与衣物主人在场；
11. car/house 小镇影像窗、真实场景选择与问句组装；
12. 三批案件自动呈现、一次开张动作与完整当日建设。

普通答对不播放全屏彩屑。里程碑演出可以跳过，减少动态效果保留最终状态；动效结束不能替代答案、音频或持久化。

## 10. 成长与完成边界

| 时点 | 可增长 | 禁止声称 |
|---|---|---|
| 单个微任务 | 场景线索或章节足迹 | 地图增长、长期掌握 |
| `L01-M06` | 室内案件章、工作灯、故事册和整理室 | 地图建筑增长、单元完成 |
| `L02-M10` 写入并读回 | 雨篷、招牌、窗口和设施的当日建设 | 全部掌握、永久三心成绩 |
| T1–T5 后续跨日掌握 | 屋顶星灯、金色铭牌和整栋暖光 | 用同日结果直接触发 |

受支持完成和伙伴救援得到完整故事与建筑，只在内部证据和回访优先级上不同。同日重玩不能制造跨日独立证据。

## 11. TDD 回归顺序

后续任何实现变更继续按以下顺序先写失败测试，再最小修复并回归：

1. **Catalog 红灯**：十五任务、来源覆盖、八份抽样、语法三任务、候选数量、答案、支架、音频和原子条件。
2. **语法红灯**：教学自由尝试不计分不改心；第三任务的组装、连接、找错与 T4 证据。
3. **冒险心红灯**：全单元持久、错减对补、零心示范/倒带/当前任务重启、支架证据不洗白。
4. **账本红灯**：接触/尝试/结果分离、十五任务原子保存、旧 M04 恢复迁移、章节停靠、M10 幂等写入与读回。
5. **音频红灯**：活动请求、取消、迟到 `ended`、自动反馈、可见英文、故障降级与无循环音轨。
6. **声明式动作红灯**：全部判定类型、选项子控件、页面零课程字符串与 catalog 唯一真源。
7. **逐任务恢复红灯**：十五任务逐一覆盖任务内刷新、保存后刷新、心数恢复和隔离预览。
8. **真实浏览器红灯**：快乐路径、每类纠错、零心恢复、减少动态、写入失败和十二个视觉锚点。

不得先把课程内容硬编码到页面再补 catalog 或测试。
