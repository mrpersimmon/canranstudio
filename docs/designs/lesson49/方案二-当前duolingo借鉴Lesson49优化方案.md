# 方案二：当前 codex/duolingo-version 借鉴 Lesson 49 的优化方案

2026-09-10 · 可评审提案，尚未实施。

以当前无键盘候选的组件、记录和复习能力承接 Lesson 49 的角色参与、语言对比与专项练习。先把 Lesson 49–50 做成完整样板，让孩子需要理解人物、作出判断、看到相应结果，并能把同一规则用于新的材料。

## 1. 当前基础与本方案新增内容

当前实施记录（`codex/duolingo-version@dee9a08:docs/designs/no-keyboard-learning/implementation.md`，位于新版分支） 标明：`lesson1-144-v7.0` 已完成本地实施与技术验收，尚未提交、推送或发布。本轮核对了记录及当前 catalog；没有重新执行该记录中的全部测试，也没有进行真实儿童试做。

| 当前已经具备 | 本方案怎样继续使用 |
| --- | --- |
| 单选、补句、排序、多选、音文配对、点词改错、分步情境任务 | 用已有操作编写本课的新情境和关键对比，控制新增交互组件数量 |
| 完整原文、真实音频结束、手动继续、重听与中文帮助 | 保持原文学习契约，课后角色任务使用已学材料 |
| likes/like、does 后原形、Does 问句的六道主线改造题 | 保留目标与有价值的检查，把人物、目的和迁移材料编写得更清楚 |
| 三道延后语法复习 | 保留，并为新增目标逐步补充对应复习 |
| 原有节点、路线、记录迁移与恢复 | 继续复用；保护旧完成、跳级和历史记录 |
| 支持条件与额外提示记录 | 继续准确报告点选条件下的表现 |

因此，“去掉键盘”“增加词块”“加入点词改错”不列为待开发的新功能。当前六道主线题已经改变了旧输入方式；接下来重点检查它们是否让孩子产生有意义的新判断。

## 2. 从 main 优先吸收什么

| 借鉴点 | main 给出的启发 | 当前新版应增加或重编的部分 | 优先级 |
| --- | --- | --- | --- |
| 角色扮演 | 孩子可以成为顾客或店员 | 完整学过原文后承担角色，按信息选物、接话；角色选择改变自己要完成的动作 | P1 |
| Do / Are 对比 | 把容易混淆的结构放在一起判断 | 成对展示身份／状态／地点与一般动词表达，再用新情境检查选哪种问句 | P1 |
| give 两种结构 | 让人与物的位置关系可见 | 识别人／物、预测变换、词块重排，再按句子交接；词序与语义分别检查 | P1 |
| either / too | 形成明确对比 | 给两个人的完整语境，先理解是否“也如此”，再选择句尾表达 | P1 |
| 多种主语判断 | 超出固定 he/she，处理人名、名词短语及并列主语 | 选择代表类型进行短分组练习，连接现有 likes、does 和 Does 检查；其他材料后续轮换 | P1 |
| 成长反馈 | 完成活动会改变小镇 | 先让任务本身产生可见结果，如商品装好、交到正确人物手中，再衔接现有结算 | P1，小镇大型扩展放 P2 |
| 独立知识活动 | 老师能清楚指出正在练哪个区别 | 建立逐项目标与教学、检查、错因、迁移、复习的对应关系 | P0 |

主干的扩展肉类词、五个锦囊、全部 21 个主语和四组变身不一次性塞入新版必修。先核准教材核心、必要复习和课程补充，再给每个保留目标安排位置；补充内容可进入选做与课堂材料。

新版原本已有完整课文，也已有 either、Are/Do 句子和 Give me… 原句。需要补足的是相应关系的教学活动与检查，不能把这些单词或句子“出现过”当成完整目标已经被考查。

## 3. Lesson 49–50 七个节点的建议编排

当前目录有 7 个节点、37 个顶层活动；活动数量与学习目标数量并不等同。保留现有节点身份作为初始方案，在节点内部重编活动。先列清被替换活动原来承担的目标，再决定删、改、增；不得因为题目形式相似而删除唯一的目标检查。

| 当前节点 | 建议的儿童任务与内容安排 | 关键边界 |
| --- | --- | --- |
| L49-STORY：替家人挑选食物 | 保留完整课文与理解检查，明确顾客要解决的问题；原文复演可在后续学习后进入 | 原文不能为缩短时长而删句；理解题对应真实信息来源 |
| L49-WORDS-1：词语与用法 1 | 认识肉铺商品与人物；沿用音文配对，再听一份简单需求选择商品 | 保留本组原有词汇目标，图片不能泄露本应由声音提供的答案 |
| L49-WORDS-2：词语与用法 2 | 认识 tell/truth/either 与相关食物；加入两个人的偏好回应，建立 either/too 对比 | 用语境帮助理解；补充 too 的形式规则和例句后才检查 |
| L49-WORDS-3：词语与用法 3 | 保留豆类、水果词；使用已经学过的货品和人物做交接，逐步学习 give 的两种结构 | 先示范、再词块操作；新增结构不会只靠“选对人物”判为完成 |
| L49-NUMBERS：用英语说顺序 | 保留 13–24 序数词及检查，可以作为独立的小任务 | 不为串联肉铺故事而删去 Lesson 50 范围或编造复杂情节 |
| L49-USE：把句子用起来 | Do/Are 对比，主语变化与现有三单、否定原形、Does 问句交替练习；完成一段顾客／店员回应 | 把连续示范拆成示范与尝试交替；提示逐步减少，正常听音一直可用 |
| L49-REVIEW：前五十课综合闯关 | 先用新需求完成肉铺任务，再做合理的跨课复习；新增目标纳入延后再练 | 保留原有跨课范围与有价值的迁移检查，课内与跨课表现有清楚依据 |

上表是目标分配草案，节点名称是否调整可在文案评审时决定。新增任务主要复用现有操作；以目标覆盖、实际屏数和儿童负担决定最终数量。若一个节点仍过长，再单独评审拆分与进度迁移，不能把完整课文裁短来满足预设时间。

保持现有“完成节点后回到路线，由孩子选择下一节点”的边界。角色练习不在结算后未经选择自动启动，当前节点进度也不冒充整条路线进度。

## 4. 一个可以直接细化成题稿的完整片段

场景：原文学习之后，孩子当肉铺店员，帮一个练习角色准备订单。角色的偏好与需求明确给出，使用已教的食物与句型；这个练习不改写 Mrs. Bird 原文。

| 步骤 | 孩子看到和完成的事 | 系统反馈 | 真正检查的目标 |
| --- | --- | --- | --- |
| 1. 听需求 | 顾客说想要牛排，孩子从已认识的货品中选择 | 答对把货品放入订单；答错保留订单并指出当前货品名称，允许重听 | 目标词听辨 |
| 2. 确认对象 | 依据已提供信息，为家人选择合适的货品 | 人物说明自己的喜好，突出与选择有关的信息 | 人物与偏好理解 |
| 3. 学习交接 | 看 Give me that piece.，标出人和物，再看同义变换 | 只突出词序和 to 的变化 | 关系理解与示范学习，不计独立掌握 |
| 4. 自己表达 | 撤去答案示范，用词块组织同义请求；换接收者再交接 | 错误时分别提示词序或接收者，不一次展示整套规则 | 受词库支持的结构组织、语义执行 |
| 5. 接上对话 | A 说不喜欢鸡肉；B 的偏好也是否定；孩子选择表示“我也不喜欢”的回应 | 解释两人偏好相同且是否定，连接 either | 否定附加意义及形式 |
| 6. 换人物再用 | 主语改成已学的名词短语或并列主语，完成喜好句或问句 | 根据漏掉 -s、重复标记、助动词等实际错因反馈 | 主语与句型的迁移 |

以上步骤用于展示教学衔接，不要求连续塞入同一节点。孩子学完对应词句后，在合适节点完成；已有练习能承担同样目标时直接改编它。

示范阶段可以突出人、物或词尾；检查阶段撤去直接指向答案的颜色与位置线索。选项中的错误形式对应已经教过的混淆点，不能靠新词、过长句子或荒谬答案人为制造难度。

角色回应可以采用确定性分支。首次版本使用现有单选、词块和分步任务即可；不把开放 AI 对话、自动口语评分或自由行走地图设为样板前置条件。

## 5. 保住关键考查点的编写规则

为每个保留目标填写一行对应表：来源及先修、学习示例、带帮助练习、减少帮助后的新材料检查、错因反馈、延后再练、证据边界。这里只提出内容契约，不预先规定必须新增一套复杂数据系统。

重点逐项核对：

- **Do/Are：**两个结构分别出现，或词库只给正确助动词，都不足以证明孩子会在两者之间选择。需要直接对比与新的提问情境。
- **give：**课文理解、人与物辨认、两种词序操作分别承担不同目标；本课新增的是后两者的明确教学和检查。
- **either/too：**先提供前文与第二人的情况。选出“也不”这一中文释义与在对话中使用 either 分别记录。
- **三单：**保留当前 likes、does 后原形、Does 问句的目标及延后题，补上主语判断，覆盖单个名词短语、并列主语和 I/you 等代表情况。
- **some/any：**当前题中指定 any 可以保留，但提示应限定在本题的中性一般疑问句，不能教成所有疑问句都必须把 some 换成 any。其他用法若未教，不纳入干扰与考核。
- **覆盖：**教材来源编号被某题引用，不等于该编号中的所有语法点都被检查；原文完整性、教学覆盖和独立检查需要各自核对。

本轮已发现的具体编写例子：故事在第 9 段附近询问“太太和丈夫是否都喜欢羊肉”，信息依据应指向表达偏好的原句，而不能仅用当前位置的 Give me… 作为考查依据。第 15 段附近关于丈夫偏好的问题也应核对实际支撑句。编写时区分“题目插入位置”“支持答案的信息”“检查的能力”。这是来源与目标映射问题；本轮不将其扩大为已经复现的所有运行时反馈错误。

## 6. 降低连续灌输感的具体做法

1. **每段给一个能理解的用途。** 听词是为了找货品，比较句型是为了问清楚，组句是为了完成请求；序数词等没有自然叙事关系的内容保留独立任务。
2. **示范后尽快尝试。** 从例句卡连续播放改为示范与小判断交替，同一种操作再次出现时应带来新的语义、主语或结构变化。
3. **有限而有效的选择。** 选角色、选回应、查看帮助、重听和撤回；路线仍提供清楚的下一步。角色选择应改变学习动作，不只改变头像。
4. **错误解释停留到孩子准备继续。** 反馈先指出当前区别，再允许修正或继续；不依靠快速换题让孩子略过错误。
5. **支持逐渐减少。** 从示范、明确句框，到词库与情境支持；正确示范音频不能在结构检查前自动泄露答案。正常听音与重听不算额外提示。
6. **结果与任务相连。** 商品装入订单、交到对应角色手中，之后再进入现有奖励结算；避免每次点选都用大动画打断思考。
7. **复习改变组合。** 使用已经教过的新人物与食物组合检查同一目标，保留到期复习；同一题无限重做成功不直接升级为迁移达标。

这些安排与 [Duolingo Adventures 的任务、角色回应和情境反馈](https://blog.duolingo.com/adventures/) 相契合；示范与练习交替、具体与抽象联系、延后检索可参考 [IES 教学指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)。它们支持设计方向，不能证明本项目采用后必然更受儿童喜欢。

| 批次 | 范围 | 交付与验收 |

| P0：核准目标和题稿 | 以已经完成本地技术验收的无键盘候选为基础，记录工作区版本；核对课文依据、规则范围和新旧目标去向 | 五组借鉴目标的对应表；逐题保留／改编／新增清单；可审阅的例句、干扰项、反馈与音频需求 |
| P1：完成 49–50 样板 | 复用现有组件重编上述节点，加入关键对比、交接和角色任务，接入相应复习 | 完整原文、保留内容和新增目标经过实际运行检查；首次、错误、提示、重听、撤回、恢复与小屏可用 |
| P2：儿童试做后推广 | 先调整样板，再选择请求、归属、位置、喜好等代表单元 | 分课堂／独立使用的观察和新材料表现；按每课目标推广，避免全册机械套同一种故事与题型 |

第一批不重复开发已完成的无键盘功能。后续检查针对实际变更展开；涉及共享组件、全局样式、素材、响应式或页面切换时，按影响范围执行既有浏览器防护网和必要回归，把实际结果记录到 design-qa。

内容、答案、候选项、顺序、音频与目标映射统一在 catalog 及其既有编写来源维护；页面只呈现与转发。新任务需要新版本或新 ID 时使用现有迁移机制：保留旧完成、解锁和跳级记录，历史书写证据继续只读，新任务不继承虚构的答题成绩。

地图与课程沿用当前统一主题。新图像服从项目既定角色与迪士尼式绘画方向，不把主干的颜色、图标或独立成长地图整体搬入新版。

## 8. 怎样判断优化有效

技术验收通过后，观察语言基础相近的目标学生，教师带领和独立操作分别记录。比较旧、新活动时使用目标与难度相当的材料，并平衡体验顺序，避免把先学会后的熟悉度当作某版的优势。

- **参与：**是否理解任务、愿意尝试、主动重听或选择重玩；求助与放弃发生在哪一步。
- **语言：**同一目标换人物或情境后是否仍答对，哪些错误持续出现，延后再练是否保留。
- **操作：**是否被选项、拖动替代操作、声音等待、反馈或小屏布局阻碍；不能把操作熟练误判为语言进步。
- **支持边界：**词库作答、额外提示、正常听音分别记录；整句自由表达和自主书写由线下任务提供独立证据。

首轮用于发现问题和调整题量，不预设未经测量的效果提升比例。兴趣改善和语言表现都满足后，再扩大改编范围。
