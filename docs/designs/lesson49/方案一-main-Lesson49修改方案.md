# 方案一：main Lesson 49 修改方案

2026-09-10 · 可评审提案，尚未实施。

保留 Lesson 49 的五关结构、肉铺情境、角色扮演、句型操作和小镇成长。修改重点是让孩子在现有活动中看清语言关系，获得可控的尝试机会，再把所学用于新的情境。

依据 main `7499a15` 的课程源码、已经查看的实际页面与[修正分析报告](修正分析报告.md)。客户反馈提供了有价值的方向；本方案尚无真实儿童试做结果，不能据此宣布哪一版教学效果更好。

## 1. 修改范围与内容去向

| 内容 | 处理方式 | 需要得到的学习证据 |
| --- | --- | --- |
| 教材原文、人物需求与偏好 | 完整保留；把理解与角色回应联系起来 | 能根据听到或读到的信息选择物品、人物或回应 |
| 原有 14 个词和 3 个短语 | 清单保留，标注教材词、补充词、补充表达；修正图义与用法 | 已教目标有相应检查；没有检查的内容不标成掌握 |
| Do you / Are you | 保留动作、身份、状态、地点的对比 | 能在当前一般现在时范围内，为要问的信息选择正确问句 |
| give 的两种宾语结构 | 保留变身，增加预测、重排和交接 | 分别理解“给谁／给什么”和两种词序 |
| either / too | 加上前一句，让两个人的意思形成联系 | 理解“也／也不”，并选出对应表达 |
| 三单主语和动词形式 | 保留主语类型，分段练习，再放回完整句子 | 能处理人名、名词短语、并列主语及 I/you 等情况 |
| does not 后用原形 | 从课文现有句子引出，新增明确对比与检查 | 能区别 He likes… 与 He doesn't like…；这项专项训练是新增内容 |
| 表达锦囊 | 保留 To tell you the truth；其余按用途整理为补充 | 能在合适语境中使用，不把不同话语功能当成同义替换 |

这里的“必修”是建议的本课产品目标，需要与教师的教学大纲核对，不能直接等同于已核验的学校考试范围。Does 问句可作为后续课程的衔接内容；若纳入本课考核，必须先安排教学和练习。

## 2. 五关怎样改

### 第一关：词汇肉铺——听懂客人要什么

保留浏览、点击发音和听辨，增加明确的使用目的。例如孩子先看清柜台上的牛排和肉馅，再根据客人的请求选择货品。

- steak 当前使用培根图标、mince 使用碗图标，先更换为能清楚辨认的教学图片；butcher 应呈现职业人物。抽象词 truth、either 用短情境解释，不强行用单个图标代表词义。
- 教材词与补充材料分别标记。mutton、pork、fish 等补充词可以保留；补充短语的英语表达经教师核准后再使用。
- 词义、声音和应用分开检查。听辨题依赖音频与选项；如果图片已经直接透露答案，该题应记录为图义选择，不能充当纯听力成绩。
- 现有“从 14 词随机抽 8 轮”改为按学习目标安排抽样与后续轮换。词汇教学、当前检查和待复习内容可以对应到具体词，不用随机题数代替覆盖。
- “肉店单词全拿下”改为符合实际结果的完成反馈，例如“完成这轮听辨”。世界成长仍可奖励参与。

验收：图词对应准确，选项有合理区别，正常重听不扣分、不记作额外提示；未检查的词不会获得掌握记录。

### 第二关：课文剧场——先听懂，再成为角色

保留完整原文与 Mrs. Bird／butcher 两个角色。原文学习与课后改编场景清楚区分。

1. **完整学习原文。** 逐句播放到真实结束，手动继续；保留重听和按需中文帮助。
2. **选择角色复演。** 对方说话时听取信息，轮到自己时可先说，再选择接话或使用词块；“看一句提示”“查看原句”作为可选帮助。
3. **做一个信息判断。** 例如根据 Mrs. Bird 与丈夫的不同偏好，为丈夫选食物。
4. **换一处信息再回应。** 使用已经学过的人物、食物和句型，改变顾客的需求；明确这是练习情境，不修改教材人物的原始设定。

线上记录接话、选择和词块组织的表现。课堂可以让同伴听孩子说出来，但点击“揭晓”不构成口语达标证据，也不增加强制录音或语音评分。

现有固定约 3.4 秒自动翻页应退出学生必修学习流程。教师如需要演示播放，可以保留单独的播放模式，但其播放状态不自动生成独立作答成绩。

### 第三关：句型魔法屋——让孩子先判断，再看变化

**Do / Are：从分篮子走到会提问。**

先用 Are you a teacher? 与 Do you like meat? 建立对比，再覆盖 busy、at home 等状态／地点以及已学的一般现在时表达。孩子需要判断“现在想知道什么”，而非只辨认篮子颜色。

给出一个情境，让孩子在两个完整问句中选择；反馈突出有区别的词。规则表述限定在本组句型：be 本身也是动词，不能教成“有动词就 Do、没有动词就 Are”的通用规则。对于 like/want 等，使用“一般动词表达”的解释，避免“没有明显身体动作就用 Are”的误解。

**give 变身：从播放动画走到理解关系。**

使用同一场景串起四步：

1. 在 Give me that piece, please. 中，分别点出接收者和物品。
2. 先猜另一种说法怎样排列，再播放变身，突出 to 的位置。
3. 撤去示范，用词块组成 Give that piece to me, please.，允许撤回。
4. 更换物品或接收者，按句子把东西交给对应人物。

词块重排检查结构，交接任务检查意思，两种结果分别记录。保留 give/show/send/take 材料，但先核准各动词在具体例句中的自然用法；学完 give 后先迁移一个已教动词，其余分配到再练，避免四套同样演示连续播放。

**either / too：补上两个人之间的联系。**

第一组：A 说 I like steak.；B 的偏好图显示也喜欢牛排；孩子补出 I like steak, too.

第二组：A 说 I don't like chicken.；B 的偏好图显示也不喜欢鸡肉；孩子补出 I don't like chicken either.

先确认两个人的偏好关系，再判断句尾表达。不能只教“看到 not 就选 either”，也不能在没有前文时假定“也”的语境成立。已有疑问句例子需要补足语境，经教师核准后放入进阶练习。

**表达锦囊：按用途整理。**

To tell you the truth 和 To be honest 可以用于坦白表达；Well、Yeah、解释性表达分别给出适合的短对话。规范核准 That's to say 等条目的表达形式。必修优先服务原文，其余作为选看材料，取消依赖反复开合次数的完成判定。

### 第四关：三单训练场——分清主语，再改变句子

保留 21 个主语材料，按有助于理解的类型分段：单个人／物、复数或并列主语、I/you 等不能仅凭人数判断的情况。初轮选有代表性的材料，其余在后续练习轮换；不要求所有孩子连续做完 21 次同类分拣。

每组遵循“示范一个—判断几个—放回句子”的节奏。分类名称使用“第三人称单数／其他主语”，不能把 I 和 you 统称为复数。

例如先比较 my aunt、my parents，再完成 My aunt likes fish. 与 My parents like fish.。随后回到课文，比较 He likes steak. 和 He doesn't like chicken.，看清 doesn't 后面使用 like。

- 对 watches、goes 明确标出 -es，避免“动词加 s”覆盖所有拼写情况。
- loves his girlfriend、drink beer 等例句可换为孩子容易理解的宠物、饮食、上学情境，保留原本的主语与词形目标。
- 原有两道中文句子“看答案”改为有作答过程的选句或词块任务；教师仍可线下要求口头表达。
- 错误后停留在当前题，指出当前的关键区别，孩子点击继续；清除上一题反馈，修复目前快速换题后旧提示仍停留的问题。

分类答对只能说明该次判断正确；完整句与换情境检查提供不同的学习证据。

### 第五关：老板考核——用新订单检查本课目标

将结业内容安排为两个可暂停的小段，每段先以 4–6 次作答进行试做，再根据孩子实际负担调整。这是方案初始配置，不是已验证的适龄题量。

| 检查内容 | 示例任务 | 主要判断什么 |
| --- | --- | --- |
| 词义与听辨 | 听顾客需求，选择货品 | 是否认出当前目标词 |
| 课文理解 | 按家人的不同偏好准备订单 | 是否理解人物信息 |
| Do / Are | 分别为身份／状态和喜好选择问句 | 是否能区分提问结构 |
| give 结构 | 换接收者或物品重排句子，再交接 | 结构与角色关系是否理解 |
| either / too | 依据前一句与第二人的偏好选择回应 | 是否理解“也／也不” |
| 主语与三单 | 换为已学名词短语或并列主语 | 是否能处理超出固定 he/she 的主语 |
| doesn't 后原形 | 选择符合新人物偏好的否定句 | 是否保留动词原形 |

词汇的逐项覆盖在词汇关和后续复习累计，不全部压进结业题。不得用结业抽样成绩宣布全部词、所有表达或自由口语已经掌握。表达锦囊补充材料、未教的 Does 问句不突然进入必考。

练习中可以提示与重试；检查时保留首次提交、是否使用额外提示及后续修正的区别。反馈显示本题支持条件下的结果，例如“未用额外提示答对／提示后完成／建议再练”。查看答案不直接转为新的正确作答证据。

## 3. 奖励、课堂与独立使用

- 保留星星和小镇成长。把奖励安排在完整小任务结束处，先让孩子看懂语言反馈，再展示成长结果。
- 奖励完成学习活动是合理的，但证书、能力标签和复习记录使用实际作答依据。点一次变身、打开锦囊、揭晓台词不能分别推断为结构掌握、表达掌握或口语达标。
- 学生端遵循“作答—检查—反馈—继续”，教师端保留组织讨论、分角色和暂停演示的入口；两端共用同一份内容。
- 整段说话、表演与写作由线下教师组织。线上无强制打字或屏幕手写，仍支持 Tab/Enter 等标准无障碍操作。
- 保留既有完成和成长记录；新增任务单独记录，不回写旧成绩为新能力达标。

## 4. 实施顺序与交付边界

| 批次 | 修改范围 | 完成时应交付 |
| --- | --- | --- |
| P0：内容与反馈准确 | 图义、规则措辞、表达用法、真实播放结束、反馈停留、完成文案、锦囊操作语义 | 经核对的内容清单；原问题复现、修复依据和实际页面结果 |
| P1：教学活动完善 | 角色回应、give 独立操作、either/too 对话、主语迁移、结业检查 | 每项目标的示范、练习、检查、再练对应表与可操作完整课程 |
| P2：儿童试做调整 | 分段题量、提示层次、课堂／独立操作、延后再练 | 观察记录、同目标新题表现与下一轮具体修订 |

新增和迁移的内容统一进入 Lesson 49 catalog。现有 WORDS、DIALOGUE、DOARE、GIVE、POUCH、ET、TP、FILL、CHOICE、TRANS、EXAM 等内联配置迁入单一内容来源，学生页与课堂页读取；页面只呈现并转发操作。

保持既定视觉方向。新增人物与物品图按项目的迪士尼式绘画方向生成；如调整主题，入口与课程一起规划。涉及共享样式、图片、响应式或页面切换时执行项目浏览器防护网，并将实际结果写入 design-qa。本提案不启动全站换肤。

## 5. 验收方法

1. **内容与目标：**每个必修目标都能指出在哪里教、怎么练、怎样用新材料检查；核心与补充范围、合理答案、干扰项及音频经过核对。
2. **实际体验：**重听、撤回、错题反馈、手动继续、刷新恢复、触控、小屏与教师演示经过实际操作；修复留下原症状、复现、原因、此前遗漏及对应回归防护。
3. **真实学生：**按实际语言基础和独立操作能力分组，分别观察教师带领与独立使用；记录是否理解任务、主动尝试、所需帮助、放弃点、同目标新题和延后表现。
4. **结果解释：**活动完成、兴趣、当场答题与延后表现分开判断。不把停留时间长、奖励多或自动检查通过解释成学习效果已经提高。

示范与练习交替、具体情境连接抽象结构、间隔后再提取，与 [IES 教学指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1) 的建议一致；以上课次安排和题量是本项目设计提案，仍需儿童试做校准。角色购物和按情境作出回应也可参考 [Duolingo Adventures 官方说明](https://blog.duolingo.com/adventures/)，不照搬其人物、美术或玩法规模。
