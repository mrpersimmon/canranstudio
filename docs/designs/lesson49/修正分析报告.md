# Lesson 49 两版课程比较

2026-09-10 的历史分析，比较对象已由用户更正为 **Lesson 49**。当次未修改课程。

当时的判断：main 将角色回应、句式对比、give 变换和主语分类做成可参与活动；新版保留教材与路线，但本单元没有等量保留这些专项教学。客户可能因此感到参与减少、关键区别不够清楚。这是机制分析，没有儿童实验支持。

## 关键差异

| 目标 | 当时 main 的机会 | 新版的情况与边界 |
| --- | --- | --- |
| 原文与回应 | 选角色、遮词、先说再揭晓 | 完整原文及两题理解检查；未见同类角色复演。揭晓不能证明口语达标。 |
| Do / Are | 专项分类和考核 | 两种句子都出现，但不等于要求孩子在两者间判断。 |
| give 两种结构 | 人、物、to 的可视变化 | 原文出现 Give me…，未见同类结构操作。观看演示也不算独立变换。 |
| either / too | 两种表达并排选择 | 有 either 词义和例句，成对语境辨析较少；不能只找 not。 |
| 主语与动词 | 21 个多类型主语 | 新版在 likes、does 后原形、Does 问句和错因记录上有长处。 |
| 词汇与复习 | 14 词、3 短语、8 轮听辨 | 新版范围含 Lesson 50 和跨课复习；抽查几词不证明全部词汇掌握。 |

“未见”只限当时核对的本单元，不代表 1–144 课从未出现。main 的扩展词和锦囊也不能全部视作新版遗漏教材。

## 两版都应改进的地方

- **按目标核对覆盖。** 材料出现、示范、练习和独立检查分别记录。例如故事题问人物喜好，即使插在 Give me… 附近，也不能证明检查了 give 结构。
- **让重复带来新判断。** 听读、选项和词块再次出现时，应改变人物、需求或语言关系，而非只延长步骤。
- **准确解释规则。** 不把 be 说成“不是动词”，不把所有三单拼写说成“加 s”，不把五种锦囊都说成“说实话”。
- **把奖励与学习证据分开。** 当时 main 看演示、揭晓或翻卡即可奖励，考核也未覆盖全部目标；满星不等于全面掌握。
- **让反馈可控。** main 的定时推进、密集长页与不准图义需要修正；新版的清楚步骤、按需帮助、错因与复习值得保留。

后续方向见[两套方案](两套改进方案-修正版.md)。比较儿童表现时应保持目标和难度相近，分别记录教师带领与独立使用，并平衡体验顺序。

当次没有儿童试做、整课通关、全量听审、全尺寸或正式站点验收。截图视口不同，不能用于像素级优劣比较。课堂投屏后来在 v1.2 移除，不能把历史入口当作当前功能。
