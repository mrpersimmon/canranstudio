## 方案一：main Lesson 49，完善现有课堂活动

目标：保留课文角色扮演、句型魔法屋和三单训练，在演示之后加入有效判断与应用，让奖励、完成和学习证据表达各自的含义。

| 环节 | 具体修改 | 验收重点 |
| --- | --- | --- |
| 词汇肉铺 | 保留 14 词与 3 短语的内容清单，区分教材核心与补充；修正 steak、mince 等不够准确的图片；根据目标安排听辨与词义检查 | 8 轮随机题不再被解释为全部词汇掌握；抽样覆盖和未检查目标可追踪 |
| 课文剧场 | 保留完整原文、选择角色和遮词；增加可选句框／词块帮助，在课文复演后更换一处已学信息作回应 | 先尝试、再核对，允许重听；录音播放和继续符合真实结束与手动推进要求；不以点“揭晓”认证口语 |
| Do/Are 分拣 | 保留动作、身份、状态与地点对比；分类后在两个完整问句之间判断，并换一个已学表达应用 | 不能只根据篮子颜色作答；说明本组规则范围，避免把 be 说成“不是动词” |
| give 变身 | 保留 give/show/send/take 对照；先预测人和物位置，再点选整理词块、补 to，最后根据对象把物品交给正确人物 | 词序和接收者分别检查；演示记录为学习活动，独立作答另记 |
| 表达锦囊 | 区分坦白表达、犹豫开口、附和回应与解释；给适合的短对话选择表达 | Well、Yeah、That's to say 不被暗示为“说实话”的同义替换；补充材料控制在已教范围 |
| either/too | 加入前后两句，先理解人物是否具有相同偏好，再选末尾表达；保留必要的形式对比 | 检查“也／也不”的意思与形式，不只检索 not 字符；多种合理回应须被正确接受 |
| 三单训练 | 保留人名、单个人／物、并列主语等类型；21 个主语分段组织，再用完整句子迁移 | 确认孩子会判断主语；准确说明 watches/goes，避免把“加 s”当成完整拼写说明 |
| 老板考核 | 保留短综合任务，从整课目标中分段抽查；补足双宾语、either/too 等尚无独立证据的目标 | 使用新人物／组合，区分直接答对、提示后完成与还需再练；证书不宣称全部能力已掌握 |

一个 give 活动示例：

1. 看见 Give me that piece, please. 与接收物品的人。
2. 先选择交换哪两个部分，再播放变身，突出 to。
3. 用词块组织同一意思的另一种说法；允许撤回。
4. 更换为已教的 show／send 场景，检查是否仍能确定谁、什么物品、to 的位置。

这样的安排让动画解释关系，并提供孩子实际判断的证据。所有例句、等义答案、干扰项、反馈与音频在 catalog 统一维护。

实施顺序：

- **P0**：规则与图义准确性、有效反馈、手动继续、奖励记录含义、明显操作问题。
- **P1**：给现有演示和分类补上独立判断、完整句与情境应用，更新考查覆盖。
- **P2**：实际儿童试做后调整分段、帮助、题量和再练；教师带领与独立使用分别记录。

保留原有完成历史，不补造新题成绩。课程内容和图像修改遵循项目设计原则；涉及共享样式、素材、响应式和页面切换时执行浏览器防护网，真实结果再写入 design-qa。界面主题如需更新，应与入口共同规划，避免单课切换割裂。

## 方案二：codex/duolingo-version，补回本单元的教学活动

目标：沿用完整教材、无键盘作答、统一主题、路线、错因与复习能力，以 Lesson 49–50 做出一个能解释关键区别、允许尝试并能记录目标表现的完整样板。

### 第一批：建立目标与活动的对应关系

优先检查五组目标：

| 目标 | 拟定活动 | 不能作为替代证据的内容 |
| --- | --- | --- |
| 课文中人物需求与回应 | 理解信息后选物，选择角色复演或以词块／接话回应 | 仅播放完原文 |
| Do you / Are you | 比较动作与身份、状态、地点；新例子判断问句 | 分别出现过两种句子 |
| give 两种宾语结构 | 关系示范、词块变换、补 to、按句子交接物品 | 课文里出现 Give me… |
| either / too | 结合前文偏好选回应，再处理对应形式 | 单独解释 either 是“也不” |
| 三单主语及句子形式 | 不同主语分类、完整句比较；保留现有 likes、does 原形和 Does 问句练习 | 只在 he/she 的固定句子里答对 |

把教材核心、必要的先修复习与扩展材料分开标记；每个保留目标都要有清楚的去向。主干的 5 张锦囊、扩展肉类词等先核对教学必要性与准确性，不因旧课件出现就全部堆进必修。

剧情位置、题目实际依据和目标能力分别编写。比如“太太和丈夫是否都喜欢羊肉”应追到偏好信息，不能将其作为 Give me… 结构已经考查的证明。

### 第二批：重编样板的学习流程

保持现有完整课文学习要求，在相应节点内部安排：课文情境与信息 → 必要词句帮助 → 角色回应 → 关键区别的对比与操作 → 回到肉铺完成任务 → 新材料检查与间隔复习。

这不是要求每课机械套同一顺序。重点是减少只有播放与继续、却没有产生新判断的重复，用目标清楚的新任务置换。已有三组词汇、序数词及跨课复习分别保留合理位置，不能因故事改编无故删去教材范围。

当前已有的补句、词块、配对、点词改错与情境步骤可以复用。示例：

- 客人说出需要的肉类，孩子选择物品并交给接收者。
- 孩子判断“询问是不是老师”与“询问喜不喜欢肉”分别如何开头。
- 人物表达否定偏好，孩子结合前文选一个表示“我也不喜欢”的回应。
- 更换人物后，孩子自己处理主语、助动词与动词形式，错误反馈只解释当前的区别。

线上全入口维持无强制打字或手写；自主口头表达可以由教师与同伴检查，不依赖新增语音评分。正常听音与重听、词库支持、额外提示分别记录。

### 第三批：验证后向全册推广

当前实施记录表明，无键盘候选已完成本地实施与技术验收，尚未提交、推送或发布。以后续实施时确认的工作区版本为基础保留现有成果，针对新增活动及受影响范围验证。样板完成后，按归属、位置、请求、喜好、动作等真实教材目标，选择代表单元推广；编译器负责生成与检查，编者负责目标、场景、候选项和错因。

对现有节点和进度保持可追溯映射；必要时拆分过长活动，但不回锁旧完成与跳级记录。新版点选不追溯替代旧书写证据。完整教材、按真实音频结束记录、手动继续、回到路线的边界继续沿用。

## 两套方案共同的验收方法

1. **内容验收**：逐项核对“已教—练习—错误解释—换情境检查—复习”，允许明确标记尚未检查。
2. **实际操作**：检查触控、撤回、提示、重听、反馈停留、刷新恢复和小屏；修复应留下旧问题复现、原因与回归防护。
3. **儿童观察**：任务理解、主动尝试、求助与放弃、同目标新题、延后表现分别记录；课堂和独立使用分开。
4. **判断标准**：兴趣改善与学习表现都要看。小规模试做用于修正设计，不承诺未经测量的提升比例。

推荐先完成 main 的 P0 与两版的目标对应表，再验证新版完整样板。两套方案的成果可以互相参考，实施、测试、实际页面验收和发布分别报告。
