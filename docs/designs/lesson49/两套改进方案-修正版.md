# Lesson 49 两套改进方向

2026-09-10 的提案，当时未实施。对象是 Lesson 49，不能用 Lesson 50 的活动解释这次反馈。

| 方向 | 保留什么 | 重点补什么 |
| --- | --- | --- |
| 方案一：改进 main Lesson 49 | 五关、肉铺、原文、角色与专项活动 | 准确图义和规则；演示后自己判断；稳定反馈；按真实作答记录。 |
| 方案二：改进 Duolingo 借鉴分支 | 完整教材、无键盘操作、路线、记录和复习 | 将角色回应、关键句型对比、give 交接与主语迁移放回 49–50 单元。 |

两套都先核对五组目标：人物信息与回应、Do/Are、give 两种结构、either/too、主语与动词。每组写清在哪里教、怎样练、用什么新材料检查、何时复习。

实施分三步：先纠正内容和反馈，再补独立判断与情境应用，最后通过儿童试做调整题量、帮助和节奏。线上以点选和词块为主，整句口头表达与书写由线下另收证据。

保护旧完成记录，不为新题补造旧成绩。正常重听、词库支持与额外提示分别记录；看演示、翻卡、领奖均不等于掌握。
