## 1. 一句话体验

孩子在同一晚、同一间星灯失物招领站里，帮助同一位男招领员和同一位女顾客完成一条连续事件：先听懂七句话，确认并归还她的手提包；再核对包中随身物品、找回她遗落在衣帽间的外套；最后听懂并认出 `car` 与 `house`，点击与英文对应的真实汽车和房屋，让女顾客上车并安全到家。英语每次都让人物回应、物品移动或场景改变，不设置路线图、交图、盖章、拉杆、点灯和“点亮已有线索”等空操作。

完成体验应让六至八岁孩子感到自己解决了一件事，而不是连续做完二十九道题。二十九份正式语言结果藏在十七个短、可见、可恢复的故事阶段中；第十七阶段是无评分但必修的双角色全篇演练，不新增结果。题目之间必须有角色回应、物品归位、场景展开、人物上车或抵达家中等真实状态变化。

## 2. 不可退让的实施边界

1. catalog 是教材英语、产品英语、中文提示、角色、实体、答案、支架、音频、阶段顺序、保存条件和故事动作的唯一真源。页面只有通用渲染与事件转发，课程内容副本为零。
2. 十七个孩子可见阶段就是十七个原子恢复微任务。进度、阶段导航、保存、归零重启和验收不得另造一套隐藏边界；无字逐句回演是另行解锁的无编号工具，不是隐藏阶段。
3. 十一项具体物品词当天全部完成词音与词形两个独立通道，共二十二个词汇结果；另外保存七个课文理解／交际／迁移结果，总计二十九个。
4. 每段语言音频播放时，对应英文始终可见；只有当前有效音频请求的真实 `ended` 才能开放门禁。失败、取消、过期回调均不得冒充结束。
5. 正式答案只按 catalog 的稳定 Source ID、Content ID、entity ID 与关系判定。随机顺序、视觉位置、页面字符串和 DOM 序号永远不是答案。
6. 冒险心只在正式提交出现。归零时伙伴示范变化实例，并从当前微任务开头完整重播；已完成微任务、章节成果和世界状态不回退。
7. 手提包只归还一次，外套只归还一次。`car` 与 `house` 构成真实回家旅程，不是抽象路线调查、第三位认领者、第三次物品交接或肉眼看钥匙猜物品。
8. Lesson 1 完成只写入章节停靠点；Lesson 2 中点只写段落停靠点；必须完成女顾客到家事实并成功保存、读回后才增长本单元地标。
9. 同日完成不等于长期掌握。回看和重玩只算练习；跨日、变化情境、无支架成功才可进入独立调用与掌握判断。
10. 本蓝图不授权合并 `main` 或发布网站；正式实现、测试、本地成人验收、儿童观察和发布证明是彼此独立的边界。
11. V2 使用两套同语义构图母版：约 9:19.5 的手机竖版和 16:10 的平板／电脑宽版；不是一张背景任意裁切，也不按设备型号逐一作图。十六个挑战型活动使用对话、物品、语法或回家旅程构型，第十七阶段使用固定双人角色演练构型，已保存的章节／段落／单元成果另用成果／停靠构型。
12. 十七阶段与二十九结果不因“更好玩”继续增加。正式挑战使用五种故事语义互动模式，同一模式最多连续承载两个正式挑战；`L01-M12` 虽是完成门禁，但没有结果或冒险心；handbag 示范、无字逐句回演与单元后三题复盘不制造新结果或主线进度。
13. 手机与电脑共享故事事实，不共享一套人物缩放值：电脑课堂宽版使用更大的落地人物，手机竖版使用更紧凑的人物尺度；同一画幅档内人物左右关系、脚底基线和比例保持稳定。手提包继续是独立故事道具，由 catalog 的竖版／宽版锚点范围动态落在真实柜台上，不烘焙进背景，也不生成额外台座。
14. 真实场景人物或物品是唯一候选层；任务面板不得复制同一组答案。正确后只在原场景中演出实体反馈、播放目标英语并同步更新冒险心，禁止再出现通用“线索找到了”卡、答案过场页或二次确认。

## 3. 四项学习功能如何完整覆盖

四项功能是内部课程验收维度，不显示成孩子端四个关卡。

| 学习功能 | 本单元中的真实承载 | 不采用的做法 |
|---|---|---|
| 语言材料建联 | 七句全文首听；十一物品词的声音主导轮、词形轮、答后自然发音与真实物品／街景 | 先背词表、每词连续双考、播放后再点一次喇叭 |
| 语篇建义 | 从七句话找出主人；按 `Excuse me! → 问归属 → Pardon? → 重问 → 确认 → 感谢` 推动一次真实归还 | 逐句中文翻译测验、打乱句子纯排序、重复交包 |
| 结构觉察与句型调用 | 用 `watch` 迁移 `Is this your ...?`，理解 `Yes, it is.` 中 `it` 指当前物品；成功后打开两层知识卡 | 三页成人语法讲义、术语背诵、`Yes, this is.` 找错陷阱 |
| 情境交际与迁移 | 礼貌叫住、请求重复、归属确认、收物致谢；外套归还与女顾客上车到家把语言放回同一事件 | 交路线图、第三位认领者、结案盖章或开张拉杆 |

### 3.1 本单元的弹性学习节奏

这不是五个儿童栏目，而是课程团队检查学习依赖的内部曲线：

1. **建立任务目的**：故事提要让孩子知道女士丢了东西、招领站需要帮助；
2. **整体输入与语篇建义**：`L01-M07` 带全文完整听七句，`L01-M08` 用最小故事行动找到主人；
3. **有选择地提取与检索**：其余阶段把目标词、交际意图和关系句框分散到托盘、衣帽间与街景，不把教材行数变成题数；
4. **整合故事调用**：归还手提包、用 `watch/it` 迁移句型、归还外套并帮助女顾客上车到家；
5. **跨日变化情境独立调用**：下一学习日按表现抽取二至四格，不把当日双角色演练、无字逐句回演或三题复盘冒充掌握。

各环节已经穿插在十七阶段中，不新增五个页面、五个导航项或五套进度。

## 5. 角色、声音与视觉连续性

- `station-keeper` 是全单元唯一男招领员；`handbag-owner` 是全单元唯一女顾客。人物只在有对话或故事职责时出现；在场时始终使用同一套全身形象与固定左右关系位。手机与电脑分别使用稳定的人物尺度档：手机更紧凑，电脑课堂宽版更大；同一画幅档内不能按题目模式忽大忽小、换边或只消失其中一人。纯物品阶段两人可以一起离场。
- `first-claimant`、`second-returner`、`coat-owner`、`third-claimant` 退出 V2 主线。旧实体可为存档迁移保留，但不得渲染或参与答案。
- 探险伙伴只有一个稳定实体 ID `explorer-cat`。当前 `child` 与 `cat-guide` 退役为指向该实体的存档别名；它只在提要、纠错示范、可理解提示和成果庆祝中出现。没有教学职责时从场景移除，不在角落放一只过小装饰猫，也不再生成第二只“小探险家”。
- 十一项词汇资产由 catalog 实体统一拥有。独立物品使用与木质星灯场景一致的精致透明插画，`car`、`house` 使用完整街景；禁止 emoji、平台字体图标、钥匙隐喻和页面临时配图。竖版与宽版背景都沿用当前木质星灯夜景画风，但背景图不烘焙人物、柜台物品或任务道具。
- 对话使用 `nce-youth-v1`：男声 `am_michael`、女声 `af_heart`。`L01-D07` 必须是女声。独立词音使用已选候选 C 的 `context-cropped-lexeme-v1`；四条已真人试听接受的衣物词保留锁定哈希，其余候选继续标记为未逐条审核，不能把同配方生成冒充真人通过。所有文件都保留 150 毫秒内英语起音与发布前逐条语言审核门禁。
- 本单元不播放连续背景音乐或环境嗡鸣。短成功视觉反馈后直接播放目标英语，不要求孩子再次点喇叭；全局一键静音仍应能关闭非语言音效。

### 5.1 双画幅故事舞台与语义场景构型

- V2 同时以约 9:19.5 手机竖版和 16:10 平板／电脑宽版为构图母版；390×844 仍是手机主验收视口。两套母版共享同一人物、物品、语言、场景锚点、动作顺序和结果，只重新编排空间；各自按清晰度导出资源，不为每个设备尺寸另画背景，也不把一张图任意裁成所有比例。
- 前十六个活动阶段分别声明 `dialogue-stage`（对话舞台）、`object-workbench`（物品操作台）、`grammar-lab`（语法实验室）或 `homeward-journey`（回家旅程）；`L01-M12` 声明 `full-role-enactment`（完整角色演练）。`outcome-rest`（成果／停靠场景）只挂在所属微任务成功保存后的停靠或最终成果上，不属于活动微任务，也不产生额外进度。这些都是空间构型，不是儿童端课程分类，也不对应四项课程学习功能。
- 每个微任务由 catalog 声明稳定 `sceneVariant` 与有序场景呈现段。呈现段表达说话者切换、物品归位、柜台变形、人物上车或汽车抵达等同一恢复边界内的可见状态变化；它不新增结果、冒险心、进度、保存或恢复位置，也不与运行时音频／作答／保存 `phase` 混名。
- 普通阶段的当前核心动作在一个手机视口内完成。完整七句、故事册等真实长内容可以使用页面级自然纵向滚动；任务卡、对话卡、候选区和反馈区不得出现内嵌滚动，所有画幅禁止横向滚动。
- 有当前交际或故事职责的人物使用近景、落地构图。手机竖版人物目标约为可用视口高度的 34%–42%，电脑课堂宽版人物目标约为故事舞台可用高度的 65%–75%，并让头部与上半身清楚高于柜台；同一画幅档内的左右关系位和尺度固定，当前说话者只用前移、明暗或动作增强，另一人物保留关系但不抢焦点。纯物品呈现段由 catalog 同时移除两名成人；人物再次入场仍回到同一关系位与尺度。
- 物品不悬浮在空背景中央。手提包保留独立图层，由 catalog 分别声明竖版与宽版的真实柜台锚点范围、接触基线和允许尺度，并在画幅档内动态投影；不能用背景烘焙、固定像素坐标或额外台座掩盖定位问题。包内物品进入托盘或标签册，衣物进入衣架，`car` 位于真实道路／汽车场景，`house` 位于真实住宅场景；相应状态变化仍由 catalog 声明。
- 旧十五阶段 V0 只保留为问题证据，不再单独修补，也不作为 V2 验收目标。短屏、顶栏、题目密度、课文跟随与横屏回退继续遵循 ADR-0107；双画幅与回家终幕由 ADR-0113 更新，最短语义点击、稳定舞台和原子回看由 ADR-0114 更新。

### 5.2 手机交互合同

- 360×640 是硬验收下限，390×844 是主视觉基准，并覆盖至 430×932。普通阶段的当前提示、焦点实体、三至四个大候选和主操作必须在最矮视口一屏可用。
- 紧凑顶栏只显示当前短标题、`已完成/17` 和独立设置入口；点击进度，或点击设置中的“选择学习阶段”，打开同一个全屏阶段地图。冒险心只在当前正式挑战区出现，不占据首听、过场、知识卡、停靠点或顶栏。
- 当前阶段短标题只在顶栏出现一次，并与阶段地图读取同一个 catalog 字段；场景中央只显示当前行动提示，不重复大标题。1280×720 及以上电脑宽版使用课堂字号档：行动提示 38–44px、英语目标 36–42px、选项 26–30px、辅助文字不低于 20px；手机使用独立紧凑字号档，不由宽版整体缩小得到。
- 所有同文音频重听继续使用主题化图标而不是可见说明文字；手机点击区为 52×52px，电脑宽版为 60×60px，图标紧邻对应英语。播放只更新图标自身的发光与禁用状态，不得重建人物、道具、题面或产生整页闪烁。
- 同一时刻只显示一个当前 `challengeRef`，正式候选挑战固定提供三至四个清楚的大候选。两词阶段在同一故事空间顺次完成；前一个物品进入托盘、衣架或故事终态后，后一个仍使用完整三至四项诊断候选集。
- 候选人物或物品已经存在于真实场景时，它们就是唯一可点击答案；任务面板只保留问题、对应英语、主题化重听和必要支架，禁止再复制一排人物卡、物品卡或答案标签。提交前所有候选保持视觉中立。
- Lesson 1–2 的 `scene-identify`、`object-place`、`label-connect`、话语选择和真实交付都使用一次最短语义点击：孩子只选择能回答当前语言问题的物品、人物或语言块，系统随后演出归位、贴签、交付或场景变化。页面不声明拖动，也不要求先点动作端再点目标端。第一次错误只轻摇并提示“再看看”，第二次才给方向性支架；提交前不得高亮正确答案。
- 正确提交不进入通用结果卡或只显示答案的第二页面；正确实体在原位完成约半秒的职责化反馈——物品轻微发光归位，人物按故事职责轻点头或伸手——目标英语立即播放，冒险心与故事终态在同一次状态切换中更新。反馈不增加飞行星光、卡片、彩纸或语言前提示音；真实 `ended` 后才自动进入下一题或显示已冻结的继续动作。
- 完整七句默认自动把当前句带到舒适阅读区；孩子主动滚动后停止跟随并显示“回到当前句”，音频继续播放。返回当前句后恢复跟随，最后一句真实 `ended` 仍是唯一门禁。
- `car`／`house` 先在完整场景中逐项听音指认；词形轮直接点击与当前英文对应的真实汽车或房屋。`car` 正确并听完发音后，女顾客上车；`house` 正确并听完发音后，汽车抵达家中，不出现路线钉、纵向地图或交图。
- 动效遵循“强状态变化、弱常驻动画”：当前说话者、物品归位、衣架展开、女顾客上车和汽车到家是主动作，背景只轻微呼吸；每段回家动作约 4–6 秒，同一时间只有一个主动作，减少动态效果直接到达同一终态。
- 手机横屏不阻断课程：显示轻量“竖屏体验更好”提示并提供可完成的紧凑布局。旋转不得清空阶段、改变候选顺序、重启音频请求或遮挡设置／退出入口。

### 5.3 六类冻结构图

- **对话舞台**：双人同框，上部保留落地人物、柜台和当前物品；英文从当前说话人一侧进入，下部承载七句全文或当前唯一挑战。手提包只沿一次真实交付路径进入女顾客手中。
- **物品操作台**：托盘、标签册和衣架是实体工作面，三至四个候选位于真实场景关系中；正确物品进入槽位并保留为可见清单，人物只在描述、确认或归还时出现。
- **语法实验室**：不切入成人黑板房。原柜台现场展开为句块轨道，人物与 `handbag/watch` 不断场，完整话轮随组装实时变化，`it` 以可见关系连回当前物品；成功后才升起非计分知识层。
- **回家旅程**：先在完整汽车／房屋场景中听音指认，再直接点击与 `car`／`house` 对应的真实实体；正确后依次演出女顾客上车与汽车到家，不显示抽象地图或额外交付。
- **完整角色演练**：招领员固定在左、手提包主人固定在右，手提包留在柜台；孩子选择先扮演哪一人，每个角色都从七句第一句走到最后一句。当前角色与当前说话者分别明确提示，但人物不换边、不消失，未轮到的角色也不被误亮成答案。
- **成果／停靠**：保留刚刚发生的真实结果，不重新压成结算卡。章节和段落停靠以继续／休息为等权主动作，指定节点可以另有视觉上次要、可跳过的隔离练习入口；最终保存和完整读回后直接衔接人物离场与地标成长，再开放离开／下一课及可选案件复盘，不增加领取、盖章、拉杆或点灯。

十七阶段线框、场景呈现段、关键动效、减少动态效果终态与三档手机边界以 [手机场景 Storyboard](./lesson1-2-v2-mobile-scene-storyboard.md) 为详细真源。

### 6.5 五种故事语义互动模式

互动模式描述“孩子做什么、世界如何回应”，不替代 §5 的手机场景构型，也不创建新的证据通道。Catalog 为每个正式 `challengeRef` 声明以下一个稳定模式：

| 稳定值 | 含义 | 本单元例子 |
|---|---|---|
| `scene-identify` | 在真实人物或物品场景中指认目标，正确实体随后自然回应或归位 | 找主人、听 `handbag` 找包、从包内找 book/watch、从衣帽间找 skirt/shirt |
| `object-place` | 孩子把目标物品放入有故事意义的承接面或目标位；不能点卡后由系统代做归位 | pen/pencil 上托盘、book/watch 入标签册目标格、衣物上架 |
| `label-connect` | 把可见英文标签连接到当前真实物品、人物或场景实体 | handbag、pen/pencil、coat/dress、car/house 的词形结果 |
| `utterance-select` | 根据当前交际意图选择完整表达，并由原教材角色说出 | `Excuse me!`、`Pardon?`、`Thank you very much.` |
| `relation-reconstruct` | 孩子组织句块或指代之间的关系，并亲自形成完整可见结果 | handbag/watch 问句、`it` 指回当前物品 |

正式挑战的有序模式为：

```text
L01-M08 scene-identify ×2
L01-M09 utterance-select
L01-M10 relation-reconstruct → utterance-select
L01-M11 label-connect → utterance-select
L02-M11 object-place ×2
L02-M12 scene-identify ×2
L02-M13 label-connect ×2
L02-M14 object-place ×2
L02-M15 relation-reconstruct ×2
L02-M16 object-place ×2
L02-M17 scene-identify ×2
L02-M18 label-connect ×2
L02-M19 object-place ×2
L02-M20 scene-identify ×2
L02-M21 label-connect ×2
```

跨阶段连续计算时，同一模式也不得超过两个正式挑战。只有动作目的、提交关系或故事后果真正变化才算切换模式；仅换图、换背景、换文案或改变点击动效不算。

`L01-M12` 的双角色全篇演练是必修阶段，但没有 `challengeRef`、语言结果或冒险心；它完整保存后才把阶段进度从 `5/17` 推进到 `6/17`。`L01-RS01:manual-dialogue` 的无字逐句回演与 `NCE-U01-OUTCOME` 后的三题案件复盘都在正式主线之外：两者可跳过、不显示主线冒险心、不改变 `17/29`、地标、排期或掌握；案件复盘最多记录 `same-day-practice`。

## 8. 随机顺序与声明式判定

1. catalog 声明候选实体集合、正确关系、内容身份和支架，不声明固定位置。
2. 第一次进入 `lesson1-2-v2` 时生成并保存新的 `unitAttemptId`；普通刷新、恢复与回看沿用，只有二次确认“重头开始整个单元”才更换。每个微任务的 `attemptRevision` 初值为 `0`，刷新保持，只有冒险心归零重启该微任务才加一。
3. 种子域精确为 `JSON.stringify([experienceRevision, unitAttemptId, microtaskId, attemptRevision, channel, challengeRef])`。规范实现使用 `fnv1a32-v1` 哈希、`mulberry32-v1` 伪随机与降序 `fisher-yates-v1`；三者版本进入快照并由黄金向量锁定，也允许测试注入 RNG。
4. 同一尝试内重绘、音频回调、旋转屏幕、前后台切换和普通恢复不改变候选顺序。声音轮、稍后的词形轮和同阶段不同 `challengeRef` 都有不同随机域。
5. 归零产生新种子并重新计算排列；两项候选时新种子仍可能随机得到相同肉眼顺序，不用强制轮换伪装随机。页面只渲染快照中已经排好的稳定候选 ID，不读取原数组再次洗牌。
6. 每个物品 `challengeRef` 都保留 catalog 声明的完整诊断候选集，至少三个不同物品。某物品在故事中进入托盘、格子或衣架，只移动视觉代理，不从下一题候选集消失；第二词不能靠消去法成为唯一剩项。
7. 答案验证必须覆盖每个正确项出现在每个可能位置的情况。声音轮目标英文持续可见；词形轮提交前不播放该题答案音频。答对后短视觉确认，紧接自然发音；无需额外喇叭按钮。

## 9. 冒险心、纠错支架与结果语义

### 9.1 主线心池

- 全单元使用可恢复的三颗冒险心，只在正式挑战面板显示；首听、故事过场、知识卡、停靠点、保存重试和最终演出隐藏。
- 答错扣一颗；答对补回一颗，最多三颗。补心不抹掉已经使用过的支架。
- 一旦使用任何支架，本次结果至少为 `supported`；冒险心归零后重玩的整个当前微任务，其所有正式结果固定为 `partner-rescue`，并保存 `rescueUsed: true`、`supportLevel: model`，不能出现“伙伴救援但支架等级为零”。
- 结果在微任务完成前先写临时尝试区；只有整个微任务完成才原子提交。归零时清除本微任务的临时结果、临时接触与步骤事实，保留此前微任务。

### 9.2 匹配纠错矩阵

| 挑战类型 | 第一次错误：让错误可理解 | 第二次错误：聚焦线索 | 归零伙伴示范：换例而不泄漏本题 |
|---|---|---|---|
| 人物／课文理解 | 被点人物做出自然反应，关键话轮与说话人重新突出 | 只重播确认归属的关键话轮并保留人物 | 小猫用另一件已经学过的物品示范“谁说是自己的” |
| 交际表达 | 错误表达真的产生对应结果，例如过早感谢让交流停住 | 聚焦当前意图：叫住、没听清或收到物品 | 小猫在不同人物／物品情境演示同一意图 |
| 声音主导找物 | 错物执行自己的轻动作后回位；目标英文保持可见并可重听 | 对比目标与易混物的声音／形状线索 | 用另一个已学词完整示范听音找物 |
| 词形找物 | 错物轻退回，不在提交前播放答案音频 | 聚焦首尾字母、长度或 `shirt/skirt` 的局部差异 | 用另一个词静默示范看词形找物，仍不说本题答案 |
| 句块／`it` 指代 | 把孩子选择的关系直接演出来，使不合语境可见 | 聚焦问句开头、物品槽位或当前指代物 | 用 `book` 等不同物品示范问句与 `it` 指回关系 |

归零顺序冻结为：取消并作废旧媒体请求 → 小猫用变化实例完成第三层示范 → 清除当前微任务全部临时结果、临时接触和临时事实 → `attemptRevision + 1` → 补满三颗 → 从第一段 authored 音频／动画自动重播。重启后不清零 `rescueUsed`，所以该次微任务所有正式结果均为 `partner-rescue`。`L01-M07` 完整首听是独立无正式题阶段，因此不会因后续错误被罚听七句。

## 10. 音频与 `ended` 门禁

- 每个音频请求拥有跨运行时重建仍唯一的 `requestId`，每段拥有 `segmentId`。`audio/ended` 与 `audio/failed` 都必须携带并同时匹配 `experienceRevision + microtaskId + attemptRevision + requestId + segmentId`；只有当前媒体元素的真实 `ended` 才推进序列或开放提交。
- 切换阶段、回看、归零、离开页面或发起新请求时，先取消旧请求并使其所有回调失效；`AbortError` 只表示取消，不进入失败或重试。任何迟到的 `ended`／`failed` 都不得改变当前状态。
- 所有有声音的儿童界面都显示对应英文。完整七句显示全文并突出当前行；单词显示目标词形；角色回应显示完整句子。
- 声音主导题先完成当前词真实 `ended` 再允许作答。词形题答对后自动发音，真实 `ended` 后自动进入下一项；没有“再点喇叭才能继续”。
- 瞬时加载／网络错误在 250ms、750ms 后自动重试两次，总播放尝试最多三次；解码不支持等非瞬时错误直接进入可见失败态。孩子点击“再听一次”会创建全新 `requestId` 并重新获得两次自动重试，绝不复用失败回调。
- 首听、声音主导题、角色回应和词形答后发音都 fail-closed：重试耗尽后不自动继续、不登记 `audio-ended`、不生成声音结果、不提交当前微任务。错误不扣心，也不显示“刚才听到”；对应英文和可点击“再听一次”始终保留。V2 删除 `continue-without-sound` 绕过路径。
- 批量两词中第一条失败不得跳过第二条或把两条一起完成；同一页面会话内的音频重试停在当前 `challengeRef/segmentId`。序列中此前真实结束的接触只保留在本微任务临时区；刷新或离开后临时区清除，并从整个阶段第一段重播。词形题已经答对但答后发音失败时，同一会话只重试发音，不要求重复作答。
- 正确反馈不播放可能被误听成人声前调的旋律、点击声或环境声；自然英语是主要可听反馈。所有候选发布前仍需逐文件真人语言审核。

## 11. 保存、恢复与阶段导航

### 11.1 原子恢复

- 每个阶段开始记录 `microtaskId + attemptRevision + seed + challengeRef`；阶段完成时一次提交其全部结果、Source 接触、故事事实、心池和下一个阶段。
- 刷新、关闭或普通返回发生在阶段中间时，从该阶段开头重来；已完成阶段不回退。冒险心归零同样只重启当前阶段。
- Lesson 1 章节停靠点和 Lesson 2 段落停靠点都可安全退出；后者只指向下一未完成微任务，不生成章节成果。

- 最终地标冻结为四步：① 原子提交 `L02-M21` 的两个词形结果、`owner-home-arrival` 与 Lesson 2 章节完成，并引用但不重提此前二十七个结果，且不写 `buildStage`；② 读回并核对十七个完成 ID、二十九格、全部必需 Source 接触和故事事实；③ 提交幂等 `unit-built` 事件；④ 再读回 `buildStage=5` 后才播放地标演出。任何一步不完整都保留可见“重新保存”，不重答语言，也不提前增长。

### 11.2 回到任意已到达阶段

- 孩子进入 `L01-M07` 前不开放阶段地图。进入后，点击紧凑顶栏进度，或点击设置中的“选择学习阶段”，打开同一个全屏儿童阶段地图。阶段地图列出十七个可理解标题而不是内部编号；`reached` 精确定义为“全部已完成阶段 + 当前第一个未完成阶段”，已完成项标“回看”，当前项标“继续学习”，未来项标“未到达”且禁用。完成全单元后十七项全部可回看；`L01-M12` 完成后另显示无编号的无字回演入口。儿童阶段地图与隐藏验收预览严格隔离。

- 点击当前阶段不创建无保存副本，只关闭地图并继续正式学习。点击已完成阶段才进入“阶段回看”，一次只运行所选阶段；手提包、外套与上车／到家只重演可撤销的视觉代理。回看顶栏始终显示一键“退出回看 · 不保存”，不弹确认框。

## 12. 跨日最小回访

下一学习日进入地图时优先显示“昨日线索”，但有“稍后再来”，不阻塞下一课、不撤销地标。每轮选 2–4 项、约 45–90 秒，不显示倒计时。

选择优先级依次为：

1. 已到期或过期；
2. 声音不可用、伙伴救援或支架完成；
3. 曾答错；
4. 最久未独立调用；
5. 在不打乱前述优先级的前提下平衡词音、词形与交际通道。

若仍有其他到期内容，同一个词的词音与词形不在一轮中相邻出现。回访使用变化人物、变化物品位置或变化街景，不复刻主线卡片队列。只有跨日、变化情境、无支架成功才写 `independent-retrieval`；支架完成安排次日再访，系统音频失败保持到期且不记儿童失败。同日阶段回看只算练习。

二十九个 `reviewCellId` 都可进入回访，但掌握仍汇聚到 T1–T5。变化情境由 catalog 使用稳定 ID 声明：物品可进入 `review-schoolbag-check`，衣物进入 `review-morning-coatroom`，街景进入 `review-homeward-journey`，交际表达进入 `review-help-desk-exchange`；不得由页面临时改词造题。回访 attempt 至少记录：

```text
reviewRunId, reviewChallengeRef, reviewCellId, targetId, sourceRef,
channel, contextId, outcome, supportLevel, learningDay, attemptedAt
```

账本根据自己的学习日时钟和冻结间隔规则推导 `lastIndependentDay/nextDueDay`，页面和提交事件不得传入 `nextDueDay`。同优先级按 `nextDueDay → 风险等级 → lastIndependentDay → reviewCellId` 稳定排序；到期项少于两项时，用最早将到期且最薄弱的格补足两项，到四项即止。若没有已学格则不显示回访入口。

Q20 已选择 A：每个跨日回访 run 都使用一套与主线完全隔离的三颗冒险心。

- 新建 `reviewRunId` 时固定从三颗开始；答错减少一颗，孩子亲手答对补回一颗，上限三颗。
- 回访心数不读取、不修改主线心池；不带入下一次回访、下一课、地标、挑战星或永久评价，回访结束即丢弃临时心态。
- 归零时，小猫先用变化实例示范；随后清除本次 review run 的临时结果，补满三颗并从该 45–90 秒短轮第一项重开。主线结果、章节、地标和下一课资格完全不变。
- 发生伙伴示范后的这一轮只记录 `review-assisted-practice`，不能产生 `independent-retrieval` 或掌握证据，并安排次日再访；未触发示范且全程无支架的跨日变化情境成功才可形成独立证据。
- 系统或音频失败不扣回访心、不触发重开；对应格保持到期。孩子选择“稍后再来”也不消耗心或更改排期。

### 13.3 规范性状态机

| 状态 | 允许事件 | 成功去向 | 禁止的捷径 |
|---|---|---|---|
| `presenting` | authored 动画／自由动作结束 | `audio-playing` 或 `awaiting-response` | 自由点击直接写结果或扣心 |
| `audio-playing` | 当前 `audio/ended`、匹配的 `audio/failed` | 下一段、`awaiting-response` 或 `audio-retry` | 超时推进、旧回调推进、无声继续 |
| `audio-retry` | `audio/retry`、安全退出 | 新 `audio-playing` 或保留当前阶段 | 视觉作答伪造声音格 |
| `awaiting-response` | 当前 `challengeRef` 的 `response/submit` | 正确进入答后音频／下一挑战，错误进入 `supporting` | 页面自行判定、迟到题提交 |
| `supporting` | 支架演出完成、再次提交 | `awaiting-response`、正确推进或 `rescue-model` | 自动代答、抹除 support 轨迹 |
| `rescue-model` | 变化示范结束 | 清临时区并进入 `restarting` | 用本题答案示范后直接结算 |
| `restarting` | 第一 authored 段开始 | `presenting` 或 `audio-playing` | 保留本阶段部分结果、漏播开头 |
| `answered-awaiting-save` | 写 outbox、幂等 commit、retry | `completed` 或继续保存重试 | 重答已完成语言、先增长地标 |
| `completed` | 继续、进入 sandbox 回看 | 下一未完成阶段／停靠点 | 重复提交故事动作 |
| `unit-verifying` | 完整 readback、幂等 `unit-built` | 再读回后 `unit-built` | 只凭最终任务事件直接 build |

任何命令都携带当前 revision 与状态版本；运行时对不允许的事件返回可诊断拒绝，不悄悄吞掉、不部分写入。`pendingCommit` 是完成全部 authored 步骤后的保存态，不是可从中编辑答案的中间草稿。

### 14.2 运行时单元测试

- `fnv1a32-v1 + mulberry32-v1 + fisher-yates-v1` 黄金向量可复现；同尝试稳定，声音／词形／challenge 域不同，归零后种子改变但允许偶然同排列；所有位置均按稳定 ID 判对。
- 每个 `challengeRef` 只绑定一个结果；批量阶段第一词正确只写第一格，第二词错误或音频失败不能污染第一格或伪造第二格；故事移动后第二题仍保留完整诊断候选集。
- 词形提交前没有答案音频；正确后自动播放，只有当前真实 `ended` 推进。
- 每次点击只提交一个稳定答案；第一次错误轻摇并显示“再看看”，第二次显示方向性支架。重复正确点击只结算一次，候选视觉在提交前保持中立，系统归位动效不生成额外提交。
- `ended/failed` 都校验 request 与 segment；旧请求、取消请求、迟到回调、解码失败和超过“两次自动重试”均不开放门禁、不扣心、不写声音结果；没有无声绕过。
- 每类错误进入匹配支架；任何支架正确为 `supported`；归零后当前阶段所有结果为 `partner-rescue`，前一阶段不变。
- 归零按取消媒体、变化示范、清临时区、版本加一、补满三心、首段重播的顺序执行；结果保存 `rescueUsed/model`。
- 正确补心但不清除支架记录；非正式步骤不显示、不扣、不补心。
- outbox 可恢复 commit 已答待存状态；最终按“完成 payload → 完整读回 → 幂等 unit-built → buildStage 再读回”四步增长，幂等重试只增长一次。
- revision 不匹配时旧完成、心池、checkpoint、buildStage 和结果全部隔离；二十九格的 cell 级回访排序、间隔推导与同词不相邻可由固定时钟复现。
- `currentPresentationMomentId` 只按 catalog 的确定性条件推进；重绘、旋转和迟到媒体回调不能跳段。它与生命周期 `phase` 独立，呈现段变化不创建结果、心池、checkpoint 或新的恢复边界；减少动态效果只改变到达终态的方式。
- 正式双角色阶段只通过主运行时保存完整角色回合和最终阶段完成，不接收语言结果、心池或掌握接口。无字逐句回演与同日案件复盘运行在隔离练习会话；退出、刷新、重复进入或答错都不得修改主线心池、首次结果、故事事实、`nextDueDay`、独立证据、掌握或地标。复盘日志若启用只能写 `same-day-practice`。

### 14.3 E2E 儿童路径

- 在 16:10 桌面／平板宽版及 360×640、390×844、430×932 三档手机竖版完整走通十七阶段的五类活动主构型，以及 `6/17`、`11/17`、`17/17` 三个成果／停靠构型；两套母版都保留真实柜台和语义锚点。人物只在有职责时出现，在场时固定左右关系位与尺度；焦点物品、当前英文与主操作清楚且互不遮挡，普通阶段一屏完成，长内容只有页面级自然纵向滚动，全程无横向滚动或卡片内嵌滚动。
- 每个正式候选挑战同屏只有一个 `challengeRef` 和三至四个大候选；两词阶段顺次完成时，第二题仍保留完整候选集。点击一个候选就完成一次语义提交；第一次错误轻摇，第二次给方向性支架；旋转或重绘不改答案、不换顺序。
- 七句播放覆盖默认跟随、孩子手动滚动、停止跟随、“回到当前句”和恢复跟随；手动查看前文不暂停音频、不重复登记接触，最后一句真实 `ended` 仍是门禁。
- `car`／`house` 覆盖逐张全宽听音指认、点击与英文对应的真实实体、女顾客上车与汽车到家；每个标准故事动作 4–6 秒，减少动态效果直接到达相同终态，任一时刻只出现一个主动作，不出现路线钉、抽象地图或额外交付。
- 覆盖减少动态效果与手机横屏中途旋转；两者都保留同一语言、候选、阶段和完成语义，横屏提示不遮设置／退出，旋转不创建新音频请求或重置随机域。
- 从每一个阶段刷新并恢复；进入首阶段前没有回看入口。阶段地图逐项区分“回看／继续学习／未到达”，点击当前阶段恢复主线而不是创建副本。
- 已完成阶段以单阶段 sandbox 回看；顶栏出口一键可用，完成后停在双出口完成页，支持连续选择另一已完成阶段。回看不重复持久化交包、交衣、上车／到家、结果、奖励或地标。
- 未来未到达阶段保持禁用；sandbox 中途退出与完成后返回都恢复同一主线题目、答案状态、冒险心和候选顺序。若原主线在播音频，以新请求从原音频段开头重播；心池、排期、首次结果和故事事实不变。
- Lesson 1 停靠、Lesson 2 中点停靠和最终完成的状态彼此不混淆。
- `L01-M12` 可任选先演角色，但两个角色都必须从 D01 到 D07 完成；人物不换边，完整角色整轮保存，未完成角色重进从 D01 开始。无字逐句回演可跳过、不记进度，所有未到达台词先隐藏，逐句揭晓与原声播放合一，已揭晓句可重听且不推进。
- `L02-M15` 先演示已完成的 handbag 关系，再由孩子组装 watch 问句并连接 `it`；只有后两项既有挑战写结果，示范和知识层不扣心、不结算。
- 至少用三组种子完整游玩；正确项覆盖所有位置。分别触发每类一次／二次错误和一次归零重启。
- 模拟每段音频失败、重试、迟到回调、快速切换和前后台恢复；所有声音位置始终有对应英文。
- 验证正确后自动自然发音，没有额外喇叭确认，也没有连续嗡鸣／背景音频节点。
- 最终到家事实保存失败时看得到重试；成功读回前无地标，成功后只增长一次。
- 单元完成后可跳过或进入三题案件复盘；题目混合三类目标但不阻塞离场、地标或下一课，重复作答最多生成同日练习诊断。
- 跨日回访覆盖 2–4 项、45–90 秒、可稍后、独立三心池、归零重开短轮、优先级、变化情境与独立证据边界。

## 15. 明确不做

- 不设计“husband 是人物还是肉类”或任何类似儿童分类题；若未来教材出现 `husband`，只保留为课文词汇与内部语义保护。
- 不把课程拆成“词汇、课文、语法、应用”四张儿童页面，也不为每个 Source ID 制造一道题。
- 不把 Lesson 49 的五关、17 张词卡、老板终考、15 星或证书搬进 Lesson 1–2；第十七阶段只用于完整角色演练，不能借机增加语言结果、评分或奖励，案件复盘仍不得变成必做关卡。
- 不要求键盘输入、逐字母拼写、语法术语背诵、口语评分或教材抄写才能完成。
- 不使用第三位失主、重复归还、钥匙猜 car／house、徽章、印章、拉杆、点灯或“再点一次播放”填充操作。
- 不把回访、同日回看、活动完成或停留时长冒充长期掌握。

## 16. 实现与验收的剩余门禁

主线课程结构、教材覆盖、二十九份结果、声音／词形节奏、纠错、恢复、音频、地标、跨日回访冒险心、双画幅交互、六类冻结构图、十七阶段主构型／场景呈现段映射和关键动效分镜的设计问题均已闭合。`L49B-01` 的互动模式接口由 ADR-0109 冻结；ADR-0112 取代 ADR-0110 中 Lesson 1 的旧短角色换位条款，并冻结必修双角色阶段与无字逐句回演；ADR-0113 取代旧路线终幕；ADR-0114 进一步冻结最短语义点击、原子阶段回看与稳定人物舞台；ADR-0110 对单元案件复盘仍有效。

## 17. 教师投屏第二阶段

教师投屏不进入当前儿童候选的完成门禁。只有儿童独立主线通过同一 SHA 自动门禁、成人完整流程和目标年龄儿童观察后，才开始第二阶段设计与实施：

- `core/course-catalog.js` 只声明投屏是否可用、路由和发布状态；
- `core/curriculum-catalog.js` 拥有本单元教师步骤、课程语言、角色、提示与音频引用；
- 共享投屏渲染器只消费 catalog，不复制 Lesson 1–2 内容；
- 教师的播放、提示、上一步、下一步与角色分配不访问或写入孩子的主线、回访、心池、结果、掌握或设备档案。

第二阶段需要独立验收包与授权；本蓝图不把“已规划”写成“已实现”。
