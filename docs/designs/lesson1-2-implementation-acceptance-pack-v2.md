#### 2.4.3 `I03`｜课程资源与交互性能预算（2026-09-01）

- 性能验收分别记录 Fast 4G 冷缓存、正常网络暖缓存、本地验收预览和正式发布地址；任一环境的快速结果不能替另一环境作证。
- 首次打开教学单元时，180ms 内显示不依赖完整课程 runtime、字体或美术的真实整课准备界面；500ms 内完成课程版本与本地完整包判断。同一浏览器、同一版本且缓存未被清除时，1s 内直接交接到学习者稳定状态。课程更新、浏览器淘汰或用户清理缓存不属于同版本暖包重开。
- 整课准备页复用现有 `assets/adventure-map/mascot/loader/frame-1…4-route-page-20260806-01-*` 探险猫整理地图画面，并把四帧轻动画放在大进度条上方作为主视觉；该动画只表达系统仍在工作，真实百分比仍只由已校验字节决定。四帧属于全课程共享轻量启动壳，不得等待 Lesson 1–2 整包后才加载，也不得阻塞 180ms 入口反馈；画面位置预先保留，稍后解码不得推动进度条或文案跳动。
- 同版本暖包判断期间不循环播放猫猫加载动画，只显示静态猫猫和唯一动态状态；启用减少动态效果时固定现有第二帧。不得为每个教学单元复制另一套加载角色，也不得用动画循环、帧数或固定时长冒充下载进度。
- Lesson 1–2 整课资源包覆盖十七阶段、主线回看、可选练习与恢复表面所需代码、样式、字体、图标、全部教学音频、横竖屏必要画面和当前浏览器首选兼容图片；不下载其他教学单元、美术母版或 AVIF/WebP/JPG 重复格式。Catalog 按教学单元拆分，中文字体按本单元实际字符生成子集，共享运行时和其他公共资源按内容哈希复用；不在首次进入网站时下载全部课程，也不牺牲已确认的字体风格。
- 大进度条按实际下载并保存的字节计算，依次区分检查、下载与校验；孩子端显示真实百分比和唯一动态状态，不展示资源文件名、答案物品、MB 明细、机制说明或不可靠的剩余时间。文件只排队、请求返回但未保存、按文件数量完成或模拟计时均不得增加真实完成百分比。只有本版本全部资源逐项校验、写入版本化 Cache Storage 并原子激活后才能显示 100%，随后立即按稳定学习状态交接，不增加“准备完成”说明或“开始课程”确认门。
- 首次安装允许随真实资源量和网络速度持续，但不得进入半成品课程；连续 3s 没有新字节时显示“网络有点慢”，连续 10s 无进展或重试失败时开放继续下载、重试和返回课程地图。孩子返回课程地图时停止未完成的后台下载，已经校验的资源必须保留，再次进入同一版本时从真实完成量续传。禁止空白页、无限转圈、虚假进度、失败后从零重来、离开后静默耗流量或偷偷切入流式课程。
- 完整包激活并进入学习状态后，本单元课程资源网络未命中数必须为 0。整包字节保存在版本化缓存中，浏览器只滚动解码当前与下一阶段：孩子操作后 100ms 内出现响应，下一阶段 350ms 内完整呈现，已准备教学音频 150ms 内开始；正常语言播放与有可见进展的故事动画时长不计为卡顿。
- 活跃交互期间不得出现空白帧、超过 100ms 的主线程停顿或画面间隔。若已激活包仍出现资源缺失或损坏，保留上一稳定故事画面和学习进度，显示明确恢复路径并把候选判为红灯，不得在孩子点击后静默联网补齐。
- 同版本重开由版本化 Cache Storage、Service Worker 和完整包标记共同支持；命中完整包时只短暂显示“正在检查”，不得重播 0→100 的假下载动画，并在 1s 内直接恢复稳定学习状态。存储持久化申请可以降低浏览器淘汰概率，但不得承诺用户清理数据、浏览器主动淘汰或课程版本变化后仍永久免下载。产品不得主动静默清除完整课程包。
- 新课程版本下载到独立缓存，只补齐变化资源；全部校验成功后再一次性切换，失败时继续保留旧完整版本和已验证的新包进度。课程结束后可以让用户主动选择提前准备下一教学单元，不自动下载整套后续课程。
- 课程包是性能与资源完整性机制，不在本轮顺带宣称正式离线课程；离线启动、学习进度可靠性、版本恢复与设备存储管理必须另有设计和验收，不能由“资源已缓存”自动推导为通过。
- 自动与发布门禁必须覆盖资源清单完整性、内容哈希与字节总量、首选格式去重、冷安装真实进度、下载中断续传、资源损坏、原子更新、同版本暖包 1s 重开、直接进入稳定学习状态、真实图片解码、真实音频开始，以及进入课程后课程资源网络未命中数为 0。正式发布地址的 Service Worker scope、CSP、压缩与缓存响应头需要读回；自动全绿仍不能替代真人完整走课。
- 2026-09-01 只读反馈回路中，普通本地入口 DCL 约 115ms、FCP 约 504ms；Fast 4G 冷缓存下开始按钮约 6.8s 才出现、全部入口资源约 10.2s 完成。当前 Python 预览不压缩文本资源；入口 HTML/CSS/JS 约 1.01MB，Brotli 内存估算约 154KB。同条件的临时 Brotli 服务对照把开始按钮降到约 1.61s，但首次内容绘制仍约 1.44s，因而入口可操作与 180ms 准备反馈是两条独立门禁。
- 字体与 AVIF 已是压缩资源，再做 gzip/Brotli 几乎无收益；单个中文字体约 726KB。单独阻断该字体只将 Fast 4G 入口从约 6.8s 降到约 6.0s，它是带宽竞争因素，但不是未压缩预览的唯一主因。正式发布地址的压缩、缓存和协议尚未核对，不得用临时对照宣布发布门禁通过。

- 十八幅首选画面若同时解码，RGBA 基础占用估算约 51.6MiB，尚未计入浏览器对象、GPU 纹理、音频与页面开销；这支持“全部字节缓存、当前与下一阶段滚动解码”，不支持把整课图片同时解码并长期常驻内存。
- Lesson 1–2 当前没有“当前／下一阶段图片请求 + decode”合同：图片只在对应 moment 渲染后发起请求。在 Brotli 入口一就绪就立即进入故事的 Fast 4G 样本中，244KB 首幅图点击后约 3.39s 才完成，超过 1.5s 冷请求上限；同会话回访命中缓存则接近即时。

- 实施前基线：暖缓存三轮交互观测的 Long Task 均为 0，rAF 最大间隔分别为 216.6ms、16.8ms、16.8ms；不能稳定复现的单次异常保留为监测项，不得写成已确认的主线程根因。当时 I03 仍为红灯，尚未修改实现或补入仓库性能测试。

## 4. 退出条件

只有以下条件全部满足，才可把状态改为“本地候选已通过成人验收”：

1. 所有计划合同转绿，`QA-MUST-01` 零闪烁自动门禁与同候选真人整课巡检均通过，且 `git diff --check` 无格式错误；
2. 单元、全部 E2E、部署合同、`verify:v1:release` 与静态构建来自同一候选 SHA；
3. 环回地址主课与跨日回访均返回 200，并完成一次真实成人全流程操作检查；主课至少覆盖竖版与 16:10 宽版、一次直接意图点击、两级错误支架、人物职责、阶段回看原子切换、主题重听图标、上车／到家标准动效与减少动态效果；
4. 完成最终语音包的逐条真人听审；自动哈希、speaker 与文件覆盖合同不能替代听感验收；
5. 明确记录分支、候选 SHA、远端同步状态，以及“未合并 main、未发布”；
6. 将目标年龄儿童观察继续列为独立待办，不把成人通过写成儿童通过。
