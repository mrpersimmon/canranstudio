### 2.5 `QA-MUST-01`｜零闪烁（发布阻断）

- 每一个新候选都必须重跑名称含 `QA-MUST-01` 的自动回归，不得沿用上一个版本的绿灯。
- 同一阶段内的重听、真实 `audio/ended`、答错、答对、支架、设置、阶段地图开合与画幅切换，必须保留 `.station-world`、`.scene-frame`、`.mission-console` 及未变人物／道具／`picture`／`img` 的 DOM 身份，不得重播 `console-rise` 或 `character-card-arrive`。
- 真实阶段、主线／回看与页面边界可以原子重建，但中间不得出现空白舞台、后备背景、人物或题面瞬时消失再出现。
- 必检画幅为 `1280×720`、`1440×900`、`390×844` 与 `844×390`；自动节点门禁之外，仍必须保留一次真实浏览器整课视觉巡检，用于发现 GPU 合成或图片解码引起的瞬时闪屏。
- 任一自动或真人项出现闪烁，候选立即阻断；HTTP 200、内容校验或其他绿灯不得替代本项。
