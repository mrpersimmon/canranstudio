# 十二城区课程地图草案

## 依据与约束

本草案依据外研社《新概念英语智慧版 1》的目录与课程使用说明整理。教材包含 Lesson 1-144；奇数情境课与紧随其后的偶数操练课构成一个教学单元。

- 教材顺序不变，共十二个城区。
- 每城区连续十二课，共六个教学单元。
- 每城区三张路线册页，每页连续四课。
- 每课一个独立地标；奇偶配对地标相邻，但不合并建筑。
- 城区面向孩子使用冒险主标题，同时配套 Lesson 范围与教材内容副标题。
- 下列册页名和地标名仍是内容结构工作名，美术定稿前可调整措辞。
