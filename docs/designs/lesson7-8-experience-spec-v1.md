## 1. 一句话体验

孩子参加午夜职业茶会，先听 Robert 与 Sophie 交换姓名、国籍和职业，再用同一套交流方式认识十种职业，完成声音—人物—职业词—完整问答的迁移。

## 3. 儿童文案与公平性

- S01 顶部不得出现 `policeman`，教材答案只在完整听读后由孩子选择。
- S05 场景人物就是唯一候选；面板不得再复制一组人物卡。
- S08 答前只显示等尺寸职业图和声音入口，不显示英文或中文职业名。
- S10 指令只说“选择适合的职业问题”，不得写出当前正确职业。
- 错误支持按“重听 → 非答案关系提示”两级处理；不扣心、不变暗错误外的候选。

## 4. 直接意图与页面节奏

1. 只用点击或触摸，不用拖拽、多步确认或答案提交按钮。
2. S03、S07、S08、S09、S10 的内部轮次全部同屏连续完成。
3. 正确后立即在原场景播放目标英语；音频结束后自然进入下一轮。
4. 所有重播按钮与其英文同屏；播放中不能叠播，也不能令人物或背景重挂载。
5. 职业图既是视觉候选，也是故事实体；面板不复制第二套选项。
