# 前六课首页发布

2026-09-06，用户明确要求将 www.canranstudio.cn 的旧页面下线，只部署当前前六课版本，并让域名首页直接进入学习路径。

## 发布范围

- 首页使用已验收的猫猫小镇 V4；教学内容、画风、正常速度音频和进度记录规则保持。
- 发布包由当前课程的 199 项资源依赖、根目录首页、课程清单组成，不发布旧课程 HTML 或旧首页。
- 首页的课程清单作用范围派生为 `/`，重新计算摘要；本地 `/poc/learning-path/` 预览清单不修改。
- 旧 HTML、目录入口和无扩展名入口跳转到 `/`；不再需要的旧资源返回 404。
- 复用当前域名、TLS 证书和服务器。替换已读取核对的 `/etc/nginx/conf.d/lesson49.conf`，移除其中旧课程和演示入口。
- 旧主站、旧独立课程的文件保留在服务器作回滚备份；新配置不公开它们。另一个域名的演示站不属于此次修改范围。

## 发布与回滚

`scripts/build-learning-path-release.js` 只从已提交且逐字匹配 HEAD 的来源生成发布包；部署脚本逐项复核文件清单和 SHA-256，拒绝额外 HTML、链接、特殊文件与不一致的服务器配置。

发布使用 `/var/www/canranstudio-learning-path/releases/` 和原子 `current` 链接。激活前备份原站点配置和完整有效配置至 `/var/backups/canranstudio/`；校验配置后重载，并检查首页字节。失败自动恢复原配置与学习路径链接。

人工回滚应读取对应备份中的 `activation.json`，还原同目录 `lesson49.conf` 到原配置路径，验证 Nginx 后重载。旧主站根目录与旧课程根目录均未删除或移动。

## 验收

发布前 431 项单元检查通过，包括首页作用范围、依赖完整性，以及未提交／已更改文件拒绝发布的检查。原本完整课程的本地真实页面验收见 `design-qa.md`。线上检查结果在激活后补记；AI 音频逐条人工发音验收仍按原记录区分，不以发布成功替代。
