## 五项视觉检查

1. **字体与层级**：保留原中文系统字体和英语圆润字体；标题、对话、选项、辅助标签保持主次。姓名与英语正文未裁字；长问题已缩短，冠词例子完整显示。未替换成未经授权的 Duolingo 字体或品牌素材。
2. **间距与布局**：桌面正文宽度继承约 690px；主操作保持底部固定。课堂、交接、图片题和语法题在最短已测视口均能看全主要选择。参考全文允许正常滚动，历史区保留单独滚动与焦点访问。
3. **颜色与状态**：沿用灰绿底 `#dfe6df`，深色文字 `#2c4035`；蓝色用于可操作候选与选择，绿色用于主操作与成功。选择前不会用绿色泄露正确答案。选中、禁用、播放、正确、重试可区分。
4. **图像与图标**：所有新角色原图与浏览器缩小后的呈现均已查看。全身、耳朵、脚和尾巴完整。Hans 光晕稿已替换为白底 v2；白底素材通过既有 multiply 处理融入画面，不宣称是真透明。衣帽间有明确柜台、外套和伞桶。继续采用现有图标库，没有用 emoji、手画 SVG 或 CSS 形状代替角色和教学图片。
5. **文案与内容**：只保留当前学习任务与必要的知识例子。a/an 的例子属于学习内容而非操作说明。长条记录按需展开；慢速入口及资源均未引入。完整原课文、人物姓名和代词保持。
