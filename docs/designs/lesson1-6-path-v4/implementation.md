# 前六课连续学习路径 V4

现行设计，2026-09-06。独立分支：`codex/duolingo-version`。本地入口：`http://127.0.0.1:42817/`；线上版本的发布记录见 [publication.md](publication.md)。

沿用用户已经确认的 V3.6 可操作性设计：灰绿背景、蓝色有底边的作答控件、绿色主操作、完整猫猫、正常速度语音、逐句手动推进。教材 Lesson 编号保留为来源索引，学习路径按交际目标组织。

共 11 个路径节点；包含 4 段互动故事、11 组手动学习卡、37 个有记录的作答活动，其中 3 个为明确标识的辅助练习。故事父活动和内嵌检查合计 52 个活动标识，不把它们呈现成 52 个小关卡。页面上的时长是设计预算，尚非儿童实测时长。

Lesson 1、3、5 的 39 句原课文逐句进入主线，每句只出现一次；Lesson 5 在介绍 Naoko 后自然分段。学习卡与后续应用允许再次听到同一个词句，作为复现而非额外首次考察。Lesson 4 与 Lesson 2 重复的十种物品不再全量重教；原文、单词、替换例句、原有笔记和练习指令在“课本回顾”中可展开查看。

## 角色和题目公平性

新增 Mr. Blake、Hans、Naoko、Chang-woo、Luming、Xiaohui 六个完整猫猫角色；Sophie 沿用已有白猫。老师介绍同学、同学向 Sophie 问好时，三者共同在场，当前说话者有明确名字状态。人物身份、姓名、原文代词与国籍保留，不以毛色、服装考国籍。son/daughter 卡明确写出亲属关系。衣帽间使用新绘制的寄存柜台、衣架、伞桶整体插画。

作答控件保持蓝色、边框、底边与选择标识；正确状态再转为绿色。图片选择和检查按钮含义分开。对话回顾是按需滚动的历史区域，当前完整一句保持可读。短屏缩短历史区和图片高度，所有猫猫保持完整轮廓。语法选项同排呈现，移除题目已经说过的重复人名。

## 进度与复习

新课程记录：`poc:learning-path:NCE-STARTER-06:lesson1-6-v4.0`。

首次打开新路径时，只从有效的 V3.6 前两课记录导入语义不变的活动、原始作答证据和逐句故事记录。旧记录完整归档到新记录，同时原存储键保持不变。实际用户预览已确认导入 3 个完成节点，新任务从第 4 关继续。导入后由新路径独立保存，不回写旧记录。本分支仅保留旧记录导入所需的契约与测试快照，不再提供旧页面。

逐词听完会保存，未触发音频结束的词不算听完；刷新后继续未完成任务。首次作答、提示、错误和已完成关卡的重练分开处理。重练不覆盖首次学习记录。

固定综合复习是第 6、11 个路径节点。间隔复习依据到期日与原作答表现选取最多四题，同一目标一轮只取一次，间隔为 1、3、7、14、30 天；不成功则次日再练。必须依赖原故事上下文的新内嵌问题不直接拿出来裸测，使用带完整线索的独立复习变式。复习事件单独保存，不把后来的答对改写为首次独立答对。

## 实现边界

- `content/learning-course.json` 是编写内容的唯一入口，持有教材正文、录音映射、课程顺序、题目、角色关系和复习规则；`content/textbook-sources.json` 保存前六课原句的固定核对基准。`core/learning-course-catalog.js` 提供读取与校验接口，不依赖旧的课程总目录。
- `core/learning-path-runtime.js` 处理连续路径、迁移、手动语音事件、跨课复习和恢复；`core/learning-path-scene.js` 负责共享呈现。
- 当前入口和附加样式位于 `poc/learning-path/`。共享视图与素材仍使用 `poc/lesson1-2-experience/` 目录名以维持线上资源地址，旧独立页面已移除。浏览器的 catalog 接口由安装器从生成的课程包提供，页面不编写教材内容。
- 课程包启动文件按内容摘要命名。`npm run build:course` 从当前 catalog 与页面依赖生成课程包；`npm run dev` 和正式发布共用单首页生成逻辑。生成的 catalog 不手动编辑。
- 当前使用的猫猫、道具原始生成图与提示词随对应素材保留。Hans 使用 v2，不保留已淘汰的光晕稿。
- 新课程包 199 项资源，3,256,201 字节；正常速度录音的原始字节保持，不包含任何慢速录音资源。
- 旧网站、旧课件运行代码、无关设计与构建工具已从本分支工作树移除；原 Git 历史和其他分支保留。清理细节见 [分支整理记录](branch-isolation.md)。
