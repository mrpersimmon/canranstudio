# 小学新概念英语游戏化课程设计纲领 V1

> 一句话纲领：先让孩子知道“为什么要说”，再让他听懂、行动、想起并换个情境使用；让游戏世界奖励真实学习，不用难题、包装或重复点击冒充学习。

## 1. 唯一目标

面向六至八岁儿童，把教材中的英语变成孩子能独立完成、愿意继续、能够在真实情境中调用的故事行动。精致画面、动效和奖励服务于理解与坚持，不替代学习本身。

## 2. 教学单元的弹性学习节奏

以下是课程团队组织学习依赖的内部节奏，不是儿童端固定栏目：

**建立任务目的 → 整体输入与语篇建义 → 有选择地提取与检索 → 用语言完成整合故事行动 → 跨日变化情境独立调用**

各环节可以按教材合并、穿插或回返。固定的是学习依赖与证据诚实，不是儿童页面、阶段数量、小游戏顺序或固定五幕。

- **建立任务目的**：先交代地点、人物、发生了什么、孩子为什么要参与；不让台词凭空出现，也不提前泄露答案。
- **整体输入与语篇建义**：保留教材话轮、人物和顺序，用画面与英文课文支撑理解；语言音频真实结束后才推进，孩子先用最小故事行动证明听懂。
- **有选择地提取与检索**：核心目标必须被主动想起，但不是每个 Source ID 都单独出题。词音与词形结果不能互相替代；首次主线默认抽样代表词，只有教学单元明确声明的材料级例外才在当天完成全量双通道。
- **整合故事调用**：完整语言块只在真正需要它的情境中使用；语法可以按“完整示范 → 孩子组织 → 变化对象近迁移”现场展开，但这些教学动作不自动各自产生正式结果。
- **跨日独立调用**：同日角色换位或故事复盘只能形成练习诊断；长期掌握来自后续学习日、变化情境、无支架成功。
- **动作忠于因果**：理解任务只执行回答问题所需的最小动作；不为增加点击或重复练习而无因果地重复同一交接，教材确有不同交际目的时可以再次交接。
- **互动必须真变化**：换背景不算换玩法；课程应避免让同一核心操作连续承载正式挑战。具体互动模式数量与连续上限由教学单元合同声明。
- **完成边界分层**：语言行动可以立即改变局部故事状态，完整微任务才原子保存，章节完成产生章节成果，完整教学单元保存并读回后才建设地标。

### 四项内部学习功能

课程团队必须用以下四项功能检查每个教学单元，但不得把它们机械显示成儿童端四关，也不得把“词汇词块”固定放在完整语篇之前：

- **语言材料建联**：把教材词汇与完整词块连接到声音、词形、物品意义和真实语境。
- **语篇建义**：让孩子理解人物、意图、话轮与因果，并用故事行动回答教材理解问题。
- **结构觉察与句型调用**：通过完整表达、句框和变化实例发现规律，再组织大词块完成交际；不先讲语法术语。
- **情境交际与迁移**：先在当前故事中造成真实结果，再改变人物、物品、线索或交际目的验证迁移。

四项功能共同经过“真实接触 → 形成性检索 → 匹配纠错 → 跨日独立调用 → 目标掌握”的课程掌握闭环。单元当日完成只证明孩子完成了首次学习，不等于长期掌握。

## 3. 八条不可妥协的原则

1. **先情境，后语言**：新的故事目的或语言用途出现前，孩子必须明白“发生了什么”和“我接下来要做什么”；已经建立的连续语篇不重复讲解前提。
2. **年龄决定复杂度**：一个画面只承担一个主要目的；中文提示短、具体、口语化；不要求语法术语、键盘输入、整段抄写或成人推理。
3. **先意义，后形式**：先用人物、物品和动作建立意义，再连接词音、词形和句子结构；不把单词表当课程主线。
4. **核心目标必有主动想起**：每个核心目标都有形成性检索，但不是每个 Source ID 都单独出题；教材接触、支架练习和独立证据必须分开。
5. **角色与声音必须忠实**：谁说、为什么说、由谁的声线说，都与教材和当前情境一致；不让一人说完双方台词，不让错误角色代说。
6. **错误必须变成教学**：第一次错误给情境后果，第二次给聚焦线索，第三次由伙伴换例示范；最终仍由孩子完成，不使用红叉、羞辱、无限猜测或游戏结束。
7. **游戏反馈必须有因果**：孩子的语言行动让物品归位、人物回应或线索改变；普通答对使用轻反馈，完整微任务才原子保存，章节完成才产生章节成果，完整教学单元保存并读回后才建设地标。
8. **课程事实只有一份**：教材文字、任务文案、答案、角色、支架和音频映射只存在于 catalog；页面只渲染，运行时只判定与保存。

## 4. 视听与交互标准

- 画面采用精致、统一、有材料感的故事世界；同一人物跨场景保持统一身份照片，人物存在时必须可见，不得回退为 emoji；教材物品也使用与场景材质、光影一致且由 catalog 管理的透明插画，不使用平台 emoji 或页面临时配图。学习者始终是全站同一只探险小猫，不为每个课程另造儿童主角。小猫只在承担开场引导、伙伴救援、孩子角色或阶段庆祝时进入画面并拥有足够视觉尺寸，不作为每页固定贴纸；同一时刻只有一个视觉焦点，动效用于说明因果、方向和成果。
- 同组、同义、同层级的装饰图标必须使用同一轮廓；颜色、尺度和动效可以建立视觉主次，但不得借不同图形制造课程没有声明的状态差异。
- 英语台词、词音和必要反馈拥有最高听觉优先级；未审核或令人分心的背景音直接不上线。
- 所有主线语言音频持续显示 catalog 对应单词或句子；同步词形支撑不能冒充纯听力证据。
- 答对后若需要播放单词、句子或角色回应，交互必须连续：视觉确认后立即播放英语，播放完自动推进，不再要求孩子点一次喇叭；英语之前不得插入提示音、旋律或点击声。
- 纠错与提示必须附着在当前任务面板内，并使用故事世界中的签条、印章或角色动作表达；不以悬浮系统 Toast 遮挡人物，不使用脱离配色的黑色状态图标。
- 主路径优先点按，关键触控区不小于 48×48 CSS px；拖动只能增加乐趣，不能成为理解或通关门槛。
- 正式语义行动本身直接提交，不追加通用确认按钮；具体使用点按、放置、连接或组装由教学单元交互合同决定。
- 若教学单元采用角色换位或同日故事复盘，它们必须自愿、非评分、不阻塞，也不能冒充口语、跨日证据或掌握。
- 每个微任务约三十至九十秒，每个连续学习段通常约六至十分钟；较长章节可以用段落停靠点拆成两段，章节总时长由单元合同声明。中断后从最后一个完整微任务恢复，不恢复半道音频或动画。
- 尚未声明书写目标的低龄单元可以把教材抄写作为纸笔或平板手写可选拓展，但它不进入儿童必做主线，不使用手机键盘代替，也不产生单元完成、地标成长或核心目标证据。

## 5. 四条红线

- 不把课程难度抬到教材之外，更不把小学课程做成中学语法考试。
- 不让孩子在不知道故事前提时直接面对台词、题目或按钮。
- 不用播放时长、动画结束、点击次数或当天答对伪造听完、证据或掌握。
- 不让占位音频、未审核声线、重复操作和纯装饰动效进入儿童正式主线。

## 6. 验收只问五件事

1. 孩子能否用自己的话说出“发生了什么”？
2. 不靠成人解释，他是否知道下一步要做什么？
3. 每个核心目标是否真的被主动想起，并得到匹配的纠错？
4. 角色、声音、动作、保存和成长是否忠实且可解释？
5. 学完后，孩子是否愿意再进入下一场冒险？

## 7. 规模化生产规则

本纲领是后续教学单元的默认母版。课程团队从教材直接完成来源核对、弹性学习节奏、故事改编、语义互动模式、微任务设计、语音包制作和验收；产品负责人只审阅最终体验与真正改变目标、证据、年龄、画风或奖励边界的重大例外，不再逐按钮重复决策。

教师投屏路径若被纳入某教学单元，必须从同一份课程事实派生，且不能写入孩子个人学习证据或补足儿童独立主线。具体实施时序由教学单元验收合同声明。
