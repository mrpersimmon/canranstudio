# 小学新概念英语游戏化课程设计纲领 V1

> 一句话纲领：先让孩子知道“为什么要说”，再让他听懂、行动、想起并换个情境使用；让游戏世界奖励真实学习，不用难题、包装或重复点击冒充学习。

## 1. 唯一目标

面向六至八岁儿童，把教材中的英语变成孩子能独立完成、愿意继续、能够在真实情境中调用的故事行动。精致画面、动效和奖励服务于理解与坚持，不替代学习本身。

## 2. 一节课的固定主线

**故事前提 → 完整听读 → 理解行动 → 词音检索 → 词形检索 → 交际调用 → 变化迁移 → 整幕成果 → 跨日回访**

- **故事前提**：先交代地点、人物、发生了什么、孩子为什么要参与；不让台词凭空出现，也不提前泄露答案。
- **完整听读**：保留教材话轮、人物和顺序，用画面与英文课文支撑理解；语言音频真实结束后才推进。
- **理解行动**：孩子先用归还、选择、排列等故事动作证明听懂，而不是先读规则或答语法题。
- **动作忠于因果**：理解题只执行回答问题所需的最小动作；“是谁的”只选主人，不提前搬动物品。同一件物品只在故事真正归还时交接一次。
- **双通道检索**：每个核心词最终分别经历“声音主导、词形支撑地找物品”和“独立看词形找物品”，两种结果不能互相替代；首次主线只抽样代表词，另一通道与未抽中词分散到跨日回访，不在当天堆满全部格；纯听力证据必须由另行隐藏词形的回访产生。
- **交际与迁移**：完整语言块只在真正需要它的情境中使用，再换人物或物品验证孩子能否迁移。
- **成果与回访**：完成整幕才改变场景或地标；当天完成不等于掌握，长期掌握来自跨日、变化情境、无支架成功。

## 3. 八条不可妥协的原则

1. **先情境，后语言**：每段输入前，孩子必须看懂“发生了什么”和“我接下来要做什么”。
2. **年龄决定复杂度**：一个画面只承担一个主要目的；中文提示短、具体、口语化；不要求语法术语、键盘输入、整段抄写或成人推理。
3. **先意义，后形式**：先用人物、物品和动作建立意义，再连接词音、词形和句子结构；不把单词表当课程主线。
4. **核心目标必有主动想起**：每个核心目标都有形成性检索，但不是每个 Source ID 都单独出题；教材接触、支架练习和独立证据必须分开。
5. **角色与声音必须忠实**：谁说、为什么说、由谁的声线说，都与教材和当前情境一致；不让一人说完双方台词，不让错误角色代说。
6. **错误必须变成教学**：第一次错误给情境后果，第二次给聚焦线索，第三次由伙伴换例示范；最终仍由孩子完成，不使用红叉、羞辱、无限猜测或游戏结束。
7. **游戏反馈必须有因果**：孩子的语言行动让物品归位、人物回应、房间点亮；普通答对轻反馈，完整微任务才保存，完整整幕才增长世界。
8. **课程事实只有一份**：教材文字、任务文案、答案、角色、支架和音频映射只存在于 catalog；页面只渲染，运行时只判定与保存。

## 4. 视听与交互标准

- 画面采用精致、统一、有材料感的故事世界；同一人物跨场景保持统一身份照片，人物存在时必须可见，不得回退为 emoji；教材物品也使用与场景材质、光影一致且由 catalog 管理的透明插画，不使用平台 emoji 或页面临时配图。学习者始终是全站同一只探险小猫，不为每个课程另造儿童主角。小猫只在承担开场引导、伙伴救援、孩子角色或阶段庆祝时进入画面并拥有足够视觉尺寸，不作为每页固定贴纸；一幕只有一个视觉焦点，动效用于说明因果、方向和成果。
- 英语台词、词音和必要反馈拥有最高听觉优先级；未审核或令人分心的背景音直接不上线。
- 所有主线语言音频持续显示 catalog 对应单词或句子；同步词形支撑不能冒充纯听力证据。
- 答对后若需要播放单词、句子或角色回应，交互必须连续：视觉确认后立即播放英语，播放完自动推进，不再要求孩子点一次喇叭；英语之前不得插入提示音、旋律或点击声。
- 纠错与提示必须附着在当前任务面板内，并使用故事世界中的签条、印章或角色动作表达；不以悬浮系统 Toast 遮挡人物，不使用脱离配色的黑色状态图标。
- 主路径优先点按，关键触控区不小于 48×48 CSS px；拖动只能增加乐趣，不能成为理解或通关门槛。
- 答案点按本身直接提交，句块放满自动判定，物品交接在点完物品与场景人物后直接成立；不追加“就是它”“就说这句”“排好问句”或通用确认按钮。
- 每个微任务约三十至九十秒，每个章节约六至八分钟；中断后从最后一个完整微任务恢复，不恢复半道音频或动画。

## 5. 四条红线

- 不把课程难度抬到教材之外，更不把小学课程做成中学语法考试。
- 不让孩子在不知道故事前提时直接面对台词、题目或按钮。
- 不用播放时长、动画结束、点击次数或当天答对伪造听完、证据或掌握。
- 不让占位音频、未审核声线、重复操作和纯装饰动效进入儿童正式主线。

## 6. 验收只问五件事

1. 孩子能否用自己的话说出“发生了什么”？
2. 不靠成人解释，他是否知道下一步要做什么？
3. 每个核心目标是否真的被主动想起，并得到匹配的纠错？
4. 角色、声音、动作、保存和成长是否忠实且可解释？
5. 学完后，孩子是否愿意再进入下一场冒险？

## 7. 规模化生产规则

本纲领是后续教学单元的默认母版。课程团队从教材直接完成来源核对、故事改编、微任务设计、语音包制作和验收；产品负责人只审阅最终体验与真正改变目标、证据、年龄、画风或奖励边界的重大例外，不再逐按钮重复决策。
