# 课程与纪念册柔和过渡

2026-10-30，`codex/book-version`。承接本轮此前的[身份导航与共享我的修复](2026-10-30-登录导航与共享我的修复.md)，按用户确认的“导航保持稳定、内容轻柔交叠”实现。工作区未提交、未推送、未发布。

## 已实现的体验

- 课程和纪念册使用同一个页面框架与React根节点；主导航保持原DOM，内容在目标准备好后接替。直接打开根路径或`awards/`也进入同一框架，`/`与`/lesson/`两种部署前缀均检查。
- 导航换色160ms；内容240ms渐显，地图整体／邮局内容轻移6px。旧画面保持不透明承接，防止两层同时淡出造成露底。固定品牌、导航和当前课程按钮不跟随地图位移。
- 先恢复目标滚动位置，再在下一帧启动动画；正常清理由`animationend`触发，1秒兜底只用于动画被取消。减少动态时取消淡化和位移。
- 等待目标时当前页仍可操作，160ms后显示轻量进度；失败可以重试／取消，连续改选只接受最后请求。原卡继续采用原60秒准备预算，页面总兜底80秒给接口与首屏准备留出空间，不把原卡慢下载误当作20秒超时。
- 返回恢复课程选择、地图与页面滚动；纪念册沿用原主卡／章节记忆，并恢复页面和侧栏位置。浏览器前进／后退、刷新、直接URL保持可达。位置按学生及升级epoch隔离，不在历史状态中存储卡面或成绩。
- 学生401或身份／epoch变化立即撤掉旧个人内容。预备页不可交互、不弹窗，也不提前消耗课程满星庆祝。初次进入或隐藏恢复仍先确认身份，不能拿缓存中的个人画面冒充当前身份。

软导航仅接管普通同源点击的课程／纪念册入口。教学单元、老师入口、改密、历史原证、外站、新标签和下载保留原生导航。HTTP授权、API成绩、首次日期和原GIF规则不变。

首次失败保留，未把失败批次写成通过：

1. 原实现准确复现整页重载：跨页后文档标记丢失。新的专项断言文档标记及导航节点身份都保留。
2. 直接纪念册入口没有课程状态节点，旧的后台字体初始化误把它当课程页。改为跟随实际显示的课程视图启动，并对缺失节点作保护，复验直接入口通过。
3. 共享文档引入旧portal的按钮flex样式，使主卡内部宽高为0；接口、解码和可访问文本都有，但画面没有卡。实际目视发现后补了可见宽高断言，限定邮局重置作用域，修复通过。保留`output/test-transition-card-before`首错证据。
4. WebKit首次中间帧专项在768px只观察到准备→完成，固定240ms清理可能早于首个绘制机会。先恢复布局、下一帧启用动画、以实际动画完成清理后，Chromium／WebKit各自完整5项专项重新通过，原失败保留于`output/test-transition-webkit-final`，通过结果在`*-verified`目录。
