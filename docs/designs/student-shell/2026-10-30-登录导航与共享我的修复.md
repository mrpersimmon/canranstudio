# 登录导航、共享“我的”与手机目录修复

2026-10-30，`codex/book-version`，基于 `febf8d2c` 的本地修改。用户反馈来自官网，本轮在相同基线的隔离本地服务复现和修复；未操作生产账号或数据库，未提交、推送或发布。

## 根因与结果

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 从纪念册返回课程先闪登录 | 初始HTML无条件包含登录表单，`api/me`异步返回后才替换；网络异常也进入登录分支。 | HTML只含中性等待；学生身份明确401后才登录，网络错误原位重试。刷新、改密返回、旧学习码、浏览器后退共用状态判断，迟到请求受代次保护。 |
| 两页“我的”不一致 | 课程手机、课程电脑、纪念册分别维护弹层／下拉及样式，内容逐渐分叉。 | 抽取`student-ui/AccountDialog.jsx`、`Dialog.jsx`及强作用域样式。固定操作顺序、字体、尺寸和关闭方式；旧记录、历史收藏和纪念册动效语义一致。 |
| 首页范围下拉与全部课程重合 | 地图切换和目录定位成为两个并行入口。 | 删除手机和电脑的外部地图范围下拉及无用样式。保留全部授权课程、跨章搜索、目录内区间筛选与地图定位。 |
| 目录下拉出现大片空白 | 原生dialog外框和列表均能滚动，flex祖先的尺寸约束不足。393×852复现时外框scrollHeight约9300px；边缘滚动使外框scrollTop=852而列表仍为0。 | 外框`overflow:clip`，内部明确高度和`min-height:0`，仅列表滚动；零至三项短结果收拢。真实边缘滚动后外框仍为0，内部列表正常滚动，标题不消失。 |

关联检查同时修正了身份等待／连接失败被尺寸采集记为“其他页面”的问题。老师与学生会话分别确认：已登录学生访问老师入口时，管理接口的明确角色403仍可进入老师登录，不把学生会话当作老师会话。浏览器禁止存储时，共用动效偏好仍在当前页面生效；不承诺无法写入的偏好可以跨刷新保存。

原卡画面、姓名、星数、首次日期、授权和授星规则不变。本机旧记录只读匿名命名空间；不会认领、上传或读取其他学生私有队列。界面小字库按当前源码重建为774字符／124552字节，原卡完整字库保持不变，轮廓与度量校验通过。

首次失败保留在本地`output/test-student-shell-*`，没有把失败批次改称全绿：

1. 新测试复用的登录助手会打开目录；缩到手机后测试直接点击背后的“我的”／“全部课程”超时。改为通过关闭按钮或检查目录已打开状态继续，保留目录书签行为。
2. 手机WebKit不提供鼠标滚轮API。该端明确记录限制，仍验证外框拒绝程序滚动、原生焦点滚动到末项与可见操作；Chromium保留实际边缘滚轮验证，另有应用内真实滚动观察。不把这一检查称为实体手指滑动验收。
3. 移除下拉后，就绪助手从`getByLabel`改为读取地图`data-chapter`，原性能计数新增一次locator身份读取。断言明确“一次身份读取＋一次就绪快照”；原20种未就绪／空目录边界与等待门槛保留，独立复验通过。
4. 身份等待统计、老师角色403与禁止存储后的开关回弹均先由用例复现，再修复复验。无脚本测试保留“无凭据表单、可重新加载、URL无密码”，并核对noscript原始HTML；执行被禁用的Chromium未将noscript内容暴露为可见DOM，不冒记该提示的目视通过。

真实Android微信／夸克、实体软键盘、系统休眠后的页面恢复尚未重新实测；浏览器后退已测，不代表所有系统缓存恢复组合。没有运行全量CI，也没有新建线上或Sites候选站。
