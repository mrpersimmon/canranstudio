# Lesson 3–4 视觉与响应式系统 V2

状态：当前本地实现合同
适用修订：`lesson3-4-v2`

## 1. 核心画面

单元保持“夜晚星灯衣帽间”的故事书舞台。背景、柜台、来客、服务员和当前故事道具共同建立情境；羊皮纸只承载需要读或点的任务，不能重新变成覆盖全景的大型后台卡片。

识别元素：深蓝夜色、胡桃木、青绿柜台织物、黄铜 5 号牌、奶油羊皮纸。三颗冒险心是学习状态，不是装饰奖励；只在正式挑战中显示。

## 2. 桌面授课构图

- 设计目标：教师投屏或电脑近中距离观看，首先看清任务、选项与两个角色。
- 背景采用宽屏母版，人物固定在左右下方，顶部明显高于柜台台面。
- 人物可比手机更大并允许底部裁切；不能缩成桌边小摆件。
- 主任务字、选项字和按钮按授课距离放大；说明文字仍保持次级层次。
- 任务卡限制最大高度，短屏时内部安全滚动；主要动作和退出路径不能被裁掉。

## 3. 手机竖屏构图

- 背景采用独立竖屏母版，不缩放桌面画布。
- 人物缩小到只承担角色关系，不与任务争夺空间。
- 顶栏压成一行：单元短标题、紧凑进度入口、设置。
- 任务卡优先占据上中部；道具落在青绿台面接触线，不悬浮。
- 五项选择允许 3+2 网格；阶段地图单列、可滚动，关闭按钮始终可达。

## 4. 字体与交互尺度

- 中文展示：`ZCOOL KuaiLe`。
- 英文词与关键选项：`Fredoka`。
- 工具与说明：`Baloo 2`。
- 桌面主任务与选项大于手机同类字号，分别定义，不使用同一画布比例缩放。
- 所有可点击目标至少 48×48px；焦点使用高对比描边，不能只靠颜色。
- `prefers-reduced-motion` 下保留即时状态，不播放位移或装饰过渡。

## 5. 稳定节点与道具

首次挂载时创建：背景、两个人物、全部可能出现的道具、任务面板、心数、阶段地图。之后：

- 背景和人物节点不替换。
- 道具节点不重建，只改变是否可见、位置类与状态属性。
- 当前阶段素材解码完成后再更新任务；下一阶段只后台预热。
- 音频播放不触发全屏类名或图片地址变化。
- 道具使用相对柜台的锚点和固定 `contain` 方框；透明补边不能变成黑块。

## 6. 阶段地图

阶段地图是课程导航，不是关卡奖励：

- 完成：`已完成 · 回演`。
- 跳过：`已跳过 · 补做`。
- 当前：`正在学习`。
- 未来：`未到达` 且不可点击。

桌面两列，手机一列。打开后焦点进入标题或首个可用项，Escape/关闭返回进度按钮；回演与补做均显示明确会话横幅和退出动作。

## 7. 探险小猫与次日复习

小猫只在冒险心归零时进入主画面，并用换例示范解释“接下来怎么继续”；不能在普通正确反馈中反复出现。

次日复习复用同一场景色彩但减少主线人物与道具，让三条新线索成为唯一焦点。手机上三张物品卡必须保留足够图像面积和可读中文标签；文本选项改为纵向排列。复习心数与 `1/3` 进度并排，不与主线状态混淆。

## 8. 防止视觉回退的检查

- 桌面人物高于柜台，手机人物明显更小。
- 背景、人物和道具在连续操作中的 DOM 身份不变。
- 页面无整屏白帧、黑块、旧 UI 横幅或通用完成中间页。
- S07 五项图可辨认；S09 匿名候选不泄露；复习卡在 390×844 可辨认。
- 所有阶段标题使用冻结的十项短标题，细节放入任务文案。
