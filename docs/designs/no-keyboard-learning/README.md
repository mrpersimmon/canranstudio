# 无键盘作答与题型丰富化修正方案

日期：2026-09-10。状态：**本地实施与技术验收完成，实际结果见 implementation.md**。基线：`codex/duolingo-version` / `1c6c3e8` / `lesson1-144-v6.1`。

用户本轮要求：“制定修正方案：去除所有需要手动输入的提醒，基于 duolingo 的题型设计，补充更多其他的题型，丰富体验。”结合此前关于小学 1–6 年级、纸笔与线下课的讨论，本方案将“提醒”按“需要手动输入的题型及相关提示”理解。用户随后要求“请开始执行”，已按本方案开展全入口实施；实际完成情况与未确认项见[实施记录](implementation.md)。

## 1. 修正目标与范围

**所有学生答题入口均可通过点选、配对、词块组合和情境操作完成。线上重点训练听辨、理解、受支持的句子组织与情境应用；规范书写、无选项口头表达及较完整写作与线下课配合。**

需要一起处理：

| 范围 | 当前已核实的输入内容 | 修正动作 |
|---|---:|---|
| 主线 | Lesson 49–50 共 6 题 | 逐题保留目标、重设计操作和支持条件 |
| 选做挑战 | 73 组，580 题：221 填空、359 整句输入 | 全部改为混合题型的小镇挑战，仍然选做 |
| 跳级测试 | 592 条题库记录：221 填空、11 单词输入、360 整句输入 | 重建无键盘题库，保留范围和通过规则 |
| 隔日语法复习 | 3 道整句输入 | 用同目标的新情境题替换 |
| 今日复习、重练、刷新恢复、旧记录入口 | 可能重新调出上述旧题 | 升级后统一解析到新题；旧题只保留历史读取能力 |
| 文案与控件 | 输入挑战、填单词/写整句、英文答案框、重置输入挑战等 | 更新入口、题干、帮助、结算、重置与无障碍标签 |

上述共 1,181 条分入口配置记录，存在内容复用，**不是 1,181 道互不重复的学习内容**。旧目标必须有映射，但重复记录可以合并，不机械要求一题换一题，更不因题型变多而增加每个孩子必须完成的量。

范围包含所有年级和模式，不保留高年级强制键盘题或跳级输入例外。自由打字、屏幕手写均不成为必经任务；不另造逐字输入的字母键盘来替代原文本框。普通键盘的 Tab/Enter/方向键无障碍操作仍应支持。

## 2. Duolingo 参考与采用边界

遵循[设计原则](../../design-principles.md)，查阅已有[题型资料](../../references/duolingo/2026-09-05/用户提供-题型与学习活动汇总.txt)与本次[官方来源核对](../../references/duolingo/2026-09-10/no-keyboard-exercises.md)。

采用的是由明确目标组织短练习、稳定的检查/反馈/继续、逐步减少帮助，以及 Stories、DuoRadio、Adventures 中的情境应用方式。题型数量、分组数量、年龄支持档位和抽样配额均为本项目设计，不宣称是 Duolingo 的统一产品规则。

现有原则中“综合后提供输入挑战”和跳级文档中的“无词库输入”条款，需要在实施时更新为本轮用户要求。历史参考、旧版本答题契约与验收记录保留可追溯性，不能全局文本替换掉历史事实。

## 3. 建议采用的 12 种练习形态

以下是产品层面的划分，不等于要开发 12 个互不相干的组件；T12 是组合任务，其内部仍使用有明确答案的选择和行动。

| 编号 | 练习形态 | 学生动作与例子 | 本项目状态 / 采用方式 | 核心目标 |
|---|---|---|---|---|
| T01 | 看图选词／看词选图／看图选句 | 看手表选 watch，或看人物动作选描述 | 扩充已有图片选择；不再大量依赖中文译义选项 | 词形、图像与意义连接 |
| T02 | 听音选图 | 听 watch 后点手表；听句子后找对应场景 | 扩充已有听句找物 | 声音到意义；答题前不显示英文转写 |
| T03 | 音频—文字配对 | 点击音频，再点击对应英文词；一组少量配对 | 新增音文配对，复用配对反馈结构 | 声音与英文词形对应；最后一对按受支持表现记录 |
| T04 | 近音辨析 | 听已学词，从近音词中二选一；或判断两段声音相同/不同 | 新增；只选已教对比，原始音频通过人工试听后接入 | 识别声音差别，不记为发音达标 |
| T05 | 听音找关键词 | 听短句，选择确实听到的 2 个词或物品 | 新增明确数量的多选；选中计数清楚，选满不自动提交 | 从连续语音中识别已学词；不等同整句理解 |
| T06 | 听音词块组句 | 听一句话，按顺序点词块还原，允许撤回选择 | 新增听力变体，复用词块组件 | 声音分段和词序重建；不记为无提示听写 |
| T07 | 情境词块组句 | 看人物意图、图片或简短中文帮助，用词块完成表达 | 保留并扩充现有组句；减少逐句中文翻译作为唯一入口 | 在词库支持下组织语言 |
| T08 | 选词补句 | 为 He ___ chicken. 选择 likes；较熟练后选短语或分步补空 | 保留并改良；每一步聚焦一个差异 | 语境中的用词与结构判断 |
| T09 | 对话接续 | 角色提问，学生选择合适回应，角色接着说或行动 | 扩充已有情境接话；让回应影响后续情境 | 判断当前应该如何回应 |
| T10 | 听读短篇理解 | 听/读一小段，选择人物、事件、原因或合适概括 | 保留并扩充理解题；按基础逐步减少母语帮助 | 整合语篇信息，不只识别几个词 |
| T11 | 点词改错 | 点击句中需要修改的词，再选正确词形 | 新增儿童适配：组合词选择与选词补句，不宣称为 Duolingo 已核实的独立标准题型 | 定位并修正目标形式，避免重输整句 |
| T12 | 情境行动 | 听懂需求后选物品，再选接收者或位置；角色给出回应 | 借鉴 Adventures 的短场景任务；本项目采用确定性步骤 | 使用语言完成目的，检验理解后的行动 |

T01、T02、T07、T08、T09、T10 已有不同程度的基础；T03、T04、T05、T06、T11、T12 是新增机制、变体或明显扩展。既有图词配对、词卡、完整课文和互动故事继续使用，不把它们另算成新增题型。

### 每种题型的共同设计约束

- 正确答案、全部等义解、干扰项、顺序/配对规则、音频映射、先修条件与错误提示都在 catalog 中编写和审核。页面不临时编题，不从正确答案自动造无意义干扰项。
- 按需提供中文帮助；基础题优先用图片、读题音频和例子解释操作。听力题的转写、图片说明、播放器标签不能提前暴露答案。辅助技术若使用文本替代音频，应记录支持条件，不把它当作纯听力成绩。
- 纯语义题不能出现两个都合理的选项；组句维护所有允许的词序。词形题必须有足够语境，不能只凭单一标准译句判错。
- 正常播放和重听是听力题材料，不属于泄露答案的“提示”；文字转写、逐词揭示和提示另记。纯组句/语法任务在提交前不自动播放完整正确句。
- 配对和情境任务默认支持“先点对象，再点目标”；可以增设拖动，但不以精准拖拽作为唯一方式。命中区、选中轮廓、剩余槽位清楚。
- 多选明示“选 2 个”，允许撤销；计分单位预先定义。配对一组按一个活动记录，避免最后一对排除所得被计算成多个独立掌握点。
- 指令、状态、颜色和动效各有明确用途。未作答、选中、正确、重试、音频播放中要可区分。保留“作答 → 检查 → 反馈 → 继续”。
- T11 的错误句只出现在明确的改错任务中；完成后突出正确整句和正常发音，不反复朗读错误形式。

## 4. 现有输入任务的替换规则

| 原任务 | 首选替代 | 内容去留与能力标记 |
|---|---|---|
| 根据中文写英文单词 | T01 图词选择 / T02 听音选图 / T03 音文配对 | 同一词义目标保留，字形识别与拼写分开 |
| 键盘填单词、词组 | T08 选词补句；适合声音辨认时用 T02/T03 | 不把有选项的补全改记为自主拼写 |
| 整句翻译 | 根据目标选择 T06 听音组句、T07 情境组句、T09 接话或 T10 理解 | 不全部改成词块翻译；判断本题原来到底要考什么 |
| 整句改错 | T11 点词改错；初学者可用 T08 聚焦目标词 | 教师需要无提示改错证据时在线下单独检查 |
| 句型转换 | T07 情境组句 / T08 分步补全 / T09 对话接续 | 从实际意图进入，例如“替他问一问”，减少术语题干 |
| 听过/练过后的延迟输入 | 同目标不同场景的 T02/T07/T09/T10 | 保留间隔复习，重新记录新题的支持条件 |

### Lesson 49–50 六道主线题逐题处理

| 当前 ID | 当前要求 | 替换任务 |
|---|---|---|
| L49:grammar-s | 写出 likes | T08：在句框中选 likes / like，聚焦 he 对应的形式 |
| L49:grammar-correct | 重输 She does not like steak. | T11：定位 likes，点选 like；随后展示正确句 |
| L49:grammar-question | 把陈述句改成一般疑问句并换 any | T07：以“帮他问问是否想要卷心菜”为意图组句；首次用句框拆开 Does 与 want 两步 |
| L49:grammar-transfer-s | 翻译“她喜欢土豆。” | T01：看图选正确整句；图片必须明确喜欢与人物 |
| L49:grammar-transfer-base | 翻译“他不喜欢卷心菜。” | T09：在明确人物喜好的对话中选择否定回应 |
| L49:grammar-transfer-question | 翻译“她想要一些鸡肉吗？” | T07：换人物与食物场景组问句，减少支架但保留词库 |

所有替换使用新题目 ID，保留原目标 ID 和新旧映射。原来写作、改错、转换的成绩不因替换而追溯改写；新题明确属于选择判断或受支持组织。

## 5. 用三种组合活动连接练习

| 活动 | 体验设计 | 采用顺序 |
|---|---|---|
| 小镇故事 | 在原有完整课文和角色对话里安排少量接话、补句、归属与理解检查 | 第一批强化已有 Stories 结构 |
| 小镇电台 | 一段短节目/场景音频串联 2–3 个听辨和理解检查；基础版有适量中文支持 | 第二批引入 DuoRadio 思路；从现有已审核音频和短素材开始 |
| 小镇任务 | 找回物品、按需求购物、整理教室等；学生听懂后通过点击完成目的，角色回应行动结果 | 第二批引入 Adventures 思路；先做有限确定性模板 |

三个活动的名称和分组是本项目设计，不复制 Duolingo 品牌。剧情反馈也保留清楚的检查和可重试状态。先采用能实际完成的短任务，不把开放 AI 对话、语音识别评分或实时视频通话当成本轮依赖。

可以提供不计分的“自己先说一遍，再听示范”时刻，但不采集语音、不以点了“说过了”生成口语达标证据。真实对话由教师和同伴完成。

## 6. 编排与小学阶段适配

**题型为目标服务；同一个动作也可以很机械。** 不要求每个词走完全部 12 种形态，不用纯随机题型拼接课程。

- 普通练习关以 6–8 个短题作为设计起点，通常使用 3–4 种合适的形态；按实际耗时和内容密度校准，不宣称这是 Duolingo 的规则。
- 尽量不连续安排超过 2 道同一机制，同一目标通常经历“辨认 → 组织/回应 → 换情境使用”，错项进入既有间隔复习。
- 3–5 分钟只是普通短练习的起始估计，不强制裁剪完整课文来满足时长。原课文顺序、真实音频结束、逐句手动继续与恢复位点要求保留。
- 现有 354 个节点作为兼容骨架，优先替换或重组节点内部活动；确需调整节点时单独列映射，不能回锁老用户。
- 低基础优先 2–3 个清楚选项、少量配对和短词块；已有基础再增加选项差异、短语长度和情境信息。小学年级是参考，语言基础与独立操作能力优先。
- 高年级通过更丰富语境、更多干扰信息、较少提示增加挑战；全程仍无强制打字或手写。
- 不新增倒计时、手速排名或扣心式普通练习。跳级测试的五次错误规则保留。
- 错后先指出当前差别，再允许重试，最后换一个情境复习；避免靠连续复制同一答案过关。
- 原始教材继续完整可读可听。成人生活情境由教师补充背景，练习迁移可采用校园、书包、朋友、宠物等儿童熟悉场景，新增句子明确标为课程补充内容。

### 一组练习示意：失物招领

前提是相关词句已在课堂或先前课程引入；所有例子在实施时绑定实际 sourceRef，不能凭展示示例跳过先修审查。

1. 听一个物品词，选对应图片（T02）。
2. 完成一组音频—词语配对（T03）。
3. 听一句认领问句，用词块还原（T06）。
4. 根据人物是否为主人，选合适回应（T09）。
5. 在明确人物关系的句框中选 my / your（T08；只放在两词均已教的章节）。
6. 根据完整对话把物品交给正确角色（T12）。

这些是可选择的编排范例，不要求把相同六步机械复制到全部章节。线下拿真实物品互相询问；纸笔按课堂目标写标签或失物卡；课后线上换场景复习，避免三处重复做同样的抄写任务。

## 7. 选做挑战与跳级测试

### 小镇挑战

- “输入挑战 · 选做”改为“小镇挑战 · 选做”，“试试输入挑战”改为“试试小镇挑战”。
- 每组围绕原主题混合听力、配对、情境理解和组句；是否参加仍不影响主线。
- “填单词，写整句。试试不用选项提示。”改为说明当前任务，如“听一听，选一选，把学过的话用起来。”
- 重置、完成页、复习页、地图气泡和无障碍标签一起更新。历史挑战可查看原结果，但不重新打开键盘题。
- 不把旧 580 题全部机械转成词块；先按词义、句序、结构、语用目标归类，再选择上面的替代方式。

### 跳级测试

保留本项目既有规则：每次 20 题，第 5 次错误立即失败，题目来自目标章节之前；重点覆盖被跳过范围，通常约 70%，其余覆盖更早知识，无更早章节时全部来自跳过范围。范围、去重和跨跨度覆盖优先于题型配额。

- 采用听音选择/组句、语境补句、对话回应和情境组句/点词改错，适当混合至少 3 种可用机制；基础章节按可用已教内容调配，不强凑语法难度。
- 题目必须有已审定的候选项或词块；这些属于题型本身的支持。原“禁止词库”规则被本轮无键盘要求替代；仍不提供额外答案提示、提前显示正确答案或反复判分。
- 听力题允许正常播放和重听；题干音频本身不算作弊式提示。
- 每题只提交计分一次；复杂配对与多步骤冒险不直接塞进跳级，以免一次活动的计分单位不清楚。
- 使用新的题库与抽样版本；冻结已发生的旧判分。正在进行的旧键盘测试存档为“版本更新中止”，不算失败、不扣机会，重新开始新版本的完整 20 题，不混用旧输入题分数判定新测试通过。
- 老用户已通过的跳级、已解锁路线和真实学习记录保留。
- 通过说明仅代表满足本产品新路线测试要求；记录层不能继续把这类成绩标为无提示书写或自由口语能力。难度变化需要试做校准，不能声称与原输入测试完全等价。

| core/course-catalog-wire.js、课程包与媒体清单 | 保持传输无损；重新编译指纹，检查新元数据/素材的启动与离线成本 |
| tests/unit/、浏览器检查、docs/designs/readability-guard/ | 新题判分、迁移、题型覆盖、负向对照与真实页面证据 |
| docs/design-principles.md、挑战/跳级说明、根目录 design-qa.md | 在实施时同步新要求；验收前不写通过，不覆盖旧历史报告 |

推荐让题目定义集中在统一 catalog 内，由主线、挑战、复习、跳级引用题目 ID；支持条件与模式规则显式记录，避免复制几份答案后再次出现判分不一致。继续复用 choice / order / cloze / match，新增声音、多选、定点改错和情境步骤的必要能力；12 种练习形态无需对应 12 个独立运行器。

新作答数据使用选项 ID、顺序数组、配对映射或步骤状态，记录题目版本、目标、支持条件、重试、提示和实际播放情况。页面只负责展示和发送动作。

迁移原则：

1. **旧成绩保留，已完成节点不回锁。** 旧书写证据只读留存，不改成新题成绩。
2. 新题使用新 ID，并保存 oldQuestionId → newQuestionId / targetId / 处理原因映射。新增题不预先授予完成或掌握。
3. 未完成的旧挑战和主线草稿保留归档；恢复学习时转入对应无键盘任务，已完成部分作为历史完成事实保留，避免要求从全课程起点重做。
4. 到期复习依据目标映射到新题；保留到期日和错项线索，不再恢复键盘作答页面。旧错误文本可只读保存。
5. 已完成旧挑战仍显示历史完成，可自愿体验新版；不会要求做新版才能维持已解锁主线。
6. 未完成旧跳级按第 7 节存档并重新开始完整测试，不能自动判通过或扣心。
7. 迁移先备份、原子写入、读回验证。失败时保持旧数据可恢复；明确版本冲突，拒绝旧标签页覆写新记录。
8. 当前“independent/supported”若继续使用，必须结合题型支持条件解释；“未点额外提示”不等于无选项生成。记录页采用听辨、理解、组句等准确标签。

## 9. 素材与交互一致性

- 图词与情境题优先复用当前经过审核的词汇图、角色和原始音频。缺少关键图片/声音时明确排入素材工作，不用占位图交付。
- 新角色、物品或场景继续按用户要求使用 imagegen 生成迪士尼绘画风格，保持角色身份和原有透明素材规范。
- 近音题必须核对音素差异确实清楚；语速处理不能破坏对比。音频失败可重试或退出，不能无声判错或自动算完成。
- 地图、题内、复习、异常页保持同一深色主题；新题复用固定检查/继续、明显选项、完整猫猫和既有结算方式。
- 图片辨识度、选项中立性、正确状态、音频标签与可点击面积需在实际小尺寸检查。图片加载成功不等于可识别。
- 避免一次加载全册新插图与长音频。维持现有课程包启动预算与按需媒体策略，以当前构建结果校验，不能凭估计宣布性能达标。

## 10. 实施顺序与完成条件

这些是一个完整目标的开发批次。**仅完成试点不能宣称“全项目已去除输入题”；全入口切换和全量验收通过后才能交付新版。**

| 批次 | 工作内容 | 可审查产物 / 完成条件 |
|---|---|---|
| A：定义与替换清单 | 冻结当前题库，归类所有输入条目，制定目标映射、题型契约、文案和旧记录迁移规则 | 每个旧输入入口有去向；先建立可暴露遗漏入口/迁移失败的检查 |
| B：覆盖所有入口 | 先用适合的现有无键盘组件替换所有必经输入，接入统一判分、草稿和版本迁移 | 主线、挑战、复习、跳级、重练、恢复全部无自由文本作答；不回锁旧进度 |
| C：新增机制与体验 | 实现音文配对、近音辨析、多关键词、听音组句、点词改错和短情境行动；先以 Lesson 1–6 与 49–50 覆盖基础/语法两类样本 | 真实页面可以完成；每个新增机制都有目标、反馈、错误和恢复证据 |
| D：全册内容适配 | 向 72 个分区按先修与目标应用合适机制，补图音，调整挑战和跳级题池，添加适量电台/任务组合 | 全册替换映射和内容审核完整；不能把未实现的新题写成已上线 |
| E：验证与发布准备 | 执行逻辑、媒体、全浏览器矩阵和真实操作；同步文档 | 检查、人工验收、提交、推送、发布及线上路由验证分别报告 |

### 必须验证的内容

- **无输入入口回归**：从 catalog 自动枚举主线、73 组挑战、到期复习、重练、全部跳级目的地和恢复路径；学生作答区不存在 textarea、contenteditable 或自由文本/数字作答框，不残留要求打字/手写的按钮、placeholder 与无障碍标签。原生选择控件、音量控件等不因使用 input 标签被误杀。
- **题目公平性**：先修已覆盖、正确解/等义解明确、干扰项有依据；重复词块可区分；多选数明确；图片、颜色、标签和字幕不泄露纯听力答案。
- **判分与节奏**：选中/撤销/检查/反馈/继续有效；重复点击只计一次；音频真实 ended；不提前显示答案；配对最后一项和多阶段任务的计分边界正确。
- **所有模式复用**：相同题在主线、挑战和复习遵守相同答案定义；跳级只改变模式规则，20 题、去重、范围、第 5 次错误、失败保存与重开保持正确。
- **历史记录**：至少覆盖初学新记录、前 6 课/前 50 课旧完成、旧主线未完成输入、旧挑战半途草稿、旧跳级已过/失败/进行中、隔日复习、损坏记录与跨标签覆写。
- **真实浏览器**：沿用 320×568、420×856、906×801、1440×900 和真实滚动条；新增题各状态加入浏览器防护网及负向对照。不得简单删除原输入题检查来制造通过；用新题与迁移检查替代对应职责。
- **可访问与异常**：Tab/Enter 可操作、焦点在正确位置，读题帮助可用，关闭声音/音频加载失败有明确处理；移动端不会因题目作答弹出软键盘。
- **儿童与课堂试做**：在低、中、高基础学生中检查独立操作、求助原因、误触、题目耗时以及换场景能否使用。没有试做时标记未确认，不宣称教学效果已改善。

预期验证入口包括 `npm run compile:course`、`npm run build:course`、`npm test`、`npm run test:review-browser`、媒体检查、`npm run test:browser`、`npm run verify:visual` 与 `npm run build`。按仓库依赖顺序和实际改动执行；根目录 design-qa.md 只记录本次实际结果。文档方案阶段不运行课程编译或更新通过记录。
