# 词块、音效、图片反馈与连续路线修复

2026-09-10。用户明确要求执行四项修改；本记录区分本地实现、自动验证、实际页面与发布。

## 本次实现

1. 所有 805 道组句题、4,766 个词块不再附带句号、问号、逗号、引号等提示。编译时统一写入 catalog，覆盖普通组句、对话组句、听音组句、挑战、跳级与延后复习。词内的撇号和连字符保留，来源整句和反馈仍保留标点；答案 ID、题序、存储格式不变。
2. 使用 Duolingo 官方公开应用的原始 MP3：`CORRECT`、`INCORRECT`、`PASSED`、`FAILED`，分别用于答对、答错、关卡/挑战/跳级完成和跳级未通过。普通配对每个有效匹配也有反馈。跳级最后一题只播放结果音效，避免叠加。刷新、重绘、重复检查及恢复已答题不重播。
3. 图片选择题在底部保留稳定的反馈区域。答对、答错和提示不再触发图片区域跳动；调整图片卡片和提示区间距，让手机上图片、标签、反馈和继续按钮同时清楚可见。较短屏幕仍可滚动查看选项。新听音选图和原有图片卡片选择共用该处理；故事角色选择保留场景内反馈。
4. 恢复 72 分区、354 关连续滚动路线，移除“展开全部路线”“只看附近分区”和前后分区分页。保留课程目录、课文入口、回到当前关卡、原有完成/跳级记录和关卡介绍。

## 图片偏移的诊断

用户原图见 [reported.png](evidence/answer-feedback/reported.png)。隔离测试记录使用同一真实题目 `PL12-11:tap`（pencil），通过实际页面控制器完成听音、点选和检查，不改用户本地记录。

在 832×902 下，答对后所有图片的屏幕 y 坐标减少 167px，但卡片内部坐标、页面坐标和尺寸完全相同。[首次失败输出](evidence/answer-feedback/red.txt)。这说明图像未重排，页面发生了滚动。

依次提出并检验三个解释：程序主动滚动反馈；浏览器焦点/滚动锚定；禁用选项造成重排。只在隔离测试中移除控制器的 `feedback.scrollIntoView({block:'center'})`，832、420、320 三种宽度均变为 0px 位移。[单变量探针](evidence/answer-feedback/scroll-probe.json)。根因是新增内联反馈后强制把它滚到视口中央。

既有检查验证了图片加载、卡片可点、反馈可读，却没有比较同一道题检查前后的屏幕坐标，因此没有拦住整组图片跳动。只删除滚动会让结果落到屏幕外，本次同时将图片题反馈移到底部、预留空间，并保留可访问的反馈焦点。

同类复查还发现：故事角色选择也使用 `kind:choice` 和图像选项，但已有场景内反馈。若按“选项是图像”统一处理，会重复输出两条反馈；新增真实故事流程测试先得到 `2 !== 1`，再将 `castChoice` 排除，保留原角色递物反馈。

去标点还会让少数重复词块变得相同：例如 Lesson 113 的 `I` 与 `I.`。新作答按可见词语比较，两个 `I` 可交换；只对判分集合实际扩大的题保留旧词块文本。新跳级响应带 `wordBankVersion:2`，旧响应继续按当时文本校验。测试覆盖原组句交换等价词后答对，以及旧跳级错题重新加载后仍保留原判分；新增记录也不能伪造为旧判分。

## 音效来源与播放边界

直接读取 [Duolingo 官方公开应用脚本](https://d35aaqx5ub95lt.cloudfront.net/js/app-d0e3a844.js) 的音效表，资源 URL、官方符号、音量、文件大小和 SHA-256 见 [provenance.json](../../../assets/feedback/provenance.json)。没有修改 MP3 字节或把相似合成音标为原音。

题目录音与音效是独立的播放通道。音效结束不能计入“已听完”，播放失败不显示题目录音失败，也不阻塞检查/继续。录音仍依赖真实 `ended`。课程包收集并校验这些音频，支持缓存后的离线使用。

词块文字变化曾使启动包超过原 4 MiB 限制。构建时改为给高频字符串分配短编号，现有 `course-table-v1` 解码格式、catalog 数据和对象顺序均不变；保存记录继续使用原编码选项。全量数据往返一致性与原体积上限继续检查。

## 2026-09-11 发布前 CI 时序复验

首次发布提交的 [CI](https://github.com/mrpersimmon/canranstudio/actions/runs/34502559088) 已通过 42 段课程原音，但在恢复已答题后立即计数反馈时得到 `0 !== 1`。控制器通过 Promise 队列与 Web Lock 执行动作，点击结束不表示恢复已渲染。单变量探针在本机也记录到“立即计数 0，等待目标反馈可见后计数 1”；存档和离线加载未改，原有恢复静默断言保留。

音效检查现先等待恢复的成功反馈可见，再验证唯一性和不重播。不增加固定延时，不模拟音频结束，也不改课程代码或判分。此前检查依赖点击后恰好已完成渲染，在不同执行速度下会提前读取页面。

同次发布还核对了 [后续复习检查](https://github.com/mrpersimmon/canranstudio/actions/runs/34503440487)：它仍要求路线最多显示三个分区，与用户要求恢复全部路线相冲突。本机复现记录为 72 分区、354 关，旧断言失败。该检查现明确要求 catalog 中全部分区与关卡都存在，且分页控件为零；目录定位、点选草稿、旧记录、离线和语法复习检查保持执行。
