# 与线下课、纸笔配合

线上题目训练听辨、理解、在选项支持下补句和组织语言。纸笔练习与师生对话提供线上点选无法证明的书写和自主表达证据。以下为课后使用建议，尚未经过学生试做校准。

| 学习基础 | 线上重点 | 线下与纸笔 |
| --- | --- | --- |
| 刚起步，常见于 1–2 年级 | 少量图片、短音频、2–3 个选项；老师先示范如何选与重听 | 用真实物品互问；已经学过书写的单词可写一张标签，教师观察握笔、字母方向和是否独立写出 |
| 有短句基础，常见于 3–4 年级 | 关键词、少量音文配对、短词块、情境接话 | 给同伴写失物卡、购物清单；在有真实对象的活动中核对内容与书写 |
| 较熟练，常见于 5–6 年级 | 更接近的选项、较长短语、较少额外帮助与新情境任务 | 写一小段有用途的信息，和同伴实际对话；教师单独记录未看选项能否表达 |

年级不直接决定难度，以学生英语基础和独立操作为准。线上不增加强制键盘或屏幕手写例外。

## 失物招领：Lesson 1–6

1. 线下先用书、外套、包等真实物品互问。需要澄清时用 Pardon?，确认归属后交还并道谢。
2. 线上练声音与图片、音文配对、听问句选关键词、失物招领两步任务。
3. 纸上写一张简短物品标签或失物卡。尚未学过规范书写时，由教师提供字样，不能用在线点对单词替代书写检查。
4. 教师分别记录“听懂并拿对”“无选项说出来”“写得正确”，不合并成一个掌握分。

## 点餐与喜好：Lesson 49–50

1. 线上选择 likes/like、定位并修正动词、用词块问伙伴想吃什么。
2. 同伴两人用食物卡完成真实问答，再各自在纸上写一条有关对方喜好的信息。
3. 教师观察是否能脱离选项使用 He/She likes…、does not like…、Does…want…，把实际口头/纸笔表现和线上选择成绩分别记录。

避免课堂、纸笔、线上三处反复抄同一句。儿童试做应记录是否读懂操作、误触、求助原因、完成耗时与换情境后的表现，再调整每关数量与选项难度。
