2026-09-10。基线 `1c6c3e8`，分支 `codex/duolingo-version`。当前本地候选 `lesson1-144-v7.0`。用户已要求执行；本地实施与技术验收已完成，尚未提交、推送或发布。

同日追加的词块标点、Duolingo 结果音效、图片答对偏移和完整路线恢复见 [修复记录](answer-feedback-fixes.md)。以下数字为无键盘改造基线；追加修复的最终验证以根目录 `design-qa.md` 为准。

## 已实现的功能

- 主线 6 道、73 组挑战 580 题、跳级题库 592 条、延后语法复习 3 题，共 1,181 条旧输入配置全部对应到新题 ID。它们是分入口配置数，不是去重后的内容数。
- 学生题面、提示、帮助、按钮与无障碍名称中不再要求打字、翻译输入或屏幕手写。删除作答 textarea、文本输入处理和输入法分支，保留按钮的 Tab/Enter 操作。
- 七种共享操作：单选、选词补句、词块排序、多选、音文配对、点词改错、分步情境任务。主线、挑战、复习与跳级共享题目判分；跳级使用自己的单次提交规则。
- 完整保留 144 课原文、354 节点、逐句真实播放结束和手动继续。原有词卡、图词配对、理解题与故事继续使用。新增机制大多通过替换现有活动接入，主线从 1,573 到 1,581 个活动，净增加 8 个。
- 72 个分区各有一组音文配对，71 个分区把适合的旧组句改为听音组句；基础开头没有适合的原组句处不强行加题。新增少量关键词多选、this/these 听辨和失物招领两步任务。
- 73 组挑战改名“小镇挑战”，仍然选做。580 题包括 221 选词补句、212 听音组句、75 情境组句、69 听音选意和 3 对话回应；72 组有三种操作机制，跨课 CHALL 使用已教目标的补句与组句。
- 新跳级题库保持 592 条、每次 20 题、第 5 次错误立即结束；完整句目标去重、目标之前的范围、跨跨度锚点和约 70% 跳过范围优先。可用时混合三种机制，不以复杂配对或多步骤任务增加一次错误的权重。
- 听完音频才可检查听力题；允许重听。结构化草稿保留选择、顺序、配对与步骤，不伪造刷新后的听完状态。
- 词块可撤回，已用词块保留位置；多选显示目标数和已选数；改错必须先选词、再选替换词；任务必须先选物品、再选接收者。
- 新成绩记录选项支持和额外提示，记录页使用“未用额外提示答对”。不将点选成绩作为自主拼写、自由写作或口语达标证据。

## 历史记录与恢复

`recordSchema` 升至 5，答题与评估契约升至 3；原存储身份不变。

1. 冻结 v6.1 契约。迁移先独立备份原存储字节，再写新记录并读回验证；损坏数据保留导出和恢复入口。
2. 旧完成节点有可验证的历史完成凭据。被新任务替换的旧成绩、旧错误与文本草稿保存在只读归档；不为新题伪造成绩。
3. 半途挑战保留已经完成的题数，从剩余新题继续；未完成文本不放进新选项状态。完整旧挑战保留完成状态，并可以自行选择重练新版。
4. 已通过或失败的旧跳级按原版本验证。进行中的旧测试标为“版本更新中止”，不扣机会，重新开始新版完整 20 题。
5. 到期复习按目标映射到新题，保留日期和错项线索。每日队列上限仍生效；未进入本轮的到期题保留在后续轮次。
6. 记录页与挑战介绍可展开以前的原答案。内容只读，不重新出现文本作答框。
7. 小草稿写入同时检查草稿字节和主记录修订号；旧标签页不能在迁移后覆盖新版草稿或成绩。重置、撤销与恢复继续保留。
8. 带完整历史归档且超过 64 KiB 的新记录，复用已有无损表编码保存；运行时仍读取原结构。迁移与隔离备份保留原始字节，新备份支持解码恢复。未归档记录与小草稿保留原格式。

## 修复与复发防护

| 发现的问题 | 原因与此前遗漏 | 本次修复与检查 |
| --- | --- | --- |
| 旧完成节点增加/替换任务后可能回锁 | 仅按当前活动列表计算完成；旧检查只覆盖追加原活动 | 保留可核验的历史完成凭据，覆盖 v3.6 导入、前六课、前 50 课和重练新题 |
| 两道基础任务转换后只剩一个可选项 | 短语与单词不能统一按空格切成排序题 | 为单词使用有依据的图选项，短回应使用已教回应；全入口校验至少两候选 |
| 极短词块 Is 在窄屏命中区不足 | 通用按钮高度足够，但宽度跟着短词收缩 | 点选控件均至少 44×44；四尺寸用真实命中检查，原检查门槛保留 |
| 恢复后配齐却无法检查，重听还会取消已有配对 | 听完状态在刷新后重置，但只显示配对数；左边按钮把重听和删除配对混在一起，原测试总是先等音频结束 | 明示听完段数及每段状态，重听保留配对，换搭档时再修改映射；加入可先复现失败的恢复/重听检查并在真实首页复验 |
| 改错词块出现默认灰按钮，答对后仍显示错误句 | 新组件未带共用按钮类；原自动可读性检查无法判断视觉语义是否合适 | 复用共用按钮样式，成功后只呈现正确句；补充成功态断言并重新目视核对 |
| 多数挑战只有两种操作 | 单看题型名称/题库规模不能反映动作变化 | 显式编写听音选意与情境组句分配，查看逐组机制分布；跳级种类配额受范围约束 |
| 大量旧进度升级后可能超过浏览器存储上限 | 全量历史与新进度重复，原检查只有新记录和少量迁移，未覆盖大归档加恢复备份 | 对大归档采用既有无损表编码；先复现容量失败，再覆盖继续保存、原始备份不变、损坏导出与恢复；真实浏览器验证 1,427 活动的历史样本 |
| 旧标签页仍可能写入小草稿 | 小草稿只比对本身，主记录升级后草稿未必变化 | 同时核对主记录修订号，回归迁移后的迟到写入 |
| 旧输入专用浏览器检查无法验收新状态 | 文本值与输入法检查已经不对应学生动作 | 替换为选择/撤销、保存/恢复、后台焦点与文本框负向注入；保留原离线、恢复、失败、跳级职责；后续全册检查又发现到期复习仍发旧选择事件，现改为按真实题型作答，并增加独立的复习/挑战预检 |

## 尚不能宣称的结果

- this/these 已作为本地候选题接入，并验证文件和实际播放。2026-09-10 用户亲自试听后反馈：“this 和 these 区分很明确。”本组声音区分已获人工确认；此反馈仅覆盖这两条录音的可辨认性。
- 九条新语音的逐句教师发音审核、低中高基础儿童试做、跳级难度校准尚未进行。没有宣称书写能力或学习效果已改善。

2026-09-10 人工试听中的跳级音频失败已另行定位为本地预览服务停止。恢复服务并启用独立后台启动后，原页面的同一道题可正常重播、检查，作答保留。新增长期预览启动与实时健康检查命令，详见 [本地试听恢复记录](preview-audio-recovery.md)。
- 12 个名称是产品练习形态，7 个是共享操作机制；既有故事、卡片与图词配对没有重复计为新增功能。少量电台/任务是确定性教学活动，不是开放 AI 对话。
