# 猫猫小镇：深色学习路线

日期：2026-09-06。实现分支：`codex/duolingo-version`。

## 设计目标

用户提供两张 Duolingo 闯关页面，要求颜色、图标、动效与整体路线表达向参考全面靠拢。以真实课程进度为基础，让孩子一眼找到当前关卡、看清操作状态，并感到逐步向前。

## 参考与取舍

- 原图保存在 `docs/references/duolingo/2026-09-06/path-dark/`，按原始字节保存。
- 参考中的深色画布约为 `#141f23`；橙色主题约为 `#ff9600`，金色完成态与灰蓝锁定态分工明确。使用弯曲排列的立体节点、章节横条、当前节点提示、固定底部导航。
- 保留探险猫身份与完整猫猫形象。节点表面与角色为独立生成的透明位图，图标使用 MIT 授权的 Phosphor 图形。没有使用 Duolingo 原角色或品牌标志。
- 参考图为静态图片，不能据此确认原 App 的真实动画。这里自行设计短暂邀请、按钮按压、预览展开、角色回应；系统“减少动态效果”生效时关闭这些动效。
- 页顶只显示现有课程范围、完成关卡数、待复习线索。没有虚构连续天数、货币、体力或排行榜。
- 橙色章节仍采用参考的主色，标题与课本图标改用深色以提高对比度；有色背景上的阅读清晰度优先于逐像素复制。
- 目前课程只有 11 个节点，分为 4 个主题，因此各主题更短；桌面适配为左侧导航、中间路线、右侧简短进度，手机保留底部导航。

## 操作规则

1. 点击关卡显示类型、时长、名称与主要按钮；未解锁关卡也可查看，但无法开始。
2. 当前关卡显示橙色定位环与“开始 / 继续”提示。定位环表达当前所在位置，不伪装成答题成绩或完成百分比。
3. 完成关卡变为金色，并保留题型图标及完成标记；点击可再练。主题星星一颗对应一个真正完成的关卡。
4. “复习”显示运行时当前到期的线索；没有待复习内容时提供返回路线入口；已完成关卡可主动重练。
5. “课本”与章节课本按钮进入现有原文回顾，仍按原声的真实结束事件记录听过的内容。
6. “记录”区分完成关卡、听过的课文原句与练习结果。仅点击导航、节点预览或猫猫不会写入学习证据。

## 实现边界

- `content/learning-course.json` 的 `journey` 是地图展示资源、节点类型与文案的唯一源。
- `core/learning-journey.js` 是读取快照的纯展示模块；已有课程运行时仍决定解锁、学习、复习与保存。
- 控制器只持有临时导航/预览状态，不向课程记录添加地图装饰状态。
- 保留 `experienceRevision` 和存储键，原有课程内容、互动故事、原声音频及进度导入规则不变。
- 课程包只引用压缩 WebP 与用到的图标；原始 PNG、参考图片和设计资料不进入公开页面资源包。
