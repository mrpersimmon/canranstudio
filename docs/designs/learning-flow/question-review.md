## 用户问题与根因

语法规则直接挂在答题反馈区域；单屏样式把规则绝对定位到按钮上方，没有单独关闭入口，答对后自动覆盖题面。必要情境则作为独立带底色块，和题干的关系不清楚。原引擎只有真正的作答游标，直接倒退它会在恢复校验时截断后续题目，不能拿它实现上一题。页面只有本关题数和已收藏星数，无法表达全课当前轮的完成阶段。
