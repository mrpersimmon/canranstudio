# 首课小图标与缓存验收

首课在已准备好资源的公开课程目录中打开时，会为一组共用的小 SVG 逐个请求服务器。它们在 Git 正式构建中合计 20,008 字节。在 10 Mbps、150 毫秒延迟条件下，等待多次往返的时间超过了它们的传输时间。

Lesson 1–2 的清单现在携带其中 36 个小图标的原始文本，总计上限为 32 KiB，每个文件上限为 2 KiB。课程沿用已有的 SVG 还原和散列校验流程。原逻辑地址、完整文件、课程授权、每个图标的独立缓存键和历史清单继续可用。正式根路径的清单多 22,510 字节，首课的 146 项逻辑资源逐项校验值相同。

从已准备好的目录点击课程到首张词卡可操作，Windows Chromium 的同机限速对照由 5.74 秒降至 4.63 秒，Linux Chromium 由 5.18 秒降至 4.07 秒。20 次从目录复访并恢复实际词卡位置，修改后的 P95 分别为 0.83 秒和 0.73 秒。两项检查沿用 5 秒和 1.5 秒上限。此处测量公开课程目录的缓存流程；真实账号公网登录至首题的样本另列。[体验站公网数据](2026-11-23-art-font-preview.md)

回归通过正在显示的词卡和翻组控件判断可操作时间，并核对上述小图标没有再发独立正文请求。结算恢复继续检查错答订正、得星状态和保存的位置，顶部绿色对号按实际获星显示。
