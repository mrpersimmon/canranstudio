# 归还手提包与纪念卡出口闪色

2026-11-08，本地修复，未提交／推送／发布。

## 根因

1. 手机答题层的`.picture-option img`命中了接收者按钮内嵌套的手提包。实际定位槽宽30px，图片宽56px；道具同时以整个按钮定位，人物缩小和下方姓名没有参与同一比例计算。只检查人物按钮外框与“图片可见”无法发现此缺陷。
2. 学习页按钮配色此前依赖临时`.learning-surface`类。纪念卡本来已挂载，进入时才换主题，并被120ms背景过渡插值。逐帧复现“返回首页”首帧为`rgb(246,181,77)`、最终为`rgb(255,252,245)`；这与图片加载无关。

## 修复边界

- 人物与持物统一为2:3人物画板，姓名留在画板外；手提包用人物画板左侧41%高度处的手部锚点、34%人物高度缩放。普通人物与可点击接收者共用该结构，原题对象、人物资产和答案控件保留。
- 通用手机缩略图尺寸只作用于选项直属主图；嵌套道具由场景组件管理。保留触摸命中与原答错／订正／回看逻辑。
- Learning shell的按钮基础样式绑定稳定的课程页面容器，进入与退出不再更换配色。保留选中、禁用、正常点击反馈和柔和入场，不全局关闭动画。
- 范围为Lesson1–2的手提包场景，以及已接入共用学习层的Lesson1–6按钮；未修改纪念卡图像、判分、学习记录和授星。

## 回归与预览

新增`tests/review/scene-exit-stability.spec.js`：三个固定手机尺寸，人物持物答对／订正／回看、两类归还场景跨320px／平板／电脑尺寸，以及三课首次与再次进入纪念卡的逐帧颜色。真实账号触摸用例补齐375×667、430×932、440×956，验证实际答题和获星。

修改前两项回归分别准确复现尺寸越界和颜色插值，证据在`output/scene-exit-stability-before/`；初次修正的2项通过在`output/scene-exit-stability-first/`。自动拦截加入`browser-scene-exit`和`browser-scene-exit-webkit`，相关场景、共用样式和路由代码变更均触发。

实际通过：Chromium／WebKit定向页面检查各7项，共14项；真实账号原生触摸、完整应用环节和获星1项；检查流程30项。SE375×667、14/15 Pro Max430×932、16 Pro Max440×956均覆盖答后、订正、回看及三课反复进入纪念卡；另含320×568、768×1024、1366×768的场景适配。结果在`output/scene-exit-stability-final/`与`output/scene-touch-real-final/`，首轮失败证据保留。最终画面与逐帧颜色分别验收，不把静态截图作为防闪色的全部证据。
