## 首错与修复过程

1. `test-accepted-ux-before`五项均复现旧问题：分页不可见、缺少一次推进、奖励回焦错误等。
2. 新测试中出现配对重试误点已正确项、漏传页面、同名“返回当前题”匹配冲突，以及目录恢复期间过早判断关闭状态。修正操作和作用域，保留原严格布局／记录断言，没有用等待加长或放宽阈值隐藏问题。
3. 组合“去练习”后SE返回课文曾只露出半条末句。根因是隐藏布局改变滚动边界；离开前保存位置，隐藏期间不覆盖，返回尺寸就绪后恢复。追加“在末尾返回”和“主动上翻历史后返回”两个方向验证，透明对白与人物比例保持。
4. 共享语法呈现器直接读取`core.unit12.copy`导致Lesson3–4启动失败。改为可选读取，新copy只供1–2使用；Lesson3–4仍使用原规则，结算三分支复验通过。
5. 旧包升级后部分有效本轮状态与历史记录runId不同，最初仅凭历史runId将前两题误标此前。改为显示已校验的当前轮状态，不迁移或改写原记录；真实升级后继续答题、统计3／5／2、既有五星、原日期、另一设备和纪念册全部通过。
