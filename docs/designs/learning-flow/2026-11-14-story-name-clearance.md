# 手机剧场姓名与人物分区

2026-11-14，修复用户指出的Lesson13–14姓名牌遮挡人物。此前只检查了底板宽度、场景边界与人物裁切，没有检查姓名牌和人物图片之间的交叠，本轮补齐这条验收。

## 根因与范围

Lesson7–8、9–10、11–12、13–14均使用方形合成人物图，姓名按`bottom:-15px`悬在图像下沿。手机上画板缩至约0.601倍，同时为了可读性补大姓名字号，使姓名牌向图内覆盖约13.77 CSS px；不同姿态的鞋子可能落入这一区域。

本轮逐句检查Lesson7–24九个单元，在上述四课复现；其余五课采用人物图与姓名顺序排布，没有同类交叠。不是通过删除人物姓名解决问题。

## 修正

四课的合成人物图下方设置独立姓名区：先测实际字号下的姓名高度，预留8px图片间距和8px底部空间，再将人物图等比放入剩余高度。横向姓名锚点、原角色及全部姿态保持。图片与姓名不再先一起缩放后补字号，三档手机中姓名以正常14px呈现。

实现限定这四个单元，其他课仍使用原布局。没有修改原题、原文、中译、学习记录、授星规则或原纪念卡；上一轮取消的装饰地点牌继续不显示。

## 设计与回归要求

- 姓名牌和整张人物图片的矩形区域分开，不借用某一姿态的透明边缘放字，避免换姿态后挡住脚、衣物或道具。
- 先满足可读姓名高度与间距，再适配人物画板；切换手机尺寸、字幕或人物姿态时保持关系，不靠固定负偏移猜位置。
- 必须检查姓名与人物是否相交。“都在场景边界里”“标签不太宽”均不能证明没有遮挡。
- 原文说话者、姓名、人物身份和姿态保持，不能用隐藏功能信息解决排版问题。
