# Lesson 1–2 参考资料与结算布局修复

2026-10-31 · `codex/book-version` · 本地开发。

## 根因

用户在375×667的`learn/manners`标注“Pardon?”显示奇怪。复现发现“礼貌用语”和“换个物品问一问”仍是练习容器旁的两个旧`details`。此前仅答题状态隐藏这些节点，进入结算后隐藏规则失效，两个资料块参与固定高度页面的纵向排版。

展开礼貌用语后，参考区约492px高，结算内容被压至约37px；操作区位于y≈147至235px，与y≈134开始的资料正文重叠。问题属于页面承载与状态隔离，英文和中文原稿没有错误。

修复前截图：[展开后的重叠](evidence/2026-10-31-reference/before-expanded-375.png)。新回归先在原代码准确失败：结算页的原`grammar-reference`仍然可见，trace保留于`output/test-practice-references-before/`。

## 调整

- 仅Lesson1–2的新学习界面将这两类参考区从练习／结算主布局中收起，更多菜单提供同名入口。隐藏范围限定为`.grammar-reference`，没有吞掉纪念卡页的练习纸。
- 点击入口先关闭更多，再打开独立参考面板；礼貌用语按“英文＋中文用途”成组，换物品的句型按“原图片＋英文＋中文”成组。原文与素材来源不变，不增加新的解释或答案。
- 面板在可用视口内居中，标题与44px关闭按钮保持可见，长正文内部滚动。关闭、Esc或点击遮罩返回更多按钮焦点；换学习关卡时关闭旧参考面板。
- 查看参考资料不调用判分、提示计数、学习位置保存或授星接口；关闭后原题／结算位置不变，重练及刷新保留原状态。
- 新检查覆盖真实完成街角练习、三张统计、打开两类资料、读到最后一项、关闭恢复、重练中的资料入口及刷新。统一读取SE375×667、Pro Max430×932和440×956预设。
