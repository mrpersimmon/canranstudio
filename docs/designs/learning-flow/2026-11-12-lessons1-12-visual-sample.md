## 根因与修正

| 发现 | 原因 | 修正及拦截 |
| --- | --- | --- |
| 换了卡框，旧词卡仍像简笔图标 | 旧SVG渐变保留了原造型 | 真实参考生成／认可素材复用／事实图保留分别登记；禁止渐变方法冒充采用 |
| 抽象词配图不明确 | 直接复用人物合图不能表达单人指代或关系 | 单人“I”重绘；33个关系图标记标签、指向和被指代者，组合引用记录SHA |
| 原剧场环境与新词卡色温、细节不衔接 | 各课旧背景与分区底色分开绘制 | 一层完整比例背景，透明人物区，接合高度由实际宽度计算；对白独立真实UI |
| 320px词卡多出2px内滚动 | 通用span规则使组合插画不能收缩 | 只让插图区让出高度，英文和音标不缩字；压力场景及三手机逐卡断言 |
| Lesson9–10短拼句题需轻微滚动 | 76px示意图加外边距挤占输入区 | 短屏仅把非交互示意图调至64px并收紧边距，实际10px滚动归零 |
| 题中紫伞仍为旧SVG | 原题跨课引用，单课词表映射遗漏 | 从明确原资源来源生成共享物品映射，歧义与品牌图排除；不改原题稿 |
| 最后一组少一张时偏在左侧 | 两列网格自动排布 | 奇数末张水平居中，大小、分页位置和原六词分组不变 |

首错保留在`output/sample-1-12/`的`coverage-before`、`scene-before`、`scene-first`、`objects-before`、`short-task-before`和`extra-sizes`证据中。部分首轮失败为测试实现：子路径断言缺少`/lesson`、选项随机顺序却按固定顺序断言、用验收台目录重载代替学生真实翻组，以及账号测试未兼容Lesson1–2没有reward.lesson字段；均修正测试后复验，没有放宽几何阈值或改变教学数据。

## 素材与提示词固化

每次生成的**完整实际提示词**、参考图、透明要求、输出原稿与采用路径保存在[45份回执](sample-1-12-generations/)。[素材说明](../../../assets/learning-sample-v1/README.md)记录尺寸、体积与运行包边界；[逐词采用台账](../../../assets/word-art-v2/adoptions.json)记录意义核对、原图审核、三设备页面证据和SHA。

后续生成固定以下约束，并在每个具体词条中补足身份和词义，不能只写“风格一致”：

1. 附本课认可的原纪念卡／角色／物品作为真实图像参考，保留脸型、衣着、标志物和准确词义。
2. 暖深棕手绘轮廓、圆润造型、柔和绘制填色、克制阴影与纸感；物品／人物完整可见。禁止写实摄影、3D塑料质感或另一套扁平图标。
3. 词卡单图透明背景、四周留足净空，不含白框、卡框、外部投影或不必要文字；原始输出保存，采用图等比处理为512×512 WebP。
4. 环境图3∶2，保留主要地面活动区域，环境内不重复画入主角或对白。网页用实际UI承载文本，不能靠图片文字代替。
5. 国旗、数字、颜色、品牌和关系词分别核对。源图通过后还需看真实手机卡片，不能因生成成功直接标为通过。

本轮45张新采用图共2,036,570字节；旧角色和原卡复用，不重复生成。原稿不进入运行资源包，历史素材不删除。
