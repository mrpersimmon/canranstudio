# 词卡连续翻页与左对齐

2026-11-14，按用户最新要求取消学生界面的“插画词卡／语境词卡”二分类入口，孤立词卡靠左放置。本记录覆盖此前分类标签、分类内页码及末组居中的设计规则。

## 当前规则

- 每课先排列全部插画／图示词卡，再接全部语境词卡；两段内部各自保留原词序。
- 合并为一条序列后每6张分页，类型边界不另起空页。因此最后几张插画后可在同页接上语境卡，保持顺序而非交错排列。
- 不显示分类标签、分类词数或“看语境词卡”等切类按钮。只保留统一的上一组／下一组、单元总页码，以及末页原“下一站”入口。
- 不足一排的卡片从首列依次排列，单张卡片从正常首行首列开始；保留正常卡片尺寸，不横向或纵向居中、不放大补空位。宽屏整体内容栏仍与其他页面对齐。
- 类型仍作为内部呈现元数据使用，负责选择图片或原句。原词条、音标、释义、例句、题目、记录和原纪念卡不变。

六课132词仍为86张插画／图示卡、46张语境卡；连续分页为Lesson1–2四页、3–4五页、5–6四页、7–8四页、9–10四页、11–12三页，共24页。旧按词锚点记录可直接恢复到新的连续页，不把旧分类页号当作新页号。

## 修改与拦截

`core/word-deck.js`先按表达类型形成稳定顺序，再统一分页；删除分类控制，统一页码及按钮。`learning-sample`移除末行横向偏移和末页自动居中。验收台目录使用“词卡 · 第N组”，直接对应真实课程连续页。

`word-deck.test.js`检查没有类型边界空槽、全部词按正确顺序出现、原锚点仍可恢复。`word-display.spec.js`覆盖单张以及三张卡片页的首行／首列位置；`sample-words.spec.js`检查没有分类入口、连续页码、类型交界和全部词条原信息。真实账号续学与答题回归改用正常上一组／下一组操作。

首错保留于`output/word-deck-linear/before/`和`pagination-before.log`：复现分类标签仍在、孤立卡片向中间偏移、类型边界过早分页。最终记录在`phones-final/`、`account-final/`和`contracts.log`。只执行本次影响范围，没有运行全站CI。
