# 首课点入到可答题：资源归属与网络对照

后续：当日已完成[独立测试站发布与新版公网复测](2026-11-21-first-course-preview.md)。下文记录发布前的本地实验与当时的公网旧版基线。

本次只改新课包的依赖列表和背景声明归属。原插画、完整字库、题稿、得星规则、学生记录和课程缓存协议均保留。未切换公网测试站或官网程序。

**根因。** 12张本应各自属于一个单元的剧场背景写在所有单元都会读取的样式表里。打包器正确收集了这些 URL，浏览器也按清单实际下载并准备了不会在本课出现的图片。现将同一条背景声明移到对应单元本来就使用的样式表，保持选择器和素材不变。明确共享背景的其他课程仍会包含它；1–2借用3–4的外套词卡也照常保留。

第二个来源是教学数据中拼接出的跨课路径。例如49–50借苹果、香蕉和橙子三张图，旧构建却把47–48整个美术目录加入必需下载。新构建从实际展开的教学数据读取这些文件名；运行时仍需动态生成文件名、暴露目录前缀或无法确定的，沿用原整目录规则。没有用单元编号过滤所有借图，也没有从仓库或历史发布中删除资源。

**验证口径。** 点击真实首页课程入口，经过原词卡页，用真实按钮翻到第一题。独立统计“词卡首次可操作”和“第一题可操作”；点击前目录准备、同步接口、缓存返回、可选提示音分别计量。浏览器记录每个必需对象返回的实际正文，并与当次已校验清单逐文件对照；本地同时用独立 HTTP 测试服务器的发送记录核对。服务工作线程的本地命中不算下载，HTTP头和TLS开销不列入正文。时间区间以点课为起点，不把字体已就绪后的点课成绩说成从零登录的总耗时。

本地对照的旧打包代码与样式在修改前留档，72份清单逐条比对路径、大小、SHA-256后再用同一账号服务器测量。桌面 Chromium 151，固定 Chrome 三档手机宽高、DPR、触摸，页面连接设为10 Mbps／150毫秒；未声称单独限制了工作线程，也不等同实体手机网速。不同单元的共用缓存可复用，不能把每课节约的字节乘72当作每个学生的实际节省。

SE另做反向对照：先新版9.81秒，再旧版11.56秒。首课冷下载由157个必需对象、10,028,235字节，降到146个、8,660,866字节（−13.6%）；已备共享字体时为152个、3,849,139字节 → 141个、2,481,770字节；复访两侧均为0个必需下载。11张背景共1,366,244字节，其余净差来自样式。代表图片包括公园181,092字节、问候街景167,928字节和衣帽间147,596字节。两版全字库均为7,032,808字节；备妥的5份共享字体抵扣6,179,096字节。可选提示音有时在首题出现前已开始回传，服务端额外发送与前台所需正文分列。

静态清单按相同SHA去重：72个单元各减少1,186,378至5,401,404字节。49–50由17,731,706降至12,330,302字节；来自47–48的三种水果原图按原路径保留。这是课包体积比较，未对该课推算首屏秒数。

**仍在运行的公网对照。** 11月17日的独立测试版本 `review-local-stars-20261117-357a3334ca26` 在三档尺寸各下载156个必需资源、10,025,967字节，首题为26.76–27.14秒；预备字体后为12.56–12.90秒，复访为1.41–1.43秒。最大的 `award-gothic-500.woff2`（4,456,656字节）从点课后的1.50–2.04秒开始，到25.74–26.13秒才结束；它与其他文件并行，不能把这段时间相加或当作删掉字体的收益。课程进入接口155–223毫秒，工作线程授权29–42毫秒。三名临时测试学生分别核验停用。官网未作测速或切换；新版在公网的改善尚待测试站发布后同口径复验。

详见[33组计时、72份清单对照及公网SE首访的156条逐文件记录](2026-11-21-first-course-transfers.json)。正文不含请求或响应头、Cookie、账号、成绩或带参数地址。

**兼容性。** 同时检查根路径与 `/lesson/`；每门课保持所需的世界背景和借用素材、两种入口都能打出完整清单；同一字体字节被目录与课程复用。旧课包在原有私有保留期内仍按旧清单读到相同字节。没有放松授权、SHA校验、图片显示就绪或旧纪念卡兼容条件。

**手机回归。** Chromium 与 WebKit 分别在 SE 375×667、14/15 Pro Max 430×932、16 Pro Max 440×956 上跑真实学生页面。每个引擎、每档尺寸均实际打开前12个教学单元和49–50、57–58，共84个课文页面组合，检查真实台词、中文展开收起、图像就绪、按钮、人物和滚动边界，另实际解码三张借用水果图。图片加载保护、无工作线程的内存降级、满星后坏图重试恢复姓名／五星／首次满星日期的6项专项通过；72课原题、奖励及原卡指纹验证通过。Chrome设备模拟与WebKit均不是本轮的实体 iPhone、安卓微信或夸克验收；未运行完整CI。
