# 剧场装饰文字审查与清理

2026-11-14，范围为已优化的Lesson1–24。用户指出Lesson13–14的“Anna家／楼上的房间”布局突兀，本轮先捕捉开场与转场页面，再核对同类文字的实际用途；未重绘插画或改动题目、对白、学习记录和原纪念卡。

## 观察与处理

1. **开场：Anna家。** 地点牌绝对定位在人物区域顶部，白底小牌压在人物头顶附近，与原文及人物姓名争抢注意力。[本轮开场截图](evidence/2026-11-14-story-labels/home-before.jpg)。移除实际节点，不留占位。
2. **转场：楼上的房间。** 同一位置换一条文字，并没有帮助学习者完成操作，却打断背景与人物的连续感。[本轮转场截图](evidence/2026-11-14-story-labels/upstairs-before.jpg)。取消可见地点牌，原课文“Come upstairs and see it.”保留；场景读屏名称仍随阶段描述Anna家／楼上。
3. **同类场景及姓名底板。** 检查Lesson1–24，9个单元存在同类重复地点牌。同步移除；Lesson21–24人物姓名底板被拉满列宽，短短“男士”额外占用118px空白，改为随文字宽度居中。人物姓名、说话者、原文、中文展开及操作提示继续保留。[本轮九课检查图](evidence/2026-11-14-story-labels/reviewed-scenes.png)。

## 统一规则

- 插画上默认不悬浮与画面重复的地点文字，尤其不能压在头部、手部或背景接缝上。删除后不保留空槽，也不先出现一帧再隐藏。
- 必需的说明进入正常阅读区域；原文和题目所需线索必须可见，不能仅放进无障碍名称。场景整体的无障碍描述继续准确。
- 人物身份保留，但姓名底板只包裹文字和正常内边距，不拉伸成空白条块。
- 检查实际用途后逐项处理；不能靠匹配中文或统一隐藏全部场景文字来“清理”。
