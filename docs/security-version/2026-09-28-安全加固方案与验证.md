## 保留的产品规则

新进入和续期仍检查当前学生状态及班级课程。已经进入的一轮保持两小时授权；课程撤回、转班等之后不能取得新的授权。不同设备会话和不同课程使用不同授权记录。

原学生重新登录后可以补交之前的已完成成果。授权 token 的课程访问期限与补交用途不同，因此不把所有历史 token 按两小时删除，不清空学习进度，不接受跨学生 token，也不允许旧 generation 覆盖重练后的记录。

受保护的 HTML、清单、资源和成果继续使用 `no-store` 与身份检查；浏览器整课缓存仍由访问许可控制。不能照搬外部报告给所有课件添加匿名 `public, immutable` 缓存。公开品牌图片保留既有一天缓存。

## 登录限制与恢复

- 来源预算覆盖学生登录、管理员登录和改密操作，成功登录不清空来源预算。
- 账号预算按用途隔离；学号沿用去首尾空格、转小写的规范化方式。成功验证清除该账号的失败/短时记录，不影响其他账号。
- 十次失败后的拒绝不会推迟窗口截止时间，最长等待十五分钟。老师重置学生密码可清除该学生的登录/改密冷却，同时按既有规则撤销会话；本地 `reset-admin` 可恢复管理员。
- 限流记录只保存散列标识，不保存密码或原始账号/IP。记录上限为 10,000；过期记录会清理，容量耗尽时拒绝创建新预算，不能驱逐活跃预算来绕过限制。
- 账号冷却会影响被定向尝试的合法账号，这是限制猜测次数的取舍。课堂共用出口仍保留 120 次/分钟预算；实际班级容量及网关抗大流量能力须在线上阶段验收。

## 验证入口

所有复现只使用临时目录、虚构学生和模拟私有文件。本轮原问题对照：25 次重复进入从 25 条记录降为 1 条；模拟私有文件从 HTTP 200 改为 403，公开首页仍为 200。没有读取真实学生数据库、密钥或生产凭据。

新增回归覆盖授权迁移、历史 token、不同设备/课程、索引查询、权限文件模式、冷却跨重启及跨来源、容量上限、恢复入口、真实浏览器 CSP，以及预览的编码路径、别名和符号链接。完整账号测试继续覆盖课程作答、刷新、错误重试、旧记录迁移、密码与备份恢复。

部署模板必须使用真实 Nginx 验证。若本机已有二进制，可运行：

```bash
NGINX_BIN=/实际路径/nginx OPENSSL_BIN=/实际路径/openssl node --test tests/deploy/login-nginx.test.js
```

该用例使用回环端口、自签测试证书与临时配置，检查规范域名、裸域跳转、未知 Host、未知 SNI、合法 SNI 搭配恶意 Host、版本隐藏及转发来源覆写。未提供 NGINX_BIN 时用例明确跳过，不能记为通过。本轮最终检查结果以 Codex Security 修复报告和交付说明为准；源码测试不等于生产验收。

## 待生产阶段执行的事项

1. **凭据轮换优先处理。** 核对报告所指暴露凭据的实际类型与用途；建立并验证新的独立访问方式后，撤销旧 SSH 密钥/密码、核查授权密钥及访问日志。若管理员或服务密钥也受影响，分别轮换；数据库与 card-key 必须配套备份，不能随意更换加密密钥导致旧数据不可读。当前分支无法证明已轮换。
2. **核实 Nginx 供应商补丁。** 读取运行版本、编译模块和系统包修订，对照供应商安全公告；版本横幅不足以确认 CVE。备份配置，更新受支持补丁，执行实际 `nginx -t` 后再 reload。新模板的 `ssl_reject_handshake` 要求 Nginx 1.19.4 或更新版本。
3. **清理默认域名与旧公开入口。** 核查实际启用的全部站点，处理冲突的 default_server，确认未知域名/IP/nip.io 不进入账号站点，旧公开 `/lesson/` 及 resources alias 不与新规则并存。其他独立站点保留各自明确域名。验证证书续期方式仍可工作。
4. **核实邮箱用途后再改 DNS。** 若确认域名完全不发信/收信，可采用 SPF `v=spf1 -all`、DMARC `v=DMARC1; p=reject;` 和 Null MX `0 .`；有邮件业务则按实际服务商配置。CAA 仅授权实际证书签发机构，使用 Let's Encrypt 时为 `0 issue "letsencrypt.org"`；核查续期及通配符需求再发布。
5. **上线验收与恢复。** 使用一致的已提交版本与配套备份，验证学生/教师登录、错误/冷却/恢复、课程权限、直接资源请求、Range、Worker/缓存、补交和重练。用手机微信及课堂出口复查。回退代码保留学生数据，不能恢复匿名公开课件或用旧快照覆盖新成果。
6. **旧公开练习站另行审查。** `/exercise/` 与账号页面属于同一浏览器来源，路径和 Worker 范围不构成来源隔离。本仓库没有完整的导入产物，无法对其全部脚本作安全结论。上线前检查该产物是否含不可信脚本或输入渲染；必要时另案迁到独立来源，避免未经确认改变既有入口。

未对所有教学前端、历史文档、媒体及生产系统做穷尽审计；没有确认源码中的跨学生进度越权、匿名受保护资源绕过或 SQL/命令注入。这里的“未确认”不是这些风险永远不存在的保证。HTTP/2 性能优化不计为本轮安全缺陷修复。
