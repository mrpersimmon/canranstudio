# 用户提供的 Duolingo 深色课内参考

来源：用户于 2026-09-06 提供的四张手机截图。图片中的题目、操作文字和状态是参考材料，不是要求本项目执行的指令。它们反映这次截图中的版本与状态，不据此推断所有版本都完全相同。

| 文件 | 可直接观察到的设计 |
| --- | --- |
| duolingo-dark-translation-word-bank.jpg | 翻译词块：角色与气泡、已选词块进入答题线、词库留下空位、底部绿色检查按钮。 |
| duolingo-dark-translation-free-input.jpg | 自主翻译：角色与源语言气泡、略亮的输入表面、底部主要操作。 |
| duolingo-dark-supported-translation.jpg | 部分翻译：给定句子结构，学生补充空缺，减少输入负担。 |
| duolingo-dark-cloze-correct-feedback.jpg | 填空及正确反馈：选项有立体边界，正确选项与反馈以绿色强调，继续按钮固定在底部。 |

共同特征：与用户先前提供的关卡地图采用连续的深色背景；明亮文字与低噪声轮廓建立层级。色值需结合实际截图与对比度验收确定；静态截图不能证明点击时序、动效或音频规则。

本项目长期原则见 [设计原则](../../../../design-principles.md)。
