## 本课采用的设计规则

以下是基于用户实际迟疑反馈和上述资料的项目设计决定，不是 Duolingo 官方组件规范。

| 角色 | 颜色与形态 | 交互和反馈 |
| --- | --- | --- |
| 背景、对话 | 保持原有灰绿背景和浅色平面气泡；对话气泡取消按钮式厚底边。 | 内容可读，独立的 44×44 重听控件说明声音入口。 |
| 待选内容 | 淡蓝 `#dcebf3`，蓝灰边界 `#5e849c`，5px 底边。 | 默认就显得可按；触屏不依赖 hover。文字/图片选择有空心选择标记。 |
| 已选择 | 更深淡蓝 `#bcdff1`、深蓝边界及实心选择标记。 | 选中不等于答对；用户可换选，再按检查。 |
| 主要动作 | 延续绿色检查/继续。未作答或必须听完时保留禁用态。 | 动作位置与含义稳定；本轮不增加提交步骤。 |
| 已确认与配对完成 | 绿色结果面、对勾和原有结果文案。 | 结果可见，不能只靠颜色；已配好的词仍可重听。 |
| 错答重试 | 暖黄色选项状态和具体反馈。 | 指明当前人物需要，保留重试，不处罚或清空主线进度。 |
| 角色答案 | 双猫答案放在对话之后，各有“选这只猫”动作条。 | 整卡可按，点击后显示“已选择”，通过后显示“已确认”。 |
| 听词与拼句 | 词卡有明确播放条，已听过仍显示重听；可加词块有加号、已选词块有撤回符号。 | 标记说明操作，不新增常驻说明段落。 |

判断标准是“无需猜测操作对象，并能看见自己的操作结果”，不是“把整页涂成鲜亮颜色”。图片、文字、按钮均保留明确的语义控件；完整学习效果和真实儿童发现操作的速度仍需使用观察。
