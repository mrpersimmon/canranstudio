**Duolingo 的人机交互与 UI 设计，可以概括为：让用户容易知道下一步、容易完成操作、立即理解结果，并持续感受到进展。**它的可爱画风、角色和动效，服务于这套体验，而不是独立的装饰。官方教学方法与设计复盘，也把互动、持续动机、愉悦感和界面清晰性放在一起考虑。Duolingo Blog

上图是网页端的路径示例，用于观察布局与状态，不代表所有 App 版本。下面以官方公开的产品设计说明、界面示例和品牌规范为依据；设计目的与我的归纳，不等于每项设计都已经被证明能提升学习效果。

## 一、人机交互：让用户始终知道“现在做什么”

人机交互关注的不只是点击，而是四个问题：我在哪里？可以做什么？操作是否生效？接下来怎么办？

### 核心交互设计汇总

| 设计维度 | Duolingo 的典型做法 | 可以提炼出的设计理念 |
| --- | --- | --- |
| 入门引导 | 询问学习目标，允许从零开始或通过测试确定起点。 | 先确定适合的开始位置，不让用户直接面对庞大的课程系统。Duolingo Blog |
| 默认学习路线 | 将新知识、练习和故事编入路径，明确当前可继续的节点。 | 把“应该怎样安排学习”的复杂决策交给系统。Duolingo Blog |
| 小步推进 | 课程由较短练习组成；中级 mini-units 减少一次引入的新内容，并更快进入实际使用。 | 降低开始负担，同时提供频繁、明确的阶段终点。Duolingo Blog |
| 聚焦当前任务 | 常规练习突出题目、作答区和底部操作；提示按需展开，而不是全部常驻。 | 让主要注意力用于学习，不用于寻找控件和阅读操作说明。Duolingo Blog |
| 逐步增加挑战 | 从有图片、词库等支持的辨认，逐步进入自行输入等更难任务。 | 保持操作容易理解，同时逐渐增加语言处理要求。Duolingo Blog |
| 明确回应操作 | 答题结果与角色反应连接；说话、停止、正确和错误可以触发不同动画状态。 | 系统不只是接受输入，还要让用户感到“它理解并回应了我的行为”。Duolingo Blog |
| 提供帮助与替代路径 | 公开示例包含词义提示、音频重听，以及当前不能听／不能说的替代入口。 | 将困难与使用环境纳入流程，而不是假设用户始终处于理想状态。Duolingo Blog |
| 让持续投入可见 | 路径、连续学习记录、任务和阶段庆祝呈现不同尺度的进展。 | 不只反馈“这一题怎么样”，还反馈“我正在坚持并向前走”。Duolingo Blog |

### 最值得借鉴的，是“稳定的操作预期”

从官方常规练习示例，可以归纳出一套熟悉的节奏：

理解任务 → 选择、组织或输入 → 检查 → 获得反馈 → 继续。

题目内容变化，但用户不需要每次重新理解整套界面。官方展示的多个练习，主操作都位于底部；选择状态、不可操作状态和音频入口也有明显区别。Ghost Storage

不过，这不意味着所有活动都必须套用“检查—继续”两次点击。Adventures 的交互更接近完成现实任务：移动、选择、与角色交流，再看到故事后果。Duolingo Blog

对产品设计的启示是：

统一操作含义，而不是强迫所有学习动作走同样多的步骤。

## 二、UI：用视觉层级告诉用户“看哪里、点哪里”

Duolingo 的视觉特征确实鲜明，但它不是简单的“绿色＋圆角＋卡通”。更准确地说，是清楚的结构、统一的形状语言、明确的状态，以及有辨识度的品牌表达。

### 核心 UI 设计汇总

| 设计维度 | 典型表现 | 设计价值 |
| --- | --- | --- |
| 信息层级 | 题目、学习内容、候选答案和主要操作有明显主次。 | 用户能先找到当下任务，而不是把所有内容当成同等重要的信息。Ghost Storage |
| 色彩分工 | 绿色承担核心品牌识别；中性色组织文字与背景；其他鲜明颜色用于交互、插画和不同场景。 | 颜色既建立品牌，也帮助组织信息，不是每个区域都争夺注意力。Duolingo Blog |
| 圆润形状与按钮轮廓 | 圆角按钮、清楚的边界，以及部分按钮可见的底边厚度。 | 我将其理解为一种“看起来能够按下”的视觉提示，而不仅是可爱造型。Duolingo Blog |
| 字体分工 | 公开品牌规范使用 Feather Bold 表达简短大标题，DIN Next Rounded 承担较长标题和正文。 | 品牌个性与长文本可读性由不同字体职责承担，不把所有文字都做成展示字。Duolingo Blog |
| 留白与分组 | 使用间距、对齐和少量文字样式建立关系，而不是给每块信息都套卡片。 | 减少视觉噪声，同时保持结构清楚。Duolingo Blog |
| 插画辨识度 | 用较少但关键的形状表达物品，重视轮廓、构图和小屏识别。 | 图片首先要让学习者认对对象，然后才是风格与趣味。Duolingo Blog |
| 角色表达 | 角色有一致身份、表情和动作，并参与对话与反馈。 | 品牌从静态标志变成可互动的学习伙伴。Duolingo Blog |
| 完整状态设计 | 同一控件在选中、禁用、播放等状态下发生清楚变化。 | 界面能解释“当前发生了什么”，而不只是初始画面好看。Ghost Storage |

### 关于颜色，有一个容易被误解的地方

官方品牌核心色包括绿色 #58CC02、深灰 #4B4B4B 和白色 #FFFFFF，并配有蓝、红、黄、橙、紫等辅助色。**这些是品牌色板，不等于所有组件都有唯一、永远不变的颜色映射。**Duolingo Blog

例如，官方听力界面中，选中的答案使用蓝色，而“检查”按钮使用绿色。因此不能简单总结成“绿色就是选中”。Ghost Storage

借鉴时真正需要建立的是：

品牌色、主要行动、选中状态、成功状态、错误状态和禁用状态，各自有清楚且稳定的规则。

### 关于插画，最重要的不是“精细”

Duolingo 的美术团队明确指出：插画不清楚，可能直接导致学习者答错；细节太少会产生歧义，细节太多又可能妨碍一眼识别。Duolingo Blog

因此，对学习产品而言：

一张缩小后仍能认出是衬衫的简单插画，比一张精美但容易与外套混淆的插画更有价值。

这是教学素材质量与纯美术质量之间的重要区别。

## 三、动效与声音：把“系统状态”变成可感知的反馈

### 1. 动效不是不停播放，而是与事件连接

Duolingo 公开的角色动画方案使用状态机：根据音频时序驱动口型，根据用户操作停止或改变动作，并根据答案结果进入相应反应状态。Duolingo Blog

从设计职责看，可以将其归纳成四类：

| 动效职责 | 要回答的问题 | 借鉴时的重点 |
| --- | --- | --- |
| 操作确认 | “我的点击被接收了吗？” | 反馈应紧跟操作，不让用户反复点击猜测。 |
| 注意力引导 | “现在该看谁、看哪里？” | 只突出当前有意义的变化，不让所有对象一起动。 |
| 结果表达 | “我刚才的行为带来了什么？” | 正确、错误、播放结束等状态需要可区分。 |
| 阶段庆祝 | “我完成了什么值得记住的事？” | 重要节点与普通操作应有不同分量。 |

这四类是我的设计归纳。官方美术说明强调动画引导注意力，产品更新也展示了连续学习里程碑、课程结束和奖励场景的不同动画用途。Duolingo Blog

值得复制的是这种分工，不是把每个元素都加上弹跳、发光和撒花。

### 2. 视觉、声音和语言承担不同职责

可以把它们理解为：

**视觉反馈：**迅速显示选择与状态。

**音效反馈：**强化确认或奖励感。

**教学语音：**提供需要学习的语言内容。

Duolingo 的声音设计参与者介绍过，将普通连击、更高连击和完美课程的奖励声音组织为同一声音家族的不同等级。这说明声音也可以是一套系统，而不只是零散音效。AMBROSE YU

对儿童英语网站，我建议进一步约束：教学语音优先，奖励音效不要遮盖或推迟需要听清的词句；关闭音效后，用户仍然应当理解结果。

### 3. 不同活动可以使用不同反馈方式

普通练习可以直接告诉用户对错；Adventures 则公开采用“沉浸式反馈”：回应不合适时，角色可能表现困惑并重新引导，而不是像批卷一样直接纠正。Duolingo Blog

两者分别适合不同任务：

辨认与结构练习，需要清晰判定。

交际与故事行动，需要让用户理解表达产生的后果。

不是所有错误都只需要一个红叉，也不是所有错误都值得演一段剧情。

## 四、它更深层的设计方法：一致，但不机械统一

Duolingo 的核心页面改版复盘提出了两组重要权衡：

一致性要服从页面用途，简洁性不能牺牲清晰度。

例如，为每个页面都放一张大插画，形式上很统一，但可能没有信息价值；删除太多容器和标记，画面更简洁，却可能让内容关系不再清楚。Duolingo Blog

所以，一套可复用设计系统应该统一的是颜色角色、文字层级、间距、控件状态与反馈规则，而不是要求每个页面都长得一样。

它也不是只在设计稿里追求一致。官方介绍过跨语言、跨设备截图检查工具，用于发现文字溢出、布局和视觉问题。Duolingo Blog

设计系统的完成标志，不是有一页漂亮的组件库，而是不同内容、不同状态、不同屏幕下仍然清楚、可用。
