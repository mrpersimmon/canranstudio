为了帮助你做产品设计，我将官方公开介绍的主要机制整理为：
18 类基础题型＋6 类组合式学习活动。
这是本文的分析口径，不是官方宣布的题型总数；两者存在包含关系，不能简单相加成“24 种互斥题型”。
下文的英语题例大多是我自拟的，用来说明机制，不是官方题库原题。“流程”描述官方展示的典型交互，“设计理念”则结合官方解释与任务本身分析；按钮位置、自动推进和具体重试规则可能因版本而异。

一、18 类基础题型：流程、设计理念与能力边界
先看整体分布：
类别	本文划分数量	主要解决的问题
词汇与意义连接	4 类	“这个词是什么意思？”
听音辨认与转写	4 类	“我刚才听到了什么？”
句子组织与语法	4 类	“这个意思应该怎样表达？”
语篇理解与交际判断	3 类	“这段话是什么意思？此时应该如何回应？”
口语输出	3 类	“我能否把相应的英语说出来？”
A. 词汇与意义连接：4 类
1. 图词选择：看词选图／看图选词
典型流程：
出现一个词和若干图片，或者出现图片和若干词语 → 选择对应项 → 获得正确或纠正反馈 → 继续。
例如，看到 handbag，从手提包、衬衫和汽车中选择对应图片。Duolingo 官方将“新词与图片匹配”列为较容易的练习，与后续包含该词的句子翻译形成难度递进。Duolingo Blog
**设计理念：**先建立“语言形式—具体意义”的联系，暂时不要求学习者同时处理拼写、完整句法和口头表达。
**能力边界：**选对图片，说明这次能辨认词义，不等于能独立想起、拼写或说出这个词。

2. 双语词汇配对：Tap the matching pairs
典型流程：
屏幕显示两组词，一组是学习语言，另一组是母语 → 分别点击对应的两个词 → 正确配对被标记完成 → 继续匹配剩余词。
例如，将 handbag 与“手提包”、shirt 与“衬衫”配对。官方的阅读练习介绍展示了这种双列词汇配对。Duolingo Blog
**设计理念：**用少量操作集中复习多个词，强化已经建立的双语对应关系。
能力边界：所有答案都在屏幕上，主要是有选项的辨认；随着剩余选项变少，排除法的帮助会变大，不能把每一对都当成同等强度的记忆证据。

3. 音频—文字配对
典型流程：
一侧是音频按钮，另一侧是词语 → 点击音频听一个词 → 选择对应文字 → 配对反馈 → 完成整组。
Duolingo 的英语发音专项，以及听力练习中，都公开展示过这种模式。文字一侧可能是英文词形，也可能是母语译义。Duolingo Blog
**设计理念：**让声音与书面形式或意义建立联系，同时避免完整句子带来的额外负担。
**能力边界：**需要区分两个不同任务：
英语声音 → 英文词形，主要检查声音与拼写轮廓的对应；
英语声音 → 母语词义，还要求完成意义识别。
它们可以共用同一个配对组件，却不应被记录成完全相同的学习证据。

4. 语境猜词／英英释义选择
典型流程：
阅读一小段英文，其中某个词被突出显示 → 根据上下文，从几个英文解释中选择其含义 → 获得反馈。
例如：
The bag is enormous. It cannot fit in the small locker.
再从英文解释中判断 enormous 的意思。Duolingo 的 B1、B2 英语内容明确展示了这种“英文段落＋英文释义选项”的题型。Duolingo Blog
**设计理念：**逐步减少对母语翻译的依赖，训练学习者用已知英语和语境理解新词。
**能力边界：**这比直接选中文译义多了一层语境理解，但仍然属于有选项的判断，不能直接等同于独立使用该词。

B. 听音辨认与转写：4 类
5. 近音辨析：听出两个声音的区别
典型流程有两个常见变体：
听一个词 → 在两个近音词中选择；或者听两段音频 → 判断两者相同还是不同 → 反馈后继续。
例如辨认 ship 与 sheep。官方英语发音专项展示了近音词选择、两段音频同异判断，并强调每次聚焦少量声音差异。Duolingo Blog
**设计理念：**把注意力集中在声音差别上，而不是同时增加生词和语法。目标是让原本容易被听成一类的声音变得可区分。
**能力边界：**听得出区别，不代表嘴巴已经能稳定发出区别；听辨和发音应分别验证。

6. 听音选词：选择听到的一个或多个词
典型流程：
播放一段音频 → 显示若干候选词 → 选出实际听到的词，某些题要求选择两个或三个 → 提交并获得反馈。
例如，音频包含 book 和 pencil，候选项中还混有未出现的词。官方 DuoRadio 的英语示例中，明确有“选出听到的三个词”的任务。Duolingo Blog
**设计理念：**练习从连续语音中捕捉已知词，不要求先听懂全部内容，也不要求完整转写。
**能力边界：**听到了几个关键词，不代表理解了它们之间的关系。例如听出 not、my、bag，还需要进一步理解整句是在否认归属。

7. 听音词块组句：Tap what you hear
典型流程：
播放一句话 → 从词库中依次点选词块 → 拼出听到的句子 → 提交 → 反馈。
例如听到：
Is this your handbag?
再从打乱的词块中组织出这句话。官方听力介绍展示了该模式，并提供正常速度、慢速或重听等支持。Duolingo Blog
**设计理念：**将连续声音分解成词序列，同时用词库降低拼写与键盘输入负担。
能力边界：词库本身提供了线索。因此，它更接近受支持的听音辨认与顺序重建，不是无提示听写。

8. 完整听写：Type what you hear
典型流程：
听一句话 → 不依赖完整词库，自己输入听到的内容 → 提交 → 查看判定和纠正。
Duolingo 官方将“输入听到的内容”列为写作与拼写练习的一部分。Duolingo Blog
**设计理念：**在听音辨认之外，要求主动提取词形、拼写和词序，比词块组句撤掉了更多支架。
**能力边界：**失败原因可能不同：没有听清、记不住整句、不会拼写，或者输入失误。因此，听写总分不能直接当作纯听力水平。

C. 句子组织与语法：4 类
9. 词块翻译：用给定词块组织译文
典型流程：
呈现源语言句子 → 给出打乱的目标语言词块 → 选择并排序 → 提交 → 获得反馈。
例如：
这是你的手提包吗？
使用 Is / this / your / handbag / ? 组成英文。Duolingo 官方明确区分了词库翻译与键盘输入，并指出两者对主动回忆的要求不同。Duolingo Blog
**设计理念：**先降低拼写负担，让学习者集中处理词义选择和句法顺序。
**能力边界：**母语译成英语，偏向受支持的表达；英语译成母语，偏向理解。只是交换翻译方向，训练重心就会改变。

10. 自主输入翻译：单词或完整句子
典型流程：
给出一个词、短语或句子 → 学习者自行输入译文 → 系统判定 → 显示反馈。
它与上一类的关键区别，是不再提供完整词库。官方写作说明展示了单词翻译、句子翻译以及词库／键盘切换。Duolingo Blog
**设计理念：**要求学习者自己检索词汇、组织句子并拼写，而不仅是在给定答案中挑选。
能力边界：这是有指定意义的受控产出，仍不等于自由写作；同时，合理的多种译法需要被纳入答案判定，否则容易把表达差异误判成错误。

11. 选词填空：Select the missing word
典型流程：
显示一个有空缺的句子 → 提供少量词语或词形 → 选择最合适的一项 → 提交 → 反馈。
例如：
She ___ a handbag.
has / have
Duolingo 的阅读与沉浸式练习介绍均展示了选词填空。Duolingo Blog
**设计理念：**保留大部分句子，只把一个关键区别留给学习者处理，让注意力集中在目标结构上。
**能力边界：**题型本身不决定考察什么。has / have 主要区分语法；handbag / house 可能主要区分词义。真正定义能力的是空缺与干扰项，而不是“填空”这个名称。

12. 输入缺词：Type the missing word／Complete the translation
典型流程：
给出残缺英文句，配合译文或音频线索 → 自己输入缺少的词 → 提交 → 获得反馈。
它可以是补全翻译，也可以是听音补词。官方写作介绍展示了这两种形式。Duolingo Blog
**设计理念：**介于“选词填空”和“完整句子输入”之间：要求主动想起局部表达，但不要求重建整个句子。
**能力边界：**音频补词与译文补词的线索不同，应分别记录；也不能因为某个缺词填对，就推断整句已经可以独立表达。

D. 语篇理解与交际判断：3 类
13. 阅读理解：Read and respond
典型流程：
阅读一段短文或多句话 → 回答信息、原因或结论问题 → 从选项中选择 → 获得反馈。
例如，短文说某人因为下雨改乘公交车，再问他为什么没有步行。官方展示了“短文＋问题／待补全判断＋选项”的阅读理解形式。Duolingo Blog
**设计理念：**从“认识词”提升到“整合意思”，要求关联人物、动作、时间、原因等信息。
**能力边界：**只匹配原文关键词的题，和需要跨句推断的题，难度与证据强度不同。不能因为都叫阅读理解，就使用同一难度标签。

14. 听力理解：Listen and respond
典型流程：
听一段话或对话 → 回答其含义相关的问题 → 选择文字、图片或判断正误 → 获得反馈。
例如，听店员说明营业时间，再判断商店何时关门。Duolingo 官方教学方法和 DuoRadio 示例中，都展示了听后理解任务。Duolingo Blog
**设计理念：**要求从声音获得意义，而不是复原每一个词。
**能力边界：****听写与听力理解不应互相替代。**前者关注听到了哪些词及其形式，后者关注这些话传达了什么。

15. 对话接续选择：Complete the conversation
典型流程：
角色说出一句话 → 提供几种回应 → 选择最符合当前交际需要的一句 → 对话或反馈继续。
例如：
Is this your handbag?
从候选回应中选择符合归属确认的一句。Duolingo 的英语沉浸式内容明确展示了这种对话接续题。Duolingo Blog
**设计理念：**训练“此时应该说什么”，不仅关注句子是否符合语法，还关注它是否适合当前问题、目的和情境。
**能力边界：**能在选项中认出合适回应，不等于在没有选项的真实对话里可以及时想起并说出它。

E. 口语输出：3 类
16. 朗读／跟读：Read aloud／Repeat
典型流程：
显示完整目标词句，通常可以听示范 → 开启麦克风 → 读出或跟说 → 系统识别并反馈。
Duolingo 官方口语介绍将重复词语、朗读句子等列为早期口语练习。Duolingo Blog
**设计理念：**先让学习者练习把已知语言实际说出口，不同时要求构思内容和组织句法。
**能力边界：****这是“给定内容的发声”，不是“自主构思的表达”。**朗读通过，不应被解释为具备同等水平的自由会话能力。

17. 口头翻译／口头补全
典型流程：
看到母语意义或不完整的英文 → 从记忆中找出对应表达 → 对着麦克风说出来 → 获得反馈。
官方展示过口头翻译，以及带空缺句子的口语练习；部分输入题也可以通过麦克风说出答案。Duolingo Blog
**设计理念：**比完整文字跟读多了一步主动检索，但通过译文或部分句框限制任务范围。
**能力边界：**输入框使用语音转文字，只是改变输入方式；除非系统另有相应评估，不能自动把它当成细致的发音诊断。

18. 选择并说出正确回应：Speak the correct response
典型流程：
听或读角色的问题 → 看几个候选回应 → 判断哪个合适 → 说出相应回应 → 系统给出反馈。
官方入门和口语介绍都展示了这种“对话候选＋麦克风”的形式。Duolingo Blog
**设计理念：**把“判断该如何回应”和“实际把话说出口”结合起来，是选择题与开放会话之间的一步。
能力边界：答案已经可见，所以它仍然属于有支架的交际输出，不是完全独立的口语生成。

二、6 类组合式学习活动：不是单道题，而是一段体验
这些活动会组合前面的基础题型，或者引入开放式对话。它们的价值在于如何安排练习、如何制造情境、如何处理反馈，不只是换一个题目外观。
1. Flashcards：主动回忆闪卡
官方介绍的典型流程：
出现一组五张卡片，每张显示母语词语 → 说出学习语言的对应词，也可改用输入 → 正确则卡片标记成功并移走 → 错误则翻面展示答案、播放发音，并移到队尾再练 → 最后显示总结。官方介绍的版本以答对三张作为通过门槛，这属于该功能的具体规则，不是所有课程练习的统一门槛。Duolingo Blog
设计理念：解决“看到答案觉得认识，但需要时想不起来”的问题。重点是先回忆，再揭晓，而不是被动翻卡。
**最值得借鉴的地方：**纠错不是停在“告诉你答案”，而是稍后再次给出检索机会。

2. Stories：互动故事
典型流程：
进入一段故事 → 分段阅读、听角色对话 → 在关键位置完成理解、填空或词序等小任务 → 继续剧情 → 完成故事。官方将 Stories 作为把语言放进较长叙事和真实交际情境的方式。Duolingo Blog
**设计理念：**让词汇、语法与人物动机连接起来。学习者不仅处理一句孤立句子，还要记住谁做了什么、为什么这样说。
**注意边界：**官方跨语言写作介绍还展示了部分高阶故事中的自由写句任务，但这不能直接证明每条英语学习路线都提供同样的开放写作环节。Duolingo Blog
**与你的网站最相关的部分：**剧情本身承担练习之间的连接，不需要每做完一道题都退出场景、重新开一张任务卡。

3. DuoRadio：互动电台
典型流程：
进入电台节目 → 听角色主持、访谈或讲述 → 中间穿插听音配对、关键词选择、理解判断等题 → 继续收听 → 完成节目。官方英语课程示例说明，早期节目可以有母语支持，随后逐步过渡到更多英语。Duolingo Blog
**设计理念：**用连续、有内容的语音训练听力，同时通过短检查点确认学习者是否跟上。
它不是把十道听写题换成电台背景，而是：
先有一段需要理解的内容，再用少量题目检查理解。
**能力边界：**关键词辨认和整段理解仍需分别记录；节目播放完毕本身也不等于听懂。

4. Adventures：场景冒险
典型流程：
扮演角色进入场景 → 获得现实任务，如购物、找物品或问路 → 移动、点击物体、阅读线索、与角色交谈 → 根据语言完成行动 → 达成任务。
官方特别强调“沉浸式反馈”：回应不合适时，角色可能表现困惑或进一步询问，而不是直接弹出批改式红叉。公开说明确认过其在部分英语学习路线中的提供情况，不能因此推断所有英语账号都可用。Duolingo Blog
**设计理念：**让语言成为完成目的的工具，反馈体现为“我的表达在这个世界中产生了什么后果”。
**与你的网站最相关的部分：**这是最接近“失物招领站”方向的机制——听懂与表达不是游戏前面的考试，而是完成游戏任务所必需的动作。

5. Roleplay：AI 情境角色扮演
典型流程：
获得明确交际情境 → 角色发出消息 → 学习者自行组织回复 → AI 根据回复继续对话 → 多轮交流后提供表达准确性、复杂度等反馈与建议。
官方资料将其描述为开放、可互动的情境聊天，并在功能说明中列出英语学习支持；属于 Max 对话功能，具体可用性仍取决于课程与账号。Duolingo Blog
**设计理念：**把学习者从“选择已经写好的答案”推向“自己组织语言完成交际”。
**能力边界：**没有唯一标准句子，评估需要关注是否完成目的、表达是否准确得体；AI 的反馈也不能被当成绝对无误的判定。

6. Video Call：AI 实时语音对话
典型流程：
进入通话 → 角色发起话题 → 听懂问题并组织口头回答 → 角色据此追问或延续 → 多轮交流 → 通话后查看记录与反馈。
官方介绍了实时会话、通话记录，以及后续加入的反馈、初学者字幕和按键发言等支持；英语也在其公开功能覆盖范围中。Duolingo Blog
**设计理念：**把听力理解、词汇检索、句法组织、发声与轮流交谈放到同一次任务里，接近真实会话所要求的技能组合。
**与 Roleplay 的主要区别：**文字聊天通常允许更从容地阅读、构思和修改；语音通话更强调当场听懂、组织回应和维持交流。
**能力边界：**对话完成或获得经验值，不等于通过了标准化口语能力认证。

三、还有一些“模式”，但不应该重复算成新题型
很多网上的“Duolingo 题型大全”会把下面这些也全部加入，导致数字越来越大。实际上，它们改变的主要是组题方式、难度、时间约束或反馈。
模式	典型流程	设计目的	为什么不单独算基础题型
专项练习：Words／Speak／Listen	选择技能 → 连续完成相应练习 → 查看结果	集中练习某一薄弱技能	主要重新组合配对、听力、朗读等已有题型
错题复习：Mistakes	提取此前错误 → 再练相应内容 → 反馈	针对具体困难安排练习	变化的是选题依据
限时挑战：Match Madness 等	在倒计时内完成词汇配对或练习	增加熟练度与挑战感	基础动作没有变，增加了时间压力
传奇挑战：Legendary	对已完成内容进行更难、无提示的挑战 → 完成后获得相应标记	检查较少支架下的表现	变化的是难度与提示条件
专项和错题入口可见官方 Practice 说明；限时与传奇模式的典型机制可见官方练习指南。Duolingo Blog
类似地，Explain My Answer 是反馈工具，不是一种新的考察题型；它帮助解释答案，而不是定义学习者需要完成哪一种作答。Duolingo Blog

四、这些模式背后，真正统一的设计理念是什么？
1. 不是追求题型多，而是逐步撤掉支架
Duolingo 官方方法明确强调，从较简单的内容与练习开始，再逐步增加挑战，让学习者把学到的东西用于新情境。Duolingo Blog
从设计上，可以理解成这样一条路径：
看见答案能辨认 → 给部分线索能补全 → 没有选项能想起 → 能把表达用于对话。
例如，同一个词可以依次出现在图片选择、配对、填空、听写、闪卡回忆和情境对话中。
**这不是六次重复同一道题，而是在改变线索与输出要求。**当然，也不意味着每个词都必须机械地走完所有题型。
2. 同样的点击动作，可以检查完全不同的能力
下面五个操作，表面上都可能只是“点击一件物品”：
提供的线索	学习者需要完成的处理
显示 handbag	从英文词形理解意义
只播放 handbag	从英语声音理解意义
先讲完一段物品归属对话	整合对话信息
中文直接说“点这个手提包”	按指令执行，未必需要处理英语
正确物品提前发光	可能只是跟随视觉提示
这是对任务逻辑的分析：**组件相同，不代表证据相同。**对你的网站而言，最重要的不是多实现几个按钮样式，而是明确孩子究竟凭什么答对。
3. 辨认、回忆、组织与交际，需要不同形式的练习
从候选中选中一句话，不需要自己找出全部词汇；词块组句不需要自己拼写；朗读不需要自己决定说什么；开放对话则同时要求理解与产出。
Duolingo 新增 Flashcards 时，就明确指出“认得一个词”和“需要时主动想起来”是不同任务；英语沉浸式内容则进一步减少了对母语翻译的依赖。Duolingo Blog
因此，产品中不宜只有一个笼统的“答对率”。至少在设计与分析层面，要能区分：
有选项辨认、无选项回忆、受支持组织、开放交际。
4. 综合活动的作用，是让技能相遇
基础题型可以把困难拆开；Stories、DuoRadio、Adventures 和对话，则让词汇、语法、语境重新组合起来。官方介绍的新 mini-units 也强调，少量新内容应更快进入故事、听力和对话中使用。Duolingo Blog
对你的“失物招领”主题，可以据此设计：
先认识物品名称，再听懂归属对话，再选择合适的确认句，最后在变化情境中独立完成一次询问与归还。
这比“实现 18 种题型，然后每关随机抽几个”更有教学意义。
