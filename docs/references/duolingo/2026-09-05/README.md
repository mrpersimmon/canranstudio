## 本课的取舍

学习目标是理解和使用原课文的礼貌用语、归属确认以及 11 个具体物品词。完整课文与双猫对话已合并为手动互动故事，穿插理解和行动判断；后续使用图词配对、听句找物、选词补句和词块组句。每种活动都有明确的线索、输出及证据边界。

不为凑齐题型加入键盘听写、开放 AI 会话、限时配对或假口语评分。成组配对的最后一对可由排除法完成，单独记作“排除支持”；整组属于辅助练习，不按四次独立掌握计分。词卡听完只表示接触过内容。

原文尚未逐项复核的功能：最小对立音、Flashcards 的容错细节、Video Call 的最新字幕与反馈覆盖、不同账号的专项入口。它们未进入本次实现，因此不作为本课的已确认产品事实。

当前课程方案见 [前六课连续路径设计](../../../designs/lesson1-6-path-v4/implementation.md)。此前交互版本的关键决定已纳入当前方案：完整互动故事、手动推进、清楚的蓝色选项、绿色主操作、归还物品前明确确认。本分支不保留已被替代的旧方案文件。
