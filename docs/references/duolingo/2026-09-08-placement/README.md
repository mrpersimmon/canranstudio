用户明确要求：抽取被跳过章节及更早内容中的挑战题，第五次错误结束本次跳级。该规则直接采纳，不以其他 Duolingo 版本的普通课程心数替代。

补查：[Duolingo 官方使用说明](https://blog.duolingo.com/duolingo-101-how-to-learn-a-language-on-duolingo/)（2026-09-08 核对）说明可以通过水平测试跳过已掌握单元，跳过后仍能回顾课程，并介绍从辨认到自行输入的难度递进。这支持“允许有基础者前进，但仍能回头学习”的产品方向；不用于推断其私有抽题算法。

本次确定的 20 题、跨章节分段抽样、记录与恢复方式，见 [实施规则](../../../designs/placement/README.md)。
