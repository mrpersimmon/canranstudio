# 纪念册统一设计标准

版本 1.5，2026-10-30。适用 `codex/book-version` 的时光邮局纪念册及后续扩展。该文件汇总已经确认的视觉、交互、数据保护和验收规则；早期方案稿与修订记录作为依据，不再作为并行的界面标准。

纪念册采用「每六课一封信，每封信收纳三张原纪念卡」。环境负责承载，原纪念卡是主体。点击信封上的卡片打开保存面板，不再提供独立“查看原卡”按钮，也不提供“放大查看原图”文字、图片链接或新窗口跳转。

## 1 范围与依据

- 正式页面实现位置为 `award-book/`，路径为 `/awards/` 或内部前缀下的 `/lesson/awards/`。覆盖 Lesson 1–144 的72个配对单元、24章；实际展示当前账号已获得的收藏。`poc/keepsake-postoffice/` 保留为已认可的1–12视觉样板，不能代替真实账号页面。
- 本文件管纪念册承载界面。授星、首次五星日期、旧证和历史版本继续遵守[教学单元统一标准 v1.55](../butcher-version/publish/2026-10-24-2200-v1.55-教学单元设计标准与验收清单.md)及[永久收藏规则](../adr/2026-09-26-2336-v1.0-ADR0023-奖章按版本永久收藏.md)。本分支替换纪念册的承载界面，不改变学习记录、奖励规则或课程授权；官网发布另行授权。
- 视觉依据为[已选时光邮局示意](../../poc/keepsake-postoffice/design/selected-reference.png)与用户后续标注。后续标注明确取消的控件，优先于示意图中原来画出的控件。
- 正式接入的实际检查、截图与限制见[接入与验证记录](2026-10-30-时光邮局正式接入与验证.md)；[原型验收记录](../../poc/keepsake-postoffice/design-qa.md)仅保留当时范围。设计目标不能写成已验证结果。

| M02 | 每章三个固定卡位，已获卡为不同主卡，缺卡位显示“尚未收藏”并禁用。柜台大卡是当前选中卡的展示，不算额外收藏，不在目录里重复出现。 |
| M03 | 缩略图用于切换卡片。选中框和Lesson底色同时变绿；每个控件的可访问名称包含完整课号与卡名。 |
| M04 | 信封上的主卡是查看和保存的入口。使用原生button，可轻点或键盘激活；不再放置第二个“查看原卡”按钮。 |
| M05 | 保存面板包含卡名、Lesson与章节、原纪念日期、完整卡片、本章上一张／下一张、保存原动图及关闭。卡片本身是被动图片，不设放大链接、`target=_blank`或原图跳转。 |
| M06 | 保存仅导出当前卡片。正式账号复用既有 `award-card-layout` 与 `award-gif`，按原姓名、星数和首次五星日期生成984×528、60帧GIF；原型直接下载既有GIF。不得下载邮局截图、重绘卡面或下载另一张卡。反馈可说“动图已生成”，不冒称已写入手机相册。 |
| M07 | 章节信箱展示章节名、完整Lesson范围、已获得数量和当前章标记。切回章节恢复本次会话最后选择；无有效记录则选择该章首卡。 |

标题旁搜索使用44×44px放大镜按钮；输入框只在搜索抽屉中出现。页面不增加浮在卡片下面的白色课号／计数条。缩略图和面板已提供对应信息，读屏状态仍播报选中卡片。

## 4 环境与卡片组合

| 编号 | 规则 |
| --- | --- |
| M12 | 复用已确认的奶油墙、青绿木窗、森林绿POST邮筒、赤陶小镇、黄铜邮戳、暖木柜台和奶油信封。两章共用邮局承载场景；不为扩课重绘卡片或改变整体画风。 |
| M13 | 背景与主卡共用1070×1470坐标系并等比缩放。当前卡位左3%、顶57.3%、宽94%，原图比例984∶528，顺时针1.1度。背景禁止cover裁切后再按视口独立定位卡片。 |
| M14 | 原卡在前，信封翻盖和绿色内衬在后。v3信封约在横向7.3%–92.2%，底边82.7%；下部与侧角须被主卡覆盖，不能形成突出的白色纸角。 |
| M15 | 标题区左上约0–64%横向、0–35%纵向留低细节奶油墙。高对比窗框、花叶、印章和按钮不能穿过文字。Lesson等实时文字用HTML，不生成进环境图。 |
| M16 | 原卡不拉伸、不截断人物、标题、姓名、星星或日期。展示图用contain或自然高度；卡片内部版式与金框保持原样。 |

**M17　页面边缘与下载文件分别验收。** 旧GIF曾铺满不透明浅色底，圆角卡纸外和四边仍有约4px实色留白；原型通过四边4px裁切、21.2px圆角遮住它，只修复了页面显示。2026-10-30起正式新导出必须在文件内部消除白边：卡框贴齐984×528画布四边，圆角外为透明像素，不铺浅色底，也不以透明矩形边距替代删除留白。正式页面仍使用1640×880设计平面的原Card DOM，不靠CSS裁切证明下载正确。历史原型GIF及其来源SHA保留，旧文件的显示裁切仅用于历史样板；新导出执行M47–M49。其他尺寸或旧证书另核对轮廓。

## 5 搜索与章节切换

| 编号 | 规则 |
| --- | --- |
| M18 | 搜索始终跨当前账号已拥有的全部主卡。当前章只影响柜台和三张缩略图，不限制搜索。匹配单个Lesson、范围、卡名，兼容大小写、空格、全角数字和常用横线。 |
| M19 | 数字按闭区间匹配。`8`只对应7–8；`11`只对应11–12，不能用字符串包含误匹配1–2。范围返回相交单元；反向范围不命中。 |
| M20 | 搜索结果含原卡缩略图、完整Lesson、卡名和章节。选择结果同时定位所属章节与卡片，关闭搜索和键盘；唯一结果可按Enter进入。清空恢复全范围，无结果时说明搜索只包含已获纪念卡，不能伪装成可用卡片。 |
| M21 | 切章保留背景、标题容器与导航，先准备并解码目标卡，再切换可见内容；等待时保留当前卡，失败可重试。连续选择只接受最后一次请求，不能让迟到结果切回旧章。 |
| M22 | 柜台、缩略图、面板和保存文件从同一selected卡派生。面板上一张／下一张只在本章三卡内操作；章节切换使用章节信箱，防止计数与章名串位。 |

示例：`2`→礼貌小帮手；`Lesson ８`→新朋友小记者；`9–10`→暖心问候小伙伴；`11`→归还物品小能手；`新朋友`可命中两章不同卡片。正式版继续覆盖Lesson13–144；数字范围以课程ID匹配，未获得的卡不能被搜索伪装成已收藏。

原型的六张GIF只用于视觉演示。正式版首屏准备当前章的三张原插图与共用素材；手动解码缓存最多保留12张课程插图加5张共用素材，搜索缩略图延迟加载，不能首屏编码72份GIF。全部收藏的文本索引应先于大图片可用。

## 6 手机交互与响应式

| 编号 | 规则 |
| --- | --- |
| M23 | 手机保持一张主卡和三张选择缩略图，不做3D翻页书，不强求所有内容同屏；短屏自然纵向滚动。固定底部导航必须有等高内容留位。 |
| M24 | 搜索、关闭、上一张／下一张等命中区至少44px；输入框至少16px。关闭系统蓝色触摸高亮，保留键盘可见焦点。拖动不能误点击，拖动之后仍能正常轻点。 |
| M25 | 搜索结果保持在键盘上方，长结果列表允许纵向滚动，不能被弹层父容器的touch-action阻断；拖动手柄单独处理。不能在pointerdown时主动失焦；等click成立后再收键盘，避免按钮在pointerup前移动。清空后继续聚焦；Tab、Escape、关闭和指针取消分别核验。 |
| M26 | 只滚动应用内容区域，聚焦使用preventScroll。禁止无边界scrollIntoView移动设备外壳、造成键盘残留或状态栏位移。关闭弹层时清理旧延迟回焦任务。 |
| M27 | 卡片切换只作轻微位移，不卸载整个页面，卡面始终不透明；禁止用降低整卡opacity的淡入让背后的信封透出来。“界面动效”默认遵从系统减少动态，也允许个人显式选择；原星光、金框和导出GIF保持原奖励效果，不被该开关整体关闭。 |

本地原型保留iPhone393×852和Pixel427×952的设备壳与键盘模型。它们验证模拟布局和指针行为，不证明实体Android、微信、夸克或95%真实设备覆盖。正式网页接入使用项目已固化的尺寸矩阵及手机优先策略；桌面不将手机柜台横向拉满，环境和卡位仍同源等比。

搜索抽屉的最终高度不得超过「屏幕高度－顶部安全区－键盘高度／底部系统区」。原型模板本身会扣除最多180px，调用方须合并计算。正式页面直接读取 `visualViewport.height/offsetTop`，搜索输入与关闭区不滚动，结果在剩余高度中滚动；不能用外层高度限制替代实际可见边界检查。

## 7 素材与提示词固定

采用文件：[postoffice-scene-v3.png](../../poc/keepsake-postoffice/public/art/postoffice-scene-v3.png)。原始提示词与编辑记录：[初稿](../../poc/keepsake-postoffice/design/scene-prompt.json)、[文字安全区](../../poc/keepsake-postoffice/design/scene-v2-prompt.json)、[信封比例](../../poc/keepsake-postoffice/design/scene-v3-prompt.json)。正式72单元复用该环境，不新增环境或纪念卡生成。

后续环境修订必须带已选示意和当前采用图作参考，固定以下约束：

> 温暖细腻的手绘小镇邮局，奶油墙、青绿木窗、赤陶远景、森林绿POST邮筒、黄铜邮戳、暖木柜台、奶油信封和鼠尾草绿内衬。左上文字安全区保持明亮低细节。信封所有侧角收在完整原卡之后，留出翻盖与绿色内衬。保持1070×1470承载比例和现有光照／视角。不得生成卡片、人物、姓名、星星、Lesson、搜索框、导航、设备边框或占位白牌。唯一保留的环境文字是POST。

生成目标和实际采用位置分别记录；不能因为生成图偏离坐标就临时挪动标题遮挡人物。原卡、品牌、图标、字库均复用现有资源。正式环境文件及SHA见[采用素材说明](../../assets/awards/postoffice/README.md)。

## 8 验收与问题拦截

| 已出现问题 | 必须拦截的标准 |
| --- | --- |
| 手机上的翻书展开奇怪 | 手机采用纵向柜台；设备壳、键盘和导航布局独立于内容动画。 |
| 一页重复卡片、只显示数字 | 每课一张主卡，Lesson与卡名完整；放大主卡不重复计数。 |
| 人物／背景或星章归属错乱 | 原卡作为完整对象呈现，所有信息由同一课程记录派生，不拆星星单独定位。 |
| 标题压在花叶或窗框上 | 在真实手机安全区和实际文字长度下验收组合图，保留标题安全区。 |
| 页码白标、信封白角、GIF白边混淆 | 分别检查UI标签、环境几何、图像画布；GIF四角和四边放大并用像素证据核对。 |
| 搜索框割裂场景、操作重复 | 标题放大镜展开搜索；只点主卡进入保存，不保留独立查看或放大原图入口。 |
| 键盘先收起导致点击无效 | 在键盘打开时直接点结果，一次完成；再测清空、Tab、Escape与取消。 |
| 切章闪烁、串章 | 目标解码前保留旧卡；快速改选只接受最后请求；章名、缩略图、日期和下载同时核对。 |

每次扩展至少核对：原卡来源与SHA；Lesson单号／范围／中文跨章搜索；章节往返及会话内选中恢复；每张卡点击保存；本章前后边界；真实画面的四角／四边；两种手机模型；控制台；构建与运行壳完整性。新增加载逻辑需覆盖延迟、失败和重试。真实手机与正式发布验收另行记录，不能以静态检查替代。

## 9 正式接入的额外约束

| 编号 | 规则 |
| --- | --- |
| M28 | 收藏从登录后的 `api/awards` 获取；使用原接口的主卡／历史版本拆分，不按当前开课清单删掉已经获得的卡。关课不恢复课程访问权，也不收回原收藏。 |
| M29 | 零收藏显示学习引导；只有部分星时不得加五星金框或补日期；稀疏收藏保留原章内卡位，上一张／下一张跳过缺卡。 |
| M30 | 姓名、星数和首次满星日期由同一条记录派生。主卡、面板与保存不得分别读取不同版本；长姓名在整卡缩放之外另有可读文本，不截断姓名。 |
| M31 | “我的”按修改密码、退出登录、历史收藏、本机旧记录、纪念册动效的顺序呈现，并与课程共用组件。历史收藏保留旧版本、原纸证和本机副本的既有查看／下载路径；首页不铺旧资料提示。 |
| M32 | 页面隐藏、退出、学生身份变化后及时清空个人卡片，终止旧导出任务。选中记录按学生ID隔离；任何缓存不得把另一账号的卡展示出来。原待同步队列的身份、版本和generation核验保持不变。 |
| M33 | 卡片切换采用最后一次选择生效。加载失败保留原卡并提供重试；超时必须释放失败中的资源请求，不能让重试重复等待同一条卡死的Promise。首次加载期间打开／关闭“我的”不能永久取消卡片准备。 |
| M34 | 手机保持原生纵向页面，固定底部导航有等高留位；电脑采用章节侧栏与有宽度上限的邮局，不横向拉满画面。弹层垂直居中和最大高度使用同一个可见视口，实际bottom不得超过可见底边；不能把顶部margin再叠加到“视口高减32px”的最大高度上。 |
| M35 | 几何检查与画面验收分开。至少核对主卡、三缩略图、搜索、保存、空收藏、部分星、长姓名、历史版本和切章失败。固定60尺寸矩阵是选样，不等于95%真实访问覆盖；真实Android微信／夸克和软键盘仍需手机实测。 |

**M36　界面字体不能阻塞原卡。** 界面标题和目录标签使用独立的小字库，覆盖当前静态文案与全部卡名，保持原字体轮廓和度量；当前774字符、124552字节，源码变化后重新生成并核对来源清单，旧125444字节记录保留其原范围。原纪念卡与姓名的完整字库保留。原卡就绪／保存只等待本卡所需字体与素材，不能额外等待界面装饰字体；即使界面字体一直未返回，原卡仍须出现并可保存。服务器隔离冷启动必须纳入上线检查，不能只看本机缓存命中。

**M37　完整字库的冷载等待独立验收。** 原卡完整姓名字库不能为追求首屏裁字。实际服务器限速链路下，原卡准备预算为60秒、单图片45秒，期间保留旧卡和明确的等待状态，允许取消与改选；HTTP错误仍立即进入可重试状态。测试要跨越旧20秒窗口后释放真实字体请求并核对原名、原星数，服务器验收须等待真实就绪或明确失败，不能用执行器默认5秒代替产品预算。

**M38　搜索必须保留原生触摸点击。** 为保留输入焦点而取消pointerdown，只允许用于鼠标；触摸和笔输入不拦截默认行为，选择／收键盘由原生click触发。搜索结果和清空按钮都须在输入框仍聚焦时用原生tap验证，不能把click鼠标检查当作触屏结果。不要另外合成touchend点击，以免拖动误选或双触发。

**M39　页面跳转不得先闪登录。** 首次打开、改密返回、刷新和缓存恢复的身份未知阶段呈现中性等待；同一学生的课程↔纪念册软切换按M43–M45保留当前已显示画面，目标就绪后接替。学生401才进入登录，超时和服务暂时不可用给重试。不要从缓存推断登录成功，也不要把网络错误当作退出。旧学习码入口仍先确认当前身份。页面隐藏及缓存恢复继续遵循M32，不先展示旧学生的个人资料。

**M40　“我的”必须是同一个实现。** 课程／纪念册复用[AccountDialog](../../student-ui/AccountDialog.jsx)、[Dialog](../../student-ui/Dialog.jsx)与[共用样式](../../student-ui/styles.css)。同宽度下菜单内容、顺序、字体、控件高度、面板几何一致；≤600px为底部弹层，宽屏居中。标题和关闭保留，正文单独滚动，可见视口与safe-area参与约束；Esc、遮罩、明确关闭按钮均可退出，焦点回到触发点。

**M41　账号动作不改变资料归属。** 历史收藏保留版本数据，课程入口可直接进入纪念册历史面板；本机旧记录只读取匿名旧命名空间，不认领、不补星、不扫描其他学生私有队列。“纪念册动效”沿用原偏好键，两页及同页组件同步；它不代表控制课程地图动画。浏览器禁止存储时，开关在当前页面仍须生效，但不承诺刷新后记忆。退出失败保留面板并允许重试，成功才广播身份变化并回到入口。

**M42　共用修改必须双页验证。** 回归至少包含真实登录后的纪念册往返、接口延迟／失败／401、改密返回、桌面和手机“我的”比较、长姓名、旧记录只读、历史收藏、偏好同步及跨页退出。共用目录纳入检查输入；几何通过不代替目视，浏览器模拟不代替实体微信／夸克。目录类弹层只设置一个内容滚动区，空／短／长结果、底部最后一项和窗口变化都需检查。尺寸统计不得把等待和错误画面算成登录或首页访问。

本轮根因、实际截图、回归结果和未覆盖范围见[登录导航与共享我的修复](../designs/student-shell/2026-10-30-登录导航与共享我的修复.md)。

**M43　导航保持，内容柔和接替。** 课程与纪念册共用同一文档中的页面框架。手机品牌栏60px、底部导航64px加安全区，电脑品牌栏86px；品牌与导航不随内容淡出，也不因两页宽度或滚动条变化而移动。手机纪念册的品牌移至共享栏，邮局内不重复绘制第二份UI品牌。原环境图、纪念卡与三个卡位不重做。

**M44　过渡以真实就绪和动画结束为界。** 首屏原卡所需图片／字体准备好、DOM图片解码且布局有一帧机会完成后，才从旧页接替。新内容240ms渐显并轻移6px，导航160ms换色；旧页保持不透明承接，避免双层淡出露底。先恢复位置，下一帧开始动画，由`animationend`清理；1秒兜底只处理动画被取消。减少动态时不执行淡化和位移。界面装饰字体仍不作为原卡门禁。

**M45　慢网、取消与身份边界。** 同一学生的切换等待不清空当前画面，160ms后出现轻量提示，失败可重试／取消，快速改选只接受最后一次。预备页面不可交互，不提前打开弹层；首次打开没有旧页时提供等待／重试入口。学生或epoch变化、401立即撤掉旧个人内容；隐藏后恢复重新确认。主卡／章节与滚动位置按学生隔离，前进／后退、直接URL、刷新以及历史原证链接保持可达。

**M46　共用文档必须隔离样式和统计。** 邮局重置、字体、按钮及主题变量限制在自己的界面中，不能继承课程的按钮flex规则而使主卡变成零高。验收实际卡片宽高、保存面板、原生轻点和原GIF，同时检查过渡中间帧。两页访问统计在实际显示后更新，预备页不计访问，后台字体准备随页面进入／离开启动和取消。实现与证据见[柔和过渡实施记录](../designs/student-shell/2026-10-30-课程与纪念册柔和过渡.md)。

**M47　导出轮廓没有外留白或浅色隔离带。** 1640×880源画布中，4px深色卡框从最外沿起画，圆角外透明；满星金边紧接深色框，内线再接金边。只修正边界，不缩放／裁切人物、文字、星星、姓名和日期，输出仍为984×528、60帧、80ms／帧、无限循环。每帧先清空透明画布，禁止再铺不透明浅色垫底。

**M48　透明必须来自alpha，首帧也必须透明。** GIF保留透明索引0并与逻辑背景索引一致，所有帧都声明透明；源alpha小于128的像素写透明索引，其余调色板索引与透明索引隔离。不能按“白色”抠图，以免抠掉纸张、白衣和高光。保留固定调色板、静态像素索引稳定及增量帧；轮廓alpha在全部60帧保持一致，循环不出现边缘残影。

**M49　保存后的文件才是验收对象。** 直接下载真实GIF并解码全部合成帧，检查四角透明、四边贴合深色轮廓、边界无浅色像素、内部完全不透明及满星金边紧贴且持续变化。`hasAlpha:true`或后续增量帧含透明标记不能证明首帧没有白底。课程内与纪念册两条保存路径都要检查，保留姓名、星数、日期、取消导出和无额外成果写入的断言。当前修复及旧／新文件见[导出GIF白边修复](2026-10-30-导出GIF白边修复.md)。
