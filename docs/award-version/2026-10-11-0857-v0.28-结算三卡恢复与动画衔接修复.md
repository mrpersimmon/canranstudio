# 结算三卡恢复与动画衔接修复

用户确认：Lesson 1–2 结算恢复「连续答对／本次答对／本次答错」，其他文字保持克制；修复统计卡与悬浮纪念卡的动画体验。已获星环节重新挑战全对，也展示已有纪念卡和星光，不重复飞入新星、不增加星数、不改首次满星日期。

本次在 `codex/debug-reward-version` 独立工作树实施。本文替代 v0.27 中用单个首次答对比例取代三项统计的方案，其余文案精简保持。

## 结算画面

Lesson 1–2 五个答题区统一恢复三张统计卡，沿用原有金黄、鼠尾草绿和浅陶红配色及图标。上方保留人物插画与一句完成标题，下方保留一条获星状态、「再练一轮」和下一站操作。

| 指标 | 计算含义 |
| --- | --- |
| 连续答对 | 本轮最长连续首次答对题数。 |
| 本次答对 | 本轮每题第一次提交正确的题数。 |
| 本次答错 | 本轮第一次提交错误的题数。同一道题多次答错只计一题；之后订正不改写首次结果。 |

例如五题中第 3 题答错后订正，显示 `2／4／1`；五题首次全对显示 `5／5／0`。详细含义写入无障碍名称，不增加页面说明段落。题目、答案、奖励版本和存档签名均不变，中途作答可继续。

## 动画与展示规则

| 完成情况 | 悬浮纪念卡 | 统计卡 |
| --- | --- | --- |
| 首次整轮零错、服务端确认新星 | 卡片浮入、星星飞入并闪亮；第五颗点亮金边。 | 卡片关闭后，三卡依次入场、数字递增。 |
| 本环节已获星，重新完整挑战且零错 | 展示当前卡面、现有星光；已满星保留流动金边。不新增飞星，不改星数或日期。 | 卡片关闭后播放本轮统计动画。 |
| 答错后订正完成 | 不作为本轮新奖励展示。已有星星不扣回。 | 直接展示并播放本轮首次结果。 |
| 不兼容旧版本中途续做后完成 | 保留既定升级卡与文案，不补发新版星星。 | 关闭升级卡后展示本轮结果。 |
| 离线或同步失败 | 未确认前不预发新星。联网补传确认后展示新星。 | 不阻塞结果查看；若已展示并播放，补传后不重复统计动画。 |
| 刷新或重新打开已完成环节 | 不重播结算卡。 | 直接显示最终统计，不重复庆祝。 |

两类动画默认播放；系统减少动态不会自动取消用户明确选择的奖励展示。悬浮卡继续无多余按钮，点击任意位置或按 Enter、空格、Escape 关闭，并把焦点交还完成页操作。

重练展示规则属于共享奖励展示层，Lesson 1–2、3–4、5–6 同步适用。三项统计卡恢复只针对 Lesson 1–2。

## 根因与修复

1. v0.27 的文案精简移除了三卡结构和对应入场呈现，用户实际想保留这部分结果视觉。现恢复三卡，保留其余短文案。
2. 原奖励层只对新获星与升级续做排队展示；已获星环节零错重练不会触发新星事件，因此不弹卡。新增同一轮仅一次的重练展示事件，使用当前奖励快照；不修改奖励账本。
3. 统计动画原先可以在纪念卡占据前景时开始，用户关闭纪念卡后就看不到过程。现在同时检查可见性、奖励排队／准备／打开状态及同步等待状态，等完成页真正位于前景后再启动入场和跳数。
4. 新增逐帧检查发现三卡放大到峰值时，外侧卡片向容器外多出 2px。改为外侧卡片固定外缘、向内缩放，保留弹性效果；全过程无横向溢出。

新获星路径在改动前的真实账号桌面／手机尺寸检查中均能飞入和闪亮，未复现“所有新星动画都失效”。此次不把它误判为星星动画被删除；实际修复的是统计结构、前后播放时机和已获星重练的展示规则。

## 为什么旧检查没发现

原检查主要验证新获星、最终星数和最后截图，并明确把「重练不弹卡」作为预期。文案调整后的检查又只认首次答对比例，无法发现三卡视觉回退。最终画面检查也无法证明动画曾在用户可见的前景播放。

现在检查真实页面操作及逐帧结果：三卡位置变化、数字递增、弹窗与统计动画不重叠、已有星光持续变化、第五颗星后的金边角度变化，以及点击关闭和刷新后不重播。保留原计星、旧进度、日期、账号隔离及防加载闪回断言。
