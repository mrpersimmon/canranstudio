# 书本式纪念册样板与服务器负担评估

版本 v0.17；2026-10-09 10:20（Asia/Shanghai）；分支 `codex/debug-reward-version`。

用户已要求把 v0.16 的翻页书本做出来，并评估是否造成服务器卡顿。本轮完成可直接操作的本地样板：[打开纪念册](http://127.0.0.1:4264/)。代码在 `poc/award-book/`。Lesson 1–2、3–4、5–6 的主题沿用已确认设计。

**范围：这是展示和交互样板。页面明确标注示例姓名与获星记录，未接入真实账号收藏，也未修改课程计星、真实学生记录或线上数据。**

## 本轮实现

| 内容 | 实际行为 |
| --- | --- |
| 展开书本 | 桌面两页，手机单页；绿色封面、暖纸、书脊、照片角贴 |
| 翻页 | 前后按钮、键盘左右键、页脚横拖；桌面围绕书脊转动，约 580ms |
| 连续操作 | 翻动过程中锁定再翻页，结束后恢复；到首尾禁用，不越界或循环 |
| 动效偏好 | 默认尊重系统“减少动态效果”；目录内可开关翻页动画，偏好仅存本样板会话 |
| 目录 | 三课条目直达；按卡片 ID 恢复位置，双页切成单页仍看同一张卡 |
| 放大 | 点卡或放大按钮进入；关闭、返回、Esc 均回到原书页，焦点回到触发按钮 |
| 保存 | 浏览器生成独立 1640×880 PNG，不包含书本、网页按钮；三课均实际下载验证 |
| 星星 | 示例前两卡五星金边并显示日期；第三卡三星、普通边框、无满星日期 |
| 加载 | 三张卡和共用素材、字体准备并解码后再展示；失败保持等待页，可重试 |
| 小窗口 | 1280×720 下根据高度缩小书本，页面高 717px，翻页按钮底部约 668px，保持同屏 |

三课卡面中人物、课名、姓名、星星、日期分别渲染，姓名没有烘焙进故事插画。新生成的素材原稿与提示词存放在 `poc/award-book-assets/`；供网页使用的压缩文件在 `poc/award-book/src/assets/`。雨伞双人近景已重新收紧构图，修正首版人物显著小于手提包人物的问题。

## 会不会让服务器卡顿

**本样板的翻页和保存图片都在浏览器内完成。实测这两类操作没有新增服务器请求。需要重点控制的是多人首次打开时的图片、字体流量，不能把本地流畅等同于线上并发已经达标。**

| 项目 | 测量结果 | 证据与边界 |
| --- | --- | --- |
| 完整静态资源预算 | 710,597 bytes，约 0.71 MB | 对本地构建的 12 个资源逐一 HTTP GET，JS/CSS/HTML 使用 gzip；不含 HTTP/TLS 头，也不是浏览器首屏计时 |
| 有动画连续翻页 10 次、放大、返回、PNG 下载 | 新增请求 0；响应体字节 0 | [请求对照](evidence/2026-10-09-1020-v0.17-award-book/action-requests.json) |
| 完整复访 5 次 | 5 个 HTML 请求，共 1,930 bytes；图片/字体/脚本请求 0 | 每次等书页显示并核对上次卡片；[复访记录](evidence/2026-10-09-1020-v0.17-award-book/revisit-requests.json) |
| 加入现有完整中文姓名字库后的预算 | 1,969,129 bytes，约 1.97 MB | 当前样板字体仅包含演示文案；完整字库 1,296,316 bytes，不能忽略这一增量 |
| 服务器 CPU / 数据库 / 手机帧率 | 未测 | 本轮没有真实收藏接口或生产并发压测；浏览器底层性能读取被权限检查拒绝，未规避限制 |

静态素材文件名含内容版本，预览服务设置一年不可变缓存；HTML 每次重新核验。上述缓存结果只针对本地预览和本次浏览器，没有把它写成线上缓存验收。完整清单见 [HTTP 资源预算](evidence/2026-10-09-1020-v0.17-award-book/http-budget.json)。

此前容量记录提过 3 Mbps 出口，这一配置**本轮没有重新核验，可能已变化**。仅把它作为保守计算场景，静态资源总量 ÷ 375 KB/s 得到以下整批传输理论下限：

| 同时首次打开人数 | 演示字库版本约 0.71 MB/人 | 完整姓名字库约 1.97 MB/人 |
| --- | --- | --- |
| 1 | 约 1.9 秒 | 约 5.3 秒 |
| 30 | 约 57 秒 | 约 2 分 38 秒 |
| 120 | 约 3 分 47 秒 | 约 10 分 30 秒 |

这不是每个学生的等待时间预测，也不包含网络延迟、协议开销及课程、登录等其他流量。它说明小带宽在集中冷启动时会排队；增加翻页动画不会消除或造成这部分下载流量。缓存被浏览器清除后，也会重新发生冷加载。

## 正式接入建议

1. 打开纪念册时一次读取当前登录学生的收藏摘要。翻页不写数据库、不逐页重复查账号；换账号后先清除上一位的显示，再取新账号数据。
2. 复用已有获星账本，保留每版卡片与第一次满星日期。前端只展示服务器记录，不根据本地页面完成状态授星。旧版卡片保留规则沿用 ADR0023。
3. 通用插画、书页、星星、字体共用版本化素材；姓名和获星信息不进入公共缓存。沿用现有认证及资源访问边界，不用本样板替代权限设计。
4. 单元数量增加后只准备当前展开页和相邻页；切页前确保对应素材就绪。不要在首次打开时把整册所有高清图片全部下载。当前样板只有三张，均预先准备。
5. 完整中文字库应跨课程和纪念册复用、长期缓存，或进一步规划常用字分包；不能将当前只覆盖“小雨”和固定文案的精简字库直接当成生产字库。
6. PNG 继续由浏览器生成。服务器保存轻量的收藏记录，不在每次翻页或下载时生成证书图片。
7. 上线前核验真实带宽与静态资源分发方式，再做集中首开、已缓存复访、账号读取的分开压测；低端安卓和微信内的动画/保存要在真实设备验收。需要时用静态分发服务减轻源站带宽，不能仅凭本轮请求数宣称承载 120 人。

## 实际验收

只做页面行为验证及与这些行为对应的资源检查，没有通过直接写学生成绩制造证书。

| 场景 | 结果 |
| --- | --- |
| 首页前翻禁用、末页后翻禁用、奇数张留自然空白 | 通过 |
| 动画开启后 10 次前后翻、快速双击不越界 | 通过；留有[中间帧](evidence/2026-10-09-1020-v0.17-award-book/turning.jpg) |
| 默认系统减少动态效果、目录内开关动画 | 通过；无需改变系统设置 |
| 目录定位、键盘翻页、鼠标横拖页脚 | 通过 |
| 切换桌面/手机保持选中卡片、重开恢复位置 | 通过 |
| 1487×1058、1280×720、390×844、320×700 | 通过本地浏览器尺寸检查；窄屏无横向溢出，主要按钮至少 44px 高 |
| 放大、Esc/返回、恢复焦点、保存按钮同屏 | 通过；[放大视图](evidence/2026-10-09-1020-v0.17-award-book/modal.jpg) |
| 三课下载内容、尺寸、三星无金边无日期 | 通过，下载文件均为 1640×880 PNG |
| 单张必需图片返回 503 | 不展示任何证书，只保留重试；恢复服务后重试完整显示 |
| 本地浏览器警告/错误 | 最终样板页未发现警告或错误 |
| 手机真实触摸、微信、GPU 帧率、服务器并发 | 未验证，不列入已通过范围 |
