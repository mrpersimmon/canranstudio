# 书本式翻页纪念册设计

版本 v0.16；2026-10-09 01:01（Asia/Shanghai）；工作分支 `codex/debug-reward-version`。

用户在确认 Lesson 1–2、3–4、5–6 三组卡面后，提出“像书一样，翻页的形式”。本稿沿着该方向细化收藏界面，保留 [v0.15](2026-10-09-0026-v0.15-纪念卡收藏页方案与三课设计确认.md) 的账号收藏方案与已确认卡面。新的书本外观和翻页交互细节是本轮提案；没有实施收藏页或实际翻页。

## 书本形态

- 页面称“我的纪念册”，标题为当前登录学生姓名加“的纪念册”。
- 书本用低饱和绿色硬封面、暖白纸页、细书脊、轻微纸张层次与阴影。网页其余部分保持干净，书本作为主体。
- 桌面展开两页，每页放一张完整的横版证书。卡面不跨书脊，姓名、人物和五个星位保持完整。书页与卡片的材质和层级可区分。
- 卡片角贴位于边缘留白，不遮挡文字、人物、星星；纸角轻微卷起只表达可翻页，不永久盖住卡面。
- 保留三课各自的颜色和故事：手提包、雨伞、新朋友。收藏外壳不改变已确认的证书设计。
- 默认直接打开纪念册并恢复上次查看的卡片，不增加每次进入都必须点击封面的步骤。

图中显示第一页和第二页；第三页对应 Lesson 5–6。示例姓名“小雨”、五星和日期是虚构展示资料。

## 翻页与查找

| 操作 | 推荐行为 |
| --- | --- |
| 上一页 / 下一页 | 清楚的按钮，桌面切换一组展开页，手机切换一张卡 |
| 翻动页角 | 桌面允许拖动页角作为补充；明确按钮始终可用 |
| 手机横向滑动 | 可以翻页，纵向拖动仍由页面滚动处理，不能误触下一页 |
| 目录 | 按课号列出已收藏的卡片，点选直接跳到对应页；保留旧版本入口 |
| 点击证书 / 放大查看 | 打开该卡的独立清晰视图，提供保存；关闭后回到相同书页 |
| 首尾边界 | 到达首尾后对应翻页按钮禁用，不循环到开头，不产生假卡片 |
| 卡片数量为奇数 | 最后展开页保留自然空白纸页，不制造未获得的证书 |
| 更换设备宽度 | 保持当前选中的证书；按证书 ID 恢复位置，避免双页变单页时跳错 |
| 登录身份变化 | 收起上一位学生的书页，身份确认后读取当前学生收藏 |

翻页动效建议约 450–600ms：纸页抬起、围绕书脊转动、阴影随之变化并落下。翻页期间不叠加多个动画，连续点击最多保留一次后续翻页意图。系统开启减少动态效果时使用即时切换或短淡入；目录及按钮支持键盘操作，隐藏页不参与焦点顺序。

## 手机与下载

手机使用单页，不把桌面整本书缩进窄屏。证书约 320–340px 宽，保留轻微纸页边缘；触控目标至少 44px。点证书后可进一步放大查看。

保存操作位于具体卡片的放大视图，避免左右两张卡同时显示时，不清楚“保存”指的是哪张。下载仍输出已确认的独立横版证书，采用 1640×880，不把书脊、页码、纸角与网页按钮放进下载图片。

## 数据与加载

继续使用账号中的真实获星记录、登录姓名和固定首次满星日期；每单元五个答题区整轮零错才获星的规则不变。旧版卡面保留及首星自动收录等细则的确认状态见 v0.15，不能因为改了书本外观而视为这些新增规则已获确认。

翻页容器与纪念卡渲染器分离，书页从同一收藏数据生成。先准备当前展开页及相邻页的图片、字体和星星，完整后再展示；下一页未准备好时保持当前页，给出简短加载或重试状态，不翻到半张卡或空白错误页。复访复用版本化素材缓存并核验账号记录。

本轮不选定新依赖库，也不宣称翻页性能或真实手机兼容已经验证。实施时应先做可点击样板，覆盖双页、单页、首尾、目录直达和连续翻页，再接入真实账号收藏。
