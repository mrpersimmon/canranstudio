# 纪念册开场动画三方案 v0.25

2026-10-11 00:45。`codex/debug-reward-version`。本文件记录三案比较时的设计；用户随后已选择 A，正式接入与验证见 [v0.26](2026-10-11-0106-v0.26-A方案开书正式接入与验收.md)。以下样板入口及启动方式为历史记录，当前默认入口已采用 A。

## 设计问题

用户认为现有展开动画不自然。原实现同时横移整本书、旋转封面、裁切露出底图、淡入左页，最后又淡出封面；这些运动互不对应，容易形成多层画面拼接的观感。此次比较不同的开书方式，保留已确认的纸面、卡面、工作室图标、持续星光和书页翻页。

## 共用视觉

沿用暖纸 `#fdfbf5`、深棕 `#513422`、书皮深绿 `#344d3d`、鼠尾草绿 `#648066` 和星光金 `#edba52`。中文为 Award Book，课号和页码为 Baloo Book；比较控件使用清晰的系统字体。

页面仍为“真实账号页眉 → 学生的纪念册 → 居中的书 → 翻页操作”。打开后卡片回到同一书页中央，不设计新的收藏规则。只有底部小型比较条属于样板，包含切换、播放／暂停、重播及进度拖动。

## 三个候选

| 方案 | 开书方式 | 节奏 | 取舍 |
| --- | --- | --- | --- |
| A：侧翻书封，推荐 | 封面沿左书脊翻开，背面带着真实左页与卡片一起落下；根据书本实际展开范围保持整体居中 | 约 1.8 秒 | 最接近已确认的翻页纪念册；桌面展为双页，手机向左揭开单页 |
| B：向上揭封 | 横版封面绕上边缘抬起，逐渐露出固定书页 | 约 1.5 秒 | 动作清楚、内容位置固定，更像桌面相册；传统书本感较弱 |
| C：双扉展开 | 两片封面从中央向两侧打开，星花图标位于合拢处 | 约 1.7 秒 | 对称、仪式感强，更像双扉收藏夹；不是普通书籍的装订方式 |

三案不添加文字开场、额外音效或粒子。封面与纸页有明确的前后关系，不以整页闪白或换色强调展开。点击封面可以跳过，完成后直接进入真实收藏页；反复播放不改变成绩、星数、首次满星日期或收藏内容。

## 预览与隔离

完整账号预览使用隔离本地数据，保留原有预览同学的真实收藏。

- A：`http://127.0.0.1:4274/lesson/awards/?prototype=opening&variant=A`
- B：`http://127.0.0.1:4274/lesson/awards/?prototype=opening&variant=B`
- C：`http://127.0.0.1:4274/lesson/awards/?prototype=opening&variant=C`

启动：`LESSON_OPENING_PROTOTYPE=1 LESSON_PORT=4274 LESSON_ORIGIN=http://127.0.0.1:4274 LESSON_DATA_DIR=.data/award-account-preview npm run preview:login`。继续使用已有本地测试账号。

只在显式启用样板构建、浏览器为本机地址且带有 `prototype=opening` 参数时显示。默认构建排除样板代码与样式；生产模式即使误设样板环境变量也不启用。普通 `/awards/` 仍保留原开场。候选代码集中在 `award-book/opening-prototype.jsx` 与对应样式文件，选定后再将单一方案正式接入。
