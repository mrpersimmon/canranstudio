# 时光邮局影响性验收与发布说明

2026-10-30。按用户要求将已认可的纪念册改版通过PR合入 `codex/release-canranstudio` 并发布官网。本轮只执行影响性检查，不运行全部课程浏览器回归或完整GitHub CI；远端检查未运行不等于通过。

## 合入范围

正式 `award-book/` 采用时光邮局，支持72单元／24章、跨章Lesson搜索、点击主卡保存原GIF；原卡、星数、姓名、首次五星日期与历史资料保留。服务端授星、课程授权和数据库结构不变。已合入发布分支的手机地标触摸修复继续保留。

既有单课浏览器检查迁移到新的纪念册入口，未删去原授星、数据隔离或导出断言。原型作为已认可的视觉和提示词依据一起归档，不进入生产运行包。

WebKit最初图片失败用例收到的仍是HTTP 200，页面级拦截没有形成预期故障，随后执行器在失败收尾时挂起；日志和trace保存在本机私有发布目录。故障注入改到既有测试服务器响应层，延迟用例还核对服务器确实握住了请求。未通过放宽可见性、星数或恢复断言解决。

Windows WebKit不提供 `-webkit-tap-highlight-color` 计算值，检查明确记录该平台限制；支持此属性的Chromium继续断言透明值。真实Android微信／夸克及iPhone真机仍需单独实测，不能由模拟视口或上述结果替代。

## 发布边界

从最终合并提交生成不可变版本。仅替换纪念册源码和新承载素材，生产依赖锁、原课程、旧纪念卡与历史资料保持可核对。发布前备份数据库、兼容密钥、Nginx及服务配置；先在隔离数据库上启动候选版本并核验，再切换 `current`。启动或数据核对失败时恢复旧代码，保留当前学习数据。

线上验证包括HTTPS匿名保护、实际运行提交、纪念册构建指纹、已获卡只读核对、服务健康与切换前后业务数据审计。正式切换结果以本次PR和部署回执为准，本文的本地通过结果不代替上线验收。
