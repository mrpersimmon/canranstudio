# 时光邮局正式接入与验证

2026-10-30，`codex/book-version`。用户认可时光邮局方案后，本分支将它接入正式 `award-book/`，覆盖Lesson1–144的72个配对单元、24章。`/awards/` 使用真实登录账号和原收藏接口；原型保留作视觉依据，官网尚未发布。

## 页面与数据

手机采用邮局柜台、一张主卡和三个固定选择位；电脑增加章节侧栏，并限制场景宽度。标题旁放大镜打开全收藏搜索，支持单号、范围、全角数字和卡名。主卡点击打开保存面板，没有独立“查看原卡”按钮、放大原图链接或新窗口入口。

每课一张主卡，历史版本进入“我的 → 历史收藏”。原纸证和本机副本的既有查看、下载路径保留。空收藏显示学习入口；稀疏收藏保留三个原始卡位，缺卡标为“尚未收藏”；未满五星不加满星金框和日期。撤下课程仍保留已得卡，但不会重新开放课程。

正式卡片复用原人物素材、字体、`award-card-layout` 和 `award-gif`，在1640×880设计平面中整体缩放。环境图与原型v3逐字节相同。数据读取及待同步队列逻辑经换行标准化后与原实现一致；没有改动授星、首次满星日期或账号接口。

## 本次发现并修复的问题

| 问题 | 根因与修正 |
| --- | --- |
| 切卡时信封透过卡面 | 整张卡从0.75透明度淡入，露出了背景翻盖。改为始终不透明，只做4px轻微位移；72张逐卡选择均测得opacity为1。 |
| 搜索抽屉在电脑上底部越界 | 最大高度已经是“视口高减32px”，顶部又加70px居中外边距。改为以实际可见视口中心定位；首次900高视口bottom=938的失败记录保留，修正后bottom=884。 |
| 初次等待时打开“我的”可能取消卡片准备 | 个人面板和选卡共用取消序号。现在打开／关闭个人面板不取消首次准备；后续改选仍只接受最后一次请求。 |
| 超时后可能继续等待同一条未完成资源 | 只对外层Promise限时不足以结束图片请求。图片本身18秒限时并释放失败项，整体准备20秒上限；恢复后重新请求。 |
| 新界面与旧测试入口不一致 | 将既有纪念册的“目录”“放大”“书页”入口迁移到搜索、主卡和邮局场景；旧证测试改从“我的 → 历史收藏”进入。保留授星、日期、版本、账号隔离和原导出断言，翻书专项改为真实加载／重试和横卡交互检查。 |

上述规则固化到[统一标准v1.1](纪念册统一设计标准.md) M27–M35。

## 验证边界与交付状态

本轮没有运行完整CI、Playwright CLI、WebKit或真实Android／微信／夸克／手机软键盘检查。历史旧纸证完整迁移、真实新增作答到授星的全链和离线待同步全链保留已有回归用例，但本轮没有重跑；当前的部分星与空收藏UI样本使用隔离本地夹具。60尺寸通过不等于95%真实流量已覆盖。
