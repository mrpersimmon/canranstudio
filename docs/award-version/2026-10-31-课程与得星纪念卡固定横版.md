# 课程与得星纪念卡固定横版

2026-10-31 · `codex/book-version` · 本地修改，未提交、推送或发布。

## 根因与修正

用户在375×667标注的纪念册卡片是横版，课程卡片却成为竖版。实页测得旧课程卡宽332、高386.04，比例约0.86；`story-certificate.css`、`award-card-layout.css`和`award-reveal.css`都有≤600px的竖版规则。旧规则还将人物移到文字下方，因而仅锁定外框比例不能恢复一致构图。

纪念册已经采用1640×880固定设计平面。本次把它的外层占位、内层等比缩放和宽度观察逻辑移入共用模块，课程及得星弹层复用相同实现。卡面字形、人物、星位、边框和纸纹一起缩放，去掉手机竖版及重复的宽高比来源。课程最大宽度保留720px；得星弹层同时按可用宽度、高度收拢整张卡，确认提示留在卡外。

修改后同一375×667页面的卡片为332×178.15，比例1.863636，与1640∶880一致。没有重新生成卡面，没有修改内容版本、课程作答、姓名、日期、奖励规则或GIF绘制坐标。
