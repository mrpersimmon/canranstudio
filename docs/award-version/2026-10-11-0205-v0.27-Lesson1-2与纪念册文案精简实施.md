## 条件状态

| 状态 | 当前文案 / 行为 |
| --- | --- |
| 空纪念册 | 点亮第一颗星，收藏第一张纪念卡。 入口按钮用「去学习」；完整获星规则在课程星星进度处解释。 |
| 打开失败 | 标题「暂时打不开纪念册」，说明「请重试，已获纪念卡会保留。」；保留重试操作。 |
| 登录失效 | 请重新登录 + 去登录 按钮与需要完成的动作一致。 |
| 等待同步 | 记录待同步，联网后自动更新。 等待队列未必每条都产生新卡，不应承诺每条成果都会加入纪念册。 |
| 多卡页码 | 按实际书页计数；三张卡在桌面显示「第 1 / 2 页」，手机显示「第 1 / 3 页」，已使用真实获星的三张卡验证。 |

同步状态按实际请求显示：在线请求未确认时为“正在同步星星…”，请求失败或离线时为“已保存，联网后同步星星。”，服务端确认后才显示“已获星”。已答但未完成的本轮草稿仅保存在当前设备，学习记录显示“本轮草稿已保存到本机。”，不混同账户同步。
