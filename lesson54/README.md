# Lesson 54 · 环球护照之旅 Ⅱ

延续 Lesson 52，学习国家、国籍，以及 does／doesn't 疑问句和否定句。

1. **单词签证官**：12 组国家与国籍词卡，听音挑国。
2. **到达大厅广播剧**：听 12 位旅客介绍国籍和来源。
3. **护照盖章**：完成 12 对国家与国籍配对。
4. **句型魔法屋**：练 does／doesn't，后面的动词使用原形。
5. **海关终极考核**：完成 8 道题。
