# 深色路线资源

三组素材分别为橙色关卡底图、金色完成底图、完整探险猫。原始 PNG 与完整提示词同名保存；页面使用对应 WebP。

运行资源使用 Pillow 的 LANCZOS 等比缩放和 WebP quality=90、method=6：节点最大边 256 px，角色最大边 480 px，保留透明通道。该转换仅用于体积与显示尺寸适配；角色及底图内容来自内置 Image Gen。

`icons/` 来自 `@phosphor-icons/core` 2.1.1 的 fill 版本，未修改矢量路径。MIT 许可保存在 `icons/LICENSE` 并随每个实际发布的 SVG 注释保留。页面通过颜色角色区分活动、已完成、未解锁与导航。

用户提供的 Duolingo 原图位于设计参考目录，不作为运行素材发布。
