# 礼貌小帮手 · Lesson 1–2

本分支为**无配音课堂配套版**，全课 **37题**，其中**语法小工坊12题、综合挑战10题**。入口 `/unit1-2/`；带加载缓存的预览入口 `/lesson/unit1-2/`。

当前实现见[五区整合 v1.5](../docs/butcher-version/2026-10-09-1134-v1.5-Lesson1-2五区整合与验收.md)：固定五个答题区，每区整轮首次零错获一颗星。按《同步导学》Grammar 学会辨认问句、运用 is／are／am、作简短回答。短示范随题出现，再逐步撤掉；礼貌表达继续在原文和还包情境里学习。

| 章节 | 活动与必做题数 |
| --- | --- |
| 身边的小物品 | 物品小图鉴；单词寻宝5题 |
| 手提包的故事 | 七句课文；故事小侦探5题 |
| 语法小工坊 | 12题连续练习 |
| 街角小帮手 | 帮忙还手提包5题 |
| 小帮手出发 | 礼貌小挑战10题；单元证书 |

七句原文、21张音标词卡、五句礼貌表达、十组物品替换例句保留。`#learn/phrases` 兼容到 `#learn/trans`，`#learn/ask` 兼容到 `#learn/listen`。礼貌与替换材料在还包环节下方展开。

`content.js` 管理题目和精确历史版本；`grammar.js / grammar.css` 负责嵌入式示范；`completion.js / completion.css` 统一五个答题环节的人物成果画面、三张结束卡与认可的新图标；作答状态仍由共用练习组件管理，获星凭据由 `core/award-rules.js` 在页面与服务器按同一规则核验。改题换题号与轮次版本，禁止旧答案填新题。页面验收见 [tests/README.md](../tests/README.md)。

结算修订见[v1.4与验收](../docs/butcher-version/2026-10-09-0121-v1.4-Lesson1-2结算页恢复与验收.md)。
