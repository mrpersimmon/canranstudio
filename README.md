## 本地预览

先安装 Node.js 24 或更新版本。向用户交付预览默认按[班级访问运行说明](deploy/login/README.md)启动正确工作树的完整账号服务，使用独立测试学生，包含首页与纪念册。下面的静态服务仅用于内部课程与缓存检查，不作为账号交付验收。在项目文件夹打开终端，逐行运行：

```bash
npm ci
node tests/support/static-server.js
```

看到服务已启动的提示后，打开 [本地首页](http://127.0.0.1:4173/)。终端保持打开；结束时按 Ctrl+C。不要直接双击 HTML 文件。
