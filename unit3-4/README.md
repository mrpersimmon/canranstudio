# 雨伞认领小帮手 · Lesson 3–4

从“我的课程”进入，或打开本地 `/unit3-4/`。启动方式见[项目首页](../README.md)。

先图鉴、听音，再学完整衣帽间对话，练习礼貌认领、肯定／否定确认及 my、your。25 张带音标词卡、12 句课文、27 道必做题、63 段录音，完成五关后领取证书；书写与真人对话放在可打印的小任务里。“你我的接力”用四题练听懂归属、肯定回应、交换说话人与不猜未知主人；完整否定由前面的基础拼句训练。

共用要求见[统一标准 v1.20](../docs/butcher-version/publish/2026-09-24-2031-v1.20-教学单元设计标准与验收清单.md)。当前题稿与实际验证见[三单元练习去重与验收](../docs/butcher-version/2026-09-21-0055-v1.0-三单元练习去重与验收.md)，教材依据和来源见[初版单元文档](../docs/butcher-version/2026-09-20-2227-v1.0-Lesson3-4教学单元与验收.md)。内容在 `content.js`，声音清单在 `audio/manifest.json`。
